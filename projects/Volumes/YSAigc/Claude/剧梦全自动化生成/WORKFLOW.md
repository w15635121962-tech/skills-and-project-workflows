# 自动化工作流与闸门

## 阶段

1. `INGEST`：读取 TXT、DOCX 或 Markdown；保留原文，不覆盖输入。
2. `STORY_BIBLE`：结合原剧本识别人物、场景、道具、人物弧线、社会背景、世界观规则，并标记“剧本事实 / 推断 / 待确认”。
3. `CLAUDE_STORYBOARD_SPLIT`：用户手动投喂 Claude；流程不操控 Claude。若用户保存并提供本地结果，则读取为可选结构参考。
5. `ASSET_BINDING`：读取资产 manifest，按稳定 `id` 绑定；缺失、重复、尺寸异常或身份冲突均进入 QA。
6. `ASSET_UPLOAD`：先上传并核对主角资产卡。主角资产缺失或身份绑定不确定时阻断；除主角外的角色、场景图、道具图缺失时，统一由提示词按文字描述保守补全，并在 QA 中记录 warning，不阻断后续流程。
7. `DOUBAO_PLAN`：将剧本、Claude 的拆镜结果和独白时长交给豆包 2.1 Turbo，分析人物表演、角色走位、戏剧冲突、镜头机位、视线、光影和声音；自动读取其结构化本地文件并与原剧本核对。
7. `STORYBOARD`：先按本地独白时长和 Claude 镜头边界拆分镜头，再合并豆包设计，建立轴线、屏幕左右、背景锚点和角色视线；任何外部分析不能替代剧本事实校验。
8. `CODEX_FORMAT_C`：由 Codex 独立生成最终 Format C V2.6 提示词，按光影连续单元分组，输出 11 个固定字段、具体构图参数和焦段；独白/旁白不进入生成提示，仅保留原英文对白。
   - 自动读取豆包结构化文件，匹配“对白与对白反应”，合并人物微表演、走位、视线、机位、戏剧冲突、光影、音频和负面约束。
   - 每组必须遵循“触发事件 → 人物初始状态 → 行动/走位 → 阻力与冲突升级 → 情绪高潮/台词 → 结果性反应 → 新稳定状态”的因果链；禁止连续生成纯人物状态。
   - 每镜必须写明具体景别、全画幅等效焦段（mm）、机位高度、轴线、构图比例、景深、视线偏移和前景遮挡状态。
6. `FORMAT_C`：将批准的镜头转为完整 Format C；每镜必须自包含，不允许凭空添加角色、道具或结果。最终提示词生成器为 Codex，不由 Claude 代写。
7. `JUMENG_DRAFT`：使用本机 Chrome 原生文件选择器上传主角资产卡，确认主角资产已显示并整理，再填写提示词；场景、道具和非主角角色按提示词补全；默认只保存草稿。
8. `HUMAN_GATE`：人工确认资产、剧梦模型“剧梦2.5Pro”、480P 分辨率、画面比例、时长、生成数量和积分消耗。
9. `GENERATE`：逐批提交并记录任务 ID、提交时间、消耗（若页面可见）和截图路径。
10. `QA`：检查生成结果的身份连续性、资产引用、轴线、口型、对白反应、动作终态、画面比例和平台报错；失败任务进入重试队列，不自动无限重试。

## 状态与恢复

每个 run 目录是一次可恢复事务。阶段成功后写入 `stage.json`，失败写入 `error.json`；重新运行只从缺失或明确要求重做的阶段开始。平台页面选择器变化、登录过期、积分不足和任何不确定的提交状态都必须暂停并要求人工处理。

## 平台适配契约

平台适配器需要实现以下动作，但不读取密码或导出 Cookie：

```text
open(url, profile_dir)
assert_logged_in()
upload_asset(file, target_folder)
fill_prompt(prompt)
select_model("剧梦2.5Pro")
save_draft()
request_generation_confirmation()
submit_generation()
collect_job_status()
```

如果剧梦没有稳定的公开 API，建议用独立浏览器的受控页面自动化；所有提交按钮前设置硬闸门，不能通过坐标盲点或忽略异常弹窗。

## 本机配置清单

- `config/local.json`：剧梦网址、浏览器类型、独立 profile 目录、dry-run、模型和积分闸门。
- `assets/manifest.json`：用户自己的图片资产清单及剧本实体绑定。
- 资产上传顺序：人物资产卡 → 场景资产卡 → 道具资产卡；三类均须完成上传和绑定核验。
- 浏览器 profile：由用户在本机创建并手动登录；不要复制到仓库。若内置浏览器无法弹出本地文件选择器，改用本机 Chrome 打开同一项目 URL；点击“本地上传”后，在 macOS 文件选择器中用 Command+Shift+G 输入绝对路径，再选择文件并点击“打开”。
- 积分：只能通过剧梦页面现有授权；本框架不生成、绕过或伪造积分。
