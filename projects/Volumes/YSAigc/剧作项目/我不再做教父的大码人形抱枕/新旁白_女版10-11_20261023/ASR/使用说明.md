# 新女版 EP10–11 独立音频验收

已验证本地 Python 3.12、MLX Whisper、large-v3-turbo 缓存模型及其哈希。准备阶段不扫描音频目录、不打开源音频、不运行识别。

制作清单固定为 `准备/manifest.json`，SHA-256：`bb46836fac7f1f325a431c4705dab336ccee79fa5a15dddf4ab5e1a972b4c6fe`。仅女版第10集6段、第11集7段；精确音色为“对标女旁白_测试A_1020”，Seed TTS／文本朗读，正常原速。音色与原速的界面证据由制作代理提供，识别和媒体参数不能证明音色身份或原速。

每批必须由制作代理或 Root 明确提供不可变的白名单绝对路径及该 JSON 的 SHA。白名单结构：

```json
{
  "version": "female_new_narration",
  "manifest_path": "本任务/准备/manifest.json的绝对路径",
  "manifest_sha256": "bb46836fac7f1f325a431c4705dab336ccee79fa5a15dddf4ab5e1a972b4c6fe",
  "files": [
    {
      "episode": 10,
      "narration_sequence": 1,
      "take": 1,
      "source_path": "已下载MP3的绝对路径",
      "sha256": "实际源文件的64位SHA",
      "bytes": 1
    }
  ]
}
```

`bytes` 必须替换为实际文件大小，示例的 1 不是有效交付数据。允许明确白名单中的备选 take，不自动寻找或替换首版。

执行入口：现有 `/Users/zc/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3.12` 运行本目录 `验收精确白名单.py --execute --whitelist 白名单绝对路径 --whitelist-sha256 白名单SHA`。

脚本先核对清单、路径、命名、集序、源大小及精确哈希，再使用技能自带 probe/loudness 只测量源参数和 true peak。单音轨完整解码到内存，记录有限 PCM、峰值、接近满幅样本、前后静段。盲识别仅英文、无 initial_prompt/hotwords/期望文本；原文比较发生在识别后。普通词缺失、重复、发音疑点须报告，不能用专名容错吞掉。保留原始识别词码及差异区间。

输出仅写入本任务 ASR：逐文件原始 JSON/TXT/TSV、测量记录、批次报告。媒体前后哈希和文件状态保持一致；不生成或修改源音频，不连接浏览器、达芬奇或网络。技术阈值仅作诊断，不自动剪静音、不自动调音量、不声称人工听审。第二模型复核仍需 Root 指定精确文件与疑点。
