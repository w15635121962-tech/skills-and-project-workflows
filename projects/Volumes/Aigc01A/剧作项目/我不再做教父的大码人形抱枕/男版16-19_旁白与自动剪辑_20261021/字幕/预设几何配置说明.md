本批预设driver不含旧ST1坐标，且尚未执行。先由根代理通过当前CUA截图和AX确认字幕轨空白位置及检查器结构，再写实际的 `current_preset_geometry.json`。

```json
{
  "verified_from_current_screenshot": true,
  "verified_from_current_ax": true,
  "inspector_ax_group_paths_verified": true,
  "observed_at_utc": "本次观察的带时区UTC时间",
  "screenshot_path": "/本次CUA截图绝对路径.png",
  "screenshot_sha256": "截图真实SHA256",
  "window_bounds": ["当前全局X", "当前全局Y", "当前宽", "当前高"],
  "st_blank_point": ["截图确认的字幕轨空白全局X", "截图确认的全局Y"]
}
```

坐标必须是数字。driver检查图片hash、观察不超过20分钟、当前窗口位置大小完全一致，四集SRT均已入轨且逐条等同源文件，才可点击。每集切换后重新检查窗口、精确集号和原生Track上下文；菜单项位置每次从当前AX按精确父预设名称和 `加载预设` 子项重新读取。保存前确认AV来源、剪点、增益、链接和字幕正文/时间全部未变。

用户本会话已明确允许AppleScript/JXA/CGEvent真实鼠标点击；本地driver只用于本批目标字幕预设，不执行其他平台或发送操作。

仅离线校验：`apply_track_presets.py --geometry current_preset_geometry.json`

实际加载：`apply_track_presets.py --geometry current_preset_geometry.json --execute`

可用 `--episodes 16` 先验证一集，再按新状态继续剩余集。真实预览和保存重开核验另执行，不把菜单点击当成完整视觉验收。
