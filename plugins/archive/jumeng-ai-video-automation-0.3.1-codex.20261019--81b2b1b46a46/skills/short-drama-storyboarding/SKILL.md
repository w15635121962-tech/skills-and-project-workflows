# 分组镜头设计兼容入口

按当前请求选择交付物：

- 用户仅要镜头设计、分镜或表演方案时，直接交付分组镜头和动作时间轴。每组说明本组作用、人物起始状态与位置；各时段写可见行动、对手反应、原台词及声音；最后写稳定终态和前后接续。镜数、时长、景别、运镜和同框人数依内容选择，不附加独立导演表、资产账本、自检表或Word文件。
- 用户要求最终视频提示词时，读取 [分组时间轴表演提示词](/Users/zc/.codex/skills/short-drama-prompts-v3/SKILL.md)、[时间轴模板](/Users/zc/.codex/skills/short-drama-prompts-v3/references/timeline-format.md) 和 [表演写法](/Users/zc/.codex/skills/short-drama-prompts-v3/references/performance-writing.md)。新写、续写或重做采用 Sxx 标题、风格与主情绪、光影、资产映射及连续分段时间轴，不再强制 Shot 八字段；原台词逐字保留。已有批准稿局部修改冻结未请求的事实和结构，不借格式更新重排。
- 用户要求剧梦操作时，读取 [统一剧梦技能](/Users/zc/.codex/skills/jumeng-episode-producer/SKILL.md)，仅完成已授权阶段。设计稿或技能维护不自动授权平台操作。

源剧情、当前用户要求和指定资产为准。新设计重新推导动作路线、主语、反馈和稳定终态；换机位重新核对左右、轴线、视线、道具及支撑面。局部修订保留未请求事实；仅绑定批准稿时复用正文。旧例中的人物、项目、固定镜数时长、人数和数字构图参数不作为当前默认。
