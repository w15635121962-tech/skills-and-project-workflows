# Seedance 2.0 Multimodal Creation Guide

## Entry Point Decision Tree

```
用户素材输入
├── 仅首帧图 + 文本prompt
│   └── → 使用「首尾帧」入口
└── 多素材组合（图+视频 / 图+音频 / 全部）
    └── → 使用「全能参考」入口
```

**首尾帧入口特点：** 优化于图生视频，首帧锁定画面风格与构图，prompt 控制运动与叙事
**全能参考入口特点：** 完整多模态控制面板，每类素材独立标注用途，支持最多4类素材同时输入

## @Annotation Standards

### 标注格式
`@素材文件名 用途：[用途类型]`

### 用途类型定义

| 用途类型 | 适用素材 | 标注示例 |
|---|---|---|
| 首帧 | 图片 | `@赛博街道.png 用途：首帧，锁定赛博朋克霓虹街道风格` |
| 尾帧 | 图片 | `@爆炸定格.png 用途：尾帧，定义序列终点画面` |
| 参考镜头 | 视频 | `@推镜头示例.mp4 用途：参考镜头语言，推镜头从远景到特写` |
| 角色动作 | 视频 | `@奔跑动作.mp4 用途：角色动作参考，快速奔跑姿态` |
| 配乐 | 音频 | `@电子配乐.mp3 用途：配乐，电子音乐，120BPM，情绪基调=悬疑，高潮=15秒` |

### 标注原则
1. 每个素材必须有且仅有一个明确用途
2. 用途描述需包含具体控制要素（什么风格？什么镜头？什么节奏？）
3. 音频必须标注：音乐类型 + BPM + 情绪基调 + 高潮时间点

## Compliance Checklist

### 禁止类素材（系统自动拦截）
- [ ] 写真真人面部照片
- [ ] 真人面部视频片段
- [ ] 任何可识别真实人物面部的素材

### 替代方案（合规素材）
- [ ] 动漫/插画风格角色
- [ ] 剪影或背影视角
- [ ] 非人类主体（机器人、动物、抽象形体）
- [ ] 第一人称视角（不露脸）
- [ ] 风格化/抽象化处理的人物

### 素材质量要求
- [ ] 首帧图 ≥ 1080p，风格明确，光影清晰
- [ ] 参考视频镜头运动可辨识（推拉摇移清晰）
- [ ] 音频节奏明确，无严重噪音

## Parameter Configuration Guide

### 运动幅度 (Motion Intensity)

| 场景类型 | 推荐值 | 原因 |
|---|---|---|
| 肖像/静态场景 | 低 | 减少不必要的画面抖动 |
| 对话/行走 | 中 | 自然的人物运动幅度 |
| 追逐/动作 | 高 | 匹配快速运动节奏 |
| 抽象/艺术 | 高 | 增强视觉动感 |

### 风格化程度 (Stylization)

| 目标 | 推荐值 | 原因 |
|---|---|---|
| 保持首帧风格一致性 | 80-100% | 最大程度锁定风格 |
| 适度写实变化 | 60-70% | 允许自然光影变化 |
| 高度写实 | 50-60% | 更接近真实摄影 |

### 生成时长 (Duration)

| 策略 | 时长 | 原因 |
|---|---|---|
| 精准控制 | 5秒 | 风格最稳定，适合关键镜头 |
| 标准片段 | 5-10秒 | 平衡控制力与叙事完整性 |
| 长片段（不推荐） | 10秒+ | 风格漂移风险高 |

## Multi-Segment Continuity Protocol

### 衔接方式

| 衔接类型 | 适用场景 | 操作 |
|---|---|---|
| 匹配剪辑 | 场景切换 | 前段末帧物体 = 下段首帧物体 |
| 动作顺接 | 连续动作 | 前段末帧 = 下段首帧（动作惯性延续） |
| 声音桥接 | 音频连续 | 音乐不中断，画面内容切换 |
| 风格锚定 | 风格一致性 | 所有段落 prompt 保持相同风格关键词 |

### Prompt 衔接模板

**延续指令：**
```
延续上一场景，角色继续[动作描述]，保持相同光影与色调，[新增叙事指令]
```

**风格锚定词（每段必含）：**
```
保持[艺术风格]风格，色调[色调描述]，光影[光影描述]
```

### 分段规划模板

```
片段N ([起始时间]-[结束时间])：[场景一句话描述]
  首帧：@图片N 或 [上一段末帧截图]
  提示词：[五要素提示词 + 风格锚定]
  衔接方式：→ [匹配剪辑/动作顺接/声音桥接]
  参数：运动幅度=[低/中/高] 风格化=[X%] 时长=[X秒]
```

## Audio-Visual Sync Mapping

### 基础映射规则

| 音频事件 | 视觉响应 | 镜头策略 |
|---|---|---|
| 鼓点/Beat drop | 冲击动作（拳击落地/爆炸/切镜） | 快速剪辑，动作匹配 |
| 渐强/Build-up | 推镜头，画面收紧，特写递增 | 缓慢推镜头，景别递减 |
| 静音/Breakdown | 静态远景，环境细节，呼吸空间 | 固定或极慢运动，大景别 |
| 旋律高潮/Chorus | 动态运动，揭示镜头，情绪顶点 | 多轴复合运动，景别跳跃 |
| 低音/Bass hit | 画面震动，重心转移，地面冲击 | 手持震动，低角度 |

### 音频标注规范

```
@音频文件名 用途：配乐，[音乐类型]，[BPM数值]BPM，情绪基调=[悬疑/欢快/史诗/宁静/悲伤/紧张]，节奏结构=[前奏Xs-主歌Xs-副歌Xs]，高潮时间点=[X秒处]
```

**示例：**
```
@史诗配乐.mp3 用途：配乐，管弦乐，95BPM，情绪基调=史诗，节奏结构=前奏5s-铺垫10s-高潮15s-收尾5s，高潮时间点=20秒处
```

## Post-Generation Editing

### 角色更替
提供新角色首帧图 → `@新角色图.png 用途：替换角色，保持原视频动作与光影匹配`

### 片段删减
标记需删除的时间戳范围 → 使用编辑功能精确裁剪

### 片段增加
提供新增片段首帧 + 五要素提示词 → 使用编辑功能插入整合

## Common Problems Quick Fix

| 问题 | 原因 | 解决方案 |
|---|---|---|
| 风格漂移 | 首帧风格不够明确 | 提高首帧质量，风格化90-100%，强化风格关键词 |
| 角色变形 | 复杂姿态或多角色 | 简化构图，使用单一风格化角色 |
| 动作不自然 | 运动幅度与复杂度不匹配 | 复杂动作用低幅度，简单动作用高幅度 |
| 场景不连贯 | 分段间缺少衔接 | 上段末帧作下段首帧，prompt保持风格词一致 |
| 水/烟雾不真实 | 物理描述不够具体 | 添加"符合重力"、"带空气阻力"等物理约束词 |
| 人物模糊 | 运动过快 | 降速或添加运动模糊描述词 |
| 真人脸部被拦截 | 使用了写实素材 | 换成动漫/剪影/背影/非人类主体 |
| 音频画面不同步 | BPM标注不准 | 标注精确BPM和beat drop时间点 |
