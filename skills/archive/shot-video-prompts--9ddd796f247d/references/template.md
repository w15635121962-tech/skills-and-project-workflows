# 用户指定的通用格式

以下为结构模板，方括号内容须替换为当前任务事实；没有依据的内容不得当作事实补写。

```text
出场角色：[角色名称及必要身份]。
场景：[时间，地点]。
以下所有Shot出场的角色和场景统一锁定参考图。[仅在已提供参考图时使用；否则写明待提供。]
画幅：竖屏 9:16。

Shot01：

时长：[秒数]秒；
环境氛围：[时间、场景、光线和气氛]；

景别：[中文景别]（[缩写]）；

拍摄角度：[机位方向、高度、俯仰及必要构图说明]；

摄像机运动：[固定或具体运动方式]；
人物角色和运动：[人物初始位置、动作执行者、对象、动作过程和终态]；
人物表演：【角色名】[可见的神态、目光、肢体及反应]；

画面内容：[主体、构图、前后景、空间关系和叙事重点]。
```

后续Shot重复同一字段顺序。镜数、时长、景别与运镜由当前内容决定，不机械复用示例的三镜组合。
