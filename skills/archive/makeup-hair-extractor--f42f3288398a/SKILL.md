# 妆发造型提取技能

## 用途

从影视剧本的场次描述或参考图中，精准提取妆发造型信息，输出结构化档案，供：
- 妆发部门造型设计与执行
- 跨场次妆发连续性核查
- AI 生图/生视频中的妆发 Prompt 素材
- 演员妆发档案管理与复盘

**按场次顺序整理，每个场次单独分析发型、妆容、发饰。**

---

## 触发条件

- 用户提供剧本文本并要求提取妆发信息
- 用户上传角色参考图并要求分析妆发造型
- 用户需要生成妆发清单或妆发档案
- 用户需要检查妆发连续性（跨场次状态一致性）
- 用户需要 AI 生图用的妆发描述 Prompt

---

## 输入模式

| 模式 | 输入内容 | 分析依据 |
|------|----------|----------|
| **图片模式** | 角色剧照 / 造型参考图 | 视觉识别，直接观察妆发 |
| **剧本模式** | 剧本文本 / 场次描述 | 从文字中推断妆发信息 |

**剧本模式说明：**
- 扫描剧本中所有与妆发相关的描述（包括场景说明、人物状态、对白暗示如「擦口红」「摘假发」）
- 按角色 × 场次维度整理，若剧本未明确描述则标注「剧本未提及，建议参考视觉参考图」
- 可结合剧情语境进行合理推断（如「葬礼场景」推断素净淡妆），但推断内容需注明「依剧情推断」

---

## 执行流程

### 第一步：确认输入

**图片模式：** 收到图片后，若用户未标注场次，主动帮用户标注，并确认角色名称和场景。

**剧本模式：** 收到剧本文本后，先扫描全文，列出所有涉及妆发描述的场次编号和角色，与用户确认分析范围。

### 第二步：逐场次分析

对每个有妆发描述的场次，按以下结构输出：

```markdown
**场次 [编号]：【场次名称】| 角色：[角色名]**

**【发型章节】**
- **发型名称**：（如：低马尾、大波浪卷发、油头背头、丸子头）
- **长度**：短发 / 中发 / 长发 / 及腰
- **发色**：黑色 / 棕色 / 金色 / 挑染 / 渐变
- **发型结构**：刘海（有/无，类型）、发包位置、发尾走向、蓬松度
- **发量感**：丰盈 / 适中 / 扁塌
- **发型状态**：整洁 / 凌乱 / 被风吹乱 / 被雨水打湿 / 出汗贴额
- **特殊造型**：假发 / 发套 / 秃顶化妆 / 伤疤化妆

**【妆容章节】**
- **妆感定位**：素颜 / 淡妆 / 浓妆 / 舞台妆 / 特效妆
- **底妆**：肤色（自然/偏白/健康小麦色）、遮瑕程度、光泽感/哑光
- **眉眼**：眉形（平眉/挑眉/野生眉）、眼影色系、眼线（有/无，上扬/下垂）、睫毛（自然/浓密/假睫毛）
- **腮红与修容**：腮红位置与色系、鼻影/轮廓修饰程度
- **唇妆**：唇色（裸色/豆沙/正红/暗色）、质地（哑光/水光/丝绒）、完整度（完好/褪色/咬唇）
- **特殊妆容**：伤痕、淤青、血迹、污渍、老年妆、角色特定标记

**【发饰与头饰章节】**
- **发箍/发带**：类型、材质、颜色、佩戴位置
- **发夹/发簪**：数量、位置（左右/后脑）、材质、装饰（珍珠/宝石/花朵）
- **帽子/头巾**：类型、佩戴方式、与发型的配合
- **其他头饰**：皇冠、头纱、发链、额饰

**【妆发状态与剧情关联】**
- **妆发变化原因**：依剧情推断（如：下雨淋湿、打斗凌乱、时间跨度导致）
- **剧本原文依据**：引用剧本中对应的原始描述片段
- **推断说明**：若为依剧情推断，注明推断逻辑
```

### 第三步：场次-妆发速查表

```markdown
**【场次-妆发速查表】**

| 场次编号 | 角色 | 发型（一句话） | 妆容关键词 | 发饰（1-2件） | 妆发状态 |
|---------|------|--------------|----------|--------------|---------|
| 场次1   | 女主 | 低马尾，碎发自然 | 淡妆，豆沙唇 | 黑色发夹（右） | 整洁 |
| 场次3   | 女主 | 同低马尾        | 同淡妆       | 同发夹        | 凌乱湿润（雨中） |
| 场次5   | 女主 | 大波浪披发     | 浓妆，红唇   | 金色发箍      | 精致完整 |
```

> 同一角色连续场次对比，方便妆发部门快速核查连戏。

### 第四步：跨场次总结

```markdown
**【妆发连续性总结】**

**核心发型元素**（贯穿多场次的共同特征，3-5条）
- 例如：女主始终以低马尾为基准发型，仅通过发饰变化区分场次

**核心妆容元素**（经常出现的妆容特征，3-5条）
- 例如：全剧唇色以豆沙+正红为主，依场景情绪切换

**妆发变化规律**（不同场次中如何调整）
- 情绪场次 → 妆容加重、发型松散
- 时间跨度 → 发型改变（如：剪发）
- 特殊场景 → 特效妆（伤痕/血迹）

**需重点关注的连续性要点：**
- 场次1→3：发型从整洁到凌乱，需确认淋雨戏份妆发预案
- 场次5→8：发型从披发回到马尾，需确认是否有剪发剧情
```

### 第五步：AI 生图 Prompt 片段

为每个角色的每场次生成精炼的「妆发」描述（50-80字），可直接用于 AI 生图工具的人物描述部分。

### 第六步：视频提示词生成

**完整视频提示词由「开场状态」+ 逐Shot组成。有台词的Shot单独成块输出。格式严格如下：**

```markdown
# 视频提示词

## 开场状态：
环境：@场景标签（时间/地点/氛围），整体色调与光感描述 <环境音效>
站位关系：[角色A] 与 [角色B] 的空间位置关系
@角色A：[详细位置、姿态、朝向、与场景中其他元素的空间关系]
@角色B：[详细位置、姿态、朝向、与场景中其他元素的空间关系]
@妆发/造型标签：[状态、完好/破损程度、特殊说明]
灯光：主光为 [光源方向 + 色温 + 光质]；[副光说明]；实用光为 [场景内光源]

---

## Shot 1
duration: X.Xs

镜头：[景别]，[角度]，[运镜]，[焦距]，[景深]，[速度]，[稳定器]。[镜头运动详细描述]

画面：[详细视觉描述，聚焦本技能提取的妆发元素]
[妆发细节+写实质感：自然噪点、色彩还原、妆发材质纹理]
[如有眼泪→追加眼泪增强关键词]

光影：[色温] [光质描述]；[阴影占比]，[反差描述]

---

## Shot 2
duration: X.Xs

镜头：[同上格式]
画面：[同上，妆发状态随时间推进的变化]
光影：[同上格式]
```

**提示词书写规则（必须遵守）：**
1. `# 视频提示词` 为总标题，`## 开场状态：` 统领全场景，用 `---` 分隔各Shot
2. `开场状态` 覆盖：环境+站位关系+各角色姿态+妆发状态+灯光，一次定义全场共享
3. 每个Shot含 `duration` + `镜头` + `画面` + `光影`，不重复开场状态中已定义的信息
4. 有台词时，在 `画面` 段落后追加 `@角色名 (情绪·音量·效果)：{对白内容}`，无台词则省略
5. `画面` 必须聚焦本技能提取的妆发元素，含写实质感关键词（自然噪点、色彩还原、皮肤纹理）
6. `光影` 必须含色温(K)、光质、阴影占比、反差描述
7. 每个Shot提示词独立成块，有台词的Shot绝不与其他Shot合并
8. 所有描述必须来自本技能提取的结果，不得虚构

### 眼泪表情专用增强关键词

**当剧本涉及「哭泣 / 流泪 / 含泪 / 眼泪」时，在「画面」段落中必须追加以下关键词：**

| 关键词类别 | 具体关键词（直接粘贴至提示词） |
|-----------|---------------------------|
| **泪液物理** | 泪液折射、泪痕反光、泪珠表层张力、晶莹泪滴、泪液沿面部轮廓滑落轨迹 |
| **眼角蓄泪** | 眼角蓄泪未落、下眼睑泪液反光、泪水充盈眼眶、泪膜覆盖眼球表面 |
| **泪流阶段** | 初泪（眼眶微红湿润）→ 溢泪（泪滴溢出眼睑边缘）→ 滑落（泪液沿面颊滑落形成湿润反光轨迹）→ 泪痕（已干泪痕呈半透明哑光条纹） |
| **妆发联动** | 泪水浸湿睫毛结块、泪液稀释眼妆导致轻微晕染、泪痕冲刷底妆露出皮肤纹理、泪水打湿鬓角发丝贴附面颊、抽泣导致发型轻微凌乱 |
| **光影交互** | 泪滴高光反射点、泪液表面对环境光的折射、泪痕反光呈冷调银白、暗部泪液依然可见微弱反光 |
| **写实质感** | 真人实拍质感、自然皮肤纹理可见、泪液物理真实、非CG水晶质感 |

> 严禁使用「水晶般」「钻石般」「珍珠般」等CG美化词汇，眼泪必须呈现真实人体泪液质感。

## 注意事项

- **图片模式**：若图片质量不佳导致细节不清，标注「图片不清晰，无法确认」而非猜测
- **剧本模式**：若剧本未明确提及某字段，标注「剧本未提及」；若依剧情合理推断，标注「依剧情推断」
- 严禁描述人物五官细节（眼型、鼻型、脸型等），聚焦妆发本身
- 发饰描述务必细致：位置（左/右/后脑）、数量、材质、颜色
- 妆容描述区分「完好状态」和「剧情导致的破损状态」（如：唇妆褪色、底妆沾污）
- 速查表重点服务连戏核查，同一角色不同场次横向对比
- 若角色在某场次有明显妆发变化（如：卸妆、换造型），务必单独列出并说明变化节点

## 参考示例（酒店大堂三角对峙）

> **本技能聚焦：** 皮肤纹理/毛孔/微红血色、面部明暗对照、冷暖光对妆面的影响

```markdown
# 视频提示词

## 开场状态：

**环境：** @酒店大堂，夜晚，3200K钨丝暖色与6500K冷蓝月光混合角力，低饱和度冷暖碰撞，吊灯光束中漂浮体积感尘埃微粒，轻微大气薄雾笼罩 <旋转门微弱的机械转动声，远处隐约的钢琴声，大堂空旷微回声>

**站位关系：** 三人形成对峙三角格局 — @女主 位于画面左侧 → @女反角 占据画面中央 → @男主 位于画面右侧中景

**@女主：** 位于画面左侧，姿态内收，双臂自然垂于身侧，手指微微向内蜷曲——透露克制的紧张；面庞被吊灯3200K暖光柔化覆盖，细腻真实的皮肤纹理，可见毛孔及自然的微红血色，无塑料感/无蜡质感/无过度柔滑

**@女反角：** 占据画面中央，下巴微抬，唇角挂着一抹冷冷的轻蔑笑意；身体语言占据空间主导；轮廓被旋转门6500K冷蓝月光硬朗勾勒，形成冷暖对抗；冷光下的面部呈现定向明暗对照（directional chiaroscuro）

**@男主：** 位于画面右侧中景，视线在地板与@女主之间来回游移，刻意避开与@女反角的直视——逃避姿态

**@妆发状态：**
- @女主：自然妆感，皮肤保留真实纹理与噪点，暖光下肤色自然还原
- @女反角：冷光下妆面呈现高反差明暗对照，轮廓线硬朗

**灯光：**
- **主光：** 天花板水晶吊灯，3200K钨丝暖光，自上而下覆盖@女主面庞，光质柔化
- **副光/轮廓光：** 旋转门方向 6500K 冷蓝月光，硬朗侧逆光勾勒@女反角轮廓
- **反差：** 暖光柔化@女主面庞 × 冷光硬朗@女反角轮廓 → 冷暖明暗对照
- **阴影：** 约40%，主要集中在@男主区域

**摄影规格：** 阿莱 Alexa 65 / 35mm / T4 / 深焦定场镜头 / --ar 9:16

**质感/技术规格：**
- 照片级真实 / 超写实 / 真人实拍质感的电影静帧
- 多层次构图：前景（失焦散景）→ 中景（三角对峙）→ 背景（旋转门+月光）纵深分明
- 胶片颗粒与皮肤噪点（film grain & skin texture noise）
- 无过度柔滑皮肤 / 无塑料质感 / 无蜡质感
- 非卡通 / 非动漫 / 非插画

---

## Shot 1
**duration: 4.0s**

**镜头：** 广角定场，平视，缓慢前推，35mm，T4深焦保留三人全景，常速，稳定器固定。镜头从大堂全景起，沿中轴线缓慢向前推进，焦点保持在全场三人，景别由大广角缓缓收紧至中广角，最后落点在三人三角对峙的定格瞬间。

**画面：**
前景中失焦的水晶吊灯碎片如破碎玻璃散景面纱。@女反角 占据画面中央，下巴微抬的冷傲姿态稳定不动，冷光下轮廓线硬朗清晰。@女主 位于画面左侧，3200K暖光柔化覆盖面庞——皮肤纹理与自然的微红血色细腻可见，毛孔清晰。@男主 位于画面右侧中景，视线游移，身体重心微移半次。冷暖光在画面中形成对角线切割。
写实质感：真人实拍，胶片颗粒与皮肤噪点，吊灯光束中尘埃微粒体积感可见，轻微大气薄雾在深焦下保留纵深层次。

**光影：** 3200K暖黄吊灯光自上而下覆盖画面左侧；6500K冷蓝月光从旋转门方向切入，硬朗侧逆光；冷暖光在中央形成对角线切割；阴影约40%；大理石地面同时反射暖光与冷光，形成双色倒映。

## Shot 2
**duration: 3.5s**

**镜头：** 中近景，侧前方平视，缓慢横移（dolly left），中长焦85mm，浅景深焦在@女主面部，常速，稳定器固定。镜头从@女反角的冷傲侧脸起，沿三角中轴线向左横移，焦点由@女反角过渡到@女主，最后落点交给@女主面庞。

**画面：**
起幅：@女反角 占据画面中央偏右，唇角冷冷的轻蔑笑意在6500K冷蓝月光硬朗勾勒下如刀锋般清晰。横移过程中焦点从@女反角平滑过渡到@女主。落幅：@女主 暖光下的面庞——3200K吊灯光从上方斜照，眼窝下投出柔和鼻影，毛孔与自然微红血色清晰可见，无塑料感/无蜡感。微垂的眼眸深处藏着一丝尚未被察觉的隐忍。胶片颗粒均匀分布，皮肤纹理保留自然噪点。

**光影：** 主光3200K暖黄从@女主前上方斜照，光质由硬朗过渡为柔化（通过大气薄雾自然柔光）；6500K冷蓝月光在落幅时退至@女主身后成为微弱的冷调边缘光；浅景深焦外散景（bokeh）由水晶吊灯碎片构成。
```
