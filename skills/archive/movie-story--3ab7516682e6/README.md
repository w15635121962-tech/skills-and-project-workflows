# Movie Story

电影级 AI 影视创作全流程智能体 — 从剧本到分镜到视频提示词，一站式完成。

适用于 WorkBuddy 平台的专家技能（Agent Skill），覆盖 AI 短剧、动画、混合实拍等全品类影视创作。

## 快速开始

### 在 WorkBuddy 中使用

1. 克隆本仓库到本地技能目录：
   ```bash
   git clone git@github.com:Billyui/movie_story.git ~/.workbuddy/skills/movie-story
   ```

2. 在 WorkBuddy 对话中触发技能，使用以下任意方式：
   - 输入 `/movie-story`
   - 提及「分镜」「剧本转分镜」「AI 视频提示词」「Seedance」「角色设计」「场景概念图」等关键词

3. 提供你的剧本，技能会自动执行完整流水线：
   ```
   剧本诊断 → 覆盖拍摄规划 → 叙事推理分析 → 视觉锚点建立 → 分镜生成 → AI 提示词 → 质量自检
   ```

## 核心特色

### 叙事推理与镜头智能层（Phase 2.8 — 你的技能是导演的手，这个是导演的脑）

AI不先决定镜头再找理由，而是先完成7步推理再推导镜头：

| 推理步骤 | 核心输出 | 直接驱动 |
|---------|---------|---------|
| 叙事意图识别 | 15类意图（RevealInfo / ShiftPower / BuildSuspense…） | 景别 + 运镜 + 剪辑策略 |
| 故事语法分析 | 7阶段（Setup→Climax→Aftermath）+ 能量曲线0-1 | 景别递进 + 光比 + 剪辑速度 |
| 角色心理画像 | dominance / body_tension / eye_contact 量化 | 机位角度 + 构图 + 运镜稳定性 |
| 人物关系图谱 | trust / fear / power_gap / hostility 量化 | 正反打风格 + 物理间距 + 延迟反应 |
| 潜台词分析 | 13类潜台词（hidden_love / manipulation…） | 镜头策略（按潜台词而非台词字面） |
| 视觉注意力 | 焦点优先级1-2-3 + 控制方法5类 | Rack Focus / 构图引导 / 光影引导 |
| 情绪弧线追踪 | 场景能量曲线 + 角色情绪递进 | 景别渐变 + 运镜节奏 + Hold时长 |

**核心优先级**：`叙事意图 > 人物关系 > 情绪变化 > 视觉注意力 > 镜头美感 > 角色外貌展示`

### 场景开场状态模块（强制首帧定场）

每个场景进入镜头前，必须先输出6子模块的"世界快照"：

1. **环境定场** — 时间/天气/光源/空气质感/色调（闭上眼就能"看到"）
2. **站位关系** — 所有在场角色空间位置/姿态/高低落差
3. **角色状态** — @角色名·状态标签 + 身体/面部/关键细节
4. **服装状态** — 材质/状态变化/角色经历的外化
5. **灯光体系** — 四步布光法（Key/Fill/Rim/Ambient）
6. **声音氛围** — 环境声/特定音效/配乐情绪方向

### 电影级写实强制协议（内联不可绕过）

生成任何分镜或 AI 提示词前，必须严格执行：
- 9条写实强制规则：风格锁定 · 相机参数 · 人物质感 · 反塑料感 · 眼泪物理（4.5）· 布料真实感（4.7）· 场景环境真实感（4.8）· 湿衣真实感（4.9）· 融合书写
- 5阶段自检流程（输入分析 → 写实自检 → 场景丰富自检 → 综合优化 → 最终确认）
- 输出前必须声明："已通过电影级写实与场景丰富强制协议全部检查"

### 镜头-动作融合书写（强制不可绕过）

画面描述禁止把「人物动作」和「镜头运动」拆成两段独立列表，必须融合为电影化 prose：
- Motivated 原则：运镜必须由情绪/动作驱动
- 正例：`女主缓缓站起，双手微微用力撑着扶手，镜头随着她起身缓慢上摇并向前推进……`
- 反例：❌ `人物：缓缓站起。镜头：从全景推至特写。`

### 覆盖拍摄规划 (Coverage Planning)
不只是生成单个镜头，而是像实拍导演一样规划完整覆盖方案：
- Master + 双方 Clean Single + OTS + Insert 的标准覆盖组合
- 精确空间坐标锁定（轴线、距离、屏幕位置、高度）
- 180° 法则强制执行，越轴需显式说明

### 视觉锚点体系
通过身份板 + 场景参考图集确保跨镜头一致性：
- 角色六维精度（面部特征、体型、发型、服装、标志性道具、肤色）
- 中性正面肖像技巧 v1.0（角色参考图专用：面朝前方、平视、不加情绪）
- 场景九机位参考体系
- Seed 固定策略 + ControlNet 指令

### 导演视觉控制与AI防失真（导演必修课模块8）

用导演思维严格把控AI输出，避免失真（变形手、塑料脸、光影冲突）：
- **四步布光法**：Key/Fill/Rim/Ambient 强制描述，5种灯光模式情绪映射
- **调色风格锁定**：Look Book + 5种风格（Teal&Orange/胶片/冷峻/梦幻/赛博朋克）
- **质感打假**：通用微细节层 + 联动布料/场景/湿衣专项质感
- **防失真技术**：CFG 5-8 / 30+步 / Inpainting修复工作流
- **高难度光照匹配（8.7）**：室内多光源 / 金属渲染 / 树影斑驳 / 夜景霓虹

### 自动重写闭环 + 连续性状态机

| 机制 | 功能 |
|------|------|
| **Auto Rewrite Loop** | Full Fusion Self-Check任意项失败→查表→定向修正→重验，最多3轮自动修复 |
| **Runtime State JSON** | 每场景维护结构化状态对象，跨镜头追踪轴线/视线/情绪/光影/注意力连续性 |
| **电影语言本体库** | 运镜/构图/剪辑三层语义速查（叙事意义→情绪效果→心理暗示） |

### 写实质感专项强制

| 规则 | 触发条件 | 核心内容 |
|------|---------|---------|
| 4.5 眼泪物理 | 涉及哭泣镜头 | 泪水路径/碎裂高光/物理轨迹 |
| 4.7 布料真实感 | 涉及衣物/布料 | 4面料类型(毛呢/棉麻/缎面真丝/平纹罗纹)正向+反向提示词 |
| 4.8 场景环境真实感 | 涉及场景/环境 | lived-in/weathered/atmospheric + 5场景类型加强词 |
| 4.9 湿衣真实感 | 涉及雨戏/水戏/落水/出汗 | 半透明+粗糙纹理+碎裂高光 + 4场景+4布料湿态 |

### 人物骨相强化（欧美人审美）
- Rembrandt Lighting / Split Lighting / Short-Side Lighting 三种光影方案
- 骨相描述词库（男性 chiseled jawline / 女性 high cheekbones）
- 多视图一致性（Character Sheet 16-Grid）

### AI 提示词工程
适配主流 AI 生成工具的提示词输出：
- **图像**：RunningHub / Midjourney / FLUX / SDXL
- **视频**：Seedance 2.0（即梦）/ Kling 3 / Runway Gen-3 / Pika 2.0
- **多模态**：首尾帧控制、微表情、运动强度、镜头节奏

### 视频提示词输出格式 v2.0
每个场景的视频提示词统一采用「开场状态」+ 逐Shot结构，覆盖**服装 + 妆发 + 道具 + 场景**四个维度：

| 组件 | 说明 |
|------|------|
| **开场状态** | 统领全场景，一次定义环境/站位/角色姿态/美术资产/灯光/摄影规格/质感标准 |
| **逐Shot** | duration + 镜头(景别+角度+运镜+焦距+景深+速度) + 画面 + 光影(色温K/光质/阴影占比) |
| **台词格式** | `@角色名 (情绪·音量·效果)：{对白内容}` |
| **分隔** | 用 `---` 分隔各Shot，有台词的Shot绝不与其他Shot合并 |

配套四维美术提取技能（与 v2.0 格式一致，无缝协作）：

| 技能 | 聚焦维度 |
|------|---------|
| costume-accessories-extractor | 服装+配饰：重量感、垂坠感、布纹褶皱、面料反光 |
| makeup-hair-extractor | 妆发造型：皮肤纹理、毛孔、面部明暗对照、冷暖光对妆面 |
| script-props-extractor | 道具：材质纹理、灯光反射、状态动态变化 |
| set-art-extractor | 场景美术：空间布局、混合色温、材质磨损、大气薄雾 |

## 与 9:16-movie-story（竖屏版）的差异

| 维度 | movie-story（横屏） | 9:16-movie-story（竖屏） |
|--------|---------------------|--------------------------|
| 画幅 | 16:9 / 2.39:1 | 9:16 |
| 构图重心 | 水平三分法 | 眼睛在上1/3 + 中心稳定区 |
| 运镜主导 | Pan / Truck / Dolly | Tilt Up/Down / Crane Up/Down |
| 节奏 | 中速为主 | 快切≥60% |
| 特写占比 | 30-40% | 50-70% |
| 底部安全区 | 无 | 底部94-140px（UI遮挡区） |
| 质感敏感度 | 正常 | 竖屏特写中放大2-3倍 |
| 布光策略 | 水平四步布光 | 垂直光影分布，顶光/侧光优先 |
| 融合书写 | 动作+运镜融合 | 竖屏快切版：一句话完成动作+运镜+构图标注 |
| 叙事推理 | Phase 2.8（水平构图映射） | 模块2.5（+占屏比/垂直层级/字幕安全区） |
| 开场状态 | 6子模块 | 6子模块+竖屏专属标注（构图预判/垂直层级/占屏比/布料可见度/灯光垂直分布/字幕安全区）|
| 状态机 | Runtime State JSON | +vertical_composition字段 |
