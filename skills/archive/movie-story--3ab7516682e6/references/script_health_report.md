# 剧本健康诊断协议 (Script Health Report)

## 目的

在开始分镜设计之前，对剧本进行全面健康诊断，确保剧本质量达到可执行的分镜标准。

## 诊断维度

### 1. 结构完整性

| 检查项 | 标准 | 状态 |
|--------|------|------|
| 三幕式结构 | 开端-发展-高潮-结尾完整 | ✓/✗ |
| 场景过渡 | 场景间逻辑连贯 | ✓/✗ |
| 节奏分布 | 动静场景交替合理 | ✓/✗ |
| 时长估算 | 各幕时间分配合理 | ✓/✗ |

### 2. 角色一致性

- **角色名统一**：全剧本中角色名称拼写一致
- **性格连贯**：角色行为符合已建立的性格特征
- **动机清晰**：每个角色在每场戏中有明确动机
- **对话辨识度**：不同角色的语言风格有区分度

### 3. 场景可行性

- **场景描述完整度**：每个场景有足够的环境描述
- **时间线一致**：白天/夜晚、季节等时间线索一致
- **空间逻辑**：角色移动路径合理
- **物理可行性**：描述的动作在物理空间内可执行

### 4. 对白质量

- **自然度**：对白读起来自然，不像书面语
- **信息密度**：每句对白要么推动剧情，要么揭示角色
- **潜台词**：重要场景有适当的潜台词层次
- **长度适当**：单句对白不超过 3 行

### 5. 视觉可转化性

- **画面感**：场景描述能否直接转化为视觉画面
- **情绪可视化**：角色情绪是否有外在表现
- **关键画面**：是否标注了需要重点呈现的画面
- **转场可行性**：场景切换是否有合理的视觉过渡方式

```
1.

【可选优化】：
1.

【分镜风险评估】：
- 高风险场景：___ 处
- 中风险场景：___ 处
- 低风险场景：___ 处

【诊断结论】：✓ 可进入分镜 / ⚠ 需修复后重检 / ✗ 需大幅修改
```

## 评分标准

- **90-100**：优秀，可直接进入分镜
- **75-89**：良好，小幅调整后可进入分镜
- **60-74**：一般，需修复建议项后重检
- **60 以下**：需大幅修改剧本

## 使用时机

1. 收到新剧本后，分镜设计之前
2. 剧本修改后，重新进入分镜流程之前
3. 用户明确要求诊断时
