```

```

| # | 特征 | 说明 |

## 色彩特征拆解

### 主色调倾向

| 色系 | 出现场景 | AI 提示词关键词 |
|------|----------|----------------|
| **深蓝 + 靛蓝** | 蓝调时刻天空 | `deep cobalt blue sky`, `indigo twilight` |
| **暖橘 + 琥珀** | 街灯/橱窗光 | `warm amber streetlights`, `pumpkin orange glow` |
| **品红 + 玫红** | 霓虹/招牌 | `vibrant magenta neon`, `hot pink signage` |
| **金黄 + 赭石** | 建筑/皮肤色调 | `rich gold ochre`, `warm sepia skin tones` |
| **墨绿 + 森林绿** | 阴影区域 | `deep forest green shadows`, `emerald night` |

### 用色规律

```
大面积深蓝/靛青底色  +  小面积暖橘/品红点缀  =  Jake 经典配色
```

**对比策略**：
- 冷暖极端对比（蓝 vs 橙，靛 vs 品红）
- 明暗极端对比（深暗背景 vs 高光主体）
- 饱和极端对比（灰暗环境 vs 鲜艳服装/灯光）

## 光影技法拆解

### 蓝调时刻（Blue Hour）捕捉

> "他擅长利用光影作画，特别是在傍晚时分进行拍摄，捕捉富有创造性的光线，捕捉到短暂的蓝调时刻"

**蓝调时刻定义**：日落后15-30分钟，天空呈深蓝靛色，人工光源刚亮起

**AI 提示词模板**：
```
blue hour cinematography, deep indigo sky gradient, 
warm tungsten streetlights contrasting cool ambience, 
transition moment between day and night, 
soft directional light, cinematic color grading
```

### 光影作画三要素

| 要素 | 手法 | AI 提示词 |
|------|------|------------|
| **主光源** | 单侧硬光（街灯/橱窗） | `single hard light source from side`, `dramatic chiaroscuro` |
| **反射光** | 墙面/地面反光 | `reflected neon glow on wet pavement`, `color bounce light` |
| **边缘光** | 轮廓逆光 | `rim lighting on subject hair`, `backlit silhouette with edge light` |

## 构图与叙事

### 剧场感构图

Jake 的照片有一种**"电影定格"**感：

```
街头瞬间  →  被赋予剧情  →  像电影截图
```

**AI 提示词关键词**：
```
cinematic still frame, movie scene capture, 
narrative street photography, decisive moment, 
documentary fashion fusion, editorial street style
```

### 色彩引导视线

- 用**鲜艳色块**引导视线到主体
- 用**大面积深色**压住画面
- 用**小面积高饱和色**做视觉锚点

**AI 提示词**：
```
color-driven composition, vibrant color block guiding eye to subject, 
large area of deep shadow anchoring frame, 
small high-saturation accent as visual anchor
```

## 对 AI 视频导演的启示

### 1. 色彩即情绪
> 不要让 AI "自动配色"，而是**指定情绪对应的色板**

```
悲伤 → 深蓝 + 灰紫 + 冷白
温暖 → 琥珀 + 金黄 + 暖橙
紧张 → 品红 + 深红 + 冷青
```

### 2. 蓝调时刻是万能氛围
> 日落后30分钟内的光线，适合**所有情绪场景**

```
通用蓝调时刻提示词片段：
"blue hour, deep indigo atmosphere, 
warm artificial light contrasting cool sky"
```

### 3. 浓烈 ≠ 堆砌
> Jake 的高饱和来自**对比**，不是所有颜色都饱和

```
正确：深暗背景 + 小面积高饱和点缀
错误：全画面高饱和（会塑料感）
```

### 4. 剧场感来自"定格瞬间"
> 视频提示词要描述**"这一刻发生了什么"**，而非连续动作

```
好：「人物在街灯下停顿，回望，表情若有所思」
差：「人物在街上走来走去」
```

## 核心检查清单

使用前核对：

- [ ] 是否指定了主色调（冷 or 暖）？
- [ ] 是否有明暗极端对比（避免灰蒙蒙）？
- [ ] 是否用了蓝调时刻或特定光线条件？
- [ ] 色彩数量是否 ≤ 4 种（避免杂乱）？
- [ ] 是否有"剧场感/叙事性"的描述？
- [ ] 是否加了质感描述（oil painting / film grain）？
