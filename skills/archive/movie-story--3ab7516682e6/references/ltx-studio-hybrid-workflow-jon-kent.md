# LTX Studio 混合工作流实战（Jon Kent 方法）

## 核心概念：感知流畅性（Perceptual Fluency）

**原理**：大脑更容易接受熟悉的真实内容。先从实景片段切入，让观众对光影、质感建立真实预期，后续AI片段出现时观众会更自然地接受，降低违和感。

**实操意义**：
- 成片**开头优先使用实景拍摄片段**（建立真实预期）
- AI生成内容放在中段（观众已建立真实感，接受度更高）
- 成片**结尾回到实景**（进一步强化真实感，模糊边界）

## 工具定位：LTX Studio

### 核心功能模块

| 功能模块 | 具体内容 |
|----------|----------|
| **前期创作** | 导入完整脚本/故事梗概；输入提示词、类型关键词、内容调性生成故事框架；自定义创建角色（年龄、外貌、服装等属性） |
| **故事板制作** | 按场景分行展示故事板；支持`@角色名`关联角色；选择镜头类型（特写/远景等）；绘制构图/上传参考图生成匹配画面；超分辨率放大、生成填充、物体移除、调整面部表情/镜头角度 |
| **动态生成** | 支持自动生成镜头动态，也可通过动态编辑器自定义运动效果 |
| **声音设计** | 添加台词、自动音效、旁白、场景音 |

## 完整混合工作流（五步骤）

### 步骤1：前期概念与故事板开发（LTX Studio端）

1. 打开LTX Studio创建新故事板，导入脚本或输入故事梗概
2. 创建故事所需全部角色，完善角色属性（可后续补充）
3. 进入分镜拆解模块，填写每个场景的地点、动作、参与角色
4. 点击开始生成故事板
5. 调整生成的故事板画面：
   - 选择镜头类型
   - 绘制构图 / 上传参考图优化生成效果
   - 不满意可重新生成
   - 按需添加台词、音效
6. 用内置工具优化画面：超分放大、生成填充补全、移除多余元素、调整表情/镜头角度

### 步骤2：添加动态，衔接实景内容

**镜头顺序策略（感知流畅性应用）**：

| 镜头序号 | 内容类型 | 制作方式 |
|----------|----------|----------|
| 1-3 | 实景片段 | 凌晨5点实地拍摄，建立真实预期 |
| 4-6 | 完全AI生成 | 远景定场镜头（文本提示词+运动提示词） |
| 7-8 | 混合镜头 | 绿幕实拍 + AI生成背景（反向流程） |
| 9-10 | 混合镜头 | 实拍近景 + AI生成特效元素 |
| 11-15 | 完全AI生成 | 悬崖海景 + 火灾元素（视觉对比） |
| 16-18 | AI生成 | 故事板生成的AI镜头 |
| 19-20 | 实景片段 | 英国南安普顿新森林实地拍摄，模糊边界 |

### 步骤3：实景+AI混合镜头（反向流程）

> 适用场景：演员表演+AI生成背景

**操作流程**：
1. 以故事板画面为参考，演员在**绿幕前**拍摄表演内容
2. 将绿幕素材导入Premiere Pro，导出**静态帧**
3. 将静态帧导入LTX Studio
4. 提示LTX生成**匹配该静态帧透视关系**的背景
5. 满意后超分放大，导入Photoshop**移除演员**，得到干净背景底图
6. 将背景底图导回LTX Studio**生成动态**
7. 在Premiere Pro完成最终合成

### 步骤4：实景融合AI元素（特效光效类）

> 适用场景：实拍人物+AI生成环境特效（如火灾光影）

**操作流程**：
1. 实地拍摄角色近景
2. 用**4个灯打光4x4尺的薄棉布**，模拟车辆火灾的光影效果
3. 翻转镜头拍摄角色背后的**反打角度**
4. 将该角度合成到AI生成的燃烧车辆镜头中

### 步骤5：收尾与内容融合

- 后续镜头完全用AI生成，加入视觉对比元素
- 最后镜头回到实景拍摄内容
- 整体形成「实景 → AI → 混合 → AI → 实景」的闭环结构

## 核心技术要点

### 1. 感知流畅性的三段式结构
```
开篇（实景）→ 中段（AI+混合）→ 结尾（实景）
```
→ 让观众始终锚定在真实感上，AI内容被视为"扩展"而非"替换"

### 2. 绿幕+AI背景的反向流程优势
- 保留演员真实表演（情感传递更准确）
- AI只需要生成背景（技术难度更低，质量更高）
- 透视匹配通过静态帧锚定，比纯AI生成更可控

### 3. 光影实拍技巧（AI特效融合关键）
- 实拍时**预先用灯光模拟AI生成元素的光影效果**
- 这样合成时画面光影一致，不会穿帮

## 对AIGC导演的启示

1. **不要试图让AI假装成实景** → 相反，让实景为AI内容"背书"
2. **绿幕+AI背景是性价比最高的混合方式** → 演员真实+背景无限可能
3. **光影预先匹配是合成成功的关键** → 实拍时就考虑后期AI元素的融入
4. **LTX Studio的价值在于角色一致性** → 解决多镜头角色不一致的痛点
5. **成片结构要设计** → 不是随机混合，而是有策略地安排实景/AI的出现顺序
