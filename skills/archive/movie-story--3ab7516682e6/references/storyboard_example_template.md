## 示例剧本片段

```
场景：深夜，小公寓厨房

林远（32岁，程序员）坐在厨房的小桌前，面前是一台笔记本电脑和三个空啤酒罐。
手机震动，他看了一眼——是"妈"的来电。
他犹豫了三秒，按下了静音。
然后他打开冰箱，里面只有一盒过期的牛奶和半瓶酱油。
他关上冰箱，靠着冰箱门，慢慢滑坐在地上。
窗外，城市的灯光在黑暗中闪烁。
```

## 分析说明

### 镜头节奏
- S01-01~02：建立（7s）— 交代环境和人物
- S01-03~06：冲突（9.5s）— 手机来电的抉择
- S01-07~09：转折（10s）— 冰箱揭示生活状态
- S01-10~11：释放（9s）— 情绪沉淀，场景收尾

### 运镜逻辑
- 从静止开始（建立距离感）
- 中间加入缓推（制造压力）
- 关键时刻固定（强调情绪）
- 最后缓慢拉出（释放、结束感）

### 色彩叙事
- 台灯暖黄 = 仅存的生活温度
- 电脑屏幕蓝白 = 工作的冰冷
- 冰箱冷白 = 现实的残酷
- 窗外城市冷蓝 = 外部世界的疏离
- 暖冷交替 = 角色内心的拉扯

### AI 提示词要点
- 每个提示词包含：主体描述 + 环境 + 光线 + 风格 + 技术参数
- 情绪类镜头加入 "cinematic, emotional" 等氛围词
- 关键道具使用 "extreme close-up, detailed" 强调质感
