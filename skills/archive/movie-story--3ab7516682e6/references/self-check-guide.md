# 分镜自检清单与常见问题

## 〇、Full Script Fidelity 专项自检（最高优先级）

### 0.1 剧本完整性覆盖检查

**检查方法**：将分镜输出与Exhaustive Inventory逐一交叉核对

| 核对维度 | 检查步骤 | 判定标准 |
|----------|---------|---------|
| 场景覆盖 | 分镜中的场景列表 vs Inventory场景清单 | 每个原始场景都有对应分镜段落 |
| 台词覆盖 | 分镜中的每句台词 vs 原始剧本对白 | 每句原始台词都被保留，无省略/合并/改写 |
| 动作块覆盖 | 分镜中的动作描述 vs 原始剧本动作块 | 每段原始动作描述都有对应镜头 |
| 括号说明覆盖 | 分镜中的情绪/节奏指示 vs 原始剧本括号说明 | 每个括号说明都有所体现 |
| 转场覆盖 | 分镜中的转场处理 vs 原始剧本时空转换点 | 每处转场都有处理 |

**常见遗漏类型**：

| 问题类型 | 示例 | 严重程度 |
|----------|------|----------|
| 场景被省略 | 原剧本8场，分镜只输出7场 | 🔴 致命 |
| 台词被合并 | 原剧本3句对白被合并为1句 | 🔴 致命 |
| 动作被跳过 | 原剧本"他猛地站起来摔门而出"被省略 | 🔴 致命 |
| 括号说明被忽略 | 原剧本"(颤抖着)"被忽略 | 🟡 高 |
| 转场被省略 | 原剧本"三天后"被跳过 | 🟡 高 |
| 台词被改写 | 原剧本"我不可能原谅你"改为"我无法原谅" | 🟡 高 |
| 动作被浓缩 | 原剧本5步动作描述浓缩为1步 | 🟠 中 |

**核对输出格式**：
```
Full Script Coverage Check:
[场景] 8/8 ✓ | [台词] 24/24 ✓ | [动作块] 15/15 ✓ | [括号说明] 6/6 ✓ | [转场] 3/3 ✓
Status: 100% COVERED
```

**修正规则**：
- 任何 🔴 致命遗漏必须立即修正，不可进入下一阶段
- 修正后必须重新核对，确认遗漏项已补全
- 最终输出必须包含声明："Self-check complete: 100% of original dialogue lines and every scene segment accounted for. No omissions."

### 0.2 Exhaustive Inventory 完整性检查

**检查方法**：确认Phase 1的详尽清单是否完整创建

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 未创建清单 | 跳过Exhaustive Inventory直接开始分镜 | ❌ 强制步骤 |
| 清单不完整 | 场景列了但台词数未统计 | ❌ 5个维度必须全覆盖 |
| 清单数字与实际不符 | 标注"24句台词"但实际有26句 | ❌ 必须精确 |
| 清单完整且准确 | 5个维度全部列出且数字正确 | ✅ |

**标准**：Exhaustive Inventory的5个维度必须全部创建，数字必须精确，不可估算。

## 一、连续性自检

### 1.1 景别连续性
**问题类型**：相邻镜头景别跳变不合理

**检查方法**：
- 列出每个场景的景别序列，检查相邻镜头的景别差距
- 差距超过3级（如特写→大远景）视为跳变，需确认是否有叙事理由

**合理跳变的场景**：
- 情感爆发点（突然的特写→远景表达孤独）
- 时空转换（回忆闪回）
- 角色主观感受（耳鸣→失焦拉远）

**不合理的跳变**：
- 日常对话中景→大远景→中景（无理由来回跳）
- 连续特写后突然接全景（缺少过渡）

**修正方式**：插入过渡景别，或调整前后镜头的景别使其更接近

### 1.2 空间连续性
**问题类型**：角色位置/道具/光线在连续镜头间不一致

**检查方法**：
- 在脑中模拟场景的平面图，标注每个镜头中角色的位置
- 检查光线方向是否一致（同一场景内主光源方向不变）
- 检查道具位置是否前后一致

**常见错误**：
- 正反打中左右位置互换
- 手持物品在切镜后消失/换手
- 窗户方向在切镜后改变

### 1.3 轴线一致性
**问题类型**：违反180度轴线规则

**检查方法**：
- 对话场景中，画出两个角色的连线
- 确认所有机位都在连线的同一侧
- 标注每个正反打镜头的机位位置

**越轴处理**：
- 如需越轴，必须安排过渡镜头
- 在越轴镜头中让角色移动到画面另一侧

## 二、节奏自检

### 2.1 镜头时长节奏
**问题类型**：节奏过快或过慢

**检查方法**：
- 计算每个场景的平均镜头时长
- 对比场景情绪基调与节奏的匹配度

| 情绪基调 | 建议平均镜头时长 |
|----------|-----------------|
| 紧张/追击 | 1-2秒 |
| 日常/对话 | 3-5秒 |
| 抒情/沉思 | 5-8秒 |
| 高潮爆发 | 先长后短（递减） |

**常见问题**：
- 对话场景全是2秒短镜头→节奏急促，不自然
- 抒情段落全是8秒长镜头→拖沓，缺乏变化

### 2.2 景别节奏
**问题类型**：景别单调

**检查方法**：
- 统计每个场景各景别占比
- 单一景别占比超过60%需警惕

**修正方式**：
- 对话场景交替使用中景/近景/特写
- 每3-4个镜头安排一次景别变化
- 关键台词用特写或近景强调

### 2.3 运镜节奏
**问题类型**：运镜方式单一

**检查方法**：
- 统计每个场景固定镜头vs运动镜头的比例
- 全固定或全运动都需调整

**建议比例**：
- 文戏：固定70% + 运动30%
- 动作戏：固定30% + 运动70%
- 纪实风：手持50% + 固定50%

## 三、叙事自检

### 3.1 信息覆盖
**问题类型**：关键信息缺少镜头表达

**检查方法**：
- 对照剧本，确认每个叙事要点都有镜头覆盖
- 特别检查：角色关系变化、关键道具、空间转折

### 3.2 冗余检查
**问题类型**：多个镜头表达同一信息

**检查方法**：
- 连续3个以上镜头表达同一情绪/信息→冗余
- 检查是否可以合并或替换为更有信息量的镜头

### 3.3 转场合理性
**问题类型**：场景间跳转生硬

**检查方法**：
- 检查相邻场景的转场方式是否匹配情绪
- 高潮→平静：叠化/淡出
- 平行叙事：切/匹配剪辑
- 时间跳跃：淡出/黑场

## 四、严重程度评级

| 严重程度 | 定义 | 处理优先级 |
|----------|------|-----------|
| 高 | 违反轴线规则、空间连续性错误、关键叙事遗漏 | 必须修正 |
| 中 | 景别跳变无理由、节奏明显不合理、运镜单调 | 建议修正 |
| 低 | 时长微调、转场方式可优化、构图可更精致 | 可选修正 |

## 五、动作戏/打斗戏专项自检

### 5.0 正反打拆分充分性

**检查方法**：审查所有标注为"正反打"或涉及角色切换的镜头，是否已拆分为独立镜头

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 正反打未拆分 | "S1-03 正反打：林冲出棍，反派恐惧" | ❌ 不可接受——必须拆成两个独立镜头 |
| 正反打缺碰撞镜 | 有出招有反应，但缺少碰撞/交锋的独立镜头 | ❌ 动作链断裂 |
| 正反打构图不互补 | 正方占右2/3面向右，反方也占右2/3面向右 | ❌ 违反180度轴线 |
| 对话正反打未拆分 | "S2-02 正反打：A说话B点头" | ❌ 两人两个镜头，不能合并 |
| 正反打时长相同 | 攻击方0.5s+防御方0.5s，无情绪区分 | ⚠️ 缺少情绪主导，谁更重要谁的镜头应该更长更紧 |

**标准**：每一"正"和每一"反"必须是独立镜头，各自有完整的编号、景别、角度、运镜、构图、时长。正反打之间如有碰撞，碰撞也是独立镜头。对话场景同理。

### 5.1 动作拆解充分性

**检查方法**：逐镜头审查，是否存在"一句话概括打斗"的问题

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 笼统概括 | "两人激烈打斗" | ❌ 不可接受 |
| 缺少动作细节 | "林冲出棍"（未描述轨迹/部位/力度） | ⚠️ 需补充 |
| 缺少碰撞瞬间 | 有出招有反应，缺少碰撞那一帧 | ❌ 动作链断裂 |
| 缺少环境反馈 | 打斗发生在雪地但无雪被搅起的描述 | ⚠️ 需补充 |
| 缺少声音层 | 只有视觉描述，无Foley设计 | ⚠️ 需补充 |

**标准**：每个动作镜头必须包含完整的"出招-碰撞-反应"三拍子中的至少一拍，且碰撞瞬间必须有独立镜头或精确描述。

### 5.1b 打斗叙事弧线检查

**检查方法**：审查打斗段落的整体叙事结构，是否遵循"权力三次翻转"原则

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 单方面碾压 | 主角从头到尾占优，对手毫无还手之力 | ⚠️ 缺乏戏剧张力，至少需要一次被制 |
| 无触发直接打 | 缺少"建立"镜头，上来就打 | ⚠️ 观众没有情绪准备 |
| 无收束直接结束 | 打完没有"胜负已分"的确认镜头 | ⚠️ 情绪没有落地 |
| 即兴武器无伏笔 | 角色突然掏出灭火器但之前没出现过 | ❌ 叙事断裂 |
| 环境只是背景 | 走廊打斗但无湿地面/墙面/灯光参与 | ⚠️ 浪费了环境的叙事潜力 |
| 无首尾呼应 | 首格和末格的构图方向完全不同 | ⚠️ 可优化——首尾呼应是最高的叙事效率 |
| 翻转只有一次 | 反击→胜利，没有中间的"被制" | ⚠️ 情绪弧线太平，建议至少三次翻转 |

**标准**：完整打斗段落应包含9拍结构（建立→触发→焦灼→反击→逆转→翻盘→决胜→收束→离场），至少3次权力翻转。即兴武器需要提前埋设视觉伏笔。环境应参与叙事而非仅作背景。

### 5.2 武器/道具连续性

**检查清单**：
1. 每个镜头中武器的位置是否与前镜动作终点一致？
2. 武器持握方式是否与动作逻辑匹配（正握/反握/双手/单手）？
3. 武器脱手后是否有交代去向？
4. 正反打切换时，攻击方和防御方的武器状态是否互补（一个在出招，一个在防御）？

### 5.3 受伤与破损累积

**检查清单**：
1. 打斗段落中受伤是否只增不减？
2. 血迹位置和扩散方向是否符合重力？
3. 衣物破损是否在后续镜头中保持？
4. 是否有"自愈"的伤口或"自修"的衣物？

### 5.4 空间方位一致性

**检查清单**：
1. 正反打中攻击方和防御方的左右位置是否与空间设定一致？
2. 快切中角色是否发生了不合理的位移（被击退后"回位"）？
3. 180度轴线规则是否在打斗中保持？（除非有意越轴并安排了过渡）
4. 打斗过程中的空间移动是否有逻辑（不是凭空瞬移）？

### 5.5 节奏合理性

**检查清单**：
1. 打斗段落的镜头时长是否与紧张度匹配？（快切段落应≤1秒/镜）
2. 是否存在节奏单调（全部0.3秒或全部1秒）？
3. 是否有"加速→顶点→减速"的节奏弧线？
4. 最关键的碰撞/击中是否有稍长的镜头做"顶点"？
5. 收束镜头是否给了足够的呼吸时间？

### 5.6 声音层完整性

**检查清单**：
1. 每个碰撞镜头是否有对应Foley描述？
2. 喘息声是否在合适的节奏点出现？
3. 环境音（风啸/雨声/回响）是否与场景一致？
4. 是否有声音的"留白"——不是每个镜头都要填满声音，偶尔的静默也是节奏工具

## 六、手持摄影专项自检

### 6.1 手持层级选择合理性

**检查方法**：审查每个镜头的手持标注是否与场景情绪和空间复杂度匹配

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 大型战场用混乱手持 | 多人混战全程剧烈手持 | ❌ 空间本就复杂，手持让它更难读 |
| 呼吸感手持标注"手持微晃"以外 | 分镜只写"手持"不分层级 | ⚠️ 必须区分三层 |
| 超自然动作用手持 | 魔法战斗用临场感手持 | ⚠️ 纪实感与奇幻内容冲突 |
| 混乱手持超5秒 | 连续8秒剧烈手持 | ❌ 观众疲劳，真实感反转 |
| 全景+手持 | 打斗全景用混乱手持 | ⚠️ 全景手持失去空间可读性，用稳定器/轨道 |

**标准**：动作戏的手持选择必须回答两个问题——(1) 这个镜头的手持传递什么感受？(2) 这个感受是否与场景的叙事功能一致？

### 6.2 追焦延迟描述

**检查清单**：
1. 临场感手持镜头中，是否有追焦延迟的描述？
2. 碰撞/冲击瞬间，是否有冲击失焦的标注？
3. 角色突然变向时，是否有焦点追赶的描述？
4. 是否存在"手持+完美焦点"的矛盾——手持了但焦点永远精准，这比不用手持还假

### 6.3 手持与声音层配合

**检查清单**：
1. 手持镜头的声音层是否只有Foley，缺少环境音不稳定/电平波动的标注？
2. 临场感手持是否有"操作员呼吸声"或类似临场音效的标注？
3. 手持微晃节奏与撞击Foley是否有同步关系的标注？
4. 混乱手持段落的声画是否匹配——画面混乱但声音干净是不合理的

### 6.4 手持段落的空间可读性

**检查清单**：
1. 临场感手持段落中，180度轴线是否仍然可辨？
2. 正反打切换时，手持是否导致观众丢失左右关系？
3. 混乱手持段落结束后，是否有恢复空间可读性的过渡镜头？
4. 手持段落的构图是否仍保持"中心主体+清晰地理方向"——即使是晃的，观众也要知道谁在哪

## 七、场景参考图集专项自检

### 7.1 光影方向一致性

**检查方法**：对比9张参考图中的主光方向，是否与场景锚点表一致

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 光源方向翻转 | 正面全景主光从左来，侧面全景主光从右来 | ❌ 严重不一致 |
| 色温跳变 | 近景3500K暖调，俯视突然变6500K冷调 | ❌ 严重不一致 |
| 丁达尔遗漏 | 全景有明显丁达尔光效，近景无任何光柱/光斑 | ⚠️ 近景可能因景深看不到完整丁达尔，但局部光效应保留 |
| 阴影方向矛盾 | 正面光从左来但阴影向左投射 | ❌ 物理错误 |

**标准**：9个镜头的光源逻辑（方向+色温+光质+特殊光效）必须完全一致。近景中看不到完整光效是合理的，但不允许出现矛盾的光源方向。

### 7.2 空间结构一致性

**检查方法**：以镜头9（俯视全景）为"地图"，检查其他8个镜头中的空间关系是否与地图一致

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 道路位置矛盾 | 俯视显示道路居中，侧面显示道路偏右 | ❌ 空间矛盾 |
| 建筑朝向矛盾 | 正面显示门朝南，背面显示门朝北 | ❌ 方位矛盾 |
| 植被分布矛盾 | 正面全景右侧无大树，近景右侧出现大树 | ❌ 元素凭空出现 |
| 地形结构矛盾 | 俯视显示平坦，侧面显示有明显坡度 | ❌ 地形矛盾 |

**标准**：镜头9确立了场景的"上帝视角地图"，其他8个镜头的空间关系必须与地图一致。如果某个镜头的地标位置与地图矛盾，该镜头需重新生成。

### 7.3 色调与材质一致性

**检查方法**：审查9张图的色调和材质表现是否统一

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 新色调出现 | 8张都是粉+绿+暖金，某张突然出现大面积紫色 | ❌ 色调不一致 |
| 材质丢失 | 全景中花瓣通透有质感，某张近景花瓣变成色块 | ⚠️ 材质精度下降 |
| 季节/时段不一致 | 某张图花已凋谢或光线变成正午 | ❌ 时间矛盾 |
| 对比度跳变 | 8张柔和高对比，某张突然变成低对比扁平 | ⚠️ 风格不统一 |

**标准**：核心色调关键词跨9张图一致。材质精度保持同级。光影时段和季节状态一致。

### 7.4 景别区分度

**检查方法**：9张图放在一起，是否可以清晰区分每个机位

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 近景机位雷同 | 镜头1和镜头4几乎看不出区别 | ⚠️ 失去补充机位的意义 |
| 俯视机位雷同 | 镜头3和镜头6构图角度过于相似 | ⚠️ 浪费机位 |
| 全景机位雷同 | 镜头2和镜头5没有明显氛围差异 | ⚠️ 补充全景应有独特的氛围强化 |

**标准**：每个机位应有独特的视觉焦点和构图逻辑。两个近景机位应聚焦不同层次的前景元素；两个全景机位应有不同的氛围强化方向（如一个偏纵深一个偏雾气）。

### 7.5 叙事功能覆盖度

**检查方法**：9个机位是否覆盖了该场景在分镜中可能用到的所有镜头类型

**必须覆盖的叙事功能**：
- ✅ 定场镜头（正面全景/俯视全景）
- ✅ 角色主叙事镜头（正面全景/侧面全景）
- ✅ 角色特写前景（正面近景）
- ✅ 转场空镜（俯视近景/正面近景）
- ✅ 反向叙事（背面近景）
- ✅ 运动跟拍（侧面全景）
- ✅ 时空转场（俯视全景）

**常见遗漏**：背面近景最容易被忽略，但它对"回头镜头""反向主观视角"至关重要。如果9个机位没有背面视角，应补充。

## 八、视觉聚焦逻辑（Ocular Focus Logic）专项自检

### 8.1 双眼聚焦一致性

**检查方法**：审查所有近景/特写镜头，角色两眼是否聚焦于同一目标

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 两眼方向不一致 | 左眼看左，右眼看镜头 | ❌ "蜡像感"——大脑优先检测眼神方向 |
| 焦点漂浮 | 角色在对话中眼神无明显目标 | ❌ 空洞——没有视觉目标 |
| 跨镜头注视对象跳变 | S1-03注视A，S1-04突然注视B（无转移动作） | ❌ 视线转移缺失 |
| 远近聚焦不分 | 看近物和看远方的双眼内聚程度相同 | ⚠️ 缺少vergence变化 |

**标准**：每个眼神镜头必须标注注视目标+聚焦距离+内聚程度。跨镜头注视对象改变必须有视线转移描述。

### 8.2 高光锚点一致性

**检查方法**：对比同一场景内不同镜头的角色眼部高光方向

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 两眼高光方向不同 | 左眼高光在左上，右眼在右上 | ❌ 违反真实光学 |
| 高光与主光矛盾 | 主光在左上，高光在右下 | ❌ 物理不可能 |
| 多个高光来源 | 每只眼出现2+个高光点 | ⚠️ 如非多光源场景则为错误 |
| 跨镜头高光跳变 | S1-03高光在左上，S1-05高光在右上 | ❌ 同一场景光源体系不可变 |

**标准**：两眼高光方向必须一致且与场景主光方向对应。多光源场景允许两个高光但必须声明来源。

### 8.3 瞳孔与情绪匹配

**检查方法**：审查每个镜头的瞳孔状态是否与角色当前情绪一致

| 情绪 | 期望瞳孔状态 | 常见错误 |
|------|-------------|----------|
| 悲伤/隐忍 | 微缩+眼神下坠 | 瞳孔放大（AI默认瞳孔偏大） |
| 愤怒/决意 | 轻扩张+聚焦锁死 | 瞳孔正常大小（缺少扩张） |
| 恐惧/震惊 | 明显放大+上睑抬升露白 | 瞳孔正常+上睑正常（恐惧不到位） |
| 平静/日常 | 正常+微弱呼吸变化 | 瞳孔完全无变化（死板） |

**标准**：瞳孔大小不是固定的——它受情绪和光线双重影响，分镜中必须标注当前状态。

### 8.4 眼睑联动充分性

**检查方法**：审查眼神镜头是否有眼睑参与描述

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 眼皮完全不参与 | "眼球右转"但无眼睑描述 | ⚠️ 像"贴图在移动" |
| 恐惧不露白 | "恐惧"但上睑位置正常 | ❌ 恐惧必须有上睑抬升 |
| 凝视无张力 | "凝视"但眼睑无压迫感 | ⚠️ 缺少"凝视重量" |

**标准**：所有涉及眼神变化的镜头，必须有眼睑参与描述——眼球和眼皮是联动的，不是分离的。

### 8.5 视觉目标存在性

**检查方法**：审查每个近景/特写镜头，角色是否有明确的注视目标

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 无注视目标 | "角色看向镜头"但无叙事理由 | ⚠️ 空洞——角色在看什么？ |
| 注视目标不明 | "角色看着前方" | ⚠️ 太模糊——前方有什么？ |
| 目标与情绪矛盾 | 角色愤怒但注视目标不是愤怒对象 | ❌ 视觉注意链断裂 |

**标准**：每个眼神镜头必须回答"角色在看什么"和"为什么看"——没有视觉目标的眼神 = 没有灵魂的角色。

### 8.6 四易暴露区修正检查

**检查方法**：审查眼部特写提示词是否覆盖了4个AI最易穿帮区域

| 区域 | 必含修正声明 | 常见遗漏 |
|------|-------------|---------|
| 眼白（Sclera） | `subtle scleral veining, blue-white gradient` | 只有"white"无渐变/血丝 |
| 瞳孔边缘 | `pupil border with natural soft falloff` | 默认硬边未修正 |
| 虹膜纹理 | `radial iris fibers with depth variation, central heterochromia` | 贴图式均匀花纹 |
| 泪阜 | `translucent lacrimal caruncle with micro-capillaries` | 粉色贴片 |

**标准**：眼部特写（近景/极特写）提示词中4个区域至少覆盖3个。泪阜是重灾区，不可省略。

### 8.7 意识导向vs纹理导向优先级检查

**检查方法**：审查提示词中意识类词汇和纹理类词汇的数量比

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 纯纹理导向 | "ultra detailed eyes, glossy eyes, 8K iris" | ❌ 画了漂亮的假眼——高清但空洞 |
| 纯意识导向 | "locked gaze, focused attention" | ⚠️ 有效但可补充纹理修正 |
| 意识>纹理 | 3个意识词+1-2个纹理修正词 | ✅ 最优比例 |
| 纹理>意识 | 5个纹理词+0-1个意识词 | ❌ 本末倒置 |

**标准**：意识导向词汇（locked/conscious/alive/anchored/converged/emotionally focused）必须多于纹理导向词汇（detailed/glossy/bright/8K/high-res）。最低比例2:1。

### 8.8 视频微动画层完整性检查

**检查方法**：审查AI视频提示词中眼部4层微动画是否齐全

| 微动画层 | 必含声明 | 缺失后果 |
|----------|---------|---------|
| 微型扫视 | `microsaccadic eye movement every 1-2 seconds` | 眼睛像冻住的蜡像 |
| 瞳孔呼吸 | `pupil breathing rhythm, subtle dilation cycle` | 缺少自主神经信号 |
| 不规则眨眼 | `natural irregular blink pattern, 2-4s intervals` | 像不眨眼的恐怖人偶 |
| 眼睑跟随 | `eyelid compression following eye rotation` | 像贴图在移动 |

**标准**：AI视频生成中4层微动画缺一不可。静帧可以省略，但视频必须齐全。

## 九、多镜头视频序列专项自检

### 9.1 Global Motion Style 完整性

**检查方法**：审查序列开头是否有完整的全局声明

| 必含项 | 常见遗漏 |
|--------|----------|
| 整体风格基调 | 只有"cinematic"，缺少具体声明 |
| 皮肤真实感标准 | 缺少`visible pores`/`translucent skin tone`/`no fake whiteness` |
| 多参考图一致性锁 | 缺少`strictly using reference images`声明 |
| 影视级提示词原则块 | 缺少微表情+自然聚焦+粒子+光影+景深层次 |
| 运镜风格 | 只写"handheld"未标注呼吸感/微调 |
| 帧率与运动质感 | 缺少24fps声明或motion blur描述 |
| zero AI traces | 缺少`zero AI modeling traces`/`no soap opera effect` |

**标准**：7项缺一不可。全局声明是整个序列的"宪法"，缺失任何一项都会导致后续镜头在对应维度上失控。

### 9.2 解剖学肌肉控制充分性

**检查方法**：审查每个镜头的表情描述是否使用了解剖学肌肉名+权重

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 笼统情绪词 | "她很悲伤" | ❌ 无肌肉控制，AI自由发挥 |
| 缺少权重 | "zygomaticus lift" | ⚠️ 无权重=默认1.0，控制力弱 |
| 权重过高 | `(zygomaticus major lift:2.0)` | ❌ 过度，可能失真 |
| 过渡状态缺肌肉 | "微笑逐渐消失" | ⚠️ 需标注`(slow zygomaticus release:1.4)` |

**标准**：核心情绪转折必须用解剖学肌肉名+权重值(1.2-1.6)替代笼统情绪词。过渡状态同样需要肌肉标注——"微笑消退"不是没有肌肉活动，而是颧大肌的缓慢释放。

### 9.3 三层次结构完整性

**检查方法**：审查每个镜头是否包含主表演+小动作+微反应

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 只有主表演 | "她哭了，眼泪滑落" | ⚠️ 缺少身体维度和生理维度 |
| 缺少小动作 | 无手指/手部/身体的潜意识动作 | ⚠️ 表演"悬浮"在脸上，身体没参与 |
| 缺少微反应 | 无快速眨眼/吞咽/泛红等生理反应 | ⚠️ 像面具在变化，不是活人在反应 |
| 小动作无惯性 | "手指握紧"但缺少`natural inertia` | ⚠️ 动作太"指令感"，不像自然的 |

**标准**：三层次同时存在。小动作必须有`natural inertia`声明。微反应必须是"不受控的"生理反应，不是"决定做的"动作。

### 9.4 情绪着陆点与弧线

**检查方法**：列出所有镜头的情绪着陆点，检查是否构成连贯弧线

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 无着陆点 | 镜头描述完就结束，无情绪状态声明 | ❌ 镜头间情绪断裂 |
| 着陆点跳跃 | Shot 1: joy → Shot 2: heartbreak | ❌ 缺少过渡情绪 |
| 着陆点重复 | Shot 3和Shot 4都是"sadness" | ⚠️ 情绪无推进 |
| 弧线断裂 | 情绪从悲伤突然回到快乐（无叙事理由） | ❌ 不合理的情绪跳变 |

**标准**：每个镜头有明确的情绪着陆点。连续镜头着陆点构成渐进的弧线（不能跳跃超过一个情绪梯度）。着陆点不是"开始时的情绪"而是"结束时的情绪"。

### 9.5 焦距节奏合理性

**检查方法**：审查焦距变化序列是否有节奏逻辑

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 焦距无变化 | 5个镜头全是85mm | ⚠️ 缺少视觉节奏 |
| 焦距跳变 | 50mm → 100mm → 50mm | ⚠️ 过于剧烈，缺少过渡 |
| 最紧焦距不在情绪高点 | 100mm用在平静的镜头 | ⚠️ 焦距与情绪不匹配 |
| 结尾无呼吸空间 | 最后一个镜头用100mm | ⚠️ 观众无法消化，需要拉远给空间 |

**标准**：焦距变化应与情绪弧线同步——情绪越激烈焦距越紧，结尾应给观众退一步的空间(50mm)。典型节奏：85→85→100→85→50。

### 9.6 眼泪物理进度连贯性

**检查方法**：审查跨镜头眼泪状态是否遵循物理时间线

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 眼泪凭空出现 | 上一镜无泪，下一镜满脸泪痕 | ❌ 缺少形成过程 |
| 眼泪倒退 | 下一镜泪痕比上一镜少 | ❌ 违反不可逆原则 |
| 缺少泪液蓄积 | 直接从"无泪"跳到"第一滴滑落" | ⚠️ 缺少tear meniscus buildup |
| 第二滴与第一滴相同 | "second tear follows"但无asymmetric merging | ⚠️ 两滴泪不应完全相同 |

**标准**：眼泪跨镜头遵循"无→蓄积→第一滴形成→第一滴滑落→第二滴跟随→多泪痕"的完整物理时间线。每一阶段都有对应的肌肉和光线描述。

## 十、面瘫美学（Deadpan Aesthetics）专项自检

### 10.1 表情纯度——情绪泄露检查

**检查方法**：审查面瘫场景的所有镜头，角色是否有任何情绪微表情"泄露"

| 泄露类型 | 示例 | 判定 |
|----------|------|------|
| 意外微笑 | 角色嘴角微微上扬 | ❌ 面瘫场景不允许 |
| 意外皱眉 | 角色眉间出现竖纹 | ❌ 情绪泄露 |
| 瞳孔情绪响应 | 角色在恐惧事件中瞳孔扩张 | ❌ 瞳孔只响应光线，不响应情绪 |
| 眼睑紧张 | 角色上睑有压迫感 | ❌ 眼睑应完全放松 |
| 嘴唇微颤 | 角色下唇轻微抖动 | ❌ 最常见的情绪泄露 |

**标准**：面瘫角色的面部肌肉必须始终处于休息态——无紧张、无微颤、无情绪性变化。唯一的生理性允许项：光线引起的瞳孔微调+自然频率眨眼。

### 10.2 眼神区分——面瘫 vs Dead-Eye

**检查方法**：确认角色的"不反应"是创作选择而非AI技术缺陷

| 判定维度 | 面瘫（✅） | Dead-Eye（❌） |
|----------|----------|---------------|
| 双眼聚焦 | 一致但抽离 | 不一致或漂浮 |
| 高光 | 正常存在 | 缺失或矛盾 |
| 意识感 | 在场但不参与 | 不在场（空洞） |
| 微扫视 | 极微但存在 | 完全缺失 |

**标准**：面瘫眼神=`conscious + detached`，dead-eye=`unconscious + hollow`。提示词中必须同时包含两者声明。

### 10.3 构图与色调纯度

**检查方法**：审查面瘫场景的构图和色调是否与微表情场景有明显区分

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 构图打破对称 | 面瘫场景用了三分法 | ❌ 面瘫要求对称/居中 |
| 情绪色调混入 | 低饱和场景突然变暖黄 | ❌ 色调不参与情绪 |
| 前景遮挡 | 面瘫场景有前景遮挡 | ❌ 前景遮挡暗示主观视角，面瘫不需要 |
| 手持晃动 | 面瘫场景用手持 | ❌ 摄影机也不"反应" |

**标准**：面瘫场景的构图/色调/运镜都应服从"不反应"原则——构图对称稳定、色调低饱和冷淡、运镜固定或极缓慢。

### 10.4 荒诞可见性

**检查方法**：面瘫的幽默/张力来自"事件荒诞+角色不反应"——事件本身是否足够荒诞？

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 事件不荒诞 | 角色面瘫地喝了一杯水 | ⚠️ 缺少张力——日常行为+面瘫=无聊 |
| 事件荒诞但角色反应了 | 爆炸发生，角色微微惊讶 | ❌ 面瘫被打破 |
| 事件荒诞+角色不反应 | 爆炸发生，角色继续喝茶 | ✅ 面瘫的幽默成立 |

**标准**：面瘫美学需要"事件荒诞+角色不反应"同时成立。如果事件本身不荒诞，面瘫只是"无聊"；如果角色对荒诞有反应，面瘫被打破。


## 十一、多人物场面调度专项自检

### 11.1 空间坐标一致性

**检查方法**：审查多人场景的所有镜头，角色在屏幕上的位置是否跨镜头一致

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 左右互换 | S1-01角色A在screen left，S1-03角色A跑到screen right（无移动描写） | ❌ 空间断裂 |
| 前后层跳 | S1-02角色B在midground，S1-04角色B突然在foreground（无走位描写） | ❌ 空间断裂 |
| 使用相对描述 | "角色A站在B旁边" | ⚠️ 应使用绝对坐标screen left/right |
| Z轴矛盾 | 俯视图中角色在台阶下方，正面镜头角色在高位 | ❌ 空间矛盾 |

**标准**：多人场景必须使用Screen Position绝对坐标（screen left/right + foreground/midground/background）。跨镜头角色位置变化必须有走位/动作描写覆盖，不允许"瞬移"。

### 11.2 摄影机方向一致性

**检查方法**：审查同一场景内所有镜头的摄影机朝向声明

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 摄影机方向缺失 | 多人镜头无`camera facing`声明 | ⚠️ AI会自由选择方向 |
| 方向跨镜头变化 | S1-01 camera facing east，S1-03 camera facing west | ❌ 等于越轴 |
| 只变方向不变空间 | 换了camera facing但空间描述没跟着更新 | ❌ 方向与空间矛盾 |
| 景别变化时遗漏声明 | 从广角切近景时省略`camera facing` | ⚠️ AI可能重新猜方向 |

**标准**：同一场景内所有镜头必须声明相同的`camera facing [方向]`。景别/焦距可以变，摄影机方向不变。空间不变，只变取景。

### 11.3 180°法则检查

**检查方法**：对话/对峙场景中，画出角色连线，确认所有镜头机位在轴线同一侧

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 正反打越轴 | A看右B看右（应该A看右B看左） | ❌ 越轴 |
| 正反打视线不匹配 | A看向screen right但B不在screen right | ❌ 视线错误 |
| 缺少锁轴声明 | 正反打提示词无`consistent camera orientation` | ⚠️ AI可能越轴 |
| 轴线随镜头移动 | 两人位置关系在正反打中互换 | ❌ 空间崩塌 |

**标准**：正反打镜头必须有`consistent camera orientation same side of axis`声明。角色A在screen left→A看向screen right；角色B在screen right→B看向screen left。视线方向与位置必须互补。

### 11.4 角色身份与标签一致性

**检查方法**：审查多人场景中每个角色的标签是否跨镜头固定

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 使用泛称 | 提示词中只有"man""woman" | ❌ AI无法区分 |
| 标签跨镜头变化 | S1-01"scar-faced commander"，S1-03"the commander" | ⚠️ 标签省略可能导致串脸 |
| 两个角色标签相似 | "armed guard"和"armed soldier" | ⚠️ 区分度不足 |
| 标签与锚点表矛盾 | 锚点表"红色铠甲"，标签写"black armor" | ❌ 一致性红线 |

**标准**：每个角色必须拥有独特的视觉特征标签，跨镜头逐字重复。标签应包含至少一个独特元素（颜色+身份+标志性特征）。

### 11.5 主角色优先级合理性

**检查方法**：审查Primary/Secondary/Background的分配是否与叙事重心一致

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 无层级声明 | 多人场景没有Primary/Secondary区分 | ⚠️ AI注意力分散 |
| 层级与叙事矛盾 | 配角是Primary，主角是Secondary | ❌ 画面重心错位 |
| Background过度描述 | 3个背景群演各用50词描述 | ⚠️ 分散AI注意力 |
| 层级跨镜头跳变 | S1-01 A是Primary，S1-03 B变Primary | ⚠️ 需确认是否有叙事理由 |

**标准**：每个多人镜头必须有Primary/Secondary/Background层级声明。Primary=叙事焦点角色，获得最详尽描述。Background extras=占位角色，极简描述即可。

### 11.6 负空间与人物分离

**检查方法**：审查AI生成的多人画面，角色之间是否有足够的视觉分离

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 人物融合 | 两个角色的身体部位混在一起 | ❌ AI灾难 |
| 肢体重叠 | 角色A的手臂穿过角色B的躯干 | ❌ 空间逻辑崩坏 |
| 无负空间声明 | 提示词中无negative space/separation | ⚠️ 高融合风险 |
| 过度拥挤 | 4+角色挤在前景，无层级分离 | ⚠️ AI难以处理 |

**标准**：所有多人场景提示词必须包含负空间声明（`large negative space between characters`或`clear visual separation`）。超过3人的场景建议使用深度分层（foreground/midground/background）分散角色。

### 11.7 动作连续性检查

**检查方法**：审查多人动作场景中，动作是否跨镜头延续

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 动作断裂 | 上一镜出拳，下一镜角色站在原地（无收招描写） | ❌ 动作链断裂 |
| 缺少continuation声明 | 连续动作镜头无`continuation motion` | ⚠️ AI可能重置动作 |
| 位移丢失 | 角色被击退3米，下一镜站在原位 | ❌ 空间逻辑错误 |
| 群戏动线混乱 | 多人同时移动但轨迹未标注 | ⚠️ AI容易混淆方向 |

**标准**：多人动作场景的连续镜头必须声明`continuation motion`/`same movement trajectory`。角色位移必须有走位描写覆盖。群戏中每条动线独立标注。

### 11.8 构图稳定性

**检查方法**：审查多人场景的构图选择是否有利于空间稳定

| 构图类型 | 稳定性 | 风险点 |
|----------|--------|--------|
| 对称构图 | ★★★★★ | AI可能微调打破对称，需声明`strictly symmetrical` |
| 三角构图 | ★★★★☆ | 三人位置需明确声明，否则AI可能排成一字 |
| 深度分层 | ★★★★☆ | 需景深配合，前景锐利+中景适中+背景虚化 |
| 三分法 | ★★★☆☆ | 多人场景中三分法不如对称稳定 |
| 随意构图 | ★★☆☆☆ | AI自由发挥，多人场景风险最高 |

**标准**：多人场景优先使用对称/三角/深度分层构图——这三种构图对AI来说最稳定。避免随意构图。

### 11.9 俯视Blocking图与镜头位置校验

**检查方法**：如果生成了俯视Blocking图，校验所有镜头中的角色位置是否与俯视图一致

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 无俯视规划 | 多人场景无空间规划图 | ⚠️ 空间关系可能自相矛盾 |
| 镜头与俯视图矛盾 | 俯视图A在左B在右，镜头中B在左A在右 | ❌ 空间矛盾 |
| 动线未在俯视图标注 | 角色在镜头中移动但俯视图无动线 | ⚠️ 位移无规划 |
| 光源未在俯视图标注 | 俯视图无光源位置 | ⚠️ 光影方向可能矛盾 |

**标准**：3人及以上场景建议先生成俯视Blocking图。所有镜头的角色位置必须与俯视图一致。动线和光源应在俯视图中标注。

### 11.10 空镜先行工作流合规性

**检查方法**：审查多人场景是否遵循"先生成空镜再放角色"的工作流

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 直接生成多人 | 无空镜基础，直接写多人提示词 | ⚠️ 空间和光影一致性风险高 |
| 空镜与人物镜光影不一致 | 空镜月光从右，人物镜月光从左 | ❌ 底板不一致 |
| 空镜空间与人物镜空间矛盾 | 空镜中无柱子，人物镜中出现柱子 | ❌ 空间矛盾 |
| 后续镜头未引用空镜锚定段 | 人物镜头重新描述空间而非复制空镜描述 | ⚠️ 可能引入矛盾 |

**标准**：多人场景优先使用空镜先行工作流。空镜锁定空间+光影后，人物镜头的CAMERA+SPACE+LIGHTING段应逐字复制空镜描述，只替换BLOCKING段。


## 十二、三步表演法专项自检

### 12.1 面部肌肉拆解充分性

**检查方法**：审查情绪镜头是否用了解剖学肌肉+权重替代了笼统情绪词

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 使用笼统情绪词 | "她很开心" | ❌ AI随机发挥，结果不可控 |
| 有肌肉名无权重 | "zygomaticus lift" | ⚠️ 无权重=默认1.0，控制力弱 |
| 有肌肉无辅助细节 | "(zygomaticus major:1.35)" 但无鱼尾纹/泪光/鼻翼等 | ⚠️ 情绪有"质"但无"味" |
| 有肌肉无程度副词 | 面部肌肉描述但不标注"微微""缓慢""极轻微" | ⚠️ 情绪有"质"但无"量" |

**标准**：情绪万能公式三项缺一不可——核心肌肉动作（质）+辅助细节（味）+程度副词（量）。三者同时存在才算完整的表演指令。

### 12.2 肢体语言存在性

**检查方法**：审查情绪镜头是否包含身体维度的同步描述

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 纯面部表演 | 只有面部肌肉描述，无任何肢体动作 | ❌ 假人感——身体没参与 |
| 肢体动作太笼统 | "她很紧张地坐着" | ⚠️ 没写具体身体在做什么 |
| 缺少生理微反应 | 有动作无耳根泛红/手指发白/吞咽等 | ⚠️ 缺少不受控的生理层 |
| 肢体与面部矛盾 | 面部写"克制"但肢体写"激动地挥舞双手" | ❌ 表演逻辑自相矛盾 |

**标准**：情绪镜头必须同时包含面部+肢体+生理微反应三个维度。肢体动作必须有`natural inertia`声明。

### 12.3 角色性格差异化

**检查方法**：审查同一场景中不同角色对同一情绪的表达方式是否不同

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 所有角色同一种"开心" | 冷酷男主和活泼女二用同样的微笑描述 | ❌ 角色没有区分度 |
| 锚点表无性格标注 | 角色锚点表中没有标注性格类型 | ⚠️ 无法判断该用什么表演风格 |
| 性格与表演矛盾 | 角色性格标注"冷酷"但提示词写"咧嘴大笑" | ❌ 表演与设定矛盾 |
| 同角色跨场景表情雷同 | 角色在所有场景中都用同一套情绪表达 | ⚠️ 表演缺乏层次变化 |

**标准**：角色锚点表中必须标注性格类型（冷酷/温柔/活泼/沉稳等）。同一情绪，不同性格用不同的肌肉组合+肢体动作。同角色在不同情境下可以有细微变化但基调整体一致。

### 12.4 时间轴拆解充分性

**检查方法**：审查复杂情绪是否拆成了逐秒/逐镜头的递进阶段

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 一句话概括情绪 | "她很惊喜" | ❌ AI无法执行复杂情绪递进 |
| 无时间轴 | "她先是震惊然后开心最后哭了" | ⚠️ 有顺序但无节奏，AI不知道每个阶段多长 |
| 时间轴过于贪心 | 10秒内要完成5个情绪转折 | ❌ AI处理不了，会变成表情包 |
| 阶段间缺过渡 | "震惊→开心"无中间的消化过程 | ⚠️ 情绪跳变不自然 |

**标准**：复杂情绪必须拆成逐秒/逐镜头的递进阶段。单次AI生成的情绪阶段不超过3个转折。单次抽卡时长控制在情绪阶段的70%以内——分镜+剪辑才是正道。

### 12.5 强约束兜底

**检查方法**：审查每段情绪提示词末尾是否有兜底约束声明

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 无兜底约束 | 提示词结束无任何变形/夸张/稳定声明 | ⚠️ AI可能放飞自我 |
| 约束与表演矛盾 | 克制表演但约束写"emotional performance" | ❌ 约束与表演方向冲突 |
| 约束太笼统 | "natural" | ⚠️ 太模糊，AI理解不一 |

**标准**：每段情绪提示词末尾必须有强约束兜底声明。克制表演→"no exaggerated expressions, no facial deformation, stable frame"；爆发表演→"emotional peak but controlled, no facial distortion"；哭戏→"realistic tear physics, no melodramatic sobbing"。

### 12.6 光影与情绪绑定

**检查方法**：审查情绪镜头是否有与情绪匹配的光影描述

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 无光影描述 | 情绪特写但无光影声明 | ⚠️ AI随机给光=氛围感打折 |
| 光影与情绪矛盾 | 悲伤场景用暖调柔光 | ❌ 光影与情绪冲突 |
| 光影不变 | 情绪递进但光影没有跟随变化 | ⚠️ 浪费了光影叙事潜力 |
| 只写笼统光影 | "cinematic lighting" | ⚠️ 太模糊，必须指定冷/暖/硬/柔+方向 |

**标准**：情绪镜头必须写明光影描述，且光影类型与情绪类型匹配。情绪递进时光影可随之渐变（如迷茫→觉醒时冷调散光→正面硬光）。


## 十三、运镜五境专项自检

### 13.1 运镜速度精确化

**检查方法**：审查所有运镜镜头是否使用了具体数字替代形容词

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 使用形容词 | "缓慢推进""快速横移" | ❌ 不可控，模型只能猜 |
| 有距离无时间 | "推进2米" | ⚠️ 不知道多久推完，速度不确定 |
| 有时间无距离 | "5秒内推进" | ⚠️ 不知道推进多少，距离不确定 |
| 时间+距离完整 | "5秒内从3米推进到1米" | ✅ 精确可控 |
| 焦段变焦 | "4秒内从35mm变焦到85mm" | ✅ 更精准 |

**标准**：所有运镜必须使用"时间+距离"或"时间+焦段"的精确描述。形容词（"缓慢""快速""轻轻"）在提示词中禁止使用。

### 13.2 反向规则检查

**检查方法**：审查每个运镜镜头，主体动作方向和运镜方向是否形成"对抗"

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 同向运镜（无叙事理由） | 主体向前走+镜头向前推 | ❌ 平庸如vlog跟拍 |
| 同向但需确认 | 主体抬头+镜头向上摇 | ⚠️ 是否有叙事理由必须同向？ |
| 反向运镜 | 主体向前走+镜头向后退 | ✅ "动而不离"电影感 |
| 视线反向 | 角色看向左+镜头右移 | ✅ 视觉张力 |
| 无主体动作的运镜 | 纯运镜无人物动作 | — 不适用反向规则 |

**标准**：有人物动作的运镜镜头，主体动作方向和运镜方向应相反（除非有明确叙事理由需要同向，如跟拍长镜头）。视线方向同理。

### 13.3 锚点充分性

**检查方法**：审查每个运镜镜头是否有明确的起始画面和结束画面

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 无锚点 | "镜头推进" | ❌ 起止状态混乱 |
| 仅有起点 | "从全景开始推进" | ⚠️ 不知道推到哪 |
| 仅有终点 | "推进到面部特写" | ⚠️ 不知道从哪开始 |
| 双锚点完整 | "全景全身→5秒推进→面部特写" | ✅ |
| 长镜头缺三锚点 | 8秒+镜头只有起止 | ⚠️ 中间缺过渡锚点 |

**标准**：所有运镜镜头必须有双锚点（起始画面+结束画面）。8秒以上长镜头推荐三锚点（起点+中点+终点）。每个锚点包含景别+主体位置+构图+背景。

### 13.4 复合运镜合理性

**检查方法**：审查复合运镜的选择是否与叙事功能匹配

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 所有镜头都是单一运镜 | 全片只有推/拉/摇 | ⚠️ 视觉单调，复合运镜是模型舒适区 |
| 复合运镜过于复杂 | 4个维度同时运动 | ⚠️ 过度，模型可能失控 |
| 希区柯克变焦用于日常 | 对话场景用Dolly Zoom | ❌ 过度炫技，不服务叙事 |
| 复合运镜与场景匹配 | 登场用环绕推进/揭示用横移变焦 | ✅ 运镜服务叙事 |

**标准**：重要镜头（登场/揭示/情绪转折/高潮）优先使用复合运镜。日常叙事可用单一运镜。希区柯克变焦仅用于眩晕/强烈情绪场景。

### 13.5 静止镜头使用判断

**检查方法**：审查是否有本应使用静止镜头却用了运镜的场景

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 情绪特写用了运镜 | 哭泣特写+推镜 | ⚠️ 运镜分散注意力，静止更好 |
| 决定性瞬间用了运镜 | 角色做决定前+横移 | ⚠️ 应该用静止制造"屏住呼吸"感 |
| 全片无静止镜头 | 8个镜头全部有运镜 | ⚠️ 观众疲劳，缺少呼吸空间 |
| 静止但写法错误 | "完全静止固定机位" | ⚠️ 像照片，应加"极微弱呼吸感" |

**标准**：情绪特写/决定性瞬间/极致美景/心理深度场景→静止镜头。静止≠完全不动，需加`extremely subtle breathing motion (<5cm)`声明。项目中静止镜头占比建议≥30%。

### 13.6 运镜速度词典一致性

**检查方法**：审查同一项目内运镜速度描述是否使用统一标准

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 同场景同速度用不同描述 | S1-01"5秒推进2米"，S1-03"缓慢推进" | ❌ 标准不统一 |
| 速度等级与场景不匹配 | 日常对话用超快推进 | ❌ 叙事节奏错误 |
| 无速度词典 | 项目没有统一的速度标准 | ⚠️ 建议建立项目速度词典 |

**标准**：同一项目内使用统一的速度词典（极慢8-10s/慢速5-6s/中速3-4s/快速1.5-2s/超快<1s）。速度等级与叙事节奏匹配——日常用中慢速，紧张用快速，情绪高潮后用静止。

## 十四、角色描写精度专项自检

### 14.1 抽象词清零检查

**检查方法**：搜索角色锚定段和提示词中的抽象评价词/情绪词

| 抽象词类型 | 示例 | 判定 |
|-----------|------|------|
| 权力类 | "imposing""powerful""intimidating""authoritative" | ❌ AI不可执行，替换为空间占有/动作节奏/视线方向 |
| 奢华类 | "luxurious""expensive""high-end" | ❌ 替换为具体面料/金属/剪裁术语 |
| 情绪类 | "cold""arrogant""mysterious" | ❌ 替换为肌肉状态+眼睑高度+视线落点 |
| 氛围类 | "powerful aura""intimidating presence" | ❌ 替换为体态占位+微动作频率+环境反射 |
| 颜色类 | "black suit""white shirt""blue tie" | ⚠️ 过于笼统，需精确色名 |

**标准**：角色锚定段和提示词中零抽象评价词。每个词都必须是AI能"画出来"的视觉指令。

### 14.2 六维覆盖完整性检查

**检查方法**：逐维度审查角色锚点表是否六维齐全

| 维度 | 必含信息 | 常见遗漏 |
|------|---------|---------|
| 1.体型与轮廓 | 身高+肩型+剪影+重心 | 只写"高大"无具体数据 |
| 2.面部特征 | 骨骼结构+肌肉走向+嘴角方向 | 只写"冷酷"无骨相描述 |
| 3.发型 | 颜色+密度+款式+光泽+鬓角 | 只写"整齐"无技术细节 |
| 4.服饰 | 颜色+面料+驳头+扣位+剪裁+袖口+配套 | 只写"西装"无任何规格 |
| 5.道具 | 材质+颜色+尺寸+位置+光线交互 | 只写"腕表"无交互描述 |
| 6.体态 | 姿态角度+微动作频率+视线落点+静止部位 | 只写"气场"无物理描述 |

**标准**：六个维度每个至少3项具体信息。服饰维度至少7项（颜色/面料/驳头/扣位/剪裁/袖口/配套）。道具维度必须包含光线交互。

### 14.3 服饰精度检查

**检查方法**：审查西装/重要服饰是否达到行业术语级精度

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 颜色笼统 | "black suit" | ❌ 应为"charcoal-black"或"midnight navy"等精确色名 |
| 无面料信息 | "custom suit" | ❌ 应含材质+织法+光泽度 |
| 无驳头类型 | "suit jacket" | ❌ 必须指定notch/peak/shawl |
| 无扣法说明 | "two-button suit" | ❌ 必须说明扣几粒+扣法惯例 |
| 无剪裁描述 | "fitted suit" | ❌ 应为structured/natural shoulder + suppressed/regular waist |
| 衬衫无配套 | 仅写"shirt" | ❌ 应含颜色+领型+袖型+袖扣 |
| 领带无规格 | "tie" | ❌ 应含颜色+材质+结型+紧密度 |

**标准**：西装类服饰7要素全覆盖（颜色/面料/驳头/扣位/剪裁/袖口/配套）。每个要素用行业术语而非日常用语。

### 14.4 道具光线交互检查

**检查方法**：审查每个标志性道具是否写了它与场景光线的交互

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 死道具 | "platinum watch on left wrist" | ❌ 无光线交互 |
| 活道具 | "platinum watch, dial catching cold spotlight reflection" | ✅ 有光线交互 |
| 反射面未写 | "glass walls" | ❌ 应写反射效果 |
| 地面反射遗漏 | "marble floor" | ⚠️ 应写反射内容 |

**标准**：每个标志性道具必须写光线交互——它在场景光源下的反射/折射/投影效果。这是道具从"贴图"变成"存在于场景中的物"的关键。

### 14.5 表演基态检查

**检查方法**：审查角色锚点表是否包含"不做表情时的默认脸"

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 无表演基态 | 锚点表只有外貌无表情基态 | ❌ AI每个镜头随机表情 |
| 情绪词代替 | "cold expression" | ❌ 应为肌肉级描述 |
| 眼睑未指定 | "staring" | ❌ 应指定眼睑遮盖虹膜比例 |
| 视线无目标 | "looking at viewer" | ❌ 应指定精确落点如"glabella" |
| 下颌线未锁定 | 表情描述无下颌线状态 | ⚠️ 下颌线松弛/收紧=情绪泄露 |

**标准**：锚点表必须包含面部表演锚定（基态层）：眼睑高度+视线落点+眉头状态+下颌线张力。没有表演基态=AI在每个镜头中随机赋予表情。

### 14.6 权力视觉化检查（仅权力角色）

**检查方法**：审查权力角色是否用视觉证据链替代了抽象"权势"

| 视觉证据层 | 已实现？ | 常见问题 |
|-----------|---------|---------|
| 空间占有 | ☐ | 仅写"气场"无空间占位描述 |
| 动作节奏控制 | ☐ | 微动作无频率，如"occasionally" |
| 视线方向权力 | ☐ | 视线无精确落点 |
| 环境映射 | ☐ | 场景中无反射/叠影效果 |
| 材质等级 | ☐ | 服饰/道具品质笼统 |

**标准**：权力角色至少覆盖4/5层视觉证据链。每层用具体物理描述替代抽象评价词。

### 14.7 通用工作流合规性检查

**检查方法**：审查角色描写是否经过五步法流程

| 步骤 | 检查项 | 未通过的后果 |
|------|--------|-------------|
| 第一步·圈抽象词 | 原始描述中所有抽象词是否已标记？ | 遗漏的抽象词会混入提示词浪费token |
| 第二步·追问视觉证据 | 每个抽象词是否找到了视觉证据链？ | 未转化的抽象词仍不可执行 |
| 第三步·六维重组 | 六个维度是否都有内容？ | 空白维度=AI随机发挥 |
| 第四步·服饰道具加码 | 服饰7要素+道具光线交互？ | AI最易随机发挥的两个维度失控 |
| 第五步·表演基态 | 默认脸+1-2种情绪变体+肢体同步？ | 每个镜头表情随机 |

**标准**：五个步骤都必须有输出物。第三步零空白维度。第四步服饰7要素全覆盖。

### 14.8 角色类型精度重点覆盖检查

**检查方法**：确定角色类型后，审查其精度优先级最高的2个维度是否达到最高精度

| 角色类型 | 最高优先级维度 | 必达精度 |
|----------|---------------|---------|
| 权力型反派 | 维度6体态+维度2面部 | 体态：空间占有+微动作频率+静止部位+视线落点；面部：骨相+眼睑+基态+1种情绪变体 |
| 魅惑型反派 | 维度4服饰+维度2面部 | 服饰：面料/剪裁/露肤度/颜色精确化；面部：吸引力的视觉机制（非笼统"美丽"） |
| 女主/恋人 | 维度2面部+维度6体态 | 面部：3种以上情绪变体的肌肉级描写；体态：情感泄露机制（手/呼吸/视线） |
| 少年/成长型 | 维度3发型+维度1体型 | 发型：活力/运动/成长隐喻；体型：半成熟特征（骨线未定/手偏大/肩线发育中） |
| 老人/智者 | 维度2面部+维度5道具 | 面部：皱纹地图+皮肤质感+虹膜清浊；道具：磨损/包浆/故事感+光线交互 |
| 冷面/面瘫型 | 维度2面部+维度6体态 | 面部：禁令级描写（NO+ONLY约束）；体态：极低频率+机械化动作+禁用微反应 |
| 配角/功能型 | 维度4服饰+维度3发型 | 服饰：1-2个远距离可辨识标志；发型：剪影即可辨认 |

**标准**：角色类型对应的最高优先级2个维度必须达到"必达精度"。其余维度允许简化但不可空白。

## 十五、暧昧/恋爱/亲密戏专项自检

### 15.1 双力结构检查——暧昧镜头是否同时存在靠近+克制

**检查方法**：审查每个暧昧镜头的提示词是否同时包含吸引力和抵抗力

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 只有靠近 | "loving gaze toward her" | ❌ 直白无张力 |
| 只有克制 | "avoiding eye contact" | ❌ 冷漠无温度 |
| 靠近+克制并存 | "gaze drawn toward her then catching himself" | ✅ 暧昧张力 |
| 抽象暧昧词 | "romantic tension between them" | ❌ 不可执行，需双力替代 |

**标准**：每个暧昧镜头必须同时声明[attraction signal]+[resistance signal]。抽象词"romantic tension"不能替代双力结构。

### 15.2 视线类型与停留时间检查

**检查方法**：审查恋爱镜头中的视线是否精确到类型+时间

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 视线笼统 | "they look at each other" | ❌ 应明确偷看/余光/反射/擦肩/对视后移开 |
| 无停留时间 | "he looks at her longingly" | ❌ 应为"2 seconds too long"等精确时间 |
| 完整直视过多 | 连续3个镜头都是正面完整对视 | ⚠️ 真正心动的人很少长时间直视 |
| 无不完整视线 | 没有偷看/余光/反射等 | ⚠️ 高级暧昧极少正面直视 |

**标准**：视线类型必须5选1（偷看/余光/反射/擦肩/对视后移开），停留时间精确到秒。不完整视线占比应≥60%。

### 15.3 呼吸感镜头检查

**检查方法**：审查运镜是否随情绪状态变化而非固定节奏

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 运镜无变化 | 全程"缓慢推进" | ❌ 应随情绪变化：靠近→推进/发现→停止/失控→微晃 |
| 无停顿 | 暧昧镜头全部连续运镜 | ❌ 镜头停止是叙事事件——"空气变了" |
| 呼吸感缺失 | 运镜机械无生命感 | ⚠️ 镜头应像"一个人正在偷偷观察另一个人" |

**标准**：恋爱戏运镜必须有节奏变化——推进→停止→微晃→锁定的情绪同步。至少30%的镜头包含"停顿"时刻。

### 15.4 空间距离逻辑检查

**检查方法**：审查恋爱戏是否通过空间距离外化心理距离

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 无距离变化 | 所有镜头两人距离相同 | ❌ 爱情戏真正拍的是距离变化 |
| 无空间障碍 | 初识阶段就站得很近 | ⚠️ 安全距离阶段应有障碍物 |
| 无"差一点" | 只有牵手/拥抱等完成动作 | ⚠️ 未完成动作张力更强 |
| 距离倒退 | 暧昧阶段反而比初识更远 | ❌ 除非有叙事理由（如争吵后疏离） |

**标准**：恋爱戏必须有明确的空间距离递进：安全距离（障碍物）→危险距离（私人空间）→暧昧距离（差一点）。至少1个"差一点碰到"镜头。

### 15.5 亲密戏镜头重点检查

**检查方法**：审查亲密戏的镜头对准部位

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 镜头对准正面身体 | 亲密戏大量正面身体镜头 | ❌ 高级亲密戏重点在手/后颈/肩膀/呼吸/头发 |
| 无呼吸停顿 | 亲密戏持续无中断 | ❌ 呼吸与停顿=亲密戏骨架 |
| 直接从动作开始 | 亲密戏一开场就是接触 | ❌ 应先建立安静/情绪/空间 |
| 无手部特写 | 亲密戏无手部镜头 | ⚠️ 手部是最亲密的非接触部位 |

**标准**：亲密戏镜头重点顺序：手>后颈>肩膀>呼吸>头发>眼神>皮肤光线>正面身体。必须有"靠近→停住→不立刻继续"节奏。必须先建立安静再进入接触。

### 15.6 焦距与恋爱阶段匹配检查

**检查方法**：审查焦距选择是否匹配恋爱阶段

| 阶段 | 正确焦距 | 错误焦距 |
|------|---------|---------|
| 初识 | 24-35mm广角 | ❌ 85mm（太亲密） |
| 暧昧 | 50mm中焦 | ❌ 24mm（太疏离）或135mm（太压迫） |
| 心动 | 85-100mm长焦 | ❌ 35mm（距离感不对） |
| 失控 | 变焦/手持 | ❌ 固定50mm（太冷静） |
| 平静 | 50-85mm回中 | ❌ 135mm（压迫感未释放） |

**标准**：焦距随恋爱五阶段递进（广角→中焦→长焦→失控→回中焦）。心动阶段背景应逐渐失焦——世界在消失。

### 15.7 光影情绪匹配检查

**检查方法**：审查光影类型是否服务于恋爱情绪

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 纯硬光 | 暧昧场景用硬直光 | ❌ 应为柔光/侧光/冷暖混合 |
| 无阴影 | 完全明亮无暗部 | ⚠️ 阴影=秘密，爱情戏需保留阴影 |
| 无冷暖混合 | 暧昧场景单色温 | ⚠️ 冷暖混合=理性世界中的情绪温度 |
| 光影与情绪矛盾 | 心动场景用冷色大平光 | ❌ 应有温度变化 |

**标准**：暧昧场景至少包含柔光+阴影+冷暖混合中的一种。心动场景光影应有变化（如环境光渐暖/阴影渐深）。亲密戏光线必须包裹感（非硬直光）。

## 十六、剧本→视觉资产提取专项自检

### 16.1 角色提取完整性检查

**检查方法**：审查每个角色是否提取了10项信息

| 遗漏字段 | 后果 | 优先级 |
|----------|------|--------|
| 外貌特征 | 设定图面部随机 | 必须补全 |
| 服装风格 | 设定图服装随机 | 必须补全 |
| 核心气质 | 角色缺乏辨识度 | 必须补全 |
| 常见表情 | 无表演基态=每镜随机 | 必须补全 |
| 关键动作 | 角色姿态空洞 | 应补全 |
| 人物关系 | 孤立角色无互动锚点 | 应补全 |
| 发型发色 | 设定图发型随机 | 应补全 |

**标准**：10项必须全部填写。外貌特征和服装风格必须达到角色描写精度规范的六维拆解级别。

### 16.2 角色设定图提示词精度检查

**检查方法**：审查设定图提示词是否符合精度规范

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 气质用抽象词 | "气质高贵" | ❌ 应视觉化替代 |
| 服装笼统 | "黑色西装" | ❌ 应7要素精度 |
| 无表演基态 | 只有情绪词无肌肉描写 | ❌ 必须写基态 |
| 道具无光线交互 | "戴着手表" | ❌ 应写反射效果 |
| 缺少负声明 | 无"不要文字/水印/多余人物" | ⚠️ 可能生成多余元素 |

**标准**：设定图提示词必须通过21.4节自检清单6项。

### 16.3 场景提取完整性检查

**检查方法**：审查每个场景是否提取了7项信息

| 遗漏字段 | 后果 | 优先级 |
|----------|------|--------|
| 光影氛围 | 概念图随机给光 | 必须补全 |
| 空间结构 | 概念图无纵深 | 必须补全 |
| 材质细节 | 概念图质感随机 | 必须补全 |
| 时间 | 无法确定色温 | 应补全 |
| 镜头视角 | 概念图构图随意 | 可选 |

**标准**：7项中至少5项必须填写。光影氛围和空间结构不可省略。

### 16.4 道具一致性清单检查

**检查方法**：审查重要道具是否建立了一致性清单

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 无道具清单 | 跨镜头道具无追踪 | ❌ 必须建立 |
| 外观描述笼统 | "名贵手表" | ❌ 应4层精度 |
| 无一致性红线 | 未标注不可变特征 | ⚠️ 自检时无硬参照 |
| 无叙事功能 | 不知道道具为什么重要 | ⚠️ 可能遗漏关键道具 |

**标准**：跨镜头出现≥2次的道具必须入清单。每个道具有4层精度+3条一致性红线+叙事功能描述。

## 十七、AI视频生成技术参数专项自检

### 17.1 摄影机后缀合规检查

**检查方法**：审查每个视频提示词是否包含摄影机技术参数后缀

| 必含参数 | 缺失后果 |
|----------|---------|
| 摄影机机身（如Shot on Arri Alexa 65） | AI无法锁定色彩科学和画面风格 |
| 光圈值（如T2.8） | 无景深控制=AI随机景深 |
| film grain | AI过度干净=塑料感 |
| 分辨率（4k） | AI可能生成低分辨率质感 |
| 宽高比（--ar） | 构图与目标格式不匹配 |

**标准**：每个视频提示词末尾必须包含完整的5参数后缀。光圈值应根据场景类型调整（特写T1.4-T2.0/中景T2.8/全景T4.0-T8.0）。

### 17.1b 电影打光位置合规检查

**检查方法**：审查每个提示词是否使用了标准电影打光术语，而非模糊灯光描述

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 无光位声明 | 提示词中未提及任何光位 | ❌ "cinematic lighting"不是光位 |
| 模糊灯光描述 | "good lighting"/"cinematic lighting"/"dramatic lighting" | ❌ 必须使用八大光位术语 |
| 光位正确+视觉语言 | "front-side Rembrandt light, triangular cheek highlight, conveying determination" | ✅ |
| 光位正确但缺少情绪 | "front-side Rembrandt light"（无视觉语言/情绪声明） | ⚠️ 不完整 |
| 光位与场景矛盾 | 恐怖场景使用蝴蝶光（优雅光位） | ❌ 光位情绪与叙事矛盾 |
| 光位与导演风格矛盾 | 诺兰风格使用底光（恐怖光位） | ❌ 诺兰偏好前侧光+冷灰自然光 |

**八大光位术语对照**：

| 术语 | 关键词 | 必须声明 |
|------|--------|---------|
| 前侧光 | `front-side Rembrandt light` | 45°位置+三角光斑+坚毅/专业情绪 |
| 顶光 | `overhead top light` | 正上方+眼窝阴影+压抑/审判情绪 |
| 正侧光 | `split side light` | 90°+明暗各半+分裂/对立情绪 |
| 逆光 | `backlight / silhouette` | 正后方+轮廓光边+神秘/希望情绪 |
| 蝴蝶光 | `butterfly Paramount light` | 正上高位+鼻下对称影+优雅/仪式情绪 |
| 顺光 | `front flat light` | 同向+均匀受光+客观/真实情绪 |
| 底光 | `under light / horror light` | 下方+阴影翻转+恐怖/扭曲情绪 |
| 侧逆光 | `rim kicker light` | 135°+轮廓一侧光边+危险/神秘情绪 |

**标准**：每个提示词的[LIGHTING]段必须包含：光位名称+视觉语言描述+情绪效果。光位必须与叙事情绪和导演风格一致。

### 17.1c 光位与皮肤六层联动检查

**检查方法**：确认不同光位下的皮肤声明是否正确

| 光位 | 必须声明的皮肤层级 | 缺失判定 |
|------|-------------------|---------|
| 前侧光 | SSS(鼻翼/耳廓)+微纹理+色区差异 | 缺SSS=最易暴露 |
| 顶光 | 色区差异(上下半脸)+边缘光3D+上半脸SSS | 缺色区差异=蜡像分界 |
| 正侧光 | 边缘光3D+色区差异(亮侧全声明) | 缺边缘光=暗面无3D |
| 逆光 | 边缘光3D(轮廓光边)+耳廓SSS | 缺边缘光=唯一3D证据丢失 |
| 蝴蝶光 | 色区差异+微纹理+油汗层 | 缺色区=均匀光下最假 |
| 顺光 | 微纹理+色区差异+油汗层 | 缺微纹理=无阴影帮衬最暴露 |
| 底光 | SSS+色区差异+`still natural skin, NOT wax figure` | 缺NOT声明=恐怖+假双重打击 |
| 侧逆光 | SSS(边缘光侧)+微纹理+边缘光3D | 缺SSS=最佳展示机会浪费 |

**标准**：不同光位下的皮肤声明必须与上表联动。缺失关键层级=该光位下的皮肤失真风险极高。

### 17.1d 生产级首帧提示词6层覆盖检查

**检查方法**：审查每个含人物的分镜图提示词是否完整覆盖6层声明结构

| 缺失层 | 后果 | 判定 |
|--------|------|------|
| L1 缺失（无表情表演） | 空洞眼神+僵硬表情 | ❌ 致命——AI人物没有灵魂 |
| L2 缺失（无动作惯性） | 人物像雕塑/蜡像，无生命力 | ❌ 高——动作僵硬呆板 |
| L3 缺失（无光源氛围） | 大平光+均匀受光=AI标志性假光 | ❌ 致命——一眼AI |
| L4 缺失（无皮肤真实感） | 塑料陶瓷肌+AI建模痕迹 | ❌ 致命——皮肤是判断真假的第一标准 |
| L5 缺失（无景深镜头） | 全景深锐利=手机质感 | 🟡 高——缺乏电影分离感 |
| L6 缺失（无整体质感） | 过度干净+棚拍感 | 🟡 中——缺乏生活质感 |

**L1 表情表演层的细化检查**：

| 检查项 | 示例 | 判定 |
|--------|------|------|
| 有微表情 | "slight tension at jaw corners" | ✅ |
| 有眼神聚焦 | "eyes focused on distant window" | ✅ |
| 有眨眼声明 | "subtle natural blink" | ✅ |
| 有"小事+下意识反应+情绪落点" | "turning page, subconsciously biting lip, landing on quiet anxiety" | ✅ |
| 只有空泛表情词 | "sad expression" | ❌ 不够具体 |

**L2 动作惯性层的细化检查**：

| 检查项 | 示例 | 判定 |
|--------|------|------|
| 有动作力量感 | "leaning forward with weight" | ✅ |
| 有衣角/头发惯性 | "coat hem drifting from recent turn" | ✅ |
| 有下意识小动作 | "thumb absently rubbing index finger" | ✅ |
| 无惯性声明 | 动作描述无物理惯性 | ❌ 僵硬 |

**L3-L6 快速检查**：

| 层级 | 一句话检查标准 |
|------|--------------|
| L3 | 有光位术语+明暗变化+灰尘/颗粒=通过 |
| L4 | 有毛孔+色区差异+SSS+不对称=通过 |
| L5 | 有前景虚化+中景清晰+背景虚化=通过 |
| L6 | 有film grain+8K+生活化穿搭+实景=通过 |

**标准**：含人物的提示词6层必须全覆盖（L1-L6），不含人物的全景/空镜必须覆盖L3-L6。L1和L4是最关键的"防假"层，缺失任一即判定为不合格。

### 17.2 Negative Prompt覆盖检查

**检查方法**：审查每个提示词是否包含对应的Negative Prompt

| 场景类型 | 必含负提示类别 |
|----------|---------------|
| 所有场景 | 画质类+人体类+面部类+风格类 |
| 面瘫角色 | 额外：smile, raised eyebrows, open mouth, emotional outburst |
| 动作戏 | 额外：slow motion blur, frozen pose, static composition |
| 暧昧/恋爱 | 额外：explicit content, nudity, aggressive pose |
| 竖屏短剧 | 额外：horizontal composition, wide landscape, letterboxing |

**标准**：通用5类负提示全覆盖+场景专用负提示按需添加。面瘫角色和竖屏短剧是负提示最关键的两种场景。

### 17.3 Lip Sync合规检查

**检查方法**：审查有台词的镜头是否包含口型同步声明

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 有台词无口型声明 | 角色在说话但提示词无lip sync | ❌ AI会生成闭嘴说话或嘴形不匹配 |
| 口型与情绪矛盾 | 愤怒台词配"minimal jaw movement" | ❌ 愤怒时下颌前推+牙齿微露 |
| 缺少口型负提示 | 无"frozen mouth"等禁止项 | ⚠️ AI可能生成不动嘴的说话效果 |

**标准**：有台词的镜头必须包含：(1)自然唇部运动声明 (2)情绪专属口型描述 (3)口型负提示。

### 17.4 Motion Strength合理性检查

**检查方法**：审查Motion Strength值是否与场景类型匹配

| 错误类型 | 示例 | 判定 |
|----------|------|------|
| 静止场景Motion过高 | 面瘫角色Motion=8 | ❌ 应为3-4 |
| 动作戏Motion过低 | 打斗场景Motion=4 | ❌ 应为8-9 |
| 连续镜头Motion值跳变 | 同场景5→9→3 | ⚠️ 除非有叙事理由 |

**标准**：Motion Strength值必须与场景类型匹配。同场景连续镜头的Motion值变化不超过±2。

### 17.5 竖屏短剧格式合规检查

**检查方法**：审查竖屏短剧的提示词是否符合9:16构图逻辑

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 竖屏用水平构图逻辑 | 竖屏双人左右排列 | ❌ 应上下排列 |
| 竖屏缺少--ar 9:16 | 无宽高比声明 | ❌ AI默认横屏 |
| 竖屏环境建立无垂直纵深 | 只有水平描述 | ❌ 应有地面→角色→天空三层 |

**标准**：竖屏短剧必须声明`--ar 9:16`，构图描述使用垂直纵深逻辑，双人构图优先上下排列。

### 17.6 Cliffhanger检查（仅短剧/剧集尾场）

**检查方法**：审查每集最后一场是否有Cliffhanger策略

| 检查项 | 未通过判定 |
|--------|-----------|
| 集尾有无Cliffhanger类型选择 | ❌ 无收尾策略=观众无理由看下集 |
| 最后一个镜头是否在"揭示前0.5秒"切断 | ❌ 揭示完成后切断=悬念感消失 |
| 最后镜头运镜是否为slow dolly-in/push-in | ⚠️ 静止镜头也可但推动感更优 |
| 是否有未完成的声音设计 | ⚠️ 声音延续能增强悬念 |

**标准**：短剧每集最后一场必须有Cliffhanger四型之一。最后镜头必须在情绪/信息爆发点前0.5秒切断。

## 十八、单帧叙事密度专项自检

### 18.1 叙事密度三层完整性检查

**检查方法**：审查每个静止镜头是否三层都有叙事内容

| 层级 | 问题 | 未通过的后果 |
|------|------|-------------|
| 焦点层 | 角色身上的痕迹是否都有因果？ | 无因果的痕迹=装饰=浪费画面空间 |
| 过渡层 | 中景元素是否至少各有1项叙事功能？ | 无功能的元素=背景板=环境空洞 |
| 虚化层 | 虚化内容是否可读且不可删除？ | 可删除的虚化层=景深浪费 |

**标准**：三层每层至少有1个叙事元素。焦点层每个可见痕迹必须有因果链。

### 18.2 零装饰检查

**检查方法**：逐元素追问"它为什么在这里"

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 装饰性元素 | 地面"有落叶"但无时间/气候推断 | ❌ 应为"枯叶+碎枝=深秋+最近有风" |
| 装饰性痕迹 | 角色手"有点脏"但无行为推断 | ❌ 应为"泥污在指缝和关节=最近抓握过地面" |
| 装饰性色彩 | 背景"有暖色"但非焦点锚定 | ⚠️ 可能分散视觉焦点 |
| 功能性虚化 | 虚化处有牲畜=牧场经济 | ✅ 即使虚化也在叙事 |

**标准**：画面中0个装饰性元素。每个可见元素都能回答"它为什么在这里"。

### 18.3 角色痕迹因果链检查

**检查方法**：审查角色身上的每个痕迹是否有完整因果链

| 痕迹类型 | 必含信息 | 常见遗漏 |
|----------|---------|---------|
| 脏污 | 位置+分布+推断原因 | 只写"脏"无原因 |
| 磨损 | 位置+磨损类型+推断原因 | 只写"旧"无磨损细节 |
| 凌乱 | 具体状态+推断原因 | 只写"凌乱"无风吹/奔跑/无暇整理 |
| 伤害 | 位置+新旧程度+推断原因 | 只写"受伤"无时间线 |
| 面料物理 | 褶皱/堆叠/垂坠=重力+姿态 | 裙摆/袖口违背物理 |

**标准**：每个痕迹必须有"位置→分布→原因"三步因果链。缺失原因=装饰。

### 18.4 色彩锚点合理性检查

**检查方法**：审查画面色彩策略是否服务于视觉焦点

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 无暖色锚点 | 冷灰画面中角色也是冷色 | ❌ 视觉焦点无色彩支撑 |
| 多暖色锚点 | 3个以上暖色分散在画面各处 | ❌ 焦点分散=力度消散 |
| 锚点错位 | 暖色在背景而非角色身上 | ⚠️ 可能是故意的（如远处灯光=希望），需确认意图 |
| 锚点与角色矛盾 | 邪恶角色身上是唯一暖色 | ⚠️ 可能是有意反差，需确认意图 |

**标准**：冷灰/低饱和基调中必须有1个暖色锚点锚定视觉焦点。最多2个锚点（需有叙事理由）。

### 18.5 环境叙事五层证据覆盖检查

**检查方法**：审查非动作场景的环境是否覆盖至少3/5层证据

| 证据层 | 是否覆盖？ | 缺失后果 |
|--------|-----------|---------|
| 时间痕迹 | ☐ | 场景无历史感=布景感 |
| 人的痕迹 | ☐ | 场景无生活感=舞台感 |
| 经济痕迹 | ☐ | 角色阶层无环境支撑 |
| 气候痕迹 | ☐ | 场景无体感=无沉浸感 |
| 威胁痕迹 | ☐ | 场景无紧张感=安全=无聊 |

**标准**：非动作场景至少覆盖3/5层。动作场景使用"环境参与打斗叙事"规范（环境参与动作而非提供证据）。

## 十九、色彩叙事体系专项自检

### 19.1 色温=空间深度检查

**检查方法**：审查画面色温梯度是否符合"冷退暖进热吸引"规律

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 远景用暖色 | 背景用暖黄/暖棕 | ❌ 暖色前进=远景不退=空间扁平 |
| 角色冷色在暖环境中 | 蓝衣角色在花海 | ⚠️ 色桥断裂=角色不属此世界，需确认是否有意跳脱 |
| 无热色高光 | 画面无金/黄色高光点 | ❌ 视觉缺乏焦点=画面无力 |

**标准**：三梯度（冷远景→暖中景→热近景）必须清晰。角色所在层=暖色区。光源=热色区。

### 19.2 色桥完整性检查

**检查方法**：审查角色服装色是否桥接肤色和环境色

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 无色桥 | 角色蓝色服装在粉色花海 | ❌ 角色像贴上去的 |
| 色桥方向错误 | 肤色→环境色无中间过渡 | ❌ 跳变=视觉断裂 |
| 有意跳脱 | 冷色角色在暖环境中 | ⚠️ 需确认是叙事选择（如反派入侵）而非错误 |

**标准**：皮肤色→服装色→环境色必须是渐变过渡。跳脱必须有叙事理由。

### 19.3 同色系材质差检查

**检查方法**：审查同色系场景是否通过材质差制造层次

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 同色同质 | "粉裙+粉花"无材质声明 | ❌ 画面扁平 |
| 有材质差 | 缎面光泽+棉质漫反+花瓣哑光 | ✅ 同色不同质=有层次 |
| 缺少皮肤声明 | 同色系中未声明皮肤次表面散射 | ⚠️ 皮肤应与织物有光学差异 |

**标准**：同色系场景必须声明至少3种材质差异。皮肤必须声明subsurface scattering。

### 19.4 冷呼吸孔检查

**检查方法**：审查暖色主导画面中是否有5-10%冷色区域

| 暖色画面冷元素面积 | 判定 | 原因 |
|-------------------|------|------|
| 0% | ⚠️ 可能窒息 | 除非刻意制造不适（噩梦/密室） |
| 5-10% | ✅ 推荐 | 呼吸感=视觉舒适 |
| 15-25% | ✅ 冷暖撞色型 | 戏剧感 |
| 30%+ | ⚠️ 可能非暖色主导 | 检查是否误入冷暖双主导 |

**标准**：暖色主导画面必须有5-10%冷呼吸孔。全暖无冷=刻意不适需声明。冷浸型反转：冷色主导画面需5%暖呼吸孔（除非刻意压迫）。

### 19.5 光源色总开关检查

**检查方法**：审查光源色是否作为色彩体系的"总开关"显式声明

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 无光源色声明 | "自然光"无色温 | ❌ 光源色温决定一切色调 |
| 光源色与环境矛盾 | 暖金光源但画面整体冷 | ❌ 除非有冷环境光+暖点光源（撞色型） |
| 多光源无主次 | 两个光源无色温区分 | ⚠️ 需指定主光+辅光+各自色温 |

**标准**：光源必须声明类型+色温+方向+覆盖范围。主光=调色板总开关。

### 19.6 调色板类型匹配检查

**检查方法**：审查场景选择的调色板类型是否与叙事情绪匹配

| 叙事情绪 | 推荐调色板 | 不匹配 |
|----------|-----------|--------|
| 梦幻/治愈/恋爱 | 暖浸型 | ❌ 冷浸型 |
| 孤独/庇护/安全岛 | 冷暖撞色型 | ❌ 暖浸型 |
| 亲密/日常/温柔 | 暖调透气型 | ❌ 冷浸型 |
| 史诗/纵深/旅途 | 温度梯度型 | ❌ 单色型 |
| 恐惧/疏离/监视 | 冷浸型 | ❌ 暖浸型 |
| 产品/活力/丰富 | 三色三角型 | ❌ 单色型 |

**标准**：每个场景必须选定一种调色板类型。调色板类型必须与叙事情绪匹配。

## 二十、皮肤真实感六层专项自检

### 20.1 次表面散射（SSS）检查

**检查方法**：审查提示词中是否声明SSS行为

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 无SSS声明 | 提示词中无subsurface scattering | ❌ AI默认无SSS=塑料皮肤 |
| SSS笼统 | 只写"realistic skin" | ❌ 未声明透光行为 |
| SSS具体 | 鼻翼逆光透暖橙红+颧骨高光从内亮起 | ✅ |

**标准**：提示词必须包含SSS声明+至少2个具体透光行为（如鼻翼透光+颧骨内发光）。

### 20.2 微纹理地图检查

**检查方法**：审查皮肤微纹理是否分区声明

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 无微纹理 | 皮肤描述为"smooth"或"perfect" | ❌ 完美=塑料 |
| 全脸统一 | "textured skin"无分区 | ❌ 真皮肤各区域纹理不同 |
| 分区微纹理 | T区毛孔+面颊绒毛+眼周微血管 | ✅ |

**标准**：至少声明3个面部区域的微纹理差异。面部必须有"活着的证据"（毛孔/雀斑/绒毛/微血管至少1种）。

### 20.3 油汗层检查

**检查方法**：审查油汗层声明是否分寸得当

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 无油汗层 | 皮肤完全哑光 | ❌ 哑光=死物 |
| 油汗过强 | "greasy skin, sweaty face" | ❌ 太强=出油不是油汗膜 |
| 分寸得当 | "natural subtle sheen on nose tip" | ✅ |

**标准**：鼻头+额头必须有极微妙光泽。颧骨侧面应为干区（无油光）。全脸同光泽度=假。

### 20.4 色区差异检查

**检查方法**：审查面部肤色是否有分区差异

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 全脸同色 | 提示词只写一种肤色 | ❌ 蜡像感第一原因 |
| 有色区差异 | 额头偏黄+眼周偏红+面颊偏粉 | ✅ |

**标准**：面部至少声明3个色区差异。额头≠面颊≠下颌线。

### 20.5 边缘光3D检查

**检查方法**：审查面部3D转折处是否有边缘光

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 无边缘光 | 面部描述无转折光边 | ❌ 面部扁平=贴图 |
| 有边缘光 | 鼻梁两侧+颧骨下方+下颌线有细光边 | ✅ |

**标准**：鼻梁+颧骨+下颌线至少2处有边缘光声明。

### 20.6 视频微动态检查（仅视频场景）

**检查方法**：审查视频提示词中是否有皮肤微动态声明

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 无微动态 | 皮肤完全静止 | ❌ 蜡像皮肤 |
| 有微动态 | 油汗微光变+绒毛微动+鼻翼呼吸 | ✅ |
| Motion=0 | 皮肤区域零运动 | ❌ 应为3-4 |

**标准**：视频提示词必须包含至少2种皮肤微动态。Motion Strength至少3。


## 二十一、导演风格圣经专项自检

### 21.1 导演风格声明检查

**检查方法**：审查分镜文档是否在第零步（视觉锚点）声明了导演风格

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 无风格声明 | 分镜文档未提及任何导演风格 | ❌ 缺少视觉操作系统 |
| 风格声明模糊 | "电影感风格" | ❌ 必须指定具体导演 |
| 风格声明正确 | "主风格：维伦纽瓦，辅助：伯格曼（仅面部特写序列）" | ✅ |
| 辅助风格过多 | 主+3位辅助风格 | ❌ 最多1位辅助 |

**标准**：1位主风格+最多1位辅助风格，且辅助必须声明具体负责维度。

### 21.2 导演风格一致性检查

**检查方法**：逐镜审查提示词是否符合声明的导演风格DNA

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 光影策略冲突 | 声明诺兰但使用柔散逆光（Deakins式） | ❌ 光影策略属于主风格 |
| 运镜冲突 | 声明小津但使用手持跟拍 | ❌ 小津=完全静止 |
| 构图冲突 | 声明维伦纽瓦但构图拥挤无留白 | ❌ 极端留白是维伦纽瓦签名 |
| 情绪节奏冲突 | 声明奉俊昊但全场无tonal shift | ❌ 缺少突然暴力/幽默突变 |

**标准**：每个镜头的5参数（VISUAL DNA/CAMERA/COMPOSITION/LIGHTING/EMOTION）必须与声明的导演风格一致。辅助风格只负责其声明的具体维度。

### 21.3 导演风格与锚点表冲突检查

**检查方法**：确认风格选择是否篡改了角色的物理特征锚点

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 风格改变角色外观 | 诺兰冷灰调→角色头发颜色改变 | ❌ 风格只改变呈现方式，不改变锚点 |
| 风格改变服饰锚点 | 维伦纽瓦极简→删除角色标志性道具 | ❌ 道具属于锚定层，不可删除 |
| 风格只改变光影 | 伯格曼高反差→面部光影对比变化 | ✅ 合理 |
| 风格只改变构图 | 小津低机位→改变拍摄角度 | ✅ 合理 |

**标准**：风格可改变光影/构图/运镜/色调，不可改变角色体型/面部/服饰/道具的物理描述。

### 21.4 导演风格调色板匹配检查

**检查方法**：确认色彩选择是否与导演风格一致

| 导演 | 预期调色板 | 检查项 |
|------|-----------|--------|
| 诺兰 | 冷灰蓝+零星暖橙 | 冷浸型，低饱和，无暖色主导 |
| 维伦纽瓦 | 单色冷+光束暖 | 温度梯度型，单暖光源 |
| 王家卫 | 霓虹暖+深夜蓝 | 暖浸型，混合色温 |
| 张艺谋 | 饱和补色对 | 三色三角型，高饱和 |
| 是枝裕和 | 自然暖+窗光 | 暖调透气型，低对比 |
| 科恩兄弟 | 冷灰+荧光黄 | 冷浸型，冷色主导+黄色点睛 |

**标准**：色彩选择必须与导演风格的调色板匹配。冲突时以导演风格为准。

### 21.5 混搭冲突检查

**检查方法**：审查主+辅助风格组合是否存在不可调和的冲突

| 冲突类型 | 示例 | 判定 |
|----------|------|------|
| CAMERA冲突 | IMAX稳定器+手持跟拍 | ❌ 不可共存 |
| LIGHTING冲突 | Deakins柔散逆光+塔伦蒂诺高对比明暗 | ❌ 不可共存 |
| COMPOSITION冲突 | 维伦纽瓦极端留白+费里尼群像环绕 | ❌ 不可共存 |
| EMOTION同属不同层级 | 诺兰理性失控+伯格曼存在恐惧 | ✅ 可共存（主风格控制节奏） |

**标准**：CAMERA和LIGHTING不可冲突；COMPOSITION冲突时按场景类型选择；EMOTION由主风格控制。

## 二十二、色彩情绪圣经专项自检

### 22.1 色调数量限制检查

**检查方法**：统计单帧/单场景中出现的色调种类

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 色调过多 | 同一画面橙+红+蓝+紫+绿 | ❌ 超过5种=调色板崩溃 |
| 主色>2 | 橙+红+蓝三种主色 | ❌ 主色≤2 |
| 无点睛色 | 全画面均匀蓝灰 | ❌ 缺少视觉焦点锚定 |
| 结构正确 | 2主色+1辅助色+1点睛色 | ✅ |

**标准**：主色≤2 + 辅助色≤2 + 点睛色=1，总计≤5种色调。

### 22.2 色彩-情绪语义匹配检查

**检查方法**：确认使用的色彩是否与叙事情绪一致

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 色彩情绪矛盾 | 死亡场景使用温暖橙色主调 | ❌ 橙色=温暖/激情，与死亡矛盾 |
| 色彩情绪匹配 | 孤独场景使用冷蓝主调 | ✅ 蓝色=孤独/压抑 |
| 色彩反讽有意识 | 死亡场景用粉色（荒诞讽刺） | ✅ 但必须在分镜文档中声明反讽意图 |
| 色彩无声明反讽 | 暴力场景用粉色但未声明 | ❌ 无意图=错误 |

**标准**：色彩情绪必须与叙事情绪一致，除非刻意反讽且在文档中声明。

### 22.3 皮肤色彩失真检查

**检查方法**：审查每种色彩情绪下皮肤是否有正确的声明

| 色彩 | 必须声明 | 禁止出现 |
|------|---------|---------|
| 橙色 | `warm SSS, amber glow through thin skin` | `orange face paint` |
| 粉色 | `SSS with faint pink-warm beneath, chromatic zonation preserved` | `silicone doll skin, flat pink wash` |
| 红色 | `warm SSS with visible blood beneath (NOT red face paint)` | `red face paint, red skin` |
| 蓝色 | `cool SSS with FAINT warm blood beneath, NOT dead blue skin` | `dead blue skin, blue face` |
| 绿色 | `natural skin with green AMBIENT REFLECTION, NOT green-tinted skin` | `green-tinted skin, alien skin` |
| 紫色 | `purple ambient reflection on surface, NOT purple skin pigmentation` | `purple skin, oxygen-deprived` |
| 黄色 | `warm SSS golden, chromatic zonation (forehead amber, cheeks warm-pink)` | `jaundiced skin, sallow tone` |

**标准**：每种色彩情绪下的皮肤声明必须包含SSS保护+色区差异保护+NOT声明。

### 22.4 冷呼吸孔检查

**检查方法**：暖色调画面中是否有冷色区域

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 暖色无冷孔 | 全画面橙红黄，无任何冷色 | ❌ 视觉灼烧 |
| 暖色有冷孔 | 橙红画面角落5%蓝灰阴影 | ✅ |
| 冷色无暖锚 | 全画面冷蓝，无任何暖色 | ❌ 情感冰封 |
| 冷色有暖锚 | 蓝色画面中一个极小暖黄灯光 | ✅ |

**标准**：暖色画面5-10%冷呼吸孔；冷浸型画面至少1个暖色锚定点。

### 22.5 色彩与导演风格一致性检查

**检查方法**：确认色彩选择是否与导演风格自带的色彩偏好一致

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 色彩与风格矛盾 | 诺兰风格+高饱和红绿对比 | ❌ 诺兰=低饱和冷灰 |
| 色彩与风格一致 | 诺兰风格+冷灰蓝+零星暖橙 | ✅ |
| 色彩扩展合理 | 是枝裕和+自然暖+辅助冷绿（自然生机） | ✅ 合理扩展 |
| 色彩扩展矛盾 | 是枝裕和+霓虹紫（都市迷幻） | ❌ 与导演风格冲突 |

**标准**：色彩选择优先遵循导演风格的调色板，扩展时不可与风格DNA矛盾。

## 二十三、万能分镜模板专项自检

### 23.1 景别逻辑检查

**检查方法**：审查分镜是否遵循了对应模板的景别递进逻辑

| 模板 | 正确景别递进 | 错误示例 |
|------|-------------|---------|
| 吵架 | 中→近→特→中→全 | 全→特→近→特→全（缺少情绪升级过程） |
| 打斗 | 全→中→近→特→全 | 特→特→特→特→特（缺少空间交代） |
| 走路 | 远→中→近→特→远 | 近→近→近→近→近（缺少环境氛围） |

**标准**：5拍基础版必须遵循模板景别递进。变奏版必须在文档中声明变奏意图。

### 23.2 情绪弧线完整性检查

**检查方法**：审查分镜是否完整覆盖了模板的情绪弧线

| 模板 | 情绪弧线 | 缺失判定 |
|------|---------|---------|
| 吵架 | 克制→升级→爆发→崩溃→冷战 | 缺少爆发=核心缺失 |
| 打斗 | 对峙→交锋→受挫→反杀→结果 | 缺少受挫=权力无翻转 |
| 走路 | 氛围→行进→聚焦→极点→余韵 | 缺少极点=情绪无高点 |

**标准**：5拍情绪弧线中，核心拍（吵架=爆发，打斗=受挫+反杀，走路=极点）不可省略。

### 23.3 模板与已有规范强制叠加检查

**检查方法**：审查模板执行时是否叠加了对应的已有规范

| 模板 | 必须叠加 | 检查项 |
|------|---------|--------|
| 吵架 | 正反打多镜拆分 | 拍2-3是否拆分为独立正反镜头 |
| 吵架 | 三步表演法 | 每镜头是否含主表演+小动作+微反应 |
| 吵架 | 视觉聚焦逻辑 | 爆发特写是否声明眼部4层微动画 |
| 打斗 | 打斗叙事弧线 | 完整版是否有权力三次翻转 |
| 打斗 | 运镜美学框架 | 是否选择并贯穿一种美学 |
| 打斗 | 手持摄影三层 | 各阶段手持层级是否正确 |
| 打斗 | 即兴武器 | 全景是否有环境武器伏笔 |
| 走路 | 单帧叙事密度 | 远景是否覆盖3/5层环境证据 |
| 走路 | 色彩叙事 | 远景色温梯度+服装色桥是否声明 |
| 走路 | 静态抒情 | 远景和特写是否适用静态抒情规范 |

**标准**：每个模板必须叠加其对应的已有规范，缺一不可。

### 23.4 最短版vs完整版选择合理性检查

**检查方法**：审查模板版本选择是否与段落重要性匹配

| 场景 | 合理选择 | 不合理选择 |
|------|---------|-----------|
| 关键争吵（分手/对峙） | 完整版7-9镜 | 最短版3镜（不够充分） |
| 过场争吵 | 最短版3镜 | 完整版9镜（过度展开） |
| 高潮打斗 | 完整版9-12镜 | 最短版5镜（缺少翻转） |
| 过场打斗 | 最短版5镜 | 完整版12镜（拖沓） |
| 情绪走路 | 完整版7-9镜 | 最短版3镜（缺少细节） |
| 过场走路 | 最短版3镜 | 完整版9镜（冗余） |

**标准**：模板版本选择与段落重要性成正比。高潮段落=完整版，过场段落=最短版。

### 23.5 变奏声明检查

**检查方法**：审查变奏版分镜是否在文档中声明了变奏意图和理由

| 问题类型 | 示例 | 判定 |
|----------|------|------|
| 变奏无声明 | 打斗从特写开始但未说明原因 | ❌ |
| 变奏有声明 | "倒叙变奏：从反杀开始，逐步揭示如何到达此处" | ✅ |
| 混合变奏无声明 | 吵架→走路转场但未标注模板切换 | ❌ |
| 混合变奏有声明 | "吵架转入走路，情绪从对抗转为孤独" | ✅ |

**标准**：任何偏离基础模板的变奏必须在分镜文档中声明变奏类型+变奏意图。


## 二十四、角色设定板生成专项自检

## 二十五、镜头时长估算与景别推断专项自检

### 25.1 时长估算合理性

| 检查项 | 标准 | 常见错误 |
|--------|------|---------|
| 有对白的镜头时长是否≥对白阅读时间 | 中文3字/秒，英文2.5词/秒，下限2秒 | 3秒镜头塞了15字台词 |
| 特写/极特写是否有情绪着陆时间 | +2秒 | 特写1秒就切走 |
| 面瘫美学镜头是否有额外停留 | +3秒 | 面瘫特写按普通特写处理 |
| 全景/远景是否给了定位时间 | ≥4秒 | 远景2秒就切走，观众还没看清空间 |
| 长镜头时长是否≥8秒 | 是 | 声明长镜头但只给4秒 |

### 25.2 景别推断逻辑合规

| 检查项 | 标准 | 常见错误 |
|--------|------|---------|
| 角色首次出现是否WS→MS递进 | 先定场再进入 | 首次出现直接CU |
| 对白密集段落是否MS↔MCU正反打 | 是 | 对话场景用WS从头到尾 |
| 动作+对白冲突时对白是否优先 | 声音主导景别 | 动作段落中台词被WS淹没 |
| "他看着"类描写是否推断CU | 是 | "盯着"用了MS，看不到眼睛 |
| 群戏是否先WS→MCU关键角色 | 两镜拆分 | 群戏从头到尾一个景别 |

### 25.3 表格式分镜完整性

| 检查项 | 标准 |
|--------|------|
| 11个标准字段是否齐全 | 场次/镜号/集号/场景/时段/景别/运镜/画面/对白/时长/提示词摘要 |

## 二十九、电影级对白分镜专项自检

### 29.1 对白五层核心结构完整性

- [ ] 视线关系是否有设计（谁直视/谁闪躲/谁先移开/谁偷看）——机械正反打=不合格
- [ ] 停顿镜头是否完整（稳镜+微推+留环境音+让观众等待）——切掉停顿=丢失核心情绪
- [ ] 空间距离是否三阶段递进（远→近→远=理性→压迫→崩塌）——距离不变=情绪没有弧线
- [ ] 潜台词镜头是否存在（拍谎言泄漏点：手/呼吸/视线/光线）——只拍说话的脸=初级
- [ ] 情绪主导权是否有变化（强势→弱势→反转→崩塌镜头同步）——权力不变=对白没有戏剧性

### 29.2 呼吸镜头合规性

- [ ] 呼吸镜头是否有情绪驱动逻辑（靠近=推进/退缩=停住/失控=失稳/崩裂=同步）——无逻辑晃动=技术驱动≠情绪驱动
- [ ] 推镜是否极轻不被明显察觉——可感知的推镜=观众出戏
- [ ] 对白呼吸镜头是否区分于恋爱呼吸镜头（对白=权力感知/恋爱=情感靠近）——混淆=定位错误

### 29.3 不对称正反打合规性

- [ ] 正反打是否构图不对称——对称构图=情绪对称=不符合对白权力逻辑
- [ ] 强势方是否近+满+稳+低机位——弱势方构图与强势方完全相同=权力未表达
- [ ] 是否考虑焦距不对称（不同焦距拍双方=不同情绪空间）——同焦距=情绪同构

### 29.4 第三视角检查

- [ ] 是否在适当位置使用第三视角（角落/门外/走廊/镜子/家具后）——全部主观视角=缺少命运感/旁观感
- [ ] 第三视角是否产生宿命感/旁观感——只是换个角度=未达到第三视角的叙事功能

### 29.5 对白节奏五阶段完整性

- [ ] 是否覆盖五阶段（平静→试探→压迫→爆发→坍塌）——跳过阶段=情绪弧线断裂
- [ ] 各阶段景别/运镜/空间/声音是否匹配规范——平静阶段用手持快切=阶段错位
- [ ] 坍塌阶段是否有留白/空镜/人物被空间吞没——爆发后直接结束=缺少余震

### 29.6 导演对白风格合规

- [ ] 使用导演风格时是否匹配对白风格（王家卫=无法表达/诺兰=信息压迫/黑泽明=空间权力/教父=沉默累积）——风格选择与场景性质冲突=错误
- [ ] 导演风格是否与导演风格圣经的通用参数一致——对白风格与整体风格矛盾=不一致

### 29.7 对白光影心理学合规

- [ ] 对白场景光位是否有心理暗示（顶光=审判/侧光=分裂/背光=隐藏/下光=威胁）——随意用光=失去光影叙事
- [ ] 光比是否随情绪递进变化（阴影侵蚀=真相吞噬关系）——光比不变=情绪未升级

### 29.8 焦距-情绪映射合规

- [ ] 对白焦距是否符合情绪规律（疏离→广角/靠近→中焦/失控→长焦）——冷静对话用135mm=不符合
- [ ] 焦距变化是否有叙事动机——焦距变化无原因=技术展示

### 29.9 短剧对白电影感检查

- [ ] 是否有解释性台词可以被身体语言替代——台词说"我很痛苦"而身体无表现=浪费镜头语言
- [ ] 对白场景是否有环境呼吸声——纯人声无环境=空间不真实
- [ ] 是否只拍脸部特写——缺少"空间中的人物"=缺少电影感

### 29.10 暧昧/恋爱环境声音设计增强检查

- [ ] 暧昧/恋爱场景是否有环境声音设计——纯台词无环境声=缺少私人空间感
- [ ] 声音类型是否匹配情绪阶段（呼吸声=私人入侵/衣料摩擦=靠近证据/电流钟表=时间压迫）——声音与情绪错位=叙事脱节

## 三十、AI视频模型微表情实战对比专项自检
