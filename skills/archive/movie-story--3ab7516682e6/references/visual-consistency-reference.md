# 视觉一致性参考图系统 — @ 锁定协议

跨镜头生成时，人物长相、道具细节、场景空间必须保持一致。本协议定义"一致性参考图"的生成规则和 `@标注` 语法。

> 核心原则：**先锁定参考图，再生成叙事画面**。所有涉及同一人物/道具/场景的 AI 提示词，必须通过 `@参考图` 锚定视觉基准。

---

## 一、三类参考图体系

```
┌─────────────────────────────────────────────────────┐
│                视觉一致性参考图体系                       │
├───────────┬───────────┬───────────┬─────────────────┤
│  人物参考图 │  道具参考图 │  场景参考图 │  色彩/光照参考图   │
│ @角色名    │ @道具名    │ @场景名    │ @调色板          │
│ 多角度     │ 多角度     │ 空间结构   │ 色彩体系          │
│ 全身/半身  │ 细节特写   │ 光照方案   │ 调性参考          │
│ 表情参考   │ 材质纹理   │ 氛围参考   │ 胶卷模拟          │
└───────────┴───────────┴───────────┴─────────────────┘
```

## 二、@ 标注语法规范

### 基本格式

```
@[类别]:[名称]_[角度/用途]
```

### 定义列表语法（在文档开头统一声明）

```markdown
## 视觉一致性参考图清单

### 人物参考图 @角色
- @角色:Olivia_正面 — 正面中景，中性表情，标准三点布光
- @角色:Olivia_侧面 — 右侧45°侧面，自然光
- @角色:Olivia_表情 — 4格表情集（平静/愤怒/悲伤/微笑）
- @角色:Louis_正面 — 正面近景，硬朗光线，下颌阴影
- @角色:Louis_全身 — 全身站立，展示服装和体态

### 道具参考图 @道具
- @道具:面具_正面 — 白色陶瓷面具，正面正视
- @道具:面具_手持 — 手持面具的姿势参考
- @道具:项链_特写 — 蓝宝石项链微距，金属光泽

### 场景参考图 @场景
- @场景:Castellan客厅_广角 — 广角室内全景，下午光线
- @场景:Castellan客厅_壁炉侧 — 壁炉方向视角，火光氛围
- @场景:控制室_主视角 — 监控墙正面，蓝冷色调

### 色彩/光照参考图 @调色板
- @调色板:EP1_冷蓝 — Episode 1 整体色调参考（青蓝+暖橙补色）
- @调色板:回忆_暖金 — 闪回段落暖金色调参考
```

### 提示词中的引用语法

在 AI 绘图提示词中，用 `@引用` 标注需要锁定一致性的元素：

```
@角色:Olivia_正面 @道具:面具_手持 @场景:Castellan客厅_壁炉侧
```

**规则**：
- 引用必须使用与定义列表**完全一致**的名称
- 一个提示词可引用多个参考图
- 未出现在定义列表中的元素**不可**使用 @ 标注
- 如果某个元素尚未生成参考图，标记为 `@待锁定`，提示先完成参考图生成

## 三、参考图生成协议

### Phase 0：一致性参考图预生成（在正式分镜提示词之前）

```
For each 持久元素（出现在 ≥2 个镜头中）:
  1. 确定需要的角度/状态清单
  2. 为每个角度生成独立的参考图
  3. 验证参考图质量（清晰度、特征准确性）
  4. 将参考图路径填入定义清单
  5. 后续所有提示词必须引用这些参考图
```

### 人物参考图 — 生成规范

| 角度 | 用途 | 提示词关键要素 |
|------|------|---------------|
| **正面中景** | 主要面部锁定 | 中性光照 + 三庭五眼参考 + 皮肤纹理 + 发型完整 |
| **左侧45°** | 过肩镜头面部 | 同角色圣经描述 + 45°光照保持特征一致 |
| **右侧45°** | 反打过肩 | 对称于左侧，确保面部结构不漂移 |
| **全身站姿** | 体态和服装 | 展示完整服装剪裁 + 身高比例 + 站姿习惯 |
| **表情集** | 情绪一致性 | 4宫格：平静/愤怒/悲伤/微笑，确保同一张脸 |

### 道具参考图 — 生成规范

| 角度 | 用途 | 提示词关键要素 |
|------|------|---------------|
| **正面正视** | 主要外观锁定 | 纯色背景 + 完整形态 + 材质清晰 |
| **45°透视** | 多角度展示 | 展示厚度和立体结构 |
| **手持/使用态** | 比例和交互 | 角色手持道具，展示人-物比例关系 |
| **细节特写** | 纹理/材质 | 微距，突出材质纹理、磨损、反光特性 |

### 场景参考图 — 生成规范

| 角度 | 用途 | 提示词关键要素 |
|------|------|---------------|
| **广角全景** | 空间结构锁定 | 展示完整空间布局 + 主要光源位置 |
| **主视角** | 叙事方向基准 | 角色主要活动方向，180°线确立 |
| **反打视角** | 对话反打 | 180°线对侧，保证空间连续 |
| **氛围参考** | 光影/色调 | 重点展示光照氛围，可略去细节 |

## 四、提示词中的 @ 标注示例

### 示例 1：英雄镜头（人物 + 道具 + 场景 全部锁定）

```
**SHOT 001 — Hero Shot**
@角色:Olivia_正面 @道具:面具_手持 @场景:Castellan客厅_壁炉侧 @调色板:EP1_冷蓝

AI 绘图提示词：
"Cinematic wide shot, @角色:Olivia_正面 stands before a crackling fireplace
in @场景:Castellan客厅_壁炉侧, holding @道具:面具_手持 at chest level,
her face illuminated by warm firelight from left, cold blue moonlight
streaming through french windows from right creating dramatic split lighting.
35mm anamorphic lens, f/2.8, @调色板:EP1_冷蓝 color grade,
Roger Deakins chiaroscuro style, Kodak Vision3 500T film emulation,
skin texture visible with subtle subsurface scattering, 8K cinematic."
```

### 示例 2：对话特写（仅锁定人物）

```
**SHOT 008 — Olivia Reaction CU**
@角色:Olivia_正面 @调色板:EP1_冷蓝

AI 绘图提示词：
"Extreme close-up, @角色:Olivia_正面 face filling frame, eyes widening
with restrained shock, a single tear forming at lower lash line,
```

### 示例 3：未锁定元素标记

```

moody low-key lighting. NOTE: This is first appearance of dagger,
generate reference image first before proceeding."
```

## 五、一致性校验清单

### 提示词输出前必须检查

```
□ 人物核对
  □ 所有人物镜头是否标注了 @角色:XXX_角度？
  □ 同一角色在不同镜头中引用的参考图是否来自同一张脸？
  □ 角色圣经中的外貌描述是否与参考图一致？

□ 道具核对
  □ 跨镜头出现的道具是否标注了 @道具:XXX_角度？
  □ 道具的材质/颜色/尺寸在不同镜头中是否一致？
  □ 首次出现的道具是否标记 @待锁定？

□ 场景核对
  □ 同一场景的不同角度是否标注了对应的 @场景:XXX_角度？
  □ 场景中的空间关系是否遵守 180° 规则？
  □ 主要光源位置（Key Light）在不同镜头中是否保持一致方向？

□ 整体核对
  □ 所有 @引用 是否都在定义清单中存在？
  □ 同一场景的所有镜头是否引用了同一个 @调色板？
  □ 是否有新的跨镜头元素尚未生成参考图？
```

## 七、关键规则速记

| # | 规则 |
|---|------|
| 1 | **先生成参考图，再生成叙事画面** — 不跳过 Phase 0 |
| 2 | **一个持久元素 = 至少一张参考图** — 出现 2+ 次的都是持久元素 |
| 3 | **@标注必须与定义清单完全匹配** — 名称不一致 = 一致性断裂 |
| 4 | **同一角色必须引用同一张脸的参考图** — 杜绝"换脸"问题 |
| 5 | **首次出现的元素标记 @待锁定** — 提醒先生成参考图 |
| 6 | **每个场景引用同一个 @调色板** — 确保全片色调统一 |
| 7 | **交付前完成一致性校验清单** — 逐项检查，逐项勾选 |
