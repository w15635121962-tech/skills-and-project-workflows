## 元提示词框架（核心）

> 这是本文的核心价值：一套完整的**五步思维链提示词工程框架**，让 AI 从图片识别 → 镜头分析 → 动作设计 → 节奏编排 → 参数输出。

### 第一步：图片内容识别与分析

```
识别以下关键元素：
- 主体对象：主要人物、物体或场景
- 环境背景：场景类型（室内/室外）、时间（白天/夜晚）、氛围
- 构图特征：当前的构图方式
- 色彩情绪：主色调和整体情绪基调
- 动态潜力：哪些元素最适合添加动态效果
- 叙事暗示：图片中暗示的故事或情感
```

### 第二步：智能镜头语言分析

#### 构图类型识别 → 运动建议

| 构图类型 | 特征 | 适合运动 |
|----------|------|----------|
| 三分法构图 | 主体在画面1/3处 | 横向或纵向运动 |
| 对称构图 | 中心对称 | 缩放或旋转 |
| 对角线构图 | 斜线引导 | 沿对角线轨迹运动 |
| 框架构图 | 前景框架包裹 | 景深变化或穿越运动 |
| 引导线构图 | 线条引导视线 | 沿线条跟随运动 |
| 黄金螺旋 | 螺旋构图 | 环绕运动 |
| 三角形构图 | 稳定结构 | 局部动态保持整体稳定 |

#### 镜头角度 → 运动映射

| 角度 | 适合运动 | 情绪效果 |
|------|----------|----------|
| 鸟瞰 Bird's Eye | 全局展示、旋转 | 上帝视角 |
| 高角度 | 下压运动 | 压抑感、渺小感 |
| 平视 | 水平运动 | 自然观察 |
| 低角度 | 上扬运动 | 威严感 |
| 荷兰角度 | 倾斜不稳定运动 | 不安定感 |
| 虫视角度 | 仰视运动 | 极低视角冲击 |

#### 镜头运动类型（含强度参数 1-10）

| 运动类型 | 变体 | 强度参考 | 适用场景 |
|----------|------|----------|----------|
| **推进** | 缓慢推进/快速推进/变速 | 3-7 | 亲密感、聚焦、冲击 |
| **拉远** | 缓慢拉远/快速拉远 | 3-7 | 展示环境、孤独感 |
| **横移** | 左右平移/弧形横移 | 3-5 | 展示空间、跟随主体 |
| **升降** | 上升/下降 | 3-6 | 希望/压抑 |
| **摇镜** | 水平摇镜/垂直摇镜 | 2-5 | 展示全景、高度关系 |
| **变焦** | 推焦/拉焦/反向 | 4-8 | 接近/远离/眩晕 |
| **旋转** | 顺/逆时针/倾斜旋转 | 5-8 | 动感、迷幻 |

### 第三步：动作设计决策树

```
人物场景 → 动作设计
├── 肖像/特写 → 微表情、眨眼、呼吸、发丝飘动
├── 半身像   → 手势、转头、肩部起伏
└── 全身像   → 步态、姿态转换、衣物飘动

风景场景 → 动作设计
├── 自然风景 → 云朵飘移、水面涟漪、树叶摆动
├── 城市景观 → 车流、灯光闪烁、人群移动
└── 建筑物   → 光影变化、透视移动、细节展现

物品静物 → 动作设计
├── 产品展示 → 360度旋转、细节特写、光效扫过
├── 食物     → 热气升腾、酱汁流淌、切面展示
└── 艺术品   → 多角度展示、光影游走、质感呈现
```

### 第四步：6秒版本节奏设计（起承转合）

```
起（0-1.5秒）：建立场景，引入动态
承（1.5-4秒）：动作发展，节奏展开  ← 最长段
转（4-5.5秒）：达到高潮，视觉冲击
合（5.5-6秒）：快速收尾，循环衔接  ← 最短段
```

**关键帧时间点**：1.5秒 / 4秒 / 5.5秒

**节奏控制类型**：
- **渐进式**：强度逐步递增（如延时摄影）
- **起伏式**：强度波动（如动作-静止-再动）
- **爆发式**：前平后爆（如突然的镜头冲击）

### 第五步：技术参数细化

| 参数 | 范围 | 说明 |
|------|------|------|
| 运动强度 | 1-10 | 1=极微动，10=剧烈运动 |
| 运动曲线 | 线性/缓入/缓出/缓入缓出 | 动作加速度曲线 |
| 景深变化 | 前景/中景/背景虚实 | 焦点转移 |
| 时间扭曲 | 常速/慢动作/快动作/冻结 | 时间节奏变化 |

## 完整案例：雨中撑伞女孩

### 场景描述
侧面剪影，城市霓虹背景，雨中独行

### 中文版

```
整体构思：雨夜独行，从环境到情感的快速叙事

分镜脚本：
[0-1.5秒] 起：中景 - 雨夜街道霓虹闪烁 - 女孩剪影出现
[1.5-4秒] 承：推进跟拍 - 侧面接近，雨滴飘落 - 伞下细节渐显
[4-5.5秒] 转：微旋至正面 - 女孩停步凝视 - 雨珠定格瞬间
[5.5-6秒] 合：快速拉远 - 转身继续 - 融入雨幕

详细参数：
第一阶段：运动强度2/10，场景氛围渲染
第二阶段：运动强度5/10，动态跟随推进
第三阶段：运动强度4/10，情绪凝聚时刻
第四阶段：运动强度6/10，快速收尾
节奏控制：渐进式加速
关键帧设置：1.5秒（开始推进）、4秒（旋转停步）、5.5秒（拉远）
```

## 作者核心观点

> "有时候'尽信提示词不如无提示词'——提示词只要描述清楚了想要的动作一样可以得到很不错的效果。出发点是让 AI 从图片可能的整体发展趋势去写提示词，没有硬控分镜。"

**六个高级提示**：
1. **智能场景识别**：根据图片自动判断最适合的镜头语言
2. **情绪匹配**：动作设计与画面情绪保持一致
3. **技术可行性**：确保 AI 视频生成工具能够实现
4. **创意平衡**：在技术限制内最大化视觉表现力
5. **文化适配**：中英文版本考虑不同文化的视觉语言习惯
6. **循环衔接**：结尾动作能自然衔接到开头，支持无缝循环
