## 核心挑战 — 推文 vs 剧本

推文分镜与传统剧本分镜的根本差异：

| 维度 | 剧本 | 推文 |
|------|------|------|
| 格式 | slugline + 对话 + 舞台指示 | 散文叙述，无格式标记 |
| 视角 | 第三人称客观 | 多为第一人称主观 |
| 声音轨道 | 对话驱动 | **旁白驱动**（VO即推文原文） |
| 时间标记 | 有明确转场 | 隐含，需推断 |
| 情绪表达 | 通过对话+动作 | **大量隐喻/感官描写** |
| 视觉信息 | 舞台指示直接描述 | 需从叙述中提取+补全 |
| 节奏控制 | parenthetical + beat | 落点句 + 段尾钩子 |

因此，推文分镜的核心工作是 **文字→画面的转译**，而非简单的格式映射。

---

## 工作流

按五步顺序执行，每步输出后再进入下一步。

```
STEP 1 → DISSECT   拆解推文，提取叙事节拍与情感曲线
STEP 2 → EXTRACT   从散文中提取角色/场景/物品视觉锚点
STEP 3 → TRANSLATE  文字→画面转译，每个节拍分配视觉策略
STEP 4 → BOARD     输出分镜表
STEP 5 → CHECK     自检，修复，通过声明
```

**硬规则：**
- 不跳过、不合并、不省略任何推文内容
- 每个镜头必须有对应的推文原文依据
- Step 5 未通过前不输出最终结果
- 每个镜头回答：**"这个画面比前一个多了什么新信息？"**

---

## STEP 1 — DISSECT（拆解推文）

### 1.1 段落标记

将推文按自然段（或viral-thread-story的分段）标记，识别每个段落的功能：

```
推文拆解
标题: ___  |  类型: ___  |  总段数: ___

 # | 段落首句摘要          | 情感   | 功能        | 落点句
---|----------------------|--------|------------|--------
 1 | ___                  | ___    | 钩子/铺垫/升级/破防/反转/收束 | ___
 2 | ___                  | ___    | ___        | ___
```

### 1.2 情感曲线标注

为每段标注情感强度（1-10）和情感方向：

```
情感曲线
段01: 强度 ___ | 方向 ↑↓→ | 标签: ___
段02: 强度 ___ | 方向 ↑↓→ | 标签: ___
...
峰值段落: 段___ | 低谷段落: 段___
曲线形态: W形 / 单峰 / 阶梯 / ___
```

### 1.3 旁白节奏计算

推文视频以旁白(VO)为时间轴主轴：

**中文旁白语速：**
- 日常旁白：3.5字/秒
- 情感浓烈：2.8字/秒
- 金句强调：2.0字/秒

**单段时长公式：**
```
段字数 ÷ 语速 + 情感停顿(0.5-2.0s) + 画面呼吸(0.3-1.0s)
```

**全文预估时长：** ___ 秒（目标区间 30-120s）

### 1.4 完整性合约

```
完整性合约
段落数: ___ | 金句数: ___ | 隐喻/感官描写: ___ | 角色名: ___ | 物品: ___ | 场景: ___
```

## STEP 2 — EXTRACT（提取视觉锚点）

推文是散文，没有舞台指示，需要从文字中**提取并补全**视觉信息。

### 2.1 角色锚点

从推文叙述中提取每个角色的视觉信息。推文通常不会完整描述角色外观，需要根据上下文推断+补全：

```
角色锚点: [名字] — [角色功能]
  原文线索: "___"（引用推文中关于此角色的描述）
  外观推断: 年龄约___ · 体型___ · 发型___
  面部锚点: 眼睛___ · 嘴角___ · 默认表情___
  服装推断: ___（根据场景+类型推断）
  情绪标记: 紧张时___ · 崩溃时___ · 反转时___
  屏幕默认位: [上/中/下三分之一] · [左/中/右]
  不可变更: 1.___ 2.___
```

**推断规则：**
- 推文明确描述的 → 直接使用，不可变更
- 推文暗示的 → 推断并标注「推断」
- 推文未涉及的 → 根据类型/世界观补全，标注「补全」
- 补全优先考虑视觉区分度（避免角色撞脸）

### 2.2 场景锚点

```
场景锚点: [场景名]
  原文线索: "___"
  类型: INT/EXT · 时间: 日/夜/黄昏/黎明
  规模: 密闭/中型/开阔/宏大
  氛围: ___
  光线: 主光源___ · 方向___ · 色温___K · 质感硬/软
  隐藏(SPIELBERG): ___（此场景的黑暗角落/视觉盲区）
  色彩: 主色___ | 辅色___ | 点缀___
```

### 2.3 关键物品锚点

推文中出现的具象物品往往承载隐喻，需要标记：

```
物品锚点: [物品名]
  原文: "___"
  字面功能: ___
  隐喻功能: ___
  视觉强调: 需要INSERT · 不需要
  出现段落: 段___
```

## STEP 3 — TRANSLATE（文字→画面转译）

这是推文分镜的核心步骤。推文是旁白驱动的叙述体，每个镜头的关键问题是：

**"这段旁白配什么画面？"**

### 3.1 五种转译策略

| 策略 | 适用场景 | 示例旁白 | 对应画面 |
|------|---------|---------|---------|
| **直译** | 叙述中有明确视觉描写 | "他站在雨中" | 男人站在雨中的画面 |
| **具象化** | 情感隐喻需视觉落地 | "胸口像灌了水泥" | ECU：手紧握胸口，指节发白 |
| **反差映衬** | 旁白与画面形成张力 | "我很好" | 角色独自蹲在角落，眼泪无声流下 |
| **留白代述** | 旁白描述情感，画面展示环境 | "那一刻天塌了" | 空镜：天空/天花板，缓慢下压 |
| **金句定格** | 落点句/金句 | "我先遇到他的。" | CU/MCU静态定格≥3s，字幕叠加 |

### 3.2 每段转译

为每一段推文执行文字→画面转译：

```
段[N] 转译
原文: "___"
旁白字数: ___ | 预估VO时长: ___s
策略: 直译/具象化/反差映衬/留白代述/金句定格
视觉核心: ___
镜头数: ___ | 节奏: 快/中/慢
```

### 3.3 转译规则

**必须遵守：**
1. **旁白不可删改** — VO即推文原文，逐字保留
2. **金句必须独占镜头** — 落点句/金句不得与其他旁白共用镜头
3. **情感峰值=镜头密度峰值** — 情感最强的段落，镜头切换最密
4. **隐喻必须视觉化** — 不得出现"画面表现悲伤"，必须写明怎么悲伤
5. **第一人称旁白规则** — 旁白出现"我"时：显示主角（沉浸感）或显示主角所见（观察感），每段内保持一致
6. **禁止抽象画面描述** — 不写"悲伤的画面""紧张的氛围"，必须具体到：什么人、什么动作、什么光线、什么构图

**禁止词汇（无物理对应）：**
"悲伤""愤怒""紧张""开心""恐惧" → 必须替换为身体动作/面部微表情/光线变化

## STEP 4 — BOARD（分镜表输出）

### 场景头部（每个场景前）

```
═══════════════════════════════════════════
段[N] — [段落功能] | 情感强度: ___ | 策略: ___
═══════════════════════════════════════════
VO原文: "___"
预估时长: ___s | 镜头数: ___
═══════════════════════════════════════════
```

### 分镜主表

| 镜号 | 景别 | 运镜 | 画面描述 | 角色表演 | VO/音效 | 时长(s) | 备注 |
|------|------|------|---------|---------|--------|--------|------|
| ___ | ___ | ___ | ___ | ___ | ___ | ___ | ___ |

**各列填写规范：**

**镜号**：顺序编号。子镜号（03A/03B）用于同一情感节拍的碎片化快切。

**景别**：ECU / CU / MCU / MS / WS / ELS / INSERT / FRAGMENT / LINGER / 金句定格

- **金句定格**：推文特有景别。落点句/金句出现时，画面静态定格+字幕叠加，≥3.0s。构图留出字幕安全区（画面下方20%不放置关键视觉元素）。
- **FRAGMENT vs INSERT**：FRAGMENT = 观众需脑补拼合的碎片（HITCHCOCK），INSERT = 需要阅读的信息物。
- **LINGER**：凝视/驻留，≥4.0s，用于情感沉浸。

**运镜**：静态 / 缓推 / 缓拉 / 上摇 / 下摇 / 手持 / 急推 / 横移 / 微漂移 / 凝视保持

推文视频运镜偏好：
- **旁白段**：以缓推/静态为主，避免频繁运镜干扰VO节奏
- **情感峰值**：急推/手持增加紧迫感
- **金句定格**：纯静态，运镜归零
- **反转段**：运镜方向反转（缓推→缓拉，或静态→突然横移）

**画面描述**（画给分镜师看的 — SCOTT法则）：
描述取景框内的全部内容：主体位置（上/中/下三分之一）、背景内容、前景元素、构图方式。必须具体到可以画出来。竖屏9:16构图规则：
- 单人特写：面部居中偏上，留出下方字幕空间
- 双人对峙：上下构图（一人上方一人下方）或前后景
- 环境交代：纵向延伸（走廊/楼梯/道路向画面深处）

**角色表演**（身体细节 — SCOTT法则）：
描述角色身体在做什么 — 下巴/眼睛/眉头/嘴唇/呼吸/姿势/手势。禁止抽象情绪词。示例：
- ❌ "悲伤地看着他" → ✅ "眼眶微红，下唇轻颤，手指无意识地攥紧衣角"
- ❌ "愤怒地转身" → ✅ "下颌咬紧，肩膀猛然绷直，转身时拳头未松"

**VO/音效**：
- VO：引用推文原文，用引号标注。标注语速模式（日常/情感/金句）
- 音效：具体描述环境声+特殊音效。不写"背景音"，写"雨滴打在铁皮屋顶+远处犬吠"
- 音乐方向：需要/不需要 · 类型标注

**时长(s)**：
```
VO字数 ÷ 语速 + 情感停顿 + 画面呼吸
```
最低时长地板：ECU≥1.0 · CU≥2.0 · MCU≥3.0 · MS≥3.5 · WS≥2.0 · INSERT≥1.5 · LINGER≥4.0 · 金句定格≥3.0

**备注**：三个结构化子项：
1. **[光线]** 主光源+方向+色温+质感+具体细节。命名光线隐藏了什么（SPIELBERG）。
2. **[功能]** 此镜头在叙事中的独特作用。适用哪条法则。
3. **[连贯]** 角色位置/视向/物品状态/运镜出点。隐藏了什么。

格式：`[光线] ___ [功能] ___ [连贯] ___`

## 四条导演法则

推文分镜精简为四条核心法则（从storyboard技能的八条中提炼）：

| # | 法则 | 一句话 | 适用 |
|---|------|--------|------|
| 1 | **HITCHCOCK** | 峰值时刻：展示碎片，而非全貌。不完整的画面更有力量。 | 所有 |
| 2 | **SCOTT** | 具体到演员、摄影师、特效各取所需而无需追问。 | 所有 |
| 3 | **SPIELBERG** | 每个镜头说明它隐藏了什么，以及为什么隐藏服务于故事。 | 所有 |
| 4 | **MILLER** | 声明每个空间位置。居中构图。必须无字幕也能成立。 | 所有 |

**HITCHCOCK优先** — 推文的情感爆发点（破防/反转）必须用碎片化视觉处理，而非全景直述。

## STEP 5 — CHECK（自检）

全部分镜表完成后执行。修复每个失败项后再声明通过。

**A · 完整性** — 对照Step 1合约：
- [ ] 每个段落有分镜表，无段落被合并/跳过
- [ ] 每句旁白原文被引用在至少一个镜头的VO列
- [ ] 每个金句/落点句有独立的「金句定格」镜头
- [ ] 每个隐喻/感官描写被视觉转译（非直述情感词）
- [ ] 每个命名物品出现，关键物品有INSERT镜头
→ **修复：** 缺失镜头→补加并标注原文出处。缺失隐喻转译→应用转译策略重写。

**B · 叙事** — 每个镜头有存在价值：
- [ ] 每个镜头备注中有明确功能（不是"氛围""感觉"）
- [ ] 无两个镜头做完全相同的事
- [ ] 情感曲线→镜头密度曲线：峰值段镜头最密
- [ ] 金句定格镜头≥3.0s
- [ ] 视觉强度匹配旁白强度：弱旁白+强画面=反差映衬（需有意设计），不可无意为之
→ **修复：** 重复镜头→合并或重赋功能。密度错位→调整镜头切分。无意反差→统一强度。

**C · 运镜连贯**：
- [ ] 每个镜头的运镜出点流入下一个镜头的运镜入点
- [ ] 禁止组合：缓推→紧接缓拉 / 急推→急推 / 手持→立刻静态锁定
- [ ] 每次运镜有叙事动机
- [ ] 金句定格=纯静态，运镜归零
→ **修复：** 禁止组合→插入中性桥接镜头（静态WS或INSERT）。缺少连贯→补写备注连贯项。

**D · 具象化** — 无模糊语言：
- [ ] 禁止单独使用：悲伤/愤怒/紧张/开心/恐惧 → 必须有身体/面部/光线规格
- [ ] 每个CU/ECU的表演列含：视向+呼吸+一个具体微表情
- [ ] 每个CU/ECU的备注含：光线方向+光源命名
- [ ] 画面描述列无抽象词，可画=合格
→ **修复：** 抽象词→替换为物理规格。缺微表情→补充。缺光线→补充方向+光源。

**E · 时长**：
- [ ] 每个时长格有计算数值
- [ ] 无低于地板值：ECU≥1.0 · CU≥2.0 · MCU≥3.0 · MS≥3.5 · WS≥2.0 · INSERT≥1.5 · LINGER≥4.0 · 金句定格≥3.0
- [ ] 全片总时长在30-120s区间
→ **修复：** 低于地板→提升至地板值+补hold。缺计算→应用公式。总时长超→压缩过渡镜头。
