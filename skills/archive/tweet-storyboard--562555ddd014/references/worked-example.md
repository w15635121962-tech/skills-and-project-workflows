# 推文分镜案例示范

> 完整展示一篇推文从文字到分镜表的转化过程。
> 案例来源：虚构推文，模拟 `viral-thread-story` 产出风格。

## 原始推文

**《替身》· 虐文/替身文学**

```
[1]
在我成人礼那晚，我的双胞胎姐姐爬上了我未婚夫的床。
所有人都觉得是意外。连他自己都这么觉得。

[2]
可我记得，她穿过走廊时，回头看了我一眼。
那眼神，像猫叼走了鱼，还嫌鱼不够肥。

[3]
我没有哭。
我把那条准备了一整年的裙子叠好，放进柜子最底层。
然后关灯，睡觉。

[4]
第二天的订婚宴，她挽着他的手臂，笑得像朵花。
他看见我，顿了一下，说："我们……还需要谈谈。"
我笑了："恭喜。"

[5]
我转身的时候，手指掐进了掌心。
我等了十七年，等来的就是一句"需要谈谈"。

[6]
后来我才知道，从始至终，他分不清我和她。
那张脸，他看着的从来不是我。

[7]
我搬走了。没带那条裙子。
有些东西，不值得带走。

[8]
三个月后，他找到我。
他说，他弄错了。他说，他要的人一直是我。

[9]
我看着他。他的眼睛里确实有我。
可是，我也终于看清了他的眼睛。
那里面，从来没有选择。

[10]
"谢谢你来，"我说，"不过——
我先遇到他的。"
```
