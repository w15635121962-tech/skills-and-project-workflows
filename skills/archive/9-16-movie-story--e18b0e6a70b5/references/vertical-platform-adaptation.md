# 竖屏平台适配手册 (Vertical Platform Adaptation)

> 抖音/ TikTok / Reels / Shorts / 即梦 / 快手 等竖屏平台的画幅、UI、算法适配指南。

---

## 一、平台画幅与 UI 规范

### 1.1 画幅对比

| 平台 | 推荐画幅 | 分辨率 | UI 遮挡区 |
|------|---------|---------|-----------|
| 抖音/ TikTok | 9:16 | 1080×1920 | 右侧 15%（头像/点赞），底部 18%（文案/音乐） |
| Instagram Reels | 9:16 | 1080×1920 | 底部 20%（文案），顶部 10%（账号名） |
| YouTube Shorts | 9:16 | 1080×1920 | 底部 15%（进度条），右侧 12%（订阅按钮） |
| 快手 | 9:16 | 1080×1920 | 右侧 18%，底部 20% |
| 即梦 (Dreamina) | 9:16 | 1080×1920 | 无（纯创作平台） |
| 微信视频号 | 9:16 | 1080×1260 (≈9:10.5) | 底部 22%（点赞/评论） |

### 1.2 安全区定义（通用）

```
┌─────────────────┐  ← 顶部 10%：账号名/标题（避免放置主体）
│  顶部安全区     │
├─────────────────┤
│                 │
│  核心内容区      │  ← 主体必须在此区域 (10-80%)
│  (眼睛在 1/3)  │
│                 │
├─────────────────┤
│  底部安全区      │  ← 底部 20%：字幕/文案/互动按钮（避免放置主体）
└─────────────────┘
```

### 1.3 各平台安全区详细

| 平台 | 顶部安全区 | 底部安全区 | 右侧 UI 区 |
|------|-----------|-----------|------------|
| 抖音 | 0-10% | 80-100% | 85-100% (右侧) |
| Reels | 0-10% | 80-100% | 无 |
| Shorts | 0-8% | 82-100% | 88-100% (右侧) |
| 快手 | 0-10% | 80-100% | 82-100% (右侧) |
| 视频号 | 0-8% | 78-100% | 无 |

## 二、平台算法适配

### 2.1 完播率优化（竖屏专属）

竖屏视频前 **3 秒**决定完播率：

| 技巧 | 提示词关键词 | 效果 |
|------|-------------|------|
| 快速切入 | `fast cut, immediate action` | 0-1秒展示核心画面 |
| 悬念开头 | `mystery,悬念, open ending` | 诱导看完 |
| 视觉冲击 | `visual impact, high contrast` | 停留时间 +30% |
| 人脸特写 | `face close-up, eyes locked` | 情感共鸣更强 |

### 2.2 互动率优化

| 平台 | 互动按钮位置 | 提示词适应 |
|------|-------------|------------|
| 抖音 | 右侧（点赞/评论/分享） | 主体偏左 20% |
| Reels | 底部（点赞/评论） | 主体居中偏上 |
| Shorts | 右侧（订阅） | 主体偏左 15% |

### 2.3 算法推荐关键词（中文平台）

```
# 抖音/快手
热门, 爆款, 剧情反转, 高燃, 催泪, 爽剧, 短剧

# 即梦（AI 视频）
AI生成, 电影感, 写实, 细节丰富, 50帧

# 微信视频号
情感, 剧情, 正能量, 家庭, 职场
```

## 四、竖屏剪辑规范

### 4.1 镜头时长（竖屏节奏）

| 镜头类型 | 横屏时长 | 竖屏时长 | 原因 |
|---------|---------|---------|------|
|  establishing | 5-8秒 | 2-3秒 | 竖屏节奏更快 |
| 对话（中景） | 3-5秒 | 1-3秒 | 注意力更短 |
| 特写 | 2-4秒 | 1-2秒 | 快速切特写 |
| 动作 | 1-3秒 | 0.5-2秒 | 高帧率慢动作 |

### 4.2 转场（竖屏专属）

| 转场 | 横屏 | 竖屏 | 提示词关键词 |
|------|------|------|-------------|
| 切 (Cut) | 硬切 | 硬切（最常用） | `hard cut, fast paced` |
| 叠化 (Dissolve) | 常用 | 少用（显得慢） | `dissolve (avoid)` |
| 擦除 (Wipe) | 偶尔 | 垂直擦除 | `vertical wipe transition` |
| 匹配剪辑 | 动作匹配 | 表情匹配 | `expression match cut` |

### 4.3 字幕位置（竖屏）

```
┌─────────────────┐
│  标题字幕       │  ← 顶部 5-8%（白色，描边）
│  (5-8%)        │
├─────────────────┤
│                 │
│  主体区域        │
│  (10-80%)      │
├─────────────────┤
│  对话字幕       │  ← 底部 12-18%（黄色/白色）
│  (12-18%)      │
└─────────────────┘
```

**字幕提示词**：
```
space at bottom 15% for subtitles,
title safe zone top 8%,
dialogue subtitles bottom 12-18%
```

## 五、竖屏色彩与光影（平台优化）

### 5.1 手机屏显示特性

| 特性 | 影响 | 提示词适应 |
|------|------|-----------|
| OLED 高对比 | 黑色更深，高光更亮 | `high contrast, OLED optimized` |

| 自动亮度 | 暗部细节丢失 | `lift shadows, avoid crushed black` |

| 即梦 | 电影感 | `cinematic color, teal & orange, film look` |

## 七、竖屏音频规范

### 7.1 音乐同步（竖屏专属）

竖屏视频**音乐 > 对白**（尤其是抖音/ Reels）：

| 平台 | 音乐重要性 | 提示词适应 |
|------|-----------|-----------|
| 抖音 | ⭐⭐⭐⭐⭐ | `music sync, beat matching, trending audio` |
| Reels | ⭐⭐⭐⭐⭐ | `Instagram audio, music sync` |
| Shorts | ⭐⭐⭐ | `background music, YouTube audio library` |
| 即梦 | ⭐⭐ | `no audio dependency`（纯视觉） |

### 7.2 对白可读性（竖屏）

手机扬声器音质差，对白必须：

1. **字幕必须**（100% 覆盖）
2. **语速慢**（字幕停留时间 ≥1.5 秒）
3. **避开底部 18%**（字幕在 12-18%，不能更低）

```
# 提示词
dialogue subtitles at bottom 12-18%,
slow speech, clear pronunciation,
subtitles 100% coverage
```

## 十、检查清单（平台适配）

每完成一个视频，自查：

- [ ] 画幅是否为 9:16（无黑边）？
- [ ] 主体是否在安全区 (10-80%)？
- [ ] 眼睛是否在 1/3 处？
- [ ] 底部 20% 是否为空（或仅有字幕）？
- [ ] 右侧 UI 区是否避开（抖音/ Shorts）？
- [ ] 前 3 秒是否有视觉冲击？
- [ ] 字幕是否在 12-18%（不在最底部 5%）？
- [ ] 色彩是否适配手机屏（高对比/高饱和）？
- [ ] 是否包含平台热门关键词？
- [ ] 音乐是否同步（抖音/ Reels）？
