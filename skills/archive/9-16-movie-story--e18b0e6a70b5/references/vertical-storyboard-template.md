# 竖屏分镜脚本模板 (Vertical Storyboard Template)

> 专为 9:16 竖屏画幅重构的分镜脚本模板。原版 16:9 分镜表直接用于竖屏会导致构图描述错误、安全区遗漏、平台适配缺失。

---

## 一、竖屏分镜表（12列重构版）

### 1.1 原版 vs 竖屏版对比

| 列名 | 16:9 横屏 | 9:16 竖屏 |
|------|-----------|-----------|
| 画幅 | 16:9 (1.78:1) | 9:16 (0.56:1) |
| 构图 | 三分法/对称/引导线 | 垂直三分法/中心构图/垂直引导线 |
| 安全区 | 4:3 安全框 | 上 10% + 下 20% 留空 |
| 平台 | 无 | 抖音/Reels/Shorts/即梦 |
| 提示词 | `--ar 16:9` | `--ar 9:16 + vertical framing` |

### 1.2 竖屏分镜表（Markdown 格式）

```
| 镜号 | 场景 | 时间 | 镜头描述 (融合书写) | 构图 (垂直) | 运镜 (竖屏) | 光影与色彩 | 对白/音效 | 空间坐标 | AI 提示词 (竖屏) | 覆盖 |
|------|------|------|-------------------|------------|-------------|-----------|-----------|---------|-----------------|------|
| 001  | INT. 偏殿-夜 | 00:00:00 | 王勃跪拜，蓝色官袍，闪电照亮 | 眼睛在1/3，头顶留白15% | 静态广角，脚贴底 | 冷蓝灰，闪电高光 | 雷声 | [C1] ΔX=+4m | 见下方 | Master |
```

### 1.3 分镜表填写规范（竖屏）

| 列 | 填写规范 | 示例 |
|----|---------|------|
| 镜号 | 3位数，001-999 | `001` |
| 场景 | `INT./EXT.` + 地点 + 时间 | `INT. 偏殿-夜` |
| 时间 | `HH:MM:SS` | `00:02:15` |
| 镜头描述 | **融合书写**：镜头+动作+表演+情感 | `王勃跪拜，颤抖，瞳孔收缩` |
| 构图 (垂直) | 必须指定眼睛位置 | `眼睛在1/3，头顶留白15%` |
| 运镜 (竖屏) | 使用竖屏运镜缩写 | `V-PU` (垂直推进) |
| 光影与色彩 | 竖屏色彩 + 手机屏优化 | `冷蓝灰，高对比，OLED优化` |
| 对白/音效 | 对白 + 环境音 + 音效 | `雷声，雨声，纸张撕裂声` |
| 空间坐标 | `[C1] ΔX/ΔY/ΔZ` | `[C1] ΔX=+4m, ΔY=+1m` |
| AI 提示词 | 四步框架 + `--ar 9:16` | 见下方模板 |
| 覆盖 | Master/Single/OTS/Insert | `Master, Single A, OTS` |

## 二、融合书写规范（竖屏版）

### 2.1 原版融合书写

```
镜001：王勃（前中）跪拜，闪电侧光（Hard Plunge），
蓝灰调，嘶吼："我不服！"（16:9 横屏构图）
```

### 2.2 竖屏融合书写（重构）

```
镜001：王勃（上前），跪拜，眼睛在画面上1/3处，
闪电侧光（Hard Plunge），冷蓝灰调，高对比（OLED优化），
底部20%留空（互动区），嘶吼："我不服！"，
提示词：王勃，蓝色官袍，跪拜，眼睛在1/3处，
阴雨夜，闪电，冷蓝调，--ar 9:16, vertical framing
```

### 2.3 融合书写模板（竖屏）

```
镜{镜号}：{主体}（{位置}），{动作}，
{眼睛位置：在1/3处}，{垂直构图}，
{光影}（{光位}），{色彩}（{手机屏优化}），
{底部处理：留空20%}，{对白/音效}，
提示词：{AI提示词（含--ar 9:16）}
```

## 三、竖屏构图标注规范

### 3.1 垂直三分法（竖屏核心）

```
┌─────────────────┐
│  上 1/3          │  ← 眼睛位置（标准）
│  (眼睛在1/3)    │
├─────────────────┤
│  中 1/3          │  ← 口鼻/下巴
├─────────────────┤
│  下 1/3          │  ← 留空20%（互动区）
└─────────────────┘
```

**标注格式**：
```
构图：垂直三分法，眼睛在1/3处，头顶留白15%
```

### 3.2 竖屏构图类型

| 构图类型 | 标注 | 使用场景 |
|---------|------|---------|
| 垂直三分法 | `垂直三分法，眼睛在1/3` | 标准人物镜头 |
| 中心构图（竖） | `中心构图，人脸竖直居中` | 权威/对称场景 |
| Top-Heavy | `主体在上2/3，底部留空` | 权利镜头 |
| Bottom-Heavy | `主体在下2/3，顶部留空` | 弱势/屈服 |
| 垂直引导线 | `垂直引导线，建筑/楼梯` | 场景建立 |

### 3.3 安全区标注

```
安全区：上10%（标题区），下20%（互动区），
核心区：10-80%，人脸必须在核心区
```

## 四、竖屏运镜标注规范

### 4.1 运镜缩写（竖屏专用）

| 缩写 | 全称 | 中文 | 提示词关键词 |
|------|------|------|-------------|
| V-PU | Vertical Push-In | 垂直推进 | `vertical push-in, eyes locked at 1/3` |
| V-PO | Vertical Pull-Out | 垂直拉远 | `vertical pull-out, reveal full body` |
| TU | Tilt Up | 上摇 | `tilt up from feet to face` |
| TD | Tilt Down | 下摇 | `tilt down from face to feet` |
| DF | Diagonal Follow | 斜向跟随 | `diagonal follow shot, 45° angle` |
| FS | Front Follow Shot | 前跟镜头 | `front follow, walking towards camera` |
| VO | Vertical Orbit | 垂直环绕 | `vertical orbit, eyes locked at 1/3` |
| HS | Handheld Shake | 手持抖动 | `vertical handheld shake` |

### 4.2 运镜标注示例

```
镜002：V-PU（垂直推进，从全身推到腰部以上，眼睛锁定1/3）
镜005：TU（上摇，从官袍下摆摇到脸部，揭示身份）
镜012：DF（斜向跟随，45°跟拍，背景虚化）
镜018：HS（手持抖动，奔跑时垂直颠簸）
```

## 五、AI 提示词模板（竖屏分镜表用）

### 5.1 四步黄金框架（竖屏版）

```
{主体}, {动作}, {垂直位置: 眼睛在1/3处},
{环境}, {光影}, {底部处理: 留空20%},
--ar 9:16, vertical framing, 9:16 aspect ratio,
{质感层: 手机屏优化, OLED optimized},
--no {负面词: horizontal composition, face cropped}
```

### 5.2 分镜表内提示词缩写

由于分镜表空间有限，AI 提示词可以缩写：

| 完整提示词 | 缩写 |
|-----------|------|
| `eyes at upper 1/3` | `E@1/3` |
| `vertical framing, 9:16 aspect ratio` | `V-9:16` |
| `headroom 15%` | `HR15%` |
| `mobile display optimized` | `MOB-OPT` |
| `bottom 20% empty` | `B20%E` |

**缩写示例**：
```
王勃, 跪拜, E@1/3, 阴雨夜, 冷蓝调, V-9:16, MOB-OPT, --no face cropped
```

### 5.3 完整提示词（分镜表外）

在每个镜头的详细说明中，提供完整提示词：

```
AI 提示词（Midjourney）：
Wang Bo, blue official robe, kneeling, eyes at upper 1/3,
rainy night, lightning, cold blue tone, vertical framing,
--ar 9:16, mobile display optimized, OLED optimized,
--no horizontal composition, face cropped, watermark
```
