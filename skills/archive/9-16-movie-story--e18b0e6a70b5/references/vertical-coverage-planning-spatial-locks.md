# 覆盖规划与空间坐标锁定（竖屏 9:16 版）

> **适用**：竖屏对话场景的覆盖拍摄规划  
> **核心差异**：9:16 画幅下的 180° 法则、空间坐标系统、竖屏覆盖镜头

---

## 180° 法则（竖屏版）

### 横屏 vs 竖屏 180° 法则

| 维度 | 横屏 16:9 | 竖屏 9:16 |
|------|-----------|-----------|
| **Master Axis (C1)** | 水平线（左→右） | 垂直线（上→下）或斜线 |
| **OC1（单数镜头）** | 从 C1 左侧拍 | 从 C1 上方拍 |
| **OC2（双数镜头）** | 从 C1 右侧拍 | 从 C1 下方拍 |
| **屏幕方向** | 左右布局 | 上下布局 |
| **视线方向** | 水平（左←→右） | 垂直（上←→下）或对角线 |

### 竖屏 180° 法则定义

```
Master Axis (C1)：
- 从角色 A 的鼻尖指向角色 B 的鼻尖（3D 向量）
- 竖屏版：优先使用对角线（左上→右下 或 右上→左下）
- 原因：竖屏画幅垂直，水平轴线容易导致构图呆板

轴线 (Axis Line)：
- 连接 A 和 B 的直线（延长线）
- 摄像机必须放在轴线的同一侧（180° 范围内）

越轴 (Crossing the Line)：
- 摄像机跨过轴线到另一侧
- 观众会感觉角色突然"调转方向"
- 竖屏版越轴后果更严重（大脑对垂直方向更敏感）
```

## 空间坐标系统（竖屏版）

### 坐标定义（9:16 画幅）
```
坐标系统（归一化）：
- x: 0.0 (左) → 1.0 (右)
- y: 0.0 (上) → 1.0 (下)
- z: 0.0 (远) → 1.0 (近)

竖屏画幅安全区：
- 中心稳定区: x [0.25, 0.75], y [0.25, 0.65]
- 头部安全区: y [0.0, 0.4]
- 底部安全区: y [0.65, 1.0]（留白或字幕区）
```

### 对话场景坐标（竖屏版）

**方案 A：上下布局（推荐）**
```
角色 A (上方):
- Position: x=0.5, y=0.25
- Gaze: x=0.5, y=0.75 (看向 B)
- 占据画面上半部分

角色 B (下方):
- Position: x=0.5, y=0.75
- Gaze: x=0.5, y=0.25 (看向 A)
- 占据画面下半部分

Master Axis (C1):
- 从 A 的鼻尖 (0.5, 0.25) → B 的鼻尖 (0.5, 0.75)
- 方向：垂直向下（向量 [0, 1, 0]）
```

**方案 B：左右布局（传统）**
```
角色 A (右侧):
- Position: x=0.7, y=0.5
- Gaze: x=0.3, y=0.5 (看向 B)
- 占据画面右侧

角色 B (左侧):
- Position: x=0.3, y=0.5
- Gaze: x=0.7, y=0.5 (看向 A)
- 占据画面左侧

Master Axis (C1):
- 从 A 的鼻尖 (0.7, 0.5) → B 的鼻尖 (0.3, 0.5)
- 方向：水平向左（向量 [-1, 0, 0]）
```

**方案 C：对角线布局（电影感）**
```
角色 A (左上):
- Position: x=0.3, y=0.25
- Gaze: x=0.7, y=0.75 (看向 B)
- 占据画面左上

角色 B (右下):
- Position: x=0.7, y=0.75
- Gaze: x=0.3, y=0.25 (看向 A)
- 占据画面右下

Master Axis (C1):
- 从 A 的鼻尖 (0.3, 0.25) → B 的鼻尖 (0.7, 0.75)
- 方向：右下（向量 [0.4, 0.5, 0]）
```

## 竖屏覆盖镜头（Coverage Shots）

### 对话场景最小覆盖（竖屏版）

| 镜头 | 名称 | 坐标 | 时长 | 说明 |
|------|------|------|------|------|
| **C1** | Master Axis | 全景，展示 A+B | 3-5 秒 | 建立空间关系 |
| **OC1** | 单数镜头（A 看 B） | A 在右/上，看镜头左/下 | 2 秒 | 从 C1 左侧/上方拍 |
| **OC2** | 双数镜头（B 看 A） | B 在左/下，看镜头右/上 | 2 秒 | 从 C1 右侧/下方拍 |
| **OTS-A** | A 的 OTS（看 B） | A 的肩膀占画面左/上 30% | 1-2 秒 | 越肩镜，强调 A 的 POV |
| **OTS-B** | B 的 OTS（看 A） | B 的肩膀占画面右/下 30% | 1-2 秒 | 越肩镜，强调 B 的 POV |
| **Insert** | 插入镜（道具/细节） | 居中，特写 | 0.5-1 秒 | 强调关键道具 |

### 竖屏覆盖镜头示例（《大唐文圣》EP01）

**场景：周王府偏殿·暴雨夜·王勃与陆雪对峙**

```
Master Axis (C1):
- 方向：对角线（王勃在右上，陆雪在左下）
- 坐标：王勃 (0.65, 0.3)，陆雪 (0.35, 0.7)
- 镜头：双人全景，展示空间关系（3 秒）

OC1 (王勃看陆雪):
- 王勃在画面上方（y=0.3），看向下方（陆雪）
- 坐标：x=0.65, y=0.3，gaze=(0.35, 0.7)
- 镜头：中景，王勃占上半部分（2 秒）

OC2 (陆雪看王勃):
- 陆雪在画面下方（y=0.7），看向上方（王勃）
- 坐标：x=0.35, y=0.7，gaze=(0.65, 0.3)
- 镜头：中景，陆雪占下半部分（2 秒）

OTS-王勃 (王勃的 POV):
- 王勃的肩膀占画面上方 30%
- 陆雪在画面下方 70%
- 镜头：越肩镜，强调王勃的视角（1.5 秒）

OTS-陆雪 (陆雪的 POV):
- 陆雪的肩膀占画面下方 30%
- 王勃在画面上方 70%
- 镜头：越肩镜，强调陆雪的视角（1.5 秒）

Insert (休书):
- 休书特写，居中
- 坐标：x=0.5, y=0.5
- 镜头：插入镜，强调关键道具（1 秒）
```

## 竖屏构图与覆盖规划

### 构图与覆盖的关系

| 构图 | 覆盖镜头 | 适用场景 |
|------|---------|---------|
| **中心构图** | Master / Insert | 定场、道具特写 |
| **三分法** | OC1 / OC2 | 对话镜 |
| **满屏构图** | 特写 | 情绪爆发 |
| **分割构图** | OTS | 双人流，POV 镜 |

### 竖屏覆盖规划检查清单

- [ ] Master Axis (C1) 已定义（方向 + 坐标）
- [ ] 轴线 (Axis Line) 已标注
- [ ] 所有摄像机位置在轴线同一侧（180° 范围内）
- [ ] 对话场景至少有 5 个覆盖镜头（Master + OC1 + OC2 + OTS-A + OTS-B）
- [ ] 每个镜头标注空间坐标（x, y, gaze）
- [ ] 人脸在中心稳定区（x:0.25-0.75, y:0.25-0.65）
- [ ] 眼睛位置在画面上 1/3（y≈0.33）
- [ ] 越轴镜头已标注 ⚠️ 并说明叙事目的

## 竖屏覆盖规划常见错误

### ❌ 错误 1：Master Axis 定义不清
**后果**：后续覆盖镜头混乱，观众迷失方向。  
**解决**：在分镜开头明确定义 C1 的方向和坐标。

### ❌ 错误 2：人脸不在中心稳定区
**后果**：竖屏观看时人脸被裁剪。  
**解决**：所有对话镜标注 Camera Position (x, y)，确保人脸在中心区。

### ❌ 错误 3：越轴镜头未标注
**后果**：观众感觉角色突然"调转方向"。  
**解决**：越轴镜头必须标注 ⚠️ 并说明叙事目的（如权力反转）。

### ❌ 错误 4：覆盖镜头不足
**后果**：剪辑时镜头单调，无法选择。  
**解决**：对话场景至少 5 个覆盖镜头（Master + OC1 + OC2 + OTS-A + OTS-B）。

### ❌ 错误 5：竖屏构图用横屏思维
**后果**：主体太小或位置尴尬。  
**解决**：使用竖屏构图（中心构图、三分法、满屏构图），避免左右布局。

## 总结

竖屏覆盖规划 = **横屏覆盖规划** + **竖屏坐标适配** + **9:16 构图约束**

**核心差异**：
1. Master Axis (C1) 优先使用对角线（而非水平线）
2. 坐标系统标注 Camera Position (x, y) 和 Gaze (x, y)
3. 人脸必须在中心稳定区（x:0.25-0.75, y:0.25-0.65）
4. 对话场景至少 5 个覆盖镜头
5. 越轴镜头必须标注 ⚠️
