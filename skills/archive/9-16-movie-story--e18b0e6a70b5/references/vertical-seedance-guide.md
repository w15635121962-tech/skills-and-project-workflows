# Seedance 2.0 竖屏指南 (Vertical Seedance Guide)

> 针对 9:16 竖屏画幅的 Seedance 2.0 使用指南。即梦（Dreamina）Seedance 2.0 是目前最强的中文 AI 视频生成模型，竖屏适配至关重要。

---

## 一、Seedance 2.0 竖屏核心特性

### 1.1 画幅设置

| 参数 | 横屏 16:9 | 竖屏 9:16 |
|------|-----------|-----------|
| 分辨率 | 1920×1080 | 1080×1920 |
| 即梦设置 | 选择"横屏" | 选择"竖屏" |
| 提示词语法 | `--ar 16:9` | `--ar 9:16` |
| 多模态参考 | 参考图自动适配 | 参考图需手动裁剪为 9:16 |

### 1.2 竖屏多模态参考图规范

**关键问题**：Seedance 多模态参考图如果是横屏，生成视频会被裁剪或变形。

**解决方案**：
1. 参考图先裁剪成 9:16（用 Midjourney 或即梦自带裁剪）
2. 上传参考图后，选择"人物保持"
3. 提示词明确写：`参考图中人物，竖屏构图，--ar 9:16`

## 二、竖屏提示词结构（Seedance 专用）

### 2.1 四步黄金框架（Seedance 竖屏版）

```
第一步：主体+动作+垂直位置
   ↓
第二步：环境+光影+底部处理
   ↓
第三步：技术参数（--ar 9:16 + vertical framing）
   ↓
第四步：质感层+手机屏优化
```

### 2.2 完整示例

**横屏原版**：
```
参考图中人物，
推进镜头，从脚推到脸部，
阴雨夜，闪电，冷蓝调，
电影感，--ar 16:9
```

**竖屏重构版**：
```
参考图中人物，眼睛在画面上1/3处，
垂直推进镜头，从脚推到脸部，
阴雨夜，闪电，冷蓝调，画面底部留互动区，
电影感，竖屏构图，--ar 9:16，
手机屏显示优化，高对比度
```

### 2.3 必加竖屏关键词

| 关键词 | 作用 |
|--------|------|
| `眼睛在画面上1/3处` | 锁定眼睛位置 |
| `竖屏构图` | 强制竖屏理解 |
| `画面底部留互动区` | 避免 UI 重叠 |
| `人脸竖直居中` | 防止人脸偏移 |
| `头顶留白15%` | 控制构图 |
| `--ar 9:16` | 技术参数（必须） |

## 五、Seedance 竖屏高级技巧

### 5.1 人物保持 + 竖屏构图

**问题**：上传横屏参考图，Seedance 生成横屏视频。

**解决方案**：
1. 先用 Midjourney 生成 9:16 人物参考图：
   ```
   {人物描述}, vertical framing, --ar 9:16
   ```
2. 上传这张 9:16 参考图到即梦
3. 选择"人物保持"
4. 提示词加 `参考图中人物，竖屏构图，--ar 9:16`

### 5.2 情绪渐变（竖屏版）

```
参考图中人物，
从震惊到愤怒的情绪渐变，
眼睛始终在画面1/3处，
微表情捕捉，瞳孔收缩，
--ar 9:16，竖屏构图，
高清，50帧
```

### 5.3 多镜头拼接（竖屏）

Seedance 单次生成 5-10 秒，竖屏长视频需要拼接：

**方案**：用即梦的"视频延长"功能
1. 生成第一段（0-5秒）
2. 点击"延长"
3. 上传第一段最后一帧作为参考图
4. 提示词：`接续上一段，{继续动作}，--ar 9:16`

### 5.4 动作流畅度（竖屏专属）

竖屏观看时，垂直方向的动作流畅度更关键：

```
避免：人物突然跳动，摄像机剧烈抖动
推荐：缓慢垂直推进，平滑上摇/下摇，
      人物动作从下往上（起身/抬头）更有竖屏感
```

## 七、即梦 Web 端竖屏操作指南

### 7.1 画幅选择

1. 打开即梦 Web：https://jimeng.jianying.com
2. 点击"AI 视频" → "Seedance 2.0"
3. 在右侧面板选择：**画幅 → 9:16（竖屏）**

### 7.2 多模态参考图上传

1. 点击"参考图"
2. 上传 9:16 人物参考图（**必须预先裁剪成 9:16**）
3. 选择"人物保持"（保持面孔不变）
4. 相似度调到 **0.7-0.8**（太高会失真，太低会不像）

### 7.3 提示词输入框

在"提示词"输入框中写：

```
参考图中人物，{动作描述}，
眼睛在画面上1/3处，竖屏构图，
{环境描述}，{光影描述}，
--ar 9:16，电影感，高清
```

### 7.4 高级设置（竖屏）

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 视频时长 | 5秒 / 10秒 | 竖屏建议5秒（快节奏） |
| 运动幅度 | 3-5 | 太低会卡顿，太高会抖动 |
| 帧率 | 50帧 | 竖屏高帧率更流畅 |
| 负面提示词 | 见上方 | 必须填 |

## 八、移动端竖屏观看优化

### 8.1 竖屏观看特性

- **握持方向**：手机竖直，拇指在底部 20% 区域
- **视觉重心**：眼睛在画面上 1/3 处最舒适
- **单手操作**：底部 20% 是互动区（点赞/评论/转发）
- **环境光**：户外/室内，屏幕亮度自动调节

### 8.2 提示词优化（移动端）

```
手机屏显示优化，高对比度，
室外可见，OLED优化，
底部20%留空，互动区不遮挡，
--ar 9:16
```

### 8.3 字体与字幕

竖屏视频字幕位置：
- **顶部 10%**：标题字幕
- **底部 15%**：对话字幕（**不能占用最底部 5%**，会被点赞按钮遮挡）

提示词：
```
底部留白15%用于字幕，
最底部5%留空（互动按钮区），
--ar 9:16
```

## 九、质量检查（Seedance 竖屏）

### 9.1 生成前检查

- [ ] 参考图是否为 9:16？
- [ ] 提示词是否包含 `--ar 9:16`？
- [ ] 是否指定了眼睛位置？
- [ ] 是否指定了底部留白？
- [ ] 负面提示词是否填写？

### 9.2 生成后检查

- [ ] 画幅是否为 9:16（无黑边）？
- [ ] 眼睛是否在 1/3 处？
- [ ] 人脸是否变形？
- [ ] 底部 20% 是否为空（或被字幕占用但不遮挡互动区）？
- [ ] 在手机上播放是否清晰？
