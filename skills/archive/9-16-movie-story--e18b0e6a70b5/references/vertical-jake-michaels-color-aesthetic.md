# Jake Michaels 色彩美学（竖屏 9:16 版）

> **适用**：竖屏影视项目的 Jake Michaels 色彩美学设计  
> **核心**：9:16 画幅下的色彩美学、竖屏色彩系统、手机端优化

---

## Jake Michaels 色彩美学基础（竖屏版）

### 横屏 vs 竖屏色彩美学

| 维度 | 横屏 16:9 | 竖屏 9:16 |
|------|------------|------------|
| **色彩占比** | 任意 | 避免顶部 20% |
| **色彩位置** | 任意 | 中心稳定区 |
| **色彩对比** | 任意 | 中心高对比 |
| **色彩情绪** | 任意 | 眼睛位置强调 |

---

## 竖屏色彩美学系统

### 1. 主色系统（60-70%）
```
Primary Color System (60-70%):
- 背景/服装主色
- 位置：画面大部分区域
- 竖屏适配：避免顶部 20%（状态栏区域）
```

**色彩情绪映射**：
| 主色 | 情绪 | 竖屏适配 |
|------|------|----------|
| **深红** | 愤怒、权力 | 避免顶部 20% |

| **深紫** | 恐惧、神秘 | 避免顶部 20% |
| **暖黄** | 喜悦、温暖 | 中心稳定区 |
| **冷绿** | 焦虑、不安 | 避免顶部 20% |
| **中性灰** | 平静、日常 | 中心稳定区 |

### 2. 辅色系统（20-30%）
```
Secondary Color System (20-30%):
- 道具/环境辅色
- 位置：画面小区域
- 竖屏适配：避免底部 20%（字幕区域）
```

**辅色搭配**：
| 主色 | 辅色 | 竖屏适配 |
|------|------|----------|
| **深红** | 黑、金 | 避免底部 20% |

| **冷绿** | 灰、白 | 避免底部 20% |
| **中性灰** | 白、蓝 | 中心稳定区 |

### 3. 强调色系统（5-10%）
```
Accent Color System (5-10%):
- 光影/细节强调色
- 位置：中心稳定区（人脸/主体）
- 竖屏适配：眼睛位置强调
```

**强调色搭配**：

## 竖屏色彩美学三阶段演变

### 阶段 1：冷色调（<20% 进度）
```
Cool Tone (Progress <20%):
- 主色：冷蓝灰 (#2A3B4A)
- 辅色：深红 (#8B0000)、黑 (#0A0A0A)
- 强调色：烛火黄 (#FFA500)
- 适用：压抑、紧张、冲突
```

**提示词关键词**：
```
cool blue-gray color palette, desaturated,
cold tone, 9:16 frame,
color grading: cool tones
```

### 阶段 2：暖色调（30-40% 进度）
```
Warm Tone (Progress 30-40%):
- 主色：金琥珀 (#C8A03C)
- 辅色：暖橙 (#FF8C00)、深红 (#8B0000)
- 强调色：烛火黄 (#FFA500)
- 适用：希望、转折、情感
```

**提示词关键词**：
```
warm amber color palette, golden hue,
warm tone, 9:16 frame,
color grading: warm tones
```

### 阶段 3：对比色调（>60% 进度）
```
Contrast Tone (Progress >60%):
- 主色：金 (#C8A03C) + 蓝 (#2A3B4A)
- 辅色：深红 (#8B0000)、黑 (#0A0A0A)
- 强调色：烛火黄 (#FFA500)
- 适用：高潮、冲突、结局
```

**提示词关键词**：
```
gold and blue contrast, color contrast,
9:16 frame, cinematic color grading,
color grading: high contrast
```

## 竖屏色彩美学检查清单

### ✅ 必选要素
- [ ] 主色已定义（60-70%）

- [ ] 竖屏适配已考虑（避免顶部/底部 20%）
- [ ] 眼睛位置已强调（强调色在眼睛位置）

### ✅ 进阶优化
- [ ] 使用三阶段色彩演变（冷→暖→对比）
- [ ] 使用竖屏专属色彩（避免顶部/底部 20%）
- [ ] 使用眼睛位置强调（强调色在眼睛位置）
- [ ] 使用中心稳定区高对比
- [ ] 使用电影感色彩梯度（color grading）

## 总结

竖屏色彩美学 = **横屏色彩美学** + **9:16 画幅适配** + **眼睛位置强调**

**核心差异**：
1. 主色避免顶部 20%（状态栏区域）
2. 辅色避免底部 20%（字幕区域）
3. 强调色在眼睛位置（y≈0.33）
4. 提示词必须含 `vertical frame, 9:16`
