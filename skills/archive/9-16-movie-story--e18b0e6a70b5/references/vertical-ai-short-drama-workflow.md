# AI 短片工作流（竖屏 9:16 版）

> **适用**：竖屏 AI 短片的完整工作流  
> **核心**：9:16 画幅下的 AI 短片制作、竖屏适配、手机端优化

---

## AI 短片工作流基础（竖屏版）

### 横屏 vs 竖屏 AI 短片工作流

| 阶段 | 横屏 16:9 | 竖屏 9:16 |
|------|------------|------------|
| **1. 剧本** | 3-5 分钟 | 1-3 分钟 |
| **2. 分镜** | 8-15 镜 | 8-15 镜（相同） |
| **3. 提示词** | `--ar 16:9` | `--ar 9:16` |
| **4. 生成** | Midjourney/Runway | Midjourney/Seedance/Kling |
| **5. 剪辑** | Premiere/DaVinci | CapCut/Premiere（竖屏） |
| **6. 字幕** | 底部 10% | 底部 20% |

---

## 竖屏 AI 短片工作流（6 阶段）

### 阶段 1：剧本改编（竖屏适配）
```
1. 时长压缩：横屏 3-5 分钟 → 竖屏 1-3 分钟
2. 镜头数增加：8-15 镜/分钟（快切）
3. 对话减少：对话占比 <30%（用动作和情绪推动）
4. 视觉爆点：每集至少 1 个视觉爆点（巴掌、摔倒、拥抱等）
```

**输出**：竖屏适配剧本（1-3 分钟，8-15 镜/分钟）

### 阶段 2：分镜生成（使用 `9-16-movie-story` 技能）
```
1. 调用 `9-16-movie-story` 技能
2. 输入：竖屏适配剧本
3. 输出：完整竖屏分镜脚本（含提示词）
```

**输出**：竖屏分镜脚本（Markdown + 提示词）

### 阶段 3：AI 生成（竖屏版）
```
图像生成：
- 工具：Midjourney v6/v7（`--ar 9:16`）
- 提示词：含 `--ar 9:16` + 竖屏构图关键词

视频生成：
- 工具：Seedance 2.0 / Kling 3.0 / Runway Gen-3
- 提示词：含 `--ar 9:16` + 竖屏构图关键词
- 时长：1-3 秒/镜（快切）
```

**输出**：AI 生成图像/视频（9:16 画幅）

### 阶段 4：实拍补充（竖屏适配）
```
1. 手机拍摄：使用 iPhone/Android 拍摄竖屏素材（9:16）
2. 绿幕拍摄：拍摄人物表演，后期合成 AI 背景
3. 道具/场景：实拍关键道具/场景，AI 生成辅助
```

**输出**：实拍竖屏素材（9:16 画幅）

### 阶段 5：后期合成（竖屏版）
```
1. 剪辑：使用 CapCut/Premiere/DaVinci 剪辑竖屏素材
2. 合成：AI 生成 + 实拍混合剪辑
3. 调色：统一色彩风格（三阶段色彩演变）
4. 字幕：添加竖屏字幕（底部 20% 区域，60-80px）
```

**输出**：竖屏短片（9:16 画幅，1-3 分钟）

### 阶段 6：导出与发布（竖屏版）
```
导出设置：
- 分辨率：1080x1920 (FHD+) 或 1440x2560 (QHD+)
- 帧率：24fps（电影感）或 30fps（流畅感）
- 编码：H.264 / H.265
- 比特率：10-20 Mbps

发布平台：
- 抖音 / 快手（1-3 分钟）
- Reels / Shorts（1-3 分钟）
- 小红书（1-5 分钟）
```

**输出**：竖屏短片（发布就绪）

## 总结

竖屏 AI 短片工作流 = **横屏 AI 短片工作流** + **9:16 画幅适配** + **手机端优化**

**核心要点**：
1. 剧本时长 1-3 分钟（而非 3-5 分钟）
2. 镜头数 8-15 镜/分钟（快切）
3. 对话占比 <30%（用动作和情绪推动）
4. 每集至少 1 个视觉爆点
5. 所有提示词含 `--ar 9:16`
6. 字幕在底部 20% 区域（60-80px）
