# 分镜时间码拆解（竖屏 9:16 版）

> **适用**：竖屏分镜脚本的时间码拆解  
> **核心**：9:16 画幅下的时间码、竖屏节奏、手机端优化

---

## 时间码基础（竖屏版）

### 横屏 vs 竖屏时间码

| 维度 | 横屏 16:9 | 竖屏 9:16 |
|------|------------|------------|
| **单镜时长** | 2-4 秒 | 1-3 秒（快切） |
| **剪辑节奏** | 舒缓 | 快切 |
| **时间码格式** | `HH:MM:SS:FF` | `HH:MM:SS:FF`（相同） |
| **帧率** | 24fps / 30fps | 24fps / 30fps（相同） |

---

## 竖屏分镜时间码格式

### 标准格式
```
HH:MM:SS:FF
HH   = 小时（00-99）
MM   = 分钟（00-59）
SS   = 秒（00-59）
FF   = 帧（00-23 @24fps / 00-29 @30fps）
```

### 竖屏分镜时间码示例
```
00:00:00:00  - 00:00:02:00  SHOT 001 (2.0s)
00:00:02:00  - 00:00:04:00  SHOT 002 (2.0s)
00:00:04:00  - 00:00:05:00  SHOT 003 (1.0s)
00:00:05:00  - 00:00:07:00  SHOT 004 (2.0s)
...
```

---

## 竖屏分镜时间码拆解流程

### 阶段 1：剧本时长估算
1. **总时长**：估算剧本总时长（分钟）
2. **镜头数**：总时长 × 8-15 镜/分钟（竖屏快切）
3. **平均时长**：总时长 / 镜头数（1-3 秒）

### 阶段 2：时间码分配
1. **起始时间码**：`00:00:00:00`
2. **逐镜分配**：根据每个镜头的时长，计算结束时间码
3. **累计时间码**：确保时间码连续，无重叠或间隙

### 阶段 3：时间码验证
1. **总时长验证**：所有镜头时长之和 = 剧本总时长
2. **时间码连续性**：每个镜头的起始时间码 = 上一个镜头的结束时间码
3. **帧率一致性**：所有时间码使用相同帧率（24fps 或 30fps）

## 竖屏分镜时间码拆解检查清单

### ✅ 必选要素
- [ ] 剧本总时长已估算
- [ ] 镜头数已确定（8-15 镜/分钟）
- [ ] 平均时长已计算（1-3 秒/镜）
- [ ] 时间码已分配（起始时间码 `00:00:00:00`）
- [ ] 时间码已验证（总时长/连续性/帧率一致性）

### ✅ 进阶优化
- [ ] 使用 24fps（电影感）或 30fps（流畅感）
- [ ] 使用时间码计算工具（Excel/Python/在线工具）
- [ ] 使用分镜软件（Studio Binder / Shot Designer）
- [ ] 使用时间码标注软件（DaVinci Resolve / Premiere Pro）
- [ ] 使用竖屏分镜模板（9:16 时间码标注）

---

## 总结

竖屏分镜时间码拆解 = **横屏分镜时间码拆解** + **9:16 节奏适配** + **快切剪辑**

**核心差异**：
1. 单镜时长 1-3 秒（而非 2-4 秒）
2. 镜头数 8-15 镜/分钟（而非 2-4 镜/分钟）
3. 剪辑节奏快切（而非舒缓）
4. 时间码格式相同（`HH:MM:SS:FF`）
