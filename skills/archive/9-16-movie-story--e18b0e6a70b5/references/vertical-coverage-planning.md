# 竖屏覆盖拍摄规划 (Vertical Coverage Planning & Spatial Locks)

> 专为 9:16 竖屏画幅重构的覆盖拍摄规划与空间坐标锁定协议。原版 16:9 覆盖策略直接用于竖屏会导致构图失衡、空间混乱、平台裁剪。

---

## 一、竖屏覆盖核心差异

### 1.1 原版 vs 竖屏版对比

| 概念 | 16:9 横屏 | 9:16 竖屏 | 原因 |
|------|-----------|-----------|------|
| 轴线 | 水平线（180°法则） | **垂直线/斜线** | 竖屏空间关系 |
| Master Shot | 全景建立空间 | 全身景，脚贴底 | 竖屏构图 |
| Coverage 数量 | 5-8 镜 | **3-4 镜** | 竖屏单镜信息密度高 |
| 空间坐标 | XZ 平面 | **XYZ 三维**（Y 轴更重要） | 竖屏垂直空间 |
| 180°法则 | 严格 | **严格**（轴线可以是斜线） | 空间连续性 |

### 1.2 竖屏 Master Axis（主轴）定义

**横屏**：Master Axis C1 是水平线（A → B）
**竖屏**：Master Axis C1 是**垂直线或斜线**

```
竖屏 Master Axis C1 定义（示例）：

人物 A (陆雪) 在上 1/3 处
           ↓
           │ C1 (斜线，从上到下)
           ↓
人物 B (王勃) 在下 1/3 处
```

**Master Axis C1 类型（竖屏）：**
1. **垂直线**：A 在正上方，B 在正下方（权力关系明确）
2. **斜线（45°）**：A 在右上，B 在左下（对话场景最常用）
3. **S 形曲线**：三人对话（A 上，B 中，C 下）

## 二、竖屏空间坐标系

### 2.1 坐标系定义（竖屏重构）

```
Y轴（垂直）
  ↑
  │   [画面顶部 0%]
  │     ┌─────────────────┐
  │     │  上 1/3         │ ← 眼睛理想位置
  │     ├─────────────────┤
  │     │  中 1/3         │ ← 口鼻/下巴
  │     ├─────────────────┤
  │     │  下 1/3         │ ← 留空 20%（互动区）
  │     └─────────────────┘
  │   [画面底部 100%]
  │
  └──────────────────────→ X轴（水平）

Z轴（垂直屏幕）：从观者向里
  Z+：远离观者
  Z-：靠近观者（推进镜头）
```

### 2.2 空间坐标标注（竖屏版）

| 标注 | 含义 | 竖屏示例 |
|------|------|---------|
| `[C1] ΔX=+2m` | X 轴移动 +2m | 人物右移 2m |
| `[C1] ΔY=+1m` | Y 轴移动 +1m（**更重要**） | 人物上移 1m（更权威） |
| `[C1] ΔZ=-0.5m` | Z 轴移动 -0.5m | 推进 0.5m（特写） |
| `[C1] ΔY=-1.5m` | Y 轴移动 -1.5m | 人物下移 1.5m（屈服） |

### 2.3 空间坐标与权力关系（竖屏专属）

**竖屏可以利用垂直位置表示权力**：

| 位置 | 含义 | 示例 |
|------|------|------|
| **上 1/3 处** | 权威/主导 | 陆雪（休书持有者） |
| **中心** | 中立/过渡 | 中间人 |
| **下 1/3 处** | 屈服/弱势 | 王勃（跪拜者） |

**提示词**：
```
power dynamics, character A at upper 1/3, character B at lower 1/3,
vertical framing, 9:16 aspect ratio
```

## 三、竖屏覆盖策略（Coverage Strategy）

### 3.1 对话场景最小覆盖（竖屏 3 镜方案）

**横屏**：Master + 2x Single + OTS + Insert = 5 镜
**竖屏**：Master + 2x Single = **3 镜**（OTS 和 Insert 可合并）

```
镜1: 2人全身（垂直构图，A 在上，B 在下）
      ↓ Master Shot (建立权力关系)
镜2: A 腰部以上（眼睛在 1/3）
      ↓ Single A
镜3: B 腰部以上（眼睛在 1/3）
      ↓ Single B
```

**为什么竖屏可以少 2 镜？**
- OTS（过肩镜头）：竖屏单镜可以同时展示两人（A 在上 1/3，B 在下 1/3）
- Insert（插入镜）：竖屏特写信息密度高，可以合并到 Single 中

### 3.2 竖屏覆盖镜头类型

| 镜头类型 | 横屏 16:9 | 竖屏 9:16 |
|---------|-----------|-----------|
| **Master Shot** | 全景建立空间 | 全身景，脚贴底，头顶留白 15% |
| **Single (正)** | 胸部以上 | 腰部以上，眼睛在 1/3 |
| **Single (侧)** | 侧面轮廓 | 3/4 侧面（避免纯侧面） |
| **OTS (过肩)** | 过肩镜头 | 过肩+斜下（A 在上，B 在下，同框） |
| **Insert** | 物体特写 | 物体竖直构图（避免横放） |
| **Two-Shot** | 两人同框 | 垂直构图（A 上 B 下） |

### 3.3 竖屏覆盖规划表（模板）

```
| 场景 | Master Axis | 覆盖镜头 | 空间坐标 | 提示词关键词 |
|------|-------------|-----------|-----------|-------------|
| 偏殿对话 | C1 (陆雪→王勃, 斜线) | Master + 2x Single | ΔY=+1m (A), ΔY=-1.5m (B) | `vertical two-shot, A at 1/3, B at lower 1/3` |
```

## 四、竖屏 180°法则（重构版）

### 4.1 轴线定义（竖屏）

**横屏**：轴线是水平线（A ←→ B），180° 法则禁止越轴
**竖屏**：轴线是**垂直线或斜线**（A ↑↓ B），180° 法则依然有效

```
竖屏轴线示例（斜线）：

    陆雪 (A)
       ↘
        C1 (轴线)
       ↙
    王勃 (B)

✅ 正确：摄影机在 C1 的 0-180° 半圆内
❌ 错误：摄影机越过 C1 到对面（越轴）
```

### 4.2 越轴处理（竖屏版）

**横屏**：越轴需要插入"中性镜头"或"运动越轴"
**竖屏**：越轴可以更**视觉化**（利用垂直位置变化）

| 越轴方式 | 横屏 | 竖屏（更直观） |
|---------|------|----------------|
| 中性镜头 | 插入物体特写 | 插入**垂直运动**（雨水从上落下） |
| 运动越轴 | 人物走过镜头 | 人物**起身/跪下**（垂直运动） |
| 人物运动 | 横向走过 | **纵向走过**（从下往上走） |

### 4.3 越轴提示词（竖屏）

```
# 故意越轴（权力反转）
crossing the axis, POV shift, vertical framing,
character A moves from upper 1/3 to lower 1/3,
power reversal, 9:16 aspect ratio
```

## 六、竖屏空间连续性检查

### 6.1 空间连续性必检项

- [ ] Master Axis C1 是否在全场景保持一致？
- [ ] 人物 Y 轴位置是否符合权力关系（上位者在上）？
- [ ] 180° 法则是否遵守（轴线是斜线）？
- [ ] 越轴是否有合理叙事理由（权力反转）？
- [ ] 空间坐标是否每个镜头都标注？

### 6.2 竖屏专属检查

- [ ] 眼睛位置是否全场景一致（都在 1/3 处）？
- [ ] 头顶留白是否全场景一致（15%）？
- [ ] 底部 20% 是否全场景留空？
- [ ] 人物 A (上位) 是否始终在上 1/3 处？
- [ ] 人物 B (下位) 是否始终在下 1/3 处（除非权力反转）？

## 八、竖屏覆盖质量自检

### 8.1 六轮自检（覆盖规划专项）

1. **剧本覆盖度**：是否 100% 覆盖剧本内容？
2. **视觉一致性**：眼睛位置/头顶留白/底部留空是否全场景一致？
3. **镜头语法**：覆盖镜头是否 ≥3 个（Master + 2x Single）？
4. **AI 提示词质量**：是否全部包含 `--ar 9:16` 和 `vertical framing`？
5. **Coverage & Spatial**：空间坐标是否每个镜头都标注？Master Axis 是否一致？
6. **整体验收**：在手机上预览分镜，空间关系是否连贯？

### 8.2 常见问题与修正

| 问题 | 原因 | 修正 |
|------|------|------|
| 空间混乱 | Master Axis 不清晰 | 明确 C1 是斜线，标注每个镜头的空间坐标 |
| 眼睛位置不一致 | 未指定垂直位置 | 所有提示词加 `eyes at upper 1/3` |
| 底部被 UI 遮挡 | 未留空 20% | 所有提示词加 `bottom 20% empty` |
| 越轴生硬 | 未用竖屏专属越轴方式 | 用"垂直运动"（起身/跪下）作为越轴过渡 |
