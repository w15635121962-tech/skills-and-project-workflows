# 投流场面设计参考

## 高频情绪

愤怒、心疼、爽感、焦虑、猎奇、危险暧昧、恐惧、后悔、期待、争议。

## 高频母题

公开羞辱、亲近者背叛、二选一放弃、身份反转、误会惩罚、亲情偏心、抢功顶替、禁忌暧昧、生死倒计时、真相公开处刑、死亡归来、血脉觉醒。

## 视觉放大器

高位/低位、主位/边缘、人群起哄或沉默、手机拍摄、直播屏、突然安静、集体转向、门打开、信物特写、协议/鉴定/遗嘱/股权书/药瓶/监控/徽章等道具。

## 动作化原则

不要让人物站定互吵。让台词同时伴随摘戒指、撕文件、推门、阻拦、抢物、播放证据、转身离开、关门、屏幕切换、危险逼近或权力位置变化。反派应利用规则、证据、亲情、舆论或主角善良，而不只是尖叫。

## 五种万能公式

1. 公开羞辱：重要场合 + 亲近者背叛 + 全场站反派 + 主角失去身份/关系 + 关键人物出现 + 打脸前切断。
2. 虐恋后悔：主角牺牲 + 爱人误会 + 爱人公开伤害 + 主角离开 + 真相出现 + 追赶已晚。
3. 二选一：两人遇险 + 爱人选择别人 + 主角亲眼看见 + 独自求生 + 身份/能力线索觉醒。
4. 身份打脸：主角被当底层 + 反派连续羞辱 + 特殊信物出现 + 高位人物赶到 + 众人态度逆转。
5. 真相公开：伪证公布 + 全场指责 + 完整记录出现 + 反派阻止 + 更大秘密露头 + 答案前切断。

## 题材转译提示

- 豪门/家庭：婚礼换人、亲子鉴定、继承权、孩子或房产争夺。
- 职场/娱乐：成果被抢、公开领奖、直播事故、原始记录或后台证据。
- 校园/青春：全校拒绝、作弊陷害、公开误会；暧昧表达保持成年且非露骨。
- 奇幻/狼人吸血鬼：命定印记、公开拒绝、血脉觉醒、兽化危机；锁定唯一身体和可见尺度。
- 古装/宫廷：滴血认亲、毒酒调换、审判、政变、祭台或王位继承。
- 医疗/灾难/悬疑：二选一、药物/名额、倒计时、监控或死者留下的证据；避免无必要的血腥细节。

## 终点

投流素材的最后一帧应停在“答案已可感知、但尚未证实”的位置：门将打开、证据将播放、关键人物刚出现、反派表情凝固、主角刚睁眼或信物刚亮起。
