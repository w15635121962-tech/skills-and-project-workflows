# 剧梦整集制作（按用户示范）

## 输入（本机连接文件夹 剧梦全自动化生成）
- 剧本：01自动化项目素材/<剧名>/EPxx/EPxx剧本.md；镜头表 玻璃箱里的神明分镜拆解/全剧镜头表.xlsx；表演描述词 演员表演方案/*.md；灯光方案 02故事策划/<剧名>/灯光和影调方案.md；构图标准 分镜构图参数执行标准.md。
- 旁白录音：旁白录音时长/EPxx/xx-N.mp3|wav —— 用 ffprobe 读时长，这是分镜时长的唯一来源。
- 本集角色/场景图：EPxx/人物图、EPxx/场景图；道具在平台素材库「道具」页。

## 1. 定时长
1. ffprobe 读取每条旁白音频时长。
2. 把剧本英文句按顺序切成与音频条数相同的连续段（按字符比例对齐），再按字符比例把每条音频时长分给该段的各镜，取 0.5s。
3. 单镜可超过 6s（完整长句），组时长 ≤30s，平台最短 4s。

## 2. 写提示词（Format C V2.6 + 用户项目覆盖）
- 分组：同空间+同时间+同主光方向色温。组头依次：【EPxx-Gnn｜标题】→【组头｜固定画质词与光影基调】固定画质词 / 强制要求（皮肤）/ 本项目镜头参数覆盖（保留 ARRI Alexa 65 质感、竖版 9:16、180 度快门；85mm 为人像基线，各镜用下列全画幅等效焦段，不得理解为画内变焦）/ 光影基调 / 节奏结构（组型、镜数、总时长、各镜时长；按本地单条音总长分配画面承载，精确音画对齐在剪辑阶段处理）/ 景别循环 / 视觉动线 / 引用锁。
- 引用锁：列出本组 @角色 @场景 @道具；写明“角色参考只提取对应单人身份与服饰，禁止把卡片文字、分格和多视图复制进视频”；场景/道具图只用于什么、剧情需要的补全写清楚。室内卧室戏引用卧室图（正打/反打），客厅戏引用客厅图。
- 镜头头：【shot N｜人物｜景别｜机位｜运动｜焦段｜duration: X.Xs】，再写 11 字段：叙事任务｜镜头｜画面｜视觉引导｜微表演（加欧美肢体语言）｜对白反应｜人物背景融合｜光影细节（面光清晰、皮肤细腻）｜音频｜运动强度｜负面提示词。
- 画面字段：每个角色在本镜首次出现处插入 @角色图（如“@Aria深蓝色星空长裙.png Aria左、@Hades黑色西装.png Hades右”）。
- 音频：旁白/独白一律不写进生成提示词。无对白镜：“无台词；所有人闭口，禁止生成口型。无旁白、无音乐、无生理音效。仅保留与本镜可见动作对应的轻微衣料/接触环境声。”有对白镜：“X英文原台词："…"；仅X生成说话口型，其他人闭口。无旁白、无音乐。”
- 负面提示词末尾固定：禁止换脸、服装互换、左右互换、跳轴、道具复制；禁止粗颗粒皮肤、蜡感、塑料感、浮油；禁止眼球自发光、与观众对视、打破第四面墙；禁止字幕、水印、旁白、音乐、非说话者口型。
- 平台敏感词替换：血→暗红液珠/红润，高潮→峰值，去掉 欲望/裸/情欲/刀片/自杀/枪/尸。
- 存稿：提示词组/分集/EPxx_<标题>_V2.6.md 与 平台填充/EPxx_V2.6_平台填充.json。

## 3. 平台填写（用户示范的做法）
1. 在剧梦项目页选集下拉里找到本集；没有就「新增剧集」并改名“第xx集”；按组数在时间线「+」新增分镜。
2. 每个分镜：粘贴本组提示词。
3. 把所有 @xxx.png 纯文本换成真引用：光标放在该处输入“@”，在「选择参考素材」弹窗里从 当前引用 / 角色 / 场景 / 道具 选中对应卡片，再删掉残留的纯文本名。引用锁行和各镜画面里的角色首现处都要换。
4. 自动化等价做法：用 TipTap 编辑器 setContent 写入 inline-mention 节点（value=`${imageId}-1`，extraProps 含 materialId/sourceMaterialId/materialType/url/名称），素材 id 从 /gw/storyboard/api/projectLibraryList（header authorization=localStorage.token；type 1 角色/2 场景/3 道具）取。
5. 核对：顶部引用卡片 = 本组应引用的角色+场景+道具，且无“请选择”、无“检测出敏感词”；模型 九梦 2.5 Pro、480P、时长=组时长（参数弹窗「按秒数」输入）。
6. 点「生成」；确认分镜历史出现生成中任务后再进下一组。切分镜前核对 URL 的 storyBoardId，防止写错分镜。

## 4. 收尾
- 记录每组 storyBoardId、时长、消耗积分；把提示词文件写回连接文件夹。
- 用户说“不要停”时连续做完所列各集，只在登录失效、积分不足、平台报错时停下汇报。
