# 电影参考指南（竖屏 9:16 版）

> **适用**：竖屏影视项目的电影感参考  
> **核心**：9:16 画幅下的电影感、竖屏构图参考、手机端观影体验

---

## 电影感要素（竖屏版）

### 横屏 vs 竖屏电影感

| 要素 | 横屏 16:9 | 竖屏 9:16 |
|------|------------|------------|
| **画幅** | 2.39:1 (变形宽银幕) | 9:16 (竖屏全屏) |
| **构图** | 左右平衡 | 上下平衡 |
| **视线** | 水平 | 垂直/对角线 |
| **运镜** | 左右摇/推拉 | 上下摇/推拉 |
| **焦点** | 多人物 | 单人物（人脸） |
| **字幕** | 可选 | 必须（底部 20%） |

## 竖屏电影感构图

### 1. 中心构图（电影感）
```
Center Composition (Cinematic Vertical):
- 主体在画面中心（x=0.5, y=0.4）
- 眼睛在画面上 1/3（y≈0.33）
- 头顶留 15% 呼吸空间（y≈0.15）
- 下巴到画面底部留 20%（y≈0.8）
- 左右留 10% 呼吸空间（x≈0.1, x≈0.9）
```

**电影感关键词**：
```
centered composition, vertical cinematography, 9:16 frame,
eyes at upper third, rule of thirds vertical,
shallow depth of field, bokeh background,
cinematic lighting, Arri Alexa 65, Cooke Anamorphic
```

### 2. 三分法（电影感）
```
Rule of Thirds (Vertical Cinematic):
- 画面分成 3x3 网格
- 眼睛在上横线上（y≈0.33）
- 鼻子在中心横线上（y≈0.5）
- 嘴巴在下横线上（y≈0.66）
- 人脸在左/右竖线上（x≈0.33 或 x≈0.66）
```

**电影感关键词**：
```
rule of thirds vertical, eyes at upper third,
vertical framing, 9:16 cinematic,
off-center composition, dynamic vertical framin
```

### 3. 满屏构图（电影感）
```
Full-Frame Composition (Cinematic Vertical):
- 主体占满画面（上下贴合）
- 头顶留 5% 呼吸空间（y≈0.05）
- 下巴留 5% 呼吸空间（y≈0.95）
- 左右留 10% 呼吸空间（x≈0.1, x≈0.9）
```

**电影感关键词**：
```
full-frame vertical, close-up, extreme close-up,
fills screen, 9:16 full frame,
intense gaze, emotional impact
```

## 竖屏电影感运镜

### 1. Push-in（推）
```
Push-in (Vertical Adaptation):
- 缓慢推入，强调情绪
- 速度：慢（2-3 秒）
- 方向：垂直推入（从脚到头）或中心推入
- 电影感：浅景深，背景虚化
```

**提示词关键词**：
```
slow push-in, vertical push-in, cinematic push-in,
shallow depth of field, bokeh background,
emotional impact, intense
```

### 2. Pull-out（拉）
```
Pull-out (Vertical Adaptation):
- 拉出全景，展示环境
- 速度：中（1-2 秒）
- 方向：垂直拉出（从头到脚）或全景拉出
- 电影感：深景深，环境清晰
```

**提示词关键词**：
```
slow pull-out, vertical pull-out, cinematic pull-out,
deep depth of field, full environment visible,
establishing shot, wide shot
```

### 3. Tilt（俯仰）
```
Tilt (Vertical Adaptation):
- 上下摇摄，强调权力关系
- 速度：慢（1-2 秒）
- 方向：从下往上（权力）/ 从上往下（脆弱）
- 电影感：动态构图，情绪变化
```

**提示词关键词**：
```
vertical tilt, tilt up, tilt down,
low angle, high angle,
power dynamics, emotional shift
```

## 竖屏电影感参考影片

### 1. 《纸房子》 (Money Heist) - 竖屏版
- **风格**：快节奏，高对比，情绪爆发
- **构图**：中心构图，眼睛在画面上 1/3
- **光影**：烛光/顶光，强对比
- **运镜**：手持 + 快切

### 2. 《怪奇物语》 (Stranger Things) - 竖屏版
- **风格**：复古，温暖，神秘
- **构图**：三分法，眼睛在上横线
- **光影**：窗户光/烛光，柔和
- **运镜**：推拉 + 摇摄

### 3. 《王冠》 (The Crown) - 竖屏版
- **风格**：古典，庄重，权力
- **构图**：中心构图，对称
- **光影**：顶光/侧光，戏剧性
- **运镜**：缓慢推拉，静态构图

## 竖屏电影感检查清单

### ✅ 必选要素
- [ ] 画幅 9:16（1080x1920）
- [ ] 眼睛在画面上 1/3（y≈0.33）
- [ ] 人脸在中心稳定区（x:0.25-0.75, y:0.25-0.65）
- [ ] 光影有电影感（chiaroscuro/Rembrandt/顶光/底光）
- [ ] 运镜有电影感（推拉/俯仰/手持）

- [ ] 使用烛光/窗户光/顶光等电影感光影

## 总结

竖屏电影感 = **横屏电影感** + **9:16 构图适配** + **手机端优化**

**核心差异**：
1. 眼睛在画面上 1/3（而非水平中心）
2. 人脸在中心稳定区（x:0.25-0.75, y:0.25-0.65）
3. 运镜以垂直运动为主（推拉/俯仰）
4. 光影强调单光源（烛光/顶光/底光）
5. 浅景深 + 胶片感
