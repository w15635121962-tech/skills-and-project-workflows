# Eric Vannynatten 9 条规则（竖屏 9:16 版）

> **适用**：竖屏影视项目的 Eric Vannynatten 9 条规则  
> **核心**：9:16 画幅下的 9 条规则、竖屏适配、手机端优化

---

## Eric Vannynatten 9 条规则基础（竖屏版）

### 横屏 vs 竖屏 9 条规则

| 规则 | 横屏 16:9 | 竖屏 9:16 |
|------|------------|------------|
| **1. 眼睛位置** | 水平中心 | 画面上 1/3 |
| **2. 人脸位置** | 中心稳定区 | 中心稳定区（相同） |
| **3. 头顶留白** | 15% | 15%（相同） |
| **4. 下巴留白** | 20% | 20%（相同） |
| **5. 视线方向** | 水平（左/右） | 垂直（上/下）或对角线 |
| **6. 构图** | 左右平衡 | 上下平衡 |
| **7. 运镜** | 左右摇/推拉 | 上下摇/推拉 |
| **8. 剪辑节奏** | 2-4 秒/镜 | 1-3 秒/镜（快切） |
| **9. 提示词** | `--ar 16:9` | `--ar 9:16` |

## 竖屏 9 条规则

### 规则 1：眼睛位置在画面上 1/3
```
Eyes at Upper Third:
- 眼睛位置在画面 y≈0.33 处
- 适用：所有镜头（全景/中景/特写）
- 原因：竖屏观看时，眼睛在画面上 1/3 最舒适
```

### 规则 2：人脸在中心稳定区
```
Face in Center Stable Zone:
- 人脸在 x:0.25-0.75, y:0.25-0.65
- 适用：所有镜头（全景/中景/特写）
- 原因：避免人脸被裁剪或位置尴尬
```

### 规则 3：头顶留 15% 呼吸空间
```
Head Room 15%:
- 头顶到画面上边缘留 15% 空间
- 适用：所有镜头（全景/中景/特写）
- 原因：避免头顶被裁剪
```

### 规则 4：下巴留 20% 呼吸空间
```
Chin Room 20%:
- 下巴到画面底部留 20% 空间
- 适用：所有镜头（全景/中景/特写）
- 原因：避免下巴被裁剪，且为字幕留空间
```

### 规则 5：视线方向垂直或对角线
```
Vertical or Diagonal Gaze:
- 视线方向：垂直（上←→下）或对角线（左上←→右下）
- 适用：对话镜/对视镜
- 原因：竖屏画幅，水平视线容易导致构图呆板
```

### 规则 6：构图上下平衡
```
Vertical Balance:
- 构图：上下平衡（而非左右平衡）
- 适用：所有镜头（全景/中景/特写）
- 原因：竖屏画幅，上下平衡更舒适
```

### 规则 7：运镜上下摇或推拉
```
Vertical Camera Movement:
- 运镜：上下摇（而非左右摇）或推拉
- 适用：所有运镜（推/拉/摇/俯仰）
- 原因：竖屏画幅，上下运镜更自然
```

### 规则 8：剪辑节奏快切（1-3 秒/镜）
```
Fast Cut Editing (1-3 seconds/shot):
- 剪辑节奏：1-3 秒/镜（快切）
- 适用：所有场景（对话/动作/情绪）
- 原因：竖屏观看，节奏快更吸引人
```

### 规则 9：提示词必须含 `--ar 9:16`
```
Prompt Must Include --ar 9:16:
- 提示词必须含 `--ar 9:16`
- 适用：所有 AI 生成（图像/视频）
- 原因：确保生成竖屏画幅
```

## 总结

竖屏 9 条规则 = **横屏 9 条规则** + **9:16 画幅适配** + **垂直视线**

**核心差异**：
1. 眼睛位置在画面上 1/3（而非水平中心）
2. 视线方向垂直或对角线（而非水平）
3. 构图上下平衡（而非左右平衡）
4. 运镜上下摇或推拉（而非左右摇）
5. 提示词必须含 `--ar 9:16`
