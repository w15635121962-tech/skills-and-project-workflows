# 竖屏剧本健康诊断 (Vertical Script Health Diagnosis)

> 专为 9:16 竖屏画幅重构的剧本健康诊断协议。竖屏叙事节奏更快、信息密度更高、视觉重心在垂直方向。

---

## 一、诊断维度（竖屏重构版）

### 1.1 原版 vs 竖屏版对比

| 维度 | 16:9 横屏 | 9:16 竖屏 | 变化 |
|------|-----------|-----------|------|
| 情节密度 | 正常 | **更高** | 竖屏完播率要求 |
| 视觉叙事 | 靠环境 | **靠人脸** | 竖屏人脸占比大 |
| 对白效率 | 正常 | **更高** | 竖屏字幕小，对白要精 |
| 电影语言 | 常规 | **快切** | 竖屏节奏快 2-3 倍 |
| 权力距离 | 任何 | **垂直** | 上位者在上，下位者在下 |

### 1.2 竖屏剧本六大问题

| 问题 | 横屏表现 | 竖屏表现 | 修复方案 |
|------|---------|---------|---------|
| ① 竖屏开场慢 | 前 30 秒建立 | **前 3 秒必须抓眼球** | 第一镜就是高潮/悬念 |
| ② 对白冗长 | 可接受 | **字幕小，难阅读** | 对白压缩 50% |
| ③ 权力距离缺失 | 可用镜头语言 | **垂直构图直接表达** | 上位者在上 1/3，下位者在下 1/3 |
| ④ 视觉叙事不足 | 环境交代 | **人脸特写传达** | 每镜必须有情绪特写 |
| ⑤ 节奏过慢 | 正常 | **完播率杀手** | 镜头长度减半 |
| ⑥ 平台适配缺失 | 无 | **必须考虑算法** | 每 5 秒一个钩子 |

## 二、竖屏剧本诊断清单

### 2.1 情节逻辑（竖屏版）

- [ ] **开场 3 秒**：是否有视觉冲击/悬念？
- [ ] **每 5 秒**：是否有一个"钩子"（反转/悬念/情绪高点）？
- [ ] **对白密度**：是否 ≤50% 横屏原版（竖屏字幕难阅读）？
- [ ] **视觉叙事**：是否 70% 信息靠画面传达（不是对白）？
- [ ] **节奏**：是否每镜 1-3 秒（横屏是 3-5 秒）？

### 2.2 视觉叙事审计（竖屏版）

| 审计项 | 横屏标准 | 竖屏标准 | 检查方式 |
|--------|---------|---------|---------|
| 人脸占比 | 20-40% | **40-60%** | 测量人脸在画面中占比 |
| 眼睛位置 | 任何 | **必须在 1/3 处** | 检查每个镜头构图 |
| 垂直构图 | 任何 | **必须有垂直分量** | 避免纯水平构图 |
| 底部留空 | 无 | **必须留 20%** | 检查互动区是否为空 |
| 平台 UI | 无 | **必须避开右侧/底部** | 检查抖音/Reels UI 遮挡 |

### 2.3 对白角色（竖屏版）

| 检查项 | 横屏 | 竖屏 | 修复 |
|--------|------|------|------|
| 对白长度 | 正常 | **压缩 50%** | 删减冗余对白 |
| 字幕可读性 | 任何 | **必须 100% 覆盖** | 竖屏手机扬声器差 |
| 情绪传达 | 靠对白 | **靠表情** | 增加微表情描写 |
| 停顿节奏 | 任何 | **更快** | 删减停顿描写 |

### 2.4 电影语言定义（竖屏版）

| 语言 | 横屏 | 竖屏 | 提示词适应 |
|------|------|------|-----------|
| 镜头长度 | 3-5 秒 | **1-3 秒** | `fast cut, 1-2 seconds per shot` |
| 转场 | 叠化/擦除 | **硬切为主** | `hard cut, fast paced` |
| 构图 | 三分法 | **垂直三分法** | `vertical rule of thirds, eyes at 1/3` |
| 运镜 | 任何 | **必须有垂直分量** | `vertical camera movement` |
| 色彩 | 任何 | **高饱和/高对比** | `high saturation, OLED optimized` |

## 三、竖屏剧本优化措施

### 3.1 开场 3 秒优化

**问题**：横屏剧本前 30 秒用于建立空间/人物，竖屏用户 3 秒内划走。

**方案**：
```
横屏原版：
镜001： Establishing shot，周王府偏殿全景，10秒

竖屏重构版：
镜001：王勃脸部特写，暴雨浇脸，眼睛猛然睁开，1秒
         ↓ 硬切
镜002：王勃跪拜，Flash-forward 闪回（被贬场景），0.5秒
         ↓ 硬切
镜003：陆雪冷笑，休书入画，1秒
```

### 3.2 对白压缩（竖屏版）

**问题**：竖屏字幕小，对白太长用户来不及看。

**方案**：
```
横屏原版（30 字）：
陆雪："王勃，你的《斗鸡檄》震动京城，可曾想过，"
     "有些文字，写了便是死罪？"

竖屏重构版（15 字）：
陆雪："《斗鸡檄》——你可知，写便是死？"
```

### 3.3 权力距离可视化（竖屏专属）

**问题**：横屏可以用镜头距离表示权力，竖屏用**垂直位置**更直接。

**方案**：
```
上位者（陆雪）：
  眼睛在画面上 1/3 处（标准）
  或：人物在下 1/3，俯拍（压迫感）

下位者（王勃）：
  眼睛在画面下 1/3 处（屈服）
  或：人物在上 1/3，仰拍（求助/仰望）
```

### 3.4 视觉叙事增强（竖屏版）

**问题**：竖屏人脸占比大，环境信息少。

**方案**：
1. **用道具传达信息**（竖屏特写更清晰）
2. **用微表情传达情绪**（竖屏人脸大，微表情可见）
3. **用光影传达氛围**（竖屏高对比更明显）

```
横屏原版（靠对白）：
王勃："我不服！"
陆雪："你可知罪？"

竖屏重构版（靠视觉）：
王勃：瞳孔骤缩（特写，0.5秒）→ 咬肌鼓起（特写，0.5秒）→ "我不服！"（1秒）
陆雪：冷笑（特写，1秒）→ 展开休书（Insert，0.5秒）
```

## 五、竖屏剧本优化案例

### 5.1 案例：《大唐文圣》第一集（竖屏重构）

**原版（横屏思维）**：
```
诊断评分：7.5/10
问题：
  1. 开场慢（前10秒建立空间）
  2. 对白冗长（平均20字/句）
  3. 权力距离靠镜头距离（未用垂直构图）
  4. 视觉叙事60%（靠对白40%）
  5. 节奏慢（平均镜头长度4秒）
  6. 无平台钩子
```

**竖屏重构版**：
```
诊断评分：8.8/10（预估）
优化措施：
  1. 开场3秒：王勃脸部特写+暴雨+猛然睁眼（视觉冲击）
  2. 对白压缩50%：平均10字/句
  3. 权力距离：陆雪眼睛在1/3，王勃眼睛在下1/3
  4. 视觉叙事85%：增加12个微表情特写
  5. 节奏：平均镜头长度2秒，硬切为主
  6. 平台钩子：每5秒一个反转/悬念
```

### 5.2 优化前后对比

| 维度 | 优化前 | 优化后 | 提升 |
|------|--------|--------|------|
| 开场 3 秒 | 无冲击 | 脸部特写+暴雨 | +2.0 分 |
| 对白效率 | 20 字/句 | 10 字/句 | +0.8 分 |
| 视觉叙事 | 60% | 85% | +1.5 分 |
| 节奏 | 4 秒/镜 | 2 秒/镜 | +1.2 分 |
| 权力距离 | 镜头距离 | 垂直构图 | +0.8 分 |
| 平台适配 | 无 | 每 5 秒钩子 | +0.5 分 |
| **总分** | **7.5** | **8.8** | **+1.3** |
