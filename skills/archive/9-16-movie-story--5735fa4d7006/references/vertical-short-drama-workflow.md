# 竖屏短剧工作流（9:16 版）

> **适用**：Reels / Shorts / 抖音 / 快手 / 小红书 竖屏短剧  
> **核心**：快节奏、高情感密度、手机端优化

---

## 竖屏短剧 vs 横屏长剧

| 维度 | 横屏长剧 | 竖屏短剧 |
|------|----------|----------|
| 画幅 | 16:9 / 2.39:1 | 9:16 |
| 单集时长 | 40-60 分钟 | 1-3 分钟 |
| 镜头数/分钟 | 2-4 镜 | 8-15 镜 |
| 对话占比 | 40-60% | 20-30% |
| 动作/情绪占比 | 40-60% | 70-80% |
| 剪辑节奏 | 舒缓 | 快切 |
| 视觉焦点 | 多人物 | 单人物（人脸） |
| 字幕 | 可选 | 必须（底部 20%） |

## 竖屏短剧分镜规范

### 1. 镜头时长（竖屏节奏）
| 镜头类型 | 时长 | 说明 |
|---------|------|------|
| 特写（ emotion beat） | 1-2 秒 | 情绪爆发点 |
| 中景（对话） | 2-3 秒 | 对话核心 |
| 全景（定场） | 1-2 秒 | 快速定场 |
| 插入镜（道具/细节） | 0.5-1 秒 | 快速剪辑 |
| 动作镜（打戏） | 0.5-2 秒 | 快切 |

**总原则**：单集 1-3 分钟 = 20-40 镜

### 2. 构图规范（竖屏）
| 构图 | 说明 | 适用 |
|------|------|------|
| **中心构图** | 人脸在画面中心 | 对话、情感戏 |
| **三分法** | 眼睛在画面上 1/3 | 所有镜头 |
| **满屏构图** | 主体占满画面 | 特写、情绪镜 |
| **留白构图** | 头顶留 15% | 全景、定场 |
| **分割构图** | 上下分割（如对话） | 双人流 |



### 3. 运镜规范（竖屏）
| 运镜 | 竖屏适配 | 时长 |
|------|----------|------|
| **Push-in（推）** | 缓慢推入，强调情绪 | 2-3 秒 |
| **Pull-out（拉）** | 拉出全景，展示环境 | 1-2 秒 |
| **Pan（摇）** | 上下摇（而非左右） | 1-2 秒 |
| **Tilt（俯仰）** | 俯仰拍（强调权力关系） | 1-2 秒 |
| **Handheld（手持）** | 模拟手机拍摄 | 全程 |
| **Static（定镜）** | 少用，避免无聊 | <1 秒 |

**注意**：竖屏运镜以 **上下运动** 为主，左右运动容易被裁剪。

### 4. 对话场景规范（竖屏）
```
180° 法则（竖屏版）：
- Master Axis (C1)：从角色 A 的鼻尖指向角色 B 的鼻尖（3D 向量）
- 单数镜头 (OC1)：从 C1 左侧拍摄（A 在右，B 在左）
- 双数镜头 (OC2)：从 C1 右侧拍摄（A 在左，B 在右）
- 越轴镜头 (OA)：故意打破 180° 法则（需标注 ⚠️）
```

**竖屏对话最小覆盖**：
1. **Master 镜**：双人中景，建立空间关系（2-3 秒）
2. **A 单镜**：A 在画面右侧，看镜头左（看 B 的方向）（2 秒）
3. **B 单镜**：B 在画面左侧，看镜头右（看 A 的方向）（2 秒）
4. **OTS 镜**：A 的肩膀遮挡画面左侧，B 在右侧（1-2 秒）
5. **插入镜**：道具/手部/细节（0.5-1 秒）

## 竖屏短剧工作流

### 阶段 1：剧本适配（横屏→竖屏）
1. **拆分长对话**：将 5 分钟对话拆成 10 个 2 秒镜头
2. **增加动作描写**：每 2 秒至少有一个动作或情绪变化
3. **删除旁白**：竖屏短剧少用旁白，用画面讲故事
4. **强化视觉冲突**：每集至少有 1 个视觉爆点（巴掌、摔倒、拥抱等）

### 阶段 2：分镜生成（竖屏版）
1. **定场镜**：1-2 秒，建立场景（外景/内景）
2. **对话镜**：8-15 镜，快速剪辑
3. **动作镜**：5-10 镜，快切
4. **情绪镜**：3-5 镜，特写
5. **结尾镜**：1-2 秒，悬念/情感收尾

### 阶段 3：AI 提示词生成（竖屏版）
1. 每个镜头生成完整提示词（含 `--ar 9:16`）
2. 使用 Seedance 2.0 多模态（图片 + 提示词）
3. 生成视频片段（1-3 秒/镜）
4. 剪辑合成（CapCut / Premiere / DaVinci）

### 阶段 4：剪辑输出（竖屏版）
1. **画面**：9:16，分辨率 1080x1920
2. **字幕**：底部 20% 区域，字体大小 60-80px
3. **音频**：对话清晰，背景音乐音量 -15dB
4. **转场**：快切（<0.5 秒），避免花哨转场
5. **节奏**：每 2-3 秒一个镜头，保持快节奏

```
Medium shot, two people facing each other,
{Character A description}, {Character B description},
vertical composition, 9:16 frame,
{dialogue emotion}, {lighting},
--ar 9:16 --style raw --stylize 100
```

```

{emotion}: {detailed emotion description},
eyes at upper third, vertical framing,
{lighting}, {skin texture},
--ar 9:16 --style raw --stylize 150
```

```
{motion description}, {character} {action},
dynamic motion, motion blur,
vertical composition, 9:16 frame,
{lighting}, high shutter speed,
--ar 9:16 --style raw --stylize 200
```

```
Establishing shot, {location},
exterior, {time of day}, {weather},
vertical composition, 9:16 frame,
wide shot, full location visible,
--ar 9:16 --style raw --stylize 50
```

## 竖屏短剧常见错误

### ❌ 错误 1：镜头时长过长
**后果**：观众划走。  
**解决**：单镜 <3 秒，快节奏剪辑。

### ❌ 错误 2：人脸不在中心稳定区
**后果**：竖屏观看时人脸被裁剪。  
**解决**：眼睛在画面上 1/3，人脸在中心 50% 区域。

### ❌ 错误 3：字幕被遮挡
**后果**：观众看不清字幕。  
**解决**：字幕放在底部 20% 区域，避免人脸遮挡。

### ❌ 错误 4：横屏构图用于竖屏
**后果**：主体太小，观看体验差。  
**解决**：使用竖屏构图关键词（中心构图、三分法、满屏构图）。

### ❌ 错误 5：对话过多
**后果**：节奏拖沓。  
**解决**：对话占比 <30%，用动作和情绪推动剧情。

## 竖屏短剧平台适配

### 抖音 / 快手
- **时长**：1-3 分钟
- **比例**：9:16（全屏）
- **字幕**：必须（底部 20%）
- **音乐**：版权音乐库
- **特效**：少用，保持真实感

### Reels / Shorts
- **时长**：1-3 分钟（Reels 最长 90 秒）
- **比例**：9:16
- **字幕**：必须（多语言）
- **音乐**：版权音乐库
- **封面**：第一帧（吸引点击）

### 小红书
- **时长**：1-5 分钟
- **比例**：9:16（推荐）/ 4:5（可选）
- **字幕**：必须（中文字幕）
- **封面**：精美封面（吸引女性观众）
- **标签**：#短剧 #竖屏剧 #AI影视

## 总结

竖屏短剧 = **快节奏** + **高情感密度** + **手机端优化**

**核心要点**：
1. 单镜 <3 秒，快切剪辑
2. 人脸在中心稳定区（眼睛在画面上 1/3）
3. 字幕在底部 20% 区域
4. 对话占比 <30%，用动作和情绪推动
5. 每集至少有 1 个视觉爆点
6. 提示词必须含 `--ar 9:16`
