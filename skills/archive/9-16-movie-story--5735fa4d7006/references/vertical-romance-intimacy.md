# 亲密场景设计（竖屏 9:16 版）

> **适用**：竖屏影视项目的亲密场景设计  
> **核心**：9:16 画幅下的亲密构图、竖屏情感表达、手机端优化

---

## 亲密场景基础（竖屏版）

### 横屏 vs 竖屏亲密场景

| 维度 | 横屏 16:9 | 竖屏 9:16 |
|------|------------|------------|
| **构图** | 左右布局（人物 A 左，人物 B 右） | 上下布局（人物 A 上，人物 B 下）或中心构图 |
| **视线** | 水平（左←→右） | 垂直（上←→下）或对角线 |
| **运镜** | 缓慢推拉/摇摄 | 缓慢推拉/俯仰 |
| **剪辑节奏** | 3-5 秒/镜 | 2-4 秒/镜 |
| **视觉焦点** | 多人物 | 单人物（人脸/眼睛/手部） |

---

## 竖屏亲密场景构图

### 1. 中心构图（推荐）
```
Center Composition (Intimate):
- 人物 A 和 B 在画面中心（x=0.5, y=0.4）
- 眼睛在画面上 1/3（y≈0.33）
- 头顶留 15% 呼吸空间（y≈0.15）
- 下巴到画面底部留 20%（y≈0.8）
- 适用：拥抱、亲吻、深情对视
```

**优点**：
- 强调情感连接
- 观众沉浸感强
- 电影感强

**提示词关键词**：
```
centered composition, intimate moment,
characters in center, vertical frame, 9:16,
eyes at upper third, emotional connection,
soft lighting, romantic
```

### 2. 上下布局（对话/对视）
```
Vertical Layout (Top-Down):
- 人物 A 在画面上方（y=0.25）
- 人物 B 在画面下方（y=0.75）
- 视线方向：垂直（上←→下）
- 适用：深情对视、对话、情感交流
```

**优点**：
- 符合竖屏画幅
- 视线方向清晰
- 情感传递直接

**提示词关键词**：
```
vertical layout, top-down composition,
character A above, character B below,
vertical gaze, emotional dialogue,
vertical frame, 9:16, romantic
```

### 3. 对角线布局（电影感）
```
Diagonal Layout (Intimate):
- 人物 A 在左上（x=0.3, y=0.25）
- 人物 B 在右下（x=0.7, y=0.75）
- 视线方向：对角线（左上←→右下）
- 适用：拥抱、亲吻、亲密接触
```

**优点**：
- 电影感强
- 构图动态
- 情感张力强

**提示词关键词**：
```
diagonal layout, dynamic composition,
character A top-left, character B bottom-right,
diagonal gaze, intimate moment,
vertical frame, 9:16, cinematic romance
```

## 竖屏亲密场景运镜

### 1. 缓慢推入（Slow Push-in）
```
Slow Push-in (Intimate):
- 速度：缓慢（3-5 秒）
- 方向：中心推入（强调情感连接）
- 电影感：浅景深，背景虚化
- 适用：深情对视、亲吻、拥抱
```

**提示词关键词**：
```
slow push-in, intimate moment,
shallow depth of field, bokeh background,
vertical frame, 9:16, romantic,
emotional connection, cinematic
```

### 2. 缓慢拉出（Slow Pull-out）
```
Slow Pull-out (Intimate):
- 速度：缓慢（3-5 秒）
- 方向：中心拉出（展示环境和人物关系）
- 电影感：深景深，环境清晰
- 适用：拥抱、牵手、亲密接触
```

**提示词关键词**：
```
slow pull-out, intimate moment,
deep depth of field, full environment visible,
vertical frame, 9:16, romantic,
emotional connection, cinematic
```

### 3. 缓慢俯仰（Slow Tilt）
```
Slow Tilt (Intimate):
- 速度：缓慢（2-3 秒）
- 方向：从下往上（强调人物 A 的视角）或从上往下（强调人物 B 的视角）
- 电影感：动态构图，情感变化
- 适用：深情对视、对话、情感交流
```

**提示词关键词**：
```
slow tilt, intimate moment,
vertical framin, 9:16, emotional dialogue,
character A perspective, character B perspective,
romantic, cinematic
```

## 竖屏亲密场景光影

### 1. 柔光（Soft Lighting）
```
Soft Lighting (Intimate):
- 光源：窗户光/烛光/灯笼光
- 强度：低（30-50%）
- 阴影：柔和，无明显阴影
- 适用：深情对视、对话、日常亲密
```

**提示词关键词**：
```
soft lighting, gentle light, romantic,
vertical frame, 9:16, intimate moment,
shallow depth of field, bokeh background,
cinematic lighting, emotional
```

### 2. 侧光（Side Lighting）
```
Side Lighting (Intimate):
- 光源：侧面（左或右）
- 强度：中（50-70%）
- 阴影：明暗对比，Rembrandt lighting
- 适用：深情对视、亲吻、拥抱
```

**提示词关键词**：
```
side lighting, Rembrandt lighting, chiaroscuro,
vertical frame, 9:16, intimate moment,
half face in shadow, emotional depth,
cinematic lighting, romantic
```

### 3. 逆光（Backlighting）
```
Backlighting (Intimate):
- 光源：背后（摄像机对面）
- 强度：中（50-70%）
- 阴影：面部较暗，轮廓光明显
- 适用：亲吻、拥抱、剪影
```

**提示词关键词**：
```
backlighting, silhouette, romantic,
vertical frame, 9:16, intimate moment,
rim light, emotional, cinematic,
soft glow, gentle
```

## 总结

竖屏亲密场景 = **横屏亲密场景** + **9:16 构图适配** + **情感强化**

**核心要点**：
1. 构图：中心/上下/对角线
2. 视线方向：垂直/对角线
3. 运镜：缓慢推拉/俯仰
4. 光影：柔光/侧光/逆光
5. 提示词含 `--ar 9:16`
