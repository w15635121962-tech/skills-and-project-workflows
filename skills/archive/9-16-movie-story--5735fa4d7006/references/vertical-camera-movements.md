# 竖屏摄影机运镜手册 (9:16 Vertical Camera Movements)

> 专为 9:16 竖屏画幅重构的摄影机运镜体系。原版 16:9 运镜直接套用会导致主体偏移、构图失衡、平台裁剪。

---

## 一、竖屏运镜核心法则

### 1.1 垂直构图优先级
| 横屏 16:9 | 竖屏 9:16 | 原因 |
|------------|------------|------|
| 左右平衡 | 上下平衡 | 手机握持方向 |
| 视线留白在侧面 | 视线留白在上方/下方 | 人脸居中稳定区 |
| 横向跟拍 | 垂直跟拍/斜向跟拍 | 避免头部出画 |

### 1.2 安全区定义
```
┌─────────────────┐  ← 顶部标题/字幕区 (0-10%)
│                 │
│  核心内容区      │  ← 人脸/主体必须在此区域 (10-80%)
│  (眼睛在 1/3)  │
│                 │
├─────────────────┤  ← 分割线 (80%)
│  互动区          │  ← 点赞/评论/转发按钮区 (80-100%)
└─────────────────┘
```

### 1.3 人脸稳定区（竖屏专用）
- **眼睛位置**：画面上 1/3 处（约 y=33%）
- **头顶留白**：眼睛上方留 15-20% 空间
- **下巴留白**：下巴下方留 20-30% 空间（含互动区）
- **中心稳定区**：x=25-75%, y=20-70%

## 二、八大基础运镜（竖屏重构版）

### 2.1 静态镜头 (Static / Wide)
**横屏**：全景建立空间关系
**竖屏重构**：
- 人物全身景：脚贴底部，头顶留 15%
- 人物中景：腰以上，眼睛在 1/3 线
- 建立镜头：优先展示垂直空间关系（高天花/深井/楼梯）

```
提示词关键词：
vertical framing, full body shot, headroom 15%, 9:16 aspect ratio
```

### 2.2 推镜头 (Push-In / Dolly-In)
**横屏**：摄影机沿 Z 轴推进
**竖屏重构**：
- 推进方向：从脚→头（垂直推进）或从远→近（斜向推进）
- 避免：纯水平推进（显得扁平）
- 重点：眼睛在 1/3 位置锁定，背景虚化增强

```
提示词关键词：
vertical push-in, subject locked at 1/3, shallow depth of field, 9:16
```

### 2.3 拉镜头 (Pull-Out / Dolly-Out)
**横屏**：从特写拉到全景
**竖屏重构**：
- 拉镜终点：人物全身+环境（脚贴底，头顶留 15%）
- 重点：揭示垂直空间（如从人脸拉到全身，展示高耸建筑）

```
提示词关键词：
vertical pull-out, reveal full body and vertical space, 9:16 aspect ratio
```

### 2.4 垂直摇镜头 (Vertical Tilt / Pedestal)
**横屏**：摄影机俯仰
**竖屏重构**：
- **上摇 (Tilt Up)**：从脚摇到脸，揭示人物全貌/身高
- **下摇 (Tilt Down)**：从脸摇到脚，展示服装/动作/地面细节
- 核心运镜：竖屏最常用的运镜之一

```
提示词关键词：
vertical tilt up, from feet to face, revealing character, 9:16
```

### 2.5 横摇 (Pan) → 改用斜向运镜
**横屏**：摄影机水平旋转
**竖屏重构**：
- ❌ 避免：纯水平横摇（信息密度低，显得呆板）
- ✅ 替代：**斜向运镜 (Diagonal Move)** — 同时包含水平和垂直分量
- 示例：从人物 A 的脸 → 斜下 → 人物 B 的脸

```
提示词关键词：
diagonal camera move, from subject A to subject B, vertical framing, 9:16
```

### 2.6 跟随镜头 (Follow Shot)
**横屏**：侧面跟拍
**竖屏重构**：
- ✅ **前跟 (Front Follow)**：摄影机面对人物，后退跟拍，人脸始终居中
- ✅ **后跟 (Back Follow)**：从背后跟拍，头顶留白 20%
- ✅ **斜跟 (Diagonal Follow)**：45° 跟拍，展示人物侧面+环境

```
提示词关键词：
front follow shot, face centered, walking towards camera, vertical format 9:16
```

### 2.7 手持镜头 (Handheld)
**横屏**：模拟手持不稳定感
**竖屏重构**：
- 重点：**垂直抖动**（模拟走路时上下颠簸）
- 避免：左右抖动（手机握持时左右更稳定）
- 用途：紧张/奔跑/打斗场景

```
提示词关键词：
vertical handheld shake, walking rhythm, shaky cam, 9:16 aspect ratio
```

### 2.8 环绕镜头 (Orbit / Arc)
**横屏**：360° 环绕人物
**竖屏重构**：
- 环绕时保持：**眼睛始终在 1/3 线**
- 环绕平面：**垂直椭圆**（不是水平圆）
- 提示词：明确指定 "vertical orbit", "eyes locked at 1/3"

```
提示词关键词：
vertical orbit shot, eyes locked at 1/3, elliptical path, 9:16
```

## 三、竖屏专属运镜（横屏不存在）

### 3.1 垂直揭示 (Vertical Reveal)
- 从地面细节 → 缓慢上摇 → 揭示人物/场景
- 用途：悬念建立、人物出场

### 3.2 分割揭示 (Split Reveal)
- 屏幕分割：上半屏 A 视角，下半屏 B 视角
- 然后合并：摄影机后退，两人在同一画面

### 3.3 垂直对比 (Vertical Contrast)
- 上帧：富人/强者/光明
- 下帧：穷人/弱者/黑暗
- 用途：社会对比、权力关系

### 3.4 人脸穿梭 (Face Pass-Through)
- 摄影机从人物脸部**极近**经过（鼻尖前 5cm）
- 然后揭示背后场景
- 用途：转场/时间流逝

## 四、对话场景覆盖（竖屏版）

### 4.1 传统覆盖 vs 竖屏覆盖

| 镜头类型 | 横屏 16:9 | 竖屏 9:16 |
|---------|-----------|-----------|
| Master Shot | 全景建立空间 | 全身景，脚贴底 |
| Single (正) | 胸部以上 | 腰部以上，眼睛在 1/3 |
| Single (侧) | 侧面轮廓 | 3/4 侧面，避免纯侧面 |
| Over the Shoulder | 过肩镜头 | 过肩+斜下，展示两人 |
| Insert | 物体特写 | 物体竖直构图（避免横放） |

### 4.2 竖屏对话最小覆盖（3 镜方案）
```
镜1: 2人全身（垂直构图，A 在上方，B 在下方）
镜2: A 腰部以上（眼睛在 1/3）
镜3: B 腰部以上（眼睛在 1/3）
```
> 比横屏少 2-3 个镜头，因为竖屏单镜信息密度更高

### 4.3 越轴处理（竖屏）
- 180° 法则在竖屏**依然有效**
- 但轴线可以是**斜线**（不是纯水平线）
- 越轴提示词：`crossing the axis, POV shift, vertical framing`

## 五、AI 提示词模板（竖屏运镜）

### 5.1 基础模板
```
{SUBJECT}, {ACTION}, {VERTICAL_CAMERA_MOVE},
{EXPRESSION}, {LIGHTING}, {VERTICAL_COMPOSITION},
--ar 9:16, vertical framing, mobile format, 9:16 aspect ratio
```

### 5.2 运镜关键词库
| 运镜 | 英文关键词 |
|------|-----------|
| 垂直推进 | `vertical push-in, camera moves up closer` |
| 垂直拉远 | `vertical pull-out, reveal full body` |
| 上摇 | `tilt up from feet to face` |
| 下摇 | `tilt down from face to feet` |
| 斜向跟随 | `diagonal follow shot, 45 degree angle` |
| 前跟 | `front follow shot, walking towards camera` |

## 六、常见错误与修正

### 6.1 人脸出画
- ❌ 错误：推进时人脸超出画面上沿
- ✅ 修正：提示词加 `face always visible, headroom 15%`

### 6.2 构图扁平
- ❌ 错误：所有镜头都是正脸，无垂直变化
- ✅ 修正：交替使用 `low angle` (从下往上拍) 和 `high angle` (从上往下拍)

### 6.3 平台裁剪
- ❌ 错误：主体在画面边缘，被平台 UI 遮挡
- ✅ 修正：主体在中心稳定区 (x=25-75%, y=20-70%)

### 6.4 字幕重叠
- ❌ 错误：对话字幕与人脸重叠
- ✅ 修正：提示词加 `space at bottom for subtitles, lower frame empty`

## 七、分镜标注规范（竖屏版）

在分镜脚本的 `Camera` 栏，使用以下缩写：

| 缩写 | 含义 |
|------|------|
| V-PU | Vertical Push-In (垂直推进) |
| V-PO | Vertical Pull-Out (垂直拉远) |
| TU | Tilt Up (上摇) |
| TD | Tilt Down (下摇) |
| DF | Diagonal Follow (斜向跟随) |
| VO | Vertical Orbit (垂直环绕) |
| FS | Front Follow Shot (前跟镜头) |
| HS | Handheld Shake (手持抖动) |

## 八、检查清单

每完成一组镜头后，自查：

- [ ] 眼睛是否在画面上 1/3 处？
- [ ] 头顶是否留白 15-20%？
- [ ] 互动区（底部 20%）是否为空？
- [ ] 运镜是否包含垂直分量（不是纯水平）？
- [ ] 提示词是否包含 `--ar 9:16` 和 `vertical framing`？
- [ ] 人脸是否在中心稳定区 (x=25-75%, y=20-70%)？
