## 1. 协议概述

### 1.1 什么是文戏

文戏 = 以对白、情绪对抗、心理博弈、权力关系变化为核心驱动力的场景。与动作戏、打斗戏相对。

典型文戏类型：
- **情感对峙**：争吵、质问、坦白
- **权力博弈**：谈判、审讯、命令
- **情感流动**：告白、安慰、告别
- **心理压迫**：威胁、羞辱、操控
- **关系转折**：决裂、和解、反转

### 1.2 与模块11.9的关系

| 维度 | 模块11.9 | 模块15（本协议） |
|------|---------|-----------------|
| 定位 | 技术模块库 | 执行流程 + 强制规则 |
| 内容 | 视线关系、停顿、权力转移等技法 | 诊断→拆镜→自检的完整工作流 |
| 使用方式 | 按需调用具体技法 | 文戏场景必须完整执行全流程 |
| 自检 | 无专项自检 | 4大类12项强制自检清单 |

## 2. 第一步：场景诊断详解

### 2.1 核心情绪弧线

情绪弧线是整场戏的骨架，必须标注4个关键节点：

```
起点（平静/紧张/愤怒/悲伤）
  ↓
转折点（信息揭示/态度变化/意外事件）
  ↓
高潮（爆发/崩溃/反转/沉默）
  ↓
落点（余韵/空虚/新状态/悬念）
```

**诊断要点**：
- 起点和落点的情绪差异越大，戏越有张力
- 转折点必须有一个明确的"触发事件"（一句台词/一个动作/一个眼神）
- 高潮不一定是最大声——有时最安静的镜头最震撼

### 2.2 冲突类型与权力动态

| 冲突类型 | 权力特征 | 典型镜头处理 |
|----------|---------|-------------|
| 强对弱 | 一方明显主导 | 强势方低角度/大占屏比，弱势方高角度/被遮挡 |
| 势均力敌 | 权力来回摇摆 | 对称构图，权力转移时构图同步反转 |
| 多方博弈 | 联盟与背叛 | 快切反应镜头，每人的反应揭示其真实立场 |
| 自我冲突 | 人物内部撕裂 | ECU 面部特写 + 镜中镜/倒影构图 |
| 隐性压迫 | 表面平静实则操控 | 稳定构图 + 缓慢推轨 + 光线渐冷 |

### 2.3 关键 Subtext 节点

Subtext = 没有说出口但必须让观众感知到的信息。

**可视化方法映射表**：

| Subtext 类型 | 可视化手段 | 竖屏适配 |
|-------------|-----------|---------|
| 说谎/隐瞒 | 视线偏移、手部紧张动作、呼吸变化 | ECU 中这些细节被放大2-3倍 |
| 渴望/克制 | 身体微微前倾又收回、手指触碰又缩回 | 竖屏中"差一点碰到"极具张力 |
| 恐惧/掩饰 | 喉结滚动、瞳孔收缩、笑容不达眼底 | 竖屏面部特写中微表情无处隐藏 |
| 愤怒压抑 | 下颌收紧、拳头攥紧、颈静脉凸起 | 竖屏垂直构图突出颈部/手部的紧张 |
| 悲伤克制 | 强忍泪水、嘴唇抿紧、眨眼频率变化 | 竖屏眼泪轨迹形成天然垂直引导线 |

### 2.4 表演核心需求

根据场景诊断，明确每个角色需要突出的表演元素：

- **微表情**：眉头微蹙、嘴角抽搐、眼眶泛红
- **肢体语言**：双臂交叉（防御）、手插口袋（紧张）、身体前倾（投入）
- **眼神**：视线停留位置（对方眼睛/嘴唇/地面）、聚焦/失焦
- **呼吸**：加速/屏住/颤抖/长叹

### 2.5 空间与连续性要求

- **人物站位**：谁坐谁站、距离远近、是否被桌椅/柱子隔开
- **视线方向**：人物看向哪里（屏幕左/右、上方/下方）
- **道具位置**：杯子/手机/文件等道具的初始位置和移动轨迹
- **光线方向**：主光源从哪个方向来，是否随情绪变化

## 3. 第二步：分镜拆解详解

### 3.1 景别递进规则

情绪越强，景别越紧：

```
平静（MS 中景） → 试探（MCU 中近景） → 冲突（CU 特写） → 爆发（ECU 大特写） → 坍塌（MS/WS 拉远）
```

**竖屏特化**：
- 竖屏 ECU 中面部可占屏 70-80%，冲击力远超横屏
- 竖屏拉远至 WS 时人物被垂直空间吞没，孤独感更强
- 景别收紧速度应比横屏快1档（横屏用 MS 的地方，竖屏直接用 MCU）

### 3.2 运镜动机映射

| 情绪变化 | 运镜选择 | 动机 |
|---------|---------|------|
| 逼近/压迫 | 垂直推轨 Dolly In | 镜头代替观众"靠近"人物，制造亲密或压迫 |
| 退缩/距离 | 缓慢拉远 Zoom Out | 人物被空间吞没，关系疏远 |
| 不安/紧张 | 轻微手持 Steadicam Wobble | 模拟呼吸般的微晃，制造观察感 |
| 观察/审视 | 垂直 Tilt（从手到脸） | 从肢体语言揭示到面部表情的叙事推进 |
| 权力转移 | 水平滑动 Truck（仅当动机充分时） | 一方被"推"出画面，另一方"进入"主导 |

### 3.3 反应镜头设计

反应镜头是文戏的灵魂。核心原则：

**65% 反应 / 35% 说话**的分配比例。

| 说话内容 | 应切到的反应 |
|---------|------------|
| 关键台词/坦白/威胁 | 听者的面部反应（ECU）—— 眼神变化、呼吸停顿、嘴唇微颤 |
| 情绪爆发/怒吼 | 被吼者的沉默反应—— 不动、不闪、不躲 = 更有力量 |
| 温柔告白 | 听者的眼泪/微笑/闭眼 = 情感投射 |
| 侮辱/羞辱 | 旁观者的不忍/幸灾乐/不安 = 多维度叙事 |

**竖屏反应镜头技法**：
- ECU 反应镜头中，面部占屏 60-80%，微表情无处隐藏
- "延迟反应"：先拍 0.5-1s 的空白表情（信息在消化），再出情绪反应
- Reaction Insert：在说话者镜头间插入 0.5-1s 的道具/手部/环境反应镜头

## 4. 自检清单详解

### 4.1 A类：节奏与张力

**情绪曲线检查**：
- 画出本场景的情绪曲线图（X轴=镜头号，Y轴=张力值1-10）
- 曲线应该有明确的高低起伏，不能是平线
- 如果整场戏张力都在8以上 → 缺乏对比，需要加入平静段落作为"呼吸空间"

**高潮视觉冲击**：
- 高潮镜头是否是整场戏中景别最紧的？（应该是 ECU）
- 竖屏高潮是否使用了面部占屏 70%+ 的构图？
- 高潮后是否有足够的"坍塌"空间（拉远+留白+沉默）？

### 4.2 B类：表演与 Subtext

**反应镜头计数**：
- 统计本场景中反应镜头数 / 总镜头数
- 如果 < 65% → 增加反应镜头，减少 Talking Head
- 检查：是否有至少1个"延迟反应"处理？

**Subtext 可视化检查**：
- 列出场景诊断中的3个 Subtext 节点
- 逐个检查：每个 Subtext 是否都有至少1个镜头将其可视化？
- 如果某个 Subtext 仅靠台词传递 → 添加反应镜头/道具镜头/运镜来可视化

### 4.3 C类：技术与连续性

**运镜动机检查**：
- 逐个检查每个运镜：是否有明确的情绪/叙事动机？
- 无动机的运镜 → 改为固定镜头

**连续性检查**：
- 人物在不同镜头间的站位是否一致？
- 道具（杯子/文件/手机）位置是否连贯？
- 光线方向是否一致？

### 4.4 D类：竖屏适配

- 是否优先使用了垂直运镜（推轨/Tilt）而非水平运镜（Pan/Truck）？
- 群戏是否避免了横向并排构图？（应改为快速切特写或垂直堆叠）
- 人物眼睛是否在画面上1/3处？
- 高潮是否使用了竖屏 ECU？

## 5. 参考电影技法详解

### 5.1 《十二怒汉》— 景别递进教科书

**核心技法**：随着讨论深入，景别逐步从全景收紧到大特写。

**竖屏适配**：
- 竖屏中12个陪审员的构图更具挑战——禁止横向排列
- 推荐处理：说话者用 MCU，反应者用快速切 ECU
- 竖屏空间有限，每次最多展示2-3人（OTS + 1个反应）

### 5.2 《继承之战》— 手持观察式

**核心技法**：大量手持镜头 + 反应镜头驱动，制造纪录片式的亲密感和不安感。

**竖屏适配**：
- 竖屏手持微晃更具沉浸感（手机观看者天然适应手持画面）
- 反应镜头用 ECU，"偷窥感"更强

### 5.3 《血色将至》— 缓慢推进 + 身体性表演

**核心技法**：极缓慢的推镜 + 演员身体的每一个细节变化都被捕捉。

**竖屏适配**：
- 垂直推轨从 MS 到 CU，速度应比横屏更慢（竖屏距离更短，推太快会"跳"）
- 胸膛起伏、手指攥紧等身体细节在竖屏特写中更清晰

### 5.4 《霸王别姬》— 非语言表演 + 诗意运镜

**核心技法**：最强烈的情绪往往没有台词，全靠表演和运镜传递。

**竖屏适配**：
- 垂直 Tilt（从道具到面部）+ 竖屏空间留白 = 诗意构图
- 竖屏中"无言的凝视"效果极佳（面部独占全屏）

### 5.5 《销售奇才》— 强势移动 + 反应镜头驱动

**核心技法**：角色的物理移动代表权力转移，大量 reaction insert 压缩感受时间。

**竖屏适配**：
- 竖屏中垂直移动（上楼/下楼/站起来）比水平移动更有力量
- Reaction insert 在竖屏快切节奏中高效压缩时间

## 6. 常见问题与排查

| 问题 | 原因 | 修复方法 |
|------|------|---------|
| 文戏感觉"平淡" | 景别没有递进，从头到尾一个景别 | 情绪上升时收紧景别，高潮用 ECU |
| 观众感受不到潜台词 | Subtext 仅靠台词传递 | 添加反应镜头/道具特写/运镜来可视化 |
| 群戏画面拥挤 | 横向并排构图在竖屏中严重压缩 | 改为快速切特写或垂直堆叠 |
| 节奏拖沓 | 说话镜头太多，反应镜头不足 | 将反应镜头比例提升至 ≥65% |
| 运镜让人分心 | 运镜没有情绪动机 | 无动机的运镜改为固定镜头 |
| 竖屏构图失衡 | 人物眼睛不在上1/3 | 调整人物垂直位置，眼睛对齐 y≈0.33 |
