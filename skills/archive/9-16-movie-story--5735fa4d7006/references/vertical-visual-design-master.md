# 视觉设计大师（竖屏 9:16 版）

> **适用**：竖屏影视项目的视觉设计全流程  
> **核心**：9:16 画幅约束、竖屏色彩系统、手机端视觉优化

---

## 竖屏视觉设计流程

### 阶段 1：画幅定义（9:16）
```
Aspect Ratio: 9:16 (竖屏全屏)
Resolution: 1080x1920 (FHD+) / 1440x2560 (QHD+)
Pixel Aspect: 1.0 (square pixels)
Display: Smartphone (iPhone/Android)
```

### 阶段 2：色彩系统（竖屏版）
| 色彩 | 横屏 16:9 | 竖屏 9:16 | 说明 |
|------|------------|------------|------|
| **主色** | 任意 | 避免顶部 20% | 状态栏/通知栏区域 |
| **辅色** | 任意 | 避免底部 20% | 字幕/手势区域 |
| **强调色** | 任意 | 中心稳定区 | 人脸/主体区域 |
| **背景色** | 任意 | 深色优先 | 竖屏观看更舒适 |

### 阶段 3：构图系统（竖屏版）
| 构图 | 横屏 | 竖屏 | 说明 |
|------|------|------|------|
| **中心构图** | 主体居中 | 主体居中（y≈0.4） | 人脸在画面中心 |
| **三分法** | 左/右 1/3 | 上/下 1/3 | 眼睛在画面上 1/3 |
| **满屏构图** | 主体占满 | 主体占满（上下） | 特写/情绪镜 |
| **留白构图** | 左右留白 | 上下留白 | 全景/定场 |

### 阶段 4：字体系统（竖屏版）
| 字体属性 | 横屏 | 竖屏 | 说明 |
|---------|------|------|------|
| **字体大小** | 24-32px | 60-80px | 竖屏字幕更大 |
| **字体位置** | 底部 10% | 底部 20% | 避免手势区域 |
| **字体颜色** | 白色 | 白色 + 黑描边 | 提高可读性 |
| **字体样式** | 无衬线 | 粗无衬线 | 小屏幕可读性 |

## 竖屏色彩系统

### 色彩情绪映射（竖屏版）
| 情绪 | 主色 | 辅色 | 强调色 | 适用场景 |
|------|------|------|--------|---------|
| **愤怒** | 深红 | 黑 | 金 | 争吵、冲突 |
| **悲伤** | 冷蓝 | 灰 | 白 | 哭泣、离别 |
| **恐惧** | 深紫 | 黑 | 红 | 惊悚、悬疑 |
| **喜悦** | 暖黄 | 白 | 橙 | 笑容、团圆 |
| **焦虑** | 冷绿 | 灰 | 红 | 紧张、等待 |
| **平静** | 中性灰 | 白 | 蓝 | 对话、日常 |
| **权力** | 深蓝 | 金 | 红 | 权谋、对峙 |
| **脆弱** | 浅紫 | 白 | 灰 | 受伤、哭泣 |

### 竖屏色彩应用规则
1. **主色占比**：60-70%（背景/服装）
2. **辅色占比**：20-30%（道具/环境）
3. **强调色占比**：5-10%（光影/细节）
4. **顶部 20%**：避免高饱和色（状态栏区域）
5. **底部 20%**：避免高饱和色（字幕区域）
6. **中心稳定区**：高对比度（人脸/主体区域）

## 竖屏构图系统

### 中心构图（竖屏版）
```
Center Composition (Vertical):
- 主体在画面中心（x=0.5, y=0.4）
- 眼睛在画面上 1/3（y≈0.33）
- 头顶留 15% 呼吸空间（y≈0.15）
- 下巴到画面底部留 20%（y≈0.8）
```

**适用**：特写、情绪镜、单人镜头

### 三分法（竖屏版）
```
Rule of Thirds (Vertical):
- 画面分成 3x3 网格
- 眼睛在上横线上（y≈0.33）
- 鼻子在中心横线上（y≈0.5）
- 嘴巴在下横线上（y≈0.66）
- 人脸在左/右竖线上（x≈0.33 或 x≈0.66）
```

**适用**：对话镜、中景、全身镜

### 满屏构图（竖屏版）
```
Full-Frame Composition (Vertical):
- 主体占满画面（上下贴合）
- 头顶留 5% 呼吸空间（y≈0.05）
- 下巴留 5% 呼吸空间（y≈0.95）
- 左右留 10% 呼吸空间（x≈0.1, x≈0.9）
```

**适用**：特写、情绪爆发、动作镜

### 留白构图（竖屏版）
```
Negative Space Composition (Vertical):
- 主体在画面 1/3 区域
- 剩余 2/3 留白
- 留白区域可以是天空/墙壁/虚化背景
```

**适用**：全景、定场、意境镜

## 总结

竖屏视觉设计 = **横屏视觉设计** + **9:16 画幅约束** + **手机端优化**

**核心差异**：
1. 画幅 9:16（1080x1920）
2. 眼睛在画面上 1/3（y≈0.33）
3. 字幕在底部 20%（避免手势区域）
4. 字体大小 60-80px（竖屏可读性）
5. 顶部/底部 20% 避免高饱和色
