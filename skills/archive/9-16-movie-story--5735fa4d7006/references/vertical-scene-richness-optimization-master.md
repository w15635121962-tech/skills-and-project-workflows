## 核心原则详解（竖屏适配）

### 原则1：多平面空间层次 + 25-grid 思维（竖屏适配）

**为什么重要**：扁平的场景看起来像AI生成的。清晰的前景/中景/背景层次 = 电影感。**竖屏重点**：人物占据画面 60-80% 垂直高度，眼睛在上1/3，善用垂直负空间。

**如何执行**：
- 每次优化场景时，问自己：
  - 前景有什么？（物体、植物、框架 — 竖屏中前景在画面顶部或底部）
  - 中景有什么？（主体、互动 — 竖屏中主体在中心稳定区）
  - 背景有什么？（环境、光源、大气效果 — 竖屏中背景经常被压缩）
- 25-grid 思维：不只规划主镜头（正面平视），还要考虑 8 个主要变体角度（左前/右前/左/右/左后/右后/左前高角/右后高角）

**示例（竖屏适配）**：
```
优化前：女人站在雨中（竖屏 9:16）。
优化后：
- 前景：雨滴在镜头前穿过，虚化（f/2.8，竖屏顶部区域）
- 中景：女人站在湿滑鹅卵石上，右手拎着湿透的包（眼睛在上1/3）
- 背景：生锈铁门，剥落海报，远处昏黄街灯（体积光，竖屏底部1/3）
```

### 原则2：光影与色调深度融合（竖屏适配）

**为什么重要**：没有 motivated 光源 = 塑料感。光影必须来自场景中的某个光源。**竖屏重点**：顶光/底光在竖屏中更戏剧性，眼睛 catchlight 必须在上1/3区域内。

**如何执行**：
- 每个场景必须有一个明确的 **主光源**（key light）：
  - 室内：窗户、灯具、屏幕（竖屏中光源常在画面外，用阴影形状暗示）
  - 室外：太阳、路灯、车灯、霓虹（竖屏中垂直方向的光束更有冲击力）
- 光影必须与环境互动：
  - 雨水/湿润表面反光（竖屏 ECU 中可见）
  - 金属/玻璃反射（竖屏中反射更明显）
  - 布料吸光/反光特性（竖屏中布料垂直线条更明显）
  - 皮肤 subsurface scattering（SSS）（竖屏 ECU 中皮肤细节更清晰）
- 色调服务于情绪：
  - 冷色调（蓝/青）= 孤独、紧张、压抑（竖屏中冷色调更「冷」）
  - 暖色调（橙/红）= 温暖、激情、危险（竖屏中暖色调更「暖」）

**示例（竖屏适配）**：
```
优化前：rainy alley（没有指定光源，竖屏 9:16）
优化后：harsh single tungsten practical light from top-left creating dramatic Rembrandt lighting 
with distinct shadow triangle on cheek (eyes at upper third of vertical 9:16 frame)
```

### 原则3：物理真实与环境融合

**为什么重要**：AI 生成经常犯「物体悬浮」、「光线穿透固体」、「材质无互动」的错误。

**如何执行**：
- 所有物体必须「坐」在表面上（重力 — 竖屏中重力方向是从上到下）
- 所有光线必须有「来源」和「衰减」（竖屏中垂直方向的光衰减更明显）
- 所有材质必须有「反应」：
  - 布料：皱褶、吸光、惯性（竖屏中布料垂直线条更明显）
  - 金属：反射、划痕、氧化（竖屏 ECU 中划痕更清晰）
  - 皮肤：毛孔、细纹、红润感、SSS（竖屏 ECU 中皮肤细节更清晰）
  - 液体：流动、飞溅、反光（竖屏中液体垂直下落更明显）

### 原则4：环境叙事 + 12-category 资产覆盖

**为什么重要**：好的场景不只是「背景」，而是「故事的沉默叙述者」。

**如何执行**：
- 每次优化场景时，至少调用 **3 个** 12-category 资产类别
- 加入能暗示故事的细节：
  - 剥落海报 → 这个地方被遗弃多久了？（竖屏中海报在背景，ECU 中可见细节）
  - 咖啡杯仍有蒸汽 → 人物刚离开（或刚到达）（竖屏中蒸汽在画面顶部，符合热气上升）
  - 破损的镜子 → 冲突发生过了？（竖屏中镜子在背景，反射可见）

### 原则5：情绪与叙事服务

**为什么重要**：炫技的场景如果与故事无关 = 浪费时间。

**如何执行**：
- 每次添加细节时，问自己：**这个细节强化了哪个戏剧功能？**
  - Want vs Need（欲望 vs 需求）
  - 情绪张力（恐惧/爱/愤怒/悲伤）
  - 主题（救赎/复仇/成长/牺牲）
- 如果细节不能强化戏剧功能 → 删掉。

### 原则6：竖屏优先 + 空间一致性

**为什么重要**：竖屏（9:16）构图规则与横屏（16:9）完全不同。

**如何执行**：
- 构图适合 9:16，注重多镜头连续性与空间映射一致性
- 人物眼睛必须在上1/3（竖屏构图法则 #1）
- 中心稳定区（画面中间 50-65% 垂直高度）无遮挡（竖屏构图法则 #2）
- 底部94-140px 是 UI 遮挡区，重要细节不能放在这里（竖屏构图法则 #3）

### 原则7：资产与网格协同

**为什么重要**：优化后的场景应该「可拆解」为多个角度的变体。

**如何执行**：
- 优化场景时，始终考虑：「这个元素在左前低角看起来如何？在右后高角看起来如何？」（竖屏中垂直构图变化比水平构图变化更明显）
- 如果某个元素「只能从一个角度看到」→ 这是缺陷，需要调整为「多角度可见」或「战略性遮挡」

## 12-Category 资产系统详解（竖屏适配）

| 类别 | 内容示例 | 如何调用 | 竖屏适配要点 |
|------|----------|----------|-------------|
| **1. 角色资产** | 主角/配角/群演的视觉锚点、服装、表情库 | 调用 Visual Anchor System | 眼睛在上1/3，面部占屏50-70% |
| **2. 道具资产** | 关键道具、手持物、环境道具 | 调用 Prop Design & Consistency Template | 道具位于中心稳定区（避免底部94-140px） |
| **3. 场景元素** | 建筑、家具、自然元素、毁伤细节 | 调用 Scene Consistency Bible | 垂直分布：天空在上1/3，地面在下1/3 |
| **4. 光影氛围** | 光源类型、色温、阴影形状、体积光 | 在提示词中明确指定光源 | 垂直方向的光束（从上方射入）在竖屏中更有冲击力 |
| **5. 材质互动** | 布料、金属、木材、玻璃、液体物理反应 | 在提示词中添加材质关键词 | 竖屏 ECU 中材质细节更可见（毛孔、划痕、水珠） |
| **6. 大气效果** | 尘埃、烟雾、雾气、光线散射 | 添加 `floating dust motes`, `volumetric god rays`, `fog` | 垂直光束（从上方射入）在竖屏中更有冲击力 |
| **7. 表面细节** | 锈迹、污渍、磨损、指纹、生活痕迹 | 添加 `weathered surfaces`, `natural patina`, `peeling paint` | 竖屏 ECU 中表面细节更清晰（锈迹、污渍、磨损） |
| **8. 声音提示** | 环境音、脚步、材质碰撞（用于提示词描述） | 在提示词中描述声音（`rustling fabric`, `distant siren`） | 竖屏短剧节奏快，声音提示要精准 |
| **9. VFX 元素** | 火花、水花、碎片、能量效果 | 添加 `sparks on clash`, `water splatter`, `debris` | 竖屏中 VFX 要集中在中心稳定区（否则被裁切） |
| **10. 摄影机** | 机位、运镜、镜头选择、景深 | 指定镜头毫米数、T-stop、景深 | 竖屏优先垂直运镜（Tilt Up/Down, Crane Up/Down） |
| **11. 色调情绪** | 色彩方案、对比度、饱和度、色彩关系 | 指定色调关键词（`teal and orange`, `desaturated blue`, `warm tungsten`） | 竖屏色彩要更饱和（手机屏幕亮度高） |
| **12. 叙事细节** | 暗示背景故事的隐藏细节、符号、痕迹 | 添加 `peeling movie posters`（暗示遗弃）、`fresh scratch marks`（暗示最近冲突） | 竖屏中叙事细节要放在中心稳定区（否则被裁切） |

## 25-Grid 多角度场景系统详解（竖屏 9:16 适配）

### 25-Grid 布局（竖屏适配）

将场景空间划分为 5×5 网格（考虑垂直构图），规划不同机位角度：

| | 左 | 中 | 右 |
|--|----|----|-----|
| **前（低角）** | 左前低角（强调人物高度） | 正面低角（眼睛在上1/3） | 右前低角（强调人物高度） |
| **中（平视）** | 左平视（垂直构图） | **正面平视（主镜头，眼睛在上1/3）** | 右平视（垂直构图） |
| **后（高角）** | 左后高角（俯拍，展现环境） | 正面高角（俯拍，孤独感） | 右后高角（俯拍，展现环境） |

**竖屏使用方式**：优化场景时，考虑主镜头（中心）之外的 8 个主要变体角度，确保光影、道具、人物位置在所有角度下都合理且丰富。**重点**：竖屏 ECU 在高角度下冲击力更强，低角度下人物更高大。

### 使用方式（竖屏适配）

优化场景时，考虑主镜头（中心）之外的 8 个主要变体角度，确保光影、道具、人物位置在所有角度下都合理且丰富。

**示例（竖屏适配）**：

场景：雨夜小巷，女人站着悲伤（竖屏 9:16）。

| 角度 | 构图要点（竖屏适配） | 元素分布变化 | 光影调整建议 |
|------|--------------------------|----------------|--------------|
| **正面平视（主镜头）** | 女人占画面 60-80% 垂直高度，眼睛在上1/3 | 前景：雨滴虚化；中景：女人；背景：铁门 | 顶部左侧钨丝灯，Rembrandt 光影 |
| **左前低角** | 仰拍，强调女人高度（脆弱感） | 前景：雨滴在镜头前穿过；背景：建筑物向上延伸 | 光源在画面外右侧，照亮女人左侧脸 |
| **右前低角** | 仰拍，强调女人高度（脆弱感） | 同左前低角，但对称 | 光源在画面外左侧，照亮女人右侧脸 |
| **左平视** | 左侧平视，垂直构图 | 前景：湿滑墙壁；中景：女人侧脸；背景：巷子深度 | 侧光，强调鼻子和下巴轮廓 |
| **右平视** | 右侧平视，垂直构图 | 同左平视，但对称 | 侧光，强调鼻子和下巴轮廓 |
| **左后高角** | 俯拍，展现巷子深度 | 人物极小，在上1/3；背景：巷子延伸消失点 | 顶光，照亮人物头顶和肩膀 |
| **右后高角** | 俯拍，展现巷子深度 | 同左后高角，但对称 | 顶光，照亮人物头顶和肩膀 |
| **正面高角** | 俯拍，孤独感 | 人物在上1/3，占画面 20-30%；背景：巨大空旷环境 | 顶光，人物完全被阴影覆盖（只留 rim light） |

### 空间一致性检查（竖屏适配）

- [ ] 所有角度下，光源方向一致？（竖屏中垂直方向的光源一致性更重要）
- [ ] 所有角度下，人物站位一致？（门在左？窗在右？— 竖屏中左右关系更容易保持）
- [ ] 所有角度下，道具位置一致？（咖啡杯在桌左？— 竖屏中道具位置在中心稳定区）
- [ ] 所有角度下，材质互动一致？（雨水反光？金属反射？— 竖屏 ECU 中材质互动更可见）

## 工作流程详解（竖屏适配）

### 步骤1：分析原始输入 + 资产映射（竖屏适配）

**目标**：理解用户给的原始描述，找出缺失点，识别可调用的资产类型。

**执行清单**：
- [ ] 提取核心主体（谁？— 竖屏中人物必须占据 60-80% 垂直高度）
- [ ] 提取核心动作（做什么？— 竖屏中动作必须垂直分布）
- [ ] 提取情绪（感觉如何？— 竖屏中情绪必须通过面部 ECU 传达）
- [ ] 提取戏剧功能（为什么这个场景存在？）
- [ ] 识别可调用的 12-category 资产类型（至少 3 个 — 竖屏中资产必须位于中心稳定区）
- [ ] 判断当前描述在空间层次、光影、细节上的缺失（竖屏中空间层次经常被压缩）

**示例（竖屏适配）**：

原始描述：`A woman stands in a rainy alley at night, looking sad.`（竖屏 9:16）

分析：
- 核心主体：女人（竖屏中必须占据 60-80% 垂直高度，眼睛在上1/3）
- 核心动作：站着（竖屏中动作太少，需要添加「手部动作」或「身体微动」）
- 情绪：悲伤（竖屏中必须通过 ECU 传达微表情）
- 戏剧功能：孤独、失落
- 可调用的资产类型：类别4（光影氛围：单一钨丝灯从顶部左侧产生戏剧性阴影）、类别6（大气效果：雨滴、蒸汽、floating dust motes in volumetric god rays）、类别7（表面细节：湿滑鹅卵石、生锈铁门、剥落海报）
- 缺失点：空间层次（没有前景/背景）、光影无来源、环境叙事缺失（竖屏中背景经常被压缩，需要主动设计）

### 步骤2：规划丰富性方案（融入 25-grid 思维，竖屏适配）

**目标**：设计具体的空间层次、光影方案、资产调用。

**执行清单**：
- [ ] 设计前景/中景/背景的具体内容（竖屏中垂直分布：前景在顶部或底部，中景在中心，背景在后部）
- [ ] 规划光源方向、质感、体积效果（竖屏中垂直方向的光源更有冲击力）
- [ ] 规划色调方案（竖屏中色调要更饱和，因为手机屏幕亮度高）
- [ ] 考虑 25-grid 主要角度下的构图可能性（竖屏中垂直构图变化比水平构图变化更明显）
- [ ] 考虑 25-grid 主要角度下的元素分布（竖屏中元素必须位于中心稳定区，避免底部94-140px）
- [ ] 选择能强化叙事的环境细节，并关联 12-category 资产（竖屏中叙事细节必须位于中心稳定区）

**示例（竖屏适配）**：

规划方案：
- 前景：雨滴在镜头前穿过（f/2.8 虚化，竖屏顶部区域）
- 中景：女人站在湿滑鹅卵石上，右手拎湿透包（眼睛在上1/3，中心稳定区）
- 背景：生锈铁门，剥落海报，远处昏黄街灯（体积光，竖屏底部1/3）
- 光源：单一钨丝灯从顶部左侧（Rembrandt 光影，眼睛 catchlight 在上1/3）
- 体积效果：雨滴在体积光中可见（`floating dust motes in god rays`，竖屏中垂直光束更有冲击力）
- 色调：冷蓝 + 暖 tungsten 对比（孤独 vs 温暖记忆，竖屏中对比更明显）
- 25-grid 思维：主镜头正面平视（眼睛在上1/3）；可在左前低角捕捉雨滴在镜头前穿过，右后高角展现巷子深度与孤独感（人物极小，在上1/3）

### 步骤3：强制自检与优化（v1.1 增强版清单，竖屏适配）

使用以下清单逐项检查并改进：

**A. 空间层次（3 层强制，竖屏适配）**
- [ ] 是否有清晰的前景/中景/背景？（竖屏中空间层次经常被压缩，需要主动设计）
- [ ] 前景是否提供足够的「景深暗示」？（竖屏中前景虚化比背景虚化更有层次感）
- [ ] 中景是否突出主体？（竖屏中人物必须占据 60-80% 垂直高度）
- [ ] 背景是否提供环境和叙事？（竖屏中背景经常被压缩，需要选择「有叙事意义」的元素）

**B. 光影与色调（motivated lighting 强制，竖屏适配）**
- [ ] 光影是否有源？（竖屏中光源常在画面外，用阴影形状暗示）
- [ ] 是否与材质产生真实互动？（雨水反光、金属反射、布料吸光 — 竖屏 ECU 中更可见）
- [ ] 色调是否统一？是否服务于情绪？（竖屏中色调要更饱和）

**C. 资产调用（至少 3 个类别，竖屏适配）**
- [ ] 是否有效调用或描述了 12-category 中的至少 3 个资产类别？
- [ ] 每个调用的资产是否强化了戏剧功能？

## 自检清单详解（竖屏适配）

### A. 空间层次（3 层强制，竖屏适配）

**为什么重要**：扁平 = AI 感。层次 = 电影感。**竖屏重点**：空间层次经常被压缩，需要主动设计。

**如何检查**：
- 前景：有什么在镜头和主体之间？（物体、植物、框架 — 竖屏中前景在画面顶部或底部）
- 中景：主体在哪里？（竖屏中人物必须占据 60-80% 垂直高度，眼睛在上1/3）
- 背景：主体后面有什么？（环境、光源、大气效果 — 竖屏中背景经常被压缩）

**常见错误（竖屏适配）**：
- ❌ 只有中景，没有前景和背景（竖屏中常见错误）
- ❌ 前景遮挡主体（应该用浅景深虚化前景 — 竖屏中前景虚化比背景虚化更有层次感）
- ❌ 背景是纯色或渐变（应该用真实环境 — 竖屏中背景经常被压缩，需要选择「有叙事意义」的元素）

### B. 光影与色调（motivated lighting 强制，竖屏适配）

**为什么重要**：没有 motivated 光源 = 塑料感。**竖屏重点**：光源常在画面外，用阴影形状暗示。

**如何检查**：
- 每个光源都能在场景中找到「来源」？
- 光影是否与材质产生真实互动？（雨水反光、金属反射、布料吸光 — 竖屏 ECU 中更可见）
- 色调是否统一？是否服务于情绪？（竖屏中色调要更饱和）

**常见错误（竖屏适配）**：
- ❌ 双面光（flat lighting — 竖屏中更明显，因为面部占屏比大）
- ❌ 无阴影（看起来像浮在空中 — 竖屏中更明显，因为人物占屏比大）
- ❌ 色调与情绪不匹配（悲伤场景用暖色调 — 竖屏中色调对比更明显）

### C. 资产调用（至少 3 个类别，竖屏适配）

**为什么重要**：丰富的场景 = 多个资产类别的协同。**竖屏重点**：资产必须位于中心稳定区，避免底部94-140px。

**如何检查**：
- 是否调用了至少 3 个 12-category 资产类别？
- 每个调用的资产是否强化了戏剧功能？
- 每个调用的资产是否位于中心稳定区（避免底部94-140px）？

**常见错误（竖屏适配）**：
- ❌ 只用了类别1（角色资产）和类别2（道具资产）
- ❌ 调用的资产与戏剧功能无关（炫技但无用）
- ❌ 资产位于底部94-140px（UI 遮挡区 — 竖屏特有错误）

### D. 物理真实（避免塑料感，竖屏适配）

**为什么重要**：塑料感 = AI 生成最明显的痕迹。**竖屏重点**：ECU 中材质细节更可见。

**如何检查**：
- 材质是否有真实互动？（布料皱褶、金属划痕、皮肤 SSS — 竖屏 ECU 中更可见）
- 物体是否「坐」在表面上（重力 — 竖屏中重力方向是从上到下）？
- 光线是否有「来源」和「衰减」？（竖屏中垂直方向的光衰减更明显）

**常见错误（竖屏适配）**：
- ❌ 皮肤像塑料或蜡（竖屏 ECU 中最明显）
- ❌ 布料像纸张（无皱褶、无惯性 — 竖屏中布料垂直线条更明显）
- ❌ 金属像镜子（无划痕、无氧化 — 竖屏 ECU 中划痕更清晰）

### E. 空间一致性（多镜头连续使用，竖屏适配）

**为什么重要**：空间不一致 = 观众出戏。**竖屏重点**：垂直方向的一致性更容易保持。

**如何检查**：
- 25-grid 所有角度下，光源方向一致？（竖屏中垂直方向的光源一致性更重要）
- 25-grid 所有角度下，人物站位一致？（竖屏中左右关系更容易保持）
- 25-grid 所有角度下，道具位置一致？（竖屏中道具位置在中心稳定区）

**常见错误（竖屏适配）**：
- ❌ 主镜头光源在左，反应镜头光源在右
- ❌ 主镜头门在左，远景门在右
- ❌ 主镜头眼睛在上1/3，反应镜头眼睛在画面中央（竖屏特有错误）

### F. 构图适配（目标画幅 9:16，竖屏适配）

**为什么重要**：画幅不对 = 黑边或裁切。**竖屏重点**：眼睛必须在上1/3，中心稳定区无遮挡。

**如何检查**：
- 构图是否适合竖屏短剧（9:16）？
- 眼睛是否在上1/3？（竖屏构图法则 #1）
- 中心稳定区（画面中间 50-65% 垂直高度）是否无遮挡？（竖屏构图法则 #2）
- 重要细节是否不在底部94-140px（UI 遮挡区）？（竖屏构图法则 #3）

**常见错误（竖屏适配）**：
- ❌ 为竖屏生成 16:9 构图（人物眼睛在画面中央，不是上1/3）
- ❌ 重要细节在底部94-140px（UI 遮挡区 — 竖屏特有错误）
- ❌ 底部94-140px 有字幕（被 UI 遮挡 — 竖屏特有错误）

## 常见问题排查（竖屏适配）

### Q1：优化后的提示词太长，AI 不遵循怎么办？（竖屏适配）

**A**：分而治之。
- 先生成「基础提示词」（主体 + 动作 + 情绪 — 竖屏中主体必须占据 60-80% 垂直高度）
- 再生成「环境提示词」（空间层次 + 光影 + 大气效果 — 竖屏中垂直分布）
- 最后用「增强提示词」（材质细节 + 资产调用 — 竖屏 ECU 中材质细节更可见）叠加

### Q2：25-grid 所有角度都要生成吗？（竖屏适配）

**A**：不需要。
- 主镜头（正面平视）必须生成（竖屏中眼睛在上1/3）
- 根据场景需要，选择 2-3 个变体角度生成（竖屏中优先垂直构图变化：低角/高角）
- 其余角度用「空间一致性检查清单」确保逻辑正确

### Q3：竖屏（9:16）和横屏（16:9）的优化有什么区别？（竖屏适配）

**A**：主要区别：
- 竖屏：眼睛必须在上1/3，人物占画面 60-80% 垂直高度
- 竖屏：优先垂直运镜（Tilt Up/Down, Crane Up/Down）
- 竖屏：底部94-140px 是 UI 遮挡区，重要细节不能放在这里
- 横屏：眼睛在画面中央偏上，人物占画面 40-60% 高度
- 横屏：优先水平运镜（Pan, Truck, Dolly）

### Q4：如何避免「过度优化」？（竖屏适配）

**A**：每次添加细节时，问自己：**这个细节强化了哪个戏剧功能？**
- 如果不能回答 → 删掉
- 如果能回答 → 保留，但确保不遮挡主体或重要细节（竖屏中中心稳定区不能遮挡）
