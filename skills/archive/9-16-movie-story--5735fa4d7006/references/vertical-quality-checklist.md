# 竖屏质量检查清单 (Vertical Quality Checklist)

> 专为 9:16 竖屏画幅重构的质量检查清单。原版 16:9 质量检查直接用于竖屏会遗漏竖屏专属问题（安全区/平台适配/手机屏优化）。

---

## 一、竖屏质量检查清单（完整版）

### 1.1 六轮自检（竖屏重构版）

#### 第一轮：剧本覆盖度

- [ ] 是否 100% 覆盖剧本内容（无遗漏场景/对白）？
- [ ] 是否按竖屏节奏重构（镜头长度 1-3 秒，不是 3-5 秒）？
- [ ] 是否增加对白压缩（≥50%）？
- [ ] 是否增加视觉叙事（≥70% 靠画面，不是对白）？
- [ ] 是否增加竖屏开场（前 3 秒视觉冲击）？

#### 第二轮：视觉一致性（竖屏专属）

- [ ] **眼睛位置**：是否全场景一致（都在 1/3 处）？
- [ ] **头顶留白**：是否全场景一致（15%）？
- [ ] **底部留空**：是否全场景一致（20% 留空）？
- [ ] **人物垂直位置**：上位者是否始终在上 1/3，下位者是否始终在下 1/3（除非权力反转）？
- [ ] **构图**：是否避免纯水平构图（必须有垂直分量）？

#### 第三轮：镜头语法（竖屏重构）

- [ ] 运镜是否有垂直分量（不是纯水平）？
- [ ] 覆盖镜头是否 ≥3 个（Master + 2x Single，竖屏最小覆盖）？
- [ ] 转场是否以硬切为主（不是叠化/擦除）？
- [ ] 镜头长度是否 1-3 秒（不是 3-5 秒）？
- [ ] 是否避免正反打（用单镜同框替代）？

#### 第四轮：AI 提示词质量（竖屏专属）

- [ ] 是否全部包含 `--ar 9:16`？
- [ ] 是否全部包含 `vertical framing` 或 `9:16 aspect ratio`？
- [ ] 是否全部指定眼睛位置（`eyes at upper 1/3`）？
- [ ] 是否全部指定头顶留白（`headroom 15%`）？
- [ ] 是否全部包含竖屏负面词（`--no horizontal composition, face cropped, bottom frame cluttered`）？
- [ ] 是否全部包含手机屏优化（`mobile display optimized, OLED optimized`）？

#### 第五轮：Coverage & Spatial（竖屏重构）

- [ ] 空间坐标是否每个镜头都标注（`[C1] ΔX/ΔY/ΔZ`）？
- [ ] Master Axis C1 是否全场景一致（斜线，从上到下）？
- [ ] 180° 法则是否遵守（轴线是斜线，不越轴除非叙事需要）？
- [ ] 人物 Y 轴位置是否符合权力关系（上位者在上 1/3）？

#### 第六轮：整体验收（竖屏专属）

- [ ] 在手机上预览分镜，眼睛位置是否一致？
- [ ] 在手机上预览分镜，底部是否被 UI 遮挡？
- [ ] 在手机上预览分镜，人脸是否变形？
- [ ] 在手机上预览分镜，色彩是否饱和（手机屏特性）？
- [ ] 在手机上预览分镜，完播率是否预计 ≥60%？（前 3 秒视觉冲击）

## 二、竖屏平台适配检查（专属）

### 2.1 抖音/ TikTok 适配检查

- [ ] 画幅是否为 9:16（无黑边）？
- [ ] 前 3 秒是否有视觉冲击（完播率优化）？
- [ ] 右侧 15% 是否为空（点赞/评论/分享按钮）？
- [ ] 底部 18% 是否为空（或被字幕占用，不更低）？
- [ ] 色彩是否高饱和（手机屏特性）？
- [ ] 是否包含热门关键词（`热门, 爆款, 剧情反转`）？

### 2.2 Instagram Reels 适配检查

- [ ] 画幅是否为 9:16（无黑边）？
- [ ] 底部 20% 是否为空（文案区）？
- [ ] 顶部 10% 是否为空（账号名）？
- [ ] 色彩是否美学感（滤镜/调色）？
- [ ] 是否包含音乐同步（`music sync, beat matching`）？

### 2.3 YouTube Shorts 适配检查

- [ ] 画幅是否为 9:16（无黑边）？
- [ ] 右侧 12% 是否为空（订阅按钮）？
- [ ] 底部 15% 是否为空（进度条）？
- [ ] 对白是否 100% 字幕覆盖（手机扬声器差）？
- [ ] 是否包含章节标记（`chapter marker ready`）？

### 2.4 即梦 (Dreamina) 适配检查

- [ ] 画幅是否为 9:16（无黑边）？
- [ ] 提示词是否为中文（即梦中文效果更好）？
- [ ] 是否使用"参考人物"功能（上传剧照保持面孔）？
- [ ] 是否包含电影感关键词（`电影感, 写实风格, 细节丰富`）？

---

## 三、竖屏技术质量检查

### 3.1 分辨率与画质

- [ ] 分辨率是否为 1080×1920（9:16 标准）？
- [ ] 帧率是否为 25/30/50/60fps（根据平台）？
- [ ] 码率是否 ≥10Mbps（1080p）？
- [ ] 是否开启 HDR（如果平台支持）？

### 3.2 音频质量（竖屏专属）

- [ ] 对白是否 100% 字幕覆盖（手机扬声器差）？
- [ ] 语速是否慢（字幕停留时间 ≥1.5 秒）？
- [ ] 音乐是否同步（抖音/Reels 重要）？
- [ ] 环境音是否保留（雨声/雷声/脚步声）？

### 3.3 文件格式与兼容性

- [ ] 视频格式是否为 MP4 (H.264/H.265)？
- [ ] 音频格式是否为 AAC？
- [ ] 文件大小是否 ≤500MB（平台上传限制）？
- [ ] 是否包含元数据（标题/描述/标签）？
