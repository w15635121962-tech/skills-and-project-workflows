# Kling 3 vs Seedance 2 微表情对比（竖屏 9:16 版）

> **适用**：竖屏影视项目的 Kling 3 vs Seedance 2 微表情生成对比  
> **核心**：9:16 画幅下的微表情生成、竖屏适配、手机端优化

---

## 微表情基础（竖屏版）

### 横屏 vs 竖屏微表情

| 维度 | 横屏 16:9 | 竖屏 9:16 |
|------|------------|------------|
| **人脸位置** | 中心 | 中心稳定区（x:0.25-0.75, y:0.25-0.65） |
| **眼睛位置** | 中心 | 画面上 1/3（y≈0.33） |
| **微表情展示** | 全身/半身 | 特写/极端特写 |
| **提示词** | 任意 | 必须含 `--ar 9:16` |

---

## Kling 3 微表情生成（竖屏版）

### Kling 3 优势
1. **动作描述敏感**：详细动作描述 → 更好微表情
2. **时长控制**：5/10 秒可选
3. **镜头控制**：推拉/摇摄/环绕
4. **竖屏适配**：`--ar 9:16` 支持良好

### Kling 3 微表情提示词模板
```
{Subject}, {Action}, {Micro-Expression},
vertical 9:16, {Lighting}, {Style},
--ar 9:16
```

**示例 1：愤怒（微表情）**
```
Close-up of young man, early 20s,
angry micro-expression: veins bulging,
eyes wide open, pupils contracted,
vertical 9:16, top lighting, hard shadows,
--ar 9:16
```

**示例 2：悲伤（微表情）**
```
Extreme close-up of young woman, early 20s,
sad micro-expression: teardrops,
lower lip trembling, eyes red,
vertical 9:16, bottom lighting, soft glow,
--ar 9:16
```

**示例 3：恐惧（微表情）**
```
Extreme close-up of young man, early 20s,
fear micro-expression: pupils dilated,
eyes wide open, sweat beads,
vertical 9:16, side lighting, deep shadows,
--ar 9:16
```

## Seedance 2.0 微表情生成（竖屏版）

### Seedance 2.0 优势
1. **多模态输入**：图片 + 提示词 → 更好一致性
2. **中文理解**：中文提示词理解更好
3. **竖屏适配**：`--ar 9:16` 支持良好
4. **电影感**：自动添加电影感光影

## Kling 3 vs Seedance 2.0 微表情对比

| 维度 | Kling 3.0 | Seedance 2.0 |
|------|-----------|--------------|
| **微表情精度** | 高 | 中 |
| **动作描述** | 敏感 | 中等 |
| **多模态输入** | 不支持 | 支持（图片 + 提示词） |
| **中文理解** | 中等 | 高 |
| **竖屏适配** | `--ar 9:16` | `--ar 9:16` |
| **电影感** | 中 | 高 |
| **时长控制** | 5/10 秒 | 4/8 秒 |
| **镜头控制** | 推拉/摇摄/环绕 | 推拉/摇摄 |
| **一致性** | 中 | 高（多模态） |

## 竖屏微表情生成工作流

### 阶段 1：提示词生成
1. **选择平台**：Kling 3.0（动作敏感）或 Seedance 2.0（多模态）
2. **写提示词**：使用上述模板
3. **添加 `--ar 9:16`**：必须

### 阶段 2：生成视频
1. **Kling 3.0**：粘贴提示词，选择时长（5/10 秒），生成
2. **Seedance 2.0**：上传参考图，粘贴提示词（中文），选择时长（4/8 秒），生成

### 阶段 3：评估与迭代
1. **微表情精度**：是否准确？
2. **竖屏适配**：人脸是否在中心稳定区？
3. **电影感**：光影是否有电影感？
4. **迭代**：根据结果调整提示词

## 总结

竖屏微表情生成 = **横屏微表情生成** + **9:16 构图适配** + **平台选择**

**核心差异**：
1. 必须加 `--ar 9:16`
2. 人脸在中心稳定区（x:0.25-0.75, y:0.25-0.65）
3. 眼睛位置在画面上 1/3（y≈0.33）
4. Kling 3.0 动作描述敏感，Seedance 2.0 多模态输入
