# 9:16 Movie Story — 竖屏电影级 AI 影视创作全流程智能体

专为 **短视频 / Reels / Shorts / 竖屏剧** 设计的完整分镜与 AI 提示词生成系统。
在 [movie-story](https://github.com/Billyui/movie_story) 横屏版基础上，针对 **9:16 画幅** 全面重构。

## 竖屏专属特性

### 竖屏叙事推理层（模块2.5 — 竖屏特化推理引擎）

9:16画幅信息密度垂直分布，每一帧寸土寸金，比横屏更需要"先想清楚再拍"：

| 推理步骤 | 竖屏特化 |
|---------|---------|
| 叙事意图(15类) | +人物占屏比映射（Setup 15-30% / Conflict 40-60% / Climax 50-80%）|
| 故事语法(7阶段) | +竖屏能量表达方式（上升=占屏比递增，骤降=WS释放）|
| 角色心理 | +dominance→垂直位置映射（高dominance=上1/3权力高位）|
| 关系图谱 | +权力→上/下1/3构图（竖屏中垂直位置比水平位置更有效）|
| 潜台词(13类) | +垂直空间利用策略（hidden_threat下方暗示/betrayal轴线越轴）|
| 视觉注意力 | +上/中/下三层分配（面部/手部动作/环境伏笔）|
| 情绪弧线 | +能量→占屏比递进输出格式 |

### 竖屏开场状态模块（3.1.1 — 强制首帧定场）

在9:16画幅中，开场状态比横屏更关键——竖屏观众的第一帧印象决定整个场景的视觉锚定：

| 子模块 | 竖屏专属标注 |
|-------|------------|
| 环境定场 | +竖屏构图预判（上/中/下层信息分配）+ 开场首帧建议机位 |
| 站位关系 | +竖屏站位映射（每个角色位于画面上/中/下1/3处）|
| 角色状态 | +竖屏占屏比（特写40-60% / 中景25-40% / 远景15-25%）|
| 服装状态 | +竖屏布料可见度（裁切后的实际可见比例）|
| 灯光体系 | +竖屏灯光适配（阴影垂直分布/顶光优先）|
| 声音氛围 | +字幕安全区（底部94-140px）|

### 构图铁律
| 规则 | 说明 |
|------|------|
| 眼睛在上1/3 | 人脸垂直中心位于画面上1/3处（y≈0.33）|
| 中心稳定区 | 人脸必须位于 x:0.25-0.75, y:0.25-0.65 |
| 底部UI遮挡区 | 底部94-140px不放置重要信息 |
| 垂直运镜优先 | Tilt/Crane 效果远优于水平 Pan |

### 竖屏镜头-动作融合书写（强制不可绕过）
竖屏中画面垂直信息密度高，割裂写法会导致跳帧感加剧：
- 融合叙述中必须包含竖屏构图标注（人物占屏比、面部稳定区位置）
- 竖屏快切镜头（0.8-2.5s）的融合叙述需更紧凑，动作+运镜一句话完成
- 垂直运动（tilt/crane）需与竖屏空间节奏配合

### 写实质感专项强制（竖屏放大2-3倍）

| 规则 | 触发条件 | 竖屏特化 |
|------|---------|---------|
| 4.5 眼泪物理 | 涉及哭泣镜头 | 竖屏特写中泪水被放大2-3倍 |
| 4.7 布料真实感 | 涉及衣物/布料 | 竖屏近景中塑料感放大2-3倍，旗袍/汉服单独标注 |
| 4.8 场景环境真实感 | 涉及场景/环境 | 垂直光柱/垂直构图/高度利用 |
| 4.9 湿衣真实感 | 涉及雨戏/水戏/落水/出汗 | 垂直水流/旗袍湿态特化/9:16深度适配 |

### 骨相强化（欧美人审美）
竖屏特写占屏比50-70%，骨相问题被放大2-3倍。推荐使用：
- **Rembrandt Lighting**（★★★☆☆）：三角光塑形颧骨+颌线，竖屏效果最佳
- **Split Lighting**（★★★☆☆）：半面亮/半面暗，情绪高潮专用
- **Short/Side Lighting**（★★★☆☆）：颌线完整展现，侧面镜头首选

### 竖屏导演视觉控制（导演必修课模块8）
竖屏9:16画幅中AI失真问题被放大，容错率更低：
- **竖屏四步布光法**：垂直光影分布，顶光是"最佳友军"
- **垂直色温梯度**：上暖下冷/上冷下暖渐变，制造竖屏戏剧张力
- **竖屏质感打假**：通用微细节 + 联动4.7/4.8/4.9专项质感
- **竖屏防失真**：人体比例控制 + 手部变形（竖屏中占比更大）
- **四维协同公式**：垂直灯光 → 色温梯度 → 竖屏质感 → 竖屏调色
- **高难度光照匹配（8.7）**：竖屏特化4类光照（多光源/金属/树影/霓虹）

### 对白时长计算（竖屏快节奏版）
```
最终时长 = (汉字数 ÷ 2.25 + 情绪停顿 + 表演缓冲) × 1.15
```
- 竖屏最小时长保护：有对白镜头 ≥ 3.5s
- 快节奏实现方式：**用 reaction insert / prop close-up 压缩感受时间，不压缩对白表演时间**

## 视频提示词输出格式 v2.0 — 竖屏版
每个场景的视频提示词统一采用「开场状态」+ 逐Shot结构，覆盖**服装 + 妆发 + 道具 + 场景**四维度：

| 组件 | 说明 | 竖屏强化 |
|------|------|---------|
| **开场状态** | 统领全场景，一次定义环境/站位/角色/美术资产/灯光/摄影/质感 | + 竖屏站位映射(上/中/下1/3)、竖屏占屏比、字幕安全区(底部94-140px)、竖屏色温梯度 |
| **逐Shot** | duration + 镜头(景别+角度+垂直运镜+焦距+景深+速度) + 画面 + 光影 | + 竖屏构图标注(人物占屏比/面部稳定区)、竖屏放大2-3倍专项质感 |
| **台词格式** | `@角色名 (情绪·音量·效果)：{对白内容}` | 同横屏 |
| **分隔** | 用 `---` 分隔各Shot，有台词的Shot绝不合并 | 竖屏快切(0.8-2.5s)融合叙述更紧凑 |

配套四维美术提取技能（与 v2.0 格式一致，竖屏版额外追加竖屏字段）：

| 技能 | 聚焦维度 | 竖屏追加字段 |
|------|---------|------------|
| costume-accessories-extractor | 服装+配饰：重量感/垂坠感/布纹褶皱 | + 竖屏裁切可见比例、布料竖屏放大质感 |
| makeup-hair-extractor | 妆发造型：皮肤纹理/毛孔/明暗对照 | + 竖屏特写放大2-3倍、皮肤纹理竖屏强化 |
| script-props-extractor | 道具：材质纹理/灯光反射 | + 竖屏可见度(全显/半裁/裁出) |
| set-art-extractor | 场景美术：空间布局/混合色温/材质磨损 | + 竖屏上/中/下三层信息分配 |
