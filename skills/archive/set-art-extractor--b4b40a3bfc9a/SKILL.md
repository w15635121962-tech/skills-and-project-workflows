# 场景美术置景提取技能

## 用途

从影视剧本的场次/分镜描述中，精准提取场景美术信息，输出结构化档案，供：
- 美术指导与置景部门参考
- 场景调度与搭建清单
- AI 生图/生视频中的场景 Prompt 素材
- 跨场次美术连续性核查

**按场次顺序整理，每个场次单独分析空间、色调、陈设、氛围。**

---

## 触发条件

- 用户提供剧本文本并要求提取场景美术信息
- 用户需要生成置景清单或场景总表
- 用户需要检查美术连续性（跨场次色调/陈设一致性）
- 用户需要 AI 生图用的场景描述 Prompt

---

## 执行流程

### 第一步：扫描与确认

收到剧本文本后，先做：
1. 快速扫描全文，列出所有场次编号、场景名称和地点
2. 向用户确认分析范围（全部场次 or 指定场次范围）
3. 确认是否需要区分「内景/外景」「日景/夜景」

### 第二步：逐场次分析

对每个场次按以下结构输出：

```markdown
**场次 [编号]：【场次名称】| [内景/外景] | [日景/夜景]**

**【空间与布局】**
- **场景类型**：室内 / 室外 / 半开放 / 虚拟场景
- **空间尺寸感**：宽敞 / 紧凑 / 压抑 / 开阔
- **空间布局**：关键区域划分（如：入口区、会客区、工作区、背景区）
- **镜头动线**：摄影机可移动路径、主要拍摄角度

**【色调与光影】**
- **主色调**：墙面 / 地面 / 天花板主色
- **辅助色调**：家具 / 织物 / 装饰色
- **光影氛围**：自然光 / 人工光 / 强对比 / 柔光 / 阴影重点
- **色温倾向**：暖调 / 冷调 / 中性 / 高饱和 / 低饱和

**【关键陈设与道具】**
- **大型陈设**（影响空间结构的）：沙发、书架、办公桌、床、柜体
- **中型陈设**（丰富场景层次的）：台灯、花瓶、画作、地毯、窗帘
- **小型陈设**（细节质感）：书籍、杯具、文具、摆件、植物
- **墙面装饰**：挂画、照片、海报、涂鸦、壁纸

**【环境氛围要素】**
- **季节与时间**：春/夏/秋/冬，具体时段（清晨/正午/黄昏/深夜）
- **天气**：晴/阴/雨/雪/雾/沙尘（外景）
- **动态要素**：开窗的风、雨滴、烛光摇曳、电视反光
- **气味暗示**（剧本有提示时）：咖啡香、潮湿霉味、花香

**【美术连续性备注】**
- 本场次与前后场次场景是否连贯（同一场景多次出现需标注）
- 需要特别注意的美术要素（易穿帮的细节）
```

### 第三步：场景总表

```markdown
**【全剧场景总表】**

| 场次编号 | 场景名称 | 内/外景 | 日/夜景 | 主色调 | 关键陈设（3件） | 出现次数 |
|---------|---------|---------|--------|--------|----------------|---------|
| 场次1   | 男主公寓客厅 | 内景 | 夜景 | 暖黄木色 | 旧沙发、书架、台灯 | 3 |
| 场次3   | 公司天台 | 外景 | 日景 | 灰蓝冷调 | 水泥地面、栏杆、城市背景 | 1 |
```

> 同一场景出现多次时，合并为一行，在「出现次数」标注，并在备注说明场次编号。

### 第四步：美术连续性核查

```markdown
**【美术连续性核查】**

**同一场景多次出现的一致性检查：**
| 场景名称 | 涉及场次 | 色调是否一致 | 陈设是否一致 | 风险提示 |
|---------|---------|-------------|-------------|---------|
| 男主公寓客厅 | 1/5/11 | ✅ 一致 | ⚠️ 场次5多了外卖盒 | 需确认是否剧情需要 |

**跨场次色调逻辑核查：**
- 情绪转折点（如场次7从暖转冷）：是否符合剧情
- 时间跨度大的场次（如闪回）：美术风格是否有区分

**潜在问题：**
- 场次X的场景在场次Y未交代变化原因
- 外景天气在连续场次中突然变化（需确认剧情时间跨度）
```

### 第五步：AI 生图 Prompt 片段

为每个场次生成精炼的「场景描述」Prompt（50-100字），包含空间、色调、光影、关键陈设，可直接用于 Midjourney / Flux / Runway 等工具。

### 第六步：视频提示词生成

**完整视频提示词由「开场状态」+ 逐Shot组成。有台词的Shot单独成块输出。格式严格如下：**

```markdown
# 视频提示词

## 开场状态：
环境：@场景标签（时间/地点/氛围），整体色调与光感描述 <环境音效>
站位关系：[角色A] 与 [角色B] 的空间位置关系
@角色A：[详细位置、姿态、朝向、与场景中其他元素的空间关系]
@角色B：[详细位置、姿态、朝向、与场景中其他元素的空间关系]
@场景陈设/空间标签：[位置、状态、氛围描述]
灯光：主光为 [光源方向 + 色温 + 光质]；[副光说明]；实用光为 [场景内光源]

---

## Shot 1
duration: X.Xs

镜头：[景别]，[角度]，[运镜]，[焦距]，[景深]，[速度]，[稳定器]。[镜头运动详细描述]

画面：[详细视觉描述，聚焦本技能提取的场景美术元素——空间布局、关键陈设、色调光影]
[空间材质纹理+写实质感：自然噪点、色彩还原、墙体/地面/家具材质]
[如有眼泪→追加眼泪增强关键词]

光影：[色温] [光质描述]；[阴影占比]，[反差描述]

---

## Shot 2
duration: X.Xs

镜头：[同上格式]
画面：[同上，场景动态变化（灯光变化/天气变化/物体移位）+空间氛围推进]
光影：[同上格式]
```

**提示词书写规则（必须遵守）：**
1. `# 视频提示词` 为总标题，`## 开场状态：` 统领全场景，用 `---` 分隔各Shot
2. `开场状态` 覆盖：环境+站位关系+各角色姿态+场景陈设状态+灯光，一次定义全场共享
3. 每个Shot含 `duration` + `镜头` + `画面` + `光影`，不重复开场状态中已定义的信息
4. 有台词时，在 `画面` 段落后追加 `@角色名 (情绪·音量·效果)：{对白内容}`，无台词则省略
5. `画面` 必须聚焦本技能提取的场景美术元素，含写实质感关键词（自然噪点、色彩还原、空间材质纹理）
6. `光影` 必须含色温(K)、光质、阴影占比、反差描述
7. 每个Shot提示词独立成块，有台词的Shot绝不与其他Shot合并
8. 所有描述必须来自本技能提取的结果，不得虚构

### 眼泪表情专用增强关键词

**当剧本涉及「哭泣 / 流泪 / 含泪 / 眼泪」时，在「画面」段落中必须追加以下关键词：**

| 关键词类别 | 具体关键词（直接粘贴至提示词） |
|-----------|---------------------------|
| **泪液物理** | 泪液折射、泪痕反光、泪珠表层张力、晶莹泪滴、泪液沿面部轮廓滑落轨迹 |
| **场景联动** | 泪滴滴落在地面形成深色湿点扩散、泪滴打在木质/石质表面产生短暂湿润反光、泪液溅落在桌面纸面上晕染、封闭空间内压抑氛围放大泪滴坠落声 |
| **光影联动** | 泪滴高光反射点、泪液表面对环境光的折射、泪痕反光呈冷调银白、暗部泪液依然可见微弱反光、窗光穿过泪珠产生微小彩虹折射 |
| **环境氛围** | 阴雨环境的雨滴与泪滴形成视觉平行、密闭空间回响放大抽泣声、暗调照明强化泪液可见度 |
| **写实质感** | 真人实拍质感、自然皮肤纹理可见、泪液物理真实、非CG水晶质感 |

> 严禁使用「水晶般」「钻石般」「珍珠般」等CG美化词汇，眼泪必须呈现真实人体泪液质感。

---

## 注意事项

- 剧本未明确描述的美术要素，标注「剧本未提及，建议美术指导补充」
- 若剧本只有简单场景名（如「日内，客厅」），依场景类型进行合理推断并标注「依场景类型推断」
- 色调分析以剧本描述和情境逻辑为依据，不做无依据猜测
- 场景总表按场景名称分组，而非按场次编号，方便美术部门统一调度
- 连续性核查是重点，同一场景在不同场次的变化必须明确标注

## 参考示例（酒店大堂三角对峙）

> **本技能聚焦：** 空间布局（前景/中景/背景）、混合色温角力、吊灯/旋转门/大理石地面、尘埃颗粒与大气薄雾

```markdown
# 视频提示词

## 开场状态：

**环境：** @酒店大堂，夜晚，3200K钨丝暖色与6500K冷蓝月光混合角力，低饱和度冷暖碰撞，吊灯光束中漂浮体积感尘埃微粒，轻微大气薄雾笼罩 <旋转门微弱的机械转动声，远处隐约的钢琴声，大堂空旷微回声>

**站位关系：** 三人形成对峙三角格局 — @女主 位于画面左侧 → @女反角 占据画面中央 → @男主 位于画面右侧中景

**@女主：** 位于画面左侧，姿态内收，双臂自然垂于身侧，手指微微向内蜷曲；面庞被吊灯3200K暖光柔化覆盖

**@女反角：** 占据画面中央，下巴微抬，唇角挂着一抹冷冷的轻蔑笑意；轮廓被旋转门6500K冷蓝月光硬朗勾勒，形成冷暖对抗

**@男主：** 位于画面右侧中景，视线在地板与@女主之间来回游移，刻意避开与@女反角的直视

**@空间/陈设：**
- **前景：** 失焦的水晶吊灯碎片，形成如破碎玻璃般的散景面纱（bokeh veil）
- **中景：** 三人三角对峙站位核心区，大理石地面带有细微磨损痕迹与倒映
- **背景：** 旋转门将6500K冷蓝色月光倾泻进3200K钨丝暖色的大堂内部，形成混合色温的角力
- **吊灯光束：** 空气中漂浮体积感尘埃微粒，轻微大气薄雾在深焦下保留纵深层次

**灯光：**
- **主光：** 天花板水晶吊灯，3200K钨丝暖光，自上而下覆盖@女主区域，光质柔化
- **副光/轮廓光：** 旋转门方向 6500K 冷蓝月光，硬朗侧逆光勾勒@女反角轮廓
- **实用光：** 吊灯暖光在大堂空间内自然衰减，无额外补光
- **反差：** 暖色吊灯光映@女主 × 冷色月光勾勒@女反角 → 冷暖明暗对照（directional chiaroscuro）
- **阴影：** 约40%，主要集中在@男主区域

**摄影规格：** 阿莱 Alexa 65 / 35mm / T4 / 深焦定场镜头 / --ar 9:16

**空间质感：**
- 照片级真实 / 超写实 / 真人实拍质感的电影静帧
- 多层次构图：前景（失焦散景）→ 中景（三角对峙）→ 背景（旋转门+月光）纵深分明
- 充满生活痕迹的氛围——大理石地面细微磨损痕迹与倒映、空气中漂浮的尘埃微粒
- 非卡通 / 非动漫 / 非插画

---

## Shot 1
**duration: 4.0s**

**镜头：** 广角定场，平视，缓慢前推，35mm，T4深焦保留三人全景，常速，稳定器固定。镜头从大堂全景起沿中轴线缓慢向前推进，景别由大广角缓缓收紧至中广角，最后落点在三人三角对峙的定格瞬间——冷蓝月光与暖黄吊灯光在画面中形成对角线切割。

**画面：**
前景中失焦的水晶吊灯碎片如破碎玻璃散景面纱，随着镜头缓慢前推，散景光斑从画面边缘向两侧逐渐滑出——前景散景动态变化丰富画面层次。中景三人三角对峙，@女反角占据中央，下巴微抬的冷傲姿态稳定不动；@女主左侧内收；@男主右侧中景游移。背景旋转门持续倾泻6500K冷蓝月光，与3200K暖黄吊灯光在画面中形成对角冷暖切割线。大理石地面同时反射暖光与冷光，形成双色倒映。吊灯光束中尘埃微粒体积感随镜头推进逐渐清晰，轻微大气薄雾在深焦下保留纵深层次。
写实质感：真人实拍，胶片颗粒与皮肤噪点，地面磨损痕迹与倒映细节丰富。

**光影：** 3200K暖黄吊灯光自上而下覆盖画面左侧；6500K冷蓝月光从背景旋转门方向切入，硬朗侧逆光；冷暖光在中央形成对角线切割，明暗对照（chiaroscuro）；阴影约40%；大理石地面双色倒映。

---

## Shot 2
**duration: 3.5s**

**镜头：** 中近景，侧前方平视，缓慢横移（dolly left），中长焦85mm，浅景深焦在@女主面部，常速，稳定器固定。镜头从@女反角侧脸起，沿三角对峙中轴线向左横移，焦点由@女反角过渡到@女主，最后落点交给@女主面部。

**画面：**
起幅：@女反角占据画面中央偏右，下巴微抬，6500K冷蓝月光硬朗勾勒轮廓。横移过程中镜头路过画面中央——水晶吊灯碎片在浅景深下化为失焦散景光斑，大理石地面轻微磨损纹理在焦外若隐若现。落幅：@女主暖光下的面庞——3200K吊灯光从上方斜照，暖光在大气薄雾中自然柔化。背景旋转门已完全虚化为冷蓝调色块，@男主身影化为模糊暖色块。浅景深焦外散景（bokeh）由水晶吊灯碎片与@女反角礼服反光共同构成多层次散景层。
写实质感：真人实拍，空间纵深通过浅景深+散景+大气薄雾三层分离清晰呈现。

**光影：** 主光3200K暖黄从@女主前上方斜照，光质通过大气薄雾由硬朗过渡为柔化；6500K冷蓝月光在落幅时退至@女主身后成为微弱的冷调边缘光；吊灯光束在大气薄雾中呈现可见光路（visible light beam）。
```
