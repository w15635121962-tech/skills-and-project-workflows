# 推文常见隐喻/感官描写的视觉转译对照表

## 身体隐喻 → 画面

| 推文原文 | 隐喻类型 | 视觉转译 |
|---------|---------|---------|
| "胸口像灌了水泥" | 压迫 | ECU：手紧握胸口，指节发白，呼吸短促 |
| "嗓子眼里卡了鱼刺" | 哽咽 | MCU：喉结滚动，嘴角微微下撇，吞咽动作 |
| "脑子里嗡嗡的" | 麻木 | CU：眼神失焦，瞳孔微缩，背景声音压低 |
| "心脏像被攥了一把" | 心痛 | ECU：手按住左胸，手指微微颤抖，呼吸浅促 |
| "整个人像被抽空了" | 虚脱 | WS：角色瘫坐在地，身体佝偻，四肢松弛 |
| "血往头上涌" | 愤怒/羞耻 | MCU→ECU：面部潮红从颈部蔓延，下颌咬紧 |
| "胃里翻江倒海" | 恶心/紧张 | MCU：手捂腹部，额头微汗，嘴唇抿紧 |
| "后背发凉" | 恐惧 | CU：肩膀微缩，皮肤起鸡皮疙瘩（若可见），眼神警惕 |

## 关系隐喻 → 画面

| 推文原文 | 隐喻类型 | 视觉转译 |
|---------|---------|---------|
| "我们之间隔着一堵墙" | 疏离 | 双人构图：中间有物理遮挡（墙/柱/玻璃） |
| "他看我像看一只蚂蚁" | 轻蔑 | 仰拍他+俯拍她：高低落差+视角切换 |
| "我站在他身后三步远" | 距离 | WS→MS：两人同框但保持三步距离 |
| "我们背对背坐着" | 决裂 | 鸟瞰或背后WS：两人背对，中间空白 |
