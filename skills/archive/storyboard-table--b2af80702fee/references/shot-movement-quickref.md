# 景别与运镜速查卡

## 景别递进逻辑

### 标准递进（情感加强）
```
WS（建立） → MS（进入） → MCU（亲近） → CU（强调） → ECU（碎片/极致）
```

### 标准递退（情感释放）
```
ECU/CU（峰值余韵） → MCU（回稳） → WS（孤立/释放）
```

### 打斗递进
```
WS（对峙建立） → MS（交手） → CU/ECU（撞击碎片） → WS（间隔）
```

### 暧昧递进
```
WS/MS（距离） → MCU（靠近） → CU（凝视） → LINGER/ECU（失控瞬间） → 空镜（余韵）
```

## 运镜叙事功能速查

| 你想让观众感到 | 用什么运镜 | 为什么 |
|--------------|----------|--------|
| 压迫 | 缓推 | 空间在缩小 |
| 孤立 | 缓拉 | 角色在变远 |
| 震惊 | 急推 | 突然被拉入 |
| 不安 | 手持 | 世界不稳 |
| 权力 | 仰拍+缓推 | 主体在变大 |
| 羞耻 | 俯拍+缓推 | 主体在变小 |
| 渴望 | LINGER | 不舍得移开 |
| 恐惧 | 微漂移 | 世界在微颤 |
| 紧张 | 静止 | 暴风前的平静 |
| 释放 | 缓拉→静止 | 慢慢放下 |

## 9:16 vs 16:9 运镜差异

| 运镜 | 9:16竖屏适配 | 16:9横屏适配 |
|------|-------------|-------------|
| 推 | 优先纵向推（上→下或下→上） | 优先水平推（左→右或右→左） |
| 拉 | 优先纵向拉远 | 优先水平拉远 |
| 摇 | 优先上下摇 | 优先左右摇 |
| 横移 | 少用，竖屏横向空间有限 | 常用，自然运动方向 |
| 环绕 | 人物为轴心垂直环绕 | 人物为轴心水平环绕 |

## 常见运镜禁忌

| 禁忌 | 原因 | 修复方案 |
|------|------|---------|
| 缓推→紧接缓拉 | 运镜方向矛盾 | 插入静止保持镜头 |
| 急推→急推 | 连续冲击无呼吸 | 急推后必须≥0.5s恢复 |
| 手持→锁定静态 | 观众眩晕 | 先减速至微漂移，再至静止 |
| 上摇→下摇 | 方向矛盾 | 插入高位保持镜头 |
| 无动机运动 | 运镜无叙事目的 | 删除运动或补叙事动机 |
