# 灯光模式速查表

## 四步布光法标准

| 步骤 | 功能 | 必填项 | 示例 |
|------|------|--------|------|
| **Key Light** | 主光源，定义画面基调 | 来源·方向·色温K·光质(硬/柔)·覆盖区域 | 天花板水晶吊灯，自上而下，3200K，柔光，覆盖女主区域 |
| **Fill Light** | 补光，控制阴影深度 | 来源·强度比(% of Key)·效果 | 窗外环境漫反射，30%，轻微柔化阴影 |
| **Rim Light** | 轮廓光，勾勒主体 | 来源·方向·效果(勾勒/分离/塑形) | 旋转门方向冷蓝月光，侧逆光，勾勒女反角轮廓 |
| **Ambient** | 环境光，场景内实用光源 | 场景内光源·自然光方向·残余光 | 壁灯2700K暖黄+吊灯自然衰减 |

## 灯光模式→情绪映射

### 高调照明 (High-Key)

- **情绪**：明亮·柔和·轻松·纯净·希望
- **适用**：喜剧·浪漫·温暖·日常
- **技术**：`high-key lighting, soft diffused illumination, low contrast, even fill, bright atmosphere`
- **四步**：Key=柔光主灯(4500K) + Fill=50%以上 + Rim=轻微 + Ambient=均匀
- **阴影**：<20%
- **参考**：《布达佩斯大饭店》《天使爱美丽》

### 低调照明 (Low-Key)

- **情绪**：黑暗·神秘·紧张·压抑·力量
- **适用**：悬疑·惊悚·戏剧·权力对峙
- **技术**：`low-key lighting, deep shadows, high contrast, dramatic chiaroscuro, noir atmosphere`
- **四步**：Key=单点硬光(3200K) + Fill=10-20% + Rim=强边缘光 + Ambient=极少
- **阴影**：>60%
- **参考**：《教父》《银翼杀手2049》

### 侧光 (Side Light)

- **情绪**：立体感·戏剧冲突·内心挣扎
- **适用**：对峙·冲突·独白·双重人格
- **技术**：`dramatic side lighting, half face illuminated, deep shadow on opposite side, sculptural chiaroscuro`
- **四步**：Key=90°侧光 + Fill=极少(0-10%) + Rim=无或有轻微背光 + Ambient=暗
- **阴影**：50%+
- **参考**：《公民凯恩》《沉默的羔羊》

### 逆光 (Back Light / Rim Light)

- **情绪**：梦幻·隔绝·告别·神圣
- **适用**：回忆·告别·超现实·宗教感
- **技术**：`strong backlighting, silhouette rim, golden edge highlights, ethereal glow, lens flare`
- **四步**：Key=主体后方强光 + Fill=极少(正面靠反射) + Rim=即是主光 + Ambient=弱
- **阴影**：面部50-70%（正面暗）
- **参考**：《降临》开场·《银翼杀手》角色登场

### 顶光 (Top Light)

- **情绪**：孤立·威严·恐怖·审讯
- **适用**：权力·压迫·审讯·恐怖
- **技术**：`harsh top-down lighting, deep eye socket shadows, ominous overhead illumination, vertical light shafts`
- **四步**：Key=正上方硬光 + Fill=无或极少 + Rim=无 + Ambient=黑暗
- **阴影**：眼窝深陷·鼻下·唇下浓影
- **参考**：《教父》马龙·白兰度·《沉默的羔羊》汉尼拔

### 蝴蝶光 / 派拉蒙光 (Butterfly / Paramount)

- **情绪**：优雅·高贵·女神·仪式感
- **适用**：女性特写·仪式·梦幻·时尚
- **技术**：`butterfly lighting, paramount lighting, soft overhead key, butterfly shadow under nose, glamorous`
- **四步**：Key=正上方高位柔光 + Fill=低位补光 + Rim=轻微发丝光 + Ambient=柔和
- **阴影**：鼻下蝴蝶形阴影·颧骨下方柔和阴影
- **参考**：《乱世佳人》·《了不起的盖茨比》

### 混合色温 (Mixed Color Temperature)

- **情绪**：视觉张力·冷暖角力·内外分裂
- **适用**：内外对峙·情感分裂·文化碰撞
- **技术**：`mixed color temperature, warm interior practical light 3200K + cool exterior light 6500K, color temperature contrast creating visual tension`
- **四步**：Key=暖色室内光(3200K) + Fill=冷色室外光渗透(6500K) + Rim=冷暖交替 + Ambient=双重
- **阴影**：冷暖阴影并存
- **参考**：《银翼杀手2049》·《迷失东京》

| 5500K | 正午日光 | 纯白 | 客观·清晰 |

## 禁忌组合

| 禁忌 | 问题 | 修复 |
|------|------|------|
| 两个等强Key光 | 鼻影双线(双重鼻影) | 一主一辅，辅光降为Fill |
| 顶光+底光同时 | 恐怖片效果(无意) | 只保留一个方向 |
| 冷色温Key+暖色温Fill(无理由) | 混乱·不自然 | 必须有场景内光源依据 |
| 无环境光依据的光源 | 观众疑惑"光从哪来" | 每个光源必须有Practical来源 |
