# 服装与配饰提取技能（V3.0）

## 用途

从多张不同场次的剧照或参考图中，精准提取服装与配饰细节，输出结构化档案，供：
- 剧组服装管理与连戏核查
- 角色视觉一致性维护
- 生成可直接投入AI生图工具（Midjourney / Flux / Seedance 等）的Prompt片段

**只分析服装与配饰，不描述人物外貌、身份或性格。**

---

## 触发条件

- 用户上传角色图片并要求提取服装/配饰信息
- 用户提供剧本文本并要求从中提取服装/配饰描述
- 用户需要生成服装档案或服装速查表
- 用户需要用于AI生图的服装+配饰Prompt

---

## 输入模式

本技能支持两种输入模式，执行方式略有差异：

| 模式 | 输入内容 | 分析依据 |
|------|----------|----------|
| **图片模式** | 剧照 / 参考图 | 视觉识别，直接观察服装配饰 |
| **剧本模式** | 剧本文本 / 场景描述 | 从文字中推断、整理服装配饰信息 |

**剧本模式说明：**
- 扫描剧本中所有与服装/配饰相关的描述（包括场景说明、人物行为、对白暗示）
- 按角色 × 场次维度整理，若剧本未明确描述则标注「剧本未提及，建议参考视觉参考图」
- 可结合剧情语境进行合理推断（如「黑帮晚宴」推断正式西装+领带），但推断内容需注明「依剧情推断」

---

## 执行流程

### 第一步：确认输入

**图片模式：** 收到图片后，若用户未标注场次，主动帮用户标注（场次1、场次2……），并简短确认场景描述。

**剧本模式：** 收到剧本文本后，先扫描全文，列出所有出现服装/配饰描述的场次编号和角色，与用户确认分析范围（全部角色 or 指定角色）。

### 第二步：逐场次分析

**图片模式**对每张图片、**剧本模式**对每个有服装描述的场次，按以下结构输出：

```
**场次N：[场景简述]**

**【服装章节】**
- **整体风格**：（赛博朋克 / 优雅高定 / 暗黑哥特 / 简约现代等）
- **主色系**：主色 + 辅助色 + 点缀色
- **上装**：款式、材质、剪裁、细节（领口、袖型、长度、装饰）
- **下装**：款式、长度、材质、细节（裤型、裙型、褶皱等）
- **外套/外层**：有无、款式、长度、材质
- **鞋子**：类型、颜色、跟高、特色
- **服装状态**：新旧程度、破损、褶皱、湿润等
- **整体服装氛围**：

**【配饰章节】**
- **耳饰**：耳环/耳钉/耳夹（类型、材质、颜色、形状、大小、悬挂方式）
- **颈部配饰**：项链、颈链、围巾、领结（长度、坠饰、材质）
- **手部配饰**：手链、手环、戒指、手套（左右手分别描述）
- **头部配饰**：发饰、发夹、帽子、头冠、眼镜
- **腰部及身体配饰**：腰带、腰链、胸针、别针、腿环
- **其他配饰**：包包、丝袜、披肩、纹身贴等
- **配饰材质与质感**：金属、光泽、宝石、水晶、珍珠、哑光等
- **配饰整体风格**：奢华 / 简约 / 复古 / 未来感 / 民族风等
```

**剧本模式特有字段（在每场次末尾追加）：**
- **剧本原文依据**：引用剧本中对应的原始描述片段
- **推断说明**：若为依剧情推断，注明推断逻辑（如「依黑帮晚宴场景推断」）

### 第三步：场次-服装配饰速查表

在所有场次详细分析之后、跨场次总结之前，输出速查表：

```markdown
**【场次-服装配饰速查表】**

| 场次编号 | 场景描述 | 核心服装（一句话概括） | 标志性配饰（1-3件） | 整体色调 |
|----------|----------|----------------------|-------------------|----------|
| 场次1    | 雨夜街头 | 黑色皮质风衣 + 破洞紧身裤 | 银色颈链、铆钉手环 | 黑灰冷调 |
| 场次2    | 晚宴     | 酒红露肩礼服裙        | 水晶耳坠、金色腰链  | 深红金奢 |
（根据实际场次填写）
```

### 第四步：跨场次总结

```
**跨场次总结**
- **核心服装元素**（贯穿所有场次的共同特征，3-5条）
- **核心配饰元素**（经常出现的标志性配饰，3-5条）
- **变化规律**（不同场次中服装和配饰如何调整）
```

### 第五步：AI生图Prompt片段

为每个场次分别生成一段精炼的「服装+配饰」描述（80-150字），可直接粘贴至 Midjourney / Flux / Seedance 等工具使用。

### 第六步：视频提示词生成

**完整视频提示词由「开场状态」+ 逐Shot组成。有台词的Shot单独成块输出。格式严格如下：**

```markdown
# 视频提示词

## 开场状态：
环境：@场景标签（时间/地点/氛围），整体色调与光感描述 <环境音效>
站位关系：[角色A] 与 [角色B] 的空间位置关系
@角色A：[详细位置、姿态、朝向、与场景中其他元素的空间关系]
@角色B：[详细位置、姿态、朝向、与场景中其他元素的空间关系]
@服装/配饰标签：[状态描述、完好/破损程度、特殊说明]
灯光：主光为 [光源方向 + 色温 + 光质]；[副光说明]；实用光为 [场景内光源]

---

## Shot 1
duration: X.Xs

镜头：[景别]，[角度]，[运镜]，[焦距]，[景深]，[速度]，[稳定器]。[镜头运动详细描述]

画面：[详细视觉描述，聚焦本技能提取的服装与配饰元素]
[服装动态/配饰位移+写实质感：自然噪点、色彩还原、面料纹理、配饰材质反光]
[如有眼泪→追加眼泪增强关键词]

光影：[色温] [光质描述]；[阴影占比]，[反差描述]

---

## Shot 2
duration: X.Xs

镜头：[同上格式]
画面：[同上，服装动态变化/配饰位移随时间推进]
光影：[同上格式]
```

**提示词书写规则（必须遵守）：**
1. `# 视频提示词` 为总标题，`## 开场状态：` 统领全场景，用 `---` 分隔各Shot
2. `开场状态` 覆盖：环境+站位关系+各角色姿态+服装配饰状态+灯光，一次定义全场共享
3. 每个Shot含 `duration` + `镜头` + `画面` + `光影`，不重复开场状态中已定义的信息
4. 有台词时，在 `画面` 段落后追加 `@角色名 (情绪·音量·效果)：{对白内容}`，无台词则省略
5. `画面` 必须聚焦本技能提取的服装与配饰元素，含写实质感关键词（自然噪点、色彩还原、面料纹理、配饰材质反光）
6. `光影` 必须含色温(K)、光质、阴影占比、反差描述
7. 每个Shot提示词独立成块，有台词的Shot绝不与其他Shot合并
8. 所有描述必须来自本技能提取的结果，不得虚构

### 眼泪表情专用增强关键词

**当剧本涉及「哭泣 / 流泪 / 含泪 / 眼泪」时，在「画面」段落中必须追加以下关键词：**

| 关键词类别 | 具体关键词（直接粘贴至提示词） |
|-----------|---------------------------|
| **泪液物理** | 泪液折射、泪痕反光、泪珠表层张力、晶莹泪滴、泪液沿面部轮廓滑落轨迹 |
| **服装联动** | 泪滴滴落衣襟形成深色湿润斑点、领口被泪水浸湿颜色加深、袖口擦拭泪痕留下湿润痕迹、泪水沿颈部滑落浸入领口内侧 |
| **泪流阶段** | 初泪（眼眶微红湿润）→ 溢泪（泪滴溢出眼睑边缘）→ 滑落（泪液沿面颊滑落形成湿润反光轨迹）→ 泪痕（已干泪痕呈半透明哑光条纹） |
| **配饰联动** | 耳环因抽泣轻微晃动、项链坠饰被眼泪溅湿反光减弱、手帕/纸巾擦拭后褶皱湿润 |
| **光影交互** | 泪滴高光反射点、泪液表面对环境光的折射、泪痕反光呈冷调银白、暗部泪液依然可见微弱反光 |
| **写实质感** | 真人实拍质感、自然皮肤纹理可见、泪液物理真实、非CG水晶质感 |

> 严禁使用「水晶般」「钻石般」「珍珠般」等CG美化词汇，眼泪必须呈现真实人体泪液质感。

---

## 注意事项

- 严禁描述人物外貌（肤色、发色、五官、体型等）
- **图片模式**：若图片质量不佳导致细节不清，标注「图片不清晰，无法确认」而非猜测
- **剧本模式**：若剧本未明确提及某字段，标注「剧本未提及」；若依剧情合理推断，标注「依剧情推断」
- 配饰务必细致，尤其耳环：描述类型、材质、颜色、形状、大小、悬挂方式
- 速查表每场一行，保持横向对比简洁
