# 演员情绪、动作与镜头接续

## 1. 把心理意图转为可拍证据

每组先确定人物此刻想得到什么、压住什么、在对方面前维持什么状态。主情绪为表演提供方向，具体时间段负责呈现证据；不要用“内心五味杂陈”替代演员能做的动作。

可用的组织方式是：**触发 → 第一反应 → 行动 → 对手反馈 → 收住后的状态**。这条链可以跨镜完成，短反应镜也可以只拍其中一环，不固定成五项字段。

例如被质问后，嘴唇先微启，目光仍想接住对方；看见对方没有等待，她停住解释，呼吸短暂停顿，只说出原稿给定的一个词。犹豫存在于行动中断处，不能靠连续添加“害羞、害怕、尴尬”完成。

复杂情绪允许两层并存：

| 剧情需要 | 可见表演的选择 | 需要保留的事实 |
| --- | --- | --- |
| 维持职业平静，却受到羞辱 | 声音保持平稳，视线短暂移开，手指收紧后主动松开 | 不能因受辱自动改成哭泣或讨好 |
| 已经觉醒，仍需履行约定 | 先完成既定行动，再抬眼直视对方，动作稳定，目光不再寻求认可 | 义务与依恋不是同一原因；以当前剧情判断 |
| 接受关系的情人表现妩媚 | 保持亲近距离，用轻柔语气、含笑停顿与指尖触碰表达交流目的 | 不擅自变成嫉妒、愤怒、争吵或离席 |
| 躺着的人慢慢情不自禁 | 支撑与躺姿不变，呼吸或目光先变化，接触动作由轻到实，并观察对方反馈 | 不自动坐起、翻到对方上方或突然强势推进 |

这些是条件示例，不能变成每个故事人物的固定心理。爱、掌控欲、依赖、表面冷淡可以并存；判断来自当前源剧情与用户要求，不能从样例某句“不是爱情”推断整个角色。

## 2. 微表演要少、准、看得见

- 视线写具体戏内目标和变化顺序：“从合约落到母亲的手，再抬向母亲脸上”。“正面近景”不等于看镜头；除非原剧情需要，目光仍落在戏内对象。
- 呼吸写变化与控制：“原本平稳，听见一句话后停半拍，再缓慢恢复”，不要每镜急促喘息。
- 手部写作用：抓住、稳住、试探、拒绝、遮掩、松开；手指小动作要有承载面或受力对象，不能悬空乱动。
- 停顿写发生在哪个动作或词后，以及停住时仍看谁、手在哪。真实静止包含呼吸和身体承托，不要求影像冻结。
- 按景别选择一两个观众能看清的细节。面部近景不同时要求看见画外脚步落点；双人中景不依赖极细微瞳孔变化传达唯一剧情信息。
- 不把眨眼、吞咽、叹气、嘴角上扬、落泪当每镜通用标点。当前要求“不要叹气/不要微笑”时，连同转场和镜尾也排除这些动作。

## 3. 对象、路线、受力与终态

动词需要对象和结果。写“将她拉近”前，交代谁处于什么姿势、哪只手接触哪里、对方是否顺势移动、身体由哪里承托。写完后交代两人停在哪里，下一镜才能承接。

复杂动作先按真实身体顺序推导，再选镜头：

- 翻身：起始仰卧/侧卧、头向、床内外侧、支撑手、重心转移、肩背与头部落点、结束时空闲与受压的手臂。
- 递物/扔物：起始持有人、哪只手、出手方向、物件路线、承接者或落面、最终谁持有。扔出的支票不能下一镜又自动回到手中。
- 走位：起点、目的、经过路线、需要的脚步与落座时间、终点朝向。不在两秒内塞入跨房、落座、脱鞋与躺下等多个完整动作。
- 门内外关系：门的开度、人物站在内侧还是外侧、彼此是否可见、声音是否隔门、关门后谁还能看见谁。

主动作的承受者要有反馈。反馈可以是配合、避开、短暂停住、视线移走或完全不回应，不必一律夸张反应。

## 4. 服装由资产决定，动作仍完整

这位用户已要求服装、妆造由引用资产决定。正文保留行动，用中性受力对象承接，不描绘具体穿着或重新设计造型。

| 原描述的问题 | 保留动作的中性写法 |
| --- | --- |
| 以颜色、款式、材质设定外观 | “人物外观沿用指定资产”，不重复造型 |
| “拢紧领口/拉紧睡袍系带”假定了服装结构 | “手指将身前触及的衣料向内抓拢，随后短促拉紧” |
| 删除整句导致角色不再动作 | 保留转头、抬手、抓拢、拉紧、放开的发生顺序与力度 |
| 旧样例写胸口敞开，当前用户要求扣住 | 当前稿明确“衣物保持扣合，胸口遮盖”，不带回敞胸状态 |

资产正式名称中包含“睡衣”时保持名字准确，它是素材标识。光影、现场声与转场段也需检查，避免从“黑色丝质睡衣在暖光中……”等旁支重新引入外观要求。原文台词中出现服装词时仍逐字保留，不能为中性化画面而改对白。

## 5. 摄影选择服务于行动和情绪

选择机位前先确认观众需要看见什么：关系位置、触发物、主动动作、被影响者，或动作后的落差。焦段是可选摄影描述，不能代替机位方位、距离、构图与真实空间。

- 关系镜建立门口与床边、桌两侧等实际落点，后续特写仍需可追溯的视线对象。
- 近景承载情绪在脸上变化的时间，不急着用无动机切镜打断演员。
- 手部插入要接住上一镜已经开始的动作，下一镜接其结果；不要每个角度重新抓一次、再抬一次头。
- 横移可揭示被前景挡住的角色或手部；推进可把注意力集中到已发生变化的目光。固定镜头可以让对手反应同时被看见。
- 环绕写清绕谁、从哪个侧面到哪个侧面、弧段内关系轴线如何处理。必要时留在同侧小弧段；跨轴需建立可见过渡，不能同时规定环绕后所有人仍固定画面左右。
- 同一事件换机位需重新推导左右、远近、目光和前景遮挡；空间中的真实左右不等于画面左右。必要动作在画外时，不再宣称观众能看见该动作细节。

## 6. 台词不是情绪标签的附件

一条表演完整的对白包含：向谁说、希望对方怎样回应、此刻的气息与力度、词句间的停顿、说话时的动作、说完如何停住。保留原文，不擅自加词或改说话人。

对手应在听的过程中产生有依据的反应，不能等所有对白结束才统一表情变化。无台词段保持沉默行动，不添加“Please…”等口型来填充。

所有声音先判定声源：画内对白、画外对白、原有旁白、原有内心独白、自然环境与接触声、额外主观音效。纯画面说明不生成语音。“@音频”只有确切文件映射才成立；角色音色绑定不是独立音频文件。

## 7. 用时间和状态核验可执行性

有录音时按实际长度分段；无录音时朗读估算仅用于初稿。长句需要完整说完和必要反应时间，不能标“慢速”却挤入明显不足的秒数。镜头长度也要覆盖可见路线与动作阶段。

末镜留下稳定终态：视线、手、姿势、道具和接触关系具体。下一组从该状态开始；需要时间跳跃、闪回或成年/少年转换时明确标明，并列出实际对应资产。

只凭文本核对可以证明结构和动作设想，不能声称实际画面、口型、音频同步或生成质量已经通过。发现关键事实无法确定时，仅停住受影响部分并核对源稿，其余独立内容可继续。
