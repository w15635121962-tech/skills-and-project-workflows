# 分组时间轴表演提示词

以用户2026-10-22提供的EP01–EP10样例提炼写法。保留目录名 `short-drama-prompts-v3` 供旧入口调用，当前新稿默认已替换为分组时间轴格式。原Shot八字段只用于用户明确指定或既有批准稿的局部修订，不与新模板叠加。

新写或重做最终提示词时，读取[时间轴格式与模板](references/timeline-format.md)及[演员表演与动作接续](references/performance-writing.md)。只改批准稿某处时，按当前要求局部修改，冻结其他事实、结构、台词和引用。

## 先确定本组真正发生什么

- 读完交付范围内源剧情，明确事件顺序、人物目标、关系压力、真实位置、道具及前后状态；样例是写法资料，其人名、心理判断、服装和台词归属不能覆盖当前原剧本与用户最新要求。
- 先写清本组改变什么，再决定镜数、时长、景别和运动。一个时间段承载一个主要动作或紧密相连的反应，不固定15秒、三镜、单人同框或环绕运镜配额。
- 区分源对白、源旁白、内心独白、画外对白与纯画面说明。保留原语言原文及标点；不能凭画面主体确定声音归属，也不能把画面说明生成旁白或口型。
- 有对应音频时实测时长并核对文本；没有音频则注明朗读估算。段长需要容纳说话、行动及必要停顿，不能靠擅自删词或加速凑数。

## 默认交付形态

已知集号时写集号，随后每组按以下顺序组织：

1. `Sxx. 事件——本组关系或情绪变化`。
2. `【风格：…。画质：…。约束：…。主情绪：…。】`，主情绪写表面状态、内在压力与可表演变化。
3. `【光影：…】`，明确实际光源、方向、亮暗范围及人物和关键动作能否看清。
4. `@场景…；@人物…；@道具…`素材映射，只列本组实际出现、原稿需要或用户指定的对象；说明参考资产状态与画幅，默认竖屏9:16。
5. 连续时间段：`起止秒数：【摄影安排】人物起始状态 → 可见行动与反应 → 原台词及说法 → 动作停点`；必要接触音以`<音效>`穿插。
6. `现场声：…`收束真实环境底声和接触声；对白、旁白与额外主观音效的允许范围按当前要求注明。

交付可复制的正文，不再按Shot八字段逐项展开，不附加导演表、检查表或分析报告。用户明确要分析时才另交分析。

## 演员先有目标，再有表演

主情绪用于决定行动强度与节奏，不能只写“伤心、霸气、妩媚”。用一个当前目标、一个内在阻力和少量可见证据建立复杂情绪。人物可以说得平静而手指收紧，也可以保持亲近姿态而目光已经撤开；具体取舍来自源剧情与当前人物阶段。

按“触发 → 第一反应 → 行动 → 对手反馈 → 收住/稳定终态”核对因果，不把它变成每镜必须填满的五项清单。根据景别选一两个有效细节：视线落点、呼吸变化、手部力度、肩背与重心、语言停顿。避免每镜重复攥衣、吞咽、颤抖、红眼；没有依据不默认哭泣、叹气、微笑或新增亲密动作。

动作写清人物名、起点、对象、路线、受力或支撑点与落点；必要时明确哪只手。互动不仅写主动者，也写承受者如何反应、是否回应。没有新变化的停住可以成为有效镜尾，不必每镜完成情绪反转。

## 服装、空间与声音的硬事实

- 已引用资产时，服装及妆造外观由指定资产决定；不另写品类、颜色、材质、衣襟结构、滑肩、敞胸等造型。用户明确要求的扣合或遮盖状态照实保留。资产名称中的“睡衣”等标识不改名。
- 删除服装外观描述时保留抓拢、拉紧、整理、放开等剧情动作，用“衣物/衣料”等中性受力对象或清楚的双手运动承接，不凭空增加纽扣、系带等结构。原台词中的服装词仍逐字保留。
- 每次换机位重新推导画面左右。实际床位、门位、远近、人物朝向、视线对象、道具持有及动作阶段连续；过肩前景与后景比例、遮挡及支撑面可成立。环绕写清中心、弧段、起止方位和是否跨轴，不能靠全组固定左右代替推导。
- `@音频1`只在有确切音频映射时使用；角色音色引用与独立音频文件分开记录。纯画面说明不编号为音频，旁白不触发演员口型。平台原生卡须由实际操作与回读确认，文本别名不代表已绑定。
- 声音只写可听事件；心跳等主观音效按当前授权明确标注。没有旁白的要求不覆盖已批准对白。禁止新增字幕/水印与剧情需要的道具文字分别处理，不写互相冲突的总约束。

## 交付前在内部核对

核对原文覆盖、说话人与声音类型、时间段连续及总长、微表演可见性、前镜终态和后镜起态、道具与年龄资产、服装中性化以及机位视线。质量与光影词保持简洁一致；真人写实稿不混入无否定的CG/3D风格词。

本技能产出提示词文本。平台操作另读[剧梦制作技能](../jumeng-episode-producer/SKILL.md)，只执行本次授权阶段；技能更新不自动重写既有平台镜头、上传、生成或扣费。
