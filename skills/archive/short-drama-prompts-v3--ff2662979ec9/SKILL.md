# 提示词3.0进化版

以用户提供的截图为文字格式依据，把剧本内容写成能执行、能衔接的镜头提示词。3.0的提升落实在动作清晰度、表演、视点和连续性中，保持截图的字段结构。

首次按此技能制作提示词时，阅读[截图格式与示例](references/screenshot-format.md)。需要核对截图原貌时查看[原始截图](references/source-format.png)。这些参考文件与本技能自成一套，不依赖其他提示词技能。

## 固定输出格式

每组先写三项总设定，顺序为：出场角色 → 场景 → 画幅。

场景与画幅之间放全局参考图锁定说明。已有参考图时使用原句：

以下所有Shot出场的角色和场景统一锁定参考图。

未提供参考图时，在总设定中如实注明参考图待指定，不虚构素材名或已绑定状态。画幅默认“竖屏9:16”；用户明确指定其他画幅时按用户要求。

镜头标签使用“Shot01:”“Shot02:”，按交付范围连续编号；用户已有镜号时保留其编号。每个Shot严格按下列八个字段排列：

时长 → 环境氛围 → 景别 → 拍摄角度 → 摄像机运动 → 人物角色和运动 → 人物表演 → 画面内容。

使用中文字段名和中文画面描述；英文仅用于原文台词、原有可见文字和必要的镜头术语。每个字段独占一段，镜头之间留空行。默认交付可直接复制的纯文本，不用表格、JSON或额外说明包裹正文。

不自行新增“音频”“焦段”“景深”“负面提示词”“画质词”等独立字段。必要的机位、构图、遮挡及清晰度信息写进现有字段。用户明确要求扩展字段时才调整输出结构。

## 从原稿到镜头

- 先读完本次交付范围内的原稿，辨明人物、场景、动作顺序、对白、旁白与重要道具，再决定镜头数量。输入缺失到无法判断动作归属时，只问影响当前制作的必要信息。
- 以本次剧本和用户指定资产为准。截图里的人名、会客厅、合同、镜数、3秒及1.5秒都是示例，不是固定故事或时长。
- 保留原稿的事实、动机、关系、动作结果和事件顺序。补充镜头、反应和手部细节应表现已有信息，不替原稿增加新的事件或对白。
- 不用几个“名场面”代替用户要求的完整段落或完整集数。对白和旁白所包含的叙事信息均需要对应画面；旁白默认用于决定拍什么，不自动变成角色口播。
- 用户指定的角色名、场景名、素材名及服装状态原样沿用。用“角色名（@素材名）”表示已提供的引用名称，不擅自换成近似素材、其他年龄/体型/性别/服装版本。文字中的@标记不等于平台已完成真实绑定。
- 本技能默认产出或修改提示词文本；生成镜头数量和平台实际生成状态分别核对，不把文本准备描述成平台已制作完成。

## 3.0镜头写法

### 一镜一个清楚的叙事任务

先确定观众在这一镜应该看见、理解或感受到什么，再安排机位与动作。一个Shot可以有紧密相连的动作和短反应，但不要把跨房走动、落座、递合同、读完对白和情绪转折全部挤进一个短镜头。

时长随实际动作调整。1—2秒通常只适合瞬时特写、简单动作或短反应；较长路程、复杂互动或对白需要相应延长或拆镜。用户给定总时长时核对各镜之和；动作与原台词无法装进指定时长时，说明具体冲突，不删改原话来假装满足。没有实测音频时，不声称已精确核验朗读时间。

### 让每个动作有明确归属

在“人物角色和运动”里写清：谁在什么位置、朝向谁、做什么、道具在谁手上、动作落到哪里。优先用人物名指代行动者；多人互动时避免连续使用“她”“对方”“坐在她对面”等模糊主语。

例如写“Serafina在女主对面的单人沙发落座；女主始终坐在右侧长沙发”，不要出现角色坐在自己对面的矛盾。写手部时，明确哪只手、物件朝向、推动方向和接收者，维持后续镜头的一致性。

### 用可观察的表演呈现情绪变化

“人物表演”承接动作中的心理变化，用眼神落点、呼吸、停顿、肩背、手指、嘴角、重心等可见细节表达，标明具体人物，例如“【女主】”“【Serafina】”“【肢体细节】”。

需要时写出反应顺序，例如“先看合同金额，指尖停住，再抬眼望向Serafina”。不要求每镜都完成情绪反转，不用固定表情堆叠或反复出现“冷酷、强大、震惊”来替代表演。

原稿需要表现对白时，把英文原台词逐字放在对应人物的“人物表演”字段内，保留单词与标点，不翻译、改写或额外编台词。用同一字段说明说话时的动作与停顿。用户明确要求无台词画面时按其要求处理。

### 让机位和运动各司其职

- “拍摄角度”写摄影机相对于人物或道具的方位、高低和视点；构图有叙事作用时可一并说明。
- “摄像机运动”写清运动方式、跟随对象、方向和起止。人物走路不等于摄影机必须移动；固定镜头也是有效选择。
- 区分推进/拉远与跟拍。例如Push In用于向主体靠近；跟随移动人物时写跟随谁、从哪里跟到哪里。术语的中文、英文和实际动作应一致，不为了高级感叠加互相冲突的运镜。
- “画面内容”说明最终看见什么、视觉主体是谁、注意力先落到哪里及该构图的作用，不机械复述前面全部字段。竖屏中关注脸、手、道具及双方反应是否都能被看清。

### 用上一镜的落点接下一镜的起点

相邻镜头保持人物左右位置、轴线、视线方向、姿势、服装、道具归属及动作阶段一致。新机位需要越轴或改变视点时，用可见调度、过渡镜头或明确的视点建立关系。

道具特写要能追溯到上一镜谁持有、放在哪里；反应镜头要说明人物看到了什么；不要让坐着的人无故站起、文件自行换手、另一人物凭空出现。跨场景时重新写总设定，重新锁定该组人物和场景。

原稿要求的文字可保留，例如合同标题。避免把细小字的准确生成作为观众理解剧情的唯一依据；必要时用手部动作、金额位置或后期文字处理要求辅助表达，仍写在现有字段里。

## 交付前核对

先检查再交付正文，用户未要求时不额外附质检表：

- 总设定与八字段齐全、顺序正确，镜号和时长明确。
- 本次原稿覆盖完整，角色/场景/素材对应正确；没有把示例人物或场景带入其他剧本。
- 动作主语、空间关系、道具归属及相邻镜头的起落点能够衔接。
- 表演是可观察的行为；景别、机位和运镜服务于同一个镜头任务。
- 原台词及指定可见文字准确，旁白没有被误写成角色口播。
- 用户给定的画幅、镜头范围与时长条件已落实；未核验的绑定或音频时间没有被写成已验证事实。
