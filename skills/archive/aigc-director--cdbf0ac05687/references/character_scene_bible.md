# 角色与场景圣经 (Character & Scene Bible)

## 目的

角色与场景圣经是整个项目的视觉基石。它确保所有分镜中角色的外貌、场景的环境保持高度一致。

## 三、一致性检查清单

### 角色一致性
- [ ] 同一角色在不同场景中面部特征一致
- [ ] 服装在同一连续场景内不变（除非剧情需要）
- [ ] 发型在同一连续场景内一致
- [ ] 角色身高/体型比例一致
- [ ] 标志性配饰始终出现

### 场景一致性
- [ ] 同一场景在不同时间出现时布局一致
- [ ] 道具位置在不同镜头间合理衔接
- [ ] 光线方向在不同角度镜头间一致
- [ ] 门窗位置在不同角度镜头间合理
- [ ] 季节/天气在同一连续时间段内一致
