# 五轮自检协议 (Quality Checklist)

## 目的

确保每一份分镜脚本都达到可执行的专业标准。五轮自检从不同维度覆盖分镜质量的所有关键方面。

---

## 第一轮：结构完整性检查

### 检查项

| # | 检查项 | 标准 | 通过 |
|---|--------|------|------|
| 1.1 | 12 列表格完整 | 每个镜头都有完整的 12 列信息 | ☐ |
| 1.2 | 镜头编号连续 | 无跳号、无重复 | ☐ |
| 1.3 | 场景建立 | 每个新场景的第一个镜头是建立镜头（WS/EWS） | ☐ |
| 1.4 | 景别变化 | 同一场景内景别有变化（不全是同一种景别） | ☐ |
| 1.5 | 运镜多样 | 同一场景内运镜方式有变化 | ☐ |
| 1.6 | 时长合理 | 单镜头时长 1-10 秒，场景总时长与剧本匹配 | ☐ |
| 1.7 | 角色出场 | 角色首次出场有足够的外观描述 | ☐ |

### 通过标准
全部 7 项通过 → 进入第二轮

---

## 第二轮：视觉一致性检查

### 检查项

| # | 检查项 | 标准 | 通过 |
|---|--------|------|------|
| 2.1 | 角色外观一致 | 同一角色在不同镜头中描述一致 | ☐ |
| 2.2 | 服装连续 | 连续场景中角色服装不变（除非剧情需要） | ☐ |
| 2.3 | 场景布局一致 | 同一场景在不同镜头中布局合理 | ☐ |
| 2.4 | 光线方向一致 | 同一场景不同角度的光线方向合理 | ☐ |
| 2.5 | 时间连续 | 同一连续时段内时间/天气一致 | ☐ |
| 2.6 | 道具衔接 | 道具位置在不同镜头间合理衔接 | ☐ |
| 2.7 | 空间逻辑 | 角色移动路径在空间上合理 | ☐ |

### 通过标准
全部 7 项通过 → 进入第三轮

## 第三轮：叙事与情绪检查

### 检查项

| # | 检查项 | 标准 | 通过 |
|---|--------|------|------|
| 3.1 | 视角服务于叙事 | 每个镜头都有存在的叙事理由 | ☐ |
| 3.2 | 情绪递进 | 情绪强度与剧情节奏匹配 | ☐ |
| 3.3 | 关键时刻强调 | 高潮/转折点有特写或慢镜头 | ☐ |
| 3.4 | 反应镜头 | 重要对白/事件后有角色反应镜头 | ☐ |
| 3.5 | 色彩服务于情绪 | 色彩变化与情绪变化同步 | ☐ |
| 3.6 | 节奏有变化 | 有张有弛，不全程匀速 | ☐ |
| 3.7 | 转场合理 | 场景之间的视觉过渡自然 | ☐ |

### 通过标准
全部 7 项通过 → 进入第四轮

## 第四轮：AI 可执行性检查

### 检查项

| # | 检查项 | 标准 | 通过 |
|---|--------|------|------|
| 4.1 | 提示词完整 | 每个镜头的 AI 提示词包含主体+环境+光线+风格 | ☐ |
| 4.2 | 提示词具体 | 描述具体可执行（无"某个东西"等模糊词） | ☐ |
| 4.3 | 角色锚定 | 提示词中角色描述与角色圣经一致 | ☐ |
| 4.4 | 运镜可执行 | 运镜描述在 AI 工具能力范围内（参考运镜五大境界） | ☐ |
| 4.5 | 无文字依赖 | 画面描述不依赖屏幕内的文字/字幕 | ☐ |
| 4.6 | 动作简单 | 单镜头内的动作不超过 2 个连续动作 | ☐ |
| 4.7 | 风格一致 | 所有提示词使用统一风格后缀 | ☐ |

### 通过标准
全部 7 项通过 → 进入第五轮

## 常见问题与修复速查

| 问题 | 影响 | 修复方法 |
|------|------|----------|
| 连续5个以上镜头使用相同景别 | 视觉单调 | 调整景别，增加变化 |
| 缺少反应镜头 | 情绪缺失 | 在关键对白后添加角色反应近景 |
| AI 提示词不含光线描述 | 画面平淡 | 为每个提示词添加光线描述 |
| 角色服装在不同场景间不一致 | 观众困惑 | 统一服装描述或标注变化原因 |
| 全程无建立镜头 | 空间感缺失 | 在每个场景开头添加远景 |
| 运镜描述过于复杂 | AI 无法执行 | 简化运镜，拆分为多镜头 |
| 色彩描述缺失 | 风格不统一 | 为每个场景添加色彩描述 |
| 场景转换无过渡 | 跳跃感 | 添加转场镜头或视觉连接元素 |
