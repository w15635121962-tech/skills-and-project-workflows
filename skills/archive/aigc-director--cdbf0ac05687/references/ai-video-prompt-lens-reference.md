# AI 视频提示词：摄影机/镜头参数化

来源：微信公众号"希区柯克变熊" / xiao-tu-kun

## 核心思路

在 AI 文生视频提示词中，**直接写明摄影机和镜头型号**，AI 模型会根据这些参数生成具有特定电影质感的画面。不是模糊的「电影感」，而是精确的硬件参数。

| 型号 | 特点 | 适用场景 |
|------|------|----------|
| Sony Venice 2 | 暗光表现强，高饱和度，电影质感 | 暗黑奇幻、悬疑 |
| Arri Alexa 65 | 大画幅，浅景深，暖调渲染 | 史诗感、末日废墟 |
| Arri Alexa Mini LF | 便携大画幅，自然肤色 | 真人短剧、情感戏 |
| RED V-RAPTOR | 高分辨率，锐利画面 | 动作片、科幻 |
| Panavision Millennium DXL2 | 柔和复古，好莱坞质感 | 年代戏、浪漫 |

## 常用镜头规格

| 焦段 | 效果 | 使用场景 |
|------|------|----------|
| 24-70mm f/2.8 | 标准变焦，灵活构图 | 通用叙事 |
| 35mm f/1.4 | 环境 + 人物，自然视角 | 建立镜头、对话 |
| 50mm f/1.2 | 接近人眼透视 | 情感特写 |
| 85mm f/1.2 | 极致浅景深、压缩空间 | 人物肖像、情绪高潮 |
| 135mm f/2 | 远距离特写、偷窥感 | 监视、跟踪 |

## 提示词模板

### 模板结构
```
[摄影机型号] + [镜头规格] + [灯光设计] + [画面描述] + [动作细节] + [氛围/影调]
```

### 示例 1：暗黑奇幻
```
Sony Venice 2, 24-70mm f/2.8, 
暗黑奇幻场景，人物的铠甲和爪子武器在昏暗光线中泛着冷光，
暗色调，低调布光，铠甲上沾有暗色血迹，
人物缓慢转动头部，锁子甲发出细微金属摩擦声，
电影感构图，35mm胶片质感
```

### 示例 2：末日废墟剪影
```
Arri Alexa 65, 85mm f/1.2,
末日废墟全景，一个人拖着巨大十字架在沙漠中行走，
远处缓慢升起的暖金色逆光，人物呈黑色剪影，
沙尘在光线中飘浮，神圣又荒凉的史诗感，
slow motion, 颗粒感
```

### 示例 3：情绪特写
```
Arri Alexa Mini LF, 50mm f/1.2,
暖色侧光从窗户斜照进室内，
女子坐在窗边，低头看手中的信，睫毛在脸颊投下阴影，
一滴泪顺着脸颊滑落，嘴唇微微颤抖，
浅景深，浪漫又忧伤，35mm胶片质感
```

## 避坑要点

1. **不要堆砌参数** — 一套摄影机 + 一个镜头 + 一种布光足够，多了 AI 会混乱
2. **先定义后描述** — 先说硬件参数，再说画面内容，AI 会按顺序理解
3. **胶片后缀统一** — 「35mm胶片质感」「颗粒感」「analog film texture」能有效消除 AI 塑料感
4. **配合运镜关键词** — 写「static camera, slow pan, dolly in」而不是「镜头慢慢动」
