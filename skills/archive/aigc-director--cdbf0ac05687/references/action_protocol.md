# 打斗/动作场景协议 (Action Protocol)

## 核心原则

动作场景的核心不是"打得多精彩"，而是**每个动作都有叙事目的**。每一拳、每一脚都应该推动故事或揭示角色。

---

## 一、动作场景设计框架

### 1.1 动作场景三要素

```
┌─────────────────────────────────┐
│         动作场景三角             │
│                                 │
│          目标/赌注               │
│         (观众关心谁赢)           │
│           /     \               │
│          /       \              │
│    节奏/韵律   空间/地理         │
│   (打斗的节奏)  (在哪打/怎么打)   │
└─────────────────────────────────┘
```

### 1.2 动作强度分级

| 等级 | 类型 | 特征 | 分镜要点 |
|------|------|------|----------|
| L1 | 言语冲突 | 对峙、推搡 | 中近景，强调表情 |
| L2 | 简单格斗 | 拳打脚踢，2-3招 | 中景+近景交替，动作清晰 |
| L3 | 持续战斗 | 多回合交锋 | 全景→中景→特写，节奏渐快 |
| L4 | 武器/群体 | 刀剑/枪战/多对多 | 建立镜头→战术镜头→关键打击 |
| L5 | 极端场面 | 爆炸/坠落/大规模破坏 | 全景为主，慢镜头关键瞬间 |

## 二、动作分镜基础

### 2.1 动作镜头类型

| 镜头类型 | 英文 | 用途 | 时长 |
|----------|------|------|------|
| 建立镜头 | Establishing Shot | 交代战斗空间和双方位置 | 2-3s |
| 全景动作 | Wide Action | 展示完整动作和移动轨迹 | 3-5s |
| 中景动作 | Medium Action | 展示上半身动作和表情 | 2-3s |
| 动作特写 | Action CU | 关键打击点的细节 | 1-2s |
| 冲击特写 | Impact CU | 打击瞬间的面部/身体反应 | 0.5-1s |
| 慢镜头 | Slow Motion | 关键转折点的放大 | 2-4s |

### 2.2 动作分解原则

**一个动作 = 三个镜头**：
```
准备（蓄力）→ 执行（动作）→ 结果（冲击/反应）
```

示例——一拳：
```
镜头1（近景）：A握紧拳头，眼神锐利 → 准备
镜头2（中景）：A挥拳打向B → 执行  
镜头3（特写）：B脸部被击中的瞬间 → 结果
```

### 2.3 动作场景时间分配

```
总时长：假设 60 秒

[0-10s] 建立：空间、双方位置、对峙（紧张感积累）
[10-40s] 交锋：动作回合，节奏递增（3-4个回合）
[40-50s] 转折：关键一击/意外事件/形势逆转
[50-60s] 收尾：胜负已分、余波、过渡到下一场
```

## 三、动作运镜策略

### 3.1 动作运镜禁忌

| 禁忌 | 原因 | 替代方案 |
|------|------|----------|
| 镜头晃动过快 | 看不清动作 | 有控制的晃动，关键时刻稳定 |
| 切得太碎 | 失去空间感 | 每个完整动作至少一个中景 |
| 永远近景 | 看不到整体关系 | 全景↔近景交替 |
| 没有反应镜头 | 动作缺乏情感 | 每次打击后必须有反应 |

### 3.2 推荐运镜方案

| 阶段 | 运镜 | 效果 |
|------|------|------|
| 对峙 | 缓慢推镜头或环绕 | 压力积累 |
| 出手 | 突然快切或甩镜头 | 冲击力 |
| 交锋 | 跟随运动方向 | 沉浸感 |
| 关键打击 | 慢镜头+环绕或固定 | 放大重要性 |
| 收尾 | 缓慢拉出或俯拍 | 宣告结束 |

## 四、AI 动作场景提示词

### 4.1 AI 动作场景的挑战

AI 视频工具处理动作场景时有以下局限：
- 复杂动作连贯性差
- 物理碰撞不自然
- 多角色交互容易穿模
- 武器轨迹不可控

### 4.2 应对策略

| 策略 | 方法 |
|------|------|
| **拆分动作** | 一个完整动作拆为2-3个AI镜头，剪辑中组合 |
| **强调结果** | 不要求AI展示完整打击过程，用冲击特写代替 |
| **利用慢镜头** | 慢速可以掩盖AI动作的不连贯 |
| **善用遮挡** | 利用前景遮挡不完美的动作过渡 |
| **音效补足** | 拳风、碰撞声、惨叫声可以增强动作感 |

### 4.3 动作场景 AI 提示词模板

```
// 对峙阶段
[角色描述] in fighting stance, facing [对手描述], 
tense atmosphere, [环境描述], 
cinematic lighting, low angle, 
slow motion, 4K

// 打击瞬间
close-up of [角色] face reacting to impact, 
pain expression, sweat droplets in slow motion,
dramatic lighting from side, 
cinematic, high detail

// 战斗全景
wide shot of [角色] and [对手] fighting in [环境],
dynamic poses, intense action,
dramatic atmosphere, dust and debris,
cinematic wide angle, 4K
```

## 五、特殊动作类型

### 5.1 追逐场景

```
阶段1（建立）：全景交代追逐路线和距离
阶段2（加速）：跟拍+交叉剪辑（追/逃交替）
阶段3（障碍）：角色穿越障碍的全景+特写
阶段4（转折）：追/逃关系变化（被反超/设下陷阱）
阶段5（结局）：追逐结束（抓住/逃脱/新的展开）
```

### 5.2 武器战斗

| 武器类型 | 镜头要点 | 安全拍摄原则 |
|----------|----------|-------------|
| 刀剑 | 中景展示招式+特写展示刃光 | 刀剑不在近景中直接接触面部 |
| 枪战 | 建立镜头→战术中景→反应特写 | 开枪用声音和反应表示，不全展示 |
| 拳脚 | 3镜头分解法 | 冲击点用角度遮挡 |
| 车辆 | 追逐跟拍+车内交替 | 碰撞用远景和反应镜头 |

### 5.3 群体战斗

**分层聚焦法**：
```
全景：展示整个战场
  → 中景A区：主角战斗（主要焦点）
    → 特写：关键打击
  → 中景B区：配角战斗（次要焦点）
    → 特写：配角关键时刻
  → 全景：战况变化
```
