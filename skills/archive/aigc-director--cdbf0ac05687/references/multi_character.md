# 多角色场面调度 (Multi-Character Staging)

## 核心原则

三个及以上角色同时在场时，场面调度的核心任务是：**让观众清楚地知道每个人在想什么、感受什么，以及他们之间的关系动态。**

---

## 一、三人场景基础阵型

### 1.1 经典构图三角

```
        A
       / \
      /   \
     B-----C
```

- **A在顶部**：A是焦点/权威方
- **B和C在底部**：B和C是平等的两方
- **适用**：审讯、三角恋、决策场景

### 1.2 对峙阵型

```
    A       C
     \     /
      \   /
       \ /
        B
```

- **B在中间**：调停者/被争夺的对象
- **A和C在两侧**：对立的两方
- **适用**：争吵、谈判、竞争场景

### 1.3 动态三角

三人站位不断移动变化，关系动态随之改变：

```
阶段1（均衡）：     阶段2（A-C联盟）：
  A                    A──C
 / \                    \/
B---C                    B

阶段3（B孤立）：    阶段4（重新均衡）：
  A                    
  |                    A
  C                    / \
  B                  B───C
```

## 二、四人及以上场景

### 2.1 桌面场景（最常见）

**会议桌/餐桌**：

```
    ┌─────────────────┐
    │   D         A   │
    │                 │
    │   C         B   │
    └─────────────────┘
```

- 正反打原则：只拍对面的人
- 关键时刻：俯拍全景展示整桌关系
- 权力暗示：坐在桌子短边/主位的人是权力中心

### 2.2 站立场景

- 圆形站位：平等对话，如朋友聚会
- 半圆形：有焦点人物，如演讲/表演
- 分组：人物自然分为2-3个小群，暗示阵营
- 动线：人物在空间中移动，形成动态关系

### 2.3 群体场景（5人以上）

**分层处理**：
1. **前景**：1-2人，最清晰，可能虚化
2. **中景**：2-3人，主要互动区域
3. **背景**：其余人，提供环境氛围

**焦点转移**：
```
全景→中景(组A互动)→中景(组B互动)→近景(关键角色反应)→全景(整体)
```

## 三、多角色运镜策略

### 3.1 230度原则

> 在多角色场景中，摄影机应避免越过"关系轴"（通常为人物间的想象连线），保持画面方向的一致性。

```
❌ 错误：摄影机从A左边跳到右边
✓ 正确：摄影机始终在关系轴的同一侧
```

### 3.2 镜头序列设计

#### 线性覆盖（按说话顺序）

```
A说话 → 拍A的近景
B回应 → 拍B的近景  
C插话 → 拍C的近景
A反应 → 拍A的反应特写
```

**适用**：对话驱动的场景

#### 反应链覆盖

```
A说出重要信息 → B反应 → C反应 → D反应 → A观察所有反应
```

**适用**：信息揭露、真相揭示

#### 环形覆盖

```
全景 → A近景 → B近景 → C近景 → 全景（确认关系变化）
```

**适用**：关系动态发生变化的场景

### 3.3 轴线跳越技巧

有时为了制造紧张感，可以**故意**跳越轴线：

```
场景：争吵升级
镜头1-5：正常轴线内
镜头6：突然跳到轴线另一侧 → 视觉上的"不对劲"
效果：暗示关系破裂、秩序崩塌
```

## 四、多角色调度实战模板

### 4.1 餐桌争吵

```
S01-01: 全景（WS）— 餐桌俯拍，四人在桌前，气氛凝重
S01-02: 中景（MS）— 父亲（A）放下筷子
S01-03: 近景（CU）— 父亲开口说话
S01-04: 近景（CU）— 母亲（B）低头不看
S01-05: 过肩（OTS）— 从B看A，A的手拍桌子
S01-06: 特写（ECU）— 儿子（C）握紧的拳头
S01-07: 近景（CU）— 女儿（D）紧张的表情
S01-08: 中景（MS）— C站起来，椅子向后推
S01-09: 全景（WS）— C走出画面，三人留在桌前
S01-10: 近景（CU）— A的表情变化
```

### 4.2 团队决策

```
S02-01: 全景（WS）— 会议室，5人围坐
S02-02: 中景（MS）— 队长（A）站在白板前
S02-03: 过肩（OTS）— 从A看其他人
S02-04: 近景（CU）— B摇头表示反对
S02-05: 近景（CU）— C点头支持
S02-06: 中景（MS）— D举手发言
S02-07: 过肩（OTS）— 从D看A
S02-08: 特写（CU）— A的眼神变化（被说服）
S02-09: 全景（WS）— 所有人站起，气氛转变
```

### 4.3 派对场景

```
S03-01: 全景（WS）— 宽敞客厅，人群流动
S03-02: 跟随（Tracking）— 主角穿过人群
S03-03: 中景（MS）— 主角到达吧台
S03-04: 过肩（OTS）— 主角看到对面角落里的某个人
S03-05: 特写（CU）— 主角的表情
S03-06: 中景（MS）— 目标人物正在和别人交谈
S03-07: 跟随（Tracking）— 主角穿过人群靠近
S03-08: 双人中景 — 两人视线交汇
S03-09: 特写（CU）— 目标人物的微表情
```

## 五、注意力引导技巧

| 技巧 | 方法 | 效果 |
|------|------|------|
| 光线引导 | 让焦点角色处于最佳光区 | 观众自然看向亮的区域 |
| 运镜引导 | 推镜头至关键角色 | 强制引导注意力 |
| 构图引导 | 三分线放置关键角色 | 视觉重心 |
| 动作引导 | 焦点角色有微动作 | 动态吸引注意 |
| 静止对比 | 其他角色静止，焦点角色动作 | 对比突显 |
| 景深引导 | 浅景深，焦点角色清晰 | 模糊分散注意力 |
