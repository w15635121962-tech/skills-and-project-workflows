# 当前提示词格式（分组时间轴）

读取 [分组时间轴表演提示词](../../short-drama-prompts-v3/SKILL.md)、[时间轴格式与模板](../../short-drama-prompts-v3/references/timeline-format.md) 与 [表演写法](../../short-drama-prompts-v3/references/performance-writing.md)。本文件仅保留旧路径作为兼容入口，不维护独立规范。新写、续写或重做最终提示词采用最新 Sxx 标题、总设定和连续分段时间轴，不再强制 Shot 八字段。普通镜头设计稿按用户当前所需格式交付，不自动增加最终提示词或独立分镜表。

新稿按已知集号、Sxx 标题、【风格/画质/约束/主情绪】、【光影】、@场景/人物/道具映射、参考资产声明和画幅、连续起止秒数【摄影】与可见动作反应、原台词及说法、现场声组织。角色、场景、道具及素材名均来自当前真实输入；原台词按源语言逐字保留，不编对白。动作有明确主语、对象、落点和对手反应，情绪落实到可观察表演；无台词画面不新增旁白、字幕或意外口型。

平台原生引用按本次批准的位置插入。新稿通常在资产别名映射和本次指定的时间段具名位置绑定；保留角色名、动作和邻接正文。普通 @ 文字不等于原生绑定。独立音频文件引用与角色音色是两种来源，按平台实际支持和用户提供的真实映射分别核对，不用角色卡冒充音频文件卡，也不把 @音频 占位符报告成已绑定。仅绑定、保存或提交已批准旧稿时，保持原结构和原引用位置；局部修订冻结未请求的事实和结构。
