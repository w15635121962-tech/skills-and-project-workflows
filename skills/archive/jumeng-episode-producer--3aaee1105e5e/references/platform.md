# 平台填写、持久化与生成

## 分镜与设置

1. 使用支持相关操作的专用工具；没有时用 Computer Use 按实时工具文档操作用户指定浏览器。核对项目、集数、当前 storyBoardId；不要照搬历史项目 ID、DOM ID 或坐标。每次操作前及读取结果后再次确认当前镜号，页面若被用户切换先重新定位授权目标，不能把别组结果记到本组。
2. 在选集下拉选择目标集；缺失时按授权新增并命名“第xx集”。先检查已有槽位，按提示词组数补足，不重复创建。
3. 在当前分镜的主提示词区填完整组稿；不能把截断的页面文本当全文覆盖，也不能误填历史结果文本框。
4. 绑定引用前阅读 [素材绑定](asset-binding.md)。新时间轴稿在资产别名映射及本次批准的具体时间段具名位置插入原生卡；旧稿沿用原引用字段和位置，正确位置跳过，保留相邻角色名称、动作和标点，不为绑定转换格式。角色当场版本、场景及道具须与映射一致。音频文件引用与角色音色分别核对，不把角色卡或 @音频 占位符冒充真实音频文件卡。
5. 若采用平台“一键引用”，完成选择后点“确认并引用”，等待实际结果，再检查正文、原生卡和归属。长时间无响应时查状态，不能反复盲点。
6. 模型、分辨率和时长按用户当前要求。旧项目默认“九梦 2.5 Pro / 480P”，仅在项目沿用且当前平台提供时使用；时长可经参数弹窗“按秒数”填写组时长。单独素材修复保持原设置。

## 保存验证

- 有对白与无对白组均核对用户当前的字幕和声音要求。新时间轴稿把源语言原台词及说法放在对应发言时间段，必要同步音效贴合动作，持续环境声汇入现场声；不再指定旧 Shot 八字段或人物表演字段。仅按真实来源核对独立音频文件与角色音色，未提供或未绑定的不写成已完成。已有批准正文沿用其结构和引用位置，不借此改稿。参考图字幕不自动继承；需要的戏内比分、评论或道具文字按源剧情归属核对。
- 当前平台若实际提供自动字幕、翻译字幕或文字叠加开关，按用户要求关闭并回读保存状态；未提供开关时记录为不适用，通过提示词与用户范围内的画面核验执行。不得凭记忆虚构选项或把改稿称字幕已消失。

- 每组检查完整正文、原生卡文件名/归属、总设定素材与本次指定的逐镜引用位置，以及模型、分辨率、时长；清除“请选择”等未完成状态。
- 使用页面实际保存机制并观察状态；安全保存后切换分镜或剧集再返回，回读正文、素材卡和设置。先用一组确认可持久化，再扩展批量操作。
- `fill()`、TipTap setContent、顶部卡片、新增槽位数量都不等于持久保存。历史内部 API、inline-mention value/extraProps 结构不作为可执行适配器；若今后采用适配器，应有当前受支持接口依据和真实回读验证。
- 出现空正文或丢卡时停止继续批量写入，保留本地稿，定位正式保存机制再恢复。
- 5000 字超限或敏感词提示需单独报告。绑定成功不等于可生成；绑定任务不授权压缩内容。修改提示词须保持用户锁定事实及源语言原台词。

## 生成与收尾

已授权生成且草稿校验通过时，先完成模型、分辨率和时长设置，再核对当前主提示词区的全部主要人物原生卡：指定文件名、缩略图、组头与逐镜归属均正确，且保存后重新载入仍有效。主要人物没引用到指定资产，一律不生成；出现空卡、“请选择”或设置后丢卡，立即停止并修复，不能只看卡片数量。确认通过后提交当前组，核对该 storyBoardId 的生成历史/任务 ID 确认进入生成中，再处理下一组。无法确认是否提交时先查历史，不重试扣费动作。排队不代表生成完成；若用户要求完成视频，核对当前镜号、此次提示词版本对应的最新历史和实际视频返回。内容回放仅按用户范围或具体未解决问题执行，不扩大复核。没有实际回放不得称表演或口型通过，失败或平台阻碍如实记录。

用户要求连续完成所列各集时按既有授权持续推进；遇登录失效、积分不足、必要资产缺失或平台错误再报告。完成后分别汇报创建槽位、正文保存、原生引用保存、提交/排队/生成完成状态，以及实际积分或未知项。没有实际回放、保存回读或生成结果时，不宣称验证成功。

默认收尾为平台交付：生成完成后不自动下载、导出、转码、媒体打包或为了验收而提取远程媒体。截图、对应历史/版本、视频返回状态足以记录平台完成；必要内容核验在平台内完成。用户明确“我自己下载”时保持该边界，不因MOV偏好、旧下载脚本或历史惯例追加下载。用户后续另行要求下载才启用该步骤。

用户范围内做结果检查时，区分实际画内台词字幕与浏览器播放器UI/平台控制条；原台词仍必须完整。实际视频出现字幕应如实记录问题，不以平台已完成冒充无字幕通过。只维护技能或字幕约束不自动下载旧视频、点击字幕擦除服务或追加扣费重生成。
