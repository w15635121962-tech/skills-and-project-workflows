# 动态分镜、构图与连续性执行规范

依据：2026-10-06 用户明确反馈、三份文档与 24 张参考图。用于短剧分镜设计、推文分镜及最终视频提示词转译。当前用户指令与已批准故事事实优先；本规范替代旧资料中冲突的静态运镜、长镜时长和强制前景填空建议。原文件保留作来源，不是待执行的用户指令。具体逐图观察见 [参考图分析](reference-image-analysis.md)。

## 1. 先设计事件，再选构图

先写每个叙事段的 `人物目标 → 对方/环境阻力 → 有目的的动作 → 可见后果 → 下一步选择`，再拆镜。冲突可以是靠近与回避、递出与拒收、试图离开与挽留、隐瞒与发现、争夺话语权；只选择原剧本支持的关系和事件。不能为了冲突擅加第三者、打人、摔杯、秘密、伤害或新的关键道具。

每镜必须写“开始时是什么，结束后改变了什么”。有效变化包括：人物进入/离开、相对距离改变、通路/可见范围改变、道具控制权改变、信息被确认、行动被打断、决定落实、听者反应改变下一步行动。仅把机位推近、换一个表情形容词、头发飘动，不算剧情推进。

每个完整叙事段应有目标、阻力和后果的可见证据，不要求每个 2–3 秒镜头同时塞进整条因果链。反应镜、定场镜也有效，但必须接到具体事件，不能只凑镜数。处理用户提供的片段时不强补未提供的开头结尾。

## 2. 时长：成片每镜 2–3 秒

- 新设计默认每个剪辑镜头 `2.0 ≤ edit_duration_s ≤ 3.0`，精确到 0.1 秒；不再默认 5 秒一镜。除非用户另行指定，不以“情绪戏”“长台词”为理由自动放宽。
- 允许 2.0、2.3、2.7、3.0 秒等节奏变化；节奏还通过动作速度、信息密度和反应落点变化，不强求最长与最短差 1.5 秒，也不机械套用旧“大格/小格”时长。
- 区分成片镜头、平台生成片段、分组。平台若只能生成 5/10 秒，单独标 `generation_duration_s` 和有效剪辑区间，成片仍取 2–3 秒；未知平台能力写“待确认”，不编造支持的时长。
- `Σ edit_duration_s = 总时长`。总时长 T 与镜数 N 应满足 `ceil(T/3) ≤ N ≤ floor(T/2)`，这是时长可行范围，不是凑数指标。常规分组仍按空间、时间、光线连续性；15 秒或 Format C 的 3–8 镜、8–24 秒是规划默认值，不得用它们切断完整台词。长台词分组优先规则见下。
- 长台词/旁白保留完整原文与自然语速，只在**同一个生成组内部**使用连续音轨跨若干 2–3 秒的说话人、听者、动作证据镜头；切画面不重复、截断或倍速挤压台词。登记台词 ID、完整音轨时间、每镜覆盖区间和画内/画外说话人，只有当前画内说话者对口型。
- 先参考已有音频实测时长。无音频时可按资料中的英文约 2–3 词/秒、中文约 3–4 字/秒作预算并标明估算，另留情绪气口；不是保证能说完的硬公式。听清与动作完成时间不足时，在本组内补镜或整体调整分组，禁止把正在说的台词拆到下一组。
- 独立需要阅读的文字或长动作可跨镜持续保留可辨信息，不以快切隐藏不可读内容。总时长、镜数、台词实测互相不可满足时，列出具体冲突，不能暗删台词或伪称通过。

### 长台词整段留组：先定发言单元，再划组

1. 从原剧本标记连续发言单元 `dialogue_unit_id`：同一说话人从开口到自然说完的一段发言，包含内部停顿及连贯的多句，不以逗号、句号或镜头编号机械切断。原剧本明确被打断的发言按真实打断点记录，不能补写余句。
2. 每个单元只归属一个 `group_id`，完整原文、说话人、声音状态、起止时间、必要气口及紧邻落点反应在该组统一安排。组边界放在发言开始前或完整结束且必要反应落下之后。可以组内切镜，禁止上一组说半句、下一组续半句。
3. 当前组剩余时长不足时，把**整段发言与它需要的动作/反应**一起移入下一组，前组停在开口前；不要先塞几个词填满前组。若整段仍超过默认组时长/镜数，在平台支持的前提下调整该组的规划时长与镜数，单镜仍为 2–3 秒。
4. 真实平台硬上限不能靠写更长组头绕过。若单段完整音频已超过已确认上限，明确指出冲突并标记该组不可投递；保留全文，不自动断组、删词、倍速或伪称支持。只有用户选择可承载整段的生成/音频制作方式后才适配；本规范不授权自动调用收费服务。
5. 全文只在本组首个承载镜头的 `音频` 字段写一次，并附覆盖整个发言的组内时间码。后续镜头的 `音频` 写“连续承接 D01，组内 t…–t…，说话人 A，画内/画外”，不重复全文，不让每镜重新从句首发音。全文及承接记录均不得放入视觉字段。
6. 逻辑上同组的连续台词必须在实际投递中保留为同一连续音频单元；不能一边标同组，一边把每个镜头当独立请求重新合成半句话。逐镜独立生成时，只有已明确采用整段统一音轨的制作方案才可执行，不把逻辑分组当作平台支持连续声音的证明。
7. 例：D01 经音频确认需 9 秒，安排 10 秒组，4 镜各 2.5 秒；D01 在组内 0–9 秒连续，最后 1 秒接反应。即使旧组只剩 4 秒，也整体挪入新组，不做 4 秒+5 秒跨组。说话人切到画外时声音仍属 D01，听者不接替口型。
8. 原文长旁白确实横跨时空变化时，先检查是否与连续空间组规则或平台能力冲突，明示该问题；不能擅改原文场景、假称同一空间或默默拆散同一句。

## 3. 空间锁定是锁连续关系，不是锁死人

每场先建立简明空间图/表：门、窗、桌、椅等已有锚点；人物世界位置；可行走通道；初始坐站/朝向；道具归属；主光方向；对话轴与运动轴；摄影机所在侧。规划人物起点、中间路径、终点，再确定机位。

分开记录两套位置：

1. **世界位置**：人物相对门/桌的位置和距离；换机位不会改变。
2. **画面位置**：本机位投影下的左右、前中后景、裁切和视线方向；合理换机位或可见移动可以改变，不能为了机械“永远左边”把人物瞬移回去。

逐镜维护状态账本：

| 字段 | 必填内容 |
|---|---|
| `visible_cast` / `offscreen_cast` | 实际入画角色 ID 与数量；画外说话/被提及者单列，不绑定成可见角色 |
| `start_state` | 各人锚点位置、坐站、身体朝向、视线目标、手和道具状态 |
| `blocking_path` | 谁因何事，从哪里经哪条可行路线到哪里；画面运动方向；距离或步数 |
| `entrance_exit` | 首次出场/再入画/出画/已在场；入出画边、入口、预示、揭示方式、最终落点 |
| `camera_path` | 机位起终点、轴侧、跟随/横移/摇/推拉/固定、启动触发、跟随对象、停止条件 |
| `end_state` | 更新后位置、朝向、视线、支撑面、手、道具、门窗状态 |
| `cut_bridge` | 上镜结束如何接本镜开始；动作阶段、屏幕方向、音轨、锚点或视线依据 |

如果没有移动，写“因何事停住、在等待/拒绝什么、什么事件结束停顿”，不能只写“延续上一镜”。独立生成提示词必须展开关键状态，不能依赖模型记得上一镜。

### 轴线与方向

- 给轴线两个端点和摄影机所在半平面，如“桌边 A 与门边 B 连线，机位始终在窗侧”；不能只贴 `A_side` 而没有定义。
- 同一对话轴的正反打互相匹配视线：A 看画右侧的 B，B 看画左侧的 A；看向具体人物/手/门，而非都看镜头。回头时分写身体朝向与头眼朝向。
- 人物转身、跨越对方、换座、绕桌、从左向右走，必须有可见动作或明确过渡接续。出画后下一镜入画方向需与空间路径相符；“从右出、从左入”适合同向连续横移，不是所有反打/转弯场景的万能规则。
- 需要换轴时，用可读的连续过轴运动、中性轴上过渡后重新定向，或新的关系镜交代新轴；仅插手部特写不能自动证明左右互换合理。
- 人物移动后可重新定义对话轴，记录建立它的镜头；不把整场旧轴值永久锁死。反打背景按机位真实更新，保留同一空间的锚点身份，禁止把不同方向背景复制为同一张墙。

## 4. 人物出场必须与镜头揭示配合

每个新增可见角色写明出场身份来源和出场卡：`原位置 → 预示/触发 → 入画边或遮挡后位置 → 人物路径 → 镜头如何发现 → 可辨身份的时点 → 落点 → 对现场造成的变化`。角色可以开场就在场，但须在定场/关系镜建立；不是强迫每人都从门里走进来。

| 出场/出现方式 | 人物动作 + 镜头配合 | 叙事条件与后果 |
|---|---|---|
| 门后揭示 | 手推/拉门，镜头小幅横移随门缝露出身体，再接可辨正面或三分之二侧面 | 门连接的空间已成立；按原剧情进入或窥见，不能凭空开新房间 |
| 跟随进入 | 从画边进入通道，机位同向侧跟/后跟，到目标人物旁停止 | 明确从哪里来、向谁去及距离变化，不写“人物突然出现” |
| 被关注后揭示 | 已在场者望向入口，下一镜沿视线摇摄/切到来者 | 关注与来者有源剧情因果；一次主运镜，避免 2 秒内又摇又绕又变焦 |
| 遮挡移开揭示 | 人物绕过已有柱/门框，或摄影机平移让遮挡退出 | 遮挡物和人物各自位置真实，不增加无身份的前景人头 |
| 从纵深接近 | 后景角色沿通道走向中景，镜头退跟保持裁切或固定呈现尺寸连续变大 | 写清起终距离和步数，人物不能一切镜从远处跳成贴脸 |
| 手/脚先入再见人 | 同一人物的手触门/鞋跨槛，动接动接中景身份揭示 | 局部归属明确；如果仅两三秒无法辨认是谁，下一镜及时交代 |
| 已在场但刚被揭示 | 主体让开视线/镜头转向，露出先前被遮挡的人 | 其原位置须可容纳，剧情允许旁听；与“新入场”区分 |

非首次出场可简写已知身份，但仍须有路径。只有原文已有第三人时才能设计第三人出场；三角构图可由两个人和桌角/门框形成，不能按构图人数补演员。

## 5. 比例与构图：先物理关系，再百分比

人物位置、裁切与机位的具体句式，从 [参考图构图规则](composition-recipes-from-images.md) 选择与剧情相符的一类；其中包含 18 张实拍的逐图拆解和 6 张教学页的构图转译。使用归档编号查图；比例分母必须明确，参考图观察区间与新镜头设计值分开。

### 每镜必写“透视构图描述”，不能只贴构图名

用可还原画面的图解式文字说明以下项目；制作默认参考 9:16，但以项目画幅为准。坐标是设计约束，非模型像素级执行保证；原资料没有给定的尺寸标为设计值，不能伪称由参考图测得。

| 项目 | 必须说明的画面关系 |
|---|---|
| 观察方向 | 摄影机在什么锚点哪一侧、朝哪里拍、距主体的大致距离、镜头中心高度和俯仰；明确对话轴侧 |
| 透视与空间线 | 地面/桌沿/门框哪些平行边向画面哪里汇聚，水平还是倾斜；仅在这些线可见时给汇聚位置，不给脸部特写强加消失点 |
| 三层排列 | 从镜头向远处依次是哪些人物/物体，各距镜头或彼此多远；空层写无，不为了凑层次新增人或物 |
| 二维落位 | 以画面左上为 (0,0)、右下为 (100,100)，说明主体中心/所在区域、裁切边、头顶留白、左右留白；只写必要坐标，不给相互冲突的全套数值 |
| 尺度比较 | 明确比较的是头高、可见身体高还是全身高；谁比谁大、差多少及距离/坐站原因，禁止只说“前大后小” |
| 遮挡链 | 谁在谁前面、具体遮住哪部分、从哪个边缘入画；前景归属、占宽、虚实，以及必须露出的眼睛/手/道具 |
| 身体与视线 | 身体朝哪一侧、头转向哪里、眼睛看哪个具体对象；人物自己的左右手与画面左右分开说 |
| 动态构图 | 起幅→人物路径和相机路径→落幅；移动后人物位置、尺度、遮挡怎样改变，哪个环境锚点保持可辨 |

建议句式：

> 【透视构图】相机位于……，镜头朝向……，主轴在……，机位高约……，主体距镜头约……。前景为……；中景为……；后景为……。主体 A 落在画面……，裁切到……；B 落在……，两人……部位的大小关系为……，原因是……。……遮住……但不挡……。桌沿/地面线向……汇聚（不可见则不写）。A 身体朝……、眼睛看……；B……。起幅……；A 沿……移动，相机……；落幅……，尺度……、留白……、遮挡……。

设计示例（不是参考图测量值或完整生成提示词）：双人腰上关系镜，相机在桌子窗侧，平视朝桌面另一侧拍；A、B 分居桌边左右，两人距镜头近似相等。A 中心约在画宽 30%，B 在 70%，都裁到腰部，头顶约留 7%，两人头高接近且符合已知身高与姿态；下方桌沿属于前景，人物不互相遮脸，后方门框可辨，无前景人头。A 面向画右看 B，B 面向画左看 A。A 向 B 前倾，B 向椅背后撤，固定机位保留两人肩部与桌沿；落幅中两人姿态和相对距离改变，不能把 B 缩成远处小人。具体焦段与机位距离在实际项目中一并确定，不用彼此矛盾的焦段/距离/裁切值硬凑上述比例。

每镜只保留一套成立的几何关系。若世界位置、投影侧位、尺度和遮挡不能同时成立，先修机位/站位方案，再写提示词；最终必须保留这些正向空间描述，不能仅在内部分析里规划后压缩成“三分法、电影感、浅景深”。

### 统一量纲

把“人物占比”拆成 `visible_body_height_pct`（画内可见身体纵向跨度/画高）、`head_height_pct`（注明头顶到下巴的跨度/画高）、`foreground_width_pct`（前景遮挡宽/画宽）、`screen_area_pct`（面积/画面面积），与叙事注意力权重分开。给范围的同时说明景别裁切，不混用头高、全身高、面积。

- ECU 按眼/手/物等指定局部裁切；CU 按头脸到肩锁骨；MCU 按胸上；MS 按腰上；MFS 按膝上；FS 头脚完整。中文习惯不一时，以明确的身体裁切为准。
- 手册中 MS“腰上占高 30–40%”、MFS“膝上占高 20–30%”与 FS“全身占高 60–80%”不是同口径的可直接连用序列。不得照此把对話中景缩成远处小人。
- 作为本工作流的设计起点，常规 FS 可先取全身占画高约 65–85%；MS/MCU 的可见身体可占画高约 75–90%，同时显式写裁切线与头部留白；这些是可调整的设计建议，不是摄影定律或模型精确控制能力。不要另配与之矛盾的强制眼线高度/头高。
- 相邻同类反打对齐裁切和头部尺度；刻意强调权力的尺寸差要有距离、机位或高低差理由。角色真实身高差、坐站差也要保留，不强制所有头等大。
- 同机位透视近似检查 `像高比 ≈ 实际身高比 × 远者距相机距离/近者距相机距离`；只用于比较同类完整尺寸，不能拿半身裁切与全身可见高度硬比。相机距离、姿态、遮挡、镜头裁切都要同时考虑。
- 同一镜头内人接近相机可以自然放大；换镜变焦/裁切引起大小改变必须符合镜头说明。焦段数字不能单独修复错误站位，不把“长焦”当作消除透视的开关。

### 前景人头与三人风险

1. 默认允许干净单人和干净双人，不把每镜都填满。负空间可用于视线、行动入口、分离感；空白不是必须塞人。
2. OTS 前景必须是本场已建立角色的肩/后脑局部，并写 `foreground_owner=角色ID`；普通对话过肩可从 15–25% 画宽起步，按构图实际调整。不能同时出现该人的前景肩和后景完整分身。
3. 前景可以因距离近而更大，但不能挡住正在传达信息的眼神、手和关键道具；没有剧情理由的巨大清晰正脸挤边应删掉或改干净单人。
4. 图 20 的近景白衣躯干与远处坐者，是有归属的两个深度层，不是可推广到所有镜头的“大头模板”。只有连续动作说明这名角色走近/经过机位时，才使用这种明显尺寸差。
5. 画外台词、旁白提及的人、镜中倒影、墙上海报不增加可见演员数量。反射要注明同一人及反射面，禁止把倒影生成为新角色。
6. 负面词仅兜底，先用正向描述锁定“仅 A、B 两人；B 在左中景，A 在右侧前景仅肩背；无第三人”。不要单靠“无多余人物”补救错误构图。

### 构图选择服务变化

三分法：给视线/前进方向空间；对角线/楼梯：表现已有路径与高低关系；门窗框：揭示/隔离；纵深线：接近、撤离、距离；偏心/负空间：让位给即将发生的动作；对称：建立秩序，后续以真实位移打破；双人靠拢/背对背：必须由行为到达，不能直接摆姿势；反射：可用于确认或遮掩，但必须能说明反射方向。一次以一种主构图配一种辅助层次为宜，避免堆叠互斥标签。

## 6. 调度与表演：镜头跟着意图走

- 每个完整动作段至少有一个改变人物关系的位移/姿态/距离/控制权变化；若原剧情限制坐定、卧床或拘束，就用前倾后撤、转向、手的拒接/收回、道具交换等可行动作，不能强迫伤者起身。
- 活动能力正常的行走/对峙场景应设计可见走位。连续三个镜头都原地微表情且关系/道具/信息无变化，退回重排；眨眼、衣摆、推近画面不能用来冒充走位。
- 表演用一项主动作配一至两项可读反应，例如“收回递出的手，同时重心后退、目光从对方脸转向出口”。不用每镜堆齐眼睛、嘴、肩、手、脚八项，更不让每个角色同步喘气眨眼。
- 坐起/站起有支撑面、重心转移和落脚；绕桌有可通行路径；触碰有手的归属、接触位置和反馈。起点、过程、终点跨镜保持，不能下镜重做动作。
- 情绪由刺激逐步变化：察觉 → 克制 → 尝试 → 被阻 → 决定 → 后果。具体次序按原剧情，不机械套所有阶段；弱冲突不擅自升级成失控或暴力。
- 运镜说明 `触发 → 跟随对象 → 方向/路径 → 速度 → 停止条件 → 新信息`。推进用于逼近信息，退跟用于让角色主动接近，侧跟用于保持相对关系，横移用于揭示遮挡，摇摄用于注意力转换；固定机位可以让人物穿越画面，固定并不等于站桩。
- 2–3 秒内一个可执行主动作和一个主运镜。只有其因果完整时才可连贯复合；把“推门、走三米、绕桌、争抢、转身离开”拆开，不靠加快播放硬塞。
- 听者要有因果反应，但可在下一镜展示；不让所有人每镜都抢表演。手、脚、表、杯的细节只在改变决定或承接动作时用，不能作为装饰插镜重复拖延。

## 7. 输出字段与 Format C 映射

普通分镜在原模板保留信息基础上，加入：`透视构图描述`、`出场/揭示方式`、`主动作与阻力`、`起点→路径→终点`、`机位起终点与启动/停止条件`、`尺度/前景归属`、`本镜状态变化`、`接镜依据`、`成片时长/音轨覆盖`、`完整台词单元归组`。已明确要求固定模板时嵌入原字段，不强制另建超宽表。

Format C **仍为十一字段，顺序不变**：

| 原字段 | 新规范写入位置 |
|---|---|
| 叙事任务 | 目标、阻力或后果；本镜新增信息；与下一镜因果 |
| 镜头 | 成片时长、景别裁切、焦段、机位高度与起终点、轴侧、主运镜触发/终止、焦点 |
| 画面 | 透视构图描述正文：精确名单、出场方式、观察方向、世界/画面起终位置、路径、前中后景、尺度比较、遮挡链、前景归属；与镜头字段的机位保持一致 |
| 视觉引导 | 观众先看哪里再看哪里、每人视线目标、运动方向、入画留白、接镜线索 |
| 微表演 | 主动作和反应的可拍过程；情绪起点与落点 |
| 对白反应 | 触发事件、接收者、沉默者、反应动作和结果；不抄入声音或台词正文 |
| 人物背景融合 | 地面/椅/桌支撑、接触阴影、距离透视、遮挡和道具状态 |
| 光影细节 | 同场主光保持；人物位移后依据光源产生的明暗变化 |
| 音频 | 唯一承载对白/旁白/声效正文；完整发言单元 ID、唯一所属组、说话人、组内连续音轨区间与口型归属；全文只写一次，其余组内镜头按 ID 接续，禁止跨组续句 |
| 运动强度 | 分写人物运动与相机运动，避免用相机移动替代人物行动 |
| 负面提示词 | 按镜选择无多余第三人/分身、无瞬移换边、无比例突变、无遮挡主体、无动作重启等 |

V2.6 的画质段、皮肤段、泪水段继续逐字保留；本规则不改写固定段。组头与每镜摄影参数必须一致，不能一处强制 85mm 另一处无说明改 35mm。

## 8. 合成示例：8 镜共 20.0 秒

以下是**教学自拟动作段，不是参考图真实剧情**。假设原剧本已明确：A 在门口，B 坐桌右侧；A 走近，B 伸手挽留，A 不接并离开。无新增演员、台词和道具。门在世界左侧，桌在中部，B 在右侧；相机一直在两人连线的窗侧。用门、桌和椅连接各镜，A 的往返是可见转身后的返回，不是无因换边。

| 镜 | 时段/秒 | 动作、运镜与构图 | 结束变化与接镜 |
|---|---|---|---|
| 1 | 0.0–2.4 / 2.4 | 中景，A 从左侧半开门跨槛进画，向画右前进一步；相机小幅右摇随 A，露出右侧桌边 B | A 已在门内；B 从桌面抬眼看 A；只两人 |
| 2 | 2.4–5.1 / 2.7 | 双人中全景，同轴窗侧侧跟 A 向右再走两步，到桌左侧停下；B 仍在桌右侧 | 明确 A 左/B 右、桌面隔开两人；下镜从这次抬手启动 |
| 3 | 5.1–7.3 / 2.2 | B 中近景，固定机位；B 看左侧 A，前倾并向画左伸右手，手停在桌面上方 | 改变为主动挽留；A 尚未接手，空间不跳 |
| 4 | 7.3–9.6 / 2.3 | 手与袖口细节，固定；B 右手在画右伸向左；A 左侧手指短暂停住后收回，手未相碰 | 明确拒接；下一镜承接 A 收手结束，不重演 |
| 5 | 9.6–12.2 / 2.6 | A 腰上中景，沿同轴侧小幅退让保持裁切；A 向左后退半步，视线从画右 B 转向画左门口 | 距离变大、离开意图可见；拍得到重心，后退结果接下镜 |
| 6 | 12.2–14.9 / 2.7 | 双人中全景固定；A 可见地向左转身，向门迈一步；B 手停住后放回桌沿 | 新运动方向被建立；B 没有站起或凭空跟到门口 |
| 7 | 14.9–17.5 / 2.6 | A 中景，窗侧同向左跟，再走两步到门边；镜头随 A 停下，不穿过桌椅 | A 已到门口并触门边，B 留在原世界位置的画外 |
| 8 | 17.5–20.0 / 2.5 | 门侧关系镜固定，A 在左侧跨出门，B 仍在右后方坐着，望向左侧出口；保留空出的通道 | 可见后果为距离和关系断开；不额外塞第三人反应 |

这是动作与剪辑演示，制作时仍需补齐具体景别参数、服装/资产、光线和音频字段，不能把简表示例当完整可投递提示词。实际空间尺寸不足以按示例步数走完时改步数/距离，不让演员加速或穿模。

## 9. 交付前逐镜硬检查

1. **时长与整段留组**：每个成片镜头 2–3 秒、总和准确；每个完整发言单元只属一组，全文只录入一次，音轨覆盖无重复/缺口且发言及必要落点反应不越组边界；真实平台上限可满足，生成时长没有冒充剪辑时长。
2. **名单**：每个可见人/肩/手/反射都有身份归属，第三人是否原剧本已有并有出场依据；两人镜是否误写三张脸。
3. **透视构图与比例**：最终提示词有明确观察方向、三层排列、二维落位、尺度比较、遮挡链和起落幅；景别裁切、占比量纲、世界距离、坐站状态互相成立；相邻反打的头部尺度变化有原因，不只有构图术语。
4. **连续**：上镜终态与下镜初态逐项核对，位置/方向/视线/道具/门窗无无因跳变，换轴有重建依据。
5. **推进**：每镜可写出“因此”，每段有可见阻力和后果；无连续原地表情换景的假推进。
6. **出场与运动**：首次/再次出现可解释；人物路径和相机路径各自明确；运镜揭示信息或配合表演，不能只是写“电影感运动”。
7. **可执行**：2–3 秒动作量合理，支撑/接触/通道成立，表演强度有递进；静止有触发和下一步，不无目的走来走去。
8. **来源与交付**：没有从示例引入项目事实；保留当前输出格式、原对白和固定段；未生成视频时只报告文本/逻辑审查，不能声称已修复生成模型。

任何一项失败，重写对应镜头并复核相邻接续，而不是只追加负面词。修复不改变已批准故事事实；用户仅改局部时冻结其他字段。遇到原文缺失导致确实无法确定的入场/动作标为待确认，不用新故事填洞。
