# 影视语言通用决策规则

依据：用户提供《影视镜头语言实用学习指南》，经筛选、纠错与执行转译。用于新分镜设计、镜头组合、最终提示词及审校；不是某部影片的摄影复刻要求。原文及取舍依据见 [文章分析与核验](film-language-article-review.md)。

读取顺序：先读第 1 节，按任务选读景别、运镜、焦点、声画、场景或风格部分。数字构图使用 [图像构图范例](composition-recipes-from-images.md)，连续性和整段台词执行 [动态规范](dynamic-blocking-composition.md)。不用每镜重复整份理论。

## 1. 先确定观众要知道什么，再确定怎样拍

通用规则是决策方法，不是固定的情绪—镜头对应表。每个叙事段先用简短文字确定：

| 决策 | 应写明的内容 | 避免的错误 |
|---|---|---|
| 信息变化 | 开始时观众知道什么，本段揭示/确认什么，结束时还有什么疑问 | 只有“紧张、电影感”，没有可见信息 |
| 知情差 | 哪个角色知道什么；观众与角色是同时获知、观众先知，还是观众后知 | 剪辑无意让角色知道自己没看到、没听到的事 |
| 观察立场 | 外部观察、贴近某人的感知、明确主观镜头，或已建立的全知视角 | 跟背就称第一人称；正脸就要求看镜头 |
| 观看任务 | 此镜优先看脸、动作接触、关系距离还是环境中的某条线索 | 同时争夺注意力的多个“大特写重点” |
| 下一次切镜理由 | 刺激出现、动作到达节点、信息被识别、听者发生变化、空间需要重新定位 | 说话人每换一句就机械换脸；每隔固定镜数补全景 |

情绪目标转成可见证据，例如“迟疑”落实为手停在交接距离外、目光从物移向对方、身体未继续靠近。证据应来自原剧情允许的表演，不为营造悬疑添加凶器、秘密或第三人。

镜头意义由情境、表演、构图、声音和相邻镜共同形成。近景也可以冷漠，远景也可以强烈悲痛；仰拍也可能表现被天花板压迫，暖光也可以带危险。先说明本场为何选择这种拍法，不按角色善恶分配光比或俯仰。

## 2. 景别组织按信息路径，而非逐档报数

| 组织方式 | 适用任务与执行 | 边界 |
|---|---|---|
| 从环境到细节 | 先交代行动关系，再锁定决定结果的手、表情或道具 | 不必把远、全、中、近、特每档拍齐；细节需确实带来信息 |
| 从细节到环境 | 暂时隐藏主体处境，再扩大可见范围改变观众理解 | 先判断延迟揭示是否允许；不能替原作隐瞒本该立即清楚的信息 |
| 关系—反应—结果 | 双人关系镜、接受刺激者反应、动作/距离变化，形成因果 | 不要求固定三镜；听者可能在说话人开口之前就成为焦点 |
| 大小景别直接对照 | 用环境尺度与局部证据的强反差突出信息 | 大景别直切特写不自动等于 jump cut；仍需匹配时间、方位与动作阶段 |
| 保持景别、改变内部关系 | 镜头不切或裁切不变，通过前后站位、遮挡、焦点交接改变重心 | 不是演员不动的借口；也不为变化机械移动所有人 |

新场景应在观众需要理解路径/关系之前提供足够空间线索，可用全景、门口观察、相向眼线或连续移动建立；并非每场第一镜必须全景。已明确要求全部近景/中近景的项目，优先用背景锚点、肩背归属及匹配视线建立空间，不擅加全景。

选择画内切换和剪辑切换时区分：**同一连续镜头中的景别阶段不是多个剪辑镜头**。若把长镜思路改编为若干短镜，应标明是新设计，不能称为原片逐镜实录。

## 3. 运镜写成空间动作，焦距变化与焦点变化分开

沿用动态规范中的“触发—路径—速度变化—终点—信息后果”。速度受辨认信息所需时间和人物动作支配；慢推可以制造强悬念，快移也可以表现轻松，不能只按紧张/舒缓选择快/慢。

| 手段 | 必须可执行的区别 |
|---|---|
| 推进/拉远 dolly | 摄影机实际向主体靠近/远离；交代原轴侧、走向、起终裁切和前后景相对尺度变化 |
| 光学变焦 zoom | 机位不动，焦距变长/变短改变取景范围；不能写成摄影机穿过房间或产生同样的位移视差 |
| 摇/俯仰 pan/tilt | 摄影机位置基本不动，只转动观察方向；写从哪个目标转向哪个目标及落点 |
| 横移/跟拍 | 摄影机有实际位移；说明与角色同向/反向、距离是否保持、背景哪些遮挡因此变化 |
| 环绕 | 交代中心对象、从哪个方位到哪个方位、弧线方向和停点；检查是否跨越对话轴及背景如何更新 |
| 甩镜 | 起点与终点都可识别，模糊只在中间过渡；不能用整镜模糊替代缺失动作 |
| 拉焦 rack focus | 镜头焦点从前层 A 转到后层 B，或反向；交代触发与转移完成时刻，主体不因转焦瞬移 |
| 跟焦 focus tracking | 随正在移动的目标调整对焦距离，使目标持续清晰；不是一定把焦点换给另一个角色 |
| Dolly zoom | 摄影机移动与焦距变化配合，维持选定主体的画面尺度，同时改变背景相对尺度；不是“推进＋拉焦” |

Dolly zoom 的可执行方向：靠近主体时配合缩短焦距，远离主体时配合增长焦距；保持的是选定参考平面的主体尺度，不能声称画面所有物体大小都不变。仅在叙事需要且参数契约允许时采用；不能让既定固定焦距镜头同时变焦。关于该手段的术语核验见 [Adobe 说明](https://www.adobe.com/creativecloud/video/production/cinematography/camera-shots-and-angles/dolly-zoom-shot.html)。

一镜优先一个可读的主要运动。复合运动必须能在计划时长内完成，给出因果与路径；不把推、摇、绕、变焦、转焦全部叠加来表示“震惊”。静止镜头同样可有效，条件是观众在等待具体结果、观察关系变化或读到表演。

## 4. 角度、透视与焦点为具体信息服务

- 高度、光轴俯仰、横滚、人物朝向分别写。镜头在胸高不一定仰拍，正面构图不等于演员直视镜头，背后跟随不等于角色眼睛的主观视点。
- 先选观察位置和人物距离以控制近大远小，再选符合当前画幅/裁切的焦段。机位不变时仅改变焦距主要改变取景范围；不能说长焦自己把人移动得更近。镜头等效焦段须注明口径，不将原文 35/50/85mm 分档当作通用硬边界。
- 浅景深用于筛选信息：指定清晰对象、可接受虚化对象和焦点转移触发。角色在移动时仍要说明如何保持关键眼睛、手或接触点清晰。
- 多层清晰用于让观众比较同时存在的关系：前中后层各有什么、谁知情谁不知情；以位置、动作或明暗确定观看次序，不要求每层都同样醒目。一个核心叙事任务可以包含多人的相关状态，不把它拆成互不相干的几个任务。
- 深景深与浅景深是设计选择。不能在组头固定大光圈、每镜写“极浅景深”的同时又要求相距很远的前后人物全清晰；先检查实际位置与可行性，必要时指出契约冲突。保留固定质量/皮肤/泪水段原文；焦段、光圈变化只在项目明确覆盖时统一落地。
- 确需隐藏表情的剪影/背影，安排后续可读的动作或反应承接；不得用风格建议覆盖当前项目对白镜的面部清晰要求。

## 5. 剪辑控制因果、知情差与节奏

切镜前说清“为什么此时换给这个画面”。可选：动作接续、目光接目标、目标接反应、声音引起注意、形状/运动匹配、信息揭示后的关系重估。不要强制每一种都出现。

- **动作匹配：** 上镜动作阶段与下镜起点相接，记录接触、承重、道具控制权；不能重复完成同一次递物或漏掉接手。
- **眼线匹配：** 谁看向什么、目标在哪里、何时获得该信息；听者反应必须跟随其实际能看到/听到的刺激。
- **反应镜：** 切给承担变化的人，不只切给正在说话的人。给听者足够时间处理信息，保留当前说话人声音归属和口型控制。
- **并置产生含义：** 脸—物—脸可以引导判断，但相邻镜头也可能误造“他看到它”“两人相爱”“事件有因果”。审查这种推断是否被原剧情支持，不能利用剪辑悄悄改剧情。
- **交叉剪辑：** 区分同时发生、先后发生与主题对照。只有原作支持时才能暗示同时性；分别登记各空间的行动进度、时间关系和回切接点，不把跨地点镜头伪装成同一连续空间生成组。
- **跳切：** 时间/动作的明显跳跃是风格选择；不要把所有大幅景别切换或快速切换都叫 jump cut。动作连续性不佳应先修复，不能改名成“风格”避开核验。
- **重新建立空间：** 当人物换位、路径改变、出现新入口或观众无法定位时安排关系镜；不照抄“每 3–5 个特写必须插全景”的固定配额。

节奏包含切镜频率、画内运动、表演停顿、信息密度和声画关系。保持本项目默认每个成片镜 2–3 秒；在此范围内用揭示先后、等待、反应与动作快慢调整张力，不为“通用规则”恢复原文长镜或秒数。采用真正长镜头须有后续明确项目覆盖，不把“≥30 秒”当统一定义。

## 6. 声画关系与长台词：画面可切，完整发言不拆组

原文较少展开声音，本节是为实际执行补充的方法。声音是否允许、语言、台词全文仍由项目和原剧本决定。

- **画内/画外声：** 记录说话者身份与位置。说话者出画后声音可以继续，画内听者不接替口型；不同画面并不自动意味着不同声音来源。
- **声音先入（J-cut）：** 下一画面的声音先在当前画面出现；**声音延续（L-cut）：** 画面已切走，上一画面声音继续。名称与定义参考 [Adobe 剪辑文档](https://helpx.adobe.com/uk/premiere/desktop/edit-projects/trim-clips/perform-j-cuts-and-l-cuts.html)。在这里优先用于同一组内的说话人—听者覆盖。
- J/L-cut 是声画切点方法，不授权把完整台词切成两个生成组。沿用 `dialogue_unit_id → group_id`，整段音轨只记录一份全文，逐镜关联组内覆盖区间；跨时空的原作旁白按现有冲突处理规则执行。
- **声音引导画外空间：** 原作已有敲门声时，可先拍听者转头，再揭示门口；必须对应真实声源位置。不能凭空加哭喊或枪声制造故事事件。
- **有意留静：** 留出辨认、停顿或决定的空间，不要求每个情绪点都加音乐重音；环境声可以跨切镜维持场所连续。台词、音效、音乐均只进入 `音频` 字段。

## 7. 场景范式是选择路径，不是镜头配方

| 场景任务 | 优先判断与可用结构 | 禁止机械套用 |
|---|---|---|
| 普通对话 | 谁掌握信息、谁的反应改变关系；关系建立后按信息流选择单人/双人/听者覆盖 | 固定三镜循环；每句话都完整正反打 |
| 亲密/疏离 | 靠近还是隔开、是否允许共享画面、遮挡与目光是否建立联系 | 一律 85mm 以上、一律浅景深、一律暖色 |
| 冲突/权力变化 | 用接近、后退、挡住通道、坐站变化与反应显示控制权；角度变化有具体观察动机 | 弱者必俯、强者必仰、高潮必越轴 |
| 悬疑/揭示 | 先确定观众与角色的知情先后，再选择隐藏边界、画外声、焦点转移、扩大取景 | 为悬疑添加原文没有的秘密；所有紧张场面快切 |
| 追逐/动作 | 目标、障碍、相对距离、运动方向、接触与结果清楚；必要时回到能定位的关系镜 | 靠抖动或碎剪隐藏缺失动作；固定全景配额 |
| 情绪/独处 | 选择表情、身体状态或人物与空环境的关系作为证据；对比变化前后 | 情绪越强就越近；孤独必冷色、必须站着不动 |

这些只是同一剧情的覆盖方式。每次选择时确认演员、道具、资产、动作及结果都来自源剧本；没有打斗的剧情不因阅读“动作范式”增加暴力。

## 8. 风格统一：建立基准，让变化有理由

每个项目/连续场景用短卡记录：常用观察距离与例外、主要运动方式、焦点策略、主光来源与方向、明暗/色彩基准、构图重心、允许的声音风格。使用现有字段即可，不另加必须填满的长表。

1. 风格一致是变化遵循规则，不是所有镜头同景别、同角度。某次异常靠近、留白或倾斜若承担叙事转折，应能解释它偏离了什么基准。
2. 色彩作用依赖具体故事和反复建立的关联。冷暖可以区分空间或阶段，但不能自动把回忆染暖、现实染冷，也不能把某种颜色固定为善恶标签。
3. 色温、软硬、光位、光比独立描述：暖色硬光完全可能，冷色柔光也可能。写明窗/灯等光源依据以及镜头换向后照明关系如何保留；不凭“反派”给人加底光。
4. 重复母题只选择剧情已有的物、位置、色彩或动作。每次重现附带新的上下文或状态，不能为象征意义改服装颜色、替换已分配道具。
5. 当场景、时间或主光状态实际变化时，按生成组约定处理，不以“全片统一”抹去变化；完整长发言与组边界冲突须明确标注，不能默默断组。

## 9. 写入现有交付格式与验收

| 决策结果 | Format C 既有字段 |
|---|---|
| 观众获得的信息、观察立场、切镜理由 | 叙事任务；切点补入镜头/画面结尾 |
| 景别、机位、角度、运动起止、焦距与对焦 | 镜头 |
| 具体站位、裁切、遮挡、行动与结果 | 画面、人物背景融合 |
| 看什么、何时看、焦点交接与视线目标 | 视觉引导 |
| 刺激的接受者及可见变化 | 微表演、对白反应 |
| 光位、软硬、色彩及连续性 | 组头光影基调、光影细节 |
| 声画切点、说话者归属与完整台词时间 | 音频 |

不添加第十二个固定字段；不改写固定画质、皮肤、泪水原文。参数与固定段冲突时按现有项目覆盖规则解决。

交付前做三项有效性检查：

- **去掉术语复述：** 不说“库里肖夫、电影感、伦勃朗”，仍能从描述知道谁在哪里、观众看到什么及如何变化。
- **反事实比较：** 心里比较一次“固定/移动、近/远、切给说话人/听者”；选择最能服务当前信息任务的一项。只在用户要求方案比较时输出备选，不倍增正式镜数。
- **连续性与证据：** 没有未授权剧情推断；空间、声源、动作阶段、资产和台词归属可接续。没提供原片/音频时，不编精确镜头时长、焦段或台词实测长度。技能文件检查通过不等于视频生成效果已验证。
