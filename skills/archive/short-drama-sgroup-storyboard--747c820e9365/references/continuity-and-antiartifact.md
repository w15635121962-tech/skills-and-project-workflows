# 组间衔接 与 防穿帮

> 加载时机：设计尾帧、做连续性、规避 SD 生成错误与禁止画面时。

---

## 1. 组间衔接规则

每个 S 组必须有"尾帧/剪辑"设计，方便剪辑。

| 衔接类型 | 做法 |
|---|---|
| 动作衔接 | 手伸出 → 下一组抓住 |
| 道具衔接 | 卷轴展开 → 下一组宣读 |
| 声音衔接 | 脚步声入 → 下一组人物进场 |
| 视线衔接 | 角色看向门口 → 下一组门口人物出现 |
| 情绪衔接 | 呼吸停住 → 下一组冲突爆发 |
| 光影衔接 | 火光压下 → 下一组冷光空间 |

**避免：**

- 上一组还在庭院，下一组突然卧室，没有过渡。
- 上一组人物在动，下一组人物突然换位置。
- 上一组说的情绪，下一组完全不接。

**自问**：把上一组最后一帧定格，下一组第一帧能不能接上它？接不上就得补一个桥接镜头。

## 2. 防穿帮规则

### 2.1 人脸一致性

每个 S 组尽量控制主脸数量。经验：

- 情绪戏最好一镜一个清晰人物脸。
- 多人关系靠切镜，不靠同框。
- 背景人物必须虚化、背影、侧影，不能清晰露脸。
- 如果 SD 总是生重复人脸，立刻改成单人近景/特写。

### 2.2 防重复人物写法

**不要写：**

- 远处站着一群人。
- 背景里有人看着。
- 两人对面站着，旁边还有侍从。
- 对方虚在远处。

**改写成：**

- 背景只保留空石柱。
- 暗墙虚化。
- 只拍单人近景。
- 只拍手部特写。
- 另一个角色只用画外视线承接。

### 2.3 单人镜头模板

```md
AI防穿帮卡：本组每个镜头只允许一个清晰人物；背景只保留空石柱、暗墙、卷轴边缘或道具虚化；
一镜一张清晰脸，同一角色不得在同一画面重复出现。
```

## 3. 禁止和慎用画面

**禁止使用这些容易穿帮或低质的描述：**

- 月纹
- 眼睛冒光 / 瞳孔发光
- 身体发光 / 人体自带光效
- 发亮、亮起、发光
- 露骨
- 血腥
- 莫名其妙空镜
- 不解释的白布、无意义遮挡物

**可以替代为：**

- 金属反光
- 卷轴压印
- 风压
- 衣摆变化
- 石屑、尘粒
- 冷光落在手背
- 烛光压低
- 空气变静

**核心逻辑**：把"自发光特效"换成"环境光落在材质上的反应"。既高级，又不穿帮。

---

## 4. 多角色同场的处理

当剧情必须出现两人以上时：

1. 拆成单人镜头 + 反应镜头交替，用视线方向建立空间关系。
2. 需要同框时，只允许 **前景一个清晰脸 + 后景一个虚化轮廓/背影**。
3. 禁止"三人以上清晰同框"进入提示词。
4. Negative Prompt 必加：`crowd, background people, extra people, duplicate faces, cloned face, same character twice`。
