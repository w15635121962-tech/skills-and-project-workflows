# 常见问题与修正经验

> 加载时机：画面看不懂 / 情绪不对 / 台词太快 / 组间跳 / SD 重复人物 等诊断与返修时。

---

## 1. 画面看不懂

**原因：**

- 台词没有画面锚点。
- 关键因果没拍。
- 道具突然出现。
- 角色表情和剧情不匹配。
- 背景人物太多，SD 生成混乱。

**修正：**

- 把画面改成"证据链"：**道具 → 角色反应 → 关系变化 → 结果**。
- 减少同框，改成单人近景接反应。
- 给每句台词一个明确画面落点。

---

## 2. 情绪不对

**原因：**

- 把女主写哭了，但她此刻应该冷静看戏。
- 把炫耀写成普通站立对话。
- 把痛苦写成静态表情。
- 把史诗感写成大场面堆砌。

**修正：**

- 先判断人物此刻心理**优势/劣势**。
- 用身体细节表现情绪。
- 不要滥用哭。
- 让情绪通过**对方反应**升级。

---

## 3. 台词太快

**原因：**

- 长英文句塞进 1-2 秒。
- 没有拆句。
- 没有气口。

**修正：**

- 长句拆成多个镜头。
- 中间切听者反应。
- 一句台词后留表情落点。

---

## 4. S 组衔接跳

**原因：**

- 上组尾帧没有设计。
- 下一组开头没有承接动作/声音/视线。

**修正：**

- 每组都写清尾帧。
- 下一组首镜必须接住上一组最后一个动作、声音或道具。

---

## 5. SD 生成重复人物

**原因：**

- 提示词里有 `crowd`、`background people`、`attendants`。
- 画面内容写了多人同框。
- 同组挂载人物太多。
- 背景虚化人物也被 SD 当成主角生成。

**修正：**

- 改成单人近景。
- 另一个角色用画外声音/视线方向承接。
- Negative Prompt 加 `duplicate faces, cloned face, same character twice, background people, extra people`。
- 本组挂载减少露脸角色。

---

## 6. 快速诊断表

| 症状 | 优先怀疑 | 第一刀 |
|---|---|---|
| 观众看不懂 | 缺证据链 | 补道具特写 → 角色反应 |
| 看着没感觉 | 情绪错位 / 无钩子 | 重定心理优势 + 加尾帧状态变化 |
| 台词赶 | 长句塞短镜头 | 拆句 + 切听者反应 |
| 剪辑接不上 | 缺尾帧衔接 | 补桥接镜或改用声音/视线衔接 |
| SD 乱生人 | 挂载过多 / 提示词有 crowd | 改单人近景 + 补 Negative |
| 画面很假 | 自发光 / 堆特效 | 换成环境光落在材质上的反应 |
| 节奏拖 | 空镜或静态脸过长 | 删空镜，把时间给反应镜头 |
