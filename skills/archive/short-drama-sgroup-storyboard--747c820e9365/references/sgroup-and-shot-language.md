# S 组规则 与 景别规则

> 加载时机：拆 S 组、判断时长、分配景别时。

---

## 1. S 组规则

### 1.1 时长

每个 S 组必须控制在 **15 秒以内**。

| 时长区间 | 适合内容 |
|---|---|
| 10-13 秒 | 快节奏冲突 |
| 13-15 秒 | 情绪峰值、长台词、反转 |
| > 15 秒 | **必须拆成 A/B 组** |

### 1.2 每组至少一个明确情绪钩子

一个 S 组不能只是"人走、人看、人站"。必须有情绪变化：

- 轻蔑变僵硬
- 强撑变松动
- 疼痛变决断
- 炫耀变失控
- 隐忍变反击

**判据**：把这一组的首帧状态和尾帧状态各写成一个词，两个词必须不同。相同即为"没有钩子"。

### 1.3 每组最好至少有一句台词

除非是必要的纯动作转场，否则不要连续多个 S 组没有台词。

如果原剧本没有台词，可以考虑补：

- OS 内心戏
- 低声一句确认
- 对方反应句
- 环境声承接（但不能拖太久）

## 2. 景别规则

| 景别 | 负责内容 | 使用原则 |
|---|---|---|
| 远景 | OS、心境、孤独、命运感 | 少用，主要承载氛围和心理距离 |
| 全景 | 故事发展、空间关系 | 少用，避免 SD 生成多人穿帮 |
| 中景 | 调度、动作逻辑、人物位置关系 | 用来讲清谁从哪来、谁挡住谁、谁靠近谁 |
| 近景 | 对峙、台词、人物关系 | 台词戏主力景别 |
| 特写 | 表情、情绪、手部、道具证据 | 情绪爆点和信息锚点 |

**经验规则：**

- 情绪戏尽量用近景、特写、中近景。
- 动作因果用中景。
- OS 和心境可以用远景，但不要滥用。
- 全景容易让 SD 乱生人物，必须谨慎。

**一句话记忆**：远景管 OS 和心境；全景管故事发展；中景管调度和逻辑；近景管对峙和台词；
特写管表情、手部和情绪。

---

## 3. 拆组实操顺序

1. 读一段剧本，先写这一段的**情绪任务**（要让观众感受到什么）。
2. 找这一段的**情绪拐点**，拐点前为一组、拐点后为一组。
3. 每组配一句台词或一个明确动作事件。
4. 估时长；> 15 秒就再切一刀，切成 A/B。
5. 确认每组首帧状态 ≠ 尾帧状态。

---

## 4. 组内镜头数经验

| 组内镜头数 | 适用 |
|---|---|
| 1-2 镜 | 情绪特写、道具锚点、强反转瞬间 |
| 3-4 镜 | 台词戏标准组（说话人 → 听者反应 → 气口 → 落点） |
| 5-6 镜 | 需要空间交代 + 关系变化的复杂组，仍须 ≤ 15 秒 |

组内镜头越多，单镜越短；但**每镜都不能低于其景别可读的最短时间**。情绪爆点宁可拆到下一组，
不要把一组塞满。
