# 台词协调 与 人物表演设计

> 加载时机：写台词、配置台词对应画面、设计气口与表演细节时。

---

## 1. 台词时长

台词必须有足够时间说完。

| 台词长度 | 时长 |
|---|---|
| 短句 1-4 个英文词 | 1.2-1.8 秒 |
| 普通句 5-9 个英文词 | 2.2-3.5 秒 |
| 长句 10-16 个英文词 | 3.8-5.5 秒 |
| 超长句 | 必须拆镜，不能塞进 1.8 秒 |

**中文台词换算**：按语速估算 —— 日常约 3.5 字/秒、情感 2.8 字/秒、金句 2.0 字/秒。
再叠加停顿（0.5-2.0 秒）、动作（0.5-1.5 秒）、保持（0.8-1.8 秒）。

**严禁：**

- 1.8 秒塞完整长句。
- 一句长台词只给一个静态脸。
- 台词没有说话人画面，也没有听者反应。

---

## 2. 台词画面绑定

每句台词必须绑定以下至少一种画面：

- 说话人近景
- 听话人反应
- 手部动作
- 道具证据
- 站位变化
- 情绪特写

| 台词内容 | 画面绑定 |
|---|---|
| 身份宣告 | 皇冠、法令、印记、众人低头 |
| 委屈控诉 | 喉咙吞咽、手指抓皱衣料、眼神不看对方 |
| 安抚鼓励 | 握手、扶肩、遮挡风、低声靠近 |
| 炫耀挑衅 | 贴近耳边、轻笑、观察对方反应 |
| 反转确认 | 道具入前景、角色呼吸停住、下颌僵住 |

---

## 3. 表演气口

长台词要拆气口：

1. 前半句给说话人。
2. 中间切听者反应。
3. 后半句落到道具或情绪特写。
4. 台词后留 **0.5-1 秒反应**，不要马上切走。

**拆句模板**（以 12 词长句为例）：

| 镜号 | 内容 | 时长 |
|---|---|---|
| 01 | 说话人近景，前半句 | 2.0-2.5s |
| 02 | 听者反应（呼吸/眼神/手） | 1.2-1.8s |
| 03 | 说话人近景，后半句 | 2.0-2.5s |
| 04 | 落点：道具特写 或 情绪特写 + 0.5-1s 保持 | 1.5-2.0s |

---

## 4. 人物表演设计

不要只写"伤心、愤怒、震惊"，要写**可生成、可表演**的细节。

### 4.1 表情细节

- 眼神短暂失焦
- 眼睫沉下
- 下颌僵住
- 嘴唇动了动却没说出话
- 呼吸停半拍
- 喉咙轻轻吞咽
- 眼神从轻蔑变成僵硬
- 嘴角笑意慢慢消失

### 4.2 手部细节

- 指尖抓皱衣料
- 手套发抖但压得很稳
- 手指从道具上慢慢松开
- 指节发白后放松
- 指尖停在对方肩侧，没有继续推进
- 手从保护姿态转为主动伸出

### 4.3 身体细节

- 肩颈轻僵
- 半步靠近
- 后退半步
- 身体被风压逼退
- 胸口起伏慢慢平下来
- 下巴轻轻抬起
- 站到对方前方

---

## 5. 情绪 → 表演映射速查

| 情绪任务 | 不要写 | 改写成 |
|---|---|---|
| 炫耀 | 骄傲地说话 | 半步靠近、压低声音、拨弄道具、观察对方反应 |
| 委屈 | 大哭 | 手指抓皱衣料、喉咙吞咽、眼神躲闪、呼吸不稳 |
| 冷眼看戏 | 面无表情 | 不哭不崩溃，静静观察对手走向毁灭，视线稳定不移开 |
| 震惊 | 张大嘴 | 呼吸停住、肩颈僵住、眼神短暂失焦 |
| 安抚 | 温柔地安慰 | 手的落点、身体遮挡、低声靠近、视线稳定 |
| 隐忍转反击 | 生气了 | 胸口起伏平下来 → 下巴抬起 → 站到对方前方 |
| 史诗感 | 大场面全景 | 事件因果清楚 + 空间层级 + 人物站位 + 声画节奏 |

**通用禁令**：禁止单独使用"悲伤 / 愤怒 / 紧张 / 开心 / 恐惧"这类无物理对应的词，
必须替换为身体动作、面部微表情或光线变化。
