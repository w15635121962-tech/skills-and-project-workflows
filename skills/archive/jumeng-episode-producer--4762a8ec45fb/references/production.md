# 制作与时长

按当前范围读取源剧本、原台词、资产及已有稿；不要求预先具备分镜表、导演表或额外账本。保留源文件，不从其他项目导入人物或剧情。

**读来源和素材 → 按当前请求编写设计稿或提示词 → 按授权绑定、保存和生成。** 后续新生成从源剧情和当前要求重新设计表演与摄影；新写提示词读取 [提示词3.0进化版](../../short-drama-prompts-v3/SKILL.md)，不继承旧表演方案。仅绑定/保存/提交明确批准正文时复用正文；简单任务不创建整套文件。已有本地流水线只沿用真实检查点，不把旧动作或旧项目路径当新项目依赖。

有对应音频时以ffprobe或macOS afinfo实测为时长依据；确认文件与原文对应。无逐句时间戳的内部划分注明粗估，无音频注明朗读估算。字幕、旁白和对白归属分别核对，不能把所有剧本文字都当朗读内容。

最终新稿使用提示词3.0总设定与Shot八字段，具体用户时长和完整发言优先；原台词逐字写在对应人物的“人物表演”，不另加Audio字段；实际生成前核对当前平台范围。硬限制与完整内容冲突时明确指出，不能靠删词、强行加速或未经要求拆组解决。

素材缺失仅阻挡依赖该素材的部分。既有正确资产直接复用；角色身份和当场状态对应，不用相似素材代替。用户明确文字描述的场景或道具不强制配图。

豆包等表演措辞仅在用户需要且授权范围内作为可选参考；Codex负责最终镜头和表演，不将外部调用设成必经环节。实际调用需使用当前可用工具并遵循本次授权，不凭历史返回伪称本次调用完成。

恢复记录只需指向当前集/组、正文版本、素材映射、保存及任务状态，按工作需要留文件。不记录密码或登录令牌。生成结果默认留在平台；下载仅在明确请求时追加。
