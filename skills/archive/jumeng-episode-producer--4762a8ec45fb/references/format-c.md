# 当前提示词格式（3.0）

读取 [提示词3.0进化版](../../short-drama-prompts-v3/SKILL.md) 与 [截图格式及示例](../../short-drama-prompts-v3/references/screenshot-format.md)。本文件保留旧路径作为兼容入口；新写、续写或重做提示词统一用最新八字段，不再套用旧组头、十一字段或独立Audio字段。普通镜头设计稿按用户当前所需格式交付，不额外制作提示词或独立分镜表。

组头按规范列出场角色、场景及真实提供的素材名；已提供参考图才声明统一锁定。每Shot原台词逐字写在对应人物的“人物表演”，不编对白。必要的声音要求按用户当前要求写进现有字段，不另加独立音频字段。无台词画面保持可见行动和沉默反应，不新增旁白、字幕或意外说话口型；剧情明确需要的道具或屏幕文字仍按原稿处理。

平台原生引用按本次批准的位置插入。V3总设定通常在“出场角色”“场景”处引用；需要逐镜引用时，在“人物角色和运动”或“画面内容”的目标具名位置绑定，保留邻接文字。只有@文字不等于完成原生绑定。仅绑定、保存或提交已批准旧稿时，保持原结构及原引用位置，不借机转换格式。
