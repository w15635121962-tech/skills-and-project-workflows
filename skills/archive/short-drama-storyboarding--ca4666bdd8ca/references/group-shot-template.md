# 分组镜头默认模板

按用户本次指定结构输出；未另指定时使用下方模板。本模板仅用于普通镜头设计稿；最终视频提示词必须采用 [Format C V2.6组头与shot十一字段](../../write-format-c-video-prompts/references/format-c-template-v2.6.md)。只交当前需要的稿件，不另附导演表、资产总表、执行卡或公开自检表。按实际剧情决定组长、镜数、景别、动作和时间段数量，不凑字段内容，不补不存在的台词或动作。

时间轴以每组0秒为起点，镜头区间和内部动作段使用同一组时间轴。连续镜头内部的时间段表示动作、台词和注意对象变化，不表示剪切；切镜时另起镜头段。台词和动作有对应音频时优先实测；无音频时注明时长、入点为估算，不能宣称已同步。低风险未知可写“建议”或“待确认”；影响剧情或执行的未知先解决。

素材字段只列本组实际所需内容；没有图片、音频或道具时写“无”或“待提供”，不编造文件和资产ID。参考图只继承本次需要的身份、服装、结构与光线等信息；音频引用的权限按用户本次要求填写。局部修订保留其余已批准字段。

```text
EPXX-GXX｜本组标题｜本组时长

本组存在理由：这一组发生什么，怎样改变人物处境、信息、关系或行动后果。

【格式与时长】时长，画幅与制作形式，镜头数量；连续镜头或剪切安排；时间是否实测。
【所需图片】【角色图】角色及本场状态；【场景图】本场场景；【关键道具图】本组关键道具。
【所需音频】对白/旁白等实际所需音色或对应音频。
【参考素材】各参考素材锁定哪些身份、状态、结构、道具和光线。
【参考权限】哪些参考信息可继承，哪些背景、构图、文字、台词或声音不继承。
【开场状态】所有在场人物的位置、坐站/支撑、朝向、状态及关键道具；承接上一组终态。
【结束状态】主要动作完成后的稳定状态；仍在场与实际离场的人物、位置及道具结果。
【音频总则】对白语言、音乐安排、环境声与动作声，声音主次。
【跨组交接】下一组从何种状态开始，如何承接动作、视线、声音、道具或场景变化。
【避免】本组容易出现的事实、状态、空间、人物、文字或声音错误。

镜头X｜起点-终点秒

本镜主要人物

当前承担动作、发言或情绪变化的角色。

本镜出场人物

所有在场角色及画内/画外状态；背景人物按剧情需要描述。

人物位置

角色的真实空间位置、画面左右/前后、朝向、视线、支撑面、出口与相互关系。

人物状态

承接前一切点的身体、情绪、行动阶段及信息状态。

景别组合

本镜需要的景别、机位和焦点变化；连续镜头注明变化如何连续完成。

画面+运镜

起点-终点秒：
景别/机位/构图：看谁或看什么，起幅到落幅，必要的焦段与焦点、摄影机路线。
人物位置：本段人物位置及变化；没有离场或换位的角色继续保留其状态。
动作与衔接：触发、人物行动、对手反馈、动作结果及与下一段的承接。
表演：目标：…；可见行为：…；落点：…。

按剧情需要重复时间段，不固定段数。

台词入点

入点秒｜说话者，语气或表演：
原台词。

按实际发言顺序重复；无台词写“无”，保留必要沉默和身体反应，不新增OS或对白。

声音设计

本镜全程：音乐、环境声、对白与动作声的关系。

起点-终点秒：
本段可听见的声音、来源、进入/退出及衔接。

按声音变化重复时间段，不固定段数。

【本镜锁定】剧情事实、身份、位置、状态、台词归属、轴线和必须连续的动作/道具。
【本镜避免】本镜具体容易误生的内容、无关动作、错误口型、字幕、水印或其他本次禁止项。
```

完成后内部核对：原台词与说话者、动作因果与反应、人物和道具接续、台词/动作所需时间、跨镜/跨组交接。发现问题直接修正文；没有实际证据的检查不写成“通过”。
