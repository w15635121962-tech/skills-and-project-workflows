# 分组镜头稿

先读取 [简化入口](../direct-protagonist-scenes/SKILL.md) 及其流程；已读无需重复。

普通镜头设计稿使用 [分组镜头模板](references/group-shot-template.md)；用户要最终视频提示词时直接使用 [Format C V2.6写作规范](../write-format-c-video-prompts/SKILL.md) 的组头与shot十一字段，不把本设计格式当最终提示词。设计稿必须采用 [最新对白与表演方法](references/dialogue-design.md)，[经验原则](references/storyboarding-experience.md)为补充。两份新附件的原件及有效方法已收录在该参考中。需要完整写法时参看 [用户EP31-G01示例](references/ep31-g01-user-example.md)，示例人物和参数不套入其他剧本。

直接在一份稿内写清本组作用、开场和结束状态、人物位置及反应、画面与运镜时间段、原台词入点、声音和跨组衔接。时间段按实际动作及对白划分，不固定段长；一个连续镜头的内部时间段不算剪切。

先理解完整剧情段落，再选短对白正反打、长对白主镜少切或混合模式。原台词语言、文字和说话者保持；不为补情绪钩子增加旁白或对白。无台词反应单独按动作因果设计，不硬凑三镜。

所有后续新生成重新设计表演和摄影，旧稿的表情、手势和运镜不作批准约束。核实并保留源剧情、原台词、人物身份、真实席位、道具和必要前后状态；表演刺激、目标、行为和对手反馈直接写进动作时间轴。

内部核对来源、时长、台词、空间与衔接即可。不默认追加资产表、正反提示词、自检表或Word；仅用户要求时补充对应交付物。

仅处理批准稿局部修订时保留其结构及未请求事实；用户要求新生成时执行新设计政策。稿件完成不提供上传、生成或扣费授权。
