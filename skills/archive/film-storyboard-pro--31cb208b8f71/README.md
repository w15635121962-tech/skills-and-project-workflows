# Film Storyboard Pro 🎬

电影专业分镜生成器技能 — 工业级AI分镜系统

## 概述

基于电影剧本生成专业分镜脚本的完整技能系统，涵盖场景分解、镜头设计、人物/场景一致性控制、自检优化、AI生成提示词适配。

## 核心能力

### 分镜规范体系
- 打斗叙事弧线（权力三次翻转）
- 正反打多镜拆分
- 运镜美学框架（连绵美学/切割美学）
- 手持摄影三层（呼吸感/临场感/混乱感）
- 视觉聚焦逻辑（Ocular Focus Logic）
- 面瘫美学规范
- 电影级对白分镜规范
- 暧昧/恋爱/亲密戏分镜规范

### 视觉资产体系
- 角色锚点表（六维拆解法）
- 场景参考图集（场景身份板）
- 角色设定板双版本生成规范
- 剧本→视觉资产提取规范
- 工业级道具设计规范

### AI生成适配
- 生产级首帧6层声明标准
- AIGC结构化提示词四步黄金框架
- AI视频生成工作流（故事板→视频桥梁）
- AI视频模型微表情实战对比与模型路由
- 实拍+AI混合分镜工作流（[REAL]/[AI]/[HYBRID]）

### 质量控制

- 导演风格圣经（14位导演完整风格DNA）
