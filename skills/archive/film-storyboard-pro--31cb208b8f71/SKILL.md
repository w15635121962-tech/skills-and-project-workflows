# 电影专业分镜生成器

将电影/影视剧剧本转化为专业级分镜脚本，内置人物/场景一致性控制与自检优化机制，确保输出的分镜在视觉叙事、镜头逻辑、角色与环境的连贯性上都达到行业可用标准。

## 核心流程

### 第零步：建立视觉锚点（人物与场景一致性基础）

在拆分场景和生成分镜之前，先为剧本中的核心角色和关键场景建立**视觉锚点表**。这张表是整个分镜一致性的基石——后续每个镜头的角色描述和场景描述都必须回溯到这张表，确保跨镜头、跨场景的视觉连续性。

详细规范见 `references/consistency-guide.md`，以下是核心要求：

#### 角色视觉锚点表

为每个有台词或重要动作的角色建立一张锚点卡：

```
角色：Johnny
├── 体型与轮廓：中等偏高偏瘦，肩线方正但不过宽，整体剪影修长
├── 面部特征：[推断] 眼窝深陷，颧骨突出，下颌线条硬朗
├── 头部/发型：深色兜帽几乎遮住全部头发，偶尔露出鬓角碎发[推断]
├── 服饰（锚定层）：厚重哑光深色长袍，可见纤维纹理与深深褶皱；下摆有微弱潮湿痕迹；红色护目镜佩戴于面部
├── 服饰（变化层）：[根据场景逐场标注变化，如"脱去兜帽""长袍撕裂"等]
├── 标志性道具：红色护目镜（冷蓝场景中唯一暖色跳跃点）
├── 体态习惯：站立时双脚扎地、双肩方正，动作节奏偏缓慢克制
├── 色彩标签：深灰黑 + 红色点缀
└── 一致性红线：护目镜颜色（红）、长袍质感（厚重哑光）、体型轮廓（修长方正）——这三个要素在任何镜头中不可改变
```

**角色身份板（视觉锚点表的图像化）**：

文字锚点表定义了"标准态"，但AI生成器无法直接读取文字表——它需要**视觉参考**。角色身份板就是锚点表的图像化版本，一张专门设计给AI模型看的角色研究图，目的是让AI在生成每个镜头时都能"看见"角色的完整视觉定义。

**身份板 vs 标准角色参考图的差异**：

| 维度 | 标准角色参考图 | 角色身份板 |
|------|--------------|-----------|
| 目的 | 给人类美术团队参考 | 给AI模型参考+人类理解 |
| 布局 | 对称网格、蓝图式 | 不对称、留白、艺术书风格 |
| 内容 | 多角度均匀排列 | 英雄全身锚点+辅助研究 |
| 信息密度 | 均匀 | 有焦点——英雄图最大，细节研究最小 |
| 一致性保证 | 依赖画师 | 依赖提示词+参考图锁定 |
| 特殊内容 | 角色设定文字 | 轮廓研究+表情研究+细节研究+ID块 |

**身份板的核心构成**：

1. **英雄全身视角**：略偏离中心的大型全身图，作为视觉锚点——这是AI生成每个镜头时的"主参考"
2. **多角度辅助研究**：正面全身、背面、侧面、坐姿、蹲姿、俯视、仰视——每个都是独立干净的角色研究，不是场景中的帧
3. **轮廓研究**：2-3个简化黑色剪影，展示角色的标志性轮廓——AI通过轮廓识别角色身份
4. **表情研究**：微妙情感变化（不是夸张表情，是角色在剧情中实际出现的情绪范围）
5. **细节研究**：面部特写、发型边缘、服装关键细节（领口/口袋/纹理/鞋靴）
6. **ID块**：角色名称、角色定位、核心情绪、视觉标志——文字锁定身份

**身份板的布局原则**：
- **不对称、留白、优雅**——不是网格/蓝图/目录，而是高端动画工作室的角色研究与艺术书布局的结合
- **英雄图偏离中心**，周围辅助研究用不同尺寸和间距制造视觉层次
- **每个视角清晰分离**，有呼吸空间——不重叠、不裁切面部、不隐藏肢体、不堆叠姿态
- **每个视角感觉像是独立的干净角色研究**，不是来自一个场景的帧

**身份板与提示词锚定段的关系**：
- 身份板的文字ID块内容 = 提示词中的角色锚定段核心信息
- 身份板的英雄图 = Midjourney `--cref` 的参考图源
- 身份板的轮廓研究 = 验证AI输出是否保持了标志性轮廓
- 身份板的表情范围 = 限定提示词中情绪描述的合理区间

**AI生成身份板的提示词要点**：
- 背景：纯白/柔和米白，无环境无道具
- 布局声明：`asymmetric elegant art-book layout, NOT a grid, NOT a blueprint, generous white space`
- 一致性锁定：`STRICT consistency across ALL views — same face, same proportions, same clothing, same body`
- 分离规则：`NO overlapping figures, NO cropped faces, NO hidden limbs, every figure has clear separation`
- 风格：`minimalist, cinematic, high-end, art-book quality, production-ready`

**场景参考图集（场景身份板）**：

角色身份板解决了"角色跨镜头长什么样"的问题，场景同样需要解决"场景跨镜头长什么样"——场景参考图集就是场景锚点表的图像化版本，一张专门给AI模型看的场景全景参考。

**场景身份板 vs 角色身份板的差异**：

| 维度 | 角色身份板 | 场景身份板 |
|------|-----------|-----------|
| 核心问题 | "这个角色长什么样" | "这个场景从每个角度看长什么样" |
| 视角数量 | 9+个人体角度 | 9个机位角度（景别×视角组合） |
| 一致性锁定 | 同脸/同服/同体 | 同光影/同色调/同空间结构 |
| 参考图用途 | Midjourney `--cref` | 场景锚定段验证+AI生成的光影基准 |
| 输出形式 | 单张不对称艺术板 | 9张独立参考图（可合并为九宫格） |

**9机位核心镜头体系**：

场景参考图集的标准配置是9个镜头，覆盖影视拍摄最常用的景别+视角组合，形成360°无死角呈现：

| 位置 | 镜头类型 | 叙事功能 |
|------|----------|----------|
| 1 | 正面近景 (Front Close-up) | 聚焦场景标志性元素特写，适合转场空镜、人物特写前景、氛围细节 |
| 2 | 正面全景 (Front Full View) | 人眼常规主视角，完整呈现场景纵深与布局，适合定场镜头、主叙事镜头 |
| 3 | 俯视近景 (Top Close-up) | 上帝视角特写地面细节，适合人物脚步特写、地面空镜、转场 |
| 4 | 正面近景补充 (Front Close-up B) | 补充近景机位，聚焦不同层次前景，适合人物中景遮挡、氛围感镜头 |
| 5 | 正面全景补充 (Front Full View B) | 补充全景机位，强化特定氛围效果（如晨雾、丁达尔光），适合大场景定场 |
| 6 | 俯视近景补充 (Top Close-up B) | 补充俯视近景，聚焦光影层次，适合俯拍人物特写前景、唯美空镜 |
| 7 | 背面近景 (Back Close-up) | 反向机位特写，适合人物背影主观视角、回头镜头、反向叙事 |
| 8 | 侧面全景 (Side View) | 横向呈现场景纵深，适合跟拍、运动长镜头、侧方全景叙事 |
| 9 | 俯视全景 (Top View) | 完整上帝视角，适合开场定场、时空转场、整体布局展示 |

**场景参考图集的一致性硬约束**：
- **光影统一**：9个镜头采用完全相同的光源逻辑（方向、色温、光质）。如有丁达尔效应，所有适用镜头必须呈现
- **色调统一**：色温统一锁定（如3500K-4500K），核心色调跨镜头不变，保证多镜头剪辑时画面连贯
- **空间结构统一**：场景中的地面材质、植物位置、建筑元素在9个镜头中保持一致的空间关系
- **材质精度统一**：所有镜头的材质区分度保持一致水平——花瓣的通透感、树干的粗糙感、地面的质感不因景别变化而丢失

**场景参考图集在分镜工作流中的位置**：
```
剧本 → 场景锚点表（文字） → 场景参考图集（9张图） → 分镜提示词（引用图集光影/色调参数）
```
- 场景锚点表定义"场景是什么"（文字规范，人读）
- 场景参考图集呈现"场景从每个角度长什么样"（图像参考，AI读+人验证）
- 分镜提示词引用锚点表的光影参数 + 图集作为视觉基准校验

**锚点表的分层逻辑**：
- **锚定层**：全片不变的视觉特征（体型、肤色、发色、核心服饰、标志性道具）。任何镜头都不允许矛盾。
- **变化层**：随剧情变化的视觉状态（受伤、换装、道具获得/失去）。逐场标注，确保变化的因果链完整。
- **一致性红线**：每个角色选出 2-3 个绝对不可矛盾的核心特征，作为自检时的硬性校验项。

**角色描写精度规范（从抽象到AI可执行的六维拆解）**：

角色描写中充斥"权势感""奢华""冷漠"等抽象词——人读有感觉，AI无法执行。本规范将抽象角色描述转化为AI可精确执行的六维视觉规格，是锚点表填写前的必经步骤，也是提示词质量的决定性环节。

**核心原则：抽象词=浪费提示词空间**。每个占据提示词位置的词都必须是AI能"画出来"的视觉指令。"权势"画不出，但"后背不靠椅背，上身前倾5-10°，双臂展开搭在扶手两端"画得出——而且传递的权势感更强。

**六维拆解法**：

| 维度 | 常见抽象写法 | 精度写法要求 |
|------|-------------|-------------|
| 1.体型与轮廓 | "身材高大威严" | 具体身高/肩宽比/剪影形状/重心位置/坐站姿态的空间占用 |
| 2.面部特征 | "面容冷酷" | 骨骼结构（颧骨/下颌/眉骨/眼窝深度）+ 肌肉走向（嘴角自然方向/眉头基态）+ 皮肤质感 |
| 3.头部/发型 | "发型整齐" | 发量/分缝/长度/产品光泽度/鬓角处理/发际线形态 |
| 4.服饰 | "昂贵西装" | 面料材质+织法+光泽度+驳头型/宽度+扣位/扣法+剪裁类型+袖口细节+衬衫/领带配套 |
| 5.标志性道具 | "名贵腕表" | 壳材质+盘面颜色+表径+佩戴位置+在特定光线下的反射效果 |
| 6.体态习惯 | "气场压迫" | 具体姿态角度+手指/头部的微动作节奏+视线落点+呼吸节奏+身体占用空间的方式 |

**抽象词→视觉化对照表**：

| 抽象词 | 不可执行 | 视觉化替代（可执行） |
|--------|---------|---------------------|
| 权势/威压 | ❌ | 上身前倾占据空间+双臂展开+视线从略高处落下+动作极缓慢 |
| 奢华/精致 | ❌ | 具体面料（worsted wool 120s）+具体金属（哑光铂金）+剪裁精度（suppressed waist） |
| 冷漠 | ❌ | 上眼睑半垂遮住虹膜上1/4+眉头放松不蹙+视线焦点在对方眉心而非眼睛 |
| 傲慢 | ❌ | 下巴微抬+嘴角自然走向微下压+头部偏转3-5°审视角度 |
| 坏笑/邪笑 | ❌ | 右侧嘴角提肌（zygomaticus major）收缩约3mm+下颌线不放松+眼神保持审视 |
| 气场 | ❌ | 身体占用空间的方式+动作的节奏控制+他人与他的距离感 |
| 压迫感 | ❌ | 低机位仰拍+角色占据画面60%以上+环境反射叠加角色轮廓 |
| 沉稳 | ❌ | 动作频率极低（1次/3秒）+呼吸几乎不可见+手指独立运动其余纹丝不动 |

**服饰精度拆解模板**（AI最易随机发挥的重灾区）：

```
西装拆解：
├── 颜色：[具体色名+明度]（如"深炭黑"而非"黑色"）
├── 面料：[材质+织法+光泽度]（如"精纺羊毛120s，哑光"）
├── 驳头：[型/宽度]（notch/peak/shawl + Xcm width）
├── 扣位：[单/双排+粒数+扣法]（如"单排两粒扣，仅扣下摆扣"）
├── 剪裁：[肩型+腰型+长度]（structured/suppressed/regular）
├── 袖口：[开扣/假扣+数量+衬衫露出量]
└── 特殊细节：[暗纹/刺绣/里布颜色]
```

**道具精度拆解模板**：

```
腕表拆解：
├── 壳材质与颜色：[如"铂金壳，冷白色金属光泽"]
├── 盘面：[颜色+功能+刻度样式]（如"深灰盘面，计时码表，棒状时标"）
├── 表径：[Xmm，与手腕的比例关系]
├── 佩戴位置：[哪只手+表带松紧+表盘朝向]
└── 光线交互：[在特定光源下的反射效果——这是道具"活"的关键]
```

**权力视觉化——抽象权力如何变成可见画面**：

"权势"画不出，但权势的视觉证据链画得出：

| 权力层级 | 视觉证据 | 示例 |
|----------|---------|------|
| 空间占有 | 他占多大空间/别人离多远 | 后背不靠椅背+双臂展开搭扶手=整张椅子都是他的延伸 |
| 动作节奏 | 他动多慢/别人等多久 | 右手食指1次叩击/3秒=他控制时间 |
| 视线方向 | 他看哪里/谁不敢看他 | 视线落在对方眉心=审视而非交流 |
| 环境反射 | 环境如何映照他 | 玻璃幕墙叠影=他与城市融为一体 |
| 材质等级 | 他的物品什么品质 | 精纺120s+铂金袖扣+哑光表面=低调旧钱 |
| 物品极简 | 他桌上有什么/没什么 | 仅笔电+酒杯+钢笔=什么都不需要证明 |

**面部表演锚定——角色锚点表中必须包含的表演基态**：

锚点表不仅定义"角色长什么样"，还必须定义"角色不做表情时的默认脸"——AI生成器如果没有表演基态，就会在每个镜头中随机赋予表情：

```
面部表演锚定（三步表演法·基态层）：
├── 冷漠基态：眉头放松不蹙，上眼睑半垂遮住虹膜上1/4，视线焦点在对方眉心
├── "隐晦坏笑"肌肉拆解：右侧嘴角提肌极轻微收缩约3mm——不是笑，是评估
└── 肢体同步：坏笑出现时右手食指叩击暂停1拍——嘴角与手指的微同步=心理计算
```

**角色描写精度通用工作流（五步法）**：

所有角色描写——无论是反派、主角、恋人还是配角——都必须经过以下五步，从原始描述（无论多粗糙）转化为AI可执行的六维规格。这是填写锚点表前的必经步骤，不可跳过。

**第一步：圈出所有抽象词**
逐句扫描原文，标记每一个AI无法"画出来"的词。判定标准：如果AI收到这个词后可能产生两种以上截然不同的画面，它就是抽象词。
- "权势"→❌（有人画大房子，有人画表情凶）
- "深炭黑西装"→✅（颜色+材质+光泽可执行）
- 圈出的抽象词数量=需要转化的工作量

**第二步：每个抽象词追问"AI画这个时具体画什么？"**
为每个抽象词找到它的视觉证据链——不是近义词替换，而是追问"观众看到什么画面时会觉得这个角色有X特质"：
- "权势"→观众看到什么会觉得有权势？→他占据空间+别人等他+动作极慢+视线从高处落下
- "冷漠"→观众看到什么会觉得冷漠？→眼睑半垂不正视+眉头不蹙不回应+嘴角走向下压
- "奢华"→观众看到什么会觉得奢华？→面料精度+金属等级+剪裁细节+极简（只有真正有钱才不需要堆砌）

**第三步：按六维重新组织**
将第二步产出的所有视觉化描述分配到六个维度中。检查每个维度是否有内容——空白维度=缺失信息，必须补充：
- 维度1空白→说明体型轮廓未定义，AI会随机
- 维度4空白→服饰完全随机，这是最容易串场的地方
- 维度6空白→角色没有"怎么动"的描写，每个镜头姿态随机

**第四步：服饰/道具精度加码**
维度4和维度5是AI最易随机发挥的重灾区，必须逐项检查：
- 服饰是否达到7要素（颜色/面料/驳头/扣位/剪裁/袖口/配套）？
- 道具是否写了光线交互（死道具vs活道具）？
- 西装是否区分了"黑色"和"深炭黑"？
- 领带是否写了结法和长度终点？

**第五步：表演基态锚定**
定义角色"不做表情时的默认脸"——这是AI生成中最大的随机变量：
- 写出眼睑高度+视线落点+眉头状态+嘴角走向+下颌线状态
- 定义1-2种情绪变体的肌肉级描写（哪块肌肉+收缩方向+收缩幅度）
- 标注情绪变体的肢体同步信号（表情变化时手/头/身体如何联动）

**角色类型→精度重点映射表**：

不同角色类型在六维中需要最精度的维度不同。以下映射表指导"哪个维度最值得花token"：

| 角色类型 | 精度优先级排序 | 最易出问题的维度 | 原因 |
|----------|---------------|-----------------|------|
| 权力型反派 | 6体态>2面部>4服饰>5道具>1体型>3发型 | 维度6：权力感来自"怎么动"而非"穿什么" | 抽象"气场"必须转化为动作节奏和空间占有 |
| 魅惑型反派 | 4服饰>2面部>6体态>3发型>5道具>1体型 | 维度4：服饰是魅惑的载体，面料/剪裁/露肤度=叙事 | AI容易把"魅惑"画成"暴露"，需用面料精度控制 |
| 女主/恋人 | 2面部>6体态>4服饰>3发型>5道具>1体型 | 维度2+6：情感戏的核心是面部微表情和肢体张力 | AI容易把"心动"画成"傻笑"，需肌肉级控制 |
| 少年/成长型 | 3发型>1体型>6体态>2面部>4服饰>5道具 | 维度3+1：发型和体型是年龄感的决定因素 | AI容易画成25岁成年人，需明确"半成熟"特征 |
| 老人/智者 | 2面部>5道具>1体型>6体态>4服饰>3发型 | 维度2+5：面部岁月痕迹和标志性道具=角色辨识度 | AI容易把老人画成"中年人+白头发"，缺肌理 |
| 冷面/面瘫型 | 2面部>6体态>4服饰>5道具>1体型>3发型 | 维度2：面瘫角色的微反应禁用=所有信息在"几乎不动"中 | AI最怕"没表情"=随机给表情，需禁令级描写 |
| 配角/功能型 | 4服饰>3发型>5道具>2面部>6体态>1体型 | 维度4+3：配角靠外形辨识而非表演深度 | AI容易把配角画成路人，需高辨识度标签 |

**使用方法**：确定角色类型后，按优先级排序分配token和描写精力。优先级最高的维度必须达到最高精度（每个子项都填写），最低优先级的维度允许简化但仍不可空白。

**角色描写精度规范与已有规范的关系**：
- 与**视觉锚点表**：精度规范是锚点表的填写方法论——先按六维拆解精确化，再填入锚点表
- 与**三步表演法**：精度规范的面部表演锚定=三步法的"基态层"，是所有情绪表演的起点
- 与**视觉聚焦逻辑**：精度规范中的"视线落点"=视觉聚焦的注视目标输入
- 与**面瘫美学**：面瘫角色更需要精度规范——因为"没有表情"比"有表情"更需要精确到肌肉级的指令
- 与**角色身份板**：精度规范的六维输出=身份板提示词的信息源
- 与**通用工作流**：五步法是精度规范的执行路径——从任何原始描述出发，五步之后产出六维规格

#### 场景视觉锚点表

为每个关键场景建立环境锚点卡：

```
场景：修道院中殿
├── 空间结构：纵向长方形，两侧列柱，尽头为圣坛区域
├── 建筑材质：灰色石质，柱面有矿物条纹与磨损边缘，接缝处有淡淡污垢
├── 地面：湿漉漉的石地板，有水洼反光捕捉蓝色倒影
├── 天花板：高耸拱顶，被雾气柔化
├── 光源体系：主光=左侧高处冷蓝花窗月光(7000-8000K)；轮廓光=右后方细蓝边光；补光=湿地面冷色反光
├── 色温基调：冷蓝灰(7000-8000K)，低饱和度
├── 氛围元素：蓝色雾气从地面翻涌（下浓上淡）；体积光柱；灰尘/冷凝颗粒飘浮
├── 一致性红线：光源方向（左高主光）、地面湿漉反光、雾气层次（下浓上淡）
└── 可变元素：雾气浓度可微调、蜡烛散景可有可无（不影响一致性）
```

**场景一致性的核心规则**：
- **光源体系不可矛盾**：同一场景内，主光方向、色温、光质在所有镜头中保持一致。不同场景可以有不同光源，但同一场景切镜后光线"翻转"是严重错误。
- **空间坐标不可矛盾**：建立场景后，角色的位置关系（谁在左谁在右、谁靠近门谁靠近窗）在连续镜头中保持一致。用简笔平面图辅助校验。
- **氛围元素保持层次**：雾气、烟雾、雨等大气效果的方向和浓度层次需一致，不能一个镜头地面雾浓、下一个镜头地面无雾。
- **材质与色彩基调稳定**：石墙就是石墙，不会突然变成木墙；冷蓝调不会突然变暖黄调，除非有明确的叙事理由（如闪电、火焰介入）。

### ⚠️ CRITICAL RULE — Full Script Fidelity（最高优先级，非协商）

**此规则凌驾于所有其他规则之上，不可被任何理由覆盖**：

1. **必须处理完整原始剧本**——绝不允许任何省略、总结、浓缩或跳过
2. **每一句台词、每一个括号说明、每一段动作描述、每一个场景标题、每一段戏码**都必须被保留并在最终分镜中体现
3. **处理结束前必须进行显式自检**：逐行、逐场景对照原始剧本，确认100%覆盖。如有任何遗漏，立即修正后再输出
4. **违反此规则=任务失败**——即使分镜质量极高，遗漏任何剧本内容即判定为不合格输出

### 第一步：剧本解析与场景拆分

读取用户提供的剧本，执行以下分析：

**Phase 1 强制动作——Exhaustive Inventory（详尽清单）**：

在开始分镜之前，必须创建完整的剧本清单，明确记录每一个元素：

| 清单维度 | 内容 | 输出格式 |
|----------|------|---------|
| 场景清单 | 每个场景的标题、编号、起止位置 | 列表，标注场景总数X |
| 台词清单 | 每一句对白/旁白/画外音的归属角色和内容摘要 | 列表，标注台词总数Y |
| 动作块清单 | 每一段动作/走位/交互描述的场景归属 | 列表，标注动作块总数Z |
| 括号说明清单 | 每一个括号内的表演/情绪/节奏指示 | 列表，标注总数 |
| 转场/时间跳转清单 | 每一处时空转换点 | 列表 |

**清单完成后必须输出确认声明**：
> 完整剧本已加载 —— X个场景，Y句台词，Z个动作块。最终将验证100%覆盖。

**剧本解析分析**：

1. **场景识别**：按「场景标题行」（INT./EXT. + 地点 + 时间）拆分场景。没有标准格式时，按空间/时间转换点拆分。
2. **角色提取**：提取每个场景出场的角色，标注其状态（情绪、关系变化、身体状态），**同时回溯角色视觉锚点表**确认当前场景的服饰/道具/外观状态。
3. **叙事节拍标注**：识别每个场景的核心叙事功能（建立、推进、转折、高潮、收束、过渡）。
4. **情绪曲线初判**：为每个场景标注情绪基调（紧张/舒缓/悲伤/喜悦/恐惧/平静），为后续节奏设计做准备。

对剧本中缺失但分镜必需的信息，基于时代背景、角色设定和叙事逻辑做合理推断补充，在输出中用 `[推断]` 标注。常见缺失项：环境细节（光线、天气、季节）、角色微表情、道具位置、空间布局。

**剧本→视觉资产提取规范（角色设定图/场景概念图/道具清单）**：

在分镜生成之前，先从剧本中提取三类核心视觉资产，生成独立的AI绘图提示词。这些资产是后续分镜一致性的视觉基础——角色设定图=角色身份板的输入源，场景概念图=场景参考图集的输入源，道具清单=跨镜头一致性校验的硬参照。

**角色提取与设定图提示词**：

每个角色必须提取以下10项信息：

| 字段 | 说明 | 示例 |

     → 场景提取（7项/场景） → 场景概念图提示词 → 生成概念图 → 扩展9机位图集
     → 道具提取（6项/道具） → 道具清单 → 作为跨镜头一致性硬参照

### 第二步：逐场生成分镜

对每个场景生成完整的分镜条目，包含：

| 字段 | 说明 |
|------|------|
| 镜头编号 | 场景内顺序编号，格式 S1-01（场景1第1镜） |
| 景别 | 大远景/远景/全景/中景/中近景/近景/特写/大特写 |
| 镜头运动 | 固定/推/拉/摇/移/跟/升/降/手持/旋转/变焦 |
| 构图描述 | 画面中角色与物体的空间关系、构图类型（对称/三分/前景遮挡等） |
| 光线与色彩 | 光源方向、色温、明暗对比、色彩倾向——**必须与场景锚点表一致** |
| 动作与调度 | 角色动作、走位、道具互动——**角色外观必须与角色锚点表一致** |
| 台词/旁白 | 对白、内心独白、画外音 |
| 音效/音乐 | 环境音、拟音、背景音乐的节奏与情绪 |
| 时长建议 | 单镜头预估时长（秒） |
| 转场建议 | 与下一镜的衔接方式（切/叠化/划变/匹配剪辑等） |

**每个镜头的描述中，角色外观必须引用角色锚点表中的对应状态**。不要在每个镜头中重新发明角色的外观描述——锚点表定义了"标准态"，镜头描述只需标注"与锚点一致"或"变化：xxx"。例如：

```
S12-01 动作与调度：Johnny [与锚点一致：厚重深色长袍+红色护目镜] 稳稳站立...
S15-03 动作与调度：Johnny [变化：左肩长袍撕裂，露出内衬；护目镜镜面有裂纹] ...
```

**景别选择逻辑**（避免机械套用，要根据叙事意图灵活搭配）：
- 建立空间感 → 大远景/远景
- 角色关系展示 → 全景/中景
- 对话/互动 → 中景/中近景，正反打交替
- 情绪聚焦 → 近景/特写
- 关键细节强调 → 特写/大特写
- 角色主观感受 → 手持+近景，或POV镜头

**运镜选择逻辑**：
- 推镜：聚焦重点、情绪递进、揭示信息
- 拉镜：展示环境、疏离感、情绪释放
- 摇镜：跟随运动、揭示空间、建立关联
- 移轨/跟拍：陪伴角色、沉浸感、空间探索
- 手持：紧张、纪实感、主观视角
- 升降：展现规模、权力关系、情绪升降
- 固定：冷静观察、仪式感、让画面本身说话

**多人物场面调度（Multi-Character Blocking）规范**：

AI多人物生成最大的难点不是人物本身——而是空间关系稳定、摄影机逻辑连续、人物身份不漂移、动线不混乱、镜头不越轴、视觉重心统一。当前扩散模型本质上并不理解三维空间，它们更像在"根据大量视觉概率去猜测画面"，因此多人场景天然容易崩坏。多人场景的控制本质上不是绘画问题，而是**导演问题**。

**稳定性优先级**（从高到低）：

```
空间结构 ＞ 摄影机方向 ＞ Blocking（场面调度） ＞ 动线 ＞ 角色锚点 ＞ 人物细节 ＞ 风格词
```

优先级意味着：如果空间结构不稳定，再精致的角色描述也没用——AI会把人物放在错误的空间里。因此多人场景的提示词和工作流必须遵循"先空间后人物"的逻辑。

**1. Blocking核心原则：先定义空间，再放人物**：

错误方式——"男人和女人在房间里对视。"（谁在左？谁在右？谁靠近镜头？摄影机在哪？AI无法稳定。）

正确方式——先定义摄影机、空间、构图、层级，再放人物：
```
camera facing north wall, male character screen left foreground, female character screen right background, large empty center composition
```

**2. Screen Position屏幕坐标系统**：

多人场景中最重要的控制手段是屏幕坐标。AI更容易理解绝对坐标而非相对关系：

| 坐标维度 | 推荐词汇 | 避免使用 |
|----------|---------|----------|
| 左右 | `screen left`, `screen right`, `center frame`, `frame edge`, `camera left` | "男人左边""beside him""next to her"——方向歧义 |
| 前后 | `foreground`, `midground`, `background`, `deep background` | "前面""后面"——AI可能理解为画面前后或空间前后 |
| 高低（Z轴） | `higher staircase`, `lower platform`, `elevated position`, `seated lower frame` | "高一点""低一点"——模糊 |

示例：`warrior foreground, assassin midground, guards background doorway` — 空间深度会稳定很多。

**3. 摄影机锁定**：

AI每次生成都会重新理解空间，摄影机方向必须固定，否则左右交换、视线错乱、越轴、动线崩塌。

推荐写法：`camera facing east 35mm lens eye level static shot`

后续镜头只改变焦距、景别、裁切范围——不改变摄影机方向。这是电影镜头连续性的核心：**空间不变，只变取景**。

**4. 180°法则与AI越轴**：

两人形成对话/对峙关系时，两者之间形成动作轴线，摄影机必须始终位于轴线同一侧。AI特别容易越轴——因为它没有真实摄影机、没有真实舞台、没有持续空间记忆，每次生成都可能重新构建空间。

锁轴方法：`consistent camera orientation camera remains same side of axis`，或直接声明 `camera facing east` 并在整个镜头组中不变。

**5. 角色身份锁定——标签化**：

AI更依赖"视觉特征组合"而非名字——"John"对模型意义很弱，但 `scar-faced commander`、`silver-haired queen` 意义非常强。

- 推荐：`blind swordswoman`、`red-armored general`、`white-haired monk`
- 避免：长期只用 `man`、`woman`、`boy`、`girl`——太泛，AI无法区分

属性固定原则：每个角色必须拥有跨镜头固定的属性组合（如角色A=black robe + eyepatch + sharp jaw + tall body），每个镜头都重复。

**6. 主角色优先级机制**：

AI注意力机制通常优先强化最先描述的人——`A woman… A man…` 中女人更稳定。

推荐层级写法：
```
Primary subject: wounded swordsman foreground left
Secondary subject: female assassin midground right
Background extras: blurred guards doorway
```

**7. 动作连续性**：

AI不理解运动惯性，经常把每一张图当作全新场景，导致动作断裂。

推荐写法：`continuation motion`, `same movement trajectory`, `mid-turn movement`, `ongoing motion`

核心逻辑：下一镜是上一镜的延续，而不是重新开始。

**8. 负空间的重要性**：

人物之间的空白区域（负空间）是多人场景的稳定器——没有负空间，AI会融合人物、肢体重叠、透视崩坏。

推荐写法：`large negative space between characters` 或 `empty center composition`

**9. 最稳定的多人构图**：

| 构图类型 | 特点 | 适用场景 |
|----------|------|----------|
| 对称构图 | 空间稳定、左右清晰、透视稳定 | 对话、对峙、仪式感 |
| 三角构图 | 视觉平衡、权力关系可读 | 三人关系、群像结构 |
| 深度分层构图 | foreground + midground + background | 空间感、群戏、层次叙事 |

**10. 俯视Blocking图（空间规划先于镜头）**：

多人场景本质上是空间几何问题——专业电影制作都先画Blocking Diagram（俯视站位图），包含：摄影机位置、人物站位、动线、光源、轴线、视线方向。

AI工作流推荐：
```
Step 1：画/生成俯视Blocking图 → Step 2：生成空镜锁定空间 → Step 3：锁定摄影机 → Step 4：加入角色 → Step 5：保持轴线一致
```

**11. 先生成空镜，再放角色**：

高手不会直接生成多人——而是先生成空间，因为空间稳定比人物稳定更重要。推荐流程：先生成环境→锁定镜头→锁定透视→锁定光线→再加入角色。这是目前最稳定的多人AI生成方法之一。

**12. 工业级多人Prompt结构**：

分镜中涉及多人场景时，提示词必须按以下顺序组织（而非随意堆砌描述）：

```
CAMERA: 35mm lens eye level static shot camera facing east
SPACE: large temple hall snow blowing inside empty center composition
BLOCKING: primary subject: screen left foreground / secondary subject: screen right midground / third subject: background doorway
RELATIONSHIP: 3 meter distance eye-line match visual tension
LIGHTING: cold moonlight right warm candlelight left
```

**多人物常见问题与防范**：

| 问题类型 | 具体表现 | 防范措施 |
|----------|---------|----------|
| 空间问题 | 左右交换/前后错乱/身高漂移/人物融合/透视崩坏 | Screen Position坐标+摄影机锁定+负空间 |
| 镜头问题 | 越轴/视线错误/动线断裂/景别逻辑错误 | 180°法则锁轴+continuation motion声明 |
| 角色问题 | 串脸/服装漂移/发型变化/年龄变化/气质变化 | 角色标签化+属性固定+Primary/Secondary层级 |

**AI视频运镜五境实战规范**：

80%的"高级感"来自运镜，不是画面内容或人物动作。运镜怎么动比画面里有什么更重要。以下五境从基础到高级，每提升一境，视频质感知觉跃升一个档次。

**第一境：速度精确化——用具体单位替代形容词**：

"缓慢推进"在AI视频模型上：30%几乎没动，40%动作合理，30%突然加速冲过去——形容词的随机性太强。

| ❌ 形容词写法 | ✅ 数字写法 | 为什么有效 |
|--------------|-----------|----------|
| "缓慢推进" | "5秒内从3米外推进到1米处" | 训练数据来自专业拍摄记录表，记录的是精确的距离/焦段/时间变化 |
| "快速横移" | "2秒内向左横移约1.5米" | 具体数字能精准命中专业训练数据 |
| "慢慢拉远" | "4秒内从中景特写拉远到全景，1米→5米" | 形容词无法标准化，模型只能猜 |

**焦段变化比距离变化更精准**：
- "镜头从35mm焦段在4秒内变焦到85mm" — 模型理解精度比"距离"更高
- 35mm=广角中景，50mm=标准镜头，85mm=中焦特写，135mm=长焦特写

**速度词典（项目标准）**：

| 速度等级 | 时间+距离 | 适用场景 |
|----------|----------|----------|
| 极慢推进 | 8-10秒内全景→中景 | 氛围镜头、电影开场 |
| 慢速推进 | 5-6秒内中景→中近景 | 情绪铺垫、人物登场 |
| 中速推进 | 3-4秒内中近景→近景 | 标准叙事节奏 |
| 快速推进 | 1.5-2秒内明显推进 | 紧张感、揭示瞬间 |
| 超快推进 | <1秒冲击式推进 | 动作高潮、戏剧爆点 |

**第二境：反向规则——运镜与主体动作的对抗关系**：

运镜方向和主体动作方向的关系，决定了画面是"高级"还是"平庸"——这是电影摄影学的"反向原则"：

| 组合类型 | 示例 | 效果 |
|----------|------|------|
| ❌ 同向（平庸） | 主体向前走+镜头向前推 | 画面"跟着走"，平淡如vlog跟拍 |
| ❌ 同向 | 主体向左转+镜头向左移 | 主体相对镜头几乎不动 |
| ✅ 反向（高级） | 主体向前走+镜头向后退 | "动而不离"——大片电影感 |
| ✅ 反向 | 主体向左转+镜头向右移 | 冲突感+主体被强调 |
| ✅ 反向 | 主体抬头+镜头下移 | 视觉张力 |

反向运镜的核心机制：主体持续移动但相对位置保持稳定，形成"动而不离"——诺兰、维伦纽瓦电影大量使用。

**视线方向的反向延伸**：
- 主体看向左 → 镜头从右向左横移
- 主体抬头看天 → 镜头从上向下俯视
- 主体回头看 → 镜头跟着前进（视线和运镜反向）

**核心铁律**：电影感不是来自镜头的炫技，是来自镜头和主体的"对抗关系"。

**第三境：双锚点/三锚点运镜——精确起止构图**：

新手的运镜开始模糊、结束模糊。老手的运镜开始有锚点、结束有锚点——明确的"起点构图"和"终点构图"。

锚点 = 镜头停留时画面中"明确的视觉中心"。如果只写"镜头慢慢推进"，模型不知道从哪个画面开始、到哪个画面结束。写"从脚部特写推进到面部特写"，模型有两个明确的"目标画面"，中间运镜变成"插值"——稳定性飞升。

**双锚点写法**：
```
起始画面：女主背影站在窗前，全身入镜，背景模糊窗外景色（中景）
镜头运动：5秒内缓慢推进+同时围绕主体旋转30度，从背影转为侧脸
结束画面：女主侧脸特写，眼神看向窗外，窗外光晕作为背景虚化（近景特写）
```

**三锚点写法**（8秒以上长镜头推荐）：
```
起点（0秒）：远景，全身在画面中央
中点（4秒）：中景，主体走到画面右侧
终点（8秒）：近景，主体面部特写
```
把长镜头拆成两段，每段都有清晰的"起止"，稳定性能提升50%+。这是纪录片摄影学的"分段叙事运镜"。

**第四境：复合运镜——多维度同步运动**：

Seedance等AI视频模型真正擅长的是复合运镜——多个动作同时发生。模型训练数据里90%的电影素材都是复合运镜，单一运镜反而是"少数派"——不要觉得复合运镜"难"，它是模型的舒适区。

**5个复合运镜公式**：

| 公式 | 组合 | 提示词写法 | 适用场景 |
|------|------|-----------|----------|
| 环绕推进 | Orbit + Dolly | "围绕主体顺时针旋转90度，同时缓慢推进2米" | 登场镜头、揭示主体 |
| 升降推进 | Crane + Push | "从地面高度上升到主体头部高度，同时向前推进" | 氛围铺垫、主体登场 |
| 横移变焦 | Truck + Zoom | "向左横移3米，同时从中景变焦到特写" | 戏剧性揭示、情绪强化 |
| 希区柯克变焦 | Dolly Zoom | "镜头物理后退+焦段拉长（变焦推进），背景变形扭曲，主体大小不变" | 眩晕感、强烈情绪 |
| 倾斜横移 | Tilt + Pan | "从右向左缓慢横摇，同时上仰30度" | 壮丽场景、宏大叙事 |

**复合运镜 vs 单一运镜的对比**：
- 单一运镜稳定率约65%，复合运镜约60%（仅低5个百分点）
- 但视觉档次提升50%+——多花一点抽卡成本，价值翻倍

**第五境：知道何时不动——静止镜头的力量**：

最高级的运镜是"几乎不动"的运镜。静止镜头的核心优势：
1. 注意力集中在画面内容而非镜头运动
2. 制造"凝视感"——像观众亲身观察真实场景
3. "小动作"被放大——镜头不动，眼神/呼吸/微动作变得醒目
4. 给观众"喘息空间"——静止镜头反而稀缺珍贵

**真正的静止≠完全不动**：完全不动=像照片。真正的静止="几乎不动+极微弱呼吸感"：
```
locked-off camera with extremely subtle breathing motion (less than 5cm of drift)
```
画面"静止"但仍有"人在拍摄"的微妙生命感，比真正的固定镜头更高级。

**必用静止镜头的场景**：
- 人物特写情绪戏——任何运镜都会分散注意力
- 决定性瞬间——静止镜头给观众"屏住呼吸"的代入感
- 极致美的画面——完美构图本身就足够，运镜只会破坏
- 心理深度场景——内心活动多过外部动作，静止让观众"沉浸进去"

**静止镜头的商业价值**：模型跑静止镜头的稳定率约90%，跑复合运镜约60%。大量使用静止镜头=单条可用素材成本降低40%+项目周期缩短30%。新手以为"运镜越多越值钱"，其实正好相反。

**运镜五境与已有运镜框架的关系**：
- 第一境（速度精确化）→ 强化"运镜选择逻辑"中推/拉/摇/移的可执行性
- 第二境（反向规则）→ 补充"运镜方向即叙事"表格，增加"同向vs反向"维度
- 第三境（锚点）→ 强化"镜头连续性"，每个运镜镜头必须有明确的起止构图
- 第四境（复合运镜）→ 补充"运镜美学框架"，复合运镜是连绵美学的进阶形态
- 第五境（静止）→ 与"静态抒情段落规范"一致，静止是静态抒情的运镜版

**动作戏运镜美学框架**：

动作戏的运镜不是技术选择，是哲学选择——核心分野在于两种美学信仰：**连绵 vs 切割**。

**连绵美学（Continuous Aesthetics）**：
底层信仰——动作本身就是叙事。摄影机忠实记录完整的因果链：出拳因为闪避，倒地因为受力，反攻因为破绽。空间是真实的，时间是真实的，代价是真实的。

核心手法：
- **广角优先**：让观众看见全身，看见动作的来龙去脉
- **摄影机不动，让身体动**：固定机位+全景，动作编排本身就是视觉节奏
- **"打完再切"**：一个动作段落完整呈现后才切镜，不在动作中途切断

分镜特征：镜头少、时长长、景别偏全景/中景，运镜以跟拍/固定为主。"动作编排即分镜"——武术指导的排练决定分镜的结构。

典型案例：《精武英雄》仓库打斗（固定全景，动作是完整的乐句）、《突袭》长镜头肉搏（痛苦可触）、《谍影重重3》楼梯打斗（手持跟拍但不切碎，空间始终可读）

**切割美学（Cutting Aesthetics）**：
底层信仰——观众感受不到的时间才是导演的领地。用短镜头快切重新组装时间和空间，每个镜头只承载一个冲击瞬间，真实的动作连贯性被打破，取而代之的是心理连贯性。

核心武器：
- **节奏操控**：3个0.3秒镜头堆叠制造窒息感，接一个1.5秒慢镜头做呼吸口。节奏不是打出来的，是剪出来的
- **冲击放大**：近景拍攻击→特写碰撞→近景反应，同一个瞬间被放大3倍，观众感受到的力度远超真实
- **痛觉传递**：特写锁定痛苦微表情，Foley放大骨骼碰撞闷响，镜头微晃模拟冲击余波。痛觉是近景的特权

分镜特征：镜头多、时长短、景别偏近景/特写，运镜以固定快切/手持为主。"剪辑节奏即分镜"——导演的时间操控决定观众体验。

典型案例：《老男孩》走廊（长镜头框架内用切割逻辑）、《疯狂的麦克斯：狂暴之路》（中心构图+快切，空间永远可读）、《约翰·威克》系列（两种美学的融合）

**运镜方向即叙事**：
运镜不只是"动还是切"，往哪动也是选择，且可以映射角色心理状态：

| 运镜方向 | 动作中的含义 | 心理效果 |
|----------|------------|----------|
| 推镜（向角色） | 压迫感升级，进入危险区 | 观众被迫靠近暴力 |
| 拉镜（远离角色） | 暴力的余波，疏离，抽离 | 观众变成旁观者 |
| 跟拍（与角色同速） | 陪伴感，沉浸，共同经历 | "我跟他一起在打" |
| 升降（从低到高） | 从肉搏到俯瞰，从个体到战场 | 视角的权力转换 |
| 旋转（绕角色） | 眩晕，失控，时间扭曲 | 打斗中的主观迷失感 |
| 手持微晃 | 纪实感，临场感，不可控 | "这是真的在发生" |

高级用法：运镜方向可以映射角色的哲学立场。同一打斗中，混乱角色配不稳定运镜（手持、微晃、偶尔失焦），秩序角色配稳定运镜（轨道、稳定器、构图对称）——人物的哲学直接写在摄影机的运动里。

**当代融合趋势**：
最有趣的发展是两种美学在融合，不是二选一：
- **长镜头框架+内部切割**：《约翰·威克》用看似不间断的镜头拍打斗，但在镜头内部通过角色移动、摄影机环绕、景别变化实现"隐形剪辑"
- **一镜到底的幻觉**：《1917》《人类之子》——多个长镜头拼接，观众体验是"一个镜头"，获得连绵的信任感+切割的节奏控制
- **空间可读的快切**：乔治·米勒证明——快切不等于空间混乱，只要每个镜头保持"中心构图+清晰地理方向"，0.5秒也够让观读空间。关键不是切多少，而是切的时候空间逻辑是否还在

**分镜师的判断**：
连绵美学→分镜表镜头少、时长长、景别偏全景/中景，运镜以跟拍/固定为主
切割美学→分镜表镜头多、时长短、景别偏近景/特写，运镜以固定快切/手持为主
融合美学→长镜头框架下拆子动作，每个子动作用近景/特写捕捉关键瞬间，但整体空间感不断

分镜师的价值判断不在于选哪种，而在于知道为什么选这种——每个打斗段落的运镜选择，都应该回答"这段打斗在叙事中的功能是什么"，然后让美学服务于功能。

**时长分配原则**：
- 建立镜头 3-5 秒，对话单镜头 2-4 秒，动作镜头 1-2 秒，情绪特写 2-3 秒
- 节奏快的段落镜头短、切换勤；节奏慢的段落镜头长、留白多
- 关键转折点前可适当延长，制造悬念

**静态抒情段落规范**：

并非所有场景都在推进叙事。有些段落的核心是**营造氛围**——让观众沉浸在一种情绪或美感中。静态抒情段落的分镜逻辑与动作/对话场景截然不同。

**"英雄镜头"结构**：
- 静态抒情段落通常由一个**主镜头（英雄镜头）**承载全部视觉信息，它本身就是完整的表达
- 补充镜头不承担叙事推进，而是提供情绪聚焦和细节层次——近景捕捉微表情/微动作，特写捕捉质感细节
- 补充镜头数量不宜多（1-3个），否则会破坏主镜头的完整性
- 主镜头与补充镜头之间是"全局→局部"的递进关系，不是"动作A→动作B"的推进关系

**静态场景的时长分配**：
- 主镜头 5-8 秒（让观众有足够时间"进入"画面）
- 补充近景 3-5 秒（聚焦但不打断）
- 补充特写 2-3 秒（点到为止）
- 如果这个段落需要更长的屏幕时间，在主镜头和补充镜头之间缓慢切换，而非增加新镜头

**构图的叙事含义**：
- 每种构图都有情绪暗示——分镜不能只写"对称构图"，还要回答"为什么是对称"
- **完美对称**：秩序、宁静、仪式感、"画中画"的凝视关系（如同某人从窗内望出去看到的画面）
- **三分法**：自然、日常、观众熟悉
- **前景遮挡**：窥视感、主观视角、神秘
- **负空间**：孤独、渺小、诗意留白
- **对角线**：动态、张力、不稳定

**单人静态场景的一致性简化**：
- 单人静态场景无跨角色一致性风险，但仍需维护角色锚点表和场景锚点表
- 光源方向是静态场景最容易出错的一致性项——"自然光"不能笼统带过，必须指定方向、色温、光质
- 补充镜头的景深变化会影响背景元素的可读性，需标注"虚化后远处玫瑰成为色点"这类变化

**动作戏/打斗戏拆解规范**：

动作戏是分镜中最容易"一句话概括"的类型，也是最不允许这样做的类型。打斗段落必须逐镜拆解到可执行程度——每个镜头只承载一个视觉信息，每个动作都有明确的起止帧和身体状态描述。

**核心原则：每镜一信息**
- 一个镜头只承载一个视觉焦点：一个角色的动作、一个碰撞瞬间、一个反应表情、一个环境细节
- 禁止"两人激烈打斗"这类笼统描述——必须拆成"林冲出棍→刀光闪避→棍影与刀光碰撞→雪与血花飞溅"这样的逐帧级动作链
- 近景快切段落：景别以近景/中近景/特写为主，通过快速剪辑制造紧张感，而非用全景拍整个打斗过程

**打斗段落节奏设计**：
- 加速→顶点→减速：短镜头堆叠制造加速感，最关键一击用稍长镜头做顶点，收束时放慢
- 典型4秒打斗节奏：0.5s→0.3s→0.3s→0.5s→0.5s→0.3s→0.3s→1.0s（前段加速，中段密集，末段减速）
- 每个镜头时长建议1秒以内（近景快切），最长不超过1.5秒

**打斗叙事弧线——权力三次翻转**：
一个完整的打斗段落不是直线胜负，而是攻守至少三次交替——单方面碾压没有戏剧性。标准9拍结构：

| 拍 | 叙事功能 | 权力状态 | 说明 |
|---|---------|---------|------|
| 1 | 建立 | 平静→暗涌 | 角色处于日常状态，威胁在背景潜伏 |
| 2 | 触发 | 被攻击 | 对手主动出击，主角被迫应对 |
| 3 | 焦灼 | 僵持 | 近距离缠斗，双方势均力敌——此处用特写传递肉搏感 |
| 4 | 反击 | 主角反占优 | 第一次翻转，给观众希望 |
| 5 | 逆转 | 主角被制 | 第二次翻转，打掉希望——这是最低点 |
| 6 | 翻盘 | 主角绝地反击 | 第三次翻转，用环境/即兴武器打破被动 |
| 7 | 决胜 | 主角压倒 | 最紧的近景/特写，暴力高潮 |
| 8 | 收束 | 胜负已分 | 对手倒地，主角站定——景别回到中景恢复空间感 |
| 9 | 离场 | 事件结束 | 主角离开/走远，可用首尾呼应构图 |

三次翻转的戏剧逻辑：第一次反击（希望）→被制（绝望）→翻盘（爆发）——情绪弧线是"升→降→升"，比"一路升"更有张力。如果打斗更长，可以在4-6拍之间增加更多交替，但核心结构不变。

**即兴武器的叙事功能**：
打斗中角色使用环境物品作为武器（灭火器、椅子、碎玻璃等），不只是视觉趣味，而是叙事转折点——即兴武器标志着力量的重新分配：
- 即兴武器出现前：角色处于被动/僵持
- 即兴武器出现后：角色获得不对称优势，打破平衡
- 即兴武器必须来自已建立的环境——如果06格突然出现一把刀，观众会困惑；但灭火器挂在走廊墙上是合理的
- 分镜中必须提前埋设即兴武器的视觉伏笔（如01格的建立镜头中灭火器可见于背景）

**环境参与打斗叙事**：
环境不只是背景，它是打斗的参与者和叙事工具：
- **地面材质**：湿地面的水珠飞溅是缠斗的物理证据，倒地溅水是败北的视觉句号
- **墙面**：被按在墙上——墙壁是受制的视觉载体，瓷砖裂纹/污渍放大暴力痕迹
- **空间纵深**：走廊尽头的光/暗——首格的"危险在前方"可以变成末格的"出路在前方"，同一空间元素承载相反情绪
- **天花板/灯光**：荧光灯管在格斗中的闪烁/破碎可以映射权力翻转
- 分镜中必须标注环境如何参与——不是"在走廊里打"，而是"湿地面在缠斗时溅水""被按在瓷砖墙上时墙面反射痛苦表情"

**首尾呼应构图**：
打斗段落的第一个镜头和最后一个镜头可以使用同一构图方向、同一空间位置，但承载完全相反的情绪——这是最高效的叙事闭环：
- 首格：人物在画面位置A，看向空间纵深B，情绪=威胁
- 末格：人物在画面位置A（可背对），看向空间纵深B，情绪=解脱/离开
- 构图相同+情绪相反=闭环，观众不需要额外信息就理解"这段打斗改变了什么"

**打斗镜头拆解必须包含**：
| 字段 | 说明 |
|------|------|
| 攻击方动作 | 具体出击部位、轨迹、力度暗示（如"棍尖从右下向左上划弧"） |
| 防御方反应 | 具体躲闪/格挡动作、表情变化（如"上身急后仰，瞳孔收缩"） |
| 碰撞瞬间 | 武器/肢体接触的精确时刻，碰撞产生的视觉效果（火花、碎屑、飞溅） |
| 环境反馈 | 打斗对环境的影响（雪被搅起、地面碎裂、布料撕裂） |
| 声音层 | Foley分层描述（撞击声、喘息、风啸、布料摩擦） |

**手持摄影与动作真实感规范**：

手持是动作戏最常用的运镜方式，但"手持"不是一种风格，而是三个截然不同的层次，分镜中必须精确区分：

**手持三层分级**：

| 层级 | 名称 | 晃动幅度 | 空间可读性 | 真实感效果 | 分镜标注 | 适用场景 |
|------|------|----------|-----------|-----------|----------|----------|
| 一 | 呼吸感手持 | 极微（像素级） | 100% | "画面活着" | `手持微晃` / `subtle handheld breathing` | 静态/日常/近景特写增加活性 |
| 二 | 临场感手持 | 明显但可控 | 70-90% | "我在现场" | `手持跟拍` / `combat handheld` | 大部分动作戏的最佳平衡点 |
| 三 | 混乱感手持 | 剧烈/旋转/失焦 | 30-60% | 先升后降 | `剧烈手持` / `chaotic handheld` | 角色首次遭遇冲击的瞬间（≤5秒） |

**手持的真实感悖论**：手持创造真实感，但过多的手持破坏真实感。真实感需要"我在现场"（手持提供）和"我看得清"（空间可读性）同时成立。晃到看不清谁在打谁时，大脑不再认为"真实"，而是认为"拍烂了"——因为真实的旁观者能看清眼前的事，混乱手持比真实更混乱，人脑会识别出这种不自然。

**黄金法则**：晃到让你觉得"这不是排练的"，但别晃到让你觉得"摄影师在发抖"。

**手持与焦点配合——追焦延迟**：
这是手持真实感极其廉价但极其有效的技巧。稳定器+自动跟焦的画面焦点永远精准，反而暴露了"精心制作"。真实的手持有反应时间：
- 角色突然加速时，焦点**先模糊零点几秒，然后追上**——追焦过程本身就是真实感
- 焦点偶尔**短暂落在错误位置**（如打到背景再拉回）——这种"失误"是纪实标志
- 碰撞瞬间，焦点**极短暂全模糊1帧**——模拟冲击导致的视觉失焦
- 分镜写法：`焦点追赶：出棍瞬间焦点短暂偏移至背景，0.3s后拉回` / `碰撞帧：焦点全模糊1帧`

**手持与声音的共生**：
手持的真实感不是视觉独占的，与声音设计共生：
- 手持镜头的声音层不只写Foley，还应标注环境音随手持晃动的轻微不稳定（电平波动）
- 如果场景允许，标注"画外摄影机操作员呼吸声"——临场感指数级上升
- 手持微晃的节奏与脚步/撞击Foley同步时，晃动从"效果"变成"物理反馈"

**什么时候不用手持**：
- 展现动作编排几何美感时（武术片的弧线/翻腾/兵器角度）——稳定构图才能完整呈现
- 大型战场/多人混战/车辆追逐——空间逻辑已足够复杂，手持让它更难读
- 超自然/奇幻动作时——手持的"纪实感"与超自然内容产生违和，稳定器+慢速顶点的"神话感"更合适

**正反打快切逻辑**：
- 攻击方动作镜头 → 碰撞/交锋镜头 → 防御方反应镜头，形成"出招-碰撞-反应"三拍子
- 正反打不限于对话，打斗中同样适用：攻击者近景→防御者近景→碰撞特写
- 每次正反打切换都在视觉上"确认"空间关系，避免观众丢失方位

**正反打必须多镜拆分**：
正反打是分镜中最容易被一笔带过的运镜手法——"正反打"三个字就概括了，但实际上正方和反方各自承载完全不同的视觉信息，必须拆成独立镜头逐个描述。

**禁止的写法**：
```
❌ S1-03 正反打：林冲出棍，反派恐惧躲闪
```
这种写法把两个角色的动作、两个构图、两个情绪压缩成一个镜头描述，等于没有分镜——导演和摄影拿到后完全不知道正方该拍什么、反方该拍什么、两个镜头的衔接关系是什么。

**正确的写法**：
```
S1-03 近景/平视微仰/微推：林冲面部占画面右2/3，眼神死寂精准，瞳孔锁定目标，握棍右手微调角度。左侧留出棍影空间。→ 时长0.5s
S1-04 近景/平视/固定快切：反派面部占画面左2/3，恐惧表情，瞳孔收缩，上身急后仰。→ 时长0.3s
```
拆开之后，每个镜头的信息密度是清晰的：正方镜头承载"攻击意图+微动作"，反方镜头承载"恐惧反应+身体动作"，各自有独立的构图、角度、运镜、时长。

**正反打拆分规则**：
- 每一"正"和每一"反"都是独立镜头，各自有完整的镜头编号、景别、角度、运镜、构图、时长
- 正方和反方的构图必须互补：正方占画面右2/3，反方占画面左2/3（或反之），确保切镜时视线方向一致（180度轴线规则）
- 正反打之间如果有碰撞/交锋，碰撞本身也是独立镜头，不能和正方或反方合并
- 对话场景同理：A说话+B反应是两个镜头，不能写成"S1-02 正反打：A说话B点头"

**正反打的构图互补表**：

| 正方构图 | 反方构图 | 视线方向 | 适用场景 |
|----------|----------|----------|----------|
| 角色A占画面右2/3，面向左 | 角色B占画面左2/3，面向右 | A看向左=B在左，B看向右=A在右 | 标准左右站位 |
| 角色A占画面左2/3，面向右 | 角色B占画面右2/3，面向左 | A看向右=B在右，B看向左=A在左 | 反向站位 |
| 角色A居中，微偏向右看 | 角色B居中，微偏向左看 | 非严格对称，适用于群戏中的焦点切换 | 群戏中的正反打 |

**对话场景正反打拆分**：
对话中的正反打比打斗更容易偷懒——"两人对话正反打"六个字就写完了。但对话的每个正反方向同样承载不同的叙事信息：
- 说话方镜头：承载台词内容+说话时的表情/微动作
- 听话方镜头：承载反应——点头的时机、表情的变化、从平静到动摇的微转变
- 如果听话方的反应比说话方的台词更重要，听话方的镜头应该时长更长、景别更紧
- 对话中的正反打不是机械交替，而是**情绪主导**：谁的情感在上升，谁的镜头就更多更紧

**视觉聚焦逻辑（Ocular Focus Logic）规范**：

AI人像最致命的"假人感"来源不是分辨率，而是**视觉聚焦逻辑缺失**——真人眼睛是"意识的投射"，AI眼睛只是"纹理的生成"。分镜中涉及角色眼神的镜头（几乎所有近景/特写），必须遵循以下六系统规范：

**1. 双眼聚焦一致性（Vergence）**：
- 真人看一个目标时，两只眼球微微向目标汇聚；焦距越近内聚越明显，焦距远时趋于平行
- AI常见问题：左眼看左、右眼看镜头、焦点漂浮——大脑会优先检测眼神方向，一旦不一致立刻产生"蜡像感"
- 分镜标注：`双眼聚焦于[目标位置/距离]，内聚[微/中/明显]`；如角色看远方则标注`双眼趋于平行，远距凝视`
- 一致性红线：同一镜头内两眼必须聚焦于同一目标点；跨镜头时，角色注视对象改变必须伴随视线转移的动作描述

**2. 高光锚点一致（Catchlight Anchor）**：
- 真人眼睛的高光来源统一、位置逻辑一致、与主光方向严格对应——主光在左上，两眼高光都在左上角膜区域
- AI常见错误：左眼高光在上、右眼高光在右、甚至出现多个太阳——违反真实光学
- 分镜标注：角色锚点表中必须标注`眼高光位置：[方向]角膜区域，与主光方向一致`
- 一致性红线：同一场景内，所有角色两眼的高光方向必须与场景光源体系一致

**3. 角膜折射深度（Corneal Refraction）**：
- 真人眼球不是平面——角膜凸起、泪膜反射、虹膜在角膜后方有折射深度，导致瞳孔"沉"进去、高光浮在表层、虹膜有空间感
- AI常见问题：直接贴图式虹膜、没有角膜体积、没有泪膜折射——像玻璃珠
- 分镜中涉及眼部特写时，必须标注`角膜凸起折射，虹膜有纵深，高光浮于表层`
- 最易暴露的四个区域：眼白（真人有血丝/渐变/湿润阴影，AI纯白塑料感）、瞳孔边缘（真人轻微虚化，AI机械硬边）、虹膜纹理（真人放射状纤维+深浅层次+中央异色，AI贴图花纹）、泪阜内眼角（真人半透明湿润+毛细血管，AI粉色贴片）

**4. 微型扫视（Microsaccades）**：
- 真人眼睛不会完全静止——即便盯着看，每秒也有细微跳动，焦点轻微修正，伴随微弱眨眼
- AI静帧完全冻结像假人，视频中尤其明显
- 分镜标注（视频生成场景）：`微型扫视：轻微不规律跳动，每1-2秒微修正一次焦点`
- 静帧分镜中不适用，但提示词中应包含`subtle microsaccadic tension`避免完全死板

**5. 瞳孔动态**：
- 真人瞳孔受情绪和光线影响，会有微收缩——悲伤时瞳孔微缩，愤怒时瞳孔轻扩张，恐惧时瞳孔放大
- AI瞳孔大小固定，缺乏"呼吸感"，少了生命体征
- 分镜标注：根据角色当前情绪标注瞳孔状态
  - 悲伤/痛苦：`瞳孔微缩，眼神下坠`
  - 愤怒/决意：`瞳孔轻扩张，聚焦锁死`
  - 恐惧/震惊：`瞳孔明显放大，上眼睑抬高`
  - 平静/日常：`瞳孔正常，微弱呼吸变化`

**6. 眼睑与眼球联动**：
- 真人眼球转动时，上下眼睑会跟随压迫，下睑有轻微张力变化
- AI常见：只有眼珠动，眼皮不参与——像"贴图在移动"
- 分镜标注（动作性眼神）：`眼球右转时上眼睑跟随压迫，下睑轻微张力变化`
- 对话/情绪场景中：`凝视时上睑微压，下睑收紧`或`恐惧时上睑抬升露白，下睑紧张`

**核心原则：眼神是意识的投射，不是纹理的填充**：

分镜中描写角色眼神时，最重要的不是"眼睛长什么样"，而是"角色在看什么"——每个眼神镜头必须回答：
1. **视觉目标**：角色正在注视谁/什么？（`注视目标：[对象]`）
2. **聚焦距离**：近距/中距/远距？（决定双眼内聚程度）
3. **心理动机**：为什么看？注视是主动的（追踪/审视/渴望）还是被动的（恍惚/回避/空洞）？
4. **情绪状态**：当前情绪如何影响聚焦？（悲伤→聚焦慢+眼神下坠；愤怒→聚焦锁死+瞳孔扩张）

没有视觉目标的眼神 = 没有灵魂的角色。即使五官完美，目光空洞的特写也会立刻暴露AI。

**视觉注意链**：
```
目标 → 大脑（判断） → 眼外肌（聚焦） → 面部微表情（联动）
```
分镜中的眼神描写应遵循这条链：先确定角色看到了什么→再推导眼球/瞳孔/眼睑的状态→最后写微表情联动。

**四易暴露区精度规范——AI最易穿帮的眼部区域**：

| 区域 | 真人特征 | AI常见错误 | 提示词修正 |
|------|---------|-----------|-----------|
| 眼白（Sclera） | 有血丝+有渐变+有湿润阴影 | 纯白塑料感 | `subtle scleral veining, slight blue-white gradient, moist shadow at inner canthus` |
| 瞳孔边缘 | 有轻微虚化，不绝对锐利 | 机械硬边 | `pupil border with natural soft falloff, not mechanically sharp` |
| 虹膜纹理 | 放射状纤维+深浅层次+中央异色 | 贴图花纹 | `radial iris fibers with depth variation, central heterochromia, layered iris structure` |
| 泪阜（内眼角） | 半透明湿润+毛细血管 | 粉色贴片 | `translucent lacrimal caruncle with micro-capillaries, moist inner canthus` |

这四个区域是"超清但假"的重灾区——分辨率越高越暴露。提示词中必须显式声明修正，不可省略。

**情绪→眼部状态映射表**：

| 情绪 | 双眼聚焦 | 瞳孔 | 眼睑 | 扫视 | 高光 |
|------|---------|------|------|------|------|
| 悲伤 | 聚焦慢+眼神下坠 | 微缩 | 上睑下垂+眨眼减少 | 缓慢+不规律 | 变暗+模糊 |
| 愤怒 | 聚焦锁死 | 轻扩张 | 上睑抬高+下睑收紧 | 高频锁定 | 锐利+强反射 |
| 恐惧 | 焦点跳跃 | 明显放大 | 上睑抬升露白+下睑紧张 | 快速+不稳定 | 强+闪烁 |
| 渴望 | 聚焦稳定于目标 | 轻扩张 | 上睑半垂+聚焦不放 | 低频+追踪型 | 温暖+湿润 |
| 恍惚/回避 | 无明确聚焦 | 正常或微缩 | 半闭+不参与 | 极慢+不修正 | 弱+不定向 |
| 冷漠/面瘫 | 有聚焦但无情绪投资 | 不随事件变化 | 完全放松 | 极少+机械 | 正常存在 |

**意识导向vs纹理导向——提示词的优先级革命**：

| 类型 | 示例 | 效果 |
|------|------|------|
| ❌ 纹理导向 | "ultra detailed eyes, glossy eyes, 8K iris texture" | 画了漂亮的假眼——高清但空洞 |
| ✅ 意识导向 | "locked gaze, focused attention, converged eyes, emotionally anchored eye focus" | 有目标有灵魂的真实眼睛 |
| ✅✅ 意识+纹理 | 意识导向在前+纹理修正在后 | 既有灵魂又逼真 |

核心：**提示词中意识导向词汇>纹理导向词汇**。先声明"看什么"和"为什么看"，再修正"长什么样"。一个低清真人眼神，通常比一个超高清AI假眼更真实。

**视频生成中的眼部微动画层规范**：

视频与静帧不同——眼部的"活感"来自微动画，而非分辨率。AI视频生成中必须声明以下4层微动画：

| 微动画层 | 频率 | 幅度 | 提示词声明 |
|----------|------|------|-----------|
| 微型扫视（Microsaccades） | 每1-2秒 | <1°微跳 | `subtle microsaccadic eye movement, micro-focus correction every 1-2 seconds` |
| 瞳孔呼吸 | 每3-5秒 | ±0.5mm微缩放 | `pupil with natural breathing rhythm, subtle dilation-constriction cycle` |
| 不规则眨眼 | 每2-4秒 | 完整眨眼周期 | `natural irregular blink pattern, 2-4 second intervals, non-mechanical` |
| 眼睑跟随 | 随眼球转动 | 上睑压迫+下睑张力 | `eyelid compression following eye rotation, dynamic upper/lower lid tension` |

缺少微动画层的后果：完全冻结的眼睛=模特假人（mannequin），4层齐全=活人。静帧可以省略微动画声明，但视频生成中4层缺一不可。

**影视级眼神提示词模板**：
```
# 意识层（最高优先级）
[角色名] with locked gaze on [目标], 
[情绪] attention — [主动/被动] focus pattern,
both eyes converged on same focal target at [距离] distance,

# 光学层
perfect binocular convergence, 
realistic corneal refraction, 
physically accurate catchlights from [光源方向],
subtle tear film reflection, 
natural pupil depth with [情绪] dilation,

# 微动画层（视频必须）
cinematic ocular tension,
microsaccadic eye movement,
dynamic eyelid compression,
[频率] irregular blink pattern,

# 纹理修正层
radial iris fibers with depth variation,
subtle scleral veining,
translucent lacrimal caruncle,
pupil border with natural soft falloff,

# 负声明
no dead-eye effect, no glass-eye appearance, no flat iris texture,
no plastic sclera, no mechanical pupil edge
```

**视觉聚焦逻辑与已有规范的深度衔接**：
- 与**暧昧/恋爱规范**：视线停留时间=情绪浓度是聚焦逻辑的恋爱应用——注视目标从"事物"→"人"，聚焦模式从"审视"→"渴望"，瞳孔从"正常"→"轻扩张"
- 与**三步表演法**：视觉注意链=三步法的眼神版——先定"看什么"（=三步法第一步核心肌肉）→再定"怎么聚焦"（=第二步肢体语言）→最后"微表情联动"（=第三步时间轴）
- 与**面瘫美学**：面瘫眼神=有聚焦但无情绪投资——converged but detached，瞳孔不随事件变化，这是聚焦逻辑的特殊应用
- 与**角色描写精度**：面部表演锚定的"眼睑高度+视线落点"=聚焦逻辑在锚点表中的精度化表达
- 与**多人物场面调度**：多人场景中每个角色的聚焦目标必须明确——谁在看谁，决定了Blocking的关系维度

**三步表演法：从"生硬表演"到"影帝级别表演"**：

AI生成器对"她很开心"的理解是随机的——什么效果都可能出。要获得精确的表演效果，必须把笼统情绪词拆解为可执行的表演指令。核心方法论是三步递进：

**第一步：拆面部肌肉——情绪万能公式**：

```
情绪 = 核心肌肉动作 + 辅助细节 + 程度副词
```

- "她很开心" → AI随机发挥，结果不可控
- "她嘴角微微上扬15°，眼角出现细微鱼尾纹，眼轮匝肌自然收缩，眼神明亮，每3秒一次缓慢眨眼" → AI知道你要的是内敛的、温柔的微笑

核心肌肉动作决定情绪的"质"（是笑还是哭），辅助细节决定情绪的"味"（是温柔还是嘲讽），程度副词决定情绪的"量"（是微微还是剧烈）。三者缺一不可。

**第二步：加肢体语言——身体跟着脸一起动**：

光控脸不够。真人演员的身体会跟随面部一起反应，这是区分"AI假人"和"真人表演"的关键维度：

| 情绪 | 仅面部（❌ 不够） | 面部+肢体（✅ 完整） |
|------|------------------|---------------------|
| 害羞的笑 | 嘴角上扬 | 嘴角上扬+下意识低头+用手轻捂嘴巴+耳朵泛红 |
| 隐忍的难过 | 眼眶泛红 | 眼眶泛红+咬紧下唇+肩膀微微耸动+手指攥紧衣角 |
| 紧张的等待 | 表情僵硬 | 表情僵硬+不自觉搓手+来回踱步+频繁看表+吞咽口水 |

**角色性格差异化**：同一种情绪，不同性格的角色表达方式不同——这才是让角色有区分度的关键：
- 同样是紧张：内向的人攥紧手指，外向的人来回走动，沉稳的人指尖轻敲桌面，急躁的人跺脚叹气
- 同样是开心：冷酷男主=嘴角极轻微勾起一侧+喉结滚动；活泼女二=咧嘴笑+拍手+蹦跳
- 写提示词时先想清楚角色性格，再定制专属的表情动作，不能所有角色用同一套

**第三步：做时间轴——逐秒拆解情绪递进**：

不要指望AI一镜到底完成复杂情绪——应该把情绪拆成多段分镜，每段只承载一个情绪阶段，通过剪辑实现自然的递进：

```
"惊喜"的逐秒拆解：
0-1秒：表情瞬间凝固，瞳孔放大，愣住不动（震惊）
1-2秒：嘴角开始快速上扬，眼睛慢慢弯起（识别）
2-3秒：眼角泛起泪光，手不自觉地捂住嘴巴（感动）
3-5秒：肩膀放松，露出释然的微笑，轻轻点头（确认）
```

时间轴的实用策略：只要当前一次抽卡中的可用时长超过70%，再加上剪辑手法，AI生成的视频就有自然的情绪递进。不要贪心让AI一镜到底——分镜+剪辑才是正道。

**三个常见踩坑**：

| 坑 | 问题 | 解决 |
|---|------|------|
| 忘了加强约束 | AI放飞自我，五官变形、表情夸张、画面抖动 | 每段提示词末尾加兜底："无五官变形，无夸张表情，画面稳定" |
| 情绪没有角色化 | 不同角色用同一套提示词，没有区分度 | 先定角色性格，再定制专属表情动作 |
| 不写光影 | 光影对情绪烘托效果极大，AI随机给光=氛围感打折 | 暖调柔光→温馨/冷调侧光→虐心/硬光顶光→对峙，必须显式声明 |

**三步表演法与已有规范的关系**：
- 第一步（面部肌肉）→ 与"解剖学肌肉权重控制"规范一致，是其在情绪表演层面的实践化
- 第二步（肢体语言）→ 与"镜头三层次结构"中的小动作层+微反应层一致，强调身体维度不可省略
- 第三步（时间轴）→ 与"情绪着陆点"规范一致，逐秒拆解就是逐镜头着陆点的微观版本
- 三步法是上述规范在AI视频生成场景下的**实战化工作流**——从"写什么"变成"怎么写"

**暧昧/恋爱/亲密戏分镜规范**：

爱情戏的本质不是"甜"，而是**两个人的心理距离变化**——镜头真正拍的是这种距离如何一点点被打破。本规范覆盖暧昧氛围、恋爱镜头、亲密戏三个层级，每个层级有独立的镜头语言、空间逻辑和提示词策略。

**核心公式：靠近+克制=暧昧**：
- 只有靠近没有克制→直白恋爱（无张力）
- 只有克制没有靠近→冷漠（无温度）
- 同时存在"想接近又不敢接近"→暧昧张力最大化
- 暧昧最重要的不是亲密，而是克制/犹豫/试探/回避/假装正常/无法直视/情绪泄漏
- 真正高级的暧昧戏：**永远有"差一点"**

**视线规则——眼神停留时间=情绪浓度**：

| 视线类型 | 情绪层级 | 镜头处理 |
|----------|---------|---------|
| 偷看 | 初识/暗恋 | 不切镜，保持偷看者的画面让被看者"发现" |
| 余光交流 | 暧昧升温 | 侧脸构图，视线不完整抵达 |
| 倒影/反射 | 隐秘心动 | 镜子/玻璃/水面反射，看的是影子不是真人 |
| 擦肩回头 | 瞬间心动 | 动作结束后0.5秒延迟回头 |
| 对视后移开 | 心动被发现 | A看B→B发现→B移开→镜头不切停留半秒→A也移开→空气变了 |

核心原则：**真正心动的人很难长时间直视**——高级暧昧很少正面完整对视，更多是不完整视线（偷看/余光/倒影/擦肩）。

**呼吸感镜头——镜头模拟偷看者的心跳**：

| 情绪状态 | 运镜响应 | 提示词写法 |
|----------|---------|-----------|
| 情绪靠近 | 极慢推进 | `camera slowly pushing in at 0.3m per 5 seconds, as if drawn toward subject involuntarily` |
| 被发现/心虚 | 镜头停止 | `camera freezes mid-push, holding breath, sudden stillness` |
| 情绪失控 | 呼吸变重 | `subtle handheld wobble intensifying, camera breathing with the scene` |
| 空气变化 | 微弱推进+长停顿 | `extremely slow drift forward, then lock-off, silence becoming audible` |

镜头必须像"一个人正在偷偷观察另一个人"——不能机械，必须有心跳感。

**空间距离三阶段——爱情戏真正拍的是距离变化**：

| 阶段 | 距离特征 | 空间表现 | 心理状态 |
|------|---------|---------|---------|
| 安全距离 | 理性边界 | 桌子/沙发/门框/走廊等空间障碍物存在 | 关系仍然理性，未越界 |
| 危险距离 | 私人空间被侵入 | 递东西手碰到/站位靠近/呼吸能感知/说话距离变短 | 观众本能意识到关系在改变 |
| 暧昧距离 | "差一点碰到" | 手悬停/呼吸接近/额头靠近/肩膀轻触/衣角擦过 | 未完成动作产生最强情绪张力 |

**"差一点"原则**：未完成动作永远比已完成动作更有张力——手悬停>牵手，额头靠近>亲吻，衣角擦过>拥抱。

**身体语言的心理读解**：

| 身体动作 | 表面含义 | 深层心理 | 提示词要点 |
|----------|---------|---------|-----------|
| 后退 | 拒绝？ | 可能是害怕自己失控 | `stepping back half-step, not rejection but self-protection` |
| 靠近 | 主动？ | 可能是情绪压过理性 | `leaning in unconsciously, rationality overridden by emotion` |
| 停住 | 犹豫？ | 情绪已进入无法回避阶段 | `frozen mid-motion, the most dangerous state — emotion beyond retreat` |
| 手指收紧 | 紧张？ | 身体比台词更诚实的泄露 | `fingers curling tighter on fabric, body betraying composure` |
| 无意识整理头发 | 习惯？ | 心动后的无意识自我整理 | `hand unconsciously smoothing hair, autopilot grooming response` |
| 声音变轻 | 礼貌？ | 亲密空间的下意识音量调节 | `voice dropping to near-whisper, as if only he should hear` |

**焦距与亲密关系的映射**：

| 焦距 | 情绪属性 | 适合阶段 | 提示词 |
|------|---------|---------|--------|
| 24-35mm广角 | 空间真实+情绪暴露+孤独感 | 初识/疏离/青涩 | `24mm wide angle, environmental context dominating, two isolated figures in shared space` |
| 50mm标准 | 接近人眼+自然陪伴 | 日常互动/温柔交流 | `50mm normal lens, natural perspective, as if standing beside them` |
| 85-135mm长焦 | 空间压缩+呼吸变重+欲望压迫 | 暧昧/对视/欲望/心跳 | `85mm portrait lens, spatial compression making distance feel charged, background dissolving` |

**焦外=世界消失**：真正高级的爱情镜头，背景逐渐失焦——意味着世界开始消失，人物只看见彼此。提示词：`background gradually dissolving into bokeh, world disappearing until only two figures remain in focus`

**光影心理学**：

| 光影类型 | 情绪功能 | 提示词 |
|----------|---------|--------|
| 柔光 | 降低现实感+增加皮肤质感+制造梦感=主观滤镜 | `soft diffused light, dreamy quality, skin glowing, reality softened` |
| 阴影 | 阴影=秘密，半张脸藏暗处=关系危险且迷人 | `half face in shadow, mystery in the unseen, danger in concealment` |
| 冷暖混合 | 理性世界（冷）中出现情绪温度（暖） | `cold ambient light with warm practical light source, emotion entering rational space` |
| 侧光切割 | 面部被分割=内心被分割 | `hard side light splitting face, internal division made visible` |
| 霓虹闪烁 | 城市夜晚+不确定性+心跳节奏 | `neon lights flickering across face, urban heartbeat rhythm` |
| 门缝漏光 | 禁忌感+窥视感+一线希望 | `single sliver of light through door crack, forbidden visibility` |

**亲密戏分镜规范——拍情绪不拍动作**：

核心原则：高级亲密戏拍的是**信任/脆弱/情绪失控/欲望释放/心理依赖/身份变化**，不是身体接触。

| 层级 | 低级做法 | 高级做法 |
|------|---------|---------|
| 起点 | 直接从动作开始 | 先建立情绪/空间/呼吸/安静 |
| 镜头重点 | 正面身体 | 手/后颈/肩膀/呼吸/头发/眼神/皮肤光线 |
| 节奏 | 持续推进 | 靠近→停住→不立刻继续→犹豫/渴望/害怕/克制 |
| 光线 | 硬直光 | 床头暖灯/城市霓虹/柔和侧光/阴影包裹 |
| 空间 | 随意 | 安静+封闭+呼吸感+私密性 |

**亲密戏镜头重点顺序**（情绪感从强到弱）：手部动作>后颈>肩膀>呼吸>头发>眼神>皮肤光线>正面身体——越是"边缘"部位越有情绪感。

**呼吸与停顿=亲密戏的骨架**：
```
靠近 → 停住 → 不立刻继续
观众感受到：
├── 犹豫：他/她想要但不敢
├── 渴望：身体已经决定但理性还在抵抗
├── 害怕：一旦继续就无法回头
└── 克制：知道不该但身体在靠近
```

**恋爱分镜五阶段节奏**：

| 阶段 | 焦距 | 运镜 | 空间 | 视线 | 声音 | 情绪 |
|------|------|------|------|------|------|------|
| 初识 | 24-35mm广角 | 静止/极慢 | 保持距离+空间完整 | 回避 | 环境声为主 | 疏离/好奇 |
| 暧昧 | 50mm中焦 | 极慢推进+呼吸感 | 空间开始压缩+障碍物减少 | 余光/偷看 | 环境声变弱+细节声放大 | 试探/心动 |
| 心动 | 85-100mm长焦 | 推进+焦点锁定 | 世界失焦+只剩彼此 | 对视后移开 | 极安静+心跳声 | 渴望/害怕 |
| 失控 | 变焦/手持 | 不稳定+距离快速靠近 | 构图失衡+空间崩塌 | 无法回避的对视 | 节奏断裂 | 理性瓦解 |
| 平静 | 50-85mm | 长镜头+柔和 | 留白+安静空间 | 柔和凝视 | 极安静+呼吸声 | 释然/归属 |

**暧昧/恋爱/亲密戏与已有规范的关系**：
- 与**三步表演法**：恋爱戏的肢体语言是三步法第二步的专门化——后退/靠近/停住对应不同情绪阶段的肌肉+肢体组合
- 与**视觉聚焦逻辑**：视线规则（停留时间=情绪浓度）是视觉聚焦在恋爱场景的深度应用——注视目标从"事物"变成"人"，聚焦模式从"审视"变成"渴望"
- 与**运镜五境**：呼吸感镜头=运镜五境中"静止镜头的力量"的恋爱场景版——镜头停止本身是叙事事件
- 与**焦距节奏**：恋爱五阶段的焦距变化（广角→中焦→长焦→变焦→回中焦）是焦距节奏在情感弧线上的完整实践
- 与**面瘫美学**：暧昧中的"假装正常"与面瘫有交叉——区别是面瘫=主动消除情绪线索，假装正常=试图消除但身体在泄漏
- 与**角色描写精度**：恋爱戏的肢体语言需要精度规范级别的描写——"手悬停"必须精确到"手指在距离对方皮肤2cm处停住，指尖微颤"

**微表情与生理细节规范**：

情绪特写镜头中，不能只写"哭了"或"流泪"，必须描述眼泪的完整视觉行为链——因为眼泪不是一个静态符号，而是一个有物理规律的动态过程。以下为标准参考，所有涉及流泪的分镜都必须按此层级描述：

1. **溢出**：从内眼角缓慢溢出，非外眼角（解剖学事实：泪腺位于内眼角上方）。半透明生理盐水质感，不是水滴形，而是沿眼球表面扩散的薄层。
2. **表面光学**：眼泪表面有细腻的环境光反射（映射所处场景的色温），这是区分"真实眼泪"和"水珠贴纸"的关键视觉特征。
3. **滑落路径**：受重力影响沿脸颊自然滑落，呈不规则曲线（非直线），速度极慢。在颧骨处因曲面汇聚，短暂停留后滴落。
4. **皮肤互动**：打湿皮肤形成湿润反光带，反光带的宽度与亮度随时间推移变化（刚湿润时窄而亮，扩散后宽而暗）。
5. **妆面互动**：如有妆容，晕开少量睫毛膏/眼线，留下淡淡的泪痕（妆面与泪液的物理混合，非均匀溶解）。
6. **睫毛状态**：睫毛上挂着细小泪珠，因表面张力呈半球形粘附，不是沿睫毛均匀涂抹。
7. **面部联动**：面部肌肉自然紧绷（非夸张扭曲），嘴唇微微颤抖（克制情绪的标志性微动作），整体情绪克制而非爆发。

简记口诀：**溢出→反射→曲滑→汇聚→反光→晕妆→挂睫→颤唇**——写流泪镜头时逐项检查，缺一补一。

**面瘫美学（Deadpan Aesthetics）规范**：

并非所有角色都要"有表情"。面瘫美学是一种故意不露情感、冷漠和极简主义的表达风格——通过消除戏剧性的表情和情绪，让观众将注意力集中在事物本质或荒诞的底层逻辑上。它与微表情规范互为反面：微表情追求"多"，面瘫追求"无"；但两者都不是随意为之，而是精确的创作选择。

**核心特征**：
- **面无表情**：不是"面瘫"（神经障碍），而是"面瘫式表演"（主动克制）——演员/角色刻意不提供情绪线索
- **极简构图**：对称、居中、平面化，去除视觉噪音——构图本身就是叙事
- **低饱和度**：褪色、灰调、冷淡色调——情绪被从色彩中抽离
- **冷幽默感**：荒诞存在于事件本身而非反应中——角色对荒诞无动于衷，观众反而更想笑

**面瘫 vs 微表情的根本区别**：

| 维度 | 微表情范式 | 面瘫美学范式 |
|------|-----------|-------------|
| 情绪传递 | 角色表达→观众接收 | 观众自行推断→角色不确认 |
| 表演密度 | 高（肌肉/眼泪/微反应） | 极低（接近零） |
| 视觉信息 | 画面承载情绪 | 画面承载事实 |
| 观众参与 | 被动接收情绪 | 主动投射情绪 |
| 一致性焦点 | 跨镜头情绪连贯 | 跨镜头情绪空白连贯 |
| 眼神 | 有明确视觉目标+情绪聚焦 | 目标存在但情绪抽离——"看但不反应" |

**代表导演与视觉语法**：

| 导演 | 视觉语法 | 面瘫实现方式 |
|------|---------|------------|
| 韦斯·安德森 | 严格对称+平面构图+低饱和暖色 | 角色面无表情地执行荒诞动作，对称构图强化"仪式感" |
| 欧格斯·兰斯莫斯 | 机械式对白+僵硬肢体+冷调 | 角色像机器人一样说荒诞台词，肢体动作最小化 |
| 阿基·考里斯马基 | 冷色调+极简对白+面无表情 | 角色用最少的反应面对极端情境，冷幽默由此产生 |
| 贾木许 | 长镜头+静默+漫不经心 | 角色对一切漠不关心，事件在他们的无动于衷中发生 |

**面瘫美学的提示词策略**：

面瘫不是什么都不写——恰恰需要精确控制"什么都不做"的程度：

```
# 错误：什么都不写 = AI会自由发挥，给角色随机表情
close-up of character

# 错误：写"无表情"太笼统 = AI可能画成"面瘫"而非"面瘫式表演"
expressionless face

# 正确：精确控制面瘫的程度和类型
deliberately neutral expression, flat affect, no emotional engagement, 
eyes present but detached — seeing without reacting, 
facial muscles at resting state with minimal tonal variation,
subconscious micro-blinks only, no deliberate expression change,
brow completely relaxed, lips sealed at natural resting position,
jaw unclenched, neck relaxed — zero tension signals
```

**面瘫美学的眼神控制**：

面瘫角色的眼神最微妙——它不是"空洞"（那是AI的dead-eye问题），而是"在场但不参与"：
- 视觉目标明确（角色确实在看东西），但情绪聚焦抽离
- 瞳孔不随情绪变化（保持自然光线的正常响应，但不随事件扩张或收缩）
- 眼睑完全放松（无微颤、无紧张、无刻意眨眼）
- 高光正常存在（这不是死人，是活人不反应）

提示词：`conscious but detached gaze, eyes tracking target without emotional investment, present but unengaged, binocular convergence on target with flat ocular tension`

**面瘫美学的构图与运镜**：

| 元素 | 微表情范式 | 面瘫美学范式 |
|------|-----------|-------------|
| 构图 | 三分法/前景遮挡/负空间 | 严格对称/居中/平面化 |
| 运镜 | 手持+微晃+推拉 | 固定/极缓慢推/平移——摄影机也不"反应" |
| 焦距 | 85-100mm亲密特写 | 35-50mm中景——保持距离 |
| 景深 | 浅（虚化背景） | 可浅可深，但构图对称 |
| 色调 | 情绪色调（暖/冷随情绪变） | 低饱和/褪色/单一色调——色彩不参与情绪 |
| 切镜节奏 | 情绪弧线驱动 | 事件逻辑驱动——切镜不为情绪服务 |
| 前景遮挡 | 制造窥视感/主观性 | 不用——前景遮挡暗示情绪参与，面瘫不需要 |

**面瘫美学在分镜中的标注规范**：

当一场戏采用面瘫美学时，必须在场景锚点表中声明：
```
表演风格：面瘫美学（Deadpan）
构图规则：严格对称/居中
色调规则：低饱和度，[具体色调方向]
运镜规则：固定机位/极缓慢运动，摄影机不参与情绪
情绪传递方式：观众自行投射，角色不确认
```

分镜镜头描述中：
- 不使用解剖学肌肉权重（面瘫不需要肌肉控制，需要的是肌肉"不控制"）
- 不写情绪着陆点（面瘫没有情绪弧线——情绪弧线在观众脑中，不在角色脸上）
- 写`flat affect maintained throughout`替代`emotional landing: xxx`
- 小动作层仍可存在（面瘫角色可以有潜意识动作，但动作不带情绪色彩）
- 微反应层**必须禁用**（微反应是情绪泄露，面瘫的角色不泄露）

**电影级对白分镜规范**：

对白戏是电影最常见的场景类型，但最容易被拍成"A说一句→切B→B说一句→切A"的机械信息交换。真正电影级的对白戏不拍"说话"，而拍**情绪权力关系变化**——谁在回避、谁在试探、谁在撒谎、谁在等待崩溃、谁正在失去控制。高级对白的核心：**即使静音，观众依然能看懂情绪**。

**对白五层核心结构**：

| 层级 | 核心逻辑 | 镜头任务 |
|------|---------|---------|
| 视线关系 | 眼神=情绪攻击 | 拍谁敢直视/谁在闪躲/谁先移开/谁在偷看/谁在压迫 |
| 停顿 | 不说话时才是真情绪 | 停顿镜头原则：稳镜+微推+留环境音+让观众等待 |
| 空间距离 | 物理距离=心理距离 | 三阶段：远=理性/近=压迫/远=崩塌 |
| 潜台词镜头 | 角色说A但真实是B | 拍"谎言泄漏点"：手离开/呼吸停顿/视线失焦/光线变冷 |
| 情绪主导权 | 权力关系不断变化 | 镜头必须同步变化：强势近满稳低机位/弱势遮挡边缘高机位 |

**视线=情绪攻击**：
观众本能读取视线信息——这不是"看"，而是心理层面的攻击/防御/撤退。高级拍法：不要立刻正反打切脸，而是先拍停顿/先拍动作/再进入语言/延迟反应。
```
错误：问话→立刻切对方脸→回答
正确：问话→拍对方握紧的手→呼吸停顿→缓慢抬头→空气已经变了
```

**停顿=对白里的刀**：
真正的情绪不在台词里，而在呼吸/空气/犹豫/沉默/环境声中。停顿镜头的核心：**不要急着切镜头**——稳镜+微推+留环境音+让观众"熬"在情绪里，因为等待本身制造心理张力。
```
"你是不是早就知道了。"
停顿。窗外车流声。杯子轻碰桌面。
"……知道什么？"
→ 真正的戏发生在停顿里。
```

**空间距离三阶段**：

| 情绪阶段 | 距离 | 镜头 | 心理状态 |
|----------|------|------|---------|
| 情绪平稳 | 人物距离远 | 中景+对称构图+稳定镜头 | 关系尚可控制 |
| 情绪压迫 | 人物距离缩短 | 长焦+压缩空间+更近特写 | 窒息感 |
| 情绪崩塌 | 反而拉远 | 远景+人物被空间吞没 | 关系已无法挽回 |

**潜台词镜头=拍"谎言泄漏点"**：
高级对白：角色说的是A，真实情绪是B。镜头不能只拍嘴——而要拍身体在"泄漏"真相：手离开杯子/呼吸停顿/视线失焦/光线变冷。**镜头要寻找的是"情绪泄漏点"**。

**情绪主导权转移**：

| 阶段 | 镜头特征 | 视觉效果 |
|------|---------|---------|
| 强势人物 | 更近+更满+更稳定+低机位 | 完整占据画面 |
| 弱势人物 | 被遮挡+留白更多+边缘化+高机位 | 被压迫感 |
| 权力反转 | 画面中心变化+遮挡关系反转+弱势进入视觉主导 | 原本稳定的人开始手持/被压制者进入画面中心 |

**呼吸镜头理论（对白专用）**：
呼吸镜头不是简单晃动，而是**镜头拥有人的心理节奏**——它会犹豫/靠近/停顿/后退/迟疑，像人在观察另一个人。与暧昧/恋爱场景中的呼吸镜头同源，但对白场景更强调**权力感知**而非情感靠近：

| 情绪状态 | 运镜响应 | 提示词方向 |
|----------|---------|-----------|
| 情绪靠近 | 镜头缓慢推进 | `camera slowly pushing in, drawn toward subject involuntarily` |
| 情绪退缩 | 镜头停止 | `camera freezes, holding breath, sudden stillness` |
| 情绪失控 | 镜头失稳 | `subtle handheld wobble intensifying, breathing with the scene` |
| 情绪崩裂 | 镜头与人物呼吸同步 | `camera syncing with subject's breathing rhythm, immersive presence` |

高级呼吸镜头特点：推镜极轻，不被观众明显察觉，像空气在流动——**情绪驱动镜头，而非技术驱动**。

**不对称正反打的对白应用**：
普通正反打=机械切换+轴线对称+功能性表达。电影级正反打=**情绪权力设计**——因为**情绪从来不对称**：

| 正反打类型 | 镜头特征 | 情绪含义 |
|-----------|---------|---------|
| 强势方 | 更近+更满+更稳定+低机位 | 完整占据画面，侵略性强 |
| 弱势方 | 留白更多+被遮挡+位于边缘+高机位 | 被压迫，空间感被剥夺 |
| 焦距不对称 | 男85mm长焦压缩窒息/女35mm广角留环境 | 双方已不在同一个情绪空间 |

**视线压迫**：谁控制画面视线，谁就控制情绪主导权——即使角色坐着，如果眼睛位于画面高处，观众依然觉得她在心理层面占上风。

**第三视角="空间在看他们"**：
这是最高级的对白设计之一——不是A看B，也不是B看A，而是**空间正在看他们**。

| 第三视角位置 | 产生效果 |
|-------------|---------|
| 房间角落 | 命运旁观感 |
| 门外 | 窥视感+被排斥感 |
| 走廊尽头 | 宿命感+距离感 |
| 镜子里 | 双重现实+自我审视 |
| 家具后 | 隐藏的观察者+秘密感 |

观众会产生"命运正在旁观人物"的感觉——例如：夫妻争吵，镜头远远躲在客厅角落，背景电视闪烁，雨声持续→观众感受到这段关系正在死亡。

**对白节奏五阶段系统**：

| 阶段 | 景别/运镜 | 空间 | 声音 | 情绪 |
|------|----------|------|------|------|
| 情绪平静 | 中景+固定镜头+少切换 | 空间完整 | 安静/正常环境音 | 理性/控制 |
| 情绪试探 | 微推镜+增加遮挡+前景增加 | 空间开始变形 | 呼吸感增强 | 不安/试探 |
| 情绪压迫 | 长焦+特写+空间压缩 | 构图变窄 | 呼吸变重/环境音减弱 | 窒息/压迫 |

**导演对白风格速查**：

| 导演 | 对白核心 | 镜头特征 | 情绪逻辑 |
|------|---------|---------|---------|

**焦距-情绪系统映射（对白通用）**：

|------|---------|-------------|-----------|
| 广角24-35mm | 空间真实+人物孤独+情绪暴露 | 疏离/不安/压迫空间 | `24mm wide angle, subject isolated in environment, truth exposed by space` |

**焦距情绪规律**：情绪疏离→广角；情绪靠近→中焦；情绪失控→长焦特写。

**短剧对白电影感三法**：
1. **减少解释性台词**——不要直接说"我很痛苦"，而是停顿/转身/点烟/沉默/呼吸变化
2. **增加环境呼吸**——加入风声/空调声/电流声/远处车流，空间才会真实
3. **不要只拍脸**——电影感来自"空间中的人物"，不是演员特写合集

**对白分镜与已有规范的关系**：
- 与**正反打规范**：对白中的正反打不是机械交替，而是情绪权力设计——正反打规范提供了拆分方法，本规范提供了情绪逻辑
- 与**暧昧/恋爱规范**：对白规范是非恋爱场景的视线/停顿/空间系统，恋爱规范是对白在情感场景的专门化
- 与**运镜五境**：对白呼吸镜头=运镜五境"静止镜头的力量"的对白版——镜头停止本身是叙事事件
- 与**焦距节奏**：对白五阶段的焦距变化与恋爱五阶段同源但不同——恋爱是"靠近"，对白是"权力变化"
- 与**视觉聚焦逻辑**：对白中的视线攻击/回避是聚焦逻辑在对话场景的行为化——谁聚焦谁=谁被谁控制
- 与**导演风格圣经**：导演对白风格速查是风格圣经在对白场景的专门化——同一位导演在打斗/恋爱/对白中的风格参数不同
- 与**打光位置**：对白光影心理学是八大光位在对白场景的情绪映射——物理光位→心理效果

**暧昧/恋爱/亲密戏增强——环境声音设计**：
心动时人会开始听见细节——暧昧/恋爱场景的环境声音不是"背景"，而是情绪的放大器：

| 声音类型 | 情绪功能 | 提示词写法 |
|----------|---------|-----------|
| 呼吸声 | 私人空间入侵 | `breathing becoming audible, private space closing in` |
| 衣料摩擦 | 身体靠近的证据 | `fabric brushing sound, proximity made audible` |
| 风声/水声 | 空间的孤独+亲密 | `wind outside, rain on glass, two people inside — the world becomes a cocoon` |
| 电流声/钟表声 | 时间的压迫感 | `electric hum, clock ticking, time stretching in stillness` |
| 远处车流/列车 | 理性世界在远处运转 | `distant traffic, rational world continuing outside their bubble` |

**王家卫式恋爱增补——时间感改变**：
恋爱本质上会改变人的时间感——真正心动瞬间，时间会变慢。王家卫式处理：慢动作+重复动作+音乐循环+长时间凝视。提示词：`time dilating in the moment of recognition, 120fps slow motion, reality softening at edges, as if the world knows something has changed`

镜头1：广角远景。两人站得很远。只有雨声。

**多镜头视频序列规范**：

AI视频生成（Runway/Kling/Sora/Veo等）与静态图像生成有本质区别——视频是时间的艺术，每个镜头不是孤立的画面，而是情绪弧线上的一个节点。多镜头视频序列的提示词必须遵循以下规范：

**一、序列级全局声明（Global Motion Style）**：
每个多镜头序列的开头必须有一段全局声明，锁定：
- 整体风格基调（`ultra-realistic portrait photography, straight out of camera`）
- 摄影机参数（`large aperture shallow depth of field, 85mm prime`）
- 皮肤/面部真实感标准（`real skin texture with visible pores, translucent natural skin tone without fake whiteness, naturally asymmetric facial features, no stiffness`）
- 氛围质感（`slight film grain, dust noise, 8K ultra sharp, zero AI modeling traces`）
- 多参考图一致性锁（`Strictly using all previous [角色名] reference images for exact facial consistency, skin texture, eye shape and performance style lock`）
- 影视级提示词原则块（`cinematic prompt principles`：微表情+自然聚焦+皮肤质感+大气粒子+动态光影+前景遮挡+中景锐利+背景虚化）
- 运镜风格（如`shaky handheld camera style with organic breathing movement and subtle searching adjustments`）
- 帧率与运动质感（`cinematic 24fps motion with film-like motion cadence, natural motion blur on eyelashes and falling tears`）

**二、权重标注的解剖学肌肉控制**：
视频序列中面部表情的精确控制需要用解剖学肌肉名称+权重值来标注，而非笼统的"悲伤""微笑"。这是AI视频生成中最精细的控制手段：

| 情绪动作 | 解剖学肌肉 | 权重标注示例 | 视觉效果 |
|----------|-----------|-------------|----------|
| 微笑 | 颧大肌上提 | `(zygomaticus major lift:1.35)` | 嘴角上扬+脸颊自然隆起 |
| 真笑 | 眼轮匝肌收缩 | `(orbicularis oculi engagement:1.45)` | 鱼尾纹+眼角挤压+眼神闪光 |
| 眉头微蹙 | 皱眉肌激活 | `(corrugator supercilii micro-activation:1.4)` | 眉间细纹+眉内端下压 |
| 上睑微颤 | 眼轮匝肌部分放松+上睑微颤 | `(orbicularis oculi partial relaxation with upper lid micro-tremor:1.55)` | 眼轮松开+上睑抖动 |
| 嘴角下拉 | 口角降肌 | `(depressor anguli oris pulling mouth corners downward:1.45)` | 嘴角下坠+悲伤轮廓 |
| 颈部紧张 | 颈阔肌 | `(platysma neck tension:1.5)` | 颈带可见+颈部绷紧 |
| 颧肌缓慢释放 | 颧大肌放松 | `(slow zygomaticus release:1.4)` | 微笑逐渐消退 |
| 提上睑肌微垂 | 上睑提肌 | `(levator palpebrae slight droop:1.55)` | 上睑轻微下垂+疲惫感 |
| 颏肌颤动 | 颏肌 | `(mentalis chin quiver:1.45)` | 下巴微颤+克制情绪 |

权重值范围建议：1.2-1.6。低于1.2效果不明显，高于1.6可能过度导致失真。核心情绪转折点用1.4-1.55，辅助情绪用1.2-1.35。

**三、镜头三层次结构**：
每个镜头不是孤立的"画面描述"，而是由三个层次构成的完整叙事单元：

1. **主表演层（Primary Performance）**：角色的核心情绪表达——面部肌肉变化、眼神方向、眼泪行为等。这是镜头的信息主体
2. **小动作层（Small Ongoing Action）**：角色在表演中的潜意识物理动作——手指摸索项链、下意识握紧衣物、不自觉吞咽。这些动作带有自然惯性（`natural inertia`），为表演增加真实维度
3. **潜意识微反应层（Subconscious Micro-reaction）**：完全不受控的生理反应——快速微眨、脸颊泛红、肩膀微颤、喉结滚动。这些反应不服务于叙事，但服务于真实感

三层次的关系：主表演层承载"角色在表达什么"，小动作层承载"身体在做什么"，微反应层承载"生理在发生什么"——三者同时存在、互不矛盾，缺一不可。

**四、情绪着陆点（Emotional Landing）**：
每个镜头必须有一个明确的情绪着陆点——这个镜头结束时，角色处于什么情绪状态？这是镜头间情绪弧线的连接点：

```
Shot 1 → emotional landing: radiant yet fragile joy
Shot 2 → emotional landing: joy cracking into unease  
Shot 3 → emotional landing: sorrow breaking through
Shot 4 → emotional landing: quiet heartbreak
Shot 5 → emotional landing: lingering sorrow
```

情绪着陆点不是镜头开始的情绪，而是镜头结束时的情绪——它是下一个镜头的情绪起点。连续镜头的情绪着陆点构成完整的情绪弧线。

**五、焦距节奏设计**：
多镜头序列中焦距的变化构成视觉节奏——越紧的焦距=越亲密/越压迫，越宽的焦距=越疏离/越呼吸：

| 焦距 | 景别 | 心理效果 | 适用时机 |
|------|------|---------|----------|
| 50mm | 中近景 | 呼吸空间，略有距离 | 序列结尾，给观众消化空间 |
| 85mm | 近景/特写 | 亲密，日常对话距离 | 大部分情绪镜头的默认焦距 |
| 100mm | 大特写 | 极度亲密，侵入私人空间 | 情绪最激烈/最脆弱的瞬间 |

典型案例：85→85→100→85→50（建立→推进→极度亲密→回落→呼吸）——先在85mm建立亲密感，100mm刺入最深处，50mm给观众退一步的空间。

**六、CUT标记与镜头间连续性**：
- 镜头之间用`CUT;`明确标记分割——AI视频生成器需要明确的段落边界
- CUT不是情绪中断——上一个镜头的情绪着陆点是下一个镜头的情绪起点
- 连续运镜（如slow dolly-in）可以跨镜头延续，但每个镜头的运镜描述仍需独立声明
- 手持呼吸感应跨镜头延续——`camera organically breathing closer`

**七、眼泪物理的权重控制**：
在视频序列中，眼泪不是一次性的"哭了"，而是有精确时间线的物理过程，需要用权重标注精确控制：

```
(first tear forming naturally with highly refined real tear physics:1.55): 
viscous droplet swelling and slow release exactly as in real-tear references

(second tear follows the first with refined real tear physics:1.55): 
natural asymmetric merging, realistic viscosity and believable human-speed flow
```

眼泪的跨镜头进度：
- Shot 1：无泪（笑容）
- Shot 2：泪液蓄积（tear meniscus buildup at lower lash line）+ 第一滴形成
- Shot 3：第一滴滑落（slow gravitational roll with natural wobble, droplet deformation）
- Shot 4：第二滴跟随（asymmetric merging, realistic viscosity）
- Shot 5：多条泪痕（multiple natural tear trails glistening under light）

每一阶段都必须与微表情规范中的"溢出→反射→曲滑→汇聚→反光→晕妆→挂睫→颤唇"链条对应。

### 第三步：自检

生成全部分镜后，逐项检查以下问题。自检不是走过场，是核心质量环节——专业分镜的价值在于视觉叙事的准确性，一个逻辑断裂的镜头比缺失一个镜头更糟糕。

**Phase 4 强制验证——Full Script Coverage Check（完整性交叉核对）**：

在执行常规自检之前，必须先完成完整性核对——这是最高优先级的验证步骤：

1. **逐场景核对**：将分镜输出中的每个场景与Exhaustive Inventory中的场景清单逐一对照，确认每个原始场景都有对应的分镜段落
2. **逐台词核对**：将分镜中每句台词与原始剧本对白逐一对照，确认无任何台词被省略、合并或改写
3. **逐动作块核对**：将分镜中的动作/走位/交互与原始剧本动作块逐一对照，确认无任何动作描述被跳过
4. **逐括号说明核对**：确认原始剧本中每一个括号说明（表演/情绪/节奏指示）都在分镜中有所体现
5. **逐转场核对**：确认每一处时空转换点都有对应的转场处理

**核对结果必须输出**：
> Full Script Coverage Check: [场景] X/X ✓ | [台词] Y/Y ✓ | [动作块] Z/Z ✓ | [括号说明] A/A ✓ | [转场] B/B ✓
> 如有任何不匹配项，标注 ❌ 并立即修正后重新核对。

**常规检查清单：**

1. **人物一致性**：同一角色在不同镜头中的外观是否与锚点表一致？服饰、道具、体型、标志性特征是否有矛盾？变化层的变化是否有因果链？
2. **场景一致性**：同一场景内光源方向、色温、空间结构、氛围元素是否前后一致？角色在空间中的相对位置是否符合已建立的平面图？
3. **景别连续性**：相邻镜头景别跳变是否合理？无理由的跳变（如特写直接接大远景）需要过渡镜头或明确的叙事理由。
4. **运镜逻辑**：运镜方向是否一致？同一场景内的运动方向不应无故反转（遵守180度轴线规则）。
5. **空间连续性**：角色位置、道具摆放、光线方向在连续镜头间是否保持一致？
6. **节奏合理性**：是否存在连续短镜头堆砌（节奏过快）或连续长镜头拖沓（节奏过慢）？情绪曲线与镜头节奏是否匹配？
7. **叙事完整性**：每个场景的叙事节拍是否都有对应的镜头覆盖？是否有信息遗漏导致观众无法理解？
8. **重复与冗余**：是否有连续多镜头重复表达同一信息？是否有可合并的镜头？
9. **转场合理性**：场景间转场是否自然？是否有突兀的时空跳转需要过渡处理？
10. **角色动线**：角色在场景内的移动是否合理？走位是否与空间设定矛盾？

**自检输出格式：**

```
## 自检报告

### 发现问题
| 编号 | 类型 | 位置 | 问题描述 | 严重程度 |
|------|------|------|----------|----------|
| Q1 | 人物不一致 | S5-02 vs S5-07 | Johnny护目镜在S5-02为红色，S5-07描述为蓝色 | 高 |
| Q2 | 场景不一致 | S3-04 vs S3-06 | 主光从左侧变为右侧，无叙事理由 | 高 |
| Q3 | 景别跳变 | S2-03→S2-04 | 特写接大远景，缺乏过渡 | 中 |

### 优化方案
| 编号 | 对应问题 | 优化措施 |
|------|----------|----------|
| F1 | Q1 | S5-07护目镜颜色修正为红色，与锚点表一致 |
| F2 | Q2 | S3-06光源方向修正为左侧高处，与场景锚点表一致 |
| F3 | Q3 | 在S2-03与S2-04间插入一个全景过渡镜头 |
```

### 第四步：优化与输出

根据自检报告修正分镜，输出最终版本。优化时遵循：
- 优先解决高严重度问题（人物/场景不一致为最高优先级）
- 优化不能引入新的一致性问题
- 每处优化在备注栏标注优化原因

### 第五步：输出完整文档

按以下结构输出：

## 关键约束

- 基于剧本内容生成分镜，不添加剧本中没有的新情节，但可补充合理的视觉细节
- 推断内容必须用 `[推断]` 标注，让使用者区分原文依据和合理推断
- 景别和运镜的选择必须服务于叙事意图，不是为了炫技。每个镜头的存在都要回答"观众通过这个镜头获得什么信息或感受"
- **人物一致性是硬约束**：同一角色在同一状态下的外观描述不可矛盾。变化必须有因果链。锚点表的一致性红线是自检的必选项。
- **场景一致性是硬约束**：同一场景的光源、空间、氛围在连续镜头中不可矛盾。建立场景锚点表后，所有镜头描述必须回溯校验。
- 自检环节不可省略，且人物/场景一致性检查为最高优先级。如果自检未发现问题，也要明确说明"自检通过，未发现需修正的问题"
- 对于超长剧本（超过10个场景），先输出场景分解表和视觉锚点表，让用户确认范围后再逐场生成
- 分镜数量适中：一个场景通常 4-12 个镜头，除非是大型动作戏或蒙太奇段落

## AI生成适配

当分镜用于 AI 视频/图像生成时，额外输出适配提示词。详细规范见 `references/ai-generation-guide.md`，核心原则：

- **提示词中必须包含角色锚点表的核心视觉特征**，确保 AI 生成的角色跨镜头一致
- **提示词中必须包含场景锚点表的光源与氛围参数**，确保 AI 生成的场景跨镜头一致
- 为每个镜头生成独立的英文提示词，同时在提示词开头嵌入角色/场景的锚定描述
- 连续镜头的提示词之间，保持开头锚定描述完全一致，只替换动作/构图/运镜部分

### 生产级首帧提示词标准（MANDATORY Photorealism & Anti-AI-Plastic Layer）

**所有含人物的分镜图提示词必须包含6层声明结构**，这是消除AI塑料感、僵硬感、空洞眼神和扁平光影的硬性防护：

| 层级 | 名称 | 核心声明 |
|------|------|---------|
| 1 | 表情与表演结构 | 微表情 + 眼神自然聚焦 + 自然眨眼 + "人物+正在做的小事+下意识反应+情绪落点" |
| 2 | 动作与惯性 | 动作力量感 + 衣角/头发随惯性飘动 + 下意识小动作（绝不僵硬呆板） |
| 3 | 光源与氛围 | 明显明暗变化 + 顶部光/发丝光 + 侧光 + 光影颗粒 + 灰尘噪点 + 氛围感（绝不均匀受光、干净无层次） |
| 4 | 皮肤与面部真实感 | 可见毛孔细纹 + 自然红润 + 肤色不均 + 轻微小痣 + 真实肌理 + 轻微不对称 + 表情放松（绝不塑料陶瓷肌） |
| 5 | 景深与镜头 | 前景虚化遮挡物 + 中景人物清晰 + 背景虚化 + 85mm定焦浅景深 + 原相机直出质感 |
| 6 | 整体质感 | 轻微胶片颗粒感 + 8K高清 + 神态灵动自然 + 生活化穿搭 + 真实实景背景 |

**不含人物的全景/空镜**：无需L1-L2层，但L3-L6仍必须声明。

**6层与已有规范的融合**：
- L1（表情表演）= 视觉聚焦逻辑 + 三步表演法 + 情绪万能公式
- L2（动作惯性）= 三步表演法小动作层 + 打斗/走路模板
- L3（光源氛围）= 电影打光位置规范 + 色彩情绪圣经
- L4（皮肤面部）= 皮肤真实感六层系统 + 视觉聚焦逻辑
- L5（景深镜头）= 摄影机参数后缀 + 光圈景深规则
- L6（整体质感）= Negative Prompt + film grain + 单帧叙事密度

完整模板和示例见 `references/ai-generation-guide.md` §2.1。

### AI视频生成技术参数规范

**摄影机机身+镜头参数后缀**：

AI视频/图像生成器对真实摄影机型号有训练数据偏好——指定具体机身+光圈能显著提升电影质感。以下后缀必须出现在每个视频提示词末尾：

```
Shot on Arri Alexa 65, T2.8, film grain, 4k, ultra photorealistic
```

**参数解析**：

| 参数 | 作用 | 为什么不能省略 |
|------|------|---------------|
| Shot on Arri Alexa 65 | 指定顶级电影摄影机机身 | AI会参考该机身的色彩科学和动态范围 |
| T2.8 | 光圈值，浅景深 | 电影感≠全清晰，T2.8提供自然浅景深 |
| film grain | 胶片颗粒 | 消除AI特有的"过度干净塑料感" |
| 4k | 分辨率 | 基础质量锚定 |
| ultra photorealistic | 写实声明 | 防止AI向动漫/插画偏移 |

**不同场景的光圈调整**：

| 场景类型 | 推荐光圈 | 景深效果 |
|----------|---------|---------|
| 对话/情绪特写 | T1.4–T2.0 | 极浅景深，背景虚化=焦外=世界消失 |
| 室内中景 | T2.8 | 标准电影浅景深 |
| 室外/动作全景 | T4.0–T5.6 | 中等景深，前后景可读但仍有分离 |
| 大远景/环境建立 | T8.0–T11 | 深景深，全景清晰 |

**宽高比规范**：

| 格式 | 宽高比 | 用途 | 提示词后缀 |
|------|--------|------|-----------|
| 电影宽银幕 | 2.39:1 | 长片电影/高级剧集 | `--ar 21:9` |
| 标准电影 | 16:9 | 常规影视剧 | `--ar 16:9` |
| 竖屏短剧 | 9:16 | AI短剧/竖屏内容 | `--ar 9:16` |
| 方形 | 1:1 | 社交媒体/特殊叙事 | `--ar 1:1` |

默认使用16:9，短剧场景使用9:16。宽高比影响构图逻辑——竖屏时垂直空间利用优先，横屏时水平纵深优先。

### Negative Prompt（负提示）规范

Negative Prompt告诉AI"不要生成什么"，是控制质量的关键手段。每个提示词必须包含对应的Negative Prompt。

**通用负提示库**：

| 类别 | 负提示词 | 防止的问题 |
|------|---------|-----------|
| 画质类 | `blurry, low quality, watermark, text, logo, signature` | AI随机添加的水印/文字/低质量区域 |
| 人体类 | `extra fingers, extra limbs, deformed hands, mutated, disfigured, bad anatomy` | AI生成的人体畸形（手指/四肢） |
| 面部类 | `dead eyes, crossed eyes, asymmetric face, plastic skin, doll-like` | 空洞眼神、不对称脸、塑料皮肤 |
| 光影类 | `flat lighting, overexposed, harsh flash, lens flare` | 大平光、过曝、硬闪光 |
| 风格类 | `cartoon, anime, illustration, painting, 3d render` | 非写实风格漂移 |

**场景专用负提示**：

| 场景类型 | 额外负提示 |
|----------|-----------|
| 室内对话 | `no windows showing exterior, no outdoor elements` |
| 夜景 | `daylight, sun, blue sky, bright ambient` |
| 动作戏 | `slow motion blur, frozen pose, static composition` |
| 暧昧/恋爱 | `explicit content, nudity, aggressive pose` |
| 面瘫角色 | `smile, raised eyebrows, open mouth, emotional outburst` |
| 多人场景 | `floating heads, overlapping bodies, merged figures` |

**使用方式**：在提示词末尾添加 `--no [负提示词列表]`（Seedance/Midjourney格式），或在单独的Negative Prompt字段中列出。

### 专业电影打光位置与视觉语言（Cinematic Lighting Positions Mastery）

**MANDATORY Photorealism & Anti-AI-Plastic Layer 核心组件**

AI生成的灯光最常见问题不是"不够亮"——而是"不知道光从哪来"。专业电影每个镜头都有明确的打光设计，光位本身即是叙事语言。从现在起，分镜提示词必须使用标准电影打光术语，结合其经典视觉语言与情绪效果。

**八大光位速查表**：

| 光位 | 英文术语 | 光源位置 | 视觉语言 | 情绪效果 | 经典参考 |
|------|---------|---------|---------|---------|---------|
| 前侧光 | Front-Side Light / Rembrandt Light | 前侧方45°，高于视线 | 结合顺光明亮+侧光立体感，面颊三角光斑 | 空间氛围营造、突出面部轮廓、坚毅智慧 | 《肖申克的救赎》 |
| 顶光 | Top Light | 正上方直射 | 眼窝深陷阴影、鼻梁下投暗影、面部上半亮下半暗 | 压抑、威慑、非自然、审判感 | 《教父1》《沉默的羔羊》 |
| 正侧光 | Side Light / Split Light | 正侧面90° | 面部明暗各半，强对比分割 | 立体质感、戏剧性、内心分裂、二元对立 | 《公民凯恩》 |
| 逆光/背光 | Backlight | 正后方 | 轮廓光边、正面暗部、剪影效果 | 神秘、孤独、超脱、希望、牺牲 | 《降临》《银翼杀手》《这个杀手不太冷》 |
| 蝴蝶光 | Butterfly Light / Paramount Light | 正上方高位，略前倾 | 鼻下对称蝴蝶形阴影、面部均匀亮、下颌线清晰 | 优雅高贵、仪式感、女神形象、经典好莱坞 | 《乱世佳人》 |
| 顺光 | Front Light / Flat Light | 与摄像机同方向 | 面部均匀受光、阴影极少、细节清晰 | 客观真实、明亮积极、纪录片感、无隐藏 | — |
| 底光 | Under Light / Horror Light | 下方向上投射 | 违反自然光规律、阴影翻转、面部扭曲感 | 恐怖、反派、精神扭曲、超自然威胁 | 《驱魔人》《闪灵》 |
| 侧逆光 | Rim Light / Kicker | 侧后方，约135° | 轮廓一侧光边、面暗侧微光、3D分离感 | 神秘层次、轮廓突出、动态分离、危险逼近 | 《这个杀手不太冷》《谍影重重》 |

**光位组合规则**：

电影打光极少使用单一光位——经典组合=主光+辅光+轮廓光（三点打光体系）：

| 组合 | 主光 | 辅光 | 轮廓光 | 情绪效果 | 适用场景 |
|------|------|------|--------|---------|---------|
| 经典前侧 | 前侧光 | 顺光（低强度） | 侧逆光 | 专业、稳重、可信赖 | 办公室对话、法庭、新闻 |
| 压迫审判 | 顶光 | 无/极弱 | 无 | 极度压抑、无处可逃 | 审讯、独裁者、末日 |
| 戏剧分裂 | 正侧光 | 无/极弱 | 侧逆光 | 内心撕裂、道德困境 | 道德选择、背叛揭露 |
| 希望剪影 | 逆光 | 极弱正面 | 主光即逆光 | 牺牲、超越、希望 | 告别、牺牲、黎明 |
| 优雅经典 | 蝴蝶光 | 低强度顺光 | 侧逆光 | 高贵、仪式、永恒 | 晚宴、婚礼、加冕 |
| 纪录真实 | 顺光 | 自然环境光 | 无 | 客观、无干预、真实 | 纪录片、日常、证词 |
| 恐怖威胁 | 底光 | 无/极弱 | 侧逆光 | 恐惧、扭曲、非人 | 恐怖片、噩梦、疯狂 |
| 危险逼近 | 侧逆光 | 极弱正面 | 主光即侧逆光 | 危险临近、不确定 | 追踪、潜行、对峙 |

**提示词写法规范**：

提示词中必须明确写出：**光位名称 + 视觉语言 + 情绪效果**。禁止使用模糊描述。

**写法模板**：
```
[LIGHTING] [主光位] as key light, [辅光位] as fill (intensity ratio [主:辅]), [轮廓光位] as rim,
[视觉语言描述], [情绪效果],
[cinematic reference: 《参考影片》style],
[natural/atmospheric additions: 体积光/尘粒/光束/窗户投影]
```

**完整示例**：

前侧光（肖申克式坚毅）：
```
[LIGHTING] front-side Rembrandt light as key (camera-left 45°, elevated), 
soft front fill at 1:3 ratio, subtle rim light from camera-right,
creating signature triangular cheek highlight, sculpting facial contours,
conveying determined resilience and quiet intellect,
cinematic reference: The Shawshank Redemption style,
atmospheric: dust motes in light beam, volumetric haze from window
```

顶光（教父式审判）：
```
[LIGHTING] overhead top light as sole source (directly above, harsh),
no fill, no rim,
eye socket shadows deepening, nose casting downward shadow, upper face lit lower face dark,
creating oppressive inquisitional weight, power bearing down from above,
cinematic reference: The Godfather interrogation style,
atmospheric: single overhead practical light, deep shadows swallowing details
```

逆光（银翼杀手式希望）：
```
[LIGHTING] strong backlight as key (directly behind character),
very weak front fill at 1:8 ratio, no rim (backlight IS rim),
silhouette edge glow, face in shadow, light bleeding around head and shoulders,
conveying mystery, solitude, and distant hope,
cinematic reference: Blade Runner 2049 silhouette style,
atmospheric: light shafts, fog scatter, lens flare from back source
```

侧逆光（谍影重重式危险）：
```
[LIGHTING] rim kicker as key (camera-right 135°, slightly elevated),
weak front fill at 1:4 ratio,
sharp edge light on one side of face, other side in shadow, 3D separation from background,
conveying imminent danger, uncertain threat lurking,
cinematic reference: The Bourne Identity chase style,
atmospheric: urban ambient, wet surface reflections, neon edge glow
```

**光位与已有规范的强制结合**：

- 与**导演风格圣经**：每位导演有偏好光位——维伦纽瓦=逆光+体积光，伯格曼=正侧光+高反差，斯皮尔伯格=逆光+蝴蝶光+体积光，诺兰=前侧光+冷灰自然光
- 与**色彩情绪圣经**：光位决定色温分布——顶光+冷蓝=压迫审判，逆光+暖橙=希望剪影，底光+绿色=超自然恐怖
- 与**皮肤六层**：不同光位下皮肤声明不同——前侧光=SSS最明显（鼻翼/耳廓透光），逆光=边缘光3D最关键（轮廓光边），顶光=色区差异最关键（上下半脸明暗分界）
- 与**视觉聚焦逻辑**：光位决定眼部高光——前侧光=单侧catchlight，蝴蝶光=对称双catchlight，顶光=眼窝全暗（必须声明`conscious intent behind shadowed eyes`）
- 与**面瘫美学**：面瘫+顶光=审判感（conscious+judged），面瘫+逆光=超脱感（conscious+transcendent），面瘫+正侧光=分裂感（conscious+divided）

### Lip Sync（口型同步）提示规范

角色有台词时，AI视频生成器需要口型同步指令：

**基础口型声明**：
```
, speaking with natural lip movements, mouth forming syllables matching dialogue rhythm,
jaw moving subtly as in real speech, no exaggerated mouth opening,
lips maintaining natural tension and shape throughout speech
```

**口型同步与情绪的结合**：
| 情绪 | 口型特征 | 提示词补充 |
|------|---------|-----------|
| 冷静陈述 | 下颌微动，嘴唇张幅小 | `minimal jaw movement, tight lip closure between syllables` |
| 愤怒质问 | 牙齿微露，下颌前推 | `teeth slightly visible between lips, jaw thrust forward 2mm, clipped syllables` |
| 低声威胁 | 几乎不动嘴唇，气声 | `barely perceptible lip movement, words forming with minimal mouth opening, jaw locked` |
| 伤心哽咽 | 嘴唇颤抖，间歇停顿 | `trembling lower lip, irregular breathing pauses between words, chin quivering` |

**口型同步的负提示**：
```
--no frozen mouth, no open mouth without speech, no exaggerated lip movements, no ventriloquist effect
```

### Motion Strength与Seed参数控制

**Motion Strength（运动幅度）**：

| 场景类型 | 推荐值 | 效果 |
|----------|--------|------|
| 静态抒情/面瘫 | 3-4 | 极微运动，呼吸感 |
| 对话场景 | 5-6 | 自然微动，头部轻微转动 |
| 暧昧/恋爱 | 6-7 | 肢体靠近/手部微动/呼吸加速 |
| 动作戏/打斗 | 8-9 | 大幅度运动，快速切换 |
| 追逐/失控 | 9-10 | 最大运动幅度 |

**Seed参数**：
- 同一角色/场景的连续镜头使用相同Seed值，确保视觉一致性
- 新场景/新角色使用新Seed
- 记录每个场景使用的Seed值，便于后续迭代

### 即时分镜工作流

当用户直接提供故事剧情、画面描述或短剧片段时，**无需追问细节，立即进入分镜产出模式**——这是效率原则。分镜大师的核心能力是将模糊或碎片化的描述转化为具有强视觉叙事性和节奏感的连续分镜序列。

**即时产出规则**：
1. 用户给故事→直接出分镜，不问"什么风格""什么焦距"
2. 根据故事内容自动推断风格、焦距、光影
3. 如果描述较长，合理拆分多场次，确保整体连贯
4. 推断内容用`[推断]`标注
5. 产出后用户可要求调整，但首次产出不阻塞

### 集尾悬念（Cliffhanger）规则

短剧/剧集的每一集结尾需要一个"钩子"——让观众必须点下一集。Cliffhanger不是简单的"未完待续"，而是精确的情绪中断：

**Cliffhanger四型**：

| 类型 | 机制 | 视觉实现 | 示例 |
|------|------|---------|------|
| 悬念型 | 关键信息即将揭晓但未揭晓 | 特写推向关键物体/文件/屏幕+画面切断 | 镜头推向合同签名处——切黑 |
| 反转型 | 刚建立的认知被一个画面打破 | 平静构图突然出现矛盾元素 | 温馨晚餐→窗外一双眼睛 |
| 选择型 | 角色面临必须选择的瞬间 | 两个方向/两个人的正反打+定格 | 手握两把钥匙，镜头不拍结果 |
| 暴露型 | 秘密即将被发现 | 危险逼近的倒计时感+慢推+呼吸声 | 脚步逼近，手电光扫过藏身处 |

**Cliffhanger的镜头节奏**：
- 倒数第2个镜头：建立紧张/期待（正常节奏）
- 最后1个镜头：情绪爆发点或信息揭示的**前0.5秒**切断——不是揭示本身，而是揭示之前的瞬间
- 运镜：最后1个镜头推荐slow dolly-in或slow push-in——观众被迫"凑近看"但被切断
- 声音：画面切断时保留一个未完成的声音（呼吸/脚步/门把手转动声）

**Cliffhanger与分镜的关系**：Cliffhanger规则不改变分镜的逐镜设计方法，而是在场次尾端增加一个"收尾策略"选择——是圆满收束还是悬念切断。短剧默认使用悬念型收尾。

### 单帧叙事密度规范

每个静止镜头（尤其是非动作场景）的每一像素都应服务于叙事——没有装饰，没有空洞。叙事密度是衡量一个镜头是否"值得存在"的核心标准。

**叙事密度三层检查**：

| 层级 | 定义 | 标准 |
|------|------|------|
| 焦点层 | 画面最清晰的区域（角色面部/手部/关键物体） | 每个可见细节必须有因果——碎发=风吹/奔跑，泥污=摔倒/挖掘，磨损=时间/阶层下坠 |
| 过渡层 | 焦点与虚化之间的空间（中景地面/家具/近景道具） | 每个元素至少承担1项叙事功能——树桩=砍伐=人的痕迹，地面泥泞=雨后=时间锚定 |
| 虚化层 | 景深之外的环境信息（远景/背景/天空） | 即使虚化也必须可读——牲畜虚化但可辨认为牧场=生活方式锚定 |

**零装饰原则**：画面中每个可见元素必须回答"它为什么在这里"。如果答案是"因为好看"或"因为常见"，它就是装饰——必须删除或赋予叙事功能。

**角色痕迹=视觉证据链**：角色身上的每个痕迹（脏污/磨损/碎发/褶皱/伤疤/补丁）都不是风格选择，而是故事证据：
- 泥污=她触摸过地面→摔倒/挖掘/爬行（不是"脏的风格"）
- 领口金边磨损=曾经体面但现在破旧=阶层下坠（不是"做旧质感"）
- 碎发贴脸=风吹/奔跑/无暇整理=紧迫感（不是"凌乱美"）
- 裙摆堆叠=面料重力的物理真实性（不是"自然褶皱"）
- 删除任何一条痕迹=删除一个故事信息

**色彩锚点策略**：在冷灰/低饱和基调中，用唯一暖色锚定视觉焦点——角色的核心服饰或道具承担"环境中唯一温度"的功能：
- 冷灰森林+酒红上衣=她是最重要的，目光自然聚焦
- 冷蓝雨夜+暖黄灯光=安全岛/希望/家
- 暗黑办公室+冷白屏幕光=科技/疏离/控制
- 多个暖色跳跃点=视觉焦点分散=弱（除非有意制造分散）

**环境叙事五层证据**（适用于非动作场景）：

| 证据层 | 问自己 | 示例 |
|--------|--------|------|
| 时间痕迹 | 这个空间经历了什么时间？ | 树桩=砍伐历史；磨损=使用历史；褪色=日晒历史 |
| 人的痕迹 | 谁在这里生活/经过？ | 牲畜=牧人；碎枝=采集；脚印=最近有人 |
| 经济痕迹 | 这里的生活水平如何？ | 粗布=非丝质=低阶层；树桩=获取资源=经济行为；补丁=节俭 |
| 气候痕迹 | 这里的生存条件如何？ | 泥泞=多雨；枯叶=深秋；雾气=潮湿；冰霜=极寒 |
| 威胁痕迹 | 这里的危险从哪来？ | 雾中未知方向=威胁不可预测；远处光源=可能有人=不确定安全 |

每个非动作场景的过渡层+虚化层至少覆盖3/5层证据。低于3层=环境变成"背景板"而非"叙事参与者"。

### 色彩叙事体系规范

色彩不是装饰——色彩是空间架构、情绪编程和叙事工具。以下规范基于电影级AI人像的色彩实践，将色彩选择从"好看"升级为"可执行"。

**规律1：色温=空间深度（Color Temperature = Spatial Depth）**

人眼将色温当深度线索——这不是审美偏好，是视觉生理。利用这个机制，用色温梯度构建空间纵深：

```
冷色(蓝灰/冷绿/阴影色) = 最远层——窗户/天空/阴影区/背景虚化
暖色(粉/棕/肤色/环境色) = 中间层——角色+角色周围环境
热色(金/黄/高光色) = 最近层——光源+高光点+焦点锚定物
```

| 空间层 | 色温范围 | 功能 | 错误做法 |
|--------|---------|------|---------|
| 远景层 | 6500-8000K冷蓝冷灰 | 后退=纵深感 | 远景用暖色=空间扁平化 |
| 中景层 | 3500-5000K暖粉暖棕 | 角色存在感=观众认同区 | 角色用冷色=与环境脱节 |
| 近景层 | 2500-3500K暖金黄光 | 光源锚定=视觉吸引力 | 无热色高光=画面缺乏焦点 |

**规律2：角色服装色=人-环境色桥（Character Fabric = Color Bridge）**

角色服装的颜色不是随意选择——它是连接人物肤色和环境色的桥梁：

```
皮肤(暖黄/暖粉) → 服装色(粉色/暖色系) → 环境色(粉紫/暖棕/花色)
```

- 如果角色穿冷色服装（如蓝色）在暖色环境中=色桥断裂=角色像贴上去的
- 如果角色穿暖色服装在暖色环境中=色桥连通=角色"属于"这个世界
- 色桥方向：皮肤色→服装色→环境色必须是渐变过渡，不可跳变

**色桥选色规则**：

| 环境主色 | 角色服装色桥 | 为什么 |
|----------|-------------|--------|
| 粉紫花海 | 浅粉/玫瑰粉 | 粉色桥接肤色与花色 |
| 冷蓝雨夜 | 冷灰蓝/深藏青 | 冷色桥接冷环境（此时角色应融入而非跳脱） |
| 暖金室内 | 暖棕/奶油白 | 暖色桥接室内光色 |
| 深绿森林 | 暗绿/橄榄绿 | 绿色桥接环境（隐蔽/融入叙事） |
| 全黑夜景 | 角色可以是唯一暖色 | 此时刻意跳脱=色彩锚点策略 |

**规律3：同色系层次=材质差而非色相差（Monochromatic Layering = Material, Not Hue）**

当角色和环境同色系时（如粉色人+粉色花），层次来自材质差异：

| 材质 | 同色呈现 | 视觉功能 |
|------|---------|---------|
| 缎面/丝绸 | 高光点+反射=最亮处 | 画面中的"热"点 |
| 棉麻 | 漫反射+肌理=中间调 | 温暖但不抢眼 |
| 花瓣 | 哑光+半透明=吸光面 | 柔和包围感 |
| 纱/薄纱 | 透光+叠色=最轻感 | 空气感/呼吸感 |
| 皮肤 | 次表面散射=独特光泽 | 生命感锚定 |

**提示词执行**：同色系场景必须在提示词中声明材质差异——"pink satin dress with glossy reflection" vs "pink flower petals matte surface" vs "pink cotton shirt with visible weave texture"。

**规律4：冷元素=呼吸孔（Cold Element = Breathing Hole）**

全暖画面会"窒息"——观众眼睛无处休息。在暖色主导的画面中保留5-10%冷色区域，功能不是"对比"而是"呼吸"：

| 冷元素面积 | 效果 | 适用 |
|-----------|------|------|
| 0%（全暖） | 窒息感/压迫感 | 刻意制造不适（如噩梦/密室） |
| 5-10% | 呼吸感/透气感 | 大部分暖调场景的推荐值 |
| 15-25% | 冷暖对峙/戏剧感 | 冷暖撞色策略（如冷窗+暖灯） |
| 30%+ | 冷暖双主导 | 不是呼吸而是叙事冲突 |

**冷元素的典型放置位置**：
- 背景窗户透出的蓝灰天光
- 角色影子中的冷蓝底色
- 环境中的绿叶/绿茎（暖粉画面中的冷绿）
- 远景雾气的冷灰色调

**规律5：光源色=调色板总开关（Light Source Color = Master Palette Switch）**

光源色决定整个画面的色彩温度——改光源色=改整个调色板。光源是色彩体系的"总开关"：

| 光源类型 | 光源色温 | 画面效果 | 情绪 |
|----------|---------|---------|------|
| 球灯/台灯 | 2500-3000K暖黄 | 局部暖+全局冷=戏剧感 | 孤独中的温暖/庇护所 |
| 逆光/轮廓光 | 3000-3500K暖金 | 全局暖+轮廓金边=神圣感 | 梦幻/圣洁/超脱 |
| 散射自然光 | 4000-5000K柔暖 | 均匀暖=安全感 | 温柔/治愈/日常 |
| 侧光 | 3000-4000K暖金 | 半明半暗=立体感 | 亲密/私语/秘密 |
| 冷色光源 | 6000-8000K冷蓝 | 全局冷=疏离感 | 科技/监视/恐惧 |

**光源色的叙事逻辑**：
- 暖光=安全/家/爱/记忆——观众本能向暖光靠拢
- 冷光=危险/外/未知/现实——观众本能警惕冷光空间
- 冷暖共存=矛盾/选择/冲突——观众的视觉在两种温度间拉扯

**色彩叙事六型调色板**：

| 类型 | 色彩结构 | 光源 | 冷呼吸孔 | 适用场景 |
|------|---------|------|---------|---------|
| 暖浸型 | 全暖单色系+材质差 | 暖金逆光/散射 | 绿叶/影子蓝5% | 梦幻/恋爱/治愈 |
| 冷暖撞色型 | 冷环境+暖光源+暖角色 | 暖黄点光(灯/火) | 蓝灰环境30%+ | 孤独/庇护/对比 |
| 暖调透气型 | 大面积暖+微量冷 | 暖金侧光 | 一小片蓝天/冷窗10% | 亲密/日常/温柔 |
| 温度梯度型 | 冷远景→暖中景→热近景 | 暖金侧逆光 | 远景冷雾15% | 史诗/叙事/纵深 |
| 三色三角型 | 互补三角(粉+黄+紫) | 暖金侧光 | 深紫(冷倾向)15% | 丰富/活力/产品 |
| 冷浸型 | 全冷色系+材质差 | 冷蓝/冷白 | 无(压迫)或暖光5% | 恐惧/疏离/未来 |

**与已有规范的衔接**：
- 与**色彩锚点策略**（叙事密度规范）：色彩锚点是六型调色板的执行细节——"唯一暖色锚定焦点"=冷暖撞色型/暖调透气型的核心策略
- 与**环境叙事五层证据**（叙事密度规范）：气候痕迹和威胁痕迹的色彩由调色板类型决定——暖浸型无威胁，冷浸型无安全
- 与**光影映射表**（恋爱规范）：恋爱五阶段焦距递进应配套色温递进——暧昧升温=光源色温从冷向暖递增
- 与**场景概念图提取规范**：概念图的主光色温=调色板总开关，必须在提取时确定

### 皮肤真实感六层系统

AI皮肤之所以"假"，不是因为不够光滑——而是因为太光滑。真皮肤是一套"活体光学系统"，6层同时运行。缺少任何一层都会触发观众的"蜡像感/假人感"直觉。

**第1层：次表面散射（Subsurface Scattering / SSS）**

皮肤不是表面反射材质——光线穿透表皮后在真皮层散射，从内部"亮起来"。这是真皮肤和硅胶最核心的区别：

| 现象 | 真皮肤(SSS) | AI皮肤(无SSS) |
|------|-----------|--------------|
| 颧骨高光 | 从内部柔柔亮起 | 表面白点镜面反射 |
| 鼻翼逆光 | 边缘透出暖橙红 | 灰色/黑色/无透光 |
| 耳廓逆光 | 整个耳廓变暖红 | 灰暗/无变化 |
| 指尖压光 | 指尖变红橙 | 无变化 |
| 额头侧光 | 边缘有暖色内发光 | 边缘冷色/灰色 |

**提示词声明**：必须写`realistic subsurface scattering, light penetrating skin from within, warm translucency at thin skin areas (nose edges, ear rims, fingertips), NOT surface reflection`

**第2层：微纹理地图（Micro-Texture Map）**

真皮肤不是均匀色块——它是一张由毛孔、细纹、绒毛、色素不均、微血管组成的"微纹理地图"：

| 微纹理 | 描述 | AI常见问题 |
|--------|------|-----------|
| 毛孔 | T区明显、面颊较细 | 完全无毛孔=塑料感 |
| 细纹 | 眼角/嘴角的极细纹路 | 完全光滑=蜡像感 |
| 绒毛 | 面颊/额头细小汗毛 | AI从不画=缺失生命细节 |
| 色素不均 | 雀斑/晒斑/色素沉着 | 均匀肤色=化装感 |
| 微血管 | 眼周/鼻翼的极淡红/蓝 | 完全无=塑料感 |
| 肤质差异 | 油区/干区/敏感区纹理不同 | 全脸同质=假 |

**关键原则**：微纹理不是"瑕疵"——微纹理是"活着的证据"。完美无瑕的皮肤=没有活着的证据=假。

**第3层：油汗层（Sebum-Sweat Film）**

皮肤表面始终有一层极薄的皮脂+汗液混合膜，造成特定区域的微妙光泽：

| 区域 | 油汗层表现 | 缺失后果 |
|------|-----------|---------|
| 鼻头 | 自然微光泽（不是油光） | 完全哑光=死物 |
| 额头 | 极微弱光泽带 | 哑光=硅胶 |
| 颧骨 | 干净无油（干区） | 全脸同光泽度=假 |
| 手指 | 自然微妙光泽 | 干涩=假手 |

**分寸**：油汗层是"感觉得到但看不太出来"的微妙光泽——太强=出油，完全没有=死物。

**第4层：色区差异（Chromatic Zonation）**

面部不同区域肤色不同——这不是化妆，是生理现实。AI最常犯的错是把全脸画成同一色：

| 区域 | 色相倾向 | 生理原因 |
|------|---------|---------|
| 额头 | 偏黄偏暗 | 角质层厚+紫外线积累 |
| 眼周 | 偏红偏暗/偏紫 | 微血管密集+皮肤极薄 |
| 鼻翼 | 偏红 | 血管+毛孔+油汗 |
| 脸颊 | 偏粉偏亮 | 血流+脂肪层=健康信号 |
| 嘴周 | 偏黄偏暗 | 口周色素+胡须区 |
| 下颌线 | 偏暗偏冷 | 皮肤厚度变化+阴影 |

**全脸同色=蜡像感的第一原因**。真人面部至少有3-4个色区差异，即使肉眼看不太出来，潜意识能感知。

**第5层：边缘光证实3D（Edge Light = 3D Proof）**

皮肤在光照下，3D形态的转折处会形成极细的光边——这不是装饰光，是"皮肤表面是3D曲面"的光学证据：

| 3D特征 | 边缘光位置 | AI常见问题 |
|--------|-----------|-----------|
| 鼻梁隆起 | 鼻梁两侧极细暖光带 | 无光边=鼻子是贴上去的 |
| 颧骨突出 | 颧骨下方极细过渡光 | 无过渡=颧骨不存在 |
| 下颌转折 | 下颌线极细光边 | 无光边=脸和脖子一体 |
| 眉骨突出 | 眉骨下方极微阴影 | 无阴影=额头是平面 |

**第6层：呼吸感微动态（Breathing Micro-Dynamics）**

仅视频场景适用。活人皮肤的微动态：

| 微动态 | 描述 | 视频中的表现 |
|--------|------|-------------|
| 油汗微光变 | 微汗引起的极微光泽波动 | 鼻头/额头光泽轻微闪烁 |
| 血流脉动 | 肤色极微脉动 | 肉眼不可见但整体"活"感 |
| 绒毛微动 | 面部细毛在微风中 | 边缘有极微运动 |
| 呼吸起伏 | 面部随呼吸微起伏 | 鼻翼/嘴唇极微张合 |

**静态图只需要1-5层。视频必须额外覆盖第6层。**

**皮肤六层与已有规范的衔接**：
- 与**视觉聚焦逻辑**：眼神真实感靠6个眼系统，皮肤真实感靠6层皮肤系统——两者共同构成"面部活体感"
- 与**角色描写精度**：维度2面部特征应包含皮肤质感声明（SSS+微纹理+色区差异）
- 与**三步表演法**：三步法的"微反应层"依赖皮肤微动态——无微动态=表演层缺失
- 与**色彩叙事**：色区差异是调色板在面部的微观体现——暖光下皮肤色区偏暖，冷光下偏冷
- 与**面瘫美学**：面瘫角色的皮肤真实感更关键——因为表情冻结后，观众全部注意力在皮肤质感上判断"真假"

### 导演风格圣经（Director Style Bible）

分镜不是中立工具——每一个镜头都带着导演的世界观。选择导演风格=选择视觉语言的"语法系统"。本规范收录12+位顶级导演的完整风格DNA，每套风格可直接调用为分镜的"视觉操作系统"。

**核心原则**：
- 导演风格不是"贴标签"——它是从构图逻辑、运镜哲学、光影策略到情绪节奏的完整语法

**导演风格混搭规则**：
- **主风格（70%）+ 辅助风格（30%）**：如"维伦纽瓦的主体压抑+伯格曼的面部特写"
- 不可超过2位辅助风格
- 混搭必须在视觉锚点阶段声明，写明"主风格X负责构图/运镜/光影，辅助风格Y负责[具体维度]"
- 混搭冲突规则：光影策略冲突时，以主风格为准；构图冲突时，按场景类型选择（对话场景偏辅风格，动作场景偏主风格）

**导演风格与已有规范的强制结合**：
- 与**人物圣经/角色锚点表**：风格选择不改变角色的物理特征锚点（体型/面部/服饰），只改变呈现方式（光影/构图/运镜）
- 与**色彩叙事**：导演风格的调色板与六型调色板对齐——诺兰=冷浸型，张艺谋=三色三角型，王家卫=暖浸型等
- 与**皮肤六层**：风格化不取消皮肤真实感——伯格曼的高反差更需要声明SSS和色区差异
- 与**视觉聚焦逻辑**：不同风格的"意识导向vs纹理导向"比例不同——伯格曼偏意识（85:15），维伦纽瓦偏纹理（40:60）
- 与**运镜五境**：每位导演的运镜偏好直接映射五境中的某一境——诺兰=凝视境，黑泽明=飞行境，王家卫=呼吸境等
- 与**面瘫美学**：面瘫风格因导演而异——诺兰面瘫=理性压抑（conscious+calculating），伯格曼面瘫=存在恐惧（conscious+terrified），小津面瘫=日常接受（conscious+accepting）

### 色彩情绪圣经（Color Palette Mastery）

色彩不是装饰——色彩是最原始的情绪语言，比台词更快、比运镜更直接。本规范将7种主色调独立模块化，每种色调包含情绪编码、电影案例、提示词关键词和组合规则，可直接在分镜中调用。

**核心原则**：
- 色彩=情绪的第一声部——观众在理解剧情之前已经"感受"了色彩
- 一部作品的**主色调不超过2种**，辅助色1-2种，点睛色1种
- 主色调决定全片情绪基调，不可中途更换主色调
- 色彩情绪与导演风格绑定——诺兰的蓝≠是枝裕和的蓝
- 色彩与色彩叙事体系（六型调色板）互为补充：六型管"结构"，情绪圣经管"语义"

| 导演映射 | 诺兰（冷灰蓝=理性压抑）、维伦纽瓦（科技蓝=存在孤独）、王家卫（深夜蓝=城市寂寞） |

#### 绿色（Green）—— 自然/诡异/超自然

| 维度 | 内容 |
|------|------|
| 情绪编码 | 自然生机、诡异不安、超自然/魔法、毒药/腐烂、丛林原始 |
| 电影案例 | 《黑客帝国》代码绿、《女巫》森林绿、《迷雾》诡异绿雾、《天使爱美丽》巴黎绿 |
| 构图逻辑 | 绿色光源=非自然/非正常→放在画面边缘/背景→暗示"有什么不对劲" |
| 提示词关键 | `eerie green luminescence, forest canopy dappled green, toxic neon green, natural mossy green, supernatural emerald glow, verdant mist` |
| 搭配色 | 绿+暖光=自然生机；绿+冷蓝=超自然恐怖；绿+红=毒药与鲜血；绿+黑=原始丛林恐惧 |
| 禁忌 | 荧光绿面部=外星人/尸体感→必须声明`natural skin with green ambient reflection, NOT green-tinted skin`；绿色是AI最容易失真的色相 |
| 导演映射 | 黑泽明（自然绿=命运）、奉俊昊（诡异绿=不安）、维伦纽瓦（荒原绿=空旷） |

#### 紫色（Purple）—— 梦幻/黄昏/不安

| 维度 | 内容 |
|------|------|
| 情绪编码 | 梦幻、黄昏过渡、不安、权力神秘、霓虹都市、精神迷幻 |
| 电影案例 | 《银翼杀手》紫霞天际、《黑天鹅》紫红蜕变、《迷魂记》紫红执念 |
| 构图逻辑 | 紫色=天际线过渡色→放在画面上方1/3→暗示"现实与梦境的边界" |
| 提示词关键 | `twilight purple sky, neon violet haze, deep amethyst shadows, dusky magenta gradient, otherworldly purple atmosphere, regal purple velvet` |
| 搭配色 | 紫+金=皇室权力；紫+青=赛博朋克；紫+暖橙=黄昏余晖；紫+黑=深渊神秘 |
| 禁忌 | 紫色+高饱和=廉价霓虹感→降饱和+加雾气=电影级紫色；紫色皮肤=缺氧/中毒→声明`purple ambient reflection on skin surface, NOT purple skin pigmentation` |
| 导演映射 | 王家卫（霓虹紫=都市迷离）、维伦纽瓦（黄昏紫=时空交界）、费里尼（梦幻紫=超现实） |

**色彩组合的三条铁律**：

1. **主色≤2 + 辅助色≤2 + 点睛色=1**：画面中同时出现的色调不超过5种，否则=调色板崩溃
2. **互补色=张力，相邻色=和谐**：橙蓝=经典对冲，红绿=暴力冲突，紫金=权力神秘——这些是经过百年验证的电影色彩语法
3. **暖色前进，冷色后退**：除非刻意反转（如冷前景+暖背景=疏离感），否则色温梯度必须遵循"冷远景→暖近景"

**色彩情绪与已有规范的衔接**：
- 与**色彩叙事体系（六型调色板）**：六型管"色温结构布局"，情绪圣经管"每种颜色的语义含义"——两者共同决定最终调色
- 与**导演风格圣经**：每种导演风格自带色彩偏好——选择导演风格时自动继承其色彩映射
- 与**皮肤六层**：面部色区差异必须在当前色彩情绪下声明——暖光下偏暖、冷光下偏冷，不可脱离环境光独立存在
- 与**单帧叙事密度**：色彩锚点策略中的"冷灰画面1个暖色锚定"=色彩情绪中"冷蓝+暖橙"的实例
- 与**视觉聚焦逻辑**：瞳孔颜色和虹膜纹理受环境色彩影响——蓝色场景中瞳孔反射蓝光，橙色场景中反射暖光

### 万能分镜模板（Universal Storyboard Patterns）

三类最常见的叙事段落——吵架、打斗、走路——各自有经过百年验证的景别逻辑。这些模板不是公式，而是节奏骨架：在此基础上可以变奏，但不可跳过基础逻辑直接自由发挥。

**核心原则**：
- 模板是"默认节奏"——用户未指定时自动套用，用户指定时以用户为准
- 每个模板都有"最短版"和"完整版"，根据段落重要性和时长选择
- 模板与已有规范强制结合：打斗模板必须叠加打斗叙事弧线+运镜美学，吵架模板必须叠加正反打多镜拆分，走路模板必须叠加单帧叙事密度

#### 吵架模板（Argue Pattern）

**情绪弧线**：克制→升级→爆发→崩溃→冷战收尾

**景别逻辑**：中→近→特→中→全

| 拍号 | 景别 | 情绪阶段 | 镜头任务 | 运镜建议 | 时长参考 |
|------|------|---------|---------|---------|---------|
| 1 | 中景 | 克制/试探 | 双人同框，空间尚有余裕 | 静止或极微推进 | 3-4秒 |
| 2 | 近景 | 升级/压迫 | 一方逼近，空间开始收缩 | 缓慢推至近景 | 3-4秒 |
| 3 | 特写 | 爆发/极点 | 最暴力的语言或最痛的沉默 | 急推或手持震颤 | 2-3秒 |
| 4 | 中景 | 崩溃/泄气 | 情绪着陆，身体语言从攻击变为退缩 | 缓慢拉出或横移 | 3-4秒 |
| 5 | 全景 | 冷战/距离 | 两人之间恢复物理距离，但关系已变 | 静止全景或缓慢推远 | 3-5秒 |

**最短版（3镜）**：中→特→全（跳过升级和崩溃，直接克制→爆发→收场）
**完整版（7-9镜）**：在每个阶段内用正反打拆分，景别逐步递进——中景A→中景B→近景A→近景B→特写A→特写B→中景退→全景收

**吵架模板与已有规范的强制叠加**：
- **正反打多镜拆分**：拍号2-3的升级/爆发阶段必须正反打拆分，每一"正"和每一"反"都是独立镜头
- **三步表演法**：每个镜头必须包含主表演+小动作+微反应三层（吵架时微反应层=被压抑的情绪泄露）
- **视觉聚焦逻辑**：爆发特写必须声明眼部4层微动画（微扫视+瞳孔呼吸+不规则眨眼+眼睑跟随）
- **色彩叙事**：吵架场景的光源色随情绪变化——克制=中性光，升级=暖化，爆发=过曝或阴影加重，冷战=冷调
- **皮肤六层**：吵架特写必须声明油汗层升级（额头/鼻头光泽随情绪增强）

#### 打斗模板（Fight Pattern）

**情绪弧线**：对峙→交锋→受挫→反杀→结果

**景别逻辑**：全→中→近→特→全

| 拍号 | 景别 | 情绪阶段 | 镜头任务 | 运镜建议 | 时长参考 |
|------|------|---------|---------|---------|---------|
| 1 | 全景 | 对峙/态势 | 双方位置关系、环境交代、力量对比 | 静止或缓慢环绕 | 3-4秒 |
| 2 | 中景 | 交锋/接触 | 第一个动作交换，速度感建立 | 临场感手持跟拍 | 2-3秒 |
| 3 | 近景 | 受挫/困境 | 一方受创，疼痛/震惊的即时反应 | 急推至近景+微晃 | 2-3秒 |
| 4 | 特写 | 反杀/转折 | 关键瞬间——反击的起始点 | 极端特写+慢速 | 1-2秒 |
| 5 | 全景 | 结果/余波 | 战斗结束的空间关系变化 | 缓慢拉出至全景 | 3-5秒 |

**最短版（5镜）**：即上表基础5拍
**完整版（9-12镜）**：叠加打斗叙事弧线（权力三次翻转），在3-4拍之间插入权力翻转的微观镜头

**打斗模板与已有规范的强制叠加**：
- **打斗叙事弧线（权力三次翻转）**：完整版必须在5拍基础上实现希望→绝望→爆发的权力翻转
- **运镜美学框架**：选择连绵美学/切割美学/融合美学，贯穿整段打斗不可中途切换
- **手持摄影三层**：对峙=呼吸感手持，交锋=临场感手持，受创瞬间=混乱感手持（≤5秒）
- **正反打多镜拆分**：交锋阶段的攻击→碰撞→反应必须三拍子结构，每拍独立镜头
- **即兴武器**：全景（拍1）中必须埋设环境武器的视觉伏笔
- **环境参与叙事**：打斗发生地的环境必须参与叙事而非仅作背景

#### 走路模板（Walk Pattern）

**情绪弧线**：氛围建立→行进节奏→情绪聚焦→情绪释放→收尾余韵

**景别逻辑**：远→中→近→特→远

| 拍号 | 景别 | 情绪阶段 | 镜头任务 | 运镜建议 | 时长参考 |
|------|------|---------|---------|---------|---------|
| 1 | 远景 | 氛围/环境 | 人在环境中的位置，整体氛围基调 | 静止远景或缓慢横移 | 3-5秒 |
| 2 | 中景 | 行进/节奏 | 步伐节奏、身体语言、与空间的互动 | 斯坦尼康跟拍或轨道横移 | 3-4秒 |
| 3 | 近景 | 情绪/聚焦 | 面部或手部近景，内心状态的视觉化 | 缓慢推近或手持跟拍 | 3-4秒 |
| 4 | 特写 | 极点/释放 | 最小景别——一个眼神、一只手、一片落叶 | 静止特写或极微晃动 | 2-3秒 |
| 5 | 远景 | 余韵/收尾 | 回到环境，但角色状态已改变 | 静止远景或缓慢拉远 | 3-5秒 |

**最短版（3镜）**：远→近→远（跳过行进和极点，只保留氛围→聚焦→收尾）
**完整版（7-9镜）**：在近景和特写阶段增加手部/脚步/背影等切入镜头，丰富情绪层次

**走路模板与已有规范的强制叠加**：
- **单帧叙事密度**：远景（拍1和5）必须覆盖环境五层证据中的至少3层
- **色彩叙事**：远景的色温梯度=空间深度；角色的服装色=色桥
- **静态抒情段落规范**：走路段落的远景和特写适用静态抒情规范——"静"中见"动"
- **视觉聚焦逻辑**：近景/特写阶段如有眼神镜头，必须声明眼部4层微动画
- **三步表演法**：走路时的主表演=行进，小动作=步伐变化/手部动作，微反应=面部情绪泄露

**万能模板的变奏原则**：
- **情绪变奏**：同一模板，不同情绪=不同执行——吵架模板用于分手vs吵架模板用于对峙，景别相同但光影/运镜/节奏完全不同
- **节奏变奏**：打乱拍号顺序=特殊叙事效果——如打斗模板从特写（反杀）开始再倒叙回全景（对峙）
- **混合变奏**：两种模板拼接——走路转入打斗（远→中→近→全→中→近→特→全），吵架转入走路（中→近→特→中→远→中→近→远）

## 角色设定板双版本生成规范

### 核心工作流：单人图→设定板

角色设定板的生成必须遵循**两步法**，不可一步到位：

```
步骤1: 生成单人角色图（纯色背景，角色全身正面/四分之三视角）
步骤2: 以步骤1的角色图为参考，生成模块化设定板
```

**为什么不能一步到位？**
- 设定板包含9+模块（多角度/表情/动态/细节/文字），直接一步生成时AI需要同时处理角色一致性+模块布局+文字标注+细节拆解，信息过载导致：角色走形、模块缺失、布局混乱
- 先锁定一个高质量单人图作为"视觉种子"，再让AI基于这个种子展开设定板，一致性大幅提升

**步骤1：单人角色图的提示词要点**：
- 背景：`pure solid color background, [dark/black OR light/neutral]`——纯色背景，无环境无道具
- 视角：`front three-quarter view, full body standing`——四分之三全身正面
- 结尾强制：`no text, no watermark, no extra figures, character design sheet pose`
- 角色描写必须经过六维拆解法精修，禁止抽象词

**步骤2：设定板生成的提示词要点**：
- 背景：`PURE WHITE background, absolutely no beige no gray no grid lines, clean white (#FFFFFF) throughout`——纯白背景，严禁米黄/灰网格
- 布局：`modular grid layout with thin black border lines separating each module`
- 参考图：将步骤1的单人图作为ref_images传入，增强角色一致性
- **超时处理**：如果带参考图超时（设定板复杂度高），去掉参考图用纯文字提示词生成，在提示词中精确描述步骤1的角色外貌特征以替代参考图

### 六维角色锚点表（跨镜头一致性硬参照）

每个核心角色在锚点表之外，必须建立一份**六维锚点表**，作为分镜提示词的速查卡和设定板的文字ID块来源：

```
角色：[角色名]
├── 面部骨架：[脸型+颧骨+下颌线+眉骨]（如"窄长脸型、高颧骨、锐利下颌角、眉骨微突"）
├── 眼部系统：[虹膜色+眼型+瞳孔常态+眼眶情绪标志]（如"深色虹膜、眼尾微上挑、瞳孔常收缩(警惕态)、眼眶泛红但泪不落"）
├── 表情基态：[嘴部常态+下颌习惯+鼻翼状态]（如"唇紧抿→咬牙、下颌肌肉绷紧、鼻翼微张(压抑呼吸)"）
├── 体态惯性：[肩部+重心+手部习惯位]（如"肩膀内收但不塌(少年倔强)、重心偏前(随时要跑/要打)、左手永远在刀柄附近"）
├── 服饰7要素：[外层/内层/披风/肩甲/腰带/配饰/战损状态]（如"黑色轻甲(破损)/暗纹蟒袍(内层)/深灰残破披风(单肩)/皮质肩甲(磨损)/黑腰带(金属纹)/绷带(左手)/血污(袖口+衣摆)"）
└── 表演签名：[3-4个角色独有的标志性动作]（如"捂嘴压哭声/回头看战场时目眦欲裂/跌撞逃亡时刀不松手"）
```

**六维锚点表与已有规范的关系**：
- 六维锚点表 = 角色描写精度规范（六维拆解法）的**精炼输出格式**——经过五步法精修后的最终落点
- 六维锚点表 > 角色锚点表（传统格式）：传统锚点表是线性列表，六维锚点表是**维度化矩阵**，每个维度独立校验，跨维度矛盾更容易被发现
- 设定板底部ID块的CORE MOOD和VISUAL SIGNS = 六维锚点表中"表情基态"+"表演签名"的摘要

### 设定板模块覆盖检查清单

| 模块 | 必需内容 | 常见遗漏 |
|------|---------|---------|
| 中心全身正面 | 完整站立，手部可见，无遮挡 | 手被遮挡/握拳无道具 |
| 背面全身 | 披风/后背完整破损细节 | 披风细节丢失 |
| 侧面全身 | 肩甲弧度+身形线条 | 侧面变胖/变瘦 |
| 剪影 | 2-3个黑色正负形剪影 | 完全跳过 |
| 动态姿势 | 坐姿+2个蹲姿 | 只画1个动态 |
| 五表情头 | 角色实际出现的5种情绪 | 全是同表情微调 |
| 仰俯视轮廓 | 低角度+高角度全身 | 跳过 |
| 细节研究 | 眼部特写+肩甲纹理+面部多角度 | 用装饰元素替代 |
| 文字标注 | NAME/ROLE/CORE MOOD/VISUAL SIGNS | 文字模糊/缺失 |

## 镜头时长估算与景别自动推断规范

### 镜头时长估算公式

每个镜头的时长不是凭感觉定的——有公式可循。时长决定剪辑节奏，节奏决定叙事张力。

**基础公式**：
```
镜头时长(秒) = max(基础阅读时间, 动作执行时间, 情绪着陆时间)
```

**三项时间的计算规则**：

| 时间类型 | 计算方法 | 适用场景 |
|----------|---------|---------|
| 基础阅读时间 | 对白字数÷3字/秒（中文）或 词数÷2.5词/秒（英文），取2秒下限 | 有对白的镜头 |
| 动作执行时间 | 按动作复杂度：简单动作2-3秒、中等动作3-5秒、复杂动作5-8秒、战斗序列按8镜/4秒拆分 | 有动作描写的镜头 |
| 情绪着陆时间 | 特写/极特写+2秒，中景+1秒，全景+0秒。面瘫美学+3秒 | 有情绪转折的镜头 |

**景别与时长基准表**：

| 景别 | 基准时长 | 变幅 | 说明 |
|------|---------|------|------|
| 大远景(EWS) | 4-6秒 | +2/-1 | 空间信息量大，需给观众定位时间 |
| 全景(WS) | 3-5秒 | +2/-1 | 定场镜头，展示空间关系 |
| 中景(MS) | 3-4秒 | +1/-1 | 主叙事景别，最灵活 |
| 近景(MCU) | 2-4秒 | +2/-1 | 情绪聚焦，着陆时间可大幅延长 |
| 特写(CU) | 2-3秒 | +3/-0.5 | 最小景别但情绪极点可拉到5秒+ |
| 极特写(ECU) | 1-3秒 | +2/-0.5 | 单一信息点，快速切过或极端停留 |

**时长修正因子**：

| 修正项 | 调整 | 触发条件 |
|--------|------|---------|
| 对白延长 | +对白时长 | 有台词时取max(基准,对白) |
| 慢动作 | ×1.5-2.0 | 剧本明确标注"慢镜"/"时间凝固" |
| 蒙太奇快切 | ×0.5 | 连续快切序列中 |
| 长镜头 | ×2-3 | 剧本标注长镜头/一镜到底 |
| 沉默/留白 | +2-4秒 | 剧本有"沉默""静默""无语" |
| 音乐驱动 | 按节拍 | 剧本标注音乐/歌曲时按乐句 |

### 景别自动推断规则

从剧本文字描述自动推断最合适的景别，遵循"信息密度→景别"映射：

| 剧本描述特征 | 推断景别 | 逻辑依据 |
|-------------|---------|---------|
| 角色首次出现/新场景建立 | WS→MS | 先定场再进入 |
| 角色说出关键台词 | MCU→CU | 情绪聚焦，观众需要看到嘴和眼睛 |
| "他看着..."/"她盯着..." | CU | 视觉聚焦逻辑——眼睛是镜头 |
| 动作描写（走/跑/打） | MS→WS | 需要看到身体动态 |
| 细节描写（手/物品/伤口） | CU→ECU | 单一信息点极放大 |
| 群戏/多角色同框 | WS→MS | 空间关系优先 |
| 情绪转折点（震惊/落泪/微笑） | MCU→CU | 面部情绪需近距离 |
| 环境描写占主体 | EWS→WS | 空间氛围大于人物 |
| 对白密集段落 | MS↔MCU正反打 | 对话场景的标准节奏 |
| 内心独白/旁白 | MCU→CU | 声画关系：声音在脑内，画面在脸上 |
| 转场/闪回 | EWS→CU | 跳切：从大环境突然落到细节 |

**推断冲突解决**：当多个特征同时出现时——
- 动作+对白：对白优先（声音主导景别，动作主导运镜）
- 环境+情绪：情绪优先（人物永远大于环境，除非环境本身是叙事主体）
- 群戏+关键角色：先WS群像→MCU关键角色（两镜拆分）

### 生产级表格式分镜输出格式

每个分镜输出的标准字段结构：

```
| 场次 | 镜号 | 集号 | 场景/地点 | 时段 | 景别 | 镜头运动 | 画面/动作描述 | 对白 | 时长(秒) | AI提示词摘要 |
```

**各字段填写规范**：

| 字段 | 格式 | 示例 |
|------|------|------|
| 场次 | S01-S99，按剧本场景顺序 | S01 |
| 镜号 | 场次内连续编号 | S01-01, S01-02 |
| 集号 | EP01-EP99 | EP01 |
| 场景/地点 | INT/EXT + 具体位置 | INT. 皇宫大殿 - 夜 |
| 时段 | DAY/NIGHT/DAWN/DUSK/FLASHBACK/CONTINUOUS | NIGHT |
| 景别 | EWS/WS/MS/MCU/CU/ECU | MCU |
| 镜头运动 | 推镜/拉镜/横移/跟拍/环绕/升降/固定/手持 | 缓慢推镜 |
| 画面/动作描述 | 逐镜动作+构图+光影 | 三皇子握刀立于残墙下，前侧光切割面部 |
| 对白 | 角色(情绪): 台词 | 厉淮胤(压抑): 我记住了 |
| 时长(秒) | 按公式计算 | 3.5 |
| AI提示词摘要 | 锚定段关键词+变化段 | 厉淮胤/黑甲/握刀/前侧光/压抑 |

**表格与叙述式的配合**：
- 表格式=生产执行清单，导演/摄影/美术直接使用
- 叙述式=创作思考过程，含推理链和美学决策
- 两者必须同时输出，先叙述式（思考过程）后表格式（执行清单）

### 长剧本批量处理流水线

当剧本超过20场/5集时，必须使用批处理流水线，不可一次性全部处理：

```
Phase 0: 剧本摄入与结构解析
  → 提取场次列表（INT/EXT标注完整）
  → 建立场景索引（地点→场次映射）
  → 建立角色出场索引（角色→场次映射）

Phase 1: 视觉资产批量提取
  → 按角色出场索引批量提取角色描写
  → 按场景索引批量提取场景描写
  → 批量生成六维锚点表（所有角色）
  → 批量生成场景锚点表（所有场景）

Phase 2: 逐场分镜生成
  → 按Phase 0的场次顺序逐场处理
  → 每场独立输出叙述式+表格式分镜
  → 跨场引用锚点表确保一致性

Phase 3: 全片一致性校验
  → 角色锚点跨场校验（服化道变化链）
  → 场景锚点跨场校验（光影/色调连续性）
  → 对白覆盖率校验（Full Script Fidelity）

Phase 4: 合并与交付
  → 合并所有场次的表格式分镜为统一Excel/HTML
  → 生成交互式分镜文档（搜索/筛选/打印）
  → 输出完整性声明
```

**批处理的内存管理**：
- 单次处理不超过10场——超出时分割为批次
- 每批次处理完后输出中间产物，避免上下文溢出
- 批次间共享锚点表（Phase 1只做一次），分镜按批次推进

## 工业级道具设计规范（道具美术总监视角）

### 三步道具设计工作流

道具不是背景装饰——它是叙事的物理证据。从剧本提取到AI生成，必须经过三步：

```
Step 1: 剧本分析与材质介质拆解 → 提取核心道具+物理属性表
Step 2: 生成工业级道具设计图提示词 → Split View布局+材质物理控制词
Step 3: 质量检查 → 三条铁律校验
```

### Step 1：材质介质拆解表

每个核心道具必须填写：

| 道具名称 | 剧本描写与功能说明 | 核心材质属性 | 物理光学特征 |
|----------|-------------------|-------------|-------------|
| [短名] | [剧本原文描写+叙事功能] | [如：古董青铜/老旧木质/原石/通透玉石] | [如：非均匀钝光/次表面散射/深层裂纹] |

### Step 2：工业级道具设计图（Split View布局）

**布局规范**：
- **左侧**：组装完成全景——带物理重力阴影、不规则磨损、环境光遮蔽(AO)接地
- **右侧**：结构拆解图——带技术标注线(cm/mm)、零件分离展示、组装逻辑
- **底部**：5色专属色卡条——从道具实物提取的5个核心配色
- **画幅**：16:9

**材质物理控制词速查表**（6大类）：

| 材质类别 | 物理控制词（提示词中精确咬合） |
|----------|-------------------------------|
| 古董金属 | patinated bronze, weathered forged iron, realistic verdigris oxidation, micro-pitting on metallic surface, dull metallic luster, non-uniform specularity, embedded grime in crevices |
| 老旧木质 | aged wood grain with deep tactile fissures, weathered timber texture, splintered edges, matte finish with organic oils, rich micro-crevices |
| 粗糙石质 | raw unpolished stone, visible mineral streaks, realistic sediment accumulation, chipped edges, gritty chalky texture, uneven light absorption |
| 通透玉石/玻璃 | internal inclusions and subtle fractures, cloudy turbidity, subsurface scattering (SSS), realistic light refraction, dust/condensation on surface |
| 骨/象牙/角 | organic bone density variations, yellowed patina, microscopic porosity, warm translucency at thin edges, hairline age cracks |
| 织物/皮革 | visible thread weave pattern, worn leather grain, stitching irregularities, color fading at stress points, frayed edges, oil-darkened palm area |

### 道具设计三条铁律

1. **🚫 消除塑料感**：严禁均匀反光、现代打磨、CGI游戏建模感。提示词尾部必须带防塑料反向控制块
2. **🔬 微观痕迹具象化**：缝隙积垢(grime in crevices)、不对称磨损(asymmetrical wear)、表面微孔(micro-pitting)必须根据材质精准咬合
3. **📐 物理重力接地**：道具必须有自然接地阴影+环境光遮蔽(AO)，严禁悬浮/零重力放置

### 道具四视角输出

每个核心道具生成4个视角的提示词：

| 视角 | 内容 | 用途 |
|------|------|------|
| 全景(Assembly) | 组装完成+重力阴影+环境 | 分镜中道具的默认参考 |
| 拆解(Deconstructed) | 结构分解+标注线+零件 | 美术组/置景组定型参考 |
| 色卡(Color Card) | 5色色卡条 | 跨镜头色彩一致性锁定 |
| 微距(Macro) | 材质纹理超特写 | 提示词中材质声明的视觉验证 |

### 防塑料反向控制块（每条道具提示词必须携带）

```
--no plastic look, rubbery surface, synthetic gloss, uniform shading, pristine surface, flawless texture, CGI render, video game asset, flat texture map, uniform reflection, floating object, zero-gravity placement, perfectly symmetrical wear
```

### 道具设计与已有规范的强制叠加

| 已有规范 | 道具设计中的体现 |
|----------|----------------|
| 活道具vs死道具 | 道具设计图左侧必须声明光线交互——"死道具"无光线反应，"活道具"有SSS/反射/阴影互动 |
| 道具精度拆解模板 | Step 1的材质表=精度拆解的输入源 |
| 生产级首帧6层标准 | 道具微距视角必须L3-L6全覆盖（光源氛围+皮肤/材质面部+景深镜头+整体质感） |
| 色彩叙事体系 | 道具5色色卡必须纳入场景调色板，不可与场景色冲突 |
| 单帧叙事密度 | 道具的"零装饰原则"——画面中每个可见道具必须能回答"它为什么在这里" |
| 视觉聚焦逻辑 | 道具特写时如有角色手部出现，必须声明手部与道具的触觉关系（握持/轻触/悬停） |

## AI视频生成工作流规范（故事板→视频桥梁）

### 核心原则：故事板→视频的提示词逻辑

故事板是"画面定义"，视频提示词是"运动指令"——两者职责完全不同：

| 维度 | 故事板提示词（给图像AI） | 视频提示词（给视频AI） |
|------|------------------------|---------------------|
| 核心职责 | 定义"画面长什么样" | 定义"画面怎么动" |
| 描述重点 | 构图/光影/材质/表情/色彩 | 运镜/动作/情绪递进/时间节奏 |
| 禁止项 | 不写运镜/不写时间 | 不写构图/不写材质细节（已在故事板中） |
| 信息来源 | 剧本+锚点表 | 故事板+时间轴 |

**铁律：视频提示词只描述"运动"，不描述"画面"**——画面信息已经在故事板中，视频AI可以识别故事板的完整规划，只需告知角色和镜头怎么动。

### 时间戳精确控制法

视频提示词必须按时间分段描述运镜，而非笼统描述"缓慢推进"：

```
格式：[时间戳]：[景别+运镜方式]，[角色动作]，[运镜动机]

示例：
0-2秒：远景缓慢推进，跟随女主背影，风雪中有轻微手持抖动
2-4秒：切中近景，镜头轻摇向上，跟随女主抬头动作，寒风吹起编发
4-7秒：大全景，快速跟拍恶龙俯冲轨迹，女主翻滚闪避，镜头跟随翻滚动作
7-10秒：低角度手持跟跑，跟随女主起身冲锋，战斧燃起蓝光
10-15秒：慢动作，镜头环绕女主180度，定格在斧刃劈下瞬间
```

**时间戳分配原则**：
- 关键镜头给足时间（情绪转折/动作高潮 = 总时长的40-50%）
- 过渡镜头压缩时间（1-2秒快速过渡）
- 总时长 = 各段时间之和 = 目标时长
- 视频AI会根据时间戳分配渲染资源——精确时间戳=精确节奏

### 动机驱动运镜（Motivated Camera Movement）

**每一个镜头运动，都必须有场景内的动机**。没有动机的运镜=技术炫技=观众出戏。

| 运镜方式 | ❌错误示范（无动机） | ✅正确示范（有动机） |
|---------|-------------------|-------------------|
| 横移 | "镜头从左向右平移，展示战场全景" | "女主战斧从左侧挥入，镜头跟随斧刃轨迹右移，自然reveal远处恶龙" |
| 推进 | "镜头缓慢推向角色面部" | "角色听到脚步声，镜头跟随她警觉的视线向前推进" |
| 环绕 | "镜头环绕角色一周" | "角色在战斗中旋转挥刀，镜头跟随刀锋弧线环绕" |
| 升降 | "镜头从地面升高俯瞰" | "角色被击倒，镜头随她倒下的视线升高，从仰视变为俯视" |
| 手持 | "手持晃动增加动感" | "角色在爆炸中失去平衡，手持晃动模拟她眩晕的主观视角" |

**运镜动机的四类来源**：
1. **角色动作驱动**：角色动→镜头跟（最自然）
2. **角色视线驱动**：角色看→镜头指向（视觉聚焦逻辑）
3. **环境事件驱动**：爆炸/风吹/物体移动→镜头反应
4. **情绪节奏驱动**：情绪升级→镜头加速/靠近；情绪释放→镜头减速/远离

### 角色锁定三重保险

跨视频的角色一致性需要三重保障：

```
第一重：角色设定表（Character Sheet）
  → GPTimage2/Midjourney生成，含多角度/表情/服装/道具
  → 锁定角色的"标准态"

第二重：故事板内一致性（In-Storyboard Consistency）
  → 故事板生成时声明"所有分镜必须是同一画风、同一色调、同一角色"
  → 8个分镜内的角色必须互相一致

第三重：视频AI多图参考（Multi-Image Reference）
  → 将角色设定表+故事板同时导入视频AI（如Seedance2.0的参考图功能）
  → 视频AI同时读取"角色长什么样"+"在故事中怎么动"
```

**三重保险的校验顺序**：
- 先检查第一重：设定表本身是否一致（不同角度是否同一人）
- 再检查第二重：故事板8镜是否与设定表一致
- 最后检查第三重：视频输出是否与故事板一致

### 故事板五大模块格式

完整故事板应包含5大模块，每个模块有固定格式要求：

| 模块 | 内容 | 格式要求 |
|------|------|---------|
| ①顶部栏 | 项目名/集号/场景/时间/风格标签 | 横幅条，固定在顶部 |
| ②角色与风格参考 | 角色多角度参考+5-8色色卡+风格约束 | 缩略图+色卡条，左上区域 |
| ③服装与配饰 | 服装材质特写+道具参考+变化说明 | 中部独立区域 |
| ④环境与场景设计 | 场景俯视示意图+摄像机位置+拍摄类型标注+移动路径 | 中部独立区域，含箭头标注 |
| ⑤故事板分镜 | 8个编号帧，每帧含：景别/运镜/动作/情绪/灯光备注 | 底部主区域，编号连续 |

**故事板提示词中的强制声明**（防AI自由发挥）：
- "所有分镜必须是同一画风、同一色调、同一角色"
- "角色外貌、服装、武器必须与参考图完全一致"
- "信息栏文字清晰可读"

### 避坑清单（GPTimage2 + Seedance2.0双阶段）

**GPTimage2阶段**（图像/故事板生成）：

| 坑 | 表现 | 解决方案 |
|----|------|---------|
| 中文乱码 | 故事板里中文变鬼画符 | 开启Thinking模式；如还乱，中文部分单独迭代修改 |
| 风格不一致 | 8个镜头画风都不一样 | 提示词加"所有分镜必须是同一画风、同一色调、同一角色" |
| 角色崩了 | 某分镜角色脸歪/衣服变 | 上传角色设定表作为参考；或单独重新生成该分镜 |
| 构图失衡 | 某分镜元素太多太乱 | 简化该分镜画面描述，突出1-2个核心元素 |
| 文字太小 | 信息栏文字看不清 | 提示词加"信息栏文字清晰可读"，用更大字号声明 |

**Seedance2.0阶段**（视频生成）：

| 坑 | 表现 | 解决方案 |
|----|------|---------|
| 第一帧显示故事板 | 视频开头1-2秒是故事板原图 | 首帧提示词明确描述画面内容，而非"根据故事板" |
| 镜头乱切 | 运镜没有逻辑，胡乱切换 | 声明"一镜到底"+每个运镜标注动机 |
| 角色变形 | 视频中角色面部/身体走样 | 上传角色设定表作为多图参考 |
| 动作不自然 | 动作僵硬/无过渡 | 提示词加"动作自然，有微表情和呼吸感" |
| 时长不符 | 生成视频短于/长于预期 | 时间戳精确分配，总和=目标时长 |
| 风格漂移 | 视频后半段色调/风格变化 | 提示词加"全程风格统一，与故事板一致" |

### 迭代工作流（AI的优势是快，不是一次完美）

```
Round 1: 快速生成初版（不要追求完美，先看整体方向）
Round 2: 针对性修改（基于初版问题点精准调整提示词）
Round 3: 再次生成（验证修改效果）
Round 4-5: 微调打磨（细节优化：光影/表情/运镜节奏）

关键心态：3-5轮迭代 > 1轮完美主义
```

**多版本A/B测试**：
- 同一创意生成不同风格的故事板
- 对比视觉冲击力与稳定性
- 选出最优版本后再进入视频生成

### 情感短剧8镜故事板模板

情感类场景（分手/告白/对峙）的8镜标准结构：

```
镜头1：双人全景，距离=关系状态（物理距离=心理距离）
镜头2：A方特写，情绪初现（微表情捕捉）
镜头3：B方中景，回应/回避（动作+眼神方向）
镜头4：A方近景，情绪升级（从微表情到明显情绪）
镜头5：B方手部/微动作特写（内心克制的物理证据）
镜头6：B方近景，松动/决绝（微妙的情绪变化）
镜头7：A方特写，崩溃/妥协（情绪极点）
镜头8：双人全景，距离拉开，氛围定调（首尾呼应）
```

**情感8镜与已有规范的叠加**：
- 镜头1和8适用**万能分镜模板（吵架模板）**的首尾全景逻辑
- 镜头2/4/7适用**视觉聚焦逻辑**——眼神是情绪的主通道
- 镜头5适用**三步表演法**——手部微动作=小动作层
- 镜头6适用**暧昧/亲密戏规范**——"差一点"原则，未完成动作>已完成动作
- 全程适用**面瘫美学**——如果角色是克制型，微反应层禁用，只走主表演+小动作

## AIGC结构化提示词四步黄金框架

### 核心公式：提示词=定镜头+构图语言+光影色彩+质感

写提示词需像搭积木一样，四个维度组合成完整的"拍摄指令"。这不是灵感写作，而是工程化搭建——每个模块有固定功能，缺一不可。

### 第一步：定镜头（定义"怎么拍"）

镜头参数是提示词的地基——先确定观众从什么位置、用什么方式看这个画面：

| 参数 | 选项 | 提示词写法 |
|------|------|-----------|
| 景别 | 大远景→远景→全景→中景→近景→特写→极特写 | EWS/WS/FS/MS/MCU/CU/ECU |
| 角度 | 平视/仰拍/俯拍/顶拍/鸟瞰/主观/过肩/侧面 | eye-level / low angle / high angle / top-down / bird's-eye / POV / OTS / profile |
| 焦段 | 超广角/广角/标准/中焦/长焦/超长焦 | 14-24mm / 24-35mm / 50mm / 85mm / 135mm / 200mm |
| 景深 | 浅景深/深景深/焦点转移 | shallow DoF / deep focus / rack focus |

**景别→叙事功能映射**：
- 大远景(EWS)：环境叙事，人物渺小，自然/城市的力量感
- 全景(FS)：人物与环境的关系，定场镜头
- 中景(MS)：主叙事景别，动作+环境平衡
- 近景(MCU)：情绪聚焦，面部表情开始主导
- 特写(CU)：情绪极点，只看脸/手/关键物品
- 极特写(ECU)：单一信息点放大，微表情/纹理/细节

**角度→心理效果映射**：
- 仰拍(low angle)：力量/威慑/崇敬
- 俯拍(high angle)：弱小/无助/审视
- 倾斜(Dutch angle)：不安/紧张/失衡
- 主观(POV)：沉浸/第一人称/恐怖

### 第二步：构图语言（定义"画面怎么组织"）

**三层纵深构图法**——专业影视提示词的构图核心：

```
前景(Foreground)：遮挡物/框架元素/虚化层 → 制造景深和窥视感
中景(Midground)：主体/核心叙事元素 → 观众视线焦点
远景(Background)：环境/氛围/空间 → 定义世界感
```

**提示词写法**：
- 前景声明：`foreground: [具体元素], out of focus`
- 中景声明：`midground: [主体+动作], sharp focus`
- 远景声明：`background: [环境描述], soft blur`

**经典构图模式**：

| 构图 | 提示词 | 效果 |
|------|--------|------|
| 三分法 | rule of thirds composition | 平衡、自然 |
| 中心构图 | center-framed, symmetrical | 正式、庄严、仪式感 |
| 框架构图 | framed by [门框/窗框/树枝] | 窥视、被困、叙事纵深 |
| 引导线 | leading lines from [道路/河流/走廊] | 纵深感、引导视线 |
| 负空间 | vast negative space, subject small | 孤独、渺小、留白美学 |
| 对角线 | diagonal composition | 动态、紧张、不稳定 |

### 第三步：光影与色彩（定义"情绪密码"）

光影与色彩的对撞制造故事感——不是"好看"，而是"有情绪"。

**光影关键词库**：

| 光影类型 | 英文 | 视觉效果/情绪 |
|---------|------|-------------|
| 黄金时段 | Golden hour | 暖橙、长阴影、浪漫/怀旧 |
| 蓝色时刻 | Blue hour | 冷蓝、忧郁、疏离 |
| 逆光 | Backlit | 边缘发光、剪影、神秘/分离 |
| 侧光 | Side light | 半明半暗、戏剧性、对立 |
| 伦勃朗光 | Rembrandt lighting | 阴影侧三角亮区、经典肖像 |
| 体积光 | Volumetric light | 可见光束、圣洁/超自然 |
| 丁达尔效应 | Tyndall effect | 微粒散射光束、氛围感 |
| 霓虹光 | Neon light | 彩色反射、赛博朋克/都市夜 |

**色彩情绪速查**（与色彩情绪圣经对齐）：

| 主色 | 情绪 | 典型参考 |
|------|------|---------|
| 橙 | 温暖/危险/激情 | 盗梦空间落日 |
| 蓝 | 冷峻/孤独/科技 | 银翼杀手 |
| 红 | 暴力/激情/权力 | 小丑红幕 |
| 绿 | 自然/诡异/超自然 | 森林魔法 |
| 黄 | 怀旧/温暖/神秘 | 日式和室 |
| 紫 | 梦幻/黄昏/不安 | 霓虹都市 |

**光影对撞原则**：
- 冷暖对撞：冷蓝+暖橙=戏剧张力（如银翼杀手的霓虹+雨夜）
- 明暗对撞：强侧光=人物内心分裂
- 色温梯度：冷远景→暖中景→热近景=空间深度

### 第四步：质感（定义"真实感层次"）

质感是区分"AI图"和"电影帧"的最后壁垒：

| 质感层 | 提示词写法 | 作用 |
|--------|-----------|------|
| 胶片颗粒 | film grain, subtle grain texture | 消除数字感，增加有机质感 |
| 镜头缺陷 | chromatic aberration, lens flare, vignette | 模拟真实光学，非完美渲染 |
| 空气感 | atmospheric haze, dust particles, mist | 空间纵深，非真空 |
| 材质纹理 | visible pores, fabric weave, wood grain | 触觉可感的真实 |
| 光影颗粒 | light particulates, dust motes in light beam | "活"的光线 |

**质感声明公式**：
```
[film grain] + [lens characteristic] + [atmospheric element] + [surface texture]
= 电影级质感底盘
```

### 四步黄金框架→完整提示词组装

```
[第一步·定镜头]景别+角度+焦段+景深
+ [第二步·构图]前景+中景+远景三层声明
+ [第三步·光影色彩]光位+色温+对撞关系
+ [第四步·质感]胶片颗粒+镜头缺陷+空气感+材质

= 生产级电影提示词
```

**示例组装**（维京战士场景）：
```
第一步: Wide shot, low angle, 24mm wide angle, deep depth of field
第二步: Foreground: snow-laden pine branches out of focus / Midground: Viking warrior gripping battle axe, sharp focus / Background: snow-covered mountain range, atmospheric haze
第三步: Side light from camera-right, golden hour warmth on warrior, blue hour coldness in mountains, warm-cool collision
第四步: Film grain, subtle lens flare, atmospheric snow particles, worn leather texture on armor, visible breath in cold air
```

### 视频提示词七要素扩展

在四步黄金框架基础上，视频提示词增加三个要素：

```
[主体] + [动作] + [环境] + [运镜] + [光影] + [风格] + [声音]
```

| 要素 | 内容 | 图像vs视频差异 |
|------|------|-------------|
| 主体 | 谁在画面中 | 图像和视频相同 |
| 动作 | 主体在做什么 | 图像=静态姿态，视频=动作序列+速度+方向 |
| 环境 | 场景氛围 | 图像=静态背景，视频=环境动态（风/雨/光变） |
| 运镜 | 镜头怎么动 | 图像不写，视频必须写+标注动机 |
| 光影 | 光线质量 | 图像=瞬间，视频=光线随时间变化 |
| 风格 | 画风/导演风格 | 图像和视频相同，跨帧必须一致 |
| 声音 | 人声+音效+BGM | 图像不写，视频独有 |

**声音设计写入提示词**（视频独有）：
- 人声 = 角色 + 情绪 + 语调 + 语速 + 音色
- 音效 = 音源材质 + 行为 + 环境音（如"玻璃球掉落木地面，砰，室内安静"）
- BGM = 风格 + 情绪（如"悬疑风格背景音乐"）

### 四步框架与已有规范的强制叠加

| 已有规范 | 四步框架中的体现 |
|----------|----------------|
| 生产级首帧6层标准 | 四步框架是6层的精简版——定镜头=L5景深镜头，构图=L5构图，光影=L3光源氛围，质感=L4皮肤面部+L6整体质感 |
| 电影打光位置 | 第三步光影直接引用八大光位术语 |
| 色彩叙事体系 | 第三步色彩对齐色彩情绪圣经的7色模块 |
| 皮肤真实感六层 | 第四步质感声明必须包含SSS+微纹理+色区差异 |
| 导演风格圣经 | 第三步光影+第四步质感直接引用导演风格DNA |
| 动机驱动运镜 | 视频七要素中运镜必须标注动机 |

**Kling专用微表情精准控制4方案**：

Kling在微表情上的弱点（偏移率高+转头变形）可通过以下4种方案弥补：

**方案1：图生视频+结构化提示词（最常用）**
- 将微表情拆解为可量化的空间位移+时间节奏指令
- 禁止用"自然眨眼"等模糊描述，必须精确到角度+毫秒
- 示例：`head slowly turns right 12 degrees over 1.4 seconds; simultaneously completes one natural blink, closure duration 320ms, reopening with slight moisture gloss; shoulders and neck remain stationary throughout`
- 关闭"智能运镜"和"自动背景音乐"，减少AI自由发挥空间

**方案2：首尾帧语义锚定（精确控制眼部+颈部）**
- 准备同源首帧（睁眼正脸）+尾帧（闭眼/转头态），AI沿预设轨迹推演中间帧
- 勾选"强制姿态连续性校验"，ControlNet结构锁权重0.85
- 描述中精确标注时间节点：`blink starts at 1.1s, full closure at 1.4s; head turn starts at 0.8s, stops at 2.0s at 12° offset`

**方案3：帧级眨眼剧本注入（标准方案失效时用）**
- 使用Prompt Travel语法定义帧级眼睑开合节奏
- `[frame_0: open_eyes], [frame_2: eyes_half_closed], [frame_4: closed_eyes:1.2], [frame_6: eyes_half_open], [frame_8: open_eyes_with_gloss]`
- 眨眼与转头关键帧不可重叠——先眨眼后转头，或先转头后眨眼

**方案4：多视角角色档案三维锁定（反复生成一致性最优）**
- 上传4张同一人物图像：正面/左45°/右45°/微俯视
- 开启"三维结构锁定"：面部刚性权重0.88，颈部旋转容忍度0.32
- 后续所有提示词开头添加`[character:ID-XXXX]`强制调用统一面部几何先验

**AI微表情9大真实感要素**（跨模型通用检查清单）：

| # | 要素 | 常见AI问题 | 提示词修正 |
|---|------|-----------|-----------|
| 1 | 角色一致性 | 脸部特征变动0.1秒=观众潜意识异常 | 参考图锁定+锚点表跨镜头引用 |
| 2 | 皮肤质感 | 塑料光滑=最致命的AI暴露 | `natural skin texture, pores, subtle imperfections`（最大单点优化） |
| 3 | 手持拍摄感 | 稳如三脚架=一看就是AI | `slight handheld wobble, imperfect framing, natural iPhone motion blur` |
| 4 | 自然光线 | 棚拍感=假 | `soft window light, shadows following subject, real environmental catchlight in eyes` |
| 5 | 物理正确动作 | 手拿物品无重量感/不自然眨眼 | `object has weight, fabric creases, hair bounces, natural blink rhythm` |
| 6 | 唇形同步 | 嘴型与声音错位 | Seedance/Kling原生音频功能，自然停顿+呼吸+语气词 |
| 7 | 不对称性 | 过度对称=恐怖谷 | `slight head tilt, asymmetric smile, warm eye contact, subtle micro-expression variation` |
| 8 | UGC美学细节 | 过于完美=AI | `slight digital grain, shallow DOF, warm tone, iPhone-casual feel` |
| 9 | 叙事节奏 | 只有画面无叙事 | `natural jump cuts, complete logic arc, real emotional energy` |

**关键铁律**：**不对称才像真人**——微微歪头、不完全对称的笑容、有温度的眼神交流、轻微的微表情变化。恐怖谷效应的核心成因就是过度对称和过度完美。

**AI视频模型微表情与已有规范的关系**：
- 与**视觉聚焦逻辑**：模型选择直接影响眼部微动画4层规范的执行效果——Seedance对眼睑/瞳孔的控制精度更高
- 与**微表情规范**：Kling的微表情偏移率高→在Kling上必须用结构化提示词精确量化，不可用模糊描述
- 与**皮肤真实感六层**：Kling对SSS/微纹理/色区差异的渲染更强，Seedance可能需要额外声明避免过度柔化
- 与**角色锚点表**：多视角角色档案三维锁定=锚点表在Kling平台的专用实现方式
- 与**AI视频生成工作流**：模型路由策略是工作流第0步——先选模型再写提示词，选错模型=提示词再精确也无效

## 实拍+AI混合分镜工作流（Hybrid Storyboarding）

来源：Jon Kent "I Spent 9 Months Testing AI for Filmmaking" 及其混合工作流系列实践。

传统分镜只标注景别和运动方向，但在AI电影时代，每个镜头还必须标注**生成方式**——这决定了提示词写法、一致性策略和后期合成路径。混合工作流不是"全用AI"或"全用实拍"，而是在分镜阶段就决定哪些镜头用实拍、哪些用AI、哪些用混合，并给出明确理由。

### 镜头生成方式三级分类

每个分镜必须标注生成方式标签：

| 标签 | 含义 | 适用场景 | 一致性策略 |
|------|------|---------|-----------|
| **[REAL]** | 纯实拍 | 近景/特写/需要真实微表情的镜头 | 实拍锚定——后续AI镜头以此为参照 |
| **[AI]** | 纯AI生成 | 远景/大全景/不可能镜头/特效镜头 | 锚点表+参考图+末帧接力 |
| **[HYBRID]** | 实拍+AI合成 | 实拍前景+AI背景 / AI前景+实拍环境 | 绿幕流程+透视匹配+光照一致性 |

### 感知流畅性技术（Perceptual Fluency）

**核心原理**：大脑更容易接受"看起来像之前见过"的东西为真实。如果影片前3个镜头是实拍，观众已建立"这是真实世界"的心理预期；当第4个镜头切换到AI生成时，大脑会因感知流畅性而自动接受其为真实。

**分镜排序铁律**：
- 影片开头**必须用[REAL]镜头建立可信度**——至少2-3个实拍镜头后，才能出现[AI]镜头
- 从[REAL]→[AI]的过渡，景别应从近景逐渐推远——近景靠实拍保证真实感，远景用AI节省成本
- 绝对禁止开场第一个镜头就是[AI]大全景——观众还没建立信任基线，AI感会被放大

**感知流畅性景别过渡表**：

| 镜头序号 | 推荐标签 | 推荐景别 | 理由 |
|----------|---------|---------|------|
| 1-3 | [REAL] | CU/MCU/FS | 建立真实感基线 |
| 4-6 | [AI] | WS/EWS | 远景细节要求低，AI最可信 |
| 7-8 | [HYBRID] | MS/FS | 实拍前景+AI背景，渐进过渡 |
| 9+ | 自由混合 | 全景别 | 观众已接受AI为真实，可自由切换 |

### 末帧接力（Last-Frame-to-First-Frame Relay）

**问题**：AI视频模型对每个片段独立生成，片段A的最后一帧与片段B的第一帧之间无法保证视觉连续。

**解决方案**：导出片段A的最后一帧，作为片段B的首帧参考图输入。

**分镜标注格式**：
```
SHOT 07 [AI] WS → 接力源: SHOT06末帧
  首帧参考: SHOT06 last frame (人物位于画面右侧1/3处，面向左侧)
  提示词必须包含: "continuing from previous shot, character position matches frame reference"
```

**末帧接力自检规则**：
- 相邻两个[AI]镜头之间必须标注接力源
- 接力帧中人物位置、光线方向、服装状态必须与上一镜头末帧一致
- 若接力断裂（如跨场景），必须用[REAL]或标题卡做视觉分隔

### AI广角镜头策略

AI在远景/大全景上的可信度远高于近景——因为面部细节模糊、微表情不可见、皮肤质感被距离消解。

**分镜决策规则**：
- 凡是角色面部占画面面积<1/5的镜头，优先使用[AI]
- 凡是角色面部占画面面积>1/3的镜头，优先使用[REAL]或[HYBRID]
- 大全景（EWS）几乎总是用[AI]——没有理由花成本实拍一个只有轮廓的远景
- 室内对话戏的中近景必须用[REAL]——AI微表情还不够稳定

**AI广角提示词优化**：
- 远景不需要声明皮肤毛孔/微纹理，替换为大气层次声明：`atmospheric haze, depth of field layers, environmental particles in light`
- 远景不需要声明微表情，替换为体态叙事：`silhouette conveys tension through rigid posture and squared shoulders`
- 远景光线声明优先用环境光：`golden hour side-lighting casts long shadows across the valley`

### 反向绿幕工作流（Reverse Green Screen）

传统绿幕：先做虚拟背景→把人物合成进去
反向绿幕：先拍人物绿幕→用人物帧作参考→AI生成匹配背景→清洁→AI生成运动→最终合成

**分镜标注格式**：
```
SHOT 12 [HYBRID] MS
  前景: 实拍人物绿幕素材（actor_front_green_screen.mp4）
  背景: AI生成匹配透视（参考SHOT11故事板图+绿幕静帧）
  合成备注: 人物光源=5点式模拟火光(4×4 muslin+暖色LED)，背景需匹配火光方向和色温
  后期路径: Premiere Pro抠像 → LTX/Runway生成背景 → Photoshop清洁 → LTX运动 → 最终合成
```

**反向绿幕透视匹配铁律**：
- 实拍时必须记录：摄影机高度/角度/焦距/与被摄体距离
- AI背景生成提示词必须包含：`camera height X meters, shooting at Y degree angle, Zmm lens equivalent`
- 人物实拍光源方向必须与AI背景光源方向一致——若不一致，合成时会出现明显的光照不匹配

### 声音=60%情感冲击

AI电影必须像动画一样对待声音——画面只是载体，声音才是情感的驱动力。

**分镜声音设计规范**：
- 每个镜头必须标注3层声音：环境音(Ambient) + 动作音(Foley) + 情绪音(Emotional)
- [AI]镜头的声音必须全部后期添加——AI生成的视频不带真实环境音
- [REAL]镜头可保留现场音，但需标注是否需要替换/增强
- 对话场景必须声明：脚步声/呼吸声/衣物摩擦声/环境回响

**声音设计标注格式**：
```
SHOT 05 [AI] WS
  Ambient: 风声(low whoosh) + 远处犬吠(distant bark, 3-second interval) + 树叶沙沙(leaf rustle)
  Foley: 角色脚步(gravel crunch, slow pace) + 衣物拍打(fabric flap in wind)
  Emotional: 低频drone暗示不安(low drone, 60Hz, gradual fade in)
```

**关键原则**：观众对画面的宽容度远高于对声音的宽容度——画面可以有些AI瑕疵，但声音一旦不自然，整个场景的可信度瞬间崩塌。

### 混合分镜与已有规范的关系
- 与**视觉锚点系统**：[HYBRID]镜头的前景实拍部分锚定了人物外观，AI背景部分锚定了环境——两个锚点系统需分别维护再合成
- 与**感知聚焦逻辑**：感知流畅性技术是视觉聚焦的时间维度扩展——不只控制单镜头内的焦点，还控制跨镜头的可信度递进
- 与**末帧接力**：这是跨[AI]镜头一致性的实用技术，与角色锚点表互补——锚点表管"长什么样"，末帧接力管"站在哪里"
- 与**AI视频生成工作流**：混合工作流是工作流的新维度——不是纯AI管线，而是[REAL]+[AI]+[HYBRID]三轨并行管线
- 与**AI模型路由**：[AI]广角镜头→Seedance（氛围渲染强），[HYBRID]绿幕背景→Runway/LTX（透视匹配更可控），[AI]动作戏→Kling（物理仿真最强）

## 分镜逐秒情绪拆解法

将一段视频按**2秒粒度**拆解人物的表情、动作和情绪变化，形成自然过渡的时间轴。适用于AI视频提示词中需要「复杂微表情」或「情绪递进」的场景。

### 格式结构
```
[整体描述：景别/运镜/人物状态]

[逐秒时间轴]
0-2秒: [初始状态]
2-4秒: [第一个变化]
4-6秒: [第二个变化]
6-8秒: [第三个变化]
8-9秒: [收尾状态]

[总结：整体情绪弧线]
```

### 核心技巧

| 原则 | 说明 |
|------|------|
| 每个时间段只做一件事 | 2秒内只描述一种状态或一个变化 |
| 动词优先 | 用「轻扬」「舒展」「抿」「收」等精确动词代替形容词 |
| 过渡自然 | 相邻时间段的状态要有逻辑衔接，不能跳跃 |
| 细节补位 | 睷毛、嘴角、眉头、肩膀——微部位动作比大动作更真实 |
| 情绪写「弦外之音」 | 不写「她哭了」，写「眼眶泛红」「睷毛湿润」「嘴唇颤抖」 |

### 时间轴→AI提示词压缩规则
AI视频不需要逐秒写入，而是把「情绪弧线」压缩成连贯的一句话描述：
```
[景别+运镜]。[角色状态+初始情绪]，[情绪递进描述]，[情绪高潮微动作]，[收尾状态+遗留痕迹]。
[摄影机后缀]
```

## 故事板五色标记系统

在手绘/设计故事板时，用**五种颜色**区分不同类型的运动和信息，让AI理解复杂镜头调度，大幅提升视频抽卡效率。

### 五色定义

| 颜色 | 标记内容 | 示例 |
|------|----------|------|
| 🔴 红色箭头 | 身体/肢体运动 | 手指抬起、头部转动、肩膀微耸、行走方向 |
| 🔵 蓝色箭头 | 摄影机运动 | 慢推、横摇、上升、环轨、dolly zoom |
| 🟢 绿色标记 | 取景/构图笔记 | 三分法构图线、视线方向、画面留白 |
| 🟠 橙色标记 | 灯光方向与类型 | 主光方向、逆光源位置、柔光/硬光标注 |
| 🟣 紫色标记 | 声音/情感强调 | 配乐起、对白情绪、音效节点 |

### 制作流程
1. **剧本→角色板**：提取全部人物，画角色设定（正/侧/背三视图），标注核心特征
2. **剧本→分镜拆解**：一个连贯镜头拍完最具戏剧性的情绪高潮段落
3. **分镜→故事板**（黑白线稿）：手绘风格草图，关键动作标注
4. **套五色标记**：按规则标记，单画面信息量≤3-5个要素（AI视频单帧理解上限）
5. **故事板→AI提示词**：🔴→人物动作/🔵→运镜/🟢→构图/🟠→灯光/🟣→氛围

### 与分镜表12列的衔接
- 🔴 → 第4列「画面描述」、第5列「角位/角度」
- 🔵 → 第3列「运镜」
- 🟢 → 第4列「画面描述」、第2列「景别」
- 🟠 → 第6列「灯光/氛围」
- 🟣 → 第8列「音效/配乐」、第7列「色彩/调性」

两套系统互补：分镜表做详细规划，五色标记在故事板草图上做视觉化标注。

## 跟随运镜完全指南

### 五大跟随类型

| 类型 | 特点 | 适用场景 |
|------|------|----------|
| **侧面跟随** | 摄像机从侧面与主体并行 | 最常用，代入感+速度感 |
| **正面后退跟随** | 摄像机在主体前方后退，面部始终可见 | 情感戏、表情捕捉 |
| **背面推进跟随** | 摄像机在主体后方推进 | 悬念、探险、代入感 |
| **低角度贴地跟随** | 极低角度，贴近地面 | 压迫感、紧张跟踪 |
| **高空俯拍跟随** | 从高空向下跟随运动轨迹 | 展示轨迹、上帝视角 |

### 四种组合运镜

| 组合 | 模式 | 效果 |
|------|------|------|
| **推近→跟随** | 先推近聚焦表情，再切换侧面跟随 | 情绪递进型 |
| **环绕→跟随** | 先弧形绕摄展示全貌，再背面跟随入新空间 | 展示转跟踪型 |
| **低角度升起→高空俯拍跟随** | 从贴地升到树冠，切换俯拍跟随 | 空间展开型 |
| **摇镜锁定→跟随** | 先摇镜锁定快速主体，再背面跟随加速 | 追踪型 |

### 情绪→运镜映射表

| 情绪 | 推荐运镜 | 角度 | 节奏 |
|------|---------|------|------|
| 紧张、压迫 | 低角度贴地跟随 | 极低 | 慢→快 |
| 代入、共鸣 | 正面后退跟随 | 平视 | 慢 |
| 悬念、探险 | 背面推进跟随 | 平视 | 慢 |
| 速度、刺激 | 侧面跟随 | 平视 | 快 |
| 孤独、渺小 | 高空俯拍跟随 | 俯视 | 慢 |
| 激动、爆发 | 推近→跟随组合 | 平视 | 快慢结合 |
| 优雅、展示 | 环绕→跟随组合 | 平视 | 慢 |
| 追踪、紧迫 | 摇镜→跟随组合 | 平视 | 快 |

### 跟随运镜铁律
- 每条提示词最多2-3个运镜指令，多了AI混乱
- 必须描述背景如何后退/变化——不写背景就没有"跟随感"
- 先定情绪再选运镜——技巧服务于表达，不是炫技
- 主体在画面中的位置必须明确（中央/左侧/右侧三分之一）

## Grok Imagine元提示词框架

一套五步思维链提示词工程框架，让AI从**图片识别→镜头分析→动作设计→节奏编排→参数输出**。

### 五步思维链

**第一步：图片内容识别**
- 主体对象/环境背景/构图特征/色彩情绪/动态潜力/叙事暗示

**第二步：智能镜头语言分析**
- 构图类型→运动建议（7种映射）

| 构图类型 | 适合运动 |
|----------|----------|
| 三分法构图 | 横向或纵向运动 |
| 对称构图 | 缩放或旋转 |
| 对角线构图 | 沿对角线轨迹运动 |
| 框架构图 | 景深变化或穿越运动 |
| 引导线构图 | 沿线条跟随运动 |
| 黄金螺旋 | 环绕运动 |
| 三角形构图 | 局部动态保持整体稳定 |

- 镜头角度→运动映射（6种）

| 角度 | 适合运动 | 情绪效果 |
|------|----------|----------|
| 鸟瞰 | 全局展示、旋转 | 上帝视角 |
| 高角度 | 下压运动 | 压抑感 |
| 平视 | 水平运动 | 自然观察 |
| 低角度 | 上扬运动 | 威严感 |
| 荷兰角度 | 倾斜不稳定运动 | 不安定感 |
| 虫视 | 仰视运动 | 极低视角冲击 |

**第三步：动作设计决策树**
- 人物场景：肖像→微表情/眨眼/呼吸；半身→手势/转头/肩部；全身→步态/姿态/衣物飘动
- 风景场景：自然→云/水/树；城市→车流/灯光/人群；建筑→光影/透视/细节
- 物品静物：产品→360°旋转/细节/光效；食物→热气/酱汁/切面；艺术→多角度/光影游走

**第四步：6秒起承转合模板**
```
起（0-1.5秒）：建立场景，引入动态
承（1.5-4秒）：动作发展，节奏展开 ← 最长段
转（4-5.5秒）：达到高潮，视觉冲击
合（5.5-6秒）：快速收尾，循环衔接 ← 最短段
```
关键帧时间点：1.5秒 / 4秒 / 5.5秒

**第五步：技术参数**
- 运动强度1-10（1=极微动，10=剧烈运动）
- 运动曲线：线性/缓入/缓出/缓入缓出
- 景深变化：前/中/背景虚实
- 时间扭曲：常速/慢动作/快动作/冻结

### 节奏控制类型
- **渐进式**：强度逐步递增（延时摄影风格）
- **起伏式**：强度波动（动-静-再动）
- **爆发式**：前平后爆（突然冲击）

### 跨工具适配
- **Kling 2.0**：运动强度降一档，加`motion intensity subtle`
- **Seedance 2.0**：直接套用，四阶段强度参数完美匹配
- **Sora**：时间轴改为10秒版本（起3/承4/转2/合1），运动强度上调
- **Veo 2**：英文模板直接用

## GPTimage2故事板+Seedance工作流

**单张图=赌博；完整故事板=导演。** 用GPTimage2生成包含完整导演分镜板的故事板图，再喂给Seedance2.0生成一镜到底视频。

### 故事板五大模块

| 模块 | 内容 |
|------|------|
| 顶部栏 | 镜头数量、画幅、统一调色板、环境、风格基调、节奏 |
| 角色与风格参考 | 多角度模型（正面/侧面/背面/特写）、服装配饰参考 |
| 环境与场景设计 | 场景概念图、俯视机位图（标注镜头移动路径） |
| 故事板（8个镜头） | 摄像机类型、镜头大小、运动方式、动作情绪描述 |
| 灯光/情绪/风格备注 | 光线条件、氛围、纹理、时间过渡 |

### 关键技巧
- 必须开Thinking模式（复杂排版质量差距巨大）
- 加「所有分镜同一画风、同一色调、同一角色」
- 角色设定写在提示词开头，所有分镜保持一致

### 六大避坑

| 阶段 | 坑 | 解法 |
|------|-----|------|
| GPTimage2 | 中文乱码 | 开Thinking模式；出错迭代修改 |
| GPTimage2 | 风格不一致 | 加「同一画风、同一色调、同一角色」 |
| GPTimage2 | 角色崩了 | 上传角色设定表作为参考 |
| Seedance2.0 | 第一帧显示故事板 | 剪掉第一秒；或前两格用同一张图缓冲 |
| Seedance2.0 | 镜头乱切 | 加「一镜到底」；检查时间戳连续性 |
| Seedance2.0 | 角色脸崩 | 上传角色设定表；减少视频提示词里的画面描述 |

## AI真人短剧「文资视剪」全流程

### 四阶段工作流

| 阶段 | 内容 | 推荐工具 |
|------|------|----------|
| **文** | 故事扩写+分镜拆解 | Gemini 3.5 Flash / 豆包 / Kimi / DeepSeek |
| **资** | 人设、场景、道具资产（保证角色一致性） | GPT生图 |
| **视** | 分镜生成视频 | Seedance 2.0 / 即梦 / Flow |
| **剪** | 剪辑成片 | 剪映/CapCut |

### 故事扩写铁律
- 开头3秒必须有钩子（当众羞辱/突然摊牌/一句狠话/一个反常动作）
- 人物关系简单，观众10秒内看懂谁欺负谁
- 台词短、狠、直白，少用文艺腔
- 每30秒至少一个情绪变化，每1分钟至少一个小高潮
- 前期主角被压制，后期反击有释放感
- 场景控制在1-3个核心场景

### 资产提取规范
- 人物提示词：全身远景，正面站立，纯色背景，真人写实电影质感，角色设定表
- 场景提示词：场景概念图，真人短剧质感，真实物理光影，空间层次清晰
- 道具列表：剧中需保持一致的重要道具，附外观描述
- 四视图补充：面部超大特写+正面/侧面/背面全身

### 分镜头脚本规范
- 每段视频总时长10-15秒
- 每段4-5个镜头，每个镜头2-4秒
- 台词分配到对应镜头
- 情绪高潮：特写+推镜头+低角度仰拍
- 双人对话：180度轴线一致，A始终左侧，B始终右侧
- 统一风格后缀：真人写实短剧，35mm胶片拍摄，轻微胶片颗粒感，真实物理光影，高动态范围

### 避坑指南
- 别做明星脸（肖像权+审核风险）
- 一个镜头只做一件事
- 先做15秒跑通再扩展
- 必须先做资产，不然角色脸/服装全乱套
- 提示词只是门槛，真正差距在于判断力

## 摄影师风格DNA提取法

与导演风格圣经互补——导演风格偏叙事/调度/节奏，摄影师风格偏光影/色彩/构图。两者组合使用可生成更丰富的视觉风格。

### 七位摄影师风格DNA

**① Ovidiu Selaru — 黑白光影诗人**

| 维度 | 手法 | AI提示词映射 |
|------|------|-------------|
| 光影 | 极端明暗对比，投影切割画面 | `harsh chiaroscuro`, `deep shadows with crisp edges`, `dramatic light beams cutting through darkness` |
| 构图 | 几何线条引导视线，建筑结构天然画框 | `strong leading lines`, `architectural framing`, `geometric composition` |
| 层次 | 前/中/远景分明，每层有独立信息量 | `layered depth`, `foreground silhouette`, `midground subject`, `distant vanishing point` |
| 氛围 | 孤独、静谧、有呼吸感 | `solitary figure`, `quiet contemplation`, `empty urban spaces` |

**② Billy Dinh — 电影感街头导演**

| 手法 | AI提示词映射 |
|------|-------------|
| 慢门动态模糊 | `motion blur`, `slow shutter effect`, `ghostly figures in motion`, `1/15s shutter speed` |
| 对角线构图 | `diagonal composition`, `dynamic angular framing` |
| 冷暖色碰撞 | `teal and orange color grade`, `warm highlights cool shadows` |
| 电影感叙事 | `cinematic still`, `movie frame aesthetic`, `Wong Kar-wai aesthetic` |

**③ Patrick Noack — 极简几何**

**⑤ Jake Michaels — 浓烈色彩**

**⑦ Jorge Chagas — 玻璃介质诗人**

| 维度 | 手法 | AI提示词映射 |
|------|------|-------------|
| 核心技法 | 透过玻璃/窗户/屏幕拍摄，创造多层现实叠加（前景玻璃纹理→中景主体→远景反射三层深度） | `shot through glass`, `layered reflections on window surface`, `simultaneous transparency and reflection`, `three-layer depth: glass surface → subject → background reflection` |
| 光影 | 晨曦漫射自然光，柔和高光+保留暗部细节（不压至纯黑） | `soft dawn light diffusion`, `overcast ambient with subtle golden edge`, `preserved shadow detail no crushed blacks` |
| 构图 | 窗户/建筑几何框式构图，负空间留白，城市孤独感 | `frame within a frame through window`, `geometric architectural framing`, `negative space around solitary figure in vast cityscape` |
| 介质质感 | 玻璃表面的水汽/指纹/尘埃/镀膜偏色（绿-紫）是画面有机组成部分 | `condensation trails on glass`, `fingerprint smudges on window surface`, `lens coating green-magenta color shift at grazing angles` |
| 色彩 | 蓝灰/青灰冷基调 + 5-15%暖金/琥珀高光点缀 | `desaturated teal-gray color grade`, `warm amber accent on 5-15% of frame only`, `cool ambient 5600K + golden edge light 3200K` |
| 氛围 | 城市孤独、窥视距离、晨曦时刻的悬停感、多层现实 | `solitary figure in vast urban landscape`, `voyeuristic distance through glass`, `suspended dawn moment`, `poetic documentary meets cinematic street photography` |

> **Chagas 使用场景**：当项目中需要「玻璃/反射/屏幕/窗户」视觉母题，或需要「窥视/监视/多层现实/数字屏幕=现代窗户」叙事视角时，Jorge Chagas 为第一优先级摄影师。特别适用于：监控室场景、车窗对话、橱窗反射、镜面倒影、通过屏幕看世界的数字窥视。

### 摄影师风格选择优先级
```
构图优先 → Noack「极简」或 Hordijk「几何」
  ↓
光影 → Selaru「明暗」或 Van Nynatten「九律」
  ↓
色彩 → Michaels「浓烈」或 Dinh「青橙」
  ↓
叙事 → Dinh「电影感」或 Selaru「孤独诗意」
  ↓
介质 → Chagas「玻璃」——当项目含玻璃/反射/屏幕/窗户母题时优先调用
  ↓
组合 → 导演风格+摄影师风格混搭
```

### 摄影师风格+导演风格混搭规则
- 导演管叙事节奏（对白/剪辑/调度），摄影师管视觉质感（光影/色彩/构图）
- 混搭时两个维度不冲突——一个决定"怎么讲故事"，一个决定"看起来怎样"
- 同类不混（两个极简摄影师不叠加），异类互补（极简构图+浓烈色彩=强对比）
