# viral-thread-story

社交媒体爆款推文故事创作引擎 🦞

## 技能概述

专为中文社媒平台设计的分段式小说写作技能。覆盖爆款推文的完整创作方法论：

- 开头钩子设计（五式）
- 世界观分层植入
- 双线叙事结构
- 情感递进公式（W形曲线）
- 反转节奏控制
- 短句与留白技巧
- 移动端阅读适配

## 触发场景

- 创作微博/小红书/抖音图文连载故事
- 将小说改编为社交媒体分段格式
- 分析或模仿某篇爆款推文的结构与语言
- 为短剧/微短剧撰写社交媒体验证文案
- 设计「钩子-冲突-反转-留白」的故事营销文案

## 核心创作流程

### 第一步：理解需求，选择模板

| 类型 | 适用场景 | 核心情感驱动 |
|------|---------|-------------|
| 虐文/替身文学 | 情感向、女性向 | 委屈→绝望→反转→治愈 |
| 爽文/逆袭 | 大众向 | 压抑→爆发→打脸→称王 |
| 悬疑/惊悚 | 猎奇向 | 日常→异常→恐惧→真相 |
| 甜宠/治愈 | 轻松向 | 孤独→遇见→温暖→成长 |
| 系统/穿越 | 幻想向 | 死亡→重生→开挂→逆天 |

### 第二步：构建叙事骨架

采用「10段黄金结构」（可根据篇幅缩放为 5/8/12 段）：

```
段01 — 钩子（Hook）：直接用冲突场景开篇，不铺垫
段02 — 世界观植入：在叙事中自然展开设定，不另起段落说明
段03 — 伏笔层：开始植入"后来才懂"的细节
段04 — 升温：冲突升级，情感积累
段05 — 破防：情感最高点（绝望/愤怒/醒悟）
段06 — 致命一击：主角被推向绝境
段07 — 至暗时刻：走向死亡/告别/放弃
段08 — 反转降临：意料之外的转折开始
段09 — 反转展开：新线索、新设定、新关系
段10 — 收束与悬念：本段落收束 + 为下一篇埋钩子
```

### 第三步：设计情感曲线

爆款推文的情感曲线必须呈 **W 形**：

```
紧张度
  ↑     ╱╲        ╱╲
  │    ╱  ╲  ╱──╲╱  ╲
  │   ╱    ╲╱        ╲──
  │  ╱                  ╲
  └────────────────────────→ 段落
    01 02 03 04 05 06 07 08 09 10
```

### 第四步：执行语言规范

#### 4.1 句子长度规则

- 80% 的句子不超过 20 字
- 关键情绪句不超过 10 字
- 每段不超过 3-4 行（手机屏幕一屏）
- 段落之间保留空行

#### 4.2 开头钩子五式

1. **场景直入式**：「在我成人礼那晚，我的双胞胎姐姐爬上了我未婚夫的床。」
2. **反转预告式**：「所有人都以为我会死。我也这么以为。」
3. **定义式**：「在这个世界，丑陋就是原罪。」
4. **对话开篇式**：「『现在她可以替我去死了。』我姐姐说。」
5. **悖论式**：「他救了我。然后亲手杀了我。」

#### 4.3 情绪句写法

| 技法 | 示例 | 效果 |
|------|------|------|
| 短句爆发 | 「我不是被选中的。我是备胎。」 | 利落、刺痛 |
| 重复递进 | 「我先遇到他的。我先遇到他的，没人在乎。」 | 执念、委屈 |
| 感官具象 | 「胸口像灌了水泥。」 | 身体记忆 |
| 反向自嘲 | 「这一定是我活该吧。」 | 读者心疼 |
| 静默留白 | 「我低下头，什么都没说。」 | 比哭更痛 |

#### 4.4 观点表达规则

- **禁止**直接说「他很残忍」→ 用行动展示：他拔下自己最珍贵的羽毛给她做裙子，却缺席了我的仪式。
- **禁止**直接说「我很自卑」→ 用细节展示：我存下所有钱买了一棵火鸟巢树苗，抱着它在祭坛等了一整天。
- **禁止**直接说「世界不公平」→ 用对比展示：她有治愈胎记的解药，却选择给姐姐当备用方案。

#### 4.5 反转设计规则

反转必须满足三个条件：
1. **有伏笔可循**（读者回看能发现线索）
2. **改变关系格局**（引出新人物/新设定/新冲突）
3. **提供情感喘息**（绝望后必须给一点甜或希望）

### 第五步：分段输出格式

输出时严格遵循以下格式：

```
[段号]
[正文，每段 80-200 字]
[落点句：单行短句，作为钩子]
[空一行]
[段号]
...
```

每段结尾必须是：
- 一句短于 15 字的落点句
- 该句需具备独立转发价值（可截图传播）
- 该句需包含情绪张力或悬念

**落点句示例**：
- 「我先遇到他的。」
- 「我决定不哭了。」
- 「他说，你不一样。」
- 「然后他关门走了。」

### 第六步：自我审查清单

完成创作后，对照以下清单自查：

- [ ] 段01是否直接进入冲突场景？（禁止铺垫/背景介绍）
- [ ] 世界观是否在叙事中自然展开？（禁止单独说明段落）
- [ ] 每段结尾是否有落点钩子？
- [ ] 情感曲线是否呈 W 形？
- [ ] 是否做到了「展示而非告知」？
- [ ] 句子长度是否适配手机屏幕？（80% 句子 ≤20 字）
- [ ] 是否存在可截图的「金句」？（至少 3 处）
- [ ] 反转是否有前文伏笔支撑？
- [ ] 最后一段是否为下一篇留了悬念？
- [ ] 全文是否符合微博/小红书的内容审核规范？

## 适用平台

- **微博**：分段发布，每段独立成篇，段10留悬念引导转发
- **小红书**：配合"替身文学"话题，吸引情感向读者
- **抖音图文**：用图文形式，每段配一张情绪向插图
- **微信公众号**：适合长文发布，一次性放完10段

## 注意事项

1. **内容审核**：涉及敏感话题时需注意平台审核规则
2. **文化差异**：英文原作改编需注意中文读者审美
3. **篇幅控制**：10段结构适合中篇，可压缩为5段或8段
