# 社交媒体爆款推文故事创作引擎

## 技能概述

本技能提供一套完整的社交媒体分段式故事（推文体小说）创作方法论。
通过对中文社媒平台上高互动量推文故事的系统分析，提炼出可复用的叙事结构、
语言技巧、节奏控制策略和移动端阅读适配规则。

## 触发场景

- 创作微博/小红书/抖音图文连载故事
- 将小说改编为社交媒体分段格式
- 分析或模仿某篇爆款推文的结构与语言
- 为短剧/微短剧撰写社交媒体验证文案
- 设计「钩子-冲突-反转-留白」的故事营销文案

## 核心创作流程

### 第一步：理解需求，选择模板

根据用户需求，从以下模板中选择或组合：

| 类型 | 适用场景 | 核心情感驱动 |
|------|---------|-------------|
| 虐文/替身文学 | 情感向、女性向 | 委屈→绝望→反转→治愈 |
| 爽文/逆袭 | 大众向 | 压抑→爆发→打脸→称王 |
| 悬疑/惊悚 | 猎奇向 | 日常→异常→恐惧→真相 |
| 甜宠/治愈 | 轻松向 | 孤独→遇见→温暖→成长 |
| 系统/穿越 | 幻想向 | 死亡→重生→开挂→逆天 |

### 第二步：构建叙事骨架

采用「10段黄金结构」（可根据篇幅缩放为 5/8/12 段）：

```
段01 — 钩子（Hook）：直接用冲突场景开篇，不铺垫
段02 — 世界观植入：在叙事中自然展开设定，不另起段落说明
段03 — 伏笔层：开始植入"后来才懂"的细节
段04 — 升温：冲突升级，情感积累
段05 — 破防：情感最高点（绝望/愤怒/醒悟）
段06 — 致命一击：主角被推向绝境
段07 — 至暗时刻：走向死亡/告别/放弃
段08 — 反转降临：意料之外的转折开始
段09 — 反转展开：新线索、新设定、新关系
段10 — 收束与悬念：本段落收束 + 为下一篇埋钩子
```

### 第三步：设计情感曲线

爆款推文的情感曲线必须呈 **W 形**：

```
紧张度
  ↑     ╱╲        ╱╲
  │    ╱  ╲  ╱──╲╱  ╲
  │   ╱    ╲╱        ╲──
  │  ╱                  ╲
  └────────────────────────→ 段落
    01 02 03 04 05 06 07 08 09 10
```

- 段01：高开（冲突/背叛/死亡/穿越）
- 段02-04：情绪积累，缓慢爬升
- 段05：第一个情感高峰（破防点）
- 段06-07：短暂下沉，推向绝境
- 段08-09：反转上升，希望出现
- 段10：收束，留下余味

### 第四步：执行语言规范

严格遵循以下语言规则：

#### 4.1 句子长度规则

- 80% 的句子不超过 20 字
- 关键情绪句不超过 10 字
- 每段不超过 3-4 行（手机屏幕一屏）
- 段落之间保留空行

#### 4.2 开头钩子五式

1. **场景直入式**：「在我成人礼那晚，我的双胞胎姐姐爬上了我未婚夫的床。」
2. **反转预告式**：「所有人都以为我会死。我也这么以为。」
3. **定义式**：「在这个世界，丑陋就是原罪。」
4. **对话开篇式**：「『现在她可以替我去死了。』我姐姐说。」
5. **悖论式**：「他救了我。然后亲手杀了我。」
6. **高光前置式**：开局直接展示未来最爆名场面+金句（配【画面】标注集数），
   牺牲第一层悬念换取全程「憋爽式期待感」，仅适用于强打脸/强视觉题材，
   悬疑主导的故事禁用（详见案例十一）

#### 4.3 情绪句写法

| 技法 | 示例 | 效果 |
|------|------|------|
| 短句爆发 | 「我不是被选中的。我是备胎。」 | 利落、刺痛 |
| 重复递进 | 「我先遇到他的。我先遇到他的，没人在乎。」 | 执念、委屈 |
| 感官具象 | 「胸口像灌了水泥。」 | 身体记忆 |
| 反向自嘲 | 「这一定是我活该吧。」 | 读者心疼 |
| 静默留白 | 「我低下头，什么都没说。」 | 比哭更痛 |

#### 4.4 观点表达规则

- **禁止**直接说「他很残忍」→ 用行动展示：他拔下自己最珍贵的羽毛给她做裙子，却缺席了我的仪式。
- **禁止**直接说「我很自卑」→ 用细节展示：我存下所有钱买了一棵火鸟巢树苗，抱着它在祭坛等了一整天。
- **禁止**直接说「世界不公平」→ 用对比展示：她有治愈胎记的解药，却选择给姐姐当备用方案。

#### 4.5 反转设计规则

反转必须满足三个条件：
1. **有伏笔可循**（读者回看能发现线索）
2. **改变关系格局**（引出新人物/新设定/新冲突）
3. **提供情感喘息**（绝望后必须给一点甜或希望）

示例：被强行绑定给失控的龙 → 噩梦空间竟是世外桃源 → 龙变成了婴儿形态
（伏笔：此前提到龙的眼中闪过蓝光 / "你不一样"）

### 第五步：分段输出格式

输出时严格遵循以下格式：

```
[段号]
[正文，每段 80-200 字]
[落点句：单行短句，作为钩子]
[空一行]
[段号]
...
```

每段结尾必须是：
- 一句短于 15 字的落点句
- 该句需具备独立转发价值（可截图传播）
- 该句需包含情绪张力或悬念

**落点句示例**：
- 「我先遇到他的。」
- 「我决定不哭了。」
- 「他说，你不一样。」
- 「然后他关门走了。」

### 第五步之二：章节化连载变体（20-26 章长篇）

当篇幅需求超过 10 段（如公众号连载、番茄式连载、短剧母本）时，切换为章节化模式：

- **每章 300-700 字**，一屏到两屏，章末必设钩子
- **情感曲线**为「大W套多个小W」：每章自带一个完整小W（挑衅→压抑→反杀→喘息），大W主峰放在 2/3 处（验收/归来/死局揭晓）
- **付费卡点式衔接**：卡点前后的章末与章首**原句复现**（上一章末句 = 下一章首句），保证翻页/付费读者零上下文丢失，并在卡点处标注 `【卡】` 或 `（付费卡点）`
- 结构参考：钩子章（三句话压缩人设/困境/事件）→ 反派矩阵确立 → 反派清算链（升级式）→ 归来验收/死局揭晓 → 契约变真爱/悲壮留白 → 收尾金句

### 第五步之三：【画面：】视觉标注规范

为衔接推文 → 分镜 → AI 视频管线（tweet-storyboard / 9-16-movie-story），正文中可内嵌视觉导演提示：

1. 格式：`【画面：…】`，只写**视觉可拍**内容（动作/景别/音效），禁止写心理
2. 音效用引号拟声词独立标注：`【画面："砰！"】`
3. 频率：每段/每章 1-3 处，不破坏文字阅读节奏
4. 高光前置预告中的【画面】可标注集数（「第7集」），充当目录索引
5. 关键揭露/碾压时刻优先标注（巨幕亮头像、血溅黑鳞、校旗翻涌等视觉图腾）

### 第五步之四：群体合唱团装置（舆论场写作）

直播评论、看台喊声、宾客窃语、校园论坛等「围观者声音」可承担四层功能：

| 功能 | 用法 | 示例 |
|------|------|------|
| 情绪放大器 | 替读者喊出那句话 | 「这根本不是决赛，是公开处刑！」 |
| 递话人 | 由路人说出关键名字/伏笔 | 「如果Ghost还在，他敢这么嚣张吗？」 |
| 审判庭 | 对反派定性 | 「甩锅还能再明显一点吗？」 |
| 纪念碑 | 战后盖棺 | 全论坛被同一名字占满 |

使用规范：合唱团只说短句、只说读者想说的那句话、永远比场内人物晚半拍。

### 第五步之五：海外化转译规则（中文网文 → 西方超自然市场）

将中文男频/女频设定投放海外（Web novel / Wattpad / TikTok threads）时，按**功能等价**转译，骨架不动、皮相全换：

| 中文设定 | 海外等价 | 转译要点 |
|---------|---------|---------|
| 黑帮分区统治 | 狼人氏族 Alpha / 吸血鬼血族 / 女巫结社 | 种族即立场：背叛=狼、腐朽=血、清醒=巫 |
| 管理局/官方垄断 | 觉醒者事务局（Bureau） | 制度反派换个皮仍是制度反派 |
| 配给/供奉 | 血税（Tithe）/ 契约（Covenant） | 用宗教中性词规避 cult 审核敏感 |
| 等级数值 | 圣印/Sigil + 罗马环级（I-IX） | 保留数值对比打脸，换可视化图腾（烙印、纹章） |
| 修炼/吞噬升级 | 兽相（Aspect）觉醒 | 身体化+可视觉化：心跳、鳞化、竖瞳 |
| 污染值/走火入魔 | 空心化（Hollowing）倒计时 | 心跳数是天然音效卡点 |
| 帮派口号 | 月夜审判、血誓、烛火熄灯 | 场面仪式感 > 数值感 |

操作规范：
1. **金句全部中英双写**，EN 版直接产出（短句、名词化、动词收尾）
2. 人名用可拼读的短名（Kael / Fen / Wren / Aldric），种族身份入名
3. 敏感词替换表：献祭→offering、邪教→covenant、黑帮→pack/coven
4. 海外版与中文版**骨架完全对齐**（反转链/章节/卡点不变），两版并行 A/B 投放

### 第五步之六：付费短剧转制铁律（推文→竖屏短剧节奏）

推文转制付费竖屏短剧时的硬性节奏约束：

1. **零帧起手**：第 0 帧即冲突画面——无片头、无 logo、无黑屏、无环境铺垫
2. **3-5 秒一爆**：爆炸事件（视觉爆/力量爆/情绪爆/反转爆/信息爆五类轮换，连续两爆不同类）全片间隔 ≤5-7 秒
3. **5-10 秒人设锚定**：一句台词 + 一个动作，双通道让观众说出"他是什么人"
4. **20 秒转折**：首集约 20 秒处必须有改变局面的转折性事件（攻守易位/身份揭示/警报升级）
5. **集集有钩**：每集末尾为爆炸性钩子（悬念/金句/画面震慑三选一）
6. **卡点集 = 爆炸集**：付费墙前后必须是该段最强爆点；卡点切在信息揭晓前一帧；卡前 15 秒放金句；下一集开头原句/原画面复现，保证零上下文损失
7. **章→集映射**：推文 1 章 ≈ 短剧 3 集 × 90s；章节末钩子即集末钩子；每 8-10 集设一个付费级爆点集
8. **竖屏适配**：爆点画面优先特写与纵深（竖构图压迫感：推近、俯视、跨城对视）

### 第六步：自我审查清单

完成创作后，对照以下清单自查：

- [ ] 段01是否直接进入冲突场景？（禁止铺垫/背景介绍）
- [ ] 世界观是否在叙事中自然展开？（禁止单独说明段落）
- [ ] 每段结尾是否有落点钩子？
- [ ] 情感曲线是否呈 W 形？
- [ ] 是否做到了「展示而非告知」？
- [ ] 句子长度是否适配手机屏幕？（80% 句子 ≤20 字）
- [ ] 是否存在可截图的「金句」？（至少 3 处）
- [ ] 反转是否有前文伏笔支撑？
- [ ] 最后一段是否为下一篇留了悬念？
- [ ] （章节化连载）章末是否设钩子？卡点前后是否原句复现？
- [ ] （含【画面】标注）是否只写可拍内容、频率是否控制在每段 1-3 处？
- [ ] （合唱团装置）围观者声音是否只说短句、晚半拍、说读者想说的那句话？
- [ ] 全文是否符合微博/小红书的内容审核规范？
