# 分镜构图参数手册
### 供分镜提示词生成使用

适用范围：以下数值为竖屏 9:16 的构图起点，按当前画幅、人物、参考图和动作调整，不据此修改已批准的空间关系。OTS/Clean Single 用具体前景人物、机位所在轴线侧和视线描述确认，不单凭“内/外反打”名称判断。第一集正脸、字幕安全区等仅在当前项目明确需要时适用。

这份手册把"内反打""正反打"这类经验性说法,拆解成可以直接写进 JSON schema 字段(`shot_size` / `focal_length` / `camera_height` / `axis` / `composition_ratio`)的具体参数,让生成模型能按数值而不是靠"意会"来还原构图。

---

## 一、景别体系(Shot Size)与画面占比

竖屏 9:16 因为画幅窄,景别的人物占比要比横屏更精确地规定,否则人脸容易被压扁或顶天立地。

| 景别 | 英文 | 人物占画面高度 | 常用焦段(全画幅等效) | 用途 |
|---|---|---|---|---|
| 大特写 | ECU (Extreme Close-Up) | 眼睛到下巴占70-90% | 85-135mm | 情绪爆发、道具细节(戒指/伤口) |
| 特写 | CU (Close-Up) | 头顶到锁骨,占60-75% | 50-85mm | 对话核心情绪镜头 |
| 中近景 | MCU (Medium Close-Up) | 头顶到胸口,占45-55% | 35-50mm | 常规对话主镜头 |
| 中景 | MS (Medium Shot) | 头顶到腰部,占30-40% | 28-35mm | 带手势、肢体表演 |
| 中全景 | MFS (Medium Full Shot) | 头顶到膝盖,占20-30% | 24-28mm | 双人调度、走位 |
| 全景 | FS (Full Shot) | 全身占画面60-80%高度 | 18-24mm | 环境交代、动作发起 |
| 大全景 | EWS | 人物占比<15% | 14-18mm | 定场、地理关系 |

**竖屏特别注意**:9:16 画幅下,MS/MFS 容易在左右留出大量死白空间——需要用前景遮挡物(门框、植物、肩膀)去填补横向空间,构图指令里要显式写 `foreground_occlusion: true`。

---

## 二、内反打(Shot/Reverse Shot)完整参数

"内反打"通常指两人对话时,机位在两人连线内侧、越过一方肩膀拍另一方(即 OTS, Over-The-Shoulder),与"外反打"(机位在连线外侧,拍摄干净单人 Clean Single)相对。

### 2.1 OTS(内反打 / 过肩镜头)

| 参数 | 数值/规则 |
|---|---|
| 构图比例 | 前景人物(被拍摄者背影)占画面宽度15-25%,置于画面一侧(通常靠近轴线一侧的1/3处) |
| 焦点人物占比 | 对话对象占画面高度40-55%(MCU-MS之间) |
| 焦段 | 50-85mm(避免用广角,OTS用广角会让前景肩膀畸变过大) |
| 景深 | 前景人物虚化,f/1.8-f/2.8等效,虚化强度中高 |
| 视线方向 | 焦点人物视线需明确投向镜头外前景人物方向(约15-30°偏移,不能直视镜头) |
| 机位高度 | 与说话人眼睛等高,或略低5-10cm制造"被注视感" |
| 头部室(headroom) | 顶部留白5-8%画面高度 |
| 轴线位置 | 严格在180°轴线内侧,与对应反打镜头共享同一轴线 |

**JSON字段示例**:
```json
{
  "shot_size": "OTS_MCU",
  "focal_length_mm": 65,
  "composition_ratio": {"foreground_subject_width_pct": 20, "focus_subject_height_pct": 48},
  "depth_of_field": "shallow_f2.0",
  "eyeline_offset_deg": 20,
  "camera_height": "eye_level_minus_8cm",
  "axis": "A_side"
}
```

### 2.2 外反打(Clean Single / 干净单人)

| 参数 | 数值/规则 |
|---|---|
| 构图比例 | 人物单独占画面,无前景遮挡,居中偏轴线对侧1/3(留出对话方向的"看空间" look room) |
| Look room | 人物视线方向留白比背后留白多出画面宽度的10-15% |
| 焦段 | 35-50mm(比OTS更广,交代环境关系) |
| 景深 | 中等虚化,背景可辨认环境 |
| 用途 | 用于强调该角色的独立反应,或该角色情绪与对话对象产生错位时 |

### 2.3 正反打组合规则(为AI生成连续性用)

1. 两个反打镜头必须共享同一条轴线(`axis` 字段值一致,如 `A_side`),并同时核对人物左右、机位侧和视线目标；仅字段相同不能证明空间正确。
2. OTS的前景遮挡方向要与对应反打的背景方向一致(A的OTS前景是B的背影 → B的反打镜头背景里应能看到A的存在暗示,如虚化色块)。
3. 每组正反打建议至少提供三档景别可选(OTS-MCU / OTS-CU / Clean-Single-MS),给剪辑节奏留空间,写入 `coverage_options` 数组而非单一镜头。

## 三、焦段与情绪语言对照表

焦段不只是"拍多远",在短剧分镜里它承担情绪暗示功能,建议在 prompt 里显式声明原因,而不只是给数字。

| 焦段(全画幅等效) | 视觉特征 | 情绪/叙事用途 |
|---|---|---|
| 14-24mm(广角) | 畸变明显,空间感强,边缘拉伸 | 压迫感、失控感、大场面定场 |
| 28-35mm(标准偏广) | 接近人眼视角,畸变轻微 | 中性叙事、双人调度、走路戏 |
| 50mm(标准) | 无畸变,视角自然 | "客观"对话镜头、日常场景 |
| 85mm(中长焦) | 背景虚化明显,压缩空间 | 特写情绪镜头、暧昧/亲密感 |
| 135mm+(长焦) | 强烈压缩感,背景完全虚化 | 偷窥视角、狙击/监视感、极端情绪特写 |

竖屏短剧因为观众在手机上观看,建议**默认焦段区间为35-85mm**,极少用广角(容易在小屏上显脸变形,尤其正脸特写)。

## 四、构图比例细则(可直接写入 `composition_ratio` 字段)

### 4.1 三分法与视觉重心
- 人脸五官关键点(双眼连线)落在画面上1/3分割线附近,竖屏建议略微上移至距顶部28-35%高度处(比横屏三分法更靠上,因为竖屏下方要给字幕/UI留空间)。
- 双人镜头中,主导角色(视觉重心)占据画面2/3侧,弱势/被动角色占1/3侧。

### 4.2 头部室与下巴室(Headroom / Chin room)
| 景别 | Headroom(顶部留白) | Chin room(下巴以下留白) |
|---|---|---|
| ECU | 2-5% | 几乎不留,下巴可略出画 |
| CU | 5-10% | 5-8% |
| MCU/MS | 8-12% | 视身体动作留8-15% |

### 4.3 正脸清晰度规则（仅用于项目要求清晰正脸的镜头）
- 主角正脸镜头(尤其首次登场)建议:焦段50-65mm、机位与眼睛等高、面光比不超过1:2(避免大阴影)、五官清晰占比不低于画面高度45%。
- 可在 prompt 中显式加入 `face_visibility: "full_frontal_clear"` + `lighting_ratio: "1:1.5_soft"`,与你已有的"面光需清晰、皮肤质感细腻光滑"要求直接呼应。

---

## 五、机位高度(Camera Height)标准值

| 类型 | 高度描述 | 情绪暗示 |
|---|---|---|
| 平视(Eye-level) | 与人物眼睛等高 | 平等、客观、日常对话默认值 |
| 微仰(Slight Low) | 低于眼睛10-20cm | 赋予角色权威感/压迫感(适合霸总/反派登场) |
| 强仰(Low Angle) | 低于腰部,大幅仰拍 | 崇拜、威慑、力量感爆发时刻 |
| 微俯(Slight High) | 高于眼睛10-20cm | 弱化角色、怜悯视角 |
| 强俯(High/Bird's-eye) | 明显俯视或鸟瞰 | 脆弱感、命运感、大场面调度 |

## 六、可直接套用的 Prompt 片段模板

```
[内反打 / OTS-MCU]
镜头类型: 过肩镜头(内反打),50-65mm等效焦段
构图: 前景人物背影占画面左侧18-22%宽度,虚化处理;
      焦点人物(女主)居中偏右,头顶留白8%,双眼位于画面上32%高度处
景深: 浅景深,前景虚化强度高,背景environments可辨认但不抢焦
视线: 女主视线投向左前方15-20°(看向前景人物方向),不直视镜头
面光: 柔光正面补光,面光比不超过1:1.5,避免大面积阴影,皮肤质感细腻
机位高度: 与女主眼睛等高
轴线: A侧(与本场景其余反打镜头共享同一轴线,不得跳轴)
```
