# 短剧分镜经验总结｜新对话使用版

用途：制作详细分镜时参考本指南。当前用户要求、剧本事实、已批准字段与 SKILL.md 优先；示例人物、资产 ID 和平台名称不自动用于新项目。SD2.0 部分只在对应工作流下使用，其他模型沿用其适用原则和用户指定格式。

---

## 1. 总目标

分镜不是把剧本翻译成画面，而是把剧情情绪、人物关系、台词气口和剪辑节奏重新设计成观众能看懂、能代入、能剪出来的镜头方案。

输出时必须同时包含：

1. 全集资产清单。
2. 人物、场景、道具、VFX 挂载 ID。
3. 每个 S 组的剧情任务、情绪任务、衔接方式。
4. 每个镜头的时长、景别、画面内容、人物调度/运镜、声音台词、尾帧/剪辑。
5. 每个 S 组的 SD2.0 Positive Prompt 和 Negative Prompt。
6. 台词和画面绑定说明。
7. 自检表。
8. 仅在用户明确要求或项目约定需要时提供 Word 版本。

---

## 2. 分镜核心原则

### 2.1 情绪优先

每个 S 组必须先判断“这一组要让观众感受到什么”，再安排画面。

常见情绪任务：

- 炫耀：角色不是站着说话，而是靠近、压低声音、拨弄道具、观察对方反应。
- 委屈：不要只写哭，要写手指、喉咙、呼吸、眼神躲闪、衣料被抓皱。
- 冷眼看戏：角色不哭不崩溃，静静观察对手走向毁灭。
- 震惊：不是大张嘴，而是呼吸停住、肩颈僵住、眼神短暂失焦。
- 安抚：靠手的落点、身体遮挡、低声鼓励、视线稳定来表现。
- 史诗感：用事件因果、空间层级、人物站位和声画节奏制造，不靠乱堆大场面。

### 2.2 故事叙事优先

每个镜头都要回答一个问题：观众为什么需要看到这个画面？

避免：

- 空镜太多。
- 大量无台词画面拖 20-30 秒。
- 镜头只好看但不推进剧情。
- 台词说的是 A，画面拍的是 B。
- 道具出现却没有解释。
- 前后 S 组突然跳戏，不好剪辑。

## 3. S 组规则

### 3.1 时长

默认每个 S 组控制在 15 秒以内；用户指定其他上限时，以指定上限为准。

建议：

- 10-13 秒：适合快节奏冲突。
- 13-15 秒：适合情绪峰值、长台词、反转。
- 超过当前时长上限时拆组，保持台词与动作连续。

### 3.2 每组至少有一个明确情绪钩子

一个 S 组不能只是“人走、人看、人站”。必须有情绪变化：

- 轻蔑变僵硬。
- 强撑变松动。
- 疼痛变决断。
- 炫耀变失控。
- 隐忍变反击。

### 3.3 台词与无台词组

按原剧本配置台词，不为填满 S 组添加对白、OS 或旁白。无台词组仍须写清触发、情绪承受者、沉默者、身体或道具反应和稳定终态，并禁止意外口型；用动作因果、环境声和反应推进。

## 4. 景别规则

必须牢记：

| 景别 | 负责内容 | 使用原则 |
|---|---|---|
| 远景 | OS、心境、孤独、命运感 | 少用，主要承载氛围和心理距离 |
| 全景 | 故事发展、空间关系 | 少用，避免 SD 生成多人穿帮 |
| 中景 | 调度、动作逻辑、人物位置关系 | 用来讲清谁从哪来、谁挡住谁、谁靠近谁 |
| 近景 | 对峙、台词、人物关系 | 台词戏主力景别 |
| 特写 | 表情、情绪、手部、道具证据 | 情绪爆点和信息锚点 |

经验规则：

- 情绪戏尽量用近景、特写、中近景。
- 动作因果用中景。
- OS 和心境可以用远景，但不要滥用。
- 全景容易让 SD 乱生人物，必须谨慎。

---

## 5. 台词与画面协调规则

### 5.1 台词时长

台词必须有足够时间说完。

以下仅为无音频时的粗略估算；已有音频时优先实测，并注明时长依据：

- 短句 1-4 个英文词：1.2-1.8 秒。
- 普通句 5-9 个英文词：2.2-3.5 秒。
- 长句 10-16 个英文词：3.8-5.5 秒。
- 超长句必须拆镜，不能塞进 1.8 秒。

严禁：

- 1.8 秒塞完整长句。
- 一句长台词只给一个静态脸。
- 台词没有说话人画面，也没有听者反应。

### 5.2 台词画面绑定

每句台词必须绑定以下至少一种画面：

- 说话人近景。
- 听话人反应。
- 手部动作。
- 道具证据。
- 站位变化。
- 情绪特写。

示例：

| 台词内容 | 画面绑定 |
|---|---|
| 身份宣告 | 皇冠、法令、印记、众人低头 |
| 委屈控诉 | 喉咙吞咽、手指抓皱衣料、眼神不看对方 |
| 安抚鼓励 | 握手、扶肩、遮挡风、低声靠近 |
| 炫耀挑衅 | 贴近耳边、轻笑、观察对方反应 |
| 反转确认 | 道具入前景、角色呼吸停住、下颌僵住 |

### 5.3 表演气口

长台词要拆气口：

- 前半句给说话人。
- 中间切听者反应。
- 后半句落到道具或情绪特写。
- 台词后留 0.5-1 秒反应，不要马上切走。

## 6. 人物表演设计

不要只写“伤心、愤怒、震惊”，要写可生成、可表演的细节。

### 6.1 表情细节

- 眼神短暂失焦。
- 眼睫沉下。
- 下颌僵住。
- 下颌绷紧后放松；无台词镜头保持嘴唇闭合，避免意外口型。
- 呼吸停半拍。
- 喉咙轻轻吞咽。
- 眼神从轻蔑变成僵硬。
- 嘴角笑意慢慢消失。

### 6.2 手部细节

- 指尖抓皱衣料。
- 手套发抖但压得很稳。
- 手指从道具上慢慢松开。
- 指节发白后放松。
- 指尖停在对方肩侧，没有继续推进。
- 手从保护姿态转为主动伸出。

### 6.3 身体细节

- 肩颈轻僵。
- 半步靠近。
- 后退半步。
- 身体被风压逼退。
- 胸口起伏慢慢平下来。
- 下巴轻轻抬起。
- 站到对方前方。

## 7. 组间衔接规则

每个 S 组必须有“尾帧/剪辑”设计，方便剪辑。

常用衔接方式：

- 动作衔接：手伸出 -> 下一组抓住。
- 道具衔接：卷轴展开 -> 下一组宣读。
- 声音衔接：脚步声入 -> 下一组人物进场。
- 视线衔接：角色看向门口 -> 下一组门口人物出现。
- 情绪衔接：呼吸停住 -> 下一组冲突爆发。
- 光影衔接：火光压下 -> 下一组冷光空间。

避免：

- 上一组还在庭院，下一组突然卧室，没有过渡。
- 上一组人物在动，下一组人物突然换位置。
- 上一组说的情绪，下一组完全不接。

## 8. SD2.0 挂载与提示词规则

### 8.1 每组列明所需挂载

格式：

```md
本组挂载：`@角色-状态(ID)`、`@场景(ID)`、`@道具(ID)`、`@VFX(ID)`
```

仅绑定已存在或明确批准的资产；缺失资产标注待补，不虚构原生素材 ID。文字挂载表不等于平台原生引用已保存。

人物可按实际剧情状态拆 ID：

- 火场状态。
- 重生状态。
- 女仆状态。
- 龙堡状态。
- 怀孕状态。
- 觉醒状态。
- 战斗状态。
- 失忆状态。

道具也按持有人/状态拆 ID：

- 戒指在谁手里。
- 皇冠是否被举起。
- 法令是否展开。
- 药剂是否在前景。

### 8.2 Positive Prompt 写法

必须具体描述：

- 人物状态。
- 场景。
- 景别倾向。
- 情绪。
- 手部动作。
- 关键道具。
- 光线和氛围。
- 防止误解的限制。

示例：

```md
SD2.0 Positive Prompt：
`realistic cinematic fantasy drama, Diana alone in close-up, dry eyes no tears, restrained stunned expression, shallow breath pausing then settling, fingers gripping black gold dress fabric, clean empty stone pillar background, shallow depth of field, solemn public recognition, character micro expressions`
```

### 8.3 Negative Prompt 写法

必须防止：

- 重复人物。
- 背景乱生人。
- 同脸复制。
- 错误道具。
- 夸张光效。
- 字幕水印。
- 低质肢体。

示例：

```md
S组生成反向约束：
`crowd, background people, extra people, duplicate faces, cloned face, same character twice, multiple Diana, multiple Leona, group shot, wide crowd tableau, subtitles, text, watermark, bad hands, extra fingers, deformed anatomy`
```

## 9. 防穿帮规则

### 9.1 人脸一致性

以下是出现重复人脸问题时的构图选项，不得覆盖剧本规定的可见人数、已批准走位、OTS 肩归属和背景锚点。仅在当前镜头适用时采用单人模板。每个 S 组尽量控制同时清晰的主脸数量。

经验：

- 情绪戏最好一镜一个清晰人物脸。
- 多人关系靠切镜，不靠同框。
- 不承担信息任务的背景人物可虚化、用背影或侧影；需要清晰露脸时按剧本保留。
- 如果 SD 总是生重复人脸，立刻改成单人近景/特写。

### 9.2 防重复人物写法

不要写：

- 远处站着一群人。
- 背景里有人看着。
- 两人对面站着，旁边还有侍从。
- 对方虚在远处。

改写成：

- 背景只保留空石柱。
- 暗墙虚化。
- 只拍单人近景。
- 只拍手部特写。
- 另一个角色只用画外视线承接。

### 9.3 单人镜头模板

```md
AI防穿帮卡：本组每个镜头只允许一个清晰人物；背景只保留空石柱、暗墙、卷轴边缘或道具虚化；一镜一张清晰脸，同一角色不得在同一画面重复出现。
```

## 10. 禁止和慎用画面

未获剧本或用户支持时，避免添加以下可能造成穿帮或偏离风格的描述；如属于明确剧情要求，保留事实并设计适合目标平台的表达，不将这些词作为跨项目禁词：

- 月纹。
- 眼睛冒光。
- 瞳孔发光。
- 身体发光。
- 人体自带光效。
- 发亮、亮起、发光。
- 露骨。
- 血腥。
- 莫名其妙空镜。
- 不解释的白布、无意义遮挡物。

可以替代为：

- 金属反光。
- 卷轴压印。
- 风压。
- 衣摆变化。
- 石屑、尘粒。
- 冷光落在手背。
- 烛光压低。
- 空气变静。

## 11. 常见问题与修正经验

### 11.1 画面看不懂

原因：

- 台词没有画面锚点。
- 关键因果没拍。
- 道具突然出现。
- 角色表情和剧情不匹配。
- 背景人物太多，SD 生成混乱。

修正：

- 把画面改成“证据链”：道具 -> 角色反应 -> 关系变化 -> 结果。
- 减少同框，改成单人近景接反应。
- 给每句台词一个明确画面落点。

### 11.2 情绪不对

原因：

- 把女主写哭了，但她此刻应该冷静看戏。
- 把炫耀写成普通站立对话。
- 把痛苦写成静态表情。
- 把史诗感写成大场面堆砌。

修正：

- 先判断人物此刻心理优势/劣势。
- 用身体细节表现情绪。
- 不要滥用哭。
- 让情绪通过对方反应升级。

### 11.3 台词太快

原因：

- 长英文句塞进 1-2 秒。
- 没有拆句。
- 没有气口。

修正：

- 长句拆成多个镜头。
- 中间切听者反应。
- 一句台词后留表情落点。

### 11.4 S 组衔接跳

原因：

- 上组尾帧没有设计。
- 下一组开头没有承接动作/声音/视线。

修正：

- 每组都写清尾帧。
- 下一组首镜必须接住上一组最后一个动作、声音或道具。

### 11.5 SD 生成重复人物

原因：

- 提示词里有 crowd、background people、attendants。
- 画面内容写了多人同框。
- 同组挂载人物太多。
- 背景虚化人物也被 SD 当成主角生成。

修正：

- 改成单人近景。
- 另一个角色用画外声音/视线方向承接。
- Negative Prompt 加 `duplicate faces, cloned face, same character twice, background people, extra people`。
- 本组挂载减少露脸角色。

## 13. 自检清单

每次输出前必须自检：

| 检查项 | 标准 |
|---|---|
| S组时长 | 默认每组不超过 15 秒，或遵循用户指定上限 |
| 台词时长 | 长句不塞进短时长 |
| 台词画面绑定 | 每句台词都有对应画面或反应 |
| 情绪准确 | 人物状态符合剧情，不乱哭不乱崩 |
| 景别合理 | 远景管心境，全景管故事，中景管调度，近景管台词，特写管情绪 |
| 组间衔接 | 上组尾帧能接下组首镜 |
| 人脸一致 | 同组主脸明确，避免重复人物 |
| 防穿帮 | 没有容易生成错误的背景人、重复人、奇怪光效 |
| SD提示词 | Positive/Negative 都完整 |
| 光效与风格 | 不添加剧本或用户未要求的纹样、人体光效等元素 |
| Word输出 | 仅在明确要求时生成并验证可打开 |

## 14. 新对话使用提示词

可以直接复制下面这段给新的对话：

```md
请参考《短剧分镜经验总结｜新对话使用版》，以当前剧本、用户约定和 SKILL.md 为准。

你是成熟短剧导演，不只是整理剧本，而是要根据爆款短剧逻辑做分镜：情绪优先、故事因果清楚、台词画面绑定、每个 S 组默认 15 秒以内（用户另定上限时从其约定）、每句台词有足够气口、每个镜头有景别和运镜、每组有 SD2.0 挂载提示词，并做自检。

景别规则：
远景管 OS 和心境；全景管故事发展；中景管调度和逻辑；近景管对峙和台词；特写管表情、手部和情绪。

不添加剧本或用户未要求的纹样、人体光效、无意义空镜或遮挡；避免重复人物和背景乱生人，保留已锁定的空间信息。

如果台词太长，不要强塞短时长，要拆镜、切听者反应、给气口。  
如果画面看不懂，要用证据链、人物反应、道具锚点和组间衔接重构。  
如果 SD 容易穿帮，要改成单人近景/特写，一镜只保留一个清晰人物脸。

输出：资产清单 + 用户指定格式的完整分镜 + 适配目标模型的 Positive/Negative Prompt + 自检；仅在用户要求时附 Word 文件。
```

## 15. 关键判断标准

一版分镜好不好，不看文字多不多，而看：

1. 观众能不能一眼看懂发生了什么。
2. 情绪是不是跟人物此刻心理一致。
3. 台词是不是有对应画面。
4. 镜头能不能剪。
5. SD2.0 会不会乱生人、乱生道具、乱生光效。
6. 每个 S 组是不是都有明确起点、变化和尾帧。

最终标准：画面清楚、情绪准确、台词能说完、剪辑能接上、生成不穿帮。
