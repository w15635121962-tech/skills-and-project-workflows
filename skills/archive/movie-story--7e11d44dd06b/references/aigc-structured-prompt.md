# AIGC 结构化提示词 — 电影级关键帧生成

将编程思维引入 AI 图像提示词，以固定语法结构表达创作指令，消除歧义，稳定输出质量。

> 核心理念：就像给 AI 一份明确的分镜单 + 厨师指定 + 菜谱细节，而不是含糊地说"拍一个好看的画面"。

---

## 一、9 组件完整模板（AI 图像生成专用版）

适用于 Hero Shot、关键帧等需要最高质量输出的场景。

```markdown
# Role: [角色设定 — AI 此刻是摄影师/灯光师/美术师]

## Profile:
- author: [创作者]
- version: [版本号，便于迭代追踪]
- language: [中文/English]
- description: [角色专业背景、审美偏好、擅长风格]

## Goals:
- [目标1 — 这张图要传达什么情绪/信息]
- [目标2 — 要达到什么技术标准]
- [目标3 — 要呈现什么视觉风格]

## Constrains:
- [禁止项1 — 不要什么]
- [禁止项2 — 避免什么 AI 常见错误]
- [禁止项3 — 不要的画风/构图]

## Rules:
- [规则1 — 必须遵循的视觉原则]
- [规则2 — 构图/光影/色彩的硬性要求]
- [规则3 — 技术质量底线]

## Skills:
- [能力1 — 摄影师技能]
- [能力2 — 灯光师技能]
- [能力3 — 美术指导技能]

## Example:
- [参考画面描述 — 少样本参考]

## Workflows:
- [步骤1 — 构建画面骨架]
- [步骤2 — 注入光影层次]
- [步骤3 — 增强真实感细节]
- [步骤4 — 角色一致性校准]
- [步骤5 — 输出最终提示词]

## Initialization:
"[冷启动引导 — 告知用户当前状态]"
```

## 二、简洁 4 要素框架（快速版）

适用于常规分镜镜头的提示词，在保持质量的同时提高效率。

| 要素 | 英文 | 说明 | 电影提示词映射 |
|------|------|------|---------------|
| **角色** | Role | AI 此刻的身份 | "作为电影摄影师，以 Roger Deakins 的风格…" |
| **任务** | Task | 要生成的画面 | "生成一个低角度过肩镜头，角色站在雨中…" |
| **要求** | Requirement | 技术条件和限制 | "35mm 镜头，f/2.8 浅景深，2.39:1 画幅比…" |
| **提示** | Cue | 背景和上下文 | "这是黑色电影风格，角色刚失去了一切…" |

### 4 要素模板
```
角色：[摄影师/灯光师/概念艺术家身份 + 风格参照]
任务：[精确描述画面内容，含构图、动作、情绪]
要求：[技术参数：镜头/光圈/灯光/色彩/画幅比]
提示：[叙事上下文：这场戏在讲什么，观众该感受什么]
```

## 三、提示词生成器模式（元 Prompt 优化）

让 AI 成为"提示词创建专家"，帮你优化初始提示词。

### 工作流程
1. **设定角色** — 将 AI 设定为"AIGC 电影提示词优化专家"
2. **输入初始提示词** — 提供你当前想要优化的提示词
3. **AI 生成改进版** — AI 分析薄弱环节并输出优化版本
4. **对比选择** — 对比原版与优化版，选取最佳或继续迭代

### 应用场景
- 初始提示词质量不够，画面效果不理想
- 需要针对特定 AI 图像模型（Midjourney / SD / DALL·E）优化
- 希望同一画面生成多种风格变体

### 示例
```
原始提示词：「夜晚的城市街道，下雨」
→ 输入提示词优化器 →
优化后：「低角度广角镜头，雨夜曼哈顿街道，湿漉漉的沥青反射霓虹灯光，
青色与品红色调，体积雾笼罩街灯，35mm 电影镜头，Blade Runner 2049 风格，
FilmGrain 16mm，前景有模糊的出租车尾灯拖影」
```

## 四、少样本提示模式（风格锚定）

通过提供 1-3 个参考示例，精确引导 AI 的画面风格和输出格式。

### 工作流程
1. **提供参考示例** — 给出 1-3 个高质量提示词范例
2. **标注关键特征** — 指出示例中需要保持一致的元素
3. **新的输入** — 提供新的场景描述
4. **AI 匹配风格** — 生成与参考示例风格一致的新提示词

### 电影分镜场景示例

**参考示例 A — 动作戏手持镜头：**
```
手持摄影 28mm广角 | 低角度跟拍 | 镜头随角色奔跑节奏晃动 |
快门速度 1/250s 冻结动作瞬间 | 高对比度冷暖撞色 |
尘土颗粒悬浮于逆光 | 《谍影重重》近身格斗质感
```

**参考示例 B — 情感对话特写：**
```
85mm 定焦 f/1.4 极致浅景深 | 眼睫毛边缘柔焦过渡 |
窗边柔光 + ¼ CTO + 负 fill 增强面部立体感 |
表演：嘴唇微启未说出的词 + 睫毛颤动 + 瞳孔微扩 |
Kodak Portra 400 肤色科学 | 《燃烧女子的肖像》质感
```

### 新输入（锚定输出）：
"请用示例A的动作镜头语言，描述一场雨中追车戏的关键帧"

## 五、结构化提示词在电影分镜中的应用矩阵

| 场景类型 | 推荐模板 | 关键增强维度 | 风险点 |
|---------|---------|-------------|--------|
| **Hero Shot** | 9组件完整版 | Profile(风格参照) + Rules(构图规则) + Example(参考画面) | 风格漂移 |
| **对话特写** | 4要素快速版 + 少样本 | Requirement(镜头参数) + Cue(情绪上下文) | 塑料脸 |
| **动作/打斗** | 9组件完整版 | Skills(手持/运动) + Workflows(多角度覆盖) | 构图混乱 |
| **场景确立** | 4要素快速版 | Task(空间关系) + Requirement(光影方案) | 比例失真 |
| **情绪空镜** | 4要素 + 少样本 | Cue(情绪上下文) + 少样本风格锚定 | 空洞无物 |
| **多人调度** | 9组件完整版 | Rules(180°规则) + Constrains(人物关系) | 角色混淆 |

## 六、迭代版本管理

每个关键提示词保留版本记录，便于 A/B 测试和持续优化：

```markdown
## SHOT_023_HERO 提示词迭代记录

### v0.1（初版）
[原始提示词]

### v0.2（增强光影）
[增加体积光 + 电影参考]
→ 效果：光影层次提升，但角色面部偏暗

### v0.3（平衡曝光 + 角色圣经对齐）
[添加 fill light + 引用 Olivia 角色圣经]
→ 效果：面部细节清晰，角色一致性良好 ✅ 当前版本
```

## 七、核心原则总结

1. **结构先于内容** — 先搭框架，再填细节，避免想到哪写到哪
2. **版本化管理** — 每个 Hero Shot 提示词保留迭代记录
3. **少样本锚定** — 2-3 个高质量示例比长篇理论更有效
4. **约束驱动质量** — "不要什么"往往比"要什么"更能提升品质
5. **角色一致性优先** — 所有人物提示词必须引用角色圣经
6. **问 AI 学技能** — 不确定某类画面该具备什么参数时，直接问 AI 推荐
