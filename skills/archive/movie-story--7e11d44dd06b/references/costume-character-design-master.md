# 服化道角色设计 (Costume & Character Design Master)

## 核心原则

服装、化妆、道具（服化道）是角色外化的第一语言。观众在角色开口之前，已经通过外表"读"到了角色的身份、性格、状态和故事。

---

### 第二步：服装设计

#### 服装叙事功能

| 功能 | 说明 | 示例 |
|------|------|------|
| 身份标识 | 服装反映角色职业和社会地位 | 医生白大褂、军人制服 |
| 性格外化 | 服装风格映射性格特征 | 整洁西装→控制欲强；宽松衣物→随性 |
| 状态变化 | 服装随角色状态变化而变化 | 开场西装笔挺→结局衣衫褴褛 |
| 关系暗示 | 角色间服装的呼应或对比 | 情侣穿互补色、对手穿相似色 |
| 隐喻象征 | 服装作为视觉隐喻 | 红裙象征危险、白色象征纯洁 |
| 时间锚定 | 服装反映时代背景 | 70年代喇叭裤、2020年代卫衣 |

#### 服装设计要素

```
层次结构（从内到外）：
├── 贴身层：内衣/背心/打底衫
├── 中间层：衬衫/毛衣/夹克
├── 外层：外套/大衣/风衣
├── 下装：裤子/裙子
├── 脚部：鞋子/靴子
└── 配饰：手表/眼镜/项链/戒指/帽子/围巾/包
```

#### 服装状态描述模板

```markdown
**[角色名] — [场景名] 穿着**

- 上装：[具体描述，含颜色、材质、品牌风格]
- 下装：[具体描述]
- 鞋子：[具体描述]
- 外套：[如有]
- 配饰：[逐一列出]
- 穿着状态：[整洁/微乱/破损/污渍]
- 与开场的变化：[描述服装如何反映角色变化]
```

### 第三步：化妆设计

#### 化妆强度等级

| 等级 | 描述 | 适用角色 | 关键词 |
|------|------|----------|--------|
| 0级 - 素颜 | 无妆容，自然肌肤 | 学生、运动员、日常角色 | "no makeup, natural skin" |
| 1级 - 裸妆 | 轻微修整，看不出化妆 | 职场女性、日常优雅 | "natural makeup, subtle" |
| 2级 - 日常妆 | 可见但不过分 | 大多数角色默认 | "light makeup, natural look" |
| 3级 - 精致妆 | 完整妆容，精心打扮 | 派对、约会、重要场合 | "full makeup, polished" |
| 4级 - 浓妆 | 明显的妆容风格 | 夜店、戏剧化角色 | "heavy makeup, dramatic" |
| 5级 - 特效妆 | 包含特效元素 | 伤妆、老化、非人类 | "special effects makeup" |

#### 特殊妆效

- **伤妆**：淤青（紫蓝色渐变）、割伤（红色线条+血迹）、擦伤（红肿）
- **老化妆**：皱纹（细线纹路）、色斑、发色灰白
- **病态妆**：苍白、黑眼圈、嘴唇发白、肤色蜡黄
- **泪痕妆**：眼下泪痕、微红的眼眶

### 第四步：发型设计

| 类型 | 描述 | 适用 | AI 关键词 |
|------|------|------|-----------|
| 短发 | 干练、清爽 | 职场、运动型角色 | "short hair, neat" |
| 长直发 | 柔和、自然 | 温柔型角色 | "long straight hair" |
| 卷发 | 个性、浪漫 | 艺术型、复古角色 | "curly hair, wavy" |
| 束发 | 利落、专业 | 专业人士、运动 | "tied-up hair, ponytail" |
| 乱发 | 不羁、状态差 | 沮丧、疯狂、刚醒 | "messy hair, disheveled" |

## 二、角色设计速查模板

### 现代都市角色

```
职业白领（男性）：
- 衬衫（白/浅蓝）+ 西裤（深灰/黑）+ 皮鞋
- 腕表、公文包
- 发型：整洁短发，偏分
- 状态指示：领带松紧=压力程度

职业白领（女性）：
- 套装/衬衫+半裙/西裤 + 中跟鞋
- 简约首饰（耳钉、项链）
- 发型：职业束发或自然短发
- 状态指示：妆容精致度=心理状态

学生（高中/大学）：
- T恤/卫衣 + 牛仔裤/运动裤 + 运动鞋
- 书包、耳机
- 发型：随意自然
- 个性化：通过配饰（手机壳、贴纸）展示个性

创意工作者：
- 层次穿搭，混搭风格
- 复古/设计师单品
- 帽子、围巾等特色配饰
- 发型：偏个性（渐变、染色、不修边幅）
```

### 时代角色适配

| 时代 | 男性 | 女性 |
|------|------|------|
| 1920s | 西装三件套、礼帽 | Flapper裙、波波头、珍珠项链 |
| 1950s | 灰法兰绒西装、窄领带 | 收腰连衣裙、细高跟鞋 |
| 1970s | 喇叭裤、花衬衫 | 迷你裙、厚底鞋、长发 |
| 1980s | 宽肩西装、高腰裤 | 垫肩、亮色、大耳环 |
| 1990s | 格子衬衫、宽松牛仔裤 | 碎花裙、短上衣 |
| 2000s | 低腰裤、刺青文化 | 低腰牛仔裤、小背心 |

## 三、AI 绘画服化道提示词模板

```
[角色描述], wearing [服装详细描述], 
[发型描述], [化妆描述],
[配饰描述], [服装状态描述],
photorealistic, detailed fabric texture, 
natural lighting
```

### 示例
```
a 35-year-old Asian woman, wearing a wrinkled white 
blouse with sleeves rolled up to elbows, dark slim 
fit jeans, small silver necklace, hair in a messy 
low bun with loose strands, light natural makeup 
with slight dark circles under eyes, looking tired 
but determined, photorealistic, detailed fabric 
texture, soft natural light from window
```
