# 分镜时间轴：逐秒情绪/动作拆解法

## 核心思路

将一段视频按**秒级精度**拆解人物的表情、动作和情绪变化，写出自然过渡的时间线。适用于 AI 视频提示词中需要「复杂微表情」或「情绪递进」的场景。

---

## 格式结构

```
[整体描述：景别/运镜/人物状态]

[逐秒时间轴]
0-2秒: [初始状态]
2-4秒: [第一个变化]
4-6秒: [第二个变化]
6-8秒: [第三个变化]
8-9秒: [收尾状态]

[总结：整体情绪弧线]
```

---

## 示例：微表情递进

**整体描述**
中景镜头，无运镜，保持固定构图。人物穿着传统服饰，保持半躺姿势。

**逐秒时间轴**
```
0-2秒:
保持安静的表情，长发散落。眼神里有暗沉的神韵，嘴唇低低地抿着。

2-4秒:
情绪开始微变化。嘴角慢慢轻扬起来，下颚微微收，点下巴的细小动作。

4-6秒:
仍然有察觉不到的微妙变化。眉头舒展又轻皱，眼眶微微泛红，像眼泪快要掉落的瞬间。

6-8秒:
人物在安静呆滞的表情中，像在努力压抑什么。但这里有隐忍的崩溃感，没有大哭。

8-9秒:
情绪归于平静，但眼神里留下了湿润的痕迹。安静，但不再空白。
```

**总结**
整个过程表情自然过渡，没有夸张变化。情绪弧线：平静 → 微喜 → 悲伤预兆 → 压抑崩溃 → 余韵平静。适用于 AI 视频中的微表情细腻表演。

---

## 关键技巧

| 原则 | 说明 |
|------|------|
| **每个时间段只做一件事** | 2秒内只描述一种状态或一个变化 |
| **动词优先** | 用「轻扬」「舒展」「抿」「收」等精确动词代替形容词 |
| **过渡自然** | 相邻时间段的状态要有逻辑衔接，不能跳跃 |
| **细节补位** | 睫毛、嘴角、眉头、肩膀 — 微部位动作比大动作更真实 |
| **情绪写「弦外之音」** | 不写「她哭了」，写「眼眶泛红」「睫毛湿润」「嘴唇颤抖」 |

## 与 AI 提示词的对接

将时间轴转化为 AI 视频提示词时：

```
中景固定镜头，无运镜。传统服饰女子半躺。
表情从安静到微含笑意，眼神逐渐忧伤，
眉头轻皱，眼眶泛红，一滴泪将落未落，
最后归于平静但眼眶湿润。
Sony Venice 2, 50mm f/1.2, 暖调自然光, 35mm胶片质感
```

注意：AI 视频不需要逐秒写入，而是把「情绪弧线」压缩成连贯的一句话描述。
