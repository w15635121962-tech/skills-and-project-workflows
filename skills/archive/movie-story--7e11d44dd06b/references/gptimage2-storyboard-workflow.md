# GPTimage2 故事板 + Seedance2.0 电影级工作流

> 来源：设计师阿哲 — 一张图直出15秒电影

## 核心思路

**单张图 = 赌博；完整故事板 = 导演。**

故事板是一张包含完整「导演分镜板」的图：
- 角色设定（正面/侧面/背面/特写）
- 场景设计（概念图 + 俯视机位图）
- 8 个分镜（景别/运镜/情绪）
- 灯光过渡、色彩板、音频参考

把这张完整规划表喂给 Seedance2.0，等于告诉它：「这是整个剧本，你照着拍。」

---

## 两步工作流

### 第一步：GPTimage2 生成故事板

**8 个分镜剧情**（示例：深夜便利店重逢）

1. 凌晨2:17，便利店。女主独坐窗边，关东煮冒着热气。玻璃门外暴雨如注。远景，静态。
2. 门铃响，男主收伞进门，视线穿过货架定格她背影。中景，手持微晃。
3. 女主从玻璃反光看见他，手指攥紧纸杯，指节发白。没回头。特写，静态。
4. 男主走向冰柜，拿起她爱喝的乌龙茶，手指在瓶身停了一秒。中近景，缓推。
5. 女主转身，两人视线相撞。她嘴角动了一下，没笑。他捏皱了标签。双人过肩，手持。
6. 女主起身经过他身边，肩膀几乎擦到，停顿0.5秒。微距+中景。
7. 女主推门走入暴雨，没撑伞。男主追到屋檐下停住。远景，拉远。
8. 女主背影消失街角。男主低头看表——2:24，拧开乌龙茶喝一口，过期三个月，涩得皱眉。特写。

**故事板五大模块**

| 模块 | 内容 |
|------|------|
| 顶部栏 | 镜头数量、画幅、统一调色板、环境、风格基调、节奏 |
| 角色与风格参考 | 多角度模型（正面/侧面/背面/特写）、服装配饰参考 |
| 环境与场景设计 | 场景概念图、俯视机位图（标注镜头移动路径） |
| 故事板（8个镜头） | 摄像机类型、镜头大小、运动方式、动作情绪描述 |
| 灯光/情绪/风格备注 | 光线条件、氛围、纹理、时间过渡 |

**关键技巧**
- 必须开 Thinking 模式（复杂排版质量差距巨大）
- 加「所有分镜同一画风、同一色调、同一角色」
- 角色设定写在提示词开头，所有分镜保持一致
- 中文文字出错就迭代修改

### 第二步：Seedance2.0 生成视频

**核心原则：只写"运动"，不写"画面"**（画面已在故事板里）

```
根据提供的故事板，生成一镜到底的15秒视频。

【运镜要求】
- 0-2秒：远景缓慢推进，跟随女主背影，风雪中轻微手持抖动
- 2-4秒：切中近景，镜头轻摇向上，跟随女主抬头动作
- 4-7秒：大全景，快速跟拍恶龙俯冲轨迹，女主翻滚闪避
- 7-10秒：低角度手持跟踪，跟随女主起身冲锋
- 10-15秒：慢动作，镜头环绕女主180度，定格斧刃劈下

【核心要求】
- 一镜到底，不要切镜头
- 运镜有合理动机，跟随角色动作自然过渡
- 无字幕、无解说
- 画面风格与故事板一致
- 角色外貌/服装必须与故事板完全一致
- 动作自然，有微表情和呼吸感
```

## 提示词模板

### 模板一：故事板生成

```
【故事板提示】：（剧情类型）
（1-8可替换成自己的故事情节）

1) （镜头1：建立场景，远景/静态，氛围描述）
2) （镜头2：角色A入画，中景，动作+情绪）
3) （镜头3：角色B反应，特写，情绪递进）
4) （镜头4：冲突/转折，中近景，动作升级）
5) （镜头5：高潮瞬间，大全景/快速运镜）
6) （镜头6：细节特写，微距，情绪顶点）
7) （镜头7：角色反应，中景，情绪回落）
8) （镜头8：定格/收尾，远景/静态，余韵）

【格式要求】
创建一个电影制作板/视觉规划表，比例16:9，展示短片的完整概念。布局简洁、基于网格，分为清晰标记的部分。包含：
- 共享创意指导（顶部栏）：镜头数量、统一调色板、环境背景
- 角色与风格参考：多角度模型（正面/背面/侧面/特写），服装配饰参考
- 环境与场景设计：场景概念图 + 俯视机位图（标注移动路径和摄像机位置）
- 故事板：8个编号帧，每个包含：摄像机类型、镜头大小、运动方式、动作情绪描述
- 灯光/情绪/风格备注：光线条件、氛围、纹理、时间过渡
```

### 模板二：角色设定表

```
请为以下角色生成专业角色设定表：

【角色信息】
Name: / Alias: / Role: / Age:
Personality: / Core Theme:

【设定表要求】
1) 全身多角度：正面、3/4侧面、侧面、背面，带身高比例尺
2) 表情变化：8种情绪（Neutral, Curious, Worried, Surprised, Afraid, Sad, Determined, Relaxed）
3) 细微表情：Subtle Eye Tension, Slight Smirk, Lip Tension, Controlled Breath
4) 头部多角度：3/4, Side, Top, Low, Diagonal
5) 标准站姿 + 5种姿势变化
6) 服装材质特写：4种细节
7) 武器/道具特写
8) 手部姿势：5种手势

【色彩板】（5-8个关键词）
【风格】（风格描述）
```

## 六大避坑

| 阶段 | 坑 | 解法 |
|------|-----|------|
| GPTimage2 | 中文乱码 | 开Thinking模式；出错迭代修改 |
| GPTimage2 | 风格不一致 | 加「同一画风、同一色调、同一角色」 |
| GPTimage2 | 角色崩了 | 上传角色设定表作为参考 |
| Seedance2.0 | 第一帧显示故事板 | 剪掉第一秒；或前两格用同一张图缓冲 |
| Seedance2.0 | 镜头乱切 | 加「一镜到底」；检查时间戳连续性 |
| Seedance2.0 | 角色脸崩 | 上传角色设定表；减少视频提示词里的画面描述 |

---

## 高阶技巧

1. **动机驱动运镜**：不要说「镜头推进」，要说「女主抬头时，镜头自然推到她面部」
2. **时间戳精确控制**：关键镜头给足时间，过渡镜头短一些，总和等于目标时长
3. **角色锁定三重保险**：角色设定表 → 故事板内一致性 → Seedance2.0 多图参考
4. **迭代思维**：快速初版 → 针对性修改 → 再生成 → 重复3-5轮
5. **A/B 测试**：同一创意生成不同风格故事板，对比效果
