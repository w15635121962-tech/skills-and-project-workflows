# 故事板五色标记系统 (Storyboard Color-Coding System)

来源：「镜外之魂-详解版」— 角色板 + 故事板联动工作流

## 核心思路

在手绘/设计故事板时，用**五种颜色**区分不同类型的运动和信息。这套系统可以：
1. 让 AI 理解复杂的镜头调度
2. 角色板 + 故事板联动，大幅提升 AI 视频抽卡效率
3. 在「一张图」故事板中同时传达角色、运镜、灯光、声音四个维度的信息

---

## 五色标记系统

| 颜色 | 标记内容 | 示例 |
|------|----------|------|
| 🔴 **红色箭头** | 身体/肢体运动 | 手指抬起、头部转动、肩膀微耸、行走方向 |
| 🔵 **蓝色箭头** | 摄影机/摄像机运动 | 慢推、横摇、上升、环轨、dolly zoom |
| 🟢 **绿色标记** | 取景/构图笔记 | 三分法构图线、视线方向、画面留白 |
| 🟠 **橙色标记** | 灯光方向与类型 | 主光方向、逆光源位置、柔光/硬光标注 |
| 🟣 **紫色标记** | 声音/情感强调 | 配乐起、对白情绪、音效节点 |

## 故事板制作流程

### 第一步：剧本 → 角色板
- 提取全部人物，画出角色设定（正/侧/背三视图）
- 标注角色核心特征：发型、服装、标志性动作、身高比例

### 第二步：剧本 → 分镜拆解
```
不用时间限制，一个连贯镜头拍完最具戏剧性的情绪高潮段落
```

### 第三步：分镜 → 故事板（黑白线稿）
- 每个镜头画出手绘风格的黑白草图
- 参考电影级艺术风格运镜
- 关键动作标注：手部动作、慢摇、环摇、歪头、脸部旋转

### 第四步：套五色标记
- 按规则标记每个维度的信息
- 检查：一个画面的信息量不能过大（AI 视频单帧能理解的上限约 3-5 个要素）

### 第五步：故事板 → AI 提示词
- 将五色信息转化为自然语言提示词
- 红色 → 人物动作描述
- 蓝色 → 运镜关键词
- 绿色 → 构图指令
- 橙色 → 灯光描述
- 紫色 → 氛围/情感基调

## 实战要点

| 要点 | 说明 |
|------|------|
| **先做角色板再做故事板** | 角色一致性是 AI 视频最大的坑，角色板是保险 |
| **黑白线稿即可** | 故事板不需要上色，五色标记才是信息载体 |
| **一张镜头一个情绪高潮** | 不追求「讲完一个故事」，而是「拍好一个时刻」 |
| **镜头内的情绪标签** | 黑色文字写镜头情感/每帧画面标签 |
| **聚光灯收尾** | 最后给视线尽头一个聚光灯收束，是电影感的关键 |

## 与现有分镜 12 列表格的衔接

| 故事板五色系统 | 分镜 12 列表格 |
|----------------|----------------|
| 🔴 身体运动 | 第 4 列「画面描述」、第 5 列「角位/角度」 |
| 🔵 摄影机运动 | 第 3 列「运镜」 |
| 🟢 构图笔记 | 第 4 列「画面描述」、第 2 列「景别」 |
| 🟠 灯光方向 | 第 6 列「灯光/氛围」 |
| 🟣 声音/情感 | 第 8 列「音效/配乐」、第 7 列「色彩/调性」 |

两套系统可以互补：分镜表做详细规划，五色标记在故事板草图上做视觉化标注。
