## 核心原则详解

### 原则1：多平面空间层次 + 25-grid 思维

**为什么重要**：扁平的场景看起来像AI生成的。清晰的前景/中景/背景层次 = 电影感。

**如何执行**：
- 每次优化场景时，问自己：
  - 前景有什么？（物体、植物、框架）
  - 中景有什么？（主体、互动）
  - 背景有什么？（环境、光源、大气效果）
- 25-grid 思维：不只规划主镜头（正面平视），还要考虑 8 个主要变体角度（左前/右前/左/右/左后/右后/左前高角/右后高角）

**示例**：
```
优化前：女人站在雨中。
优化后：
- 前景：雨滴在镜头前穿过，虚化（f/2.8）
- 中景：女人站在湿滑鹅卵石上，右手拎着湿透的包
- 背景：生锈铁门，剥落海报，远处昏黄街灯（体积光）
```

### 原则2：光影与色调深度融合

**为什么重要**：没有 motivated 光源 = 塑料感。光影必须来自场景中的某个光源。

**如何执行**：
- 每个场景必须有一个明确的 **主光源**（key light）：
  - 室内：窗户、灯具、屏幕
  - 室外：太阳、路灯、车灯、霓虹
- 光影必须与环境互动：
  - 雨水/湿润表面反光
  - 金属/玻璃反射
  - 布料吸光/反光特性
  - 皮肤 subsurface scattering（SSS）
- 色调服务于情绪：
  - 冷色调（蓝/青）= 孤独、紧张、压抑
  - 暖色调（橙/红）= 温暖、激情、危险

**示例**：
```
优化前：rainy alley（没有指定光源）
优化后：harsh single tungsten practical light from top-left creating dramatic Rembrandt lighting with distinct shadow triangle on cheek
```

### 原则3：物理真实与环境融合

**为什么重要**：AI 生成经常犯「物体悬浮」、「光线穿透固体」、「材质无互动」的错误。

**如何执行**：
- 所有物体必须「坐」在表面上（重力）
- 所有光线必须有「来源」和「衰减」
- 所有材质必须有「反应」：
  - 布料：皱褶、吸光、惯性
  - 金属：反射、划痕、氧化
  - 皮肤：毛孔、细纹、红润感、SSS
  - 液体：流动、飞溅、反光

**示例**：
```
优化前：wet coat（只是「湿」的标签）
优化后：rain soaking into wool coat, heavy fabric physics with visible water droplets rolling down and creating dark patches on wool texture
```

### 原则4：环境叙事 + 12-category 资产覆盖

**为什么重要**：好的场景不只是「背景」，而是「故事的沉默叙述者」。

**如何执行**：
- 每次优化场景时，至少调用 **3 个** 12-category 资产类别
- 加入能暗示故事的细节：
  - 剥落海报 → 这个地方被遗弃多久了？
  - 咖啡杯仍有蒸汽 → 人物刚离开（或刚到达）
  - 破损的镜子 → 冲突发生过了？

**示例**：
```
优化前：abandoned warehouse
优化后：derelict warehouse with peeling movie posters on wall (暗示曾经的热闹), 
rusted iron gate with fresh scratch marks (最近的闯入者?), 
floating dust motes in volumetric god rays (时间静止感)
```

### 原则5：情绪与叙事服务

**为什么重要**：炫技的场景如果与故事无关 = 浪费时间。

**如何执行**：
- 每次添加细节时，问自己：**这个细节强化了哪个戏剧功能？**
  - Want vs Need（欲望 vs 需求）
  - 情绪张力（恐惧/爱/愤怒/悲伤）
  - 主题（救赎/复仇/成长/牺牲）
- 如果细节不能强化戏剧功能 → 删掉

**示例**：
```
场景：女主发现男友出轨。
不好的细节：背景有科幻飞船（与情绪无关）
好的细节：背景镜子里反射出另一个人的影子（强化背叛的震惊）
```

### 原则6：空间一致性

**为什么重要**：多镜头连续使用时，如果空间关系不一致 = 观众出戏。

**如何执行**：
- 建立 **场景圣经**（Scene Consistency Bible）
- 记录：
  - 光源方向（始终从左到右？从右到左？）
  - 人物站位（门在左边？窗在右边？）
  - 道具位置（咖啡杯始终在桌子左侧？）
- 25-grid 所有角度下，这些关系必须保持一致

### 原则7：资产与网格协同

**为什么重要**：优化后的场景应该「可拆解」为多个角度的变体。

**如何执行**：
- 优化场景时，始终考虑：「这个元素在左前低角看起来如何？在右后高角看起来如何？」
- 如果某个元素「只能从一个角度看到」→ 这是缺陷，需要调整为「多角度可见」或「战略性遮挡」

## 12-Category 资产系统详解

| 类别 | 内容示例 | 如何调用 | 竖屏适配要点 |
|------|----------|----------|----------------|
| **1. 角色资产** | 主角/配角/群演的视觉锚点、服装、表情库 | 调用 Character Consistency Bible | 眼睛在上1/3，面部占屏60-80% |
| **2. 道具资产** | 关键道具、手持物、环境道具 | 调用 Prop Design & Consistency Template | 道具位于中心稳定区（避免底部94-140px） |
| **3. 场景元素** | 建筑、家具、自然元素、毁伤细节 | 调用 Scene Consistency Bible | 垂直分布：天空在上1/3，地面在下1/3 |
| **4. 光影氛围** | 光源类型、色温、阴影形状、体积光 | 在提示词中明确指定光源 | 顶光/底光在竖屏中更戏剧性 |
| **5. 材质互动** | 布料、金属、木材、玻璃、液体物理反应 | 在提示词中添加材质关键词 | 竖屏 ECU 中材质细节更可见 |
| **6. 大气效果** | 尘埃、烟雾、雾气、光线散射 | 添加 `floating dust motes`, `volumetric god rays`, `fog` | 垂直光束（从上方射入）在竖屏中更有冲击力 |
| **7. 表面细节** | 锈迹、污渍、磨损、指纹、生活痕迹 | 添加 `weathered surfaces`, `natural patina`, `peeling paint` | 竖屏 ECU 中表面细节更清晰 |
| **8. 声音提示** | 环境音、脚步、材质碰撞（用于提示词描述） | 在提示词中描述声音（`rustling fabric`, `distant siren`） | 竖屏短剧节奏快，声音提示要精准 |
| **9. VFX 元素** | 火花、水花、碎片、能量效果 | 添加 `sparks on clash`, `water splatter`, `debris` | 竖屏中 VFX 要集中在中心稳定区 |
| **10. 摄影机** | 机位、运镜、镜头选择、景深 | 指定镜头毫米数、T-stop、景深 | 竖屏优先垂直运镜（Tilt Up/Down, Crane Up/Down） |
| **11. 色调情绪** | 色彩方案、对比度、饱和度、色彩关系 | 指定色调关键词（`teal and orange`, `desaturated blue`, `warm tungsten`） | 竖屏色彩要更饱和（手机屏幕亮度高） |
| **12. 叙事细节** | 暗示背景故事的隐藏细节、符号、痕迹 | 添加 `peeling movie posters`（暗示遗弃）、`fresh scratch marks`（暗示最近冲突） | 竖屏中叙事细节要放在中心稳定区（否则被裁切） |

## 25-Grid 多角度场景系统详解

### 25-Grid 布局

将场景空间划分为 5×5 网格，规划不同机位角度：

| | 左 | 中 | 右 |
|--|----|----|-----|
| **前（低角）** | 左前低角（强调人物高度） | 正面低角（眼睛在上1/3） | 右前低角（强调人物高度） |
| **中（平视）** | 左平视（垂直构图） | **正面平视（主镜头）** | 右平视（垂直构图） |
| **后（高角）** | 左后高角（俯拍，展现环境） | 正面高角（俯拍，孤独感） | 右后高角（俯拍，展现环境） |

### 使用方式

优化场景时，考虑主镜头（中心）之外的 8 个主要变体角度，确保光影、道具、人物位置在所有角度下都合理且丰富。

**示例**：

场景：雨夜小巷，女人站着悲伤。

| 角度 | 构图要点 | 元素分布变化 | 光影调整建议 |
|------|----------|----------------|--------------|
| **正面平视（主镜头）** | 女人占画面 60-80% 垂直高度，眼睛在上1/3 | 前景：雨滴虚化；中景：女人；背景：铁门 | 顶部左侧钨丝灯，Rembrandt 光影 |
| **左前低角** | 仰拍，强调女人高度（脆弱感） | 前景：雨滴在镜头前穿过；背景：建筑物向上延伸 | 光源在画面外右侧，照亮女人左侧脸 |
| **右前低角** | 仰拍，强调女人高度（脆弱感） | 同左前低角，但对称 | 光源在画面外左侧，照亮女人右侧脸 |
| **左平视** | 左侧平视，垂直构图 | 前景：湿滑墙壁；中景：女人侧脸；背景：巷子深度 | 侧光，强调鼻子和下巴轮廓 |
| **右平视** | 右侧平视，垂直构图 | 同左平视，但对称 | 侧光，强调鼻子和下巴轮廓 |
| **左后高角** | 俯拍，展现巷子深度 | 人物极小，在上1/3；背景：巷子延伸消失点 | 顶光，照亮人物头顶和肩膀 |
| **右后高角** | 俯拍，展现巷子深度 | 同左后高角，但对称 | 顶光，照亮人物头顶和肩膀 |
| **正面高角** | 俯拍，孤独感 | 人物在上1/3，占画面 20-30%；背景：巨大空旷环境 | 顶光，人物完全被阴影覆盖（只留 rim light） |

### 空间一致性检查

- [ ] 所有角度下，光源方向一致？
- [ ] 所有角度下，人物站位一致（门在左？窗在右？）
- [ ] 所有角度下，道具位置一致（咖啡杯在桌左？）
- [ ] 所有角度下，材质互动一致（雨水反光？金属反射？）

## 工作流程详解

### 步骤1：分析原始输入 + 资产映射

**目标**：理解用户给的原始描述，找出缺失点，识别可调用的资产类型。

**执行清单**：
- [ ] 提取核心主体（谁？）
- [ ] 提取核心动作（做什么？）
- [ ] 提取情绪（感觉如何？）
- [ ] 提取戏剧功能（为什么这个场景存在？）
- [ ] 识别可调用的 12-category 资产类型（至少 3 个）
- [ ] 判断当前描述在空间层次、光影、细节上的缺失

**示例**：

原始描述：`A woman stands in a rainy alley at night, looking sad.`

分析：
- 核心主体：女人
- 核心动作：站着
- 情绪：悲伤
- 戏剧功能：孤独、失落
- 可调用的资产类型：类别4（光影氛围）、类别6（大气效果）、类别7（表面细节）
- 缺失点：空间层次（没有前景/背景）、光影无来源、环境叙事缺失

### 步骤2：规划丰富性方案（融入 25-grid 思维）

**目标**：设计具体的空间层次、光影方案、资产调用。

**执行清单**：
- [ ] 设计前景/中景/背景的具体内容
- [ ] 规划光源方向、质感、体积效果
- [ ] 规划色调方案
- [ ] 考虑 25-grid 主要角度下的构图可能性
- [ ] 选择能强化叙事的环境细节

**示例**：

规划方案：
- 前景：雨滴在镜头前穿过（f/2.8 虚化）
- 中景：女人站在湿滑鹅卵石上，右手拎湿透包
- 背景：生锈铁门，剥落海报，远处昏黄街灯
- 光源：单一钨丝灯从顶部左侧（Rembrandt 光影）
- 体积效果：雨滴在体积光中可见（`floating dust motes in volumetric god rays`）
- 色调：冷蓝 + 暖 tungsten 对比（孤独 vs 温暖记忆）
- 25-grid 思维：主镜头正面平视；左前低角捕捉雨滴；右后高角展现巷子深度

### 步骤3：强制自检与优化

使用以下清单逐项检查并改进：

**A. 空间层次**
- [ ] 是否有清晰的前景/中景/背景？
- [ ] 前景是否提供足够的「景深暗示」？
- [ ] 中景是否突出主体？
- [ ] 背景是否提供环境和叙事？

**B. 光影与色调**
- [ ] 光影是否有源？（motivated lighting）
- [ ] 是否与材质产生真实互动？（雨水反光、金属反射、布料吸光）
- [ ] 色调是否统一？是否服务于情绪？

**C. 资产调用**
- [ ] 是否有效调用或描述了 12-category 中的至少 3 个资产类别？
- [ ] 每个调用的资产是否强化了戏剧功能？

**D. 物理真实**
- [ ] 是否避免塑料感、蜡质感、扁平感？
- [ ] 材质是否有真实互动？（布料皱褶、金属划痕、皮肤 SSS）

**E. 空间一致性**
- [ ] 是否具备空间一致性，便于多镜头连续使用？
- [ ] 25-grid 所有角度下，光源/站位/道具位置是否一致？

**F. 构图适配**
- [ ] 构图是否适合目标画幅（16:9 或 9:16）？
- [ ] 竖屏：眼睛是否在上1/3？中心稳定区是否无遮挡？

### 步骤4：生成最终输出

按照以下结构输出：

```
【场景分析与资产映射】
（简要说明原始描述的核心、缺失点、已识别的 12-category 资产类型，
以及结合 25-grid 的丰富性规划思路，120-180字）

【优化后提示词】
（输出完整、结构化、高信息密度的英文提示词，适合直接用于图像/视频生成。
必须体现多层空间、光影互动、资产细节与电影质感。）

【25-Grid 场景扩展建议】
（简要说明该丰富场景在 25-grid 主要角度下的构图要点、
元素分布变化、光影调整建议，以及如何保持空间一致性。
便于后续生成多角度变体。）

【使用建议】
（针对这一场景的镜头/运镜建议、与角色资产的衔接提示、迭代方向等）
```

## 自检清单详解

### A. 空间层次（3 层强制）

**为什么重要**：扁平 = AI 感。层次 = 电影感。

**如何检查**：
- 前景：有什么在镜头和主体之间？（物体、植物、框架）
- 中景：主体在哪里？
- 背景：主体后面有什么？（环境、光源、大气效果）

**常见错误**：
- ❌ 只有中景，没有前景和背景
- ❌ 前景遮挡主体（应该用浅景深虚化前景）
- ❌ 背景是纯色或渐变（应该用真实环境）

### B. 光影与色调（motivated lighting 强制）

**为什么重要**：没有 motivated 光源 = 塑料感。

**如何检查**：
- 每个光源都能在场景中找到「来源」？
- 光影是否与材质产生真实互动？（雨水反光、金属反射、布料吸光）
- 色调是否统一？是否服务于情绪？

**常见错误**：
- ❌ 双面光（flat lighting）
- ❌ 无阴影（看起来像浮在空中）
- ❌ 色调与情绪不匹配（悲伤场景用暖色调）

### C. 资产调用（至少 3 个类别）

**为什么重要**：丰富的场景 = 多个资产类别的协同。

**如何检查**：
- 是否调用了至少 3 个 12-category 资产类别？
- 每个调用的资产是否强化了戏剧功能？

**常见错误**：
- ❌ 只用了类别1（角色资产）和类别2（道具资产）
- ❌ 调用的资产与戏剧功能无关（炫技但无用）

### D. 物理真实（避免塑料感）

**为什么重要**：塑料感 = AI 生成最明显的痕迹。

**如何检查**：
- 材质是否有真实互动？（布料皱褶、金属划痕、皮肤 SSS）
- 物体是否「坐」在表面上（重力）？
- 光线是否有「来源」和「衰减」？

**常见错误**：
- ❌ 皮肤像塑料或蜡
- ❌ 布料像纸张（无皱褶、无惯性）
- ❌ 金属像镜子（无划痕、无氧化）

### E. 空间一致性（多镜头连续使用）

**为什么重要**：空间不一致 = 观众出戏。

**如何检查**：
- 25-grid 所有角度下，光源方向一致？
- 25-grid 所有角度下，人物站位一致？
- 25-grid 所有角度下，道具位置一致？

**常见错误**：
- ❌ 主镜头光源在左，反应镜头光源在右
- ❌ 主镜头门在左，远景门在右

### F. 构图适配（目标画幅）

**为什么重要**：画幅不对 = 黑边或裁切。

**如何检查**：
- 构图是否适合目标画幅（16:9 或 9:16）？
- 竖屏：眼睛是否在上1/3？中心稳定区是否无遮挡？

**常见错误**：
- ❌ 为竖屏生成 16:9 构图（人物眼睛在画面中央，不是上1/3）
- ❌ 重要细节在底部94-140px（UI 遮挡区）

## 常见问题排查

### Q1：优化后的提示词太长，AI 不遵循怎么办？

**A**：分而治之。
- 先生成「基础提示词」（主体 + 动作 + 情绪）
- 再生成「环境提示词」（空间层次 + 光影 + 大气效果）
- 最后用「增强提示词」（材质细节 + 资产调用）叠加

### Q2：25-grid 所有角度都要生成吗？

**A**：不需要。
- 主镜头（正面平视）必须生成
- 根据场景需要，选择 2-3 个变体角度生成
- 其余角度用「空间一致性检查清单」确保逻辑正确

### Q3：竖屏（9:16）和横屏（16:9）的优化有什么区别？

**A**：主要区别：
- 竖屏：眼睛必须在上1/3，人物占画面 60-80% 垂直高度
- 竖屏：优先垂直运镜（Tilt Up/Down, Crane Up/Down）
- 竖屏：底部94-140px 是 UI 遮挡区，重要细节不能放在这里
- 横屏：眼睛在画面中央偏上，人物占画面 40-60% 高度
- 横屏：优先水平运镜（Pan, Truck, Dolly）

### Q4：如何避免「过度优化」？

**A**：每次添加细节时，问自己：**这个细节强化了哪个戏剧功能？**
- 如果不能回答 → 删掉
- 如果能回答 → 保留，但确保不遮挡主体或重要细节
