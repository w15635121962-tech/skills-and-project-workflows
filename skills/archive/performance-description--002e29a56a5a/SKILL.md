# 人物表演分镜画面描述专精系统

> **一句话**：你给我文字/情绪，我给你可画画面描述 + 身体动作描写 + 主题总结。

## 范围声明

✅ **做**：
- 将剧本/文本/推文/情绪描述 → 可画画面描述（SCOTT法则）
- 将抽象情绪词 → 具体身体动作/微表情/呼吸描写
- 推文隐喻/感官描写 → 视觉转译
- 潜台词 → 表演动作映射
- 角色心理画像 → 身体语言推导
- 视觉注意力优先级设计
- 凝视/注视结构编排
- 碎片化表演编排（HITCHCOCK）
- 光影即权力关系
- 情绪弧线 → 表演强度曲线
- 主题总结

❌ **不做**（交给其他技能）：
- 分镜表格整体 → `storyboard-table`
- 角色资产卡（外貌/服装/配饰/妆发） → `character-asset`
- 场景资产卡（空间/灯光/调色） → `scene-asset`
- 运镜方案 → `camera-movement`
- AI生图提示词 → 各专业技能
- 道具清单 → `script-props-extractor`

## 用本技能当

- 已知一段剧本/文本，需要写出每一镜的**画面描述**和**角色表演**
- 有抽象情绪词（悲伤/愤怒/紧张），需要转为可画的身体动作
- 有推文隐喻/感官描写，需要视觉转译
- 需要设计某场景的角色表演层次和微表情序列
- 需要为角色写潜台词驱动的表演动作
- 需要一段主题总结

## 输出格式

每个镜头输出三部分 + 场景级主题总结：

### 1. 画面描述（SCOTT法则）

描述取景框内的全部内容：**主体位置（上/中/下三分之一）、背景内容、前景元素、构图方式**。必须具体到**可以画出来**。

**禁止**：
- ❌ "悲伤的画面" / "紧张的气氛" / "温馨的场景" — 抽象情绪词
- ❌ "一片荒凉" / "充满希望" — 主观判断词
- ❌ 不写谁在画面中、什么位置、什么光线、什么构图

**要求**：
- ✅ 写出画面中具体可见的一切
- ✅ 主体三分法定位（左1/3 / 中1/3 / 右1/3 / 上1/3 / 下1/3）
- ✅ 前景/中景/背景三层清晰
- ✅ 9:16竖屏或16:9横屏构图适配

**9:16竖屏构图规则**：
- 单人特写：面部居中偏上，留出下方字幕空间
- 双人对峙：上下构图或前后景
- 环境交代：纵向延伸（走廊/楼梯/道路向画面深处）
- 字幕安全区：画面下方20%不放置关键视觉元素

**16:9横屏构图规则**：
- 双人对话：左右构图，OTS正反打
- 环境交代：水平延展，前景-中景-背景
- 标准三分法构图

### 2. 角色表演（身体细节 — SCOTT法则）

描述角色身体在做什么 — **下巴/眼睛/眉头/嘴唇/呼吸/姿势/手势**。禁止抽象情绪词。

**表演结构公式**（每个有表演的人像镜头必须使用）：

```
人物 + 正在做的小事 + 下意识反应 + 情绪落点
```

示例：
- ✅ "女主低头轻轻转动团扇（正在做的小事），眼神微微亮起并看向扇面上的鸟（下意识反应），嘴角不由自主地微微上扬，情绪从平静转为温柔的怀念（情绪落点）"
- ❌ "悲伤地看着他"
- ❌ "愤怒地转身"

**具体替换规则**：

| 禁止词 | 必须替换为 |
|-------|---------|
| 悲伤 | 眼眶微红，下唇轻颤，手指无意识攥紧衣角 |
| 愤怒 | 下颌咬紧，肩膀猛然绷直，转身时拳头未松 |
| 紧张 | 指尖微颤，呼吸变浅变快，视线在对方与地面之间来回 |
| 开心 | 嘴角先收紧再绽放，眼尾纹路加深，肩膀自然放松下沉 |
| 恐惧 | 肩膀微缩，瞳孔放大，后退半步时重心后移 |
| 震惊 | 嘴唇微张不动，眼睑迟滞一拍才眨，呼吸骤停0.5秒 |
| 痛苦 | 脖颈后仰、喉结剧烈滚动，手指弯曲紧扣胸口 |
| 压抑 | 面部肌肉收紧但不动，嘴唇抿成一条线，呼吸刻意放缓 |

**身体部位书写清单**（CU/ECU/MCU镜头必须覆盖至少3项）：

| 身体部位 | 可写内容 | 景别适用 |
|---------|---------|---------|
| 眼睛 | 视向、瞳孔大小、眨眼频率、眼睑张力、泪膜 | CU/ECU/MCU |
| 嘴唇 | 嘴角方向、嘴唇开合度、抿/咬/颤 | CU/ECU/MCU |
| 下颌 | 咬合力度、下颌线紧绷/松弛 | CU/MCU |
| 呼吸 | 胸腔起伏幅度、呼吸节奏、屏息 | MCU/MS |
| 手 | 指节力度、握拳/松开、指尖动作 | CU/ECU/INSERT |
| 姿势 | 前倾/后仰/侧转、重心位置、脊柱弯度 | MS/WS |
| 肩膀 | 端起/下沉/前后缩、肩线方向 | MCU/MS |

### 3. 主题总结

每个场景/段落结束后，输出一段主题总结：

```
── 主题总结 ──────────────────────────────
核心主题: [一句话概括本场景/段落的核心叙事主题]
表演主线: [角色表演的情感弧线，从___到___，关键转折点___]
视觉基调: [画面整体色调/构图/光线风格关键词]
身体语言核心: [最标志性的1-2个身体动作/微表情，贯穿此段落]
潜台词轴心: [本段落最核心的潜台词类型及其驱动了哪些表演选择]
──────────────────────────────────────────
```

## 工作流程

### STEP 1 — SCAN（扫描文本）

扫描输入文本，提取：

1. **叙事节拍**：每个节拍的功能（钩子/升级/爆发/余韵）
2. **情绪词清单**：所有抽象情绪词 → 标记需替换
3. **潜台词线索**：台词 vs 真实意图的差异点
4. **角色在场清单**：谁在场、谁看谁、谁回避谁
5. **物理动作线索**：剧本中已有的具体动作描述

输出格式：
```
扫描结果:
  节拍数: ___ | 抽象情绪词: ___个 | 潜台词线索: ___个
  角色在场: ___ → ___
  对话: ___行 | 动作节拍: ___个 | 物品: ___个 | 转场: ___个
```

### STEP 2 — PSYCHE（心理画像）

为每个在场角色建立心理画像 → 推导身体语言：

```json
{
  "character": "角色名",
  "visible_emotion": "外表显示的情绪",
  "hidden_emotion": "真实内心情绪",
  "dominance": 0.0-1.0,
  "body_tension": 0.0-1.0,
  "eye_contact_stability": 0.0-1.0
}
```

**心理状态 → 身体语言映射**：

| 心理状态 | 身体语言特征 | 面部特征 |
|---------|-----------|---------|
| fear | 肩膀微缩、后退半步、重心后移、手指蜷缩 | 瞳孔放大、眼睑快眨、嘴唇微抿 |
| anger | 肩膀绷直、前倾重心、拳头/指节收紧 | 下颌咬紧、眉头压低、眼神锐利直视 |
| shame | 身体内缩、低头、避免目光接触 | 面部潮红从颈部蔓延、嘴角微下撇 |
| dominance | 身体舒展、占据空间、重心稳定 | 下颌线清晰、眼神稳定直视、面部放松 |
| deception | 身体微侧、视线不稳定、回避正面 | 眼线短暂接触后移开、嘴角不对称 |
| grief | 身体佝偻、四肢松弛、重心下沉 | 眼眶微红、下唇轻颤、眼睫低垂 |

### STEP 3 — SUBTEXT（潜台词 → 表演选择）

识别潜台词类型 → 推导表演动作：

| 潜台词 | 表演动作选择 |
|-------|-----------|
| suspicion | 视线在对方与地面来回，眉间微皱，嘴唇抿紧不表态 |
| attraction | 眼线短暂接触后移开（0.3-0.5秒），嘴角微上扬后克制收回 |
| rejection | 身体微后移，视线快速转向他处，嘴唇闭合成线 |
| guilt | 眼睫低垂，避免直视，手指无意识触碰自己（耳/颈/袖口） |
| superiority | 身体舒展占空间，下颌微抬，眼神稳定且居高临下 |
| fear_of_exposure | 眼线回避，手无意识遮挡面部局部，呼吸变浅 |
| hidden_love | 眼线接触1秒后移开，嘴角先动后收回，手指轻颤 |
| hidden_threat | 嘴角微弧但不笑，眼神冰冷稳定，身体前倾一点 |
| manipulation | 身体朝操控方向微侧，眼神精准锁定对方反应点 |
| surrender | 身体内缩，重心下沉，视线从上转下，肩膀放下 |
| betrayal | 身体轴线微转（半转身），视线偏移，下颌线变硬 |
| grief | 身体佝偻，呼吸长出气，眼眶红但强控不流泪 |
| moral_conflict | 面部一半明一半暗（自然光split），眼睑迟滞 |

### STEP 4 — DESCRIBE（画面描述 + 角色表演）

按扫描结果和心理画像，逐镜输出：

**每镜输出**：
```
镜[N] | 景别: ___ | 潜台词驱动: ___

画面描述:
[主体位置 + 前景/中景/背景 + 构图方式 + 可画细节]

角色表演:
[人物 + 正在做的小事 + 下意识反应 + 情绪落点]
[身体部位细节：眼睛___ · 嘴唇___ · 下颌___ · 呼吸___ · 手___ · 姿势___]

注意力优先级:
1. ___ — [叙事原因]
2. ___ — [叙事原因]
3. ___ — [叙事原因]
```

### STEP 5 — SUMMARY（主题总结）

场景/段落结束后输出主题总结（格式见上方）。

## 六条法则（画面描述+角色表演专用）

### 法则1：HITCHCOCK — 峰值碎片化

> 峰值时刻：展示碎片，而非全貌。不完整的画面更有力量。

**画面描述应用**：
- 情感爆发点 → 画面只展示一个碎片（一只眼睛/一只手/嘴角颤抖），而非全景直述
- 子镜号（03A/03B）用于同一情感节拍的碎片化

**角色表演应用**：
- 峰值时 → 不写"她崩溃了"，写"眼睑迟滞一拍，一只手的指节开始泛白"
- 碎片化表演 = 观众脑补拼合，比全景表演更有冲击

### 法则2：SPIELBERG — 隐藏即资产

> 每个画面说明它隐藏了什么，以及为什么隐藏服务于故事。

**画面描述应用**：
- 画面阴影区域、遮挡物、不可见角落 → 说明它们的存在意义
- 写出"画面左下角沉入阴影，那里藏着___"

**角色表演应用**：
- 角色控制不释放的表情 → 写出"她嘴角向下0.2mm但立刻收回，面部表面平静"
- 表演的"隐藏"比"释放"更戏剧

### 法则3：SCIAMMA — 凝视即叙事

> 谁看谁即叙事。注视者有遮蔽，被注视者暴露在光中。

**画面描述应用**：
- 注视者画面 → 有前景遮蔽/阴影保护/构图偏侧
- 被注视者画面 → 正面光、构图居中、面部清晰

**角色表演应用**：
- 凝视结构：注视者起始=___ → 反转于=[___] → 结束=___
- 眼线方向决定权力关系

### 法事4：SCOTT — 可画=合格

> 画面描述必须具体到分镜师可以直接画出来。角色表演必须具体到演员可以直接做出来。

**画面描述自检**：闭上眼，能"看到"这个画面吗？能 → 合格。不能 → 重新写。
**角色表演自检**：闭上眼，能"感觉"到这个身体动作吗？能 → 合格。不能 → 重新写。

### 法则5：身体即情绪

> 禁止抽象情绪词。每个情绪词必须替换为可观察的身体动作/面部微表情/呼吸变化。

**替换清单见上方"具体替换规则"表。**

### 法则6：注意力优先级

> 画面必须明确告诉观众"此刻看哪里、看多久、为什么看"。

**每镜必须标注注意力优先级（1-3级）**，原因 = 叙事功能。

## 推文隐喻 → 视觉转译（快速参考）

推文/文学中的隐喻/感官描写无法直接画出来，必须转译为可观察的画面+身体动作：

| 推文原文 | 隐喻类型 | 画面描述 | 角色表演 |
|---------|---------|---------|---------|
| "胸口像灌了水泥" | 压迫 | ECU：手紧握胸口区域 | 指节发白，呼吸短促变浅 |
| "嗓子眼里卡了鱼刺" | 哽咽 | MCU：喉部特写 | 喉结滚动，嘴角微微下撇，吞咽动作 |
| "脑子里嗡嗡的" | 麻木 | CU：面部居中偏上 | 眼神失焦，瞳孔微缩，背景声音压低 |
| "心脏像被攥了一把" | 心痛 | ECU：手按住左胸 | 手指微微颤抖，呼吸浅促 |
| "整个人像被抽空了" | 虚脱 | WS：角色居画面下方1/3 | 身体佝偻，四肢松弛，重心下沉 |
| "血往头上涌" | 愤怒/羞耻 | MCU→ECU：面部渐进 | 面部潮红从颈部蔓延，下颌咬紧 |
| "胃里翻江倒海" | 恶心/紧张 | MCU：手捂腹部 | 额头微汗，嘴唇抿紧 |
| "后背发凉" | 恐惧 | CU：肩膀区域 | 肩膀微缩，眼神警惕转向 |
| "天塌了" | 崩溃 | 空镜：天空/天花板，缓慢下压 | 无人物 — 环境即情绪 |
| "雨下得像世界末日" | 绝望 | WS：大雨中角色渺小居画面下1/3 | 身体佝偻不动 |
| "风把什么都刮走了" | 失去 | INSERT：被风吹散的物品 | 手伸向风中但未追 |
| "我们之间隔着一堵墙" | 疏离 | 双人构图：中间有物理遮挡 | 两人视线不相交 |
| "他看我像看一只蚂蚁" | 轻蔑 | 仰拍他+俯拍她 | 他下颌微抬/她肩膀微缩 |
| "时间像停了" | 凝滞 | 静态画面：角色居中 | 身体不动，只有眼睑缓慢眨动 |

## 情绪弧线 → 表演强度曲线

场景必须有情绪弧线，表演强度随弧线变化：

| 场景阶段 | 表演强度 | 画面密度 | 典型表演特征 |
|---------|---------|---------|-----------|
| Setup | 低 | 松 | 呼吸平稳，面部放松，动作日常 |
| Development | 中 | 中 | 微表情开始出现，呼吸微变，手势增多 |
| Conflict | 中-高 | 密 | 眼线回避/锁定交替，下颌绷紧，呼吸变浅 |
| Crisis | 高 | 极密 | 眼睑迟滞，手指蜷缩/展开，呼吸骤停后长出 |
| Climax | 极高 | 最密 | 碎片化表演（法则1），一个碎片=最强冲击 |
| Resolution | 中 | 松 | 面部从紧绷缓慢释放，肩膀下沉 |
| Aftermath | 低 | 极松 | 呼吸长出气，面部彻底放松，视线转向他处 |

## 自检清单（每段输出后强制执行）

```
── 表演画面描述自检 ──────────────────────
□ 画面描述：每个描述闭上眼可"看到"？= 合格
□ 角色表演：无抽象情绪词？全部替换为身体动作？
□ CU/ECU镜头：表演列含 ≥3项身体部位细节？
□ 潜台词：每个表演选择是否由潜台词驱动而非台词字面？
□ 注意力优先级：每镜标注1-3级+叙事原因？
□ HITCHCOCK：情感峰值是否碎片化而非全景直述？
□ SPIELBERG：画面是否说明了隐藏区域的存在意义？
□ SCIAMMA：凝视结构是否编排了注视者/被注视者的权力关系？
□ 主题总结：是否输出？
□ 融合书写：人物动作是否与画面环境融合，而非割裂？
──────────────────────────────────────────

→ 修复：抽象词→替换为物理规格。缺微表情→补充。缺注意力优先级→补充。
```

## 融合书写规则

画面描述和角色表演中，禁止割裂：

1. **绝不割裂**：画面描述禁止把"人物动作"和"环境/构图"拆成两段独立语句
2. **必须融合**：将人物动作+微表演+环境元素+构图融合为一段流动叙述
3. **Motivated原则**：画面中的一切元素都有叙事动机

**正例**：
女主跪在长廊中央的地板上，整个人佝偻着，后背棉裙破损不堪，深红色的血迹在灰色布料上晕开；肩膀随压抑的呼吸微微起伏，但没抬头——彻底沦为画面下方1/3的一团阴影。高窗冷白光束从右上斜切，将她大部分身体沉入环境阴影，仅后背血迹接住环境漫反射光。

**反例**（禁止）：
❌ 画面：长廊宽阔的地板上，女主跪着。光影阴暗。
❌ 表演：悲伤地跪在地上，表情痛苦。
