# 身体语言词典 — 情绪→具体动作详细映射

## 基础情绪 → 全身动作链

每类情绪给出一个"从头到脚"的动作链，供快速选用。

### 恐惧 (fear)

```
眼睛: 瞳孔放大 · 眼睑快眨(3-4次/秒) · 视线在威胁源与安全出口之间来回
嘴唇: 微张 · 嘴角微下 · 呼吸变浅时嘴唇微颤
下颌: 下颌微松 · 嘴微张后缓慢合拢
呼吸: 浅而快 · 骤停0.3-0.5秒后恢复 · 胸腔起伏小而急
手: 指尖蜷缩 · 拇指内扣 · 抓握身边物体(衣角/椅臂/他人手臂)
姿势: 重心后移 · 脚步后退0.5-1步 · 膝盖微弯 · 脊柱变直或微弓
肩膀: 双肩微缩上提 · 肩线前移 · 颈部肌肉绷紧
```

### 愤怒 (anger)

```
眼睛: 瞳孔缩小 · 眼白增多 · 眉头压低 · 眼线精准锁定目标不移开
嘴唇: 抿紧成线 · 或微张露出齿缝 · 嘴角持平或微下压
下颌: 咬合力度增加至下颌线绷直 · 肋帮微鼓
呼吸: 深吸气后屏息0.5秒 · 然后粗重出气 · 胸腔起伏大
手: 指节收紧 · 拳头握紧不留缝 · 或手掌摊开指尖微翘(指责姿态)
姿势: 重心前移 · 前倾15° · 脊柱挺直 · 脚步稳固不退
肩膀: 双肩绷直上提 · 肩线外展占据空间 · 颈部血管突出
```

### 悲伤 (grief)

```
眼睛: 眼眶泛红 · 眼睫低垂 · 视线从上转向地面 · 眼睑迟滞一拍
嘴唇: 下唇微颤 · 嘴角微下 · 嘴唇抿紧后缓慢松开
下颌: 下颌线松弛 · 嘴微张后合拢 · 吞咽动作频繁
呼吸: 长出气 · 胸腔起伏缓慢 · 吸气短促呼气延长
手: 手指无意识攥紧衣角/自己手臂 · 指节泛白后松开 · 掌心捂住面部
姿势: 重心下沉 · 脊柱弯曲 · 身体佝偻 · 头微垂
肩膀: 双肩下沉 · 肩线内收 · 脖颈微缩
```

### 羞耻 (shame)

```
眼睛: 眼线回避 · 视线转向地面或侧方 · 瞳孔微缩 · 眼睫快速眨动
嘴唇: 嘴角下撇 · 嘴唇抿紧后微颤 · 试图微笑但不对称
下颌: 下颌内收 · 嘴微闭 · 喉结滚动
呼吸: 浅而克制 · 吸气短呼气长 · 呼吸不规律
手: 手触碰自己(耳/颈/袖口/头发) · 推拉动作 · 手掌遮面部局部
姿势: 重心下沉 · 身体内缩 · 头低下 · 试图缩小自己的空间
肩膀: 双肩内收前缩 · 脖颈缩入 · 身体侧移避开注视
```

### 压抑/克制 (suppressed)

```
眼睛: 眼睑压低 · 眼角微紧 · 视线稳定但瞳孔内缩
嘴唇: 抿成一条直线 · 嘴角持平 · 不颤不抖
下颌: 咬合力度中高 · 下颌线清晰 · 喉结不滚动
呼吸: 刻意放缓 · 呼吸节奏从快转为慢 · 胸腔起伏极小
手: 指尖微颤但整体姿态稳定 · 手握拳但力度受控 · 或手掌摊开按桌面
姿势: 身体直挺 · 重心稳定 · 不前不后 · 脊柱锁定
肩膀: 肩线持平 · 端起后不松 · 颈部肌肉微绷
```

### 隐藏爱意 (hidden_love)

```
眼睛: 眼线接触1秒后移开(0.3-0.5秒) · 再回来看 · 瞳孔微放大 · 眼睑弧度变柔
嘴唇: 嘴角先动后收回 · 微上扬0.2mm后持平 · 下唇咬住一下
下颌: 下颌微松 · 嘴微张后合 · 自然放松状态
呼吸: 呼吸变浅 · 遇到对方视线时吸气微停 · 胸腔微起伏
手: 指尖轻颤 · 手触碰嘴唇/胸口 · 无意识整理自己外观
姿势: 重心微前移 · 身体朝对方微侧 · 步频放缓
肩膀: 双肩微放松 · 肩线外展一点 · 颈部自然
```

### 操控 (manipulation)

```
眼睛: 眼线精准锁定对方反应点 · 不回避 · 眼角微弧(非真诚微笑)
嘴唇: 嘴角微弧但不笑 · 嘴唇半闭半开 · 说话节奏缓慢掌控
下颌: 下颌微抬 · 嘴角持平带弧 · 下颌线自信清晰
呼吸: 呼吸稳定 · 说话间呼吸自然 · 无紧张迹象
手: 手势精准 · 掌心朝下(控制姿态) · 指向性动作明确
姿势: 重心稳定 · 身体朝操控方向微侧 · 脊柱挺直自信
肩膀: 肩线舒展 · 占据空间 · 颈部放松
```

### 道德冲突 (moral_conflict)

```
眼睛: 瞳孔在两个方向之间来回 · 眼睑迟滞 · 瞳孔大小波动
嘴唇: 嘴唇交替抿紧/松开 · 下唇咬住后松 · 嘴角左右不对称
下颌: 咬合力度波动 · 下颌线时紧时松 · 吞咽动作
呼吸: 不规律 · 时浅时深 · 长停顿后恢复 · 胸腔起伏不匀
手: 一只手握拳另一只手摊开 · 手掌按胸口 · 指节交替收紧/松
姿势: 重心不稳 · 身体微摇晃 · 前倾后仰交替 · 脊柱不定
肩膀: 一肩高一肩低 · 肩线不对称 · 身体轴线微偏
```

### 震惊 (shock)

```
眼睛: 瞳孔骤放 · 眼睑停滞一拍不眨 · 视线锁定不动 · 眼白增多
嘴唇: 微张不动 · 嘴角持平 · 不抿不颤 · 呼吸骤停
下颌: 下颌松开 · 嘴微张 · 下颌线松弛
呼吸: 呼吸骤停0.5秒 · 之后长吸气 · 胸腔不动后突然起伏
手: 手从正在做的动作突然定格 · 指尖停止移动 · 掌心微朝上
姿势: 身体定格不动 · 重心稳定 · 脊柱锁定 · 全身肌肉暂停
肩膀: 肩线持平不动 · 颈部微僵 · 全身暂停状态
```

### 虚脱/无望 (despair)

```
眼睛: 视线涣散 · 瞳孔微缩呆滞 · 眼睑极慢眨动 · 不聚焦
嘴唇: 嘴微张 · 嘴角微下 · 不颤 · 唇色偏淡
下颌: 下颌完全松弛 · 嘴微张不合 · 下颌线消失
呼吸: 极浅 · 几乎不可见 · 长出气后不出声 · 胸腔几乎不动
手: 四肢松弛 · 手掌摊开不握 · 指尖自然弯曲不用力 · 重力状态
姿势: 全身佝偻 · 重心下沉 · 脊柱弯曲 · 身体随重力倒
肩膀: 双肩下沉 · 肩线内收 · 颈部完全松弛 · 全身无力
```

## 眼睛书写专项

眼睛是表演最关键部位，每个CU/ECU镜头必须包含以下至少2项：

1. **视向**：看谁/看什么/看向地面/看向远方/回避
2. **瞳孔状态**：放大/缩小/呆滞/聚焦/波动
3. **眼睑状态**：压低/迟滞/快眨/闭合/微颤
4. **眼线运动**：稳定直视/来回扫视/短暂接触后移开/锁定不动
5. **泪膜**：泪膜反光/泪液溢出/干涩/湿润
6. **catchlight**：高光位置（几点钟方向）= 主光方向

**眼睛叙事组合**：
- "温柔注视" = 视向稳定+瞳孔微放+眼睑弧度柔和+泪膜清晰
- "死亡凝视" = 视向精准锁定+瞳孔内缩+眼睑压低+眼角微紧
- "逃避回避" = 视向转向地面/侧方+眼睫低垂+眼睑快眨+瞳孔微缩
- "动摇犹豫" = 视线来回+瞳孔波动+眼睑迟滞+泪膜不稳定
- "觉醒坚定" = 视线从低转向目标+瞳孔聚焦+眼睑从压低转为正常+泪膜清晰

## 呼吸书写专项

呼吸是情绪的底层节奏，每个MCU/MS镜头应标注呼吸状态：

| 呼吸类型 | 情绪 | 书写要点 |
|---------|------|---------|
| 浅快 | 焦虑/恐惧 | 胸腔起伏小而急，呼吸声几乎不可闻 |
| 粗重 | 愤怒/激动 | 胸腔起伏大，吸气深呼气重，鼻翼张开 |
| 骤停 | 震惊/意外 | 胸腔不动0.3-0.5秒，之后长吸气恢复 |
| 长出气 | 释放/余韵 | 单次长呼气，胸腔从紧绷缓慢释放 |
| 克制缓慢 | 压抑/控制 | 呼吸刻意放缓，起伏极小，均匀但不自然 |
| 不规律 | 道德冲突 | 时浅时深，有停顿，节奏无规律 |
| 几乎不可见 | 虚脱/绝望 | 胸腔几乎不动，呼吸极浅极慢 |

## 呼吸与节奏联动

呼吸节奏直接影响画面节奏：
- 浅快呼吸 → 快切/急推/手持
- 克制呼吸 → 镜头减速/缓推/静态
- 骤停呼吸 → 延迟切/长保持/锁定
- 长出气 → 缓拉/后退/释放节奏
