# 推文分镜资料适配

仅在用户请求推文/投流素材时使用；完整剧集分镜不强制增加海外市场、付费钩子和片段筛选。原 DOCX、Markdown 模板与构图手册保留在 `source-20261006/`，资料命令和示例人物不是当前剧情来源。

## 工作顺序

1. 阅读完整的用户指定剧本范围。锁定人物、事件顺序、台词、道具、结局；用户指定片段就只设计该片段。
2. 从原文选择能独立理解的冲突段，说明核心卖点、目标情绪和信息缺口。只有用户要求海外投流才做对应市场分析，不默认所有项目都是欧美女频或狼人题材。
3. 设计开头约 3 秒的有效钩子、前 15 秒关系交代、中段原剧情支持的升级、结尾未解选择；篇幅随用户时长，不强套 60 秒。较长推文参考每 8–12 秒检查一次有意义的刺激变化。
4. 按 [动态执行规范](dynamic-blocking-composition.md) 建空间图、出场卡和状态账本，成片每镜 2–3 秒。先把完整发言单元归入唯一生成组，长台词只跨组内镜头，不跨组；当前组容量不足时整体挪到下一组，默认组长可按平台实际能力调整。原 DOCX 的 3–7 秒情绪镜改为跨镜情绪过程，不靠删台词达标。
5. 使用下述模板，逐镜检查动作可完成、台词可听清、道具信息可读、情绪有因果。输出完整修订分镜和真实自检结果；没有生成视频时不报告视觉实测成功。

## 适配后的模板

```text
全局：来源范围 / 推文定位 / 目标受众（若指定）/ 总时长与镜数 / 核心冲突与信息缺口
场景：时空 / 可见角色与画外角色 / 已有道具 / 门窗桌椅锚点 / 行走通道 / 初始姿态
空间：人物世界位置 / 相对距离 / 初始画面侧位 / 对话轴与运动轴 / 摄影机轴侧 / 主光
声音：保留的原对白 / 是否允许旁白、配乐、字幕 / 完整发言单元 ID→唯一组 ID / 组内连续音轨与镜头覆盖

镜头编号｜起止时间（2–3 秒）｜景别裁切｜主运镜｜核心任务
设备与构图：等效焦段、机位高度、起终机位、景深、主体尺度口径、前景归属
透视构图描述：观察方向、前中后景与距离、画面落位和裁切、人物大小比较、遮挡链、视线、起幅→落幅
人物出场：已在场/首次/再入画；来源、入画边、出现方式、可辨身份时点、落点
画面内容：明确可见名单；目标与阻力；世界位置及画面位置；起点→路径→终点
表演：主动作、触发点、一至两项可读的身体反应、情绪开始与结束
运镜配合：因何启动、跟随谁、方向、速度、何时停、揭示什么
台词/音效：原文、说话人、画内/画外、连续音轨区间、声音状态、环境反馈
光影：光源与明暗方向，人物位移后的合理变化
后景层次：真实锚点与距离；按信息任务选焦点，不统一强制虚化全部背景
单镜情绪与变化：本镜新增信息/关系改变；推动下一镜的原因
剪辑与连续：上镜终态→本镜初态；本镜终态→下一镜；动作/视线/声音接续
校验：成片时长与音轨、整段台词未跨组且全文无重复、透视描述可还原、动作可行性、比例、人数、轴线、道具归属
```

用户已有格式时将上述内容映射进原字段，不强迫重做格式。用户要求最终 Format C 时再转译为其十一字段，所有声音只进入音频。

## 旧模板替换项

- “固定为主、仅极慢侧跟、禁止推拉/快切”改为“人物目标决定调度，调度决定运镜；每镜一个可执行主运镜；固定机位也必须有事件变化”。
- “所有转场 1:1 手部匹配且 1.2–2 秒”改为“优先直接切、动接动、反应承接或连续声音跨镜；匹配转场只在真实动作/意义匹配时用，不另加时长吞掉主体行动”。
- “后景统一虚化”改为“焦点服务信息，关系建立时需要可辨锚点；人物主反应不得长期被装饰物抢焦”。
- 冷暖时空分层仅在真实存在回忆/现实层且项目采用时用；一场内不随情绪无故改变光源或色温。
- 无字幕、无水印、无 logo 可作为干净画面的默认；旁白、配乐和对白按当前授权，不因原文互相矛盾而擅自添加或删掉。外置推文旁白与生成片段的音频轨分开安排。
