# 参考图构图拆解与可执行描述

适用：依据本批参考图设计人物站位、坐姿、画面比例、观察角度、遮挡与透视。先选符合剧情的构图，再将对应写法填入现有镜头字段；不要把所有技巧堆进同一镜头。与 [动态执行规范](dynamic-blocking-composition.md) 配合使用，长台词仍整段留在同一生成组。

检索：坐标与比例｜逐张实拍拆解｜教学图构图词库｜景别与角度｜完整提示词范例｜构图验收。

## 1. 读图口径：观察、推断、设计分开

- 来源为用户提供的 24 张图片，完整路径、文件哈希见 [来源清单](source-20261006/manifest.json)。以下 R01–R24 是归档编号，不随重复上传排序变化。最新上传第 23 张是 R24（文件尾号 `_25_191`，九宫格），第 24 张是 R23（`_24_191`，片名海报）；其他编号一致。
- 实拍部分 R06–R23 共 18 张，包含一张与 R07 类似的片名海报；教学拼图为 R01–R05、R24。教学拼图的坐标与比例均相对其中的**单张示例照片**，不是整页排版。
- 观察坐标按整张画面：左上角 `(0,0)`，右下角 `(100,100)`；x 向右、y 向下。这里的区间是肉眼近似估计，用于说明布局，不是像素检测结果。不要对这些估计再计算伪精确的面积或距离。
- “头部占高”指发顶至下巴投影高度/画面高；“可见身体占高”指画内可见身体上缘至下缘/画面高；“全身占高”仅用于完整头脚都在画内的镜头；“占宽”是该主体投影宽/画面宽。被截断的局部不能写成全身占比，包围框面积也不等于人物实际面积。
- 静图可支持左右、裁切、相对大小、重叠与清晰度判断；真实焦段、光圈、米数、俯仰度数、镜头运动及动作先后不能据图确定。“机位建议”是复现这种视觉关系的设计选择，必须标为建议，不能称原片参数。
- 主体清晰、背景模糊属于景深/焦点表现；逆光、暗部、色温属于光线；大字标题属于版式。分别描述，不能把“电影感”“长焦感”当作人物位置和裁切的替代词。

## 2. 实拍逐图：先说图中有什么，再说怎样写给 AI

以下“转写”采用图中已有的白衣人物、深衣人物、桌椅和窗等作教学示例。用于实际项目时替换成已绑定角色与场景；手别、距离和动作由剧本/连续性账本确定，不从模糊图中猜定。坐标可保留关键的 2–4 个锚点，不必把每一根手指数字化。

### R06 / `_7_191`：物清人虚，窗框分层

**观察：** 白花与花瓶形成偏右竖线，花头约在 `(62,32)`，瓶身约 x48–62、y50–66；白衣坐者在后层中左，人物可见轮廓约 y30–65。右侧木框和 y67 附近的横窗台形成 L 形边界，下方墙面约占下三分之一。人物不是焦点。

**转写：** “从窗外接近正面的方向看向室内；前层花瓶立在窗台偏右，白花向画面上方延伸，花瓣和瓶身清晰。白衣坐者在花瓶后方偏左，身体朝画左，轮廓可辨但面部虚化。右窗框贴画右，下窗台横贯画面下三分之一附近；镜头保持窗台竖直水平关系，不增加人影。”建议机位接近花瓶上部高度，焦点落在花上。若剧情要读表情，应另设人物焦点镜，不能同时要求花和远脸都极浅景深清晰。

### R07 / `_8_191`：隔桌对坐，横向关系加纵深桌面

**观察：** 白衣人头部中心约 `(23,46)`，深衣人约 `(79,45)`，面对面，眼线高度接近；坐姿身体及腿分布在画面中下部。长桌近端宽、远端窄，沿中央向后延伸；亮窗在后层，上方约四成是较暗环境。两人分居左右，桌面空隙成为关系距离。

**转写：** “摄影机在桌子近端，从对坐两人连线的一侧看向亮窗，接近坐者眼睛高度。白衣人坐在画左四分之一附近，侧脸朝右；深衣人坐在画右四分之一附近，侧脸朝左。两人处于接近的纵深，头部尺寸接近，桌面把两人分隔，桌边从下部两侧向中央后方收拢。保留完整的头肩和搭在身前的手，窗格位于人物后方。”上方暗区可以保留以表现环境压力，或按项目需求收紧裁切；不把大留白认定为错误。

### R08 / `_9_191`：脸部主焦点，近层柔化遮挡

**观察：** 深衣人物头脸大致在 x15–90、y5–65，眼睛约 y35–40；画面下半部与右侧出现失焦色块。色块来源无法仅凭此图确认，不能直接认定为另一个人的肩。

**转写：** “人物头脸为主体，发顶靠近画面上缘，两眼落在画面上半部，面向机位略偏侧，目光指向已建立的画外对手。焦点落在眼睛，嘴与下颌仍可辨。”机位建议眼平略偏正面。若项目已有明确前景人物，可补写该人的哪侧肩背从哪条边进入、遮住哪一部分；否则使用无遮挡版本，禁止凭灰色模糊区补出第三人。

### R09 / `_10_191`：身体与头眼不同向，回看式中近景

**观察：** 白衣人物发顶约 y13，眼线约 y32，头肩与上身充满中下部，身体在中右；头眼指向画左，柜架在后层，右侧窗光与头发边缘形成分离。画内下缘截取躯干，不是全身。

**转写：** “从人物侧前方拍摄，取发顶至腰部附近的可见上身；肩线斜向画右，头转向画左，眼睛看向画外已建立的对手。头脸中心略偏右，左侧留出视线空间，后方柜架保持可辨但弱化。”机位建议眼平。若生成转头动作，另写起始朝向与转头终点；这张静帧只支持结束姿态，不能证明她正在离开。

### R10 / `_11_191`：背面前景与正面后景，双人纵深

**观察：** 前层白衣背影中心约 x40，头部约 y65；后层深衣人中心约 x24，头部约 y62。前者与椅背占中下部较大范围，后者正脸露在其左侧。上方约一半为高墙、门与吊灯，右侧柱体/长台加强纵深。不是两人并排。

**转写：** “机位在白衣坐者后方偏左，越过其左侧外缘看向隔桌的深衣坐者。白衣人的后脑、双肩及椅背位于中下部偏中，深衣人的正脸在画左后层，避免前景后脑遮住他的眼睛。前景头部略大，桌边把前后两张椅子连接起来；背景柱和门保持垂直。”建议接近坐者眼高或略高，优先用前后错位露出后景脸，不能将两人强行放在同一焦平面。

### R11 / `_12_191`：手势与盖碗形成对角关系

**观察：** 深色袖口由画右进入，摊开的手约 x33–90、y45–70；盖碗在左下约 x8–40、y72–90，倒影继续向下。手与杯一高一低，背景为模糊亮窗，脸不在画面内。

**转写：** “从桌面侧方近距离观察，摄影机略高于手掌所在平面以露出掌面；深衣人物的一只手从画右伸向画中偏左，掌心朝上、指尖朝左。盖碗留在左下前层，手与杯之间保持空气间隙，背景窗格虚化。”用已确认手别替换“一只手”；除非剧情明确，不能让手碰杯，或把手势自动解释为求婚。

### R12 / `_13_191` 与 R19 / `_20_191`：相向侧脸极近景

**观察：** R12 的男性脸在右侧，鼻尖朝左，清晰眼部约 `(60,72)`；R19 女性脸在左侧，鼻尖朝右，眼部约 `(40,72)`。两张都有顶部背景和发丝，面部下半部被画底截断，眼睛位于下半幅；这些是有意裁切的侧脸局部，不符合普通半身“眼在上三分之一”的习惯。

**转写：** “只取人物侧脸局部，保留一只眼睛、眉弓、鼻梁及部分发际，嘴和下巴允许裁出画底。人物脸贴画右时朝画左，画左保留柔化背景；配对另一人物时反向设置。焦点在可见眼睛，鼻尖不顶住所朝向的画边。”建议机位接近可见眼睛高度，从侧方观察。采用此特殊低眼位须有参考复现意图；普通对白近景不要一律照搬。配对时核对角色实际位置和视线轴，不从两张截图推断原片顺序。

### R13 / `_14_191`：从室外框住室内，人物小且靠下

**观察：** 大窗框约 x10–90、y5–58；两人在室内窗洞下部，深衣人在左阴影里，白衣人在右，白衣人可见上身高度约画高 10–15%。外侧矮桌居中、软垫分列两侧，位于 y60–80；窗洞、外座与台阶形成三层。看到的是窗内实体人物，并无充分证据认定镜中像。

**转写：** “摄影机在室外正对窗洞，窗框竖线保持竖直；前层台阶与两侧坐垫、中层矮桌、后层窗内对坐人物依次后退。两名人物只露出窗台以上的上身，分别靠窗洞下缘左右两侧，窗洞上半部留暗。人物比例小，重点展示内外空间距离。”这张与 R07 的画面左右不同，需要新的观察方向解释，不能在连续对话中无说明地互换座位。

### R14 / `_15_191`：前景标志物建立地点

**观察：** 招牌约 x58–100、y53–87，露出两个相邻面；左侧树干和斜向建筑/矮墙围出空间，上部为树冠、天空与遮阳伞。没有需要识别的主要人物。

**转写：** “机位在招牌侧前方，招牌置于画右下，正面和侧面同时可见；左侧树干从画边延伸向上，矮墙与建筑向左后方退去，遮阳伞位于中右上部。焦点在招牌实体轮廓，背景略虚，保持地点层次。”这是物与环境的构图，不填人物占比；只有项目要求才沿用实际文字或安排招牌阅读。

### R15 / `_16_191`：地面低机位，桌腿分割双脚

**观察：** 中央桌腿约占 x40–65，桌底为顶部暗面；白衣下摆与浅色鞋在左，深色裤腿和皮鞋在右，鞋底接近 y75–80 的地面支撑位置。地面反光占底部。桌腿将双方脚部隔开。

**转写：** “摄影机贴近地面，从桌下横向观察两名坐者的脚，镜头略向上，桌底成为上边框。桌腿位于中央竖向分隔，白衣人物的浅色鞋留在左侧，深衣人物的皮鞋留在右侧，鞋底与地板接触。只出现这两名已建立人物的腿脚，不显示人脸。”这是低机位局部，不是把普通人像整体荷兰角倾斜。若要表现收脚起身，连续记录脚离开原点与下一镜身体承重。

### R16 / `_17_191`：双手叠压，皮肤轮廓从暗衣中分离

**观察：** 双手主体约 x15–88、y38–78，一只手横向盖住另一只手，白袖口在左，腕表在上右。背景为深衣，不见脸。重叠点与皮肤明暗把视线集中在手部。

**转写：** “从人物身前略高于双手的位置俯看局部，双手在腹前上下叠放，上手横向覆盖下手手背，下手手指向画底自然垂落。双手占画面中下部，左侧留白袖口，上右保留同一人物腕表，深色西装为简洁背景。”手别和腕表佩戴侧按资产锁定；静帧只证明叠放，不证明正在攥紧。

### R17 / `_18_191`：桌沿手指清晰，近处盖碗模糊

**观察：** 白衣前臂从左上进入，手约 x45–83、y37–52，指尖搭在桌沿；杯形失焦物占右下前层，桌面反光延伸至画底。手是焦点，杯是近层阻隔。

**转写：** “摄影机靠近桌面，从手的侧前方拍摄，视线略高于桌沿。白衣人物的前臂由左上向中右延伸，手指自然弯曲搭住桌沿，指尖和木边接触处清晰。已有盖碗位于右下极近前景，明显虚焦，但不遮住手指与桌边的关键接触点。”不要要求杯和手同时极浅景深清晰；若要抓紧，明确是动作设计并给放松/收回终点。

### R18 / `_19_191`：右侧坐姿轮廓，向左留视线空间

**观察：** 发顶约 y10，眼线约 y25，头和躯干偏右，鼻尖朝左；上身斜向左下延伸，椅背在右下承托。窗格与亮绿色背景使暗侧脸可辨。左侧主要用于视线方向留空。

**转写：** “机位在深衣坐者侧方，接近坐姿眼高，取头顶至大腿附近的坐姿中景。头部在画面右上区域，侧脸朝左看向画外对手；后脑到右画边留少量空间，鼻尖到左画边保留较多空间。椅背贴右侧支撑身体，双手落在身前下部，亮窗在后层。”实际生成对白时保证眼、嘴可读，不为复制剪影把整张脸压黑。

### R20 / `_21_191`：近大远小，前景躯干遮挡

**观察：** 白衣躯干占据右侧约三分之二宽度并延伸出画面上下缘，头脸未完整入画；深衣坐者在左后层，其头约 `(17,48)`，可见上身约 y47–61。前后尺寸反差很大，但服装、椅桌说明是不同距离的两人。

**转写：** “摄影机紧邻白衣人物侧后方，白衣肩背和躯干从右边贴近镜头，占右侧约三分之二画宽，脸保持画外、轮廓虚化。深衣坐者位于左后方透出的窄区，脸和上身清晰，坐在原椅上；前景身体不遮住他的脸。两人间保留已有桌椅与通道，形成真实近大远小。”若她从座位走到近处，必须补动作衔接；不能靠一切镜凭空放大，也不能把白衣躯干替换成陌生人的大头。

### R21 / `_22_191`：手抓门边，竖线约束动作位置

**观察：** 门边竖线约 x65–78，手围住门边，约在画面中部偏右；前臂从右画边进入。黑色把手在下方，柜架处于左后层，手和门边比背景清楚。

**转写：** “机位在门侧近距离拍摄，手从画右伸入抓住竖直门边，拇指与其他手指分处门边两侧，手掌中心在右三分线附近。门边向画面上下贯通，把手留在下方，背景柜架虚化。”该帧无法判定开门或关门；实际镜头另写铰链所在侧、门扇转向、起终门缝与手的连续接触，不能只写‘门动了’。

### R22 / `_23_191`：腕表为视觉中心，手臂斜向延伸

**观察：** 表盘中心约 `(51,46)`，直径约画宽 15–20%；白袖口从左进入，手背延伸向右，暗色衣物包围下半部，背景绿植模糊。表盘占高与占宽不同，不能混称占画面 20%。

**转写：** “从佩表手腕斜上方看向表面，前臂由画左下延伸到画右中部，表盘置于中央稍偏上，表盘直径约占画宽六分之一，表面与镜头略有夹角，白色袖口紧接表带左侧。手背向右延伸，背景与身前衣物虚化。”佩戴侧、表带和表盘样式锁定原资产；需要准确时间时单独确认，不从低清指针猜剧情时间。

### R23 / `_24_191`：关系总图叠加海报文字

**观察：** 与 R07 类似的对坐、长桌和亮窗；人物主要在中下部，白色片名覆盖上半部暗区并向下延伸。标题提供的视觉重量不能算成人物占比。

**转写：** 剧情镜采用 R07 的空间关系即可。仅在明确制作海报/封面时，另给文字框位置、字号层级和避让人脸区；文字宜后期排版。不要把片名、水印或“小红书号”纳入普通视频画面要求。

## 3. 教学图的构图词库：将名称展开为空间规则

下表 C01–C36 对应真人教学页内的条目号：C01–09 在 R24，C10–18 在 R05，C19–27 在 R04，C28–36 在 R03。同类条目合并说明，但每个编号都可追溯。**此表比例是可调整的设计起点，不是示例照片的实测值。** 必须按画幅、裁切、实际演员数量和剧情改写。

| 条目 / 技巧 | 可执行的人物位置、比例与机位写法 | 使用边界 |
|---|---|---|
| C01 单人中央 | 人物身体中线 x50；普通头肩近景可设眼线 y30–40，双肩左右展开；机位正前略偏向对手，眼平 | 居中不代表看镜头；“正脸”与“对视镜头”分别控制 |
| C02 / C03 左右三分 | 左位头中心 x33、看画右；右位头中心 x67、看画左；鼻尖前方比后脑后方留更多空间，取胸部以上或腰部以上并说清裁切 | “左三分”是位置不是只剩三分之一张脸；两种方向不能同时用于同一人同一帧 |
| C04 / C10 中轴对称 | 走廊中轴 x50，机位沿中轴正对；单人居中，双人可分居 x40/x60；全身入画可从占高约 60–75% 起调，双脚同一地面 | 对称来自建筑与位置，不要求两张脸完全同形或同姿 |
| C05 / C11 偏心重心 | 主体头肩靠 x25–35；另一侧用已有窗光、门或远处角色平衡；近人较大、远人较小，交代各自纵深 | 不凭空加陪衬人物；重心是亮度、面积、清晰度的合成，不只看几何中心 |
| C06 / C12 大面积负空间 | 单人可放 x20 或 x80；全身/坐姿可见身体占高约 20–35%，墙面等简洁区约占画面六成以上，机位后退以保留环境 | 小人物的全身高度与近景头部高度不是同一量；留白应服务等待、孤立或注视 |
| C07 三人三角 | 三个已存在角色头部中心错开，例如 `(25,40)/(50,30)/(75,40)`，中人稍靠后或站姿较高；机位拍到三人视线关系 | 实际只有两人则不选“三人”版；不可为构图补演员 |
| C08 / C14 对角线 | 楼梯由画左下通向右上，人物在真实台阶上前后错开；机位从楼梯侧面看，栏杆构成斜线 | 环境斜线不等于摄影机横滚；保持人体垂直与脚底落点 |
| C09 楼梯上下分层 | 低处人物约左下，高处人物约右上，头部高度明显不同；双方面向彼此，机位侧拍同时保留台阶高差 | 高处小/低处大取决于机位距离，不因“高处”自动写更大 |
| C13 两人加环境三角 | 两人头部分居左右上部，桌角或扶手转折在下方构成第三顶点；机位略斜向关系轴 | 第三个顶点是已有环境，不是新角色 |
| C15 斜线 | 人物保持自然站姿，窗框/扶手斜穿画面并引向头肩；取人物中景，机位斜向窗面 | 若需要荷兰角必须另写横滚方向与幅度，不能由斜窗误判 |
| C16 L 形 | 前层人物竖向占右侧，低处台面/栏杆横向延伸向左，后层角色在左侧门内，形成一竖一横 | 明确哪条实体线构成 L，不能只写字母标签 |
| C17 圆桌环形 | 桌面为中下部椭圆，两名坐者分布左上/右上，手在桌缘内侧；机位略高于坐者以露出桌面 | 两人围坐无需生成环绕一圈的人；不凭“圆桌”改成顶视镜头 |
| C18 中心放射 | 核心人物在 x50，周边已有角色肩线、视线或灯具线条向其聚拢；前层侧边人物仅作真实环绕关系 | 演员数量来自剧本；视线聚焦不得变成所有人看摄影机 |
| C19 双人中心靠拢 | 双人头中心可设 x40/x60，肩靠近但脸不重叠，取胸像，背景弱化；机位同时看到两人脸 | 靠拢需符合关系与动作，不默认贴脸或身体接触 |
| C20 背对背 | 双人身体靠画中，背部相接或留明确小间隔；一人面向左，一人面向右，侧面机位看清相背关系 | 不能同时又写两人面对面；接触必须在动作账本中成立 |
| C21 / C30 双人同侧重压 | 两人集中在同一半幅，前后错开使脸可读，另一侧留窗/墙空区；一坐一站需分别指定头高和地面位置 | 空区可形成疏离/等待，不必补第三人；避免重叠导致一人长两头 |
| C22 / C35 窗框、门框套景 | 外框贴两侧及上缘，人物在框洞内部，中间保留通道纵深；摄影机明确在框外看入 | 框是实物而非黑边滤镜；别让门框穿过主角眼睛 |
| C23 前景遮挡 | 已有植物/肩背从单侧入画，建议先用占宽 10–25% 的边缘遮挡，主体脸位于其余清晰区域 | 这不是固定上限；R20 可更大。写清来源、虚实、遮住什么与必须露出什么 |
| C24 纵深引导 | 近人置左前 x20–35，远人置右后 x65–80；走廊边线向远处收拢，机位偏走廊一侧 | 用相对头高比较远近；不要把近景裁切身体与远处全身做占高比较 |
| C25 中央消失点 | 机位对准直走廊，消失方向在 x50；对峙两人左右分列，中间留完整纵深通道 | 消失点由空间平行线形成，不能规定所有斜线必须汇于鼻尖 |
| C26 边缘压迫 | 人物靠近画边，后脑或肩部留很小余量，前方视线空间有意压缩；另一人在远处 | 区别于普通看向留白，压缩需要戏剧情绪动机，不作为默认人像 |
| C27 / C28 小人物大环境 | 人物全身占高约 10–25%，两人横向分开，建筑占主要面积；机位远离角色并展示地面关系 | C28 标题与图意相反，以可见画面为准；不照抄“大人物小环境” |
| C29 实体分隔 | 门柱/墙边位于中部，两人分别在其两侧，面向对方但被实体隔开一部分；机位略偏侧看清分隔物厚度 | 指定各自在墙前/墙后还是两间房，不能让身体穿墙 |
| C31 行进留白 | 人物从左向右行走时落在画面左半部，右半部保留目的地方向；机位侧跟或固定，明确起终位置 | 不能一边向右走一边把前方空区留在左侧，除非刻意逆向构图并说明 |
| C32 目光留白 | 人物面向右就放偏左，视线前方保留可容纳目标的空间；眼线高度与目标相符 | 留白可以是已有环境，不必让视线目标实体入画 |
| C33 前后追逐 | 近处被追者偏右、远处追者偏左错开脸，二者沿同一路径同向移动，近人投影较大 | 给起终间距及速度关系；不是两个角色原地做跑步表情 |
| C34 回头反向 | 前景人物躯干朝离开方向，头转回看后方对手；后者仍在原处或沿已定路径离开，机位拍清头肩扭转 | 分开写身体、头、眼方向，禁止只写“背对镜头看镜头”这种歧义句 |
| C36 实体与反射 | 实体人物靠玻璃一侧，玻璃平面中出现同一人物镜像；机位斜对反射面，明确实体/像的位置与虚实 | 反射必须符合平面关系，同一人不计为第二演员；镜面本身不任意加角色 |

## 4. 两张插画页补充：景别、角度与透视不能混用

R01 / `_2_191` 与 R02 / `_3_191` 有重复构图，但提供了以下独立参数。使用真人资产时只取构图关系，不继承动漫脸、校服、蓝天或屋顶设定。

| 类别 | 执行写法 | 容易混淆的地方 |
|---|---|---|
| 头肩 / 胸像 / 半身 / 膝上 / 全身 | 逐一写“发顶至肩部”“发顶至胸部下缘”“发顶至腰部”“发顶至膝盖上方”“从发顶到鞋底完整入画”；再设头顶留量及手是否入画 | 景别译名可能不统一，以身体裁切边界为准；尽量不要在手腕、膝关节正中截断 |
| 面部特写 / 局部大特写 | 特写说明发顶、下巴是否保留；极近景点名眼、鼻或手等局部及出画边 | R12/R19 属特殊裁切；不可强行补出全脸满足普通人像比例 |
| 全身 / 远景 / 大远景 | 全身以完整头脚为条件；远景进一步降低人物全身占高、增加环境；大远景人物可降至约 5–15% 高 | 这些比例仅设计起点，不是硬性行业边界；画幅与叙事任务优先 |
| 平视 / 低角 / 高角 / 顶视 | 平视：接近主体眼高且基本水平；低角：镜头低于观察目标并向上；高角：高于目标并向下；顶视：从上方近垂直看地面布局 | 低机位不必仰拍，高机位不必俯拍；高度与光轴俯仰分别填写 |
| 荷兰角 | 镜头绕光轴顺/逆时针横滚，例如设计 8°，环境竖线整体倾斜；说明人物仍受重力竖直站立 | 荷兰角不是低角，也不是楼梯天然斜线；静帧中倾斜建筑不一定来自横滚 |
| 过肩 / 跟背 | 过肩必须写 A 的哪侧肩背在前景、B 在哪侧清晰；只看到一个人物背后与环境时写跟背/背面观察更准确 | R02 的示意格不能自动证明存在第二名被摄角色，不能从“过肩”标签补人 |
| S 形引导 | 真实小径或栏杆从画面下部弯向中部再延至远处，人物落在其中一处转折，交代所在位置与朝向 | 没有弯路的场景不凭空改地形；直走廊不能同时设为 S 形 |
| 单人身体三角 | 头为上顶点，展开的双臂/肩线或衣摆为下部两角，机位正面或轻侧，姿态仍自然 | 不需要三个人，也不要为了几何强行反关节或扩大裙摆 |
| 倒影 / 镜中观察 | 水面倒影在实体下方；竖直镜像在镜面边界内。先定反射面方向、实体站位、机位，再写像的区域 | 水面与墙镜的映射不同；反射不是生成一名相似演员 |
| 长焦压缩感 / 环境肖像 | 要压缩感，可设计更远机位配合较长焦段保持裁切；要环境关系，保留建筑、道路与主体的尺度关系 | 透视主要随机位改变，焦段本身不把空间挤扁；静图不能实测原焦段 |
| 单人预留双人空间 | 单人偏一侧、另一侧留空，并明确当前只有一人入画；在剧情需要时下一镜才让已存在角色进入 | “可容纳第二人”不等于“现在生成第二人” |

## 5. 最终提示词应怎样落笔

一镜选一个主构图，最多辅以一种前后层次关系。按“**观察方向 → 人物世界位置 → 画面位置与裁切 → 大小关系 → 视线与空区 → 遮挡和焦点 → 起终变化**”连成可以想象画面的句子，不能只交付表格参数或构图名称。

### 示例 A：双人隔桌关系镜（设计值，不是原片实测）

> 9:16 竖画幅，摄影机位于长桌近端，处于两名坐者连线的室内一侧，镜头接近坐姿眼高、保持水平，看向桌后窗户。A 坐在桌左侧，头部中心约 x25/y45，侧脸朝右看 B；B 坐在桌右侧，头部中心约 x75/y45，侧脸朝左看 A。两人位于相近纵深，头部投影大小接近，均保留头肩、上身和桌边的手；两人之间是未被身体填满的桌面。桌近端横贯画面下部，左右桌边向中央后方收拢，窗格在后景。焦点覆盖两人脸部，前景不加陌生肩背。本镜 A 从身前缓慢向桌心伸出已锁定的一只手，B 的坐位保持，结尾手停在桌面上方而未接触 B；是否伸手以原剧情为准。

### 示例 B：单人右三分中近景（设计值）

> 摄影机在 B 侧前方、已建立对话轴的室内一侧，以眼平角度取发顶至胸部下缘。B 的头部中心位于画面 x65 附近，眼线约 y35，侧脸朝画左看坐在画外的 A；鼻尖前方保留约三分之一画宽的背景空间，后脑不贴右边框。背景仅保留该方向实际可见的窗框，弱化成柔和线条；B 的眼和嘴清晰，没有前景人头。结尾 B 目光从 A 的脸下降至 A 伸出的手，头部只小幅下转，身体不换座。

### 示例 C：前景大躯干与后景小坐者（设计值）

> 摄影机在 A 离桌后走近的通道旁，镜头朝仍坐在原椅上的 B。A 的白衣躯干从画右近距离经过，占画宽约 60–70%，头脸裁出上缘，肩背失焦；B 留在画左后层，头中心约 x18/y48，脸与胸口完整露在前景躯干之外。前景大、后景小来自两人的实际距离，不拉伸 B 的身体。A 沿原定出门方向继续移动，结尾右侧遮挡略减少，B 的椅子与桌角位置保持。只有原剧本已有离开动作时采用。

这些是构图教学范例，不是本批图片的原剧情还原。生成正式提示词时，将“原剧情允许时”的选项先解决，改为唯一可执行动作；不要把备选条件交给生成模型自行选择。A/B 替换成实际角色引用。

在 Format C 中：机位/角度/焦段放 `镜头`；站位/比例/裁切/起终状态放 `画面`；焦点/视线留白/线条放 `视觉引导`；支撑/接触/背景关系放 `人物背景融合`；光源与逆光放 `光影细节`。保留十一字段，完整台词仅进入 `音频`，不能为解释构图重复粘贴台词或把长发言拆组。

## 6. 构图验收：检查能否唯一还原

1. 站在哪里与出现在画面哪里是否分别说明；坐者是否有椅面支撑、手是否有归属？
2. 比例是否注明是头高、可见身体高、全身高或占宽；坐标与裁切是否兼容？
3. 机位在谁的前/后/侧、轴线哪一侧；高度、俯仰、横滚是否分开；是否把推断冒充原片参数？
4. 谁在前、谁在后、谁清晰、谁遮住谁；同一平面的人为何大小不同，近大远小是否有空间依据？
5. 头、身体和眼的方向是否自洽，视线目标是否在正确画外方向；正常留白与有意压迫是否混用？
6. 最终文字是否写了具体位置而非只写“高级电影构图”；数值是否只是必要锚点而非互相打架的密集指令？
7. 起终构图变化能否由同一条人物/摄影机路径得到；切镜后人物、桌、门和视线是否仍连续？
8. 原演员数量、资产、英文原台词、完整发言分组是否保留；图片的标题、示例设定、水印是否被误当生成要求？
