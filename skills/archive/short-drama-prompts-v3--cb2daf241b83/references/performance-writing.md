# Format C V2.5 表演、声音与位置锁定

格式与强制条款以[用户模板全文](format-c-v2.5-source.md)为准，本页落实演员和空间信息，不能覆盖当前源剧情与用户要求。

## 每个独立shot内的位置锁定

- 分开写实际空间坐标与当前画面坐标。床戏先以站在床尾面向床头为参照确认床左/右、里/外、各自枕位，再按该shot机位推导画面左右与前后；桌边、门口也使用固定参照。
- 在 `画面` 字段明确本镜谁在何处，仰卧/侧卧/坐/站，身体哪侧承重，头脚朝向、躯干朝向、视线对象；在 `镜头` 字段写摄影机处于关系轴线哪侧、距谁更近、何者作前景。
- 拉拽、翻身、圈抱写接触手、空闲手、受压手、支撑面、起点、路线、落点与对手反应。换景别和拉焦不让人自动互换床位或移到对方身上。
- 末镜再次独立写稳定终态并核对下一组起态；省略“切床尾偏高”中的具体侧别会失去锚点，必须补实。镜头真实换侧时重推画面坐标，不机械锁死所有机位的同一左右。
- 细节特写写清部位归属和前一镜动作阶段，不能要求颈侧局部镜同时看见画外眼睛/整肩；落点若不可见，不能声称观众看见。

## 表演的触发与反馈

人物先有当前目标和阻力，再有视线、呼吸、手指、肩背、重心和语句停顿等少量有效证据。明确谁发现了什么、向谁行动、对方如何反馈、动作在哪里收住。按景别选择看得见的细节，不统一套用叹气、笑、眨眼、攥衣或哭泣。

`微表演` 与 `对白反应` 只写可见表演，不重复台词或描述声音。无对白时写触发、沉默承受者、身体/道具反应和稳定终态；只拍手部时在可见范围写手部反馈，不虚构画外面部反应。熟睡的人可保持睡态，不能为了填字段让他主动托举、睁眼或说话。

意图注解须跟在完整物理描述之后，单字段最多一条、单镜建议1–3条、每条不超过20字，仅用在原文允许字段。音频、光影和负面提示词不加意图注解。

## 声音与资产

- 原对白、允许的旁白、环境声和动作音效全部放 `音频（Audio）`；对白文字按源语言原文和标点保留。未获准新增旁白或当前要求无旁白时，不从参考片重新抄入。
- 只有当前说话者有口型；听者和画外旁白画面中的人物保持相应沉默动作。正面机位仍看戏内对手，角色互看不等于直视镜头。
- 没有对应音频文件就写说话人和说法，不编@音频文件编号；角色音色与独立录音分开。
- 引用资产后不重写服装款式、色彩、材质、领口、系带或裸露造型；保留抓拢、拉紧、整理、放开的动作，用“衣物/衣料”等中性对象。用户指定扣合与遮盖状态照实保留，资产正式名不改。
- 有音频以实测时长为准；无音频只能估算。对话覆盖、动作拆解和节奏规划服务于原文，不新增情节或删词凑数。
