# Format C V2.5 输出骨架

先完整读取[用户原文](format-c-v2.5-source.md)，以下仅是字段骨架，不替代强制段和细则。组数、镜数、时长依源剧情和当前要求决定；各shot从1重新编号。

```text
第<集号>集 EP<集号>
<组编号与本组事件>
<真实人物、场景、道具及已指定资产映射；画幅、当前人物状态和必要项目覆盖>

【组头｜固定画质词与光影基调】
固定画质词（Fixed Quality Descriptor）：<逐字写入原文第三节固定词及皮肤强制段；明确的项目覆盖另注>
光影基调（Lighting Tone）：<参考气质、主光、方向高度、光线性质、冷暖、面部亮暗、阴影和反射；单独写明人物脸部明亮、五官清晰可辨>
节奏结构（Beat Structure）：<组型｜镜数｜共x.xs；铺垫、递进、最强拍、余韵与各镜时长>
景别循环（Shot Size Cycle）：<本组实际镜数对应的景别与机位角度序列>
视觉动线（Visual Flow）：<组内重心迁移、主运动方向和关系轴线>

【shot 1｜镜头主体｜景别（Shot Size）｜视角（Angle）｜运镜（Camera Movement）｜焦段（Focal Length）｜duration: x.xs】
叙事任务（Narrative Task）：<不超过25字的一项任务>
镜头：<本镜实际机位、支撑空间、焦点及必要运动>
画面：<本镜独立位置锁定、起始姿势、行动、对手反馈、稳定终态>
视觉引导（Visual Flow）：<重心、方向、与上镜接点、视觉减法；每个可见角色的戏内视线落点>
微表演（Micro-Performance）：<当前触发下的可见具体部位变化；按模型能力选择短意图注解>
对白反应（Dialogue Reaction）：<说话与沉默者的触发和微反应；无对白时写沉默行动，不新增人声>
人物背景融合（Subject-Background Integration）：<深度、遮挡、尺度、接触与环境连续>
光影细节（Lighting Detail）：<仅补相对组头发生的变化>
音频（Audio）：<仅此字段写获准原对白、旁白、自然现场声或动作音效；标说话人与说法。未提供文件不编@音频编号>
运动强度（Motion Intensity）：<动作力度、速度、重心、接触、收住及当前拍型>
负面提示词（Negative Prompt）：<原文第十三节通用及该镜专项词；人物镜保留视线与第四面墙负面项，每组保留皮肤专项>

<按本组实际镜数依次展开各shot全部字段>
```

不得把台词搬入画面、微表演或对白反应，也不得把现场声写成组外声音段。若每shot单独投递，把完整组头与该shot拼接，连同本镜人物位置锁定一起交给生成端，不使用跨组“同上”。
