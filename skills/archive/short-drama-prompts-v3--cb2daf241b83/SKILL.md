# Format C 视频提示词 V2.5

用户于2026-10-22指定以新提供的《Format C 视频提示词模板 V2.5（节奏强化版 · 视线管理）》替换原提示词技能。保留 `short-drama-prompts-v3` 路径供现有调用兼容，名称中的 v3 不代表继续使用旧时间轴模板；当前唯一权威格式为本技能所载 V2.5。

新写、续写或重做最终提示词前，完整读取[用户模板原文](references/format-c-v2.5-source.md)；用[输出骨架](references/format-c-template.md)核对字段，并按[表演、声音与位置锁定](references/performance-writing.md)落实当前事实。原文逐字保存，不以摘要代替原文的画质、皮肤、泪水、视线及负面词要求。当前用户具体要求和当前项目附录优先于通用模板；样例人物、动作与音频编号不作为当前故事事实。

## 格式和执行解释

- 已知集号先写集号，再列组号、真实人物/场景/道具及资产映射。每组独立完整，使用原文组头五项：固定画质词、光影基调、节奏结构、景别循环、视觉动线；随后使用原文 shot 标题和十一字段。只交请求的最终提示词，不额外叠加公开分镜表或检查表。
- 组以光影与空间连续性划分。按原文第2.0节及V2.2修订记录，每组3–8镜、8–24秒，默认5镜15秒，非固定五镜十五秒；组头声明组型、镜数、总时长、最强拍与非均匀节奏，各镜时长合计精确到0.1秒。原文残留的“五个shot/总和恒为15秒”按这一后续修订解释。
- 单镜通常1.0–6.0秒；第15.1节允许更短的特殊冲击接触镜，应标目标剪辑时长与实际生成时长，不能一面写低于1秒一面称满足普通下限。当前指定时长优先；不靠删台词、硬加速或编新情节凑配额，范围冲突在组头说明。
- 第三节固定画质词和皮肤强制段每组逐字保留一次，面部明亮单列；流泪时完整采用第十一节泪水段。项目有不同焦段、画幅或画质时按原文项目附录机制明确覆盖相应项，不能组头固定85mm、镜头又无说明地用冲突焦段。
- 所有声音与原台词只写 `音频（Audio）`；其他字段只写可见动作与表演。默认英文原台词逐字保留；当前项目明确要求其他源语言时按其原文，不擅自翻译。旁白/内心独白须核实来源和当前允许范围，用户已要求删除时不因模板允许而恢复。
- 每镜一项叙事任务，按原文执行景别/角度变化、对白覆盖、动作拆解、切点与组尾钩子。内部规划不以额外公开表格充数；剧情事实和本次范围不因格式换版而扩大。
- 每个独立shot都写清该镜实际位置、画面位置、身体朝向、接触和支撑、手部归属、镜头侧别及视线目标；不能只在组头写一次。换机位重新推导画面左右；拉焦不改人物实际床位。角色可以在戏内互相对视，“视线不入镜头”禁止的是注视镜头/观众。
- 情绪用触发、可见行动和对手反馈承载。无对白也保留 `对白反应` 字段，描述沉默反应及稳定终态，不编对白、意外口型、BGM或旁白。熟睡、平静、克制等当前状态不因“每镜有反应”被改成睁眼、微笑或哭泣。
- 原文“每镜面部/眼神变化”按该镜实际可见范围落实：手部、颈侧等局部特写描述可见部位的反应，并交代画外人物状态，不强塞看不见的面部或眼睛。第七/十五节的拆解下限用于原文所称关键、重点动作，不把每次眨眼、松指等从属微动作都另扩三镜；用户锁定镜数时仍须分清关键动作阶段，不靠新增剧情凑镜。
- 第十八节意图注解按已确认模型能力启用，去掉注解仍须有完整物理动作；未知模型不自动提交A/B生成，需在授权范围内验证。

## 维护和平台边界

已有批准稿只改用户指定部分，冻结其余事实、结构、台词、时长与引用；技能替换本身不批量重写或重做旧视频。普通镜头设计仍交设计稿，明确要求最终提示词时才使用本格式。

资产外观由用户指定参考决定，清理服装描述时保留动作，用中性受力对象承接。项目有附录时先读项目AGENTS及附录，再确定人物阶段和当场位置，不把角色性格或床位固定成跨场景通用值。

平台填入、引用、保存或生成另读[剧梦制作技能](../jumeng-episode-producer/SKILL.md)，只做本次授权阶段。普通@文字不等于原生卡；保存需重载回读，提交、生成完成和实际播放验收分别记录。维护技能和附件不构成上传、发送、付费生成或修改所有旧稿的授权。
