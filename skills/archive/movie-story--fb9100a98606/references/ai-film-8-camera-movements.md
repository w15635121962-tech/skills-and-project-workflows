## 八大运镜速查表

| # | 运镜 | 核心动作 | 一句话作用 |
|---|------|---------|-----------|
| 1 | **推** Push In | 镜头向前推进 | 聚焦细节，制造悬念 |
| 2 | **拉** Pull Out | 镜头向后拉远 | 从局部到全景，释放情绪 |
| 3 | **摇** Pan | 固定机位水平旋转 | 扫视环境，串联空间 |
| 4 | **移** Dolly/Truck | 机位平行移动 | 沉浸式跟随，身临其境 |
| 5 | **跟** Tracking | 镜头随主体移动 | 最强沉浸感，锁定主角 |
| 6 | **升** Crane Up | 镜头垂直上升 | 气势磅礴，打开视野 |
| 7 | **降** Crane Down | 镜头垂直下降 | 聚焦个体，营造渺小感 |
| 8 | **转/环绕** Orbit | 镜头绕主体旋转 | 立体展示，突出核心 |

## 一、推镜头（Push In）⭐ 最常用强调

**动作**：镜头从远向近移动，画面视野收窄。

| 维度 | 内容 |
|------|------|
| **核心作用** | 突出主体、引导视线、制造悬念 |
| **情绪效果** | 紧张递进、关注聚焦、压迫感 |
| **AI 提示词** | `推镜头 / 镜头缓慢推进 / 镜头逐渐推近` |

```
完整案例：
推镜头，斗笠的阴影从她脸上渐渐褪去，清晨的天光一寸寸照亮她的面容。
眉心先微微蹙起，然后缓慢舒展，一抹怜悯从眼底浮上来。

——画面从半身景别推进到面部特写，观众注意力被一步步引导到微表情上。
```

**适用赛道**：情感戏、悬疑、产品展示、微表情特写

---

## 二、拉镜头（Pull Out）⭐ 情绪释放

**动作**：镜头从近向远移动，画面视野拓宽。推镜的反向操作。

| 维度 | 内容 |
|------|------|
| **核心作用** | 交代环境关系、释放情绪、营造"豁然开朗" |
| **情绪效果** | 释放、孤独、渺小、真相大白 |
| **AI 提示词** | `拉镜头 / 镜头缓慢拉远 / 镜头逐渐后退` |

```
完整案例：
拉镜头，从她握着电话的手开始缓慢后退。她独自站在空荡荡的候车大厅里，
四周的座椅空无一人，天花板上的日光灯管忽明忽暗。然后继续拉远，
整个车站像一座孤岛漂浮在夜色中。

——从手部特写拉到车站全景，情绪从聚焦到释放，孤独感层层递进。
```

**适用赛道**：情感类（"你失约的海我一个人来了"）、悬疑揭晓、大场景展现

---

## 三、摇镜头（Pan）⭐ 丝滑转场

**动作**：相机固定机位，镜头沿水平方向左右转动（像人左右转头）。

| 维度 | 内容 |
|------|------|
| **核心作用** | 展示横向广阔场景、串联多个主体 |
| **情绪效果** | 观察感、信息递进、空间建立 |
| **AI 提示词** | `摇镜头 / 镜头缓慢向右摇动 / 镜头扫过` |

```
完整案例：
摇镜头，从冰封的湖面向右缓缓摇动。先扫过湖边枯萎的芦苇丛，
然后经过一棵被积雪压弯腰的老松树，最后停在远处山坡上的小木屋。
烟囱里飘出一缕白烟，在灰色的天空下格外显眼。

——一个摇镜串联了湖面、芦苇、松树、小屋四个元素，建立了完整的空间关系。
```

**适用赛道**：治愈风景、空间交代、丝滑转场

---

## 四、移镜头（Dolly/Truck）⭐ 身临其境

**动作**：相机机位平行移动（左右或前后），机位动但镜头不转。

| 维度 | 内容 |
|------|------|
| **核心作用** | 沉浸式跟随感，比摇镜更有"在场感" |
| **情绪效果** | 陪伴感、游走感、身临其境 |
| **AI 提示词** | `移镜头 / 镜头平行跟随 / 镜头横向移动` |

```
完整案例：
移镜头，镜头与小女孩保持同速平行移动。她骑着自行车穿过稻田间的土路，
金黄的稻穗从她两侧匀速后退，远处的风车缓缓转动。
一只白鹭从田埂上惊起，掠过她的头顶。

——移镜头让观众感觉自己在和小女孩一起骑车前进。
```

**适用赛道**：运动跟随、旅行 Vlog、宫崎骏风格

---

## 五、跟镜头（Tracking/Follow）⭐ 沉浸最强

**动作**：镜头始终跟随主体移动，主体在画面中位置不变，背景持续变化。

| 维度 | 内容 |
|------|------|
| **核心作用** | 观众"跟着走"，沉浸式代入 |
| **情绪效果** | 代入感、紧迫感、亲密感 |
| **AI 提示词** | `跟随镜头 / 跟镜头 / tracking shot` |

```
完整案例：
跟随镜头，男主角大步穿过战后的废墟。他直视前方，眼神坚定。
镜头在他前方后退跟拍，保持他的面部始终在画面中央。
断壁残垣从他身后掠过，远处还有未熄灭的火光在跳动。

——正面后退跟随，观众既能看到主角情绪，又能感受环境压迫。
```

**适用赛道**：动作戏、情感行走、长镜头叙事

---

## 六、升镜头（Crane Up）⭐ 气势磅礴

**动作**：镜头从低向高垂直移动，画面视野向上展开。

| 维度 | 内容 |
|------|------|
| **核心作用** | 展示宏伟、提升气势、从局部看全局 |
| **情绪效果** | 震撼、释然、宏大叙事 |
| **AI 提示词** | `升镜头 / 镜头缓慢上升 / 镜头升起至高空俯瞰` |

```
完整案例：
升镜头，从男主角的靴子开始。他站在雪地中，镜头缓慢上升，
经过他的大衣下摆、腰间佩剑、宽阔的肩膀，最后越过他的头顶，
视野豁然开朗——茫茫雪原在他身后无边无际地铺展开来。

——从脚底升到头再到全景，一个升镜完成了角色建立和环境交代。
```

**适用赛道**：城市文旅、角色出场、场景建立

---

## 七、降镜头（Crane Down）⭐ 聚焦个体

**动作**：镜头从高向低垂直移动，升镜的反向操作。

| 维度 | 内容 |
|------|------|
| **核心作用** | 从宏大落到个体，制造渺小感或聚焦感 |
| **情绪效果** | 渺小、温馨、压抑、聚焦 |
| **AI 提示词** | `降镜头 / 镜头缓慢下降 / 镜头从高空降落至地面` |

```
完整案例：
降镜头，从万米高空的云层开始下降。穿过厚重的乌云，雨滴开始在镜头上
凝结成水珠。城市的天际线逐渐变大，街道可辨，最后落到一条潮湿小巷里，
一个女孩撑着红伞站在路灯下等待。

——从云端降到一个人，世界很大我很小的感觉瞬间拉满。
```

**适用赛道**：情感开场、故事引入、航拍转地面

---

## 八、转/环绕镜头（Orbit）⭐ 展示核心

**动作**：镜头围绕主体做 360° 旋转运动。

| 维度 | 内容 |
|------|------|
| **核心作用** | 立体展示全貌、强化空间关系、突出主角 |
| **情绪效果** | 眩晕感、强调感、主角光环 |
| **AI 提示词** | `环绕镜头 / 镜头围绕主体360度旋转 / 轨道环绕` |

```
完整案例：
环绕镜头，镜头以女子为中心做缓慢的360度环绕。她站在旋转楼梯的底部，
一束阳光从穹顶的玻璃窗穿透下来。环绕过程中，她始终凝视同一个方向，
但周围的场景不断变换——书架、壁炉、钢琴、巨大的落地窗依次出现。

——一个环绕镜头展示了整个大厅空间，同时锁定主角为核心。
```

**适用赛道**：产品展示、角色亮相、英雄出场

⚠️ 注意：环绕镜头属于装饰性运镜，新手慎用，避免滥用。

## 补充：手持镜头（Bonus）⭐ 纪实真实感

虽然不是传统的八大运镜之一，但「子言AI」视频中很可能也涵盖了这个在 AI 短视频中极其实用的技巧。

| 维度 | 内容 |
|------|------|
| **核心作用** | 模拟真实手持拍摄，注入临场感 |
| **情绪效果** | 真实、紧张、纪实、身临其境 |
| **AI 提示词** | `手持拍摄 / 镜头轻微晃动 / 纪实感 / 动态不稳定 / 临场沉浸式` |

```
案例：
手持镜头，战地记者举着自拍杆穿越古代战场。镜头因奔跑而剧烈晃动，
箭矢从画面两侧"咻咻"飞过，地面震动，远处传来战鼓声和喊杀声。
偶尔镜头扫过自己的脸——满脸尘土和惊恐。

——手持抖动 + POV 视角 = 极强的代入感和真实感。
```

## 运镜选择决策树

```
你想让观众感受到什么？

紧张/聚焦 ──→ 推镜头
释放/孤独 ──→ 拉镜头
观察/扫描 ──→ 摇镜头
陪伴/游走 ──→ 移镜头
代入/跟随 ──→ 跟镜头
震撼/宏大 ──→ 升镜头
渺小/聚焦 ──→ 降镜头
展示/强调 ──→ 环绕镜头
真实/纪实 ──→ 手持镜头
```

## AI 运镜提示词通用公式

```
【运镜指令】镜头[速度：缓慢/快速/逐渐][方向：推/拉/升/降/左摇/右摇]
【主体描述】[谁？在做什么？]
【环境变化】[背景如何变化？]
【画面质感】电影级质感 / 4K超清 / [光影风格]

💡 提示词越具体，AI 出片越精准。
```

## 新手建议

1. **先练固定镜头** — 画面稳定是基础，先把内容拍好再加运镜
2. **一个提示词一个运镜** — 组合运镜是进阶技巧，新手先单独练
3. **运镜要服务于内容** — 不要为了炫技而运镜，问自己"这个镜头为什么动"
4. **教程看百遍不如自己练一遍** — 海螺AI / 即梦 / Seedance 都可以练手
