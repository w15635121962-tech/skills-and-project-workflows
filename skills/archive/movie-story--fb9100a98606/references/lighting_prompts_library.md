## 一、方向光类（8种）

---

### 1. 顶光 (Top Lighting)

**关键词**：`top lighting`, `light from ceiling`, `shadows under face`

**适用**：压迫感、神秘、审判

**英文模板**：
```
[subject], top lighting, light source from ceiling or above, dramatic shadows under facial features (nose, brow, chin), [atmosphere: oppressive / mysterious / dramatic], [setting: interrogation room / church / stage / corridor], cinematic lighting, photorealistic, 8K, --ar 16:9
```

**中文模板**：

## 通用技术参数速查

| 参数 | 说明 | 常用值 |
|------|------|--------|
| `--ar` | 画面宽高比 | 1:1 方图 / 2:3 肖像 / 3:4 肖像 / 4:5 社媒 / 9:16 竖屏 / 16:9 横屏 / 2.39:1 宽银幕 |
| `--v` | Midjourney 版本 | 6 / 6.1 |
| `--s` | 风格化程度 | 50(写实) / 250(中等) / 500(强风格) |
| `--style raw` | 原始风格 | 减少自动美化，更贴近提示词 |

## 光比控制速查

| 光比 | 效果 | 适用场景 |
|------|------|----------|
| 1:1 | 几乎无阴影、极其柔和 | 高调商业、美妆 |
| 1:2 | 柔和自然、保留阴影层次 | 标准人像、自然风 |
| 1:4 | 明显阴影、立体感强 | 电影感、气质人像 |
| 1:8 | 戏剧性高对比、暗部深邃 | 黑色电影、低调光 |
| No fill | 完全黑暗暗部 | 分割光、极致戏剧 |
