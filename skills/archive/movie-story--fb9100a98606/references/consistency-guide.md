# 人物与场景一致性规范

## 〇、Full Script Fidelity 一致性（最高优先级）

剧本完整性是一致性的前提——如果分镜遗漏了原始剧本的内容，所有其他一致性检查都失去意义。

**一致性规则**：
- 分镜输出的场景序列必须与原始剧本的场景序列一一对应，不可跳过任何场景
- 分镜中的台词必须与原始剧本逐字保留，不可合并、改写或省略
- 原始剧本中的每一段动作描述必须至少有一个对应镜头覆盖
- 原始剧本中的每一个括号说明（情绪/节奏/表演指示）必须在分镜中有所体现
- 任何时空转换点必须有对应的转场处理

**Exhaustive Inventory 与一致性的关系**：
- Inventory清单是完整性核对的基准——没有清单=无法核对=无法保证完整
- 清单中的数字（X个场景/Y句台词/Z个动作块）是最终100%覆盖声明的依据
- 清单数字必须精确，不可估算——估算的数字无法用于交叉核对

**完整性缺失的一致性后果**：
- 遗漏场景→后续场景的空间/时间连续性断裂
- 遗漏台词→角色行为动机链断裂→动作一致性逻辑坍塌
- 遗漏动作→走位/位置连续性无法建立→180度轴线可能被违反
- 遗漏括号说明→情绪基调不匹配→光影/色彩一致性可能偏离

## 一、为什么一致性是分镜的生命线

分镜的核心用途是让导演、摄影、美术、服装等部门对"画面应该长什么样"达成共识。如果一个镜头里角色穿着红衣，下一个镜头变成蓝衣；一个镜头光源从左来，下一个从右来——不是"艺术选择"，而是"制作事故"。

对于 AI 生成场景，一致性的重要性更加放大：AI 没有上一帧的记忆，每次生成都从提示词重新开始。如果提示词中的角色/场景描述不一致，AI 输出的画面必然不一致。**提示词中的锚定描述就是 AI 的"上一帧记忆"。**

## 二、角色一致性

### 2.1 角色视觉锚点表（全片级）

为每个有台词或重要动作的角色建立一张锚点卡，分三层管理：

**锚定层（不可变）**——全片从头到尾不变的核心特征：

| 属性 | 说明 | 示例 |
|------|------|------|
| 体型与轮廓 | 高矮胖瘦、肩宽、整体剪影 | 中等偏高偏瘦，肩线方正，剪影修长 |
| 面部基础 | 骨架、肤色、核心五官特征 | 眼窝深陷，颧骨突出，下颌硬朗，肤色偏白 |
| 头部/发型 | 发色、发长、标志性发型 | 黑色短发，鬓角碎发 |
| 核心服饰 | 贯穿全片的主服装 | 厚重哑光深色长袍 |
| 标志性道具 | 角色的视觉符号 | 红色护目镜 |
| 色彩标签 | 角色的主色调 | 深灰黑 + 红色点缀 |
| 体态习惯 | 站姿、步态、手势习惯 | 站立时双脚扎地、双肩方正，动作缓慢克制 |

**变化层（可变，但需追踪）**——随剧情变化的视觉状态：

| 属性 | 说明 | 管理方式 |
|------|------|----------|
| 服饰变化 | 换装、破损、添加配饰 | 逐场标注变化原因和结果 |
| 身体状态 | 受伤、疲劳、妆容变化 | 逐场标注变化原因和结果 |
| 道具增减 | 获得/失去/使用道具 | 逐场标注道具链 |
| 情绪外化 | 表情、体态的极端变化 | 标注情绪拐点 |

**一致性红线（绝对不可矛盾）**——每个角色选 2-3 个核心特征作为硬校验项：

- 这是自检时的必选项，任何镜头如果违反红线即为"高严重度"问题
- 红线应该是最能定义"这就是这个角色"的视觉特征
- 示例：Johnny 的红线 = 护目镜红色 + 长袍厚重哑光 + 体型修长方正

### 2.2 角色跨镜头一致性规则

1. **同一场景内**：角色外观必须完全一致（锚定层 + 当前变化层）。不允许"切镜后衣服变了"。
2. **跨场景（时间连续）**：角色外观保持上一场景结束时的状态，除非有明确的变化事件（如"他脱去了斗篷"）。
3. **跨场景（时间跳跃）**：允许外观变化，但必须在分镜中标注变化，且变化必须合理。
4. **多角色同框**：每个角色的锚点表独立维护，同框时所有角色的锚定层都需校验。

### 2.3 微表情与生理状态一致性

角色的生理状态（眼泪、汗水、伤口、妆容变化等）是变化层中特别容易出问题的类别，因为它们有明确的时间物理逻辑——不像换衣服可以瞬间完成，眼泪和汗水的消退需要时间。

**眼泪一致性规则**：

眼泪在连续镜头中必须遵循物理时间线：
- **溢出时序**：眼泪总是从内眼角开始（泪腺位置），如果 S1-03 角色刚流泪，S1-04 不能突然满脸泪痕——必须经过足够的物理时间
- **滑落进度**：眼泪在脸颊上的位置只能向后（向下）移动，不能"回退"。颧骨处汇聚→滴落是单向过程
- **湿润反光演变**：泪痕的湿润反光随时间从窄亮→宽暗。切镜后泪痕反光不能突然变亮（除非角色又哭了）
- **妆面晕开不可逆**：睫毛膏/眼线一旦被泪液晕开，不可恢复原状。后续镜头必须保持晕开状态
- **睫毛泪珠**：随时间推移，睫毛上的泪珠可能因眨眼而减少或掉落，但不能凭空增加（除非再次流泪）

**眼泪跨镜头校验清单**：
1. 上一镜头眼泪在脸颊的位置，下一镜头是否合理延续？
2. 泪痕的湿润程度是否与时间流逝匹配？
3. 妆面晕开程度是否只增不减？
4. 如果角色擦了泪，擦泪的手是否有湿痕？

### 2.4 打斗戏角色一致性

打斗戏中角色一致性面临更严峻的挑战——动作导致的外观变化（受伤、衣物破损、武器位移、身体姿态剧变）是连续的、累积的，且极易在快切中丢失追踪。

**武器/道具追踪规则**：
- 为每个持武器角色建立**武器状态链**：持握方式→攻击→回收→换手→脱手→重新拾取
- 每个镜头标注武器的精确位置和持握状态（如"右手正握棍中段，棍尖朝右下"）
- 武器脱手后必须在后续镜头中交代其去向（落地位置、被踢开、被捡起）
- 正反打切换时，攻击方和防御方的武器位置必须与动作连贯——不能攻击方出棍后切到防御方时攻击方的棍已经收回了

**受伤累积追踪**：
- 建立打斗段落的**受伤时间线**：每个伤害事件标注部位、类型、可见度
- 受伤是叠加的，不可"自愈"——S1-03被划伤左臂，S1-07左臂必须有血迹/撕裂
- 快切中受伤可能来不及在每个镜头都展示，但关键反应镜头必须体现伤害后果
- 血迹扩散方向受重力影响：伤口在上的向下淌，伤口在侧的向两侧蔓延

**衣物破损累积**：
- 与受伤同理，衣物破损只增不减
- 标注破损位置和程度：撕裂方向、裸露面积、布料飘动状态
- 破损衣物在后续镜头中必须保持——不能下一个镜头衣服又完好如初

**身体姿态连续性**：
- 快切中每个镜头的角色姿态必须与前镜动作的终点一致
- 出招→碰撞→收招：攻击方出棍后，切回攻击方时棍必须处于收招或后续动作位置，不能"时光倒流"
- 被击退的角色的身体位移要在后续镜头中体现——被击退3米后不能在下一个镜头站在原地

**打斗一致性常见错误**：

| 错误类型 | 示例 | 修正方式 |
|----------|------|----------|
| 武器瞬移 | 出棍后切镜武器已收回 | 建立武器状态链，逐镜追踪 |
| 伤害消失 | 前镜有血迹，后镜血迹消失 | 建立受伤时间线，累积追踪 |
| 姿态回退 | 出招姿态在后一镜中"倒带" | 动作起止帧对齐，姿态只能向前 |
| 位移丢失 | 被击退后下一镜站在原位 | 追踪角色空间位置变化 |
| 衣物自愈 | 破损衣物在后续镜头恢复 | 破损只增不减原则 |
| 双手矛盾 | 一手持武器切镜后双手持武器 | 检查换手动作是否被覆盖 |

### 2.5 角色一致性常见错误

| 错误类型 | 示例 | 修正方式 |
|----------|------|----------|
| 颜色矛盾 | 护目镜从红色变成蓝色 | 回溯锚点表，统一为红色 |
| 材质矛盾 | 长袍从"厚重哑光"变成"轻薄反光" | 回溯锚点表，统一为厚重哑光 |
| 体型矛盾 | 角色从"修长"变成"壮硕" | 锚点表校验，保持体型一致 |
| 道具消失 | 手持武器在切镜后消失 | 追踪道具链，标注放置/收起动作 |
| 道具瞬移 | 道具从左手变到右手 | 检查动作调度，补充换手动作 |
| 伤痕时序 | 伤痕在受伤前就出现 | 追踪变化层因果链 |
| 眼泪回退 | 下一镜头泪痕位置比上一镜头更高 | 按物理时间线校验，眼泪只能向下 |
| 妆面回退 | 睫毛膏晕开后又恢复整齐 | 晕开不可逆，保持晕开状态 |

## 三、场景一致性

### 3.1 场景视觉锚点表（场景级）

为每个关键场景建立环境锚点卡：

| 属性 | 说明 | 示例 |
|------|------|------|
| 空间结构 | 建筑类型、空间形状、关键地标 | 纵向长方形中殿，两侧列柱，尽头圣坛 |
| 建筑材质 | 墙面/地面/天花板的材质与质感 | 灰色石质，柱面矿物条纹，湿石地板 |
| 光源体系 | 主光方向+色温+光质；辅助光方向+色温 | 主光=左高冷蓝(7000-8000K)；轮廓光=右后细蓝 |
| 色温基调 | 整体色彩倾向 | 冷蓝灰，低饱和度 |
| 氛围元素 | 雾/烟/雨/灰尘等大气效果 | 蓝雾从地面翻涌（下浓上淡）；体积光柱 |
| 声音基调 | 环境音特征 | 远处滴水声，石室回响 |
| 一致性红线 | 不可矛盾的核心环境特征 | 光源方向(左高)、地面湿反光、雾气层次 |
| 可变元素 | 允许微调的次要特征 | 雾气浓度微调，蜡烛散景可有可无 |

### 3.2 场景跨镜头一致性规则

1. **光源体系不可矛盾**：同一场景内主光方向、色温、光质在所有镜头中一致。这是最容易被忽略也最致命的错误。
2. **空间坐标不可矛盾**：角色在空间中的相对位置（谁在左谁在右、谁靠近门谁靠近窗）在连续镜头中保持一致。建议用简笔平面图辅助校验。
3. **氛围元素保持层次**：雾/烟/雨的方向和浓度层次需一致。一个镜头地面雾浓、下一个镜头地面无雾是严重错误。
4. **材质与色彩基调稳定**：石墙不会变木墙，冷蓝调不会变暖黄调，除非有明确叙事理由（闪电、火焰介入等）。
5. **时间连续性**：同一场景内的时间流逝要合理。如果镜头间角色移动了位置，需要动作调度覆盖这个位移。

### 3.3 场景一致性常见错误

| 错误类型 | 示例 | 修正方式 |
|----------|------|----------|
| 光源翻转 | 主光从左侧变到右侧 | 回溯场景锚点表，统一为左高主光 |
| 色温跳变 | 冷蓝调突然变暖黄调 | 检查是否有叙事理由（火焰介入等），无则修正 |
| 空间错位 | 角色相对位置在切镜后反转 | 画平面图校验，确认180度轴线规则 |
| 道具消失 | 场景中的道具在切镜后消失 | 追踪场景内道具位置，建立道具位置表 |
| 氛围断裂 | 雾气在连续镜头中忽浓忽淡 | 统一氛围参数，标注允许的微调范围 |
| 时间矛盾 | 窗外从黑夜变白天（同一场景内） | 确认时间流逝是否合理 |

## 四、跨场景一致性

### 4.1 同一地点不同时间的场景

如果角色离开某场景后又返回，需要追踪：
- 场景是否发生了变化（时间推移导致的光线变化、破坏痕迹等）
- 角色在此期间是否发生了外观变化
- 场景中的道具状态是否延续（如上次离开时打翻的杯子）

### 4.2 平行叙事场景

如果两条叙事线交替切换（如A场景和B场景来回切），需要：
- 每条线独立维护时间线和状态
- 切回时确认时间和状态的延续性
- 两条线的视觉风格差异是否足以让观众区分

## 五、AI生成场景的一致性策略

### 5.1 提示词锚定法

为 AI 生成器编写提示词时，在开头固定一段"锚定描述"，在所有同场景/同角色的提示词中完全重复这段描述，只替换动作和构图部分：

```
[锚定段 - 每个镜头完全重复]
A solitary figure — Johnny — wearing a heavy matte-woven dark robe with a deep hood, red goggles strapped to his face. In the nave of a Gothic monastery with wet stone floor, cold blue stained-glass moonlight from camera-left high (7000-8000K), thin blue rim light from right-rear, blue-tinted fog rolling up from the floor.

[变化段 - 每个镜头不同]
Low-angle medium shot, Johnny standing with feet planted and shoulders squared, raising both hands to sternum height in a ritualistic combat mudra...
```

### 5.2 角色参考图法

如果 AI 工具支持参考图（如 Midjourney 的 `--cref`、Stable Diffusion 的 ControlNet、IP-Adapter），优先使用参考图锁定角色外观：
- 为每个角色生成一张"标准参考图"，包含正面半身、全身、侧面三个角度
- 所有该角色的镜头生成时都引入这张参考图
- 角色外观变化后，更新参考图

### 5.3 场景参考图法

同理，为每个关键场景生成一张"环境参考图"：
- 选择最能代表该场景的宽幅构图
- 包含光源方向、氛围、材质等核心元素
- 所有该场景的镜头生成时引入参考图

## 六、手持摄影与一致性

### 6.1 手持强度的一致性

同一场景内，手持的层级不应无理由跳变。如果一场打斗前半段是临场感手持，后半段突然变成呼吸感手持（除非有叙事理由），观众会感到不自然的断裂。

**手持强度连续性规则**：
- 同一打斗段落内，手持层级可以递进（呼吸感→临场感→混乱感），但不能倒退（混乱感→呼吸感=从战场突然变回客厅）
- 递进必须有触发点：呼吸感→临场感的触发点是"第一击"；临场感→混乱感的触发点是"角色首次被重创"
- 从混乱感恢复到临场感需要一个过渡镜头（如角色倒地后的静止时刻，摄影机逐渐稳定）

**常见错误**：
- 打斗前半段固定机位，后半段突然手持——风格断裂
- 整场打斗全是混乱手持——观众疲劳，真实感反转
- 两个正反打镜头一个手持一个稳定——空间感跳变

### 6.2 手持对光源一致性的影响

手持摄影机的晃动会导致光源在画面中的位置微变——同一个左高主光，手持时可能在某些帧看起来偏移。这不构成一致性错误，但需要标注：

- 手持段落在自检中，光源方向的一致性标准应放宽至"主光源整体方向一致"，允许因手持微晃导致的帧级偏移
- 但如果手持导致观众误以为光源换了方向（如主光从左跳到右），则是真正的一致性问题

### 6.3 手持与景深一致性

手持摄影经常伴随浅景深+追焦，这会导致焦点在角色和环境之间切换。一致性规则：

- 焦点切换是有意的创作选择，不构成一致性问题
- 但焦点在角色身上时角色的视觉特征必须与锚点表一致——不能因为虚化就忽略角色描述
- 手持追焦时，焦点短暂落在背景上的那些帧，背景特征仍需与场景锚点表一致

## 七、场景参考图集的一致性

场景参考图集是场景锚点表的图像化版本——9个不同机位的参考图，实现同一场景的360°无死角呈现。一致性的核心挑战是：AI没有空间想象力，9个独立生成的图像之间没有自动关联，一切一致性都必须通过提示词锚定来强制保证。

### 7.1 光影一致性（最高优先级）

光影是场景参考图集一致性中最容易出错、也最致命的维度。AI在不同景别和视角中倾向于"优化"光源，导致9张图的光源逻辑互相矛盾。

**硬性规则**：
- 9个提示词中的光源方向、色温、光质描述**逐字相同**
- 丁达尔效应等特殊光效在锚定段中声明，每个适用机位都保留（近景可只保留局部光柱/光斑）
- 阴影投射方向与光源方向物理一致——主光从左来，所有镜头阴影向右
- 冷暖对比的比例在各镜头中保持一致——不能一个镜头冷暖明显，另一个变成全暖

**常见AI偏差**：
- 俯视镜头倾向偏冷（AI默认天空=冷色），需在锚定段显式锁定色温
- 背面近景倾向过度逆光（AI把"rear angle"理解为完全背光），需声明"rim light on blossoms"保留细节
- 全景倾向正午光（AI把"full view"与"well-lit"关联），需显式声明golden hour

### 7.2 空间结构一致性

9个机位呈现的是同一个三维空间的9个视角，空间关系必须互相印证。

**地图锚定法**：镜头9（俯视全景）作为"地图"，确立了场景中所有元素的绝对位置。其他8个镜头的空间关系必须与地图一致。

**关键校验点**：
- 道路/小径的位置和走向在正面、侧面、俯视中一致
- 大型元素（大树、建筑、山丘）在各视角中的相对位置一致
- 地形起伏（平坦/坡地/台阶）在各视角中一致
- 远景元素（山、建筑、天空）的方位在各全景中一致

**空间一致性常见错误**：
- AI在生成侧面全景时可能"创造"一条新路——因为侧视角看不到正面那条路
- 俯视全景中地面元素的位置可能与正面视角矛盾——因为AI没有参考俯视的"地图"
- 背面近景中的远景可能变成不同的风景——AI不知道"回头看"应该看到什么

**修正策略**：先生成镜头9（俯视全景），作为所有后续镜头的空间基准。后续镜头的提示词中显式引用关键地标的位置（如 `the winding path visible in the lower-left portion of frame, consistent with the overhead layout`）。

### 7.3 色调与材质一致性

**色调锁定**：
- 锚定段中的色调关键词（如 `pink green warm gold palette`）跨9个提示词完全相同
- 不允许某个提示词引入新的色调词汇——AI会据此"创新"出其他8张图没有的颜色
- 色温值显式写入锚定段（如 `3500K-4500K color temperature`），不使用模糊的"warm tone"

**材质精度锁定**：
- 锚定段中声明材质区分度要求（如 `translucent petals, rough bark, soft grass texture`）
- 材质精度不应因景别变化而大幅波动——近景的材质不应反而比全景粗糙
- 特写镜头是材质精度的展示窗口，应达到比全景更高的细节水平，但不允许材质类型变化（花瓣不能从通透变成不透明）

### 7.4 场景参考图集与分镜提示词的一致性衔接

场景参考图集生成后，分镜提示词中的场景锚定段应直接引用图集的光影/色调/材质参数，确保分镜输出与图集视觉一致：

1. **光影参数逐字复制**：分镜提示词的场景锚定段，直接使用图集提示词中的光影描述段
2. **色调关键词逐字复制**：分镜提示词使用与图集完全相同的色调关键词
3. **材质声明逐字复制**：分镜提示词保留图集锚定段中的材质区分度声明
4. **机位参考映射**：分镜中的每个镜头，基于图集中最近似机位的提示词改写，只替换角色动作和构图微调

**风险**：如果分镜提示词的场景锚定段与图集提示词不完全一致（如换了近义词、省略了材质声明），AI可能生成与图集风格偏差较大的画面，导致多镜头剪辑时风格割裂。

## 八、视觉聚焦逻辑（Ocular Focus Logic）的一致性

眼神一致性是角色一致性中最容易被忽略、也最容易暴露AI的维度。五官可以靠锚点表锁定，但眼神的"灵魂感"来自六个同步系统的协调，任何一个系统的跨镜头不一致都会导致"假人感"。

### 8.1 双眼聚焦一致性（Vergence Consistency）

**跨镜头规则**：
- 同一场景内，角色注视同一目标时，双眼内聚程度必须一致——不能一个镜头内聚明显，下一个镜头两眼平行
- 角色注视对象改变时，必须有视线转移的动作描述——不能跨镜头"瞬移"注视方向
- 近距注视（对话、对峙）的内聚程度 > 远距凝视（看风景、看远方）——聚焦距离变化时vergence必须变化

**常见错误**：
- 正反打切换时，A看B的内聚程度和B看A不同（两人的物理距离是相同的）
- 情绪变化后注视同一目标，但vergence不变（愤怒锁死时内聚应比平静时更强）

### 8.2 高光锚点一致性（Catchlight Consistency）

**跨镜头规则**：
- 高光方向 = 主光方向，这是物理事实，同一场景内绝不可变
- 两眼的高光位置必须逻辑一致——如果主光从左上来，两眼高光都在左上角膜区域
- 正反打中两个角色的眼部高光方向应该一致（他们在同一光源下）

**常见AI偏差**：
- AI在正反打中可能自动"翻转"高光方向（以为反方该有反方向高光）——这是错误的，光源不会因机位翻转而改变
- 特写镜头中AI可能增加"额外高光"让眼睛更亮——这与场景光源逻辑矛盾

**修正策略**：在提示词中显式声明`physically accurate catchlights consistent with key light direction`，并在场景锚定段中锁定主光方向。

### 8.3 瞳孔动态一致性

**跨镜头规则**：
- 瞳孔大小受情绪和光线双重影响。同一场景内光线不变，瞳孔大小只随情绪变化
- 情绪变化时瞳孔应有响应——不能悲伤时瞳孔正常、下一个镜头依然悲伤但瞳孔突然放大
- 瞳孔变化是渐进的——不能"瞬间放大"，需要1-2秒的过渡期

**情绪-瞳孔映射表**（分镜中的校验基准）：

| 情绪 | 瞳孔状态 | 跨镜头变化规则 |
|------|---------|--------------|
| 平静→愤怒 | 正常→轻扩张 | 渐进扩张，伴随上睑抬升 |
| 平静→恐惧 | 正常→明显放大 | 快速扩张，伴随露白 |
| 愤怒→平静 | 轻扩张→正常 | 渐进收缩，伴随眼睑放松 |
| 恐惧→悲伤 | 明显放大→微缩 | 先收缩再微缩，伴随上睑下垂 |

### 8.4 眼神与微表情的联动一致性

眼神不是孤立的——它是视觉注意链的末端，必须与面部微表情联动：

```
目标 → 大脑 → 眼外肌（聚焦） → 面部微表情（联动）
```

**联动校验清单**：
1. 悲伤时：瞳孔微缩 + 眼神下坠 + 上睑沉重 + 嘴唇微颤 → 必须同时出现，不能只有"眼泪"
2. 愤怒时：瞳孔扩张 + 聚焦锁死 + 上睑抬升 + 下颌收紧 → 不能只画"皱眉"
3. 恐惧时：瞳孔放大 + 上睑露白 + 下睑紧张 + 面色苍白 → 不能只画"张嘴"
4. 吸引时：瞳孔微扩 + 眼睑微垂 + 目光柔和 + 嘴角微扬 → 不能只画"微笑"

**核心**：分镜中描写情绪特写时，眼神六系统和面部微表情是一个整体——不能只写"角色很悲伤"然后只在某一项上做文章，必须有完整的联动描述。AI默认只会画"悲伤脸"的标签组合，只有提示词把联动链条写完整，才能避免"五官在哭但眼神在笑"的矛盾。

### 8.6 四易暴露区跨镜头一致性

AI眼部的4个易暴露区域跨镜头必须保持一致：

| 区域 | 跨镜头一致性要求 | 常见矛盾 |
|------|-----------------|---------|
| 眼白 | 血丝/渐变/湿润阴影跨镜头不可消失 | 近景有血丝→远景变纯白 |
| 瞳孔边缘 | 柔化程度跨镜头一致 | 特写柔化→中景硬边 |
| 虹膜纹理 | 放射纤维+中央异色跨镜头不可变 | 第1镜头有异色→第3镜头消失 |
| 泪阜 | 半透明+毛细血管跨镜头不可简化 | 第1镜头细节→第2镜头粉色贴片 |

**标准**：四易暴露区的修正声明跨镜头必须重复——不能只在特写中声明、中景/远景省略。省略=AI回退默认错误。

### 8.7 意识导向声明的跨镜头一致性

角色"看什么"和"为什么看"的声明跨镜头必须逻辑自洽：

**聚焦目标跨镜头一致**：
- 如果角色A在第1镜头注视B，第2镜头不能突然变成注视C——除非有视线转移的描写
- 视线转移必须写明：`gaze shifting from [A] to [B], eyes tracking new target`
- 双眼聚焦一致性跨镜头不可退步：如果第1镜头写了`converged on same target`，后续镜头不能出现divergent gaze

**情绪→眼部映射跨镜头递进**：
- 悲伤场景中瞳孔应保持微缩状态直到情绪转变——不能某个镜头瞳孔突然扩张
- 愤怒场景中聚焦锁死应持续——不能某个镜头突然变成恍惚散焦
- 任何偏离当前情绪映射的眼部状态，必须有叙事理由

### 8.8 视频微动画层的跨镜头一致性

4层微动画的参数跨镜头应保持合理区间：

| 微动画层 | 跨镜头一致性 | 允许变化 |
|----------|-------------|---------|
| 微扫视频率 | 同一情绪状态内频率一致 | 情绪变化时频率可变（愤怒→高频） |
| 瞳孔呼吸 | 同一光线条件下节奏一致 | 光线变化或情绪高潮时允许突变 |
| 眨眼间隔 | 同一场景内间隔区间一致 | 情绪紧张时间隔缩短，放松时加长 |
| 眼睑张力 | 同一注视距离下张力一致 | 注视目标距离变化时张力调整 |

**标准**：微动画参数跨镜头不可无理由波动。参数变化必须伴随情绪/光线/注视距离的变化。

## 九、多镜头视频序列的一致性

多镜头视频序列的一致性比静态图像序列更严峻——视频有时间维度，角色的面部状态、眼泪、肌肉动作在连续镜头间必须构成物理上合理的时间线，不能像静态图像那样每个镜头"从零开始"。

### 9.1 多参考图一致性锁（Multi-Reference Lock）

视频序列中角色一致性的最高保障是**多参考图锁**——在Global Motion Style中显式声明：

```
Strictly using all previous [角色名] reference images + [特定参考图如real-tear references] 
for exact facial consistency, skin texture, eye shape, tear behavior and performance style lock.
```

**锁定的维度**：
- 面部一致性（face lock）：同一张脸、同一比例、同一肤色
- 皮肤质感（skin texture lock）：毛孔可见度、自然不均匀肤色、细微瑕疵
- 眼型（eye shape lock）：眼裂形状、眼角角度、虹膜颜色
- 眼泪行为（tear behavior lock）：粘度、流速、变形方式
- 表演风格（performance style lock）：同一角色的表情习惯和微动作模式

**参考图层级**：
1. **角色身份板**：锁定面部基础+多角度
2. **情绪参考图**：锁定该角色在特定情绪下的真实表情（如real-tear references）
3. **场景参考图**：锁定光源和氛围
4. **逐镜头参考**（可选）：为关键镜头单独生成参考帧

### 9.2 跨镜头面部肌肉状态的一致性

视频序列中面部肌肉的变化是连续的，不能跨镜头"重置"：

**肌肉状态链规则**：
- 每个镜头开始时的肌肉状态 = 上一个镜头结束时的肌肉状态（情绪着陆点）
- 肌肉只能渐进变化，不能瞬间跳转——"微笑→悲伤"必须经过"微笑消退→眉头微蹙→嘴角下拉"的中间态
- 解剖学肌肉权重的变化应与情绪弧线的梯度匹配，不能跳过中间权重值

**常见错误**：
- Shot 1用`(zygomaticus major lift:1.35)`，Shot 2直接`(depressor anguli oris:1.45)`——跳过了`slow zygomaticus release`过渡
- 同一情绪在不同镜头中的肌肉权重不一致——Shot 3的`(platysma neck tension:1.5)`到Shot 4变成了无颈部描述

### 9.3 跨镜头眼泪物理的一致性

眼泪在视频序列中是最严格的物理连续性项——它有明确的时间线，不可逆转，不可跳步：

**眼泪时间线（必须逐镜追踪）**：

| 镜头阶段 | 眼泪物理状态 | 提示词关键词 | 皮肤状态 |
|----------|------------|-------------|----------|
| 笑容（无泪） | 干燥 | `dry face, no moisture` | 正常肤色 |
| 笑容动摇 | 泪液蓄积 | `tear meniscus buildup at lower lash line` | 眼周微湿 |
| 第一滴形成 | 泪滴膨胀+缓慢释放 | `first tear forming, viscous droplet swelling and slow release` | 眼睑湿润 |
| 第一滴滑落 | 重力滚动+自然摇摆 | `slow gravitational roll with natural wobble, droplet deformation` | 泪痕窄亮 |
| 第二滴跟随 | 不对称汇合 | `second tear follows, asymmetric merging, realistic viscosity` | 泪痕扩展 |
| 多条泪痕 | 光线折射+焦散 | `multiple tear trails glistening, caustics, specular bloom` | 泪痕宽暗+妆面晕开 |

**一致性红线**：
- 眼泪只能前进（蓄积→形成→滑落→多泪痕），不能倒退
- 皮肤的湿润状态只能增加（干→微湿→湿润→泪痕），不能恢复干燥
- 泪痕的光学效果随时间变化（窄亮→宽暗），不能突然变亮
- 妆面晕开只增不减（与静态图像规范一致）

### 9.4 跨镜头运镜和光影的连续性

**运镜连续性**：
- 声明了`slow dolly-in push at 0.4m/s`的序列，每个镜头都必须声明推镜在继续——`continuing slow dolly-in push`
- 手持呼吸感应跨镜头延续——`camera organically breathing closer`
- CUT不是运镜中断——除非有明确理由（如换机位），否则运镜应延续

**光影连续性**：
- Global Motion Style锁定的光影体系适用于整个序列，不需要每个镜头重复声明
- 但如果某个镜头有特殊光影变化（如蜡烛闪烁、阴影移动），需要在镜头描述中单独声明
- 眼部高光方向在整个序列中不可变（与场景光源体系一致）
- 皮肤上的湿润折射效果随眼泪进度变化，但光源方向不变

### 9.5 小动作与微反应的跨镜头追踪

**小动作的时间线**：
- 小动作也需要跨镜头追踪——Shot 1中"手指摸索项链"，Shot 2中"手指握紧"，Shot 3中"无意识攥住"——这是一条连续的动作链
- 小动作的惯性（`natural inertia`）在镜头间延续——握紧后不会突然松开（除非有新动作触发）

**微反应的非规律性**：
- 微反应（快速眨眼、吞咽、肩膀微颤）不应每个镜头都出现——它们是不规律的
- 但同一个序列中，角色的微反应"类型"应一致——如果角色在紧张时习惯性吞咽，不应在某个镜头变成习惯性攥拳
- 微反应的频率应与情绪强度正相关——越紧张频率越高，越平静频率越低

## 十、面瘫美学的一致性

面瘫美学的一致性比微表情更难维护——因为它不是"维持某个状态"，而是"持续禁止某个状态"。AI的默认行为是添加表情，面瘫需要全程对抗这个默认行为。

### 10.1 跨镜头表情空白的一致性

微表情序列的一致性是"情绪连贯"，面瘫序列的一致性是"空白连贯"——更难，因为AI每次生成都倾向于"丰富"表情。

**空白连贯规则**：
- 面瘫场景的所有镜头，面部肌肉状态必须一致——始终是休息态
- 不能一个镜头面瘫，下一个镜头有了微表情——这比"情绪不连贯"更致命，因为它直接破坏了面瘫美学的核心承诺
- 提示词中每个镜头都必须重复面瘫基础锚定段，不能因为"之前已经声明过"就省略——AI没有跨镜头记忆

**AI常见"好心办坏事"**：
- 角色遭遇事件时，AI自动给角色添加"反应表情"——必须在提示词中再次禁止
- 角色说话时，AI自动给角色添加"说话表情"——必须声明`speaking with flat affect, no facial animation beyond lip movement`
- 角色与其他角色互动时，AI自动给角色添加"社交表情"——必须声明`maintaining flat affect despite social interaction`

### 10.2 面瘫眼神的一致性

面瘫眼神是整个面瘫一致性中最微妙的维度——它必须同时满足"活人"和"不反应"两个条件，跨镜头维持这个平衡：

**一致的面瘫眼神声明**（跨镜头完全重复）：
```
conscious but detached gaze, eyes tracking target without emotional investment, 
present but unengaged, binocular convergence on target with flat ocular tension, 
subconscious micro-blinks only, pupils responsive to light only, 
no emotional pupil dilation or constriction
```

**常见一致性错误**：
- 镜头A：面瘫眼神（conscious + detached）
- 镜头B：dead-eye（unconscious + hollow）——AI"省力"把detached理解成了空洞
- 镜头C：有情绪聚焦（conscious + engaged）——AI"好心"给角色加了反应

**修正策略**：每个镜头的提示词都重复完整的面瘫眼神声明，不能省略`conscious`或`detached`中的任何一个。

### 10.3 面瘫构图与色调的跨镜头一致性

**构图一致性**：
- 面瘫场景的对称构图必须跨镜头保持——不能一个镜头对称，下一个镜头变三分法
- 居中构图的角色位置跨镜头一致——不能一个镜头居中，下一个镜头偏左
- 平面化构图的空间逻辑跨镜头一致——不能一个镜头平面，下一个镜头有纵深

**色调一致性**：
- 低饱和度贯穿全程——不能某个镜头突然变高饱和
- 冷淡色调不随事件变化——爆炸发生了，色调也不变暖（色调不参与情绪）
- 韦斯·安德森式的"低饱和暖色"可以存在，但必须是稳定的——不能随镜头波动

### 10.4 微反应禁用的一致性

**禁用规则**：
- 面瘫场景中，所有情绪性微反应在所有镜头中被禁用——这不是"可以偶尔有"的选择，而是"必须一直无"的规则
- 跨镜头检查：如果Shot 1无微反应，Shot 3出现了肩颤——Shot 3破坏了面瘫
- 唯一允许的生理反应：自然频率眨眼、光线引起的瞳孔微调——但这两项也不应有跨镜头的频率/幅度变化

**AI最常"偷加"的微反应**（跨镜头检查重点）：
1. 说话时嘴角微微动（不是嘴唇动——嘴唇必须动——而是嘴角附带情绪性微动）
2. 事件发生时快速眨眼（情绪性眨眼，非生理性眨眼）
3. 互动时轻微点头（社交性反应，面瘫角色不做）
4. 接触时微微后退（本能反应，面瘫角色不做）


## 十一、多人物场面调度的一致性

多人物场景的一致性挑战远超单人场景——AI不仅要维持每个角色的跨镜头外观，还要维持角色之间的空间关系、摄影机逻辑、动线连续性。单人场景的错误只是"不像同一个人"，多人场景的错误则是"空间本身崩塌了"。

### 11.1 空间结构的一致性（最高优先级）

多人场景的稳定性优先级：**空间结构 ＞ 摄影机方向 ＞ Blocking ＞ 动线 ＞ 角色锚点 ＞ 人物细节 ＞ 风格词**

空间结构是多人场景一致性的根基——如果空间不稳定，角色再怎么锚定都会被放在错误的位置上。

**跨镜头空间一致性规则**：
1. **空间类型不可变**：大厅就是大厅，不能切镜变成走廊——AI可能在不同景别中"优化"空间结构
2. **地标元素不可消失**：大厅中的石柱在全景可见，切近景后即使不在画面中也应通过光影暗示存在（如柱子投下的阴影）
3. **空间纵深方向不可反转**：门在北墙，所有镜头中门的方向都是北——不能因为切到反方镜头门就跑到南墙
4. **俯视Blocking图作为空间宪法**：如果生成了俯视Blocking图，所有镜头的空间关系必须与之一致

**AI常见空间错误**：
- 正反打中AI"翻转"空间（以为反方该有反方向的空间）——必须通过`consistent camera orientation`锁轴
- 全景切近景时AI增加/删除空间元素——必须逐字重复空间锚定段
- 侧面视角中AI"创造"新地标——提示词中显式声明`consistent with overhead layout`

### 11.2 摄影机方向的一致性

摄影机方向是多人场景的"北"——如果北变了，所有方向都变了。

**锁轴规则**：
- 同一场景内所有镜头的`camera facing`声明必须相同
- 景别变化（35mm→85mm→100mm）不改变摄影机方向，只改变取景范围
- 正反打不是摄影机翻面，而是角色朝向变化——摄影机仍在轴线同一侧
- 缺少`camera facing`声明 = AI自由选择方向 = 空间一致性完全失控

**跨镜头摄影机连续性**：
```
S1-01: camera facing east, 35mm, wide shot → 空间+人物位置建立
S1-02: camera facing east, 85mm, medium shot → 同方向切近，位置逻辑不变
S1-03: camera facing east, 100mm, close-up → 继续同方向切近
S1-04: camera facing east, 35mm, wide shot → 回到建立镜头，空间可读性恢复
```

### 11.3 屏幕坐标的一致性

多人场景中角色位置的跨镜头一致性依赖**屏幕绝对坐标**，而非相对描述。

**坐标锁定规则**：
- 角色A在screen left foreground → 所有镜头中A要么仍在screen left foreground，要么有走位描写解释位移
- 角色B在screen right midground → 同上
- 前景/中景/背景层级不可跳变——角色不能从foreground"瞬移"到background
- Z轴（高低）同理——角色在台阶上不能切镜后在地面

**走位变化的连续性**：
- 角色位置变化必须覆盖在动作调度中——"A走向B，从screen left foreground移动到center frame"
- 位移量应合理——一个镜头内不可能横穿整个大厅
- 多人同时移动时，每条动线独立追踪

### 11.4 角色身份的跨镜头锁定

多人场景中"串脸"是最常见的AI灾难——两个角色交换了外观特征，或者一个角色在不同镜头中变成了另一个。

**标签化锁定**：
- 每个角色使用固定的视觉特征标签组合（如`scar-faced commander in black armor`），跨镜头逐字重复
- 标签中必须包含**颜色词**——这是AI区分角色的最强信号（`red-armored` vs `blue-robed`）
- 标签中必须包含**独特特征**——如果两个角色都是"战士"，至少一个有标志性区别（疤痕/武器/头盔形状）
- 泛称（man/woman）在多人场景中禁止使用——AI无法区分"第一个男人"和"第二个男人"

**身份锁定与锚点表的关系**：
- 锚点表定义角色的完整视觉规范（人读）
- 标签是锚点表的精简版（AI读）——提取锚点表中2-3个最具辨识度的特征
- 标签与锚点表不可矛盾——标签中的颜色/道具必须与锚点表一致

### 11.5 Blocking层级的一致性

Primary/Secondary/Background层级不仅是描述详略的控制手段，也是画面重心的声明——跨镜头中层级分配应与叙事焦点一致。

**层级一致性规则**：
- 叙事焦点不变时，层级分配不变——对话正反打中谁是Primary不因镜头方向改变
- 叙事焦点转移时，层级可调整但需有明确的镜头切换——"镜头转向角色B"是焦点转移信号
- Primary角色的描述详略度跨镜头一致——不能一个镜头详细描述，下一个镜头只剩标签
- Background extras的存在/数量跨镜头一致——不能一个镜头有2个守卫，下一个镜头空了

### 11.6 负空间的一致性

负空间不是可有可无的审美选择——在多人场景中它是防止AI融合角色的**结构性防线**。

**负空间一致性规则**：
- 声明了`large negative space between characters`的场景，所有镜头都应维持这个负空间
- 角色接近（如打斗缠斗）时负空间自然缩小，但分离后负空间必须恢复
- `empty center composition`是对峙场景的典型声明——跨镜头中心区域应保持空白
- 近景/特写中负空间可能不可见（景别原因），但角色之间的分离感仍需通过构图暗示

### 11.7 动线的一致性

多人场景中角色的移动路径（动线）必须跨镜头逻辑一致——AI没有"上一帧记忆"，动线只能靠提示词声明。

**动线追踪规则**：
- 每个角色的移动起点和终点必须与前镜的动作衔接
- `continuation motion`声明是动作延续的核心——不加这句，AI默认从静止开始
- 多人同时移动时，每条动线独立声明——`Character A moving from screen-left to center, Character B stationary screen-right`
- 动线与空间结构一致——角色不能穿过墙壁或瞬移

**动线与Blocking图的对应**：
- 如果俯视Blocking图标注了动线（箭头方向），所有镜头中的位移方向必须与箭头一致
- 动线变化必须标注——"Character A改变方向，从向北改为向东"

### 11.8 构图类型的一致性

多人场景的构图选择应在场景锚点表中声明，跨镜头保持一致——不能一个镜头对称构图，下一个镜头随意构图。

**构图一致性规则**：
- 声明了`symmetrical composition`的对峙场景，所有全景/中景镜头都应维持对称
- 三角构图中三个顶点的角色身份跨镜头不变——不能A和B换个位置
- 深度分层构图中前景/中景/背景的层级分配跨镜头一致
- 构图类型的变化需要叙事理由——从对称变为非对称，意味着权力关系变化

### 11.9 空镜先行与多镜头一致性

空镜先行工作流（先生成环境→锁定空间和光影→再加入角色）是目前最稳定的多人AI生成方法，其一致性优势：

1. **空间底板统一**：空镜锁定了空间结构和光影逻辑，后续所有镜头共享同一"底板"
2. **光影不可矛盾**：空镜中月光从右来→所有人物镜头月光从右来，因为提示词复制了空镜的光影描述
3. **空间元素不可矛盾**：空镜中有石柱→人物镜头中石柱的阴影/投影必须存在
4. **镜头间锚定段逐字复制**：CAMERA+SPACE+LIGHTING段从空镜逐字复制到所有人物镜头，只替换BLOCKING段

**空镜先行的一致性红线**：
- 空镜与人物镜头的空间描述必须逐字一致——不能改写、不能省略、不能换近义词
- 如果空镜中没有的元素在人物镜头中出现，必须解释来源（如角色带来的道具）
- 空镜中已有的元素在人物镜头中不能消失（除非有叙事理由如角色破坏了它）


## 十二、三步表演法的一致性

三步表演法（面部肌肉+肢体语言+时间轴）引入了新的跨镜头一致性维度：表演风格的一致性。同一角色在不同镜头中的情绪表达方式必须与角色性格一致——冷酷角色的所有情绪都偏克制，活泼角色的所有情绪都偏外放。这种"性格-表演"绑定关系是跨镜头一致的。

### 12.1 角色性格-表演绑定的一致性

角色性格决定情绪表达方式——这种绑定关系必须跨镜头一致：

**绑定规则**：
- 冷酷/内敛型角色：所有情绪偏克制，幅度偏小，肢体动作少而精准——不能某一镜突然大开大合
- 温柔/敏感型角色：所有情绪偏柔和，反应偏慢，肢体动作带有犹豫感——不能某一镜突然雷厉风行
- 活泼/外放型角色：所有情绪偏外放，幅度偏大，肢体动作多而快——不能某一镜突然沉默克制
- 沉稳/老练型角色：所有情绪偏内敛，有节奏感，肢体动作少但有分量——不能某一镜突然慌张失措

**常见不一致**：
- 角色标注"冷酷"，但在感动场景中突然流泪+咧嘴笑——❌ 表演与性格矛盾
- 角色标注"活泼"，但在紧张场景中突然安静端坐——❌ 除非有叙事理由（如被彻底震慑）
- 同一场景中角色A始终克制，但某一镜头突然夸张——❌ 表演风格断裂

### 12.2 情绪万能公式跨镜头的一致性

情绪万能公式（核心肌肉动作+辅助细节+程度副词）中的三个元素必须跨镜头逻辑一致：

**核心肌肉动作的一致性**：
- 同一持续情绪的跨镜头中，核心肌肉组合不变——"隐忍"始终是depressor anguli oris + orbicularis oculi tension，不能某一镜变成corrugator supercilii（变成愤怒了）
- 情绪转变时，肌肉组合的变化必须渐进——不能跳过过渡态

**辅助细节的一致性**：
- 眼泪/汗水/耳根泛红等辅助细节一旦出现，必须跨镜头延续（与眼泪一致性规范一致）
- 辅助细节的消失必须有物理时间支持——汗不会瞬间干，泪痕不会瞬间消

**程度副词的一致性**：
- 同一情绪的强度跨镜头应与叙事节奏匹配——紧张场景中"微微"可能升级为"明显"，但不能倒退
- 程度只能沿一个方向递进或维持——不能"微微紧张→明显紧张→微微紧张"（除非有叙事释放点）

### 12.3 肢体语言跨镜头的一致性

肢体动作是三步表演法中最容易在跨镜头中丢失的维度——因为分镜师容易只关注面部而忘记身体的连续性。

**肢体状态链**：
- 与面部肌肉状态链同理，肢体动作的跨镜头状态必须前后衔接
- "手指攥紧衣角"→下一镜手指仍应攥着→"手指缓缓松开"→下一镜手指放松
- "上身前倾"→下一镜上身仍应前倾→"靠回椅背"→下一镜上身靠后
- 肢体动作的惯性（`natural inertia`）跨镜头延续——攥紧后不会突然松开（除非有新动作触发）

**角色习惯动作的一致性**：
- 角色在锚点表中标注的体态习惯应在跨镜头中保持——"站立时双脚扎地"的角色不会在某个镜头中来回踱步
- 同一性格类型的习惯性动作应一致——紧张时习惯性攥拳的角色不会在另一个紧张镜头中改搓手（除非有叙事理由）

### 12.4 时间轴跨镜头的一致性

时间轴的情绪递进是跨镜头的——上一个镜头的情绪终点是下一个镜头的情绪起点：

**情绪阶段衔接规则**：
- 上一镜头时间轴末尾的情绪状态 = 下一镜头时间轴开头的情绪状态
- 情绪不能跨镜头"倒退"——除非有叙事释放点（如危机解除后的松一口气）
- 时间轴的速度节奏跨镜头一致——如果前两个镜头每个2秒，第三个镜头不能突然变成0.5秒（除非节奏加速是有意的）

**与情绪着陆点的关系**：
- 三步表演法的时间轴是情绪着陆点的微观版本
- 每个时间轴阶段的结尾情绪 = 该镜头的情绪着陆点
- 跨镜头时间轴必须与跨镜头情绪着陆点一致——两者是同一套逻辑在不同粒度上的表达

### 12.5 光影与情绪绑定的一致性

光影对情绪的烘托效果跨镜头必须逻辑一致：

**光影-情绪绑定规则**：
- 声明了"冷调侧光"的虐心场景，所有镜头都应维持冷调侧光——不能某一镜突然变暖调柔光（除非情绪本身转向温暖）
- 光影的渐变（如觉醒场景从冷散光到正面硬光）是跨镜头的——不能一个镜头就完成全部渐变
- 正反打中两个角色的光影可以不同（他们在空间中的位置不同），但光影类型应一致（同一个场景同一组光源）

### 12.6 强约束兜底跨镜头一致

强约束声明（如"no exaggerated expressions, no facial deformation, stable frame"）必须在所有相关镜头中重复——不能因为"之前已经声明过"就省略：

- AI没有跨镜头记忆——每个镜头的提示词都是独立的"合同"
- 省略强约束 = 该镜头的约束解除 = AI可能在该镜头中放飞自我
- 特别是在情绪转折点（从克制到爆发），强约束需要调整为与新的表演方向一致


## 十三、运镜五境的一致性

运镜五境（速度精确化/反向规则/锚点/复合运镜/静止）引入了新的跨镜头一致性维度：运镜逻辑的一致性。同一场景内的运镜风格、速度标准、方向逻辑必须跨镜头协调统一。

### 13.1 运镜速度标准的一致性

同一项目内的运镜速度描述必须使用统一的"时间+距离"标准——不能一个镜头用精确数字，另一个镜头用形容词：

**速度标准跨镜头一致规则**：
- 建立项目速度词典（极慢8-10s/慢速5-6s/中速3-4s/快速1.5-2s/超快<1s），所有镜头统一使用
- 同一场景内的运镜节奏应连贯——铺垫用中慢速，高潮用快速，收束回到中慢速，不能突兀变速
- 连续运镜（如持续推镜）跨镜头的距离和时间必须衔接——上一镜推了2米用了3秒，下一镜继续推1.5米用2秒

**常见不一致**：
- S1-01写"5秒推进2米"，S1-02写"缓慢推进"——❌ 标准不统一
- 打斗场景节奏混乱——前面全是中速，突然一个超快——⚠️ 需确认节奏弧线是否有意
- 连续推镜跨镜头时间断裂——上一镜3秒推2米，下一镜5秒推0.5米——❌ 速度不一致

### 13.2 反向规则跨镜头的一致性

同一场景内，如果选择了反向运镜策略，应跨镜头维持这个策略——不能一个镜头用反向（高级），下一个镜头变同向（平庸），风格会断裂：

**反向策略一致性规则**：
- 角色走向镜头的整段戏，如果第一个镜头用了"主体向前+镜头后退"的反向策略，后续所有跟拍镜头都应维持反向
- 只有场景/情绪转折点可以切换运镜策略——如从对抗到陪伴，反向变同向是有意的叙事选择
- 视线反向规则同理——角色持续看向某一方向时，运镜方向应持续与视线对抗

**反向策略切换的叙事理由**：
- 反向→同向：从对抗到陪伴——如角色从对峙到并肩行走
- 同向→反向：从陪伴到对抗——如角色发现真相后的对峙
- 无理由切换 = 风格断裂

### 13.3 锚点跨镜头的一致性

锚点（起始/结束画面）是运镜稳定性的根基，跨镜头锚点必须逻辑一致：

**锚点衔接规则**：
- 上一镜头的结束锚点 = 下一镜头的起始锚点（与情绪着陆点逻辑一致）
- 锚点中的景别、主体位置、构图必须跨镜头衔接——上一镜结束在面部特写，下一镜应从面部特写开始
- 三锚点长镜头的中点锚点，是下一段运镜的参考基准——后续镜头的空间位置应与中点锚点一致

**常见锚点不一致**：
- 上一镜结束在全景，下一镜开始在中景——❌ 缺少衔接，跳跃
- 锚点中的主体位置跨镜头矛盾——上一镜结束在画面右侧，下一镜开始在画面左侧——❌ 空间跳跃
- 长镜头中点锚点与后续镜头空间矛盾——❌ 空间逻辑断裂

### 13.4 复合运镜风格的一致性

同一场景内的复合运镜风格应协调——不能一个镜头用环绕推进（优雅），下一个镜头用希区柯克变焦（眩晕），除非有叙事理由：

**复合运镜风格协调规则**：
- 同一场景内的复合运镜"级别"应相近——不要忽高忽低
- 登场段落的运镜组合应统一——都用环绕推进系（Orbit+Dolly变体），不混搭升降推进
- 情绪转折点是复合运镜风格切换的合法时机——从环绕推进（优雅登场）→希区柯克变焦（真相揭露的眩晕）

**复合运镜的维度一致性**：
- 如果第一个复合运镜包含3个维度（推进+环绕+升降），后续镜头不应突然降到1个维度（纯推进）——维度减少会让观众感到"降级"
- 维度增加是合理的——从简到繁，运镜越来越复杂，匹配情绪升级

### 13.5 静止镜头与运镜镜头的节奏一致性

静止镜头和运镜镜头的交替构成视觉节奏——这个节奏跨场景应有一致性逻辑：

**静止-运镜节奏规则**：
- 静止镜头的"呼吸感"（<5cm drift）参数跨镜头一致——不能一个镜头3cm，另一个镜头10cm
- 静止→运镜的切换是叙事事件——运镜的开始本身就是信号，告诉观众"有事情在变化"
- 运镜→静止的切换也是叙事事件——静止的回归告诉观众"暂停，感受这一刻"
- 同一项目中静止镜头的占比应保持一定比例（建议≥30%），全片运镜或全片静止都不可取

**静止镜头的呼吸感跨镜头一致**：
- `locked-off camera with extremely subtle breathing motion (less than 5cm of drift)` — 跨镜头完全重复
- 不能某个静止镜头突然变成完全固定（0cm drift）——除非有叙事理由（如角色死亡/时间冻结的隐喻）

### 13.6 运镜方向跨镜头的轴线一致性

运镜方向（向左/向右/向前/向后）与180°轴线规则是一体两面——运镜方向的跨镜头变化必须遵守轴线：

**运镜方向与轴线的关系**：
- 运镜方向不能随意反转——同一场景内，如果推镜方向是"从南向北"，所有推镜镜头都应从南向北
- 横移方向同理——如果第一个横移是向左，后续横移不应突然向右（除非有叙事理由如揭示新空间）
- 反向规则中的"运镜反向"是相对于主体动作的反向，不是相对于上一个镜头运镜方向的反向——不要混淆

**运镜方向一致性常见错误**：
- 正反打中运镜方向翻转——❌ 角色A推镜向左，角色B推镜向右——等于越轴
- 连续推镜方向矛盾——S1-01从左推，S1-03从右推——❌ 空间混乱
- 复合运镜中的环绕方向矛盾——S1-01顺时针环绕，S1-03逆时针——⚠️ 需确认是否有叙事理由

## 十四、角色描写精度的一致性

### 14.1 六维描述跨镜头一致性

角色锚点表的六维描述一旦建立，跨镜头的所有提示词必须严格引用，不可矛盾：

| 维度 | 一致性要求 | 常见矛盾 |
|------|-----------|---------|
| 体型与轮廓 | 剪影形状+肩型+重心位置跨镜头不变 | 中景是宽肩，特写突然变窄肩 |
| 面部特征 | 骨骼结构+嘴角方向+眼窝深度不可矛盾 | 正面薄唇，侧面变厚唇 |
| 发型 | 颜色+款式+光泽度+鬓角长度一致 | 远景有分缝，近景变无分缝 |
| 服饰 | 面料+驳头+扣法+剪裁+配套跨镜头锁定 | 一个镜头两粒扣，另一个变三粒扣 |
| 道具 | 材质+尺寸+佩戴位置+光线交互一致 | 腕表从左腕跑到右腕 |
| 体态 | 基础姿态+微动作频率+视线落点一致 | 前倾姿态突然变后靠 |

**标准**：六维描述在锚点表中定义一次，所有镜头提示词直接引用锚点表文字，只替换动作/构图变化部分。锚定层绝对不变，变化层逐镜标注。

### 14.2 服饰精度的跨镜头一致性

服饰是AI最易随机发挥的区域——同一个角色在不同镜头中可能被AI换衣服。必须用锚点表的服饰锚定段锁定：

**西服7要素跨镜头校验**：
- 颜色：每个镜头必须声明"charcoal-black (NOT pure black)"——"NOT pure black"是关键声明，防止AI向纯黑漂移
- 面料：跨镜头重复"worsted wool, matte sheen"——材质词不可省略
- 驳头：一旦定为notch lapel 7cm，不可在某镜头中省略（省略=AI随机选择）
- 扣位：声明"single-breasted two-button, bottom button fastened"——扣法=角色性格的视觉表达
- 剪裁：structured shoulder + suppressed waist跨镜头不变——这是剪影一致性的基础
- 袖口：4 working buttonholes + 1cm shirt cuff visible——细节级锁定
- 配套：衬衫颜色+袖扣+领带在锚定层锁定，不随镜头变化

**颜色精确化的一致性价值**：
```
❌ "black suit" → AI每次生成不同深浅的黑色 → 跨镜头色差不一致
✅ "charcoal-black" → AI锁定在"深灰偏黑"的色域 → 跨镜头一致
❌ "white shirt" → AI可能生成纯白/米白/象牙白 → 不一致
✅ "cold-white shirt" → AI锁定冷白色域 → 一致
```

### 14.3 道具光线交互的跨场景一致性

同一道具在不同场景中的光线交互会变（因为光源不同），但道具本身的材质/尺寸/佩戴位置不变：

**跨场景道具一致性规则**：
- 材质+尺寸+佩戴位置：跨场景不变（锚定层）
- 光线交互：随场景光源变化而变化（变化层），但必须明确写出新的交互描述
- 如果某镜头省略了光线交互描述=AI随机处理=可能与其他镜头矛盾

```
场景A（室内冷光）：platinum watch, dial catching cold white spotlight reflection
场景B（室外暖光）：platinum watch, dial catching warm golden ambient glow
                            ↑材质不变           ↑光线交互随场景变化但必须显式声明
```

### 14.4 表演基态的跨镜头一致性

面部表演锚定（基态层）是角色"不做表情时的默认脸"——跨镜头必须一致：

**基态跨镜头锁定**：
- 眼睑高度：如果基态是"upper eyelids at 3/4 height"，所有非情绪特写镜头必须保持
- 视线落点：如果基态是"gaze at viewer's glabella"，所有对视镜头必须保持
- 下颌线张力：如果基态是"jawline taut"，除非有情绪变化否则不可松弛
- 眉头状态：如果基态是"brow relaxed"，不能在无叙事理由时突然皱眉

**情绪偏离基态时的规则**：
- 偏离必须逐镜声明：如"jawline taut → jawline slightly relaxed (suppressed anger)"
- 偏离必须有叙事理由：不能随机偏离
- 偏离后必须回归基态或进入新基态：不能悬停在中间态

### 14.5 权力视觉化证据链的跨镜头一致性

权力角色的五层视觉证据链跨镜头必须逻辑自洽：

**空间占有一致性**：如果角色A在全景中"双臂展开搭扶手"，近景中不可突然变成"双手交叉胸前"——除非有叙事理由
**动作节奏一致性**：如果角色的微动作频率是1次/3秒，不可在某镜头中变成1次/秒——节奏=性格
**视线方向一致性**：如果角色习惯"视线从略高处落下"，不可随机变成平视——视线高度=权力层级
**环境映射一致性**：如果场景有玻璃反射，所有适用镜头必须包含反射——不能有时有有时没有
**材质等级一致性**：如果道具是铂金+哑光，不可在某镜头中变成金+亮面——材质等级=角色身份

### 14.6 六维描述与已有规范的一致性衔接

| 已有规范 | 与精度规范的衔接点 | 一致性要求 |
|----------|-------------------|-----------|
| 视觉锚点表 | 精度规范=锚点表的填写方法论 | 六维拆解结果直接填入锚点表，不可重复定义 |
| 三步表演法 | 面部表演锚定=三步法的基态层 | 基态层是所有情绪表演的起点，不可与情绪万能公式矛盾 |
| 视觉聚焦逻辑 | 视线落点=视觉聚焦的注视目标 | 锚点表中的gaze方向必须与分镜中的注视目标一致 |
| 面瘫美学 | 面瘫角色的精度规范更严格 | "没有表情"比"有表情"需要更精确的肌肉级指令 |
| 角色身份板 | 六维输出=身份板提示词信息源 | 身份板图像必须能被锚点表的六维描述验证 |
| 多人物场面调度 | 六维中的体态维度是Blocking基础 | 角色标签化（颜色+身份+特征）与六维的体型/服饰维度一致 |

### 14.7 跨维度内部一致性检查

六维拆解中不同维度之间存在逻辑关联——如果维度A和维度B的描写互相矛盾，AI生成时会产生不协调的角色形象。以下检查确保六维内部自洽：

**维度1（体型）↔ 维度4（服饰）的一致性**：
- 体型为"宽肩收腰"→服饰必须是"suppressed waist cut"而非"regular fit"
- 体型为"瘦削"→不可写"structured shoulder"（垫肩=与体型矛盾）
- 体型为"高大"→领带长度终点必须触皮带扣（否则领带比例不对）

**维度2（面部）↔ 维度6（体态）的一致性**：
- 面部基态"上眼睑半垂+视线落对方眉心"→体态必须匹配"上身前倾5-10°"（俯视视线需要前倾姿态支撑）
- 面部"嘴角微下压"→体态不可同时写"放松姿态"（嘴下压=肌肉紧张≠放松）
- 面部"眉头不蹙"→体态不可写"紧握拳头"（面部放松与肢体紧张矛盾——除非是刻意对比，需显式声明）

**维度4（服饰）↔ 维度5（道具）的一致性**：
- 服饰为"午夜蓝丝质领带+哑光铂金袖扣"→道具不可写"金色手表"（铂金+金色=金属色系冲突）
- 服饰为"深炭黑worsted wool"→道具应匹配"冷色调金属"（铂金/银/钢），不可写"暖色黄铜/玫瑰金"
- 服饰整体"冷色极简"→道具数量应少而精，不可多件堆砌（极简=不堆砌）

**维度3（发型）↔ 维度2（面部）的一致性**：
- 发型"油亮后梳"→面部应匹配"控制感"——无碎发、无自然卷、鬓角修剪精确
- 发型"凌乱"→面部不可同时写"绝对控制"（发型与表情传递矛盾信号——除非是角色设定，需显式声明）

**跨维度一致性的显式声明规则**：
- 如果某个跨维度矛盾是**角色设定**（如"外表控制但内心波动"），必须在锚点表中显式声明："维度2与维度6的矛盾是角色设定：面部控制但手指泄露情绪"
- 未声明的跨维度矛盾=错误，必须修正
- 声明过的跨维度矛盾=角色张力，在提示词中同步体现

### 14.8 角色类型与精度重点的一致性

不同角色类型的精度重点映射表决定了提示词的信息权重分配——如果提示词的篇幅分配与角色类型不匹配，会导致该角色最需要精度的维度反而模糊：

**篇幅分配一致性检查**：
| 角色类型 | 提示词篇幅应侧重 | 常见失衡 |
|----------|-----------------|---------|
| 权力型反派 | 体态50%+面部25% | 服饰写了3行但体态只有1行 |
| 女主/恋人 | 面部40%+体态30% | 服饰细节过多但情绪变体不足 |
| 少年/成长型 | 发型30%+体型25% | 服装规格精确但缺少成长感描写 |
| 老人/智者 | 面部40%+道具25% | 体型描述过多但缺少岁月肌理 |
| 配角/功能型 | 服饰35%+发型25% | 面部描写过细但辨识度标志不够 |

**标准**：提示词中各维度的词数占比应与角色类型→精度重点映射表基本一致。最高优先级维度的词数不少于总词数的25%。

## 十五、暧昧/恋爱/亲密戏的一致性

### 15.1 视线逻辑跨镜头一致性

恋爱戏中角色的视线行为是其心理状态的窗口——跨镜头必须逻辑自洽：

**视线方向一致性**：
- 如果角色A在第1个镜头偷看B，第2个镜头不能变成"完全不看B"——除非有叙事事件（如B发现了A的偷看）
- 对视后移开的方向应一致——如果A总是先移开视线（性格：被动/羞涩），不能在后续镜头突然变成A直视不退
- 偷看的模式应一致——如果A习惯看B的手/侧脸/背影（而非正面），这个偏好跨镜头不变

**停留时间递进一致性**：
- 视线停留时间应随关系进展递增：初识0.5秒→暧昧1.5秒→心动3秒→失控不离开
- 停留时间不能无理由倒退——如果第5个镜头停留3秒，第6个镜头不能回到0.5秒（除非有疏离叙事）

### 15.2 空间距离递进的一致性

恋爱戏的核心是"距离变化"，跨镜头的距离递进必须连贯：

**距离递进规则**：
- 安全距离→危险距离→暧昧距离：单向递进（除非有叙事事件导致倒退，如争吵/拒绝/误解）
- 空间障碍物的消失应逐步：桌子→沙发→门框→无障碍——不能跳过中间阶段
- "差一点"的距离应越来越近：5cm→3cm→1cm→几乎碰到——每次更近

**距离倒退的叙事合法性**：
- 允许倒退，但必须有叙事理由：争吵后→距离拉大；被拒绝后→回到安全距离
- 倒退后重新靠近的节奏应与首次不同——通常更快（因为心理障碍已被突破过）

### 15.3 呼吸感镜头跨镜头节奏一致性

呼吸感镜头的运镜节奏跨镜头应形成情绪弧线，而非随机变化：

**运镜节奏递进规则**：
- 推进速度递增：极慢（0.2m/5s）→慢（0.3m/4s）→中（0.5m/3s）→快（1m/2s）
- 停顿次数递减：初识多停顿→暧昧少停顿→失控无停顿
- 镜头稳定性递减：稳定→微晃→明显手持——匹配情绪失控程度

**跨镜头运镜不可矛盾**：
- 如果上一镜头是"锁死静止"，下一镜头不能突然变成"快速推进"——需要过渡
- 呼吸感的"微晃幅度"跨镜头应一致或递增——不能忽大忽小

### 15.4 亲密戏镜头重点的跨镜头一致性

亲密戏中的身体部位关注应有逻辑递进而非随机切换：

**镜头重点递进规则**：
- 从边缘到中心：手→手臂→肩膀→后颈→头发→面部→嘴唇——逐步靠近核心
- 从非接触到接触：悬停→擦过→轻触→握住——每次更确定
- 从独立到交错：各自的手→手接近→手指交错→完全交握——空间占有方式的变化

**跨镜头不可跳跃**：
- 如果上一镜头是"手悬停2cm"，下一镜头不能直接跳到"接吻"——缺少中间步骤
- 如果上一个亲密镜头聚焦手部，下一个不应突然跳到完全不同的身体部位——应有过渡

### 15.5 焦距递进的跨镜头一致性

恋爱五阶段的焦距变化（广角→中焦→长焦→失控→回中焦）跨镜头应形成完整弧线：

**焦距弧线规则**：
- 同一恋爱场景内焦距递进方向一致：不能第1镜头85mm→第2镜头24mm→第3镜头100mm（跳跃）
- 焦距回退必须有叙事理由：如果已进入135mm（心动），回退到50mm必须有事件（如被打断/回忆/疏离）
- 失控阶段的焦距不稳定性跨镜头应递增：微变焦→明显变焦→手持混乱

**焦外递进一致性**：
- 背景虚化程度应随焦距递增：清晰→微虚→半虚→全虚→回到微虚（平静阶段）
- 如果第3镜头背景已完全失焦，第4镜头不能突然背景清晰——除非叙事需要（如被现实打断）

### 15.6 光影情绪跨镜头一致性

恋爱戏的光影变化应服务于情绪弧线：

**色温递进规则**：
- 暧昧升温：冷色比例递减+暖色比例递增——理性空间逐渐被情绪温度侵入
- 暧昧降温（被拒绝/争吵）：暖色消失回到冷色——情绪温度撤离
- 亲密戏：整体暖色+局部阴影——温暖但不完全暴露

**阴影递进规则**：
- 初识：两人都完整可见（没有秘密）
- 暧昧：开始出现阴影（开始有秘密/隐藏）
- 心动：半面阴影（内心分裂——理性vs情感）
- 亲密：阴影包裹（私人空间/保护/脆弱）
- 阴影方向跨镜头应一致——如果侧光从左打，不能突然变右侧（除非有光源叙事）

### 15.7 暧昧/恋爱/亲密戏与已有规范的一致性衔接

| 已有规范 | 与恋爱规范的衔接点 | 一致性要求 |
|----------|-------------------|-----------|
| 三步表演法 | 恋爱戏肢体语言=三步法的情感场景版 | 后退/靠近/停住的肌肉描写必须符合情绪万能公式 |
| 视觉聚焦逻辑 | 视线停留时间=情绪浓度是聚焦的恋爱版 | 注视目标从"事物"→"人"，聚焦模式从"审视"→"渴望" |
| 运镜五境 | 呼吸感镜头=静止镜头力量的恋爱版 | 镜头停止=叙事事件的逻辑两者一致 |
| 焦距节奏 | 恋爱五阶段焦距变化是焦距节奏的完整案例 | 焦距递进方向不可与项目整体焦距设计矛盾 |
| 面瘫美学 | "假装正常"是面瘫的泄露版 | 面瘫=主动消除情绪线索；假装正常=试图消除但身体在泄漏——区别是"是否成功" |
| 角色描写精度 | 肢体语言需要精度级描写 | "手悬停"必须精确到"2cm"+"指尖微颤"而非笼统 |

## 十六、剧本→视觉资产提取的一致性

### 16.1 角色设定图与锚点表的双向一致性

角色设定图和角色视觉锚点表必须完全一致——设定图是锚点表的图像化，锚点表是设定图的文字化：

**设定图→锚点表映射**：
- 设定图的面部→锚点表的面部特征字段
- 设定图的服装→锚点表的服饰锚定层
- 设定图的道具→锚点表的标志性道具
- 设定图的姿态→锚点表的体态习惯

**一致性校验**：设定图生成后，必须反向核对锚点表——如果设定图中出现了锚点表未描述的元素（如手表、戒指），必须补充进锚点表；如果锚点表描述了设定图未呈现的元素，必须重新生成设定图。

### 16.2 场景概念图与9机位图集的一致性

场景概念图是9机位图集的"正面全景"基础版本——概念图确认后，9个机位的光影/材质/空间结构必须与概念图一致：

**概念图→9机位一致性规则**：
- 光源方向和色温：概念图确定后，9个机位必须使用相同光源逻辑
- 材质：概念图中的地面/墙面/家具材质，9机位中不可改变
- 空间布局：概念图中的家具位置，9机位中保持一致的空间关系
- 色调：概念图的色温基调，9机位不可偏移

### 16.3 道具跨镜头一致性清单的应用

道具一致性清单在以下环节使用：

**分镜生成时**：每个涉及道具的镜头，必须回溯道具清单确认外观描述，提示词中引用清单的精确描写
**自检时**：道具外观是否与清单一致——戒指材质/手表位置/合同印章等不可矛盾
**角色设定图时**：角色手持或佩戴的道具必须在设定图中呈现，且与清单描述一致

### 16.4 道具一致性红线与锚点表一致性红线的协同

道具清单的一致性红线和角色锚点表的一致性红线可能重叠——这种重叠是正确的，因为它们从不同维度锁定同一特征：

- 锚点表红线："腕表位置（左腕）"——确保角色外观一致
- 道具清单红线："佩戴位置（左腕）"——确保道具出现位置一致
- 两者必须互不矛盾——如果锚点表写左腕，道具清单也写左腕

**冲突检测**：如果锚点表和道具清单对同一特征描述矛盾（如一个写左腕一个写右腕），以锚点表为准并修正道具清单。

## 十七、AI视频生成技术参数的一致性

### 17.1 摄影机后缀的跨镜头一致性

同一场次内所有镜头必须使用相同的摄影机机身+光圈基调——机身切换=视觉基因突变：

**一致性规则**：
- 同一场次：同一机身+同一宽高比，光圈可随景别微调（T2.0↔T2.8↔T4.0）
- 跨场次：可换机身（如室内Arri Alexa 65→室外Sony Venice 2），但同场次内不可
- film grain密度同场次内一致——不能一个镜头颗粒重、下一个镜头零颗粒

**光圈变化的合理范围**：
| 允许 | 示例 |
|------|------|
| ✅ 同场次景别变化时光圈微调 | 中景T2.8→特写T2.0（合理浅景深） |
| ✅ 角色走动时光圈跟随 | 角色靠近→T2.0，角色走远→T4.0 |
| ❌ 同场次内机身切换 | Arri Alexa 65→Sony Venice（视觉基因突变） |
| ❌ 同场次宽高比切换 | 16:9→9:16（构图逻辑崩溃） |

### 17.1b 电影打光位置的跨镜头一致性

同一场景内光位体系必须保持一致——光位切换=空间逻辑断裂。

**一致性规则**：
- **同场景同光源逻辑**：场景建立时光位体系确定后，该场景所有镜头必须遵守
- **主光方向跨镜头锁定**：如果镜头1主光从左前45°来，镜头2-10主光也必须从左前45°（除非角色/摄影机大幅移动）
- **辅光比例跨镜头保持**：如果镜头1主:辅=3:1，后续同场景镜头不可突然变8:1
- **轮廓光存在性一致**：如果镜头1有侧逆光轮廓，同场景其他镜头也应有轮廓光（除非构图角度完全不适合）

**光位切换的合理时机**：

| 允许切换 | 示例 |
|----------|------|
| ✅ 场景切换 | 室内前侧光→室外自然顺光 |
| ✅ 时间跳转 | 白天顺光→夜晚底光 |
| ✅ 叙事转折 | 正常前侧光→突然顶光（审讯/暴力突变，参考奉俊昊风格） |
| ✅ 情绪弧线推进 | 走路：远景顺光→近景正侧光→特写逆光（氛围→聚焦→超脱） |
| ❌ 同场景无理由切换 | 前侧光→底光（无叙事理由） |
| ❌ 主光方向无故反转 | 镜头1光从左来→镜头2光从右来（违反180°轴线光逻辑） |

**光位与场景锚点表的一致性**：
- 场景锚点表中的光源体系（方向/色温/光质）决定了该场景的光位选择
- 一旦场景锚点表声明了光源位置，所有镜头的打光描述必须回溯校验
- 场景锚点表未声明光源时，分镜第1镜的光位选择=该场景的光源锚定，后续镜头必须遵守

### 17.1c 生产级首帧提示词6层跨镜头一致性

6层声明结构在跨镜头时，各层的一致性要求不同：

| 层级 | 跨镜头一致性要求 | 允许变化 |
|------|-----------------|---------|
| L1 表情表演 | 情绪落点必须连续（上一镜落点=下一镜起点） | 微表情/小事/下意识反应随情绪弧线变化 |
| L2 动作惯性 | 衣角/头发惯性方向必须与动作方向一致 | 动作本身随剧情推进变化 |
| L3 光源氛围 | 同场景光位体系+灰尘/颗粒密度保持 | 光强可随情绪弧线微调 |
| L4 皮肤面部 | 皮肤声明跨镜头必须一致（SSS/色区/毛孔） | 油汗层可随情绪强度变化 |
| L5 景深镜头 | 同场景同焦段基调（如85mm贯穿） | 光圈可随景别微调（T2.0↔T2.8） |
| L6 整体质感 | film grain密度+8K+实景基调跨镜头一致 | 穿搭细节随角色动作自然变化 |

**一致性规则**：
- L1的情绪落点连续性=三步表演法的"情绪着陆点"规则——镜头结束时的情绪状态=下一个镜头的情绪起点
- L3的光源一致性=17.1b的打光位置跨镜头规则——同场景主光方向锁定
- L4的皮肤一致性=皮肤六层的跨镜头规则——色区差异分布不可变，油汗层可变

### 17.2 Negative Prompt的跨镜头一致性

同一角色/场景类型的负提示应保持一致——如果面瘫角色在镜头1禁用了"smile"，镜头3不能突然不禁止：

**一致性规则**：
- 通用5类负提示（画质/人体/面部/光影/风格）跨全片一致
- 角色专用负提示跨该角色所有镜头一致（面瘫角色永远禁用smile/raised eyebrows）
- 场景专用负提示跨该场景所有镜头一致（夜景永远禁用daylight/sun）

### 17.3 宽高比与构图逻辑的一致性

宽高比决定构图逻辑——同一场次内宽高比不可切换，否则构图语言矛盾：

**横屏(16:9/21:9)构图逻辑**：
- 水平纵深：角色+背景水平排列
- 180°轴线水平建立
- 双人构图：左右排列

**竖屏(9:16)构图逻辑**：
- 垂直纵深：前景/中景/后景垂直堆叠
- 双人构图：上下排列（前景人物上半身+后景人物下半身）
- 环境建立：地面→角色→天空三层垂直展示

**不可混合**：同场次内不可出现横屏镜头和竖屏镜头——构图逻辑完全不同，混合后空间关系矛盾。

### 17.4 Motion Strength的跨镜头连续性

Motion Strength影响画面运动的节奏感——同场次内的Motion值变化应平滑，不可突变：

**连续性规则**：
- 同场次内相邻镜头Motion值差不超过±2
- 如果需要从静止(Motion=3)到剧烈运动(Motion=9)，必须经过过渡值（3→5→7→9）
- 面瘫角色的Motion值全片不超过4——微动作是面瘫的核心，大幅度运动破坏人设

### 17.5 Seed值的一致性管理

Seed值是AI生成器的"视觉基因"——同场景用同Seed确保视觉DNA一致：

**管理规则**：
- 同一场次所有镜头使用相同Seed
- 不同场次使用不同Seed（场景切换=视觉环境切换）
- 角色设定图使用专用Seed，与该角色首场镜头Seed相同
- Seed值记录在分镜脚本的"全局设定"部分，便于回溯和迭代
- 如果某镜头需要重生成，使用原Seed+微调提示词——不要换Seed

### 17.6 Cliffhanger与叙事一致性

Cliffhanger虽然切断叙事，但必须与已建立的叙事逻辑一致——不能为了悬念而违背角色性格或因果律：

**一致性规则**：
- Cliffhanger的最后画面必须与该场次已建立的光影/构图/角色状态一致
- 不能在Cliffhanger镜头突然引入从未出现的元素（如从未暗示过的角色突然出现）
- 反转型Cliffhanger的"矛盾元素"必须在前面镜头中有视觉伏笔
- 悬念型Cliffhanger推向的"关键物体"必须在前面镜头中已建立存在感

## 十八、单帧叙事密度的一致性

### 18.1 角色痕迹的跨镜头一致性

角色身上的痕迹（脏污/磨损/伤害）在同一场景内必须保持一致或按因果链递进——不能一个镜头手上干净，下一个镜头突然出现泥污（除非有明确行为触发）：

**痕迹一致性规则**：
- 同一场次内，角色的痕迹只能增加不能消失——泥污不会自己洗干净
- 痕迹的分布位置跨镜头一致——左手背的泥污不会跑到右手
- 新痕迹的出现必须有叙事触发——摔倒/挖掘/搏斗=新痕迹出现的因果
- 痕迹颜色跨镜头一致——棕色泥污不会变成黑色泥污

### 18.2 环境证据的跨镜头一致性

同一场次的环境五层证据必须跨镜头保持一致：

| 证据层 | 一致性要求 |
|--------|-----------|
| 时间痕迹 | 树桩/磨损/褪色跨镜头位置和状态不变 |
| 人的痕迹 | 牲畜/工具/脚印跨镜头位置可微调但存在感不变 |
| 经济痕迹 | 材质/品质等级跨镜头不可升级（粗布不会变丝质） |
| 气候痕迹 | 泥泞/雾气/枯叶跨镜头保持同一状态 |
| 威胁痕迹 | 未知方向/暴露程度跨镜头不可突然消失 |

### 18.3 色彩锚点的跨镜头一致性

色彩锚点在同一场景中必须保持位置和功能一致：

**一致性规则**：
- 如果角色酒红上衣是场景中唯一暖色，所有镜头中酒红色必须在角色身上
- 冷灰基调不可在某镜头中突然变暖——除非有叙事理由（如闪电/火焰）
- 色彩锚点的色相不可跨镜头偏移——酒红不会变成玫红或橘红
- 如果是双锚点场景，两个锚点跨镜头必须同时存在

### 18.4 叙事密度与已有规范的一致性衔接

| 已有规范 | 与叙事密度规范的衔接点 | 一致性要求 |
|----------|---------------------|-----------|
| 环境参与叙事（打斗） | 打斗场景环境参与动作；静止场景环境提供证据 | 同一场次中打斗和静止镜头的环境信息不可矛盾 |
| 场景锚点表 | 五层证据是场景锚点表的叙事维度扩展 | 锚点表的环境描写必须覆盖至少3/5层证据 |
| 道具清单 | 角色痕迹是"身体上的道具" | 痕迹跨镜头追踪规则与道具一致 |
| 角色描写精度 | 痕迹因果链是精度规范的延伸 | 痕迹描写必须达到精度规范级别（位置+分布+原因） |
| 服饰精度 | 磨损是服饰精度的叙事维度 | 磨损描写不可与服饰锚定层矛盾（粗麻不会磨损出丝质光泽） |

## 十九、色彩叙事体系的一致性

### 19.1 色温梯度的跨镜头一致性

同一场次内色温梯度必须一致——不能一个镜头冷远景+暖中景+热近景，下一个镜头变成全暖：

**一致性规则**：
- 同一场次的调色板类型不可切换——暖浸型场次不会突然变冷浸型
- 色温梯度的三层（冷/暖/热）跨镜头保持方向一致——冷总是远暖总是近
- 光源色温跨镜头不变——暖金侧光不会变冷蓝顶光（除非场景内有光源切换叙事）

### 19.2 色桥的跨镜头一致性

角色服装色一旦作为色桥建立，跨镜头不可改变——色桥断裂=角色与环境脱节：

**一致性规则**：
- 同一场次内角色服装色不可变——粉色色桥不能变成蓝色
- 如果角色换装（叙事理由），新服装色必须重新建立色桥——新色桥必须与新环境匹配
- 环境色跨镜头不可突变——花海不会突然变成雪地

### 19.3 材质差的跨镜头一致性

同色系场景中各材质的光学行为跨镜头必须一致：

**一致性规则**：
- 缎面在镜头1有高光反射=镜头2-8也必须有高光反射（除非光源角度变化导致反射消失=需声明）
- 花瓣哑光吸光特性跨镜头不变
- 皮肤次表面散射效果跨镜头不变
- 如果某个镜头省略了材质声明=AI可能随机选择材质=与前后矛盾

### 19.4 冷呼吸孔的跨镜头一致性

冷呼吸孔的位置和面积跨镜头应保持一致：

**一致性规则**：
- 如果图1呼吸孔是背景蓝灰窗框，图2-8也应有蓝灰窗框（位置可微调但存在感不变）
- 呼吸孔面积跨镜头不可突变——5%不会突然变成30%
- 如果整场没有呼吸孔=全暖窒息=需确认是刻意选择

### 19.5 光源色的跨场景一致性

不同场景可以有不同光源色（=不同调色板类型），但同场景内光源色不可变：

**跨场景色温递进规则**：
- 叙事升温→光源色温可以从冷向暖递进（6500K→3500K→2800K）
- 叙事降温→光源色温从暖向冷递进（2800K→4500K→7000K）
- 这种递进是叙事弧线的色彩表达——不能无理由跳变

### 19.6 色彩叙事与已有规范的一致性衔接

| 已有规范 | 与色彩叙事的衔接点 | 一致性要求 |
|----------|-------------------|-----------|
| 色彩锚点策略（叙事密度） | 锚点是调色板类型的执行细节 | 锚点位置+色相必须与调色板类型匹配 |
| 恋爱五阶段焦距递进 | 色温应随焦距递进 | 暧昧冷→心动暖→失控全暖→回中回暖 |
| 面瘫美学 | 面瘫角色推荐冷浸型/撞色型 | 面瘫+暖浸型=风格矛盾（温暖梦幻≠冷漠面瘫） |
| 场景锚点表 | 光源体系=调色板总开关 | 锚点表中的色温基调必须与调色板类型一致 |
| 打斗环境叙事 | 打斗中的环境色变=权力翻转的色温信号 | 权力高位=暖光→权力翻转=冷光入侵 |
| 角色描写精度 | 服装色桥是六维中服饰维度的功能声明 | 服装色不可与环境色矛盾（除非有意跳脱） |

## 二十、皮肤真实感六层的一致性

### 20.1 SSS的跨镜头一致性

次表面散射行为由光源方向决定——同一场次光源方向不变，SSS行为也不应变：

**一致性规则**：
- 逆光场景中鼻翼透光=所有逆光镜头都必须有鼻翼透光（不可某镜头突然不透光）
- 颧骨高光"从内亮起"的质感跨镜头必须保持——不能镜头1从内亮、镜头2变表面白点
- SSS强度由光源强度和方向决定——同场次同光源=同SSS强度

### 20.2 微纹理的跨镜头一致性

面部微纹理是角色的"指纹"——跨镜头必须一致：

**一致性规则**：
- 雀斑位置跨镜头不可变——鼻梁上的雀斑不会跑到面颊
- 毛孔可见度跨镜头应一致——远景不可见正常，近景必须可见
- 绒毛存在感跨镜头一致——有绒毛的角色不会突然变无绒毛
- 微血管颜色跨镜头一致——眼周的淡蓝/淡红不会变深/变无

### 20.3 油汗层的跨镜头与跨情绪一致性

油汗层随情绪变化——这是它的跨镜头变化规则：

**同情绪跨镜头**：油汗层保持一致——紧张场景中所有镜头鼻头微汗
**情绪递进**：油汗层可递增——从冷静（微光泽）→紧张（微汗）→激烈（汗珠）
**不可逆规则**：一旦出现汗珠，后续镜头不能突然回到干爽——汗不会瞬间蒸发

### 20.4 色区差异的跨镜头一致性

面部色区差异是角色的"肤色彩虹"——跨镜头必须保持：

**一致性规则**：
- 额头偏黄、眼周偏红、面颊偏粉——这些色区关系跨镜头不可颠倒
- 色区差异的强度可随光源变化（暖光柔化、冷光放大），但方向不可反转
- 化妆改变色区=需要显式声明（如"嘴唇涂豆沙红"改变了嘴周色区）

### 20.5 边缘光的跨镜头一致性

边缘光由3D骨相+光源方向共同决定——骨相不变则边缘光位置不变：

**一致性规则**：
- 鼻梁两侧光边——跨镜头只要侧光存在就必须有
- 颧骨下方过渡光——跨镜头保持
- 下颌线光边——同角度同光源=必须存在
- 不同角度可改变边缘光位置（正面vs侧面），但同一角度必须一致

### 20.6 皮肤六层与已有规范的一致性衔接

| 已有规范 | 与皮肤六层的衔接点 | 一致性要求 |
|----------|-------------------|-----------|
| 视觉聚焦逻辑 | 眼睛6系统+皮肤6层=12系统面部活体感 | 眼部高光色温必须与皮肤SSS透光色温一致 |
| 角色描写精度 | 维度2面部特征包含皮肤质感 | 皮肤质感声明不可与六维中其他维度矛盾 |
| 三步表演法 | 皮肤微动态=三步法微反应层 | 微动态强度与表演层级匹配（基态极微/情绪变体增强） |
| 色彩叙事 | 色区差异=调色板在面部的微观 | 面部色区偏移方向必须与调色板类型一致 |
| 面瘫美学 | 面瘫=表情冻结+皮肤必须更真 | 面瘫角色不可省略皮肤六层——观众靠皮肤判真假 |
| Negative Prompt | 皮肤负提示防假 | `plastic skin, mannequin skin, uniform skin tone, poreless`跨全片一致 |


## 二十一、导演风格圣经的一致性

### 21.1 导演风格的跨镜头一致性

导演风格一旦声明，必须贯穿全片所有镜头——风格一致性是最高优先级之一。

**一致性规则**：
- LIGHTING策略跨镜头不可切换（声明诺兰=全片冷灰低饱和，不可中间某镜突然变暖）
- COMPOSITION签名跨场景保持（声明维伦纽瓦=全片极端留白，不可某场景突然构图拥挤）
- CAMERA运镜哲学跨段落保持（声明小津=全片静止，不可某段落突然手持）
- EMOTION节奏模式跨场景保持（声明奉俊昊=全片tonal shift，不可某场景单一情绪）

**允许变化的维度**：
- 构图具体位置可根据场景调整（诺兰的中心构图可偏左/偏右，但保持对称感）
- 光影强度可根据时间/情绪调整（维伦纽瓦的单光源可变亮变暗，但保持单源特性）
- 运镜速度可根据节奏调整（李安的极慢推进可偶尔稍快，但保持克制感）

### 21.2 导演风格与角色锚点的一致性

风格选择不可篡改角色物理特征锚点——风格只改变"怎么看"，不改变"是什么"。

**一致性规则**：
- 角色锚定层（体型/面部/服饰/道具/色彩标签）不可因风格改变
- 风格可改变光影呈现（诺兰冷灰调→角色在冷光下呈现，但角色本身不变）
- 风格可改变构图关系（维伦纽瓦留白→角色被环境吞噬，但角色物理特征不变）
- 风格可改变运镜方式（小津低机位→改变观看角度，但角色外观不变）
- 服饰颜色在风格滤镜下可有色温偏移（冷光下偏冷，暖光下偏暖），但不可改变基色

### 21.3 混搭风格的一致性维护

主+辅助风格混搭时，必须保持风格分工的一致性。

**一致性规则**：
- 辅助风格只负责声明的1个维度，不可越界
- 混搭的分界线在全片中必须一致（如"伯格曼只负责面部特写"=全片所有面部特写都用伯格曼语法）
- 主风格的5参数跨镜头不可与辅助风格的分配矛盾
- 同一场景内不可切换主/辅风格的分工

### 21.4 导演风格与色彩叙事的一致性

导演风格自带调色板，必须与色彩叙事体系的六型调色板对齐。

**一致性规则**：
- 诺兰=冷浸型，维伦纽瓦=温度梯度型，王家卫=暖浸型，张艺谋=三色三角型
- 选择导演风格后，六型调色板自动锁定对应类型
- 导演风格的色彩偏好优先于自由选色
- 色彩情绪圣经中的"导演映射"列必须与当前风格一致

### 21.5 导演风格与面瘫美学的一致性

不同导演的面瘫有不同语义——必须保持语义一致。

**一致性规则**：
- 诺兰面瘫=理性压抑（conscious+calculating），不可写成恐惧型
- 伯格曼面瘫=存在恐惧（conscious+terrified），不可写成冷漠型
- 小津面瘫=日常接受（conscious+accepting），不可写成权力型
- 跨镜头同角色同风格面瘫类型必须一致

## 二十二、色彩情绪圣经的一致性

### 22.1 主色调的跨场景一致性

主色调决定全片情绪基调，一旦确立不可更换。

**一致性规则**：
- 主色调1-2种，跨场景不可更换（全片蓝色主调不可中途变红色主调）
- 辅助色可根据场景调整，但必须从色彩情绪模块的搭配色列表中选择
- 点睛色位置可变，但色调不可变（全片暖橙点睛不可突然变冷绿点睛）
- 色温基调不可反转（冷片不可突然变暖片，除非叙事上有明确的情感转折点并声明）

### 22.2 色彩-皮肤声明的一致性

不同色彩情绪下皮肤声明不同，但跨镜头同色彩必须一致。

**一致性规则**：
- 同色彩同场景的皮肤声明必须一致（蓝色场景中所有镜头的SSS声明相同）
- 色彩切换时皮肤声明随之切换（从蓝到橙=从`cool SSS with faint warm blood`到`warm SSS amber glow`）
- 皮肤色区差异的基本分布不可因色彩改变（额头始终偏黄暖，脸颊始终偏粉亮）
- 面部色区的偏移方向必须与当前色彩情绪一致（蓝→偏冷，橙→偏暖）

### 22.3 冷呼吸孔的跨镜头一致性

暖色画面中的冷呼吸孔位置和比例需保持合理。

**一致性规则**：
- 同场景暖色调的冷呼吸孔比例5-10%，跨镜头保持
- 冷呼吸孔的位置可微调（角落阴影），但必须存在
- 冷浸型画面的暖锚定点也需跨镜头保持（至少1个暖色元素）
- 呼吸孔比例不可逐镜递减（否则=暖色入侵，视觉灼烧升级）

### 22.4 色彩组合规则的一致性

互补色/相邻色的使用规则跨场景必须一致。

**一致性规则**：
- 橙蓝互补对的分配逻辑跨场景一致（暖前景+冷背景 vs 冷前景+暖背景二选一贯穿）
- 红绿暴力冲突的使用条件一致（仅在暴力/冲突场景使用，不可在日常场景突然出现）
- 紫金皇室权力的使用场景一致（仅权力/仪式场景）
- 互补色=张力、相邻色=和谐的语义规则不可反转

### 22.5 色彩情绪与已有规范的一致性衔接

| 已有规范 | 衔接点 | 一致性要求 |
|----------|--------|-----------|
| 色彩叙事（六型调色板） | 六型管结构，情绪圣经管语义 | 同一场景中调色板类型不可与色彩情绪矛盾 |
| 导演风格圣经 | 风格自带色彩偏好 | 色彩选择必须与导演风格调色板一致 |
| 皮肤六层 | 色区差异随色彩偏移 | 偏移方向跨镜头一致 |
| 单帧叙事密度 | 色彩锚点=情绪模块实例 | 锚点色调与情绪模块对应 |
| 视觉聚焦逻辑 | 瞳孔反射环境色 | 反射色与当前色彩情绪一致 |

## 二十三、万能分镜模板的一致性

### 23.1 景别递进逻辑的跨段落一致性

同一作品中对同类段落应使用相同的模板版本。

**一致性规则**：
- 全片吵架场景统一用同版本（最短版或完整版），不可一个吵架用3镜、另一个用9镜，除非重要性差异巨大
- 全片打斗场景统一用同版本
- 全片走路场景统一用同版本
- 关键段落可升级到完整版，但升级规则需统一（如"每场高潮段落升级到完整版"）

### 23.2 情绪弧线的跨段落一致性

同类段落的情绪弧线模式应保持一致。

**一致性规则**：
- 全片吵架遵循相同的5阶段弧线（克制→升级→爆发→崩溃→冷战），不可某场跳过爆发
- 全片打斗遵循相同的5阶段弧线（对峙→交锋→受挫→反杀→结果），不可某场跳过受挫
- 全片走路遵循相同的5阶段弧线（氛围→行进→聚焦→极点→余韵），不可某场跳过极点
- 情绪的具体强度可变（高分吵架vs低分吵架），但弧线结构不变

### 23.3 模板叠加规范的一致性

模板与已有规范的叠加方式跨段落必须一致。

**一致性规则**：
- 所有吵架段落的正反打拆分规则一致（都是独立镜头）
- 所有打斗段落的运镜美学选择一致（全片选一种，不可某场连绵美学某场切割美学）
- 所有打斗段落的手持层级分配一致（对峙=呼吸感，交锋=临场感，受创=混乱感）
- 所有走路段落的远景环境证据层数一致（至少3/5层）

### 23.4 变奏与模板的一致性

变奏版必须保持与基础模板的逻辑关联。

**一致性规则**：
- 变奏版必须声明变奏类型+变奏意图
- 倒叙变奏的镜头顺序必须可还原为基础模板顺序
- 混合变奏的模板切换点必须在分镜文档中标注
- 变奏不可改变情绪弧线的核心拍（吵架的爆发、打斗的反杀、走路的极点仍须存在）

### 23.5 万能模板与已有规范的一致性衔接

| 已有规范 | 衔接点 | 一致性要求 |
|----------|--------|-----------|
| 打斗叙事弧线 | 打斗模板完整版=5拍+权力翻转 | 翻转逻辑跨段落一致 |
| 运镜美学框架 | 模板中选择美学贯穿 | 全片同类型段落同美学 |
| 正反打多镜 | 吵架拍2-3拆分 | 拆分规则跨段落一致 |
| 三步表演法 | 每镜头含三层 | 三层结构跨模板跨段落一致 |
| 皮肤六层 | 特写/极特写声明皮肤 | 皮肤声明在同景别镜头间一致 |
| 导演风格 | 模板套用导演语法 | 导演风格的5参数跨所有模板一致 |
| 色彩情绪 | 各拍情绪=色彩变化 | 色彩-情绪映射跨段落一致 |


## 二十四、角色设定板生成的一致性

### 24.1 两步法一致性保障

| 一致性维度 | 步骤1（单人图） | 步骤2（设定板） | 校验方式 |
|-----------|---------------|---------------|---------|
| 面部骨架 | 锚定窄长脸+高颧骨 | 所有模块同脸型 | 逐模块目视对比 |
| 发型发色 | 锚定长发+半披散+凌乱潮湿 | 所有模块同发型同色 | 背面/侧面模块重点检查 |
| 服饰7要素 | 锚定黑甲+蟒袍+灰披风 | 所有模块同服饰细节 | 肩甲/腰带/绷带跨模块对比 |
| 体态比例 | 锚定少年修长+重心偏前 | 坐/蹲姿同比例 | 蹲姿不能变矮/变胖 |
| 道具 | 锚定左手握刀 | 正面/侧面/动态同道具 | 刀不松手 |

### 24.2 六维锚点表→设定板→分镜的三级一致性链

```
六维锚点表（文字规范）→ 设定板ID块（文字标注）→ 设定板图像（视觉参考）→ 分镜提示词（引用锚点+参考图）
```

- 六维锚点表的6个维度 = 设定板生成后逐维度校验的6把尺
- 设定板ID块的4个字段 = 分镜提示词锚定段的核心信息来源
- 设定板图像 = 分镜提示词的 `--cref` 参考图源
- 三级链中任何一级出现偏差，必须回溯修正上游

### 24.3 设定板跨角色一致性

当同一作品中存在多个角色设定板时：

| 一致性维度 | 校验标准 |
|-----------|---------|
| 比例关系 | 两个角色同框时身高差与设定板一致 |
| 服装体系 | 同一时代的服饰细节（如甲胄制式）应呼应 |
| 色彩系统 | 多角色的服装色不冲突，符合色彩情绪圣经的铁律 |
| 打光统一 | 所有设定板使用相同的前侧光基准，避免不同光位导致肤色差异 |

### 24.4 超时兜底后的一致性维护

- 去掉参考图用纯文字生成时，步骤1的角色描写必须**逐字复用**到步骤2，不能改写或简化核心锚点
- 精简版设定板缺少的模块，在后续单独生成补充时，必须以已生成的中心全身图为参考
- 拼贴补充时，检查补充模块与已有模块的面部/服饰/比例一致性


## 二十五、镜头时长与景别推断的一致性

### 25.1 时长一致性（剪辑节奏连续性）

| 一致性维度 | 标准 | 校验方式 |
|-----------|------|---------|
| 同场景内镜头时长是否构成合理节奏 | 不可连续3个同时长镜头 | 逐场检查时长序列 |
| 快切序列时长是否递减 | 3s→2s→1.5s→1s | 动作段落检查 |
| 情绪段落时长是否递增 | 2s→3s→5s→8s | 情感高潮检查 |
| 对白镜头时长与台词量是否匹配 | max(基准,阅读时间) | 逐镜头对比 |

### 25.2 景别推断跨场一致性

| 一致性维度 | 标准 |
|-----------|------|
| 同一角色在不同场景的景别逻辑是否一致 | 主角叙事线景别节奏有规律可循 |
| 同类型场景是否用同套景别模板 | 如所有对话场景=MS↔MCU正反打 |
| 景别递进是否符合万能模板逻辑 | 吵架/打斗/走路三套模板 |
| 景别推断冲突解决逻辑跨场一致 | 动作+对白永远对白优先 |

### 25.3 表格式分镜跨场一致性

| 一致性维度 | 标准 |
|-----------|------|
| 同角色AI提示词摘要是否一致 | 角色锚点/服饰锚点跨场不可变（除非有变化层标注） |
| 同场景光影参数是否一致 | 光位+色温跨镜头不可跳变 |
| 场次编号是否全局连续 | 不可跳号/重复/倒序 |

### 25.4 长剧本批处理间一致性

- 批次1-2-3...N的锚点表必须指向同一个版本，不可各批次自行修改
- 表格式分镜的列结构跨批次必须统一（11字段不可增减）
- 交互式HTML文档必须覆盖所有批次的分镜数据，不可有遗漏
- Phase 3全片一致性校验必须跨所有批次执行，不可只在单批次内校验


## 二十六、工业级道具设计的一致性

### 26.1 同一道具跨镜头一致性

| 一致性维度 | 标准 | 校验方式 |
|-----------|------|---------|
| 材质外观 | 跨镜头同材质=同控制词 | 金属道具每个镜头都必须有patinated/verdigris |
| 磨损位置 | 不对称磨损的位置跨镜头固定 | 刀刃缺口在第3镜头和第8镜头在同一位置 |
| 色彩 | 道具5色色卡跨镜头不变 | 青铜色在所有镜头中色值一致 |
| 尺寸比例 | 道具与角色的尺寸关系固定 | 42mm腕表不可在某镜头变成50mm |
| 光线交互 | 同光源下道具反射一致 | 暖光下青铜的反射模式跨镜头统一 |

### 26.2 道具变化层追踪

当道具在剧情中发生变化（破损/改造/获得）时，必须追踪变化链：

```
道具初始态 → [事件1] → 变化态1 → [事件2] → 变化态2 → ...

示例：
完整青铜剑 → [战斗] → 剑刃缺口+血迹 → [再战斗] → 剑柄缠布更换+血迹叠加
```

- 每个变化态对应一组新的材质控制词（如"intact"→"chipped blade with dried blood"）
- 变化态只增加痕迹，不减少——血迹只会叠加不会消失
- 变化必须与叙事事件因果链对应，不可无理由变化

### 26.3 道具色卡与场景调色板的兼容

- 道具5色色卡必须在场景调色板的色彩体系内
- 道具色=场景色的子集或补色——不可出现场景冷蓝调中突然出现暖橙道具（除非道具本身就是视觉焦点/叙事道具）
- 道具作为色桥时：道具色必须桥接角色服装色与场景环境色

### 26.4 道具与角色手部的一致性

当道具出现在角色手中时：
- 握持方式跨镜头固定（左手/右手/双手/指位）
- 手部与道具的触觉关系声明跨镜头一致（紧握/轻触/悬停）
- 手部皮肤质感（汗渍/血迹/绷带）与道具表面（油脂/血迹/灰尘）必须有交互痕迹——手摸过的地方应该更亮/更脏


## 二十七、AI视频生成工作流的一致性

### 27.1 故事板→视频的一致性链

```
角色设定表 → 故事板8镜 → 视频输出
(标准态)     (分镜态)      (动态态)
```

- 角色设定表定义"角色长什么样"→ 故事板中所有分镜必须与设定表一致
- 故事板定义"每镜画面长什么样"→ 视频输出必须与故事板画面一致
- 视频提示词定义"画面怎么动"→ 运动不可改变画面中已定义的角色/场景外观

### 27.2 三重保险跨阶段一致性

| 阶段 | 一致性保障 | 失败表现 |
|------|-----------|---------|
| 设定表自身 | 多角度同脸/同服/同比例 | 正面和侧面像两个人 |
| 设定表→故事板 | 8分镜与设定表角色一致 | 某分镜脸歪/服装变化 |
| 故事板→视频 | 视频角色与故事板一致 | 视频中角色变形/风格漂移 |

**失败时的修正策略**：
- 设定表自身失败：重新生成，加强`STRICT consistency`声明
- 设定表→故事板失败：上传设定表作为参考图+单独重生成问题分镜
- 故事板→视频失败：上传设定表+故事板作为双参考+加强`与参考图完全一致`声明

### 27.3 时间戳跨段一致性

- 同一运镜跨段时间内速度一致（不可前2秒匀速后3秒突然加速无理由）
- 情绪递进与时间节奏对齐：时间加速=情绪升级，时间减速=情绪释放
- 面瘫美学的镜头时间分配：停留时间比常规+30%，给观众"阅读空白"的时间

### 27.4 迭代修改的一致性维护

- Round 2修改只调整问题段，不影响已确认段
- 每轮迭代后检查未修改段是否仍然一致（AI可能"连带修改"）
- A/B测试的两个版本使用完全相同的角色设定表，只改风格/运镜

### 27.5 避坑修复后的一致性校验

| 坑修复后 | 需校验的一致性项 |
|---------|---------------|
| 修复"角色崩了" | 重生成的分镜是否与其他7镜风格一致 |
| 修复"第一帧显示故事板" | 首帧画面是否与后续帧风格连续 |
| 修复"风格漂移" | 修复后的后半段是否与前半段色调一致 |
| 修复"中文乱码" | 单独迭代的中文是否与故事板其他元素风格统一 |


## 二十八、AIGC四步黄金框架的一致性

### 28.1 四步框架跨镜头一致性

| 框架步骤 | 跨镜头一致性要求 |
|---------|----------------|
| 定镜头 | 同场景内景别递进有逻辑（不可跳级），焦段不矛盾 |
| 构图 | 同场景内前后景元素位置固定，不可消失/突然出现 |
| 光影 | 同场景光源方向和色温跨镜头一致，只可随时间自然渐变 |
| 质感 | 同场景内胶片颗粒/空气感/材质纹理跨镜头统一 |

### 28.2 三层纵深跨镜头一致性

- 前景元素：同一场景内前景的类型和位置跨镜头固定（如门框始终在左）
- 中景主体：主体与前景/远景的空间关系跨镜头不可跳变
- 远景环境：远景的定义（建筑/山脉/天空）跨镜头不可变化

### 28.3 光影对撞跨镜头一致性

- 冷暖对撞的冷暖比例跨镜头保持一致（如暖70%冷30%）
- 色温渐变必须符合时间逻辑（日出→正午→日落，不可倒转）
- 对撞关系只在叙事转折点改变，不可随意切换

### 28.4 质感层跨镜头一致性

- 胶片颗粒型号全程统一（Kodak 5219不可中途变Fujifilm ETERNA）
- 空气感元素同场景统一（有雾的镜头全程有雾，不可突然清透）
- 材质纹理的精度级别全程统一（不可前镜有毛孔后镜光滑）

### 28.5 声音设计跨镜头一致性

- 同角色音色跨镜头不可变化
- 同场景环境音跨镜头连续
- BGM风格和情绪基调在同一场景段内统一

## 二十九、电影级对白分镜的一致性

### 29.1 对白五层结构跨镜头一致性

- 视线关系在正反打中必须保持180°轴线——A看向画面左侧则B必须看向画面右侧，越轴=视线关系断裂
- 停顿镜头中环境音必须连续——雨声/电流声/车流声不可在停顿中突然消失或变化
- 空间距离递进必须不可逆——已进入压迫阶段不可退回理性阶段（除非权力反转）
- 谎言泄漏点在同一角色跨镜头时必须保持——手指状态/呼吸节奏/光线色温不可自相矛盾
- 情绪主导权的反转必须同步运镜+构图+焦距——只反转构图不反转焦距=权力转移不完整

### 29.2 呼吸镜头跨镜头一致性

- 对白呼吸镜头的推进节奏跨镜头必须连贯——镜头5推进到A的MCU，镜头6不能突然回到WS再重新推
- 呼吸镜头的手持强度必须与情绪弧线同步——平静→轻微呼吸感→压迫→明显呼吸→爆发→混乱手持→坍塌→回稳
- 对白呼吸镜头与恋爱呼吸镜头不可在同一场景混用——权力场景用了恋爱式温柔呼吸=风格错位

### 29.3 不对称正反打跨镜头一致性

- 强势方的焦距/构图风格在同一场次内必须保持——镜头1用85mm拍强势方，镜头5不能用35mm拍同一强势方（除非权力已反转）
- 权力反转后正反打参数必须完整交换——强势变弱势=焦距+构图+机位全部反转，只反转一部分=半吊子

### 29.4 第三视角跨场景一致性

- 同一叙事段落中使用第三视角时，机位风格应一致——角落就是角落风格，门外就是门外风格，混用=观察者身份混乱
- 第三视角的情绪基调跨场景保持——命运旁观=冷漠/宿命/不可改变，不能突然变温暖

### 29.5 对白节奏跨场次一致性

- 同一角色在不同场次的对白节奏风格应一致——一个角色在A场景是压迫型强势，在B场景突然变成回避型=人设断裂（除非剧情有反转）
- 整部作品的节奏阶段推进应有序——不能所有场次都是"平静→爆发"跳过中间阶段

### 29.6 导演对白风格跨场景一致性

- 选用某导演对白风格后，同一场次内必须保持——不能用王家卫式空间阻隔开场+诺兰式信息快切收尾
- 导演对白风格与导演风格圣经的通用参数不可矛盾——王家卫对白用空间阻隔+风格圣经用霓虹拖影，两者必须同场叠加

### 29.7 对白光影跨镜头一致性

- 同一对白场次中光位心理暗示不可矛盾——开场侧光=内心冲突，不能中途变顶光=审判（除非剧情有明确转折点）
- 光比递进必须跨镜头连贯递增——不能镜头3比镜头2暗但镜头4又亮回来

### 29.8 焦距-情绪跨镜头一致性

- 焦距变化方向必须与情绪弧线方向一致——情绪升级=焦距递增，情绪退潮=焦距递减，随意跳变=无叙事逻辑
- 同一情绪阶段的焦距范围必须稳定——平静阶段不能一会24mm一会85mm

### 29.9 暧昧/恋爱环境声音跨镜头一致性

- 同一场景的环境声音底色不可变——雨声+电流声是底色，跨镜头必须持续，不能镜头3突然变晴天
- 声音细节可随情绪阶段变化——情绪升温时细节声（呼吸/衣料）放大，情绪降温时环境声回归，但底色始终在

## 三十、AI视频模型微表情的一致性

### 30.1 跨模型角色一致性

- 同一角色在Kling和Seedance间切换时，必须共用同一锚点表——锚定层不可因模型切换而改变
- 模型切换后首次生成必须与参考图/角色身份板比对——Kling和Seedance对同一锚点表的解读可能不同，需要微调提示词适配
- 跨模型的面部关键尺寸（瞳距/鼻梁高度/下颌弧度）必须人工比对——自动锚点不能保证跨模型一致性

### 30.2 模型弱点补偿跨镜头一致性

- Kling防变形声明在同一场次所有镜头中必须一致——镜头1有补偿/镜头5没有=变形在镜头5突然出现
- Seedance防柔化声明在所有含人物镜头中必须一致——不一致=皮肤质感跨镜头跳变
- 补偿声明的措辞在同一场次内不可变化——变化措辞=AI可能解读为不同指令

### 30.3 Kling微表情控制方案跨镜头一致性

- 使用方案1（结构化提示词）时，转头角度/眨眼时长的量化标准在同一场次内必须统一——镜头1转12°/镜头3转15°可以，但必须是有意的叙事递进而非随意变化
- 使用方案4（多视角角色档案）时，character ID在同一场次内必须锁定——更换ID=更换面部几何先验=角色崩塌
- 帧级剧本的帧率基准在同一场次内不可变——24fps基准和30fps基准的帧编号含义不同

### 30.4 9大真实感要素跨模型一致性

- 不对称性声明跨模型必须保持——Kling加`slight head tilt`而Seedance不加=两个模型输出的人物歪头方向不同
- 手持拍摄感参数跨模型需要分别调校——Kling原生物理晃动+Seedance需额外声明，两者参数不同但观感需一致
- 皮肤质感声明跨模型措辞不同但效果需对齐——Kling本身毛孔可见不需额外声明/Seedance需强制声明但最终效果应匹配

### 30.5 混合模型协作的色彩/质感一致性

- Kling默认偏冷锐+Seedance默认偏暖柔——同一场次混用必须在一方添加色温补偿：Kling加`slightly warm tone`/Seedance加`slightly cool sharp tone`
- 质感差异（Kling更粗糙真实/Seedance更柔滑）——混用时需统一声明质感方向，否则跨镜头质感跳变

## 三十一、混合分镜工作流的一致性

来源：Jon Kent "I Spent 9 Months Testing AI for Filmmaking" 混合工作流实践。

### 31.1 实拍→AI过渡的一致性

- [REAL]镜头建立的视觉基线（光照方向/色温/质感）必须延续到后续[AI]镜头
- 过渡提示词必须包含 `matching the [X] lighting established in previous shots`
- 从实拍到AI的景别过渡必须渐进——近景实拍→中景AI→远景AI，不可突然跳变
- 实拍镜头中角色的服装/道具状态是后续AI镜头的锚定标准——若实拍中角色穿红外套，AI镜头中也必须穿红外套

### 31.2 末帧接力跨镜头一致性

- 末帧接力是角色锚点表在视频生成环节的延伸——锚点表管"长什么样"，接力管"站在哪里"
- 接力帧的检查维度：人物位置/朝向/服装状态/手持道具/光线方向/阴影方向
- 相邻[AI]镜头之间必须建立接力链——接力断裂=视觉跳变=一致性失败
- 接力帧若需修正，应在Photoshop中微调后再用作参考，不可直接使用低质量帧
- 跨场景的接力链必须断裂——用[REAL]镜头或标题卡做视觉分隔

### 31.3 [HYBRID]镜头光照一致性

- 实拍前景和AI背景必须共享同一光源逻辑——方向、色温、光质三维度必须全部匹配
- 实拍时必须记录：主光方向、色温、光质、辅助光方向、环境反射
- AI背景提示词必须显式声明与实拍匹配的光照参数
- 常见失败模式：实拍人物受左侧暖光照射，AI背景却是右侧冷光——合成后人物浮在画面上
- 反向绿幕流程中，Photoshop清洁步骤不能改变光照——只去除人物，保留光照痕迹

### 31.4 声音一致性

- 同一场景内3层声音（Ambient/Foley/Emotional）必须跨镜头一致——SHOT05的风声不能在SHOT06突然消失
- [REAL]镜头的现场音与[AI]镜头的后期音之间不能有明显的音质差异
- 对话场景中角色脚步声的节奏和材质必须一致（不能一个镜头踩 gravel，下个镜头踩 wood）
- 环境音的混响特性必须匹配场景——室内有回响，室外无回响，不可混错

### 31.5 混合工作流与已有一致性系统的关系

- **角色锚点表**：在[HYBRID]镜头中，前景实拍部分是锚点表的"实物验证"——如果实拍外观与锚点表不符，以实拍为准更新锚点表
- **末帧接力**：是锚点表的动态扩展——锚点表定义静态外观，接力链定义动态位置连续性
- **AI模型路由**：[HYBRID]镜头的AI背景部分应选择透视匹配能力强的模型（Runway/LTX），而非微表情强的模型（Seedance）
- **感知流畅性**：是一致性的时间维度策略——确保观众在认知层面接受AI画面为"一致的"真实

## 三十二、分镜逐秒情绪拆解法的一致性

### 32.1 时间轴内情绪一致性
- 相邻时间段的微动作必须可衔接——不能从"安静"直接跳到"大哭"而无过渡
- 微部位动作在同一镜头内必须指向同一情绪方向——嘴角上扬和眉头紧锁若同时出现，必须声明为"含泪微笑"等复合情绪
- 收尾状态必须与下一个镜头的起始状态衔接——镜头间情绪不能断裂

### 32.2 情绪弧线跨镜头一致性
- 同一角色的情绪弧线必须跨镜头连贯——不能镜头A还在崩溃，镜头B突然平静而无交代
- 情绪递进的动词精度必须跨镜头一致——"眉头轻皱"不能在下个镜头变成"眉头紧锁"（程度跳变）
- 压缩后的提示词中情绪弧线关键词必须与时间轴原文对应

## 三十三、故事板五色标记系统的一致性

### 33.1 五色信息跨镜头一致
- 🔵蓝色运镜标记在连续镜头间必须有逻辑——不能前一个标记"慢推"，后一个无理由变成"急拉"
- 🟠橙色灯光标记在同一场景内必须方向一致——主光从左侧来，下一镜头不能变成右侧
- 🟣紫色声音标记在同一场景内必须跨镜头延续——配乐起后不能下一个镜头凭空消失

### 33.2 角色板→故事板→视频一致性链
- 角色板中的角色外观（🔴标记依据）必须与故事板草图一致
- 故事板中的🟠灯光标注必须与场景参考图集的光源方向一致
- 五色标记信息量≤3-5个要素——超量会导致AI理解混乱→一致性崩塌

## 三十四、跟随运镜的一致性

### 34.1 跟随类型跨镜头一致
- 同一角色的跟随运镜类型不能无理由切换——前一个镜头侧面跟随，下个镜头不能突然变成俯拍
- 跟随速度必须与角色动作速度一致——角色慢走+快速跟随=违和
- 背景变化方向必须与跟随方向一致——侧面跟随时背景横向后退，不是纵向

### 34.2 组合运镜过渡一致性
- 推近→跟随：推近的终点焦距必须与跟随的起始焦距衔接
- 环绕→跟随：环绕的结束角度必须与跟随的起始角度一致
- 多运镜组合中角色位置不能因运镜切换而跳变

- 混搭的两个维度（叙事+视觉）各自内部必须一致——叙事节奏不因摄影师风格变化而紊乱
