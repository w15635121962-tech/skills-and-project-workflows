## 一、跟随运镜是什么

**跟随镜头（Tracking/Follow Shot）**：摄像机跟随运动主体移动，保持主体在画面中的相对位置不变，背景持续变化。核心作用是让观众"跟着角色走"，产生代入感和速度感。

### 与其他运镜的本质区别

| 运镜 | 摄像机位置 | 主体 | 背景 | 观感 |
|------|-----------|------|------|------|
| **跟随镜头** | 随主体移动 | 稳定 | 剧烈变化 | 代入感、速度感 |
| 摇镜头 | 固定 | 移动 | 扫过 | 旁观感 |
| 推镜头 | 固定→推近 | 放大 | 压缩 | 压迫感 |

## 二、跟随运镜的五大类型

### 2.1 侧面跟随（最常用）

摄像机从侧面与主体并行移动，经典的"跟拍"视角。

```
通用模板：
[主体]在[环境]中[动作]。跟随运镜，摄像机从侧面跟随[主体]，
保持[主体]在画面中央/左侧/右侧。[背景变化描述]。

案例：
年轻女子在雨后湿漉漉的街道上快步行走。跟随运镜，摄像机从侧面跟随她，
保持她在画面右侧三分之一处。雨滴落在水洼中泛起涟漪，路灯的光影从她身上扫过，
远处的行人模糊成虚影。
```

### 2.2 正面后退跟随

摄像机在主体前方后退拍摄，能看到主角面部表情。适合情感戏。

```
通用模板：
[主体]向前行走/奔跑。正面跟随运镜，摄像机在[主体]前方后退拍摄，
保持[主体]面部始终可见。[环境从主体身后掠过的描述]。

案例：
战士穿越燃烧的废墟，目光坚毅地向前走来。正面跟随运镜，摄像机在战士前方后退拍摄，
保持他的面部始终在画面中央。火光在他身后跳动，灰烬从两侧飘落，废墟在身后渐渐远去。
```

### 2.3 背面推进跟随

摄像机在主体后方跟随，观众"跟着走"。适合制造悬念和代入感。

```
通用模板：
背面跟随运镜，摄像机在[主体]后方推进，观众跟随[主体]的视角前进。
[前方环境如何展开的描述]。

案例：
背面跟随运镜，摄像机在探险者后方推进，观众跟随他进入洞穴深处。
手电筒的光束在前方墙壁上晃动，水滴从钟乳石上滴落，洞穴深处传来回声。
```

### 2.4 低角度贴地跟随（压迫感跟踪）

极低角度，贴近地面，产生强烈的紧张感和压迫感。

```
通用模板：
极低角度手持跟随，摄像机贴地推进，[主体]的[部位]在画面中占据主导。
[环境的压迫感描述]。

案例：
极低角度手持跟随，摄像机贴地缓慢推进，只有角色的鞋子在画面下方交替出现。
地面上的碎石被踢飞，背景中废弃工厂的巨大管道投下阴影，压迫感越来越强。
```

### 2.5 高空俯拍跟随

从高空向下跟随，展示运动轨迹和空间关系。类似"上帝视角"跟踪。

```
通用模板：
高空俯拍跟随，摄像机从上方垂直向下跟随[主体]的运动轨迹。
[从高空能看到的全部画面]。

案例：
高空俯拍跟随，摄像机从正上方跟随一辆红色跑车在蜿蜒的沿海公路上飞驰。
公路像一条灰色的丝带缠绕在山体上，深蓝的海水拍打着悬崖，跑车的尾灯拉出红色光轨。
```

## 三、一镜到底：多种运镜组合

「探路AI」视频的核心亮点：**在一个连续镜头中组合多种运镜**，实现"一镜到底"效果。

### 3.1 组合原则

> ⚠️ 每条提示词最多用 2-3 个运镜指令，多了反而乱。

### 3.2 经典组合模板

#### 组合 A：推近 + 跟随（情绪递进型）

```
从远景缓慢推进至中景，然后转换视角开始侧面跟随[主体]移动。
[主体]从远处走来，摄像机先推近聚焦于面部表情，再切换至侧面跟随其行走。
背景从静止的广角环境过渡到动态后退的街景。

案例：
市场尽头，老人背着一筐橘子缓慢走来。摄像机从远景缓慢推近至中景，
聚焦于他额头的汗珠。然后切换为侧面跟随运镜，保持老人在画面中央，
摊位上的水果、路人、棚顶在背景中快速后退。
```

#### 组合 B：环绕 + 跟随（展示转跟踪型）

```
摄像机先以弧形绕摄[主体]半周，展示其全貌和环境关系，
然后无缝切换为背面跟随运镜，观众跟着[主体]进入下一个空间。

案例：
竹林深处，剑客负手而立。摄像机先以弧形绕摄半周，展示他挺拔的背影
和周围摇曳的竹影。然后切换为背面跟随运镜，推开竹门，观众跟随他
走进一间点着油灯的茅草屋。
```

#### 组合 C：低角度升起 + 高空俯拍跟随（空间展开型）

```
摄像机从极低角度贴地开始，缓慢垂直向上升起，逐渐过渡到高空俯瞰。
当[主体]开始移动时，切换为高空俯拍跟随，展示完整运动轨迹。

案例：
摄像头从草叶间的地面开始，缓慢垂直升起，一只鹰从巢中振翅飞出。
镜头升到树冠上方后切换为高空俯拍跟随，鹰在峡谷中盘旋滑翔，
它的影子在岩石上快速移动。
```

#### 组合 D：摇镜锁定 + 跟随（追踪型）

```
先使用摇镜头锁定快速移动的[主体]，当[主体]经过摄像机位置后，
切换为背面跟随运镜，加速跟上。

案例：
赛车从远处的弯道出现。先使用右摇镜头锁定赛车，它呼啸着从摄像机前
冲过。赛车经过后立即切换为背面跟随运镜加速跟上，排气管喷出火焰，
轮胎与地面摩擦出白烟。
```

## 四、Seedance 2.0 运镜提示词公式

### 标准公式

```
【核心画面内容】
+【精准运镜指令】（最多 2-3 个）
+【画面质感】（电影级/纪实/水墨…）
+【光影风格】（自然光/戏剧光/低饱和…）
+【Seedance 2.0 适配指令】
```

### 快慢节奏控制

| 节奏 | 提示词 | 适用场景 |
|------|--------|----------|
| 慢速跟随 | `极缓慢的跟随运镜` | 情感戏、氛围营造 |
| 常速跟随 | `平稳的跟随运镜` | 日常行走、对话 |
| 快速跟随 | `急速跟随运镜，动态模糊` | 追逐、动作戏 |
| 变速跟随 | `镜头快慢结合，先慢动作特写，再急速推动` | 情绪爆发、转折 |

### Seedance 2.0 专属增强

在提示词末尾加入：
- `适配Seedance 2.0动态渲染功能`
- `适配Seedance 2.0智能对焦功能`

## 五、情绪 → 运镜映射

> **核心心法**：先定情绪，再选运镜。你想让观众感受到什么——运镜就为这种情绪服务。

| 想表达的情绪 | 推荐运镜 | 角度 | 节奏 |
|-------------|---------|------|------|
| 紧张、压迫 | 低角度贴地跟随 | 极低 | 慢→快 |
| 代入、共鸣 | 正面后退跟随 | 平视 | 慢 |
| 悬念、探险 | 背面推进跟随 | 平视 | 慢 |
| 速度、刺激 | 侧面跟随 | 平视 | 快 |
| 孤独、渺小 | 高空俯拍跟随 | 俯视 | 慢 |
| 激动、爆发 | 推近→跟随组合 | 平视 | 快慢结合 |
| 优雅、展示 | 环绕→跟随组合 | 平视 | 慢 |
| 追踪、紧迫 | 摇镜→跟随组合 | 平视 | 快 |

## 六、新手常见错误 & 纠正

| 错误 | 问题 | 正确做法 |
|------|------|----------|
| "镜头跟随主角移动" | 太模糊，AI不知道从哪个角度跟 | 明确角度：侧面/正面/背面/俯拍 |
| 一条提示词堆 5 个运镜 | 互相冲突，AI混乱 | 最多 2-3 个，有清晰的切换逻辑 |
| 只写运镜不写背景变化 | 画面死板，没有"跟随感" | 必须描述背景如何后退/变化 |
| 运镜节奏不匹配情绪 | 悲伤用快跟随，动作戏用慢跟随 | 先定情绪，再选节奏 |
| 没有 Seedance 适配指令 | 渲染效果不够优化 | 末尾加适配语句 |

## 七、速查清单

一条完整的跟随运镜提示词应包含：

- [ ] 主体是什么？在做什么？
- [ ] 从哪个角度跟随？（侧面/正面/背面/俯/仰）
- [ ] 主体在画面中的位置？（中央/左侧/右侧三分之一）
- [ ] 跟随节奏？（慢/正常/快/变速）
- [ ] 背景如何变化？（后退/掠过/压缩）
- [ ] 光影质感？（自然光/戏剧光/低饱和/电影级）
- [ ] Seedance 2.0 适配指令？

## 附：探路AI 视频核心要点提炼

> 该视频的核心教学点：新手也能尝试的 AI 视频进阶玩法 — 一镜到底 + 多种运镜组合。

五个关键教训：
1. **一镜到底不等于一个运镜到底** —— 可以在一个镜头内按逻辑切换运镜方式
2. **运镜切换要有"动机"** —— 推近是因为情绪到了，切换跟随是因为角色开始移动
3. **最多 2-3 个运镜指令** —— 多了 AI 理解不了
4. **背景变化是跟随运镜的灵魂** —— 不写背景就不会有"跟随感"
5. **先定情绪再选运镜** —— 技巧服务于表达，不是炫技
