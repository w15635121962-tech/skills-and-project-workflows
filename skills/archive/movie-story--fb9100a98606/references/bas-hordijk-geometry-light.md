## 两大核心技法 → AI 提示词映射

### 技法一：大色块几何分割

**原理**：利用建筑边线或明亮梁柱，将画面切分成大面积色块，用极简的线条秩序压住视觉重心。路人成为几何中心里的点睛之笔。

**AI 提示词关键短语**：

| 英文 | 中文 |
|------|------|
| `large geometric color blocks dividing frame` | 大面积几何色块切分画面 |
| `architectural lines as compositional grid` | 建筑线条作为构图网格 |
| `bold color field composition` | 大胆的色域构图 |
| `minimalist geometric order` | 极简几何秩序 |
| `tiny human figure as focal point in geometric void` | 小人物作为几何空间中的焦点 |

**提示词模板**：
```
street photography, large geometric color blocks created by architectural edges,
frame divided into bold color fields, minimalist geometric order, a single passerby
as tiny focal point in the composition, strong visual weight, Bas Hordijk style
```

---

### 技法二：缝隙中的局部光影

**原理**：寻找暗部中的孔洞、墙缝，用框架将光线锁在极窄区域。这种黑暗中的"视觉出口"让画面极具叙事张力——每个穿行而过的人，故事感瞬间拉满。

**AI 提示词关键短语**：

| 英文 | 中文 |
|------|------|
| `narrow shaft of light piercing darkness` | 窄束光穿透黑暗 |
| `light trapped in architectural gap` | 光线被封在建筑缝隙中 |
| `frame within frame spotlighting subject` | 框中框聚光于主体 |
| `deep shadows with razor-thin light beam` | 深阴影 + 刀刃般细的光束 |
| `visual escape through darkness` | 黑暗中的视觉出口 |
| `dramatic narrative tension through confined light` | 受困光线制造的戏剧叙事张力 |

**提示词模板**：
```
street photography, deep enveloping darkness, a razor-thin beam of light escaping
through a narrow architectural gap, a lone figure passing through the light,
dramatic chiaroscuro, intense narrative tension, frame within frame composition,
storytelling through confined illumination, Bas Hordijk inspired
```
