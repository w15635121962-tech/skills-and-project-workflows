# 光影与色彩脚本 (Lighting & Color Script)

## 核心原则

光影与色彩是情绪的第一语言。观众在理解对白之前，已经通过光影和色彩感受到了情绪。

## 一、光影设计体系

### 1.1 自然光分类

| 光型 | 特征 | 情绪表达 | 适用场景 |
|------|------|----------|----------|
| 黄金时刻 (Golden Hour) | 低角度暖光，长阴影 | 浪漫、怀旧、温暖 | 爱情戏、回忆、告别 |
| 蓝色时刻 (Blue Hour) | 天空深蓝，冷调柔光 | 忧郁、神秘、沉思 | 独白、转折、悬念 |
| 正午光 (Midday) | 顶光，硬阴影，高对比 | 压迫、暴露、现实 | 审讯、冲突、沙漠 |
| 阴天散射 (Overcast) | 柔和均匀，低对比 | 平淡、疏离、日常 | 办公、争吵后、失落 |
| 逆光 (Backlight) | 光源在主体背后，轮廓光 | 神圣、希望、离别 | 重生、告别、顿悟 |
| 侧光 (Side Light) | 一半亮一半暗，强对比 | 内心冲突、神秘、戏剧性 | 抉择、秘密揭露 |

### 1.2 人工光方案

#### 三点布光基础

```
         Key Light (主光)
              ↘
               主体 ←—— Fill Light (补光)
              ↗
     Back Light / Rim Light (轮廓光)
```

#### 情绪化布光方案

| 方案 | 布置 | 效果 | 适用 |
|------|------|------|------|
| 伦勃朗光 | 主光45°上方，形成三角光斑 | 经典、戏剧性、深度 | 人物特写、严肃对话 |
| 蝴蝶光 | 正面顶光，鼻下蝴蝶阴影 | 优雅、时尚、女性美 | 优雅出场、妆容展示 |
| 分割光 | 90°侧光，一半脸在暗处 | 冲突、双重人格、悬疑 | 反派、内心挣扎 |
| 低调光 | 主光+弱补光，大面积暗区 | 压抑、危险、黑色电影 | 犯罪、惊悚、秘密 |
| 高调光 | 多方向均匀柔光，少阴影 | 明亮、积极、喜剧 | 喜剧、广告、日常 |

### 1.3 实用光源 (Practical Lighting)

利用场景内已有的光源：
- 台灯、蜡烛 → 暖色局部照明
- 电视/电脑屏幕 → 蓝色冷光映脸
- 霓虹灯 → 彩色光源，城市感
- 车灯/路灯 → 户外夜间戏剧性光源

## 二、色彩设计体系

### 2.1 色彩心理学速查

| 色彩 | 正面联想 | 负面联想 | 典型用途 |
|------|----------|----------|----------|
| 红色 | 热情、爱、力量 | 危险、愤怒、血 | 爱情、战争、警示 |
| 蓝色 | 平静、信任、深邃 | 忧郁、寒冷、疏离 | 回忆、科技、孤独 |
| 绿色 | 自然、生命、希望 | 疾病、嫉妒、毒药 | 成长、乡村、诡异 |
| 黄色 | 快乐、活力、温暖 | 疯狂、背叛、疾病 | 童年、阳光、不安 |
| 橙色 | 温暖、创造力、冒险 | 廉价、焦虑 | 日落、秋天、活力 |
| 紫色 | 高贵、神秘、灵性 | 忧郁、疯狂、死亡 | 幻想、宗教、梦境 |
| 白色 | 纯洁、简洁、新生 | 空虚、临床、死亡 | 婚礼、医院、天堂 |
| 黑色 | 力量、优雅、神秘 | 死亡、邪恶、未知 | 黑色电影、葬礼、高端 |

### 2.2 调色板设计原则

#### 互补色对比
- 红 ↔ 青
- 蓝 ↔ 橙
- 绿 ↔ 品红
- **效果**：强烈视觉冲击，适合高潮场景

#### 类似色和谐
- 红-橙-黄（暖色系）
- 蓝-青-绿（冷色系）
- **效果**：视觉和谐，适合日常叙事

#### 三色搭配
- 红-蓝-黄（经典三色）
- **效果**：活泼且平衡，适合轻喜剧

### 2.3 角色专属色彩

为每个主要角色设定专属色彩，贯穿全片：

```
角色A：暖琥珀色 → 代表温暖、可靠
角色B：冷蓝色 → 代表理性、疏离
角色C：深红色 → 代表危险、欲望
```

当角色色彩产生交汇时，暗示关系变化。

## 四、光影转场技巧

| 转场类型 | 方法 | 效果 |
|----------|------|------|
| 光源转场 | 画面A的光源关闭→画面B的光源亮起 | 自然过渡 |
| 阴影过渡 | 暗部逐渐扩大→完全黑→画面B渐亮 | 戏剧性停顿 |
| 色温变化 | 暖色渐变到冷色（或反之） | 情绪转变 |
| 色彩匹配 | 画面A的某颜色与画面B的某颜色匹配 | 主题关联 |
