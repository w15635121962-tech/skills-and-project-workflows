## 核心观点

> "审美不是少数人的天赋，而是你拒绝平庸的选择。"

- 2026年大多数 AI 图片仍是高饱和度、塑料感
- 用**电影叙事感**做视觉降维打击
- 追求"静谧的、不讨好的姿态"——像雨后窗台，深夜孤灯

---

## 两大关键技法

### 1. 冷暖对比
大面积的**冷色调**（灰蓝、深灰） + 微量的**暖色焦点**（屏幕光、灯光）

> 核心公式：冷为主调，暖为点缀

### 2. 胶片质感
加入微量**颗粒感**（Film Grain），消除 AI 的过度平滑感

## 五模块提示词公式

| 序号 | 模块 | 英文关键词参考 |
|------|------|---------------|
| 1 | **主题** | subject, main figure, silhouette |
| 2 | **环境/动作** | setting, action, background context |
| 3 | **光影/色彩** | lighting, color palette, mood tones |
| 4 | **镜头/媒介** | lens type, film stock, medium |
| 5 | **氛围/审美** | atmosphere, aesthetic style, emotional tone |

**拼装顺序**：
```
[主题] + [环境/动作] + [光影/色彩] + [镜头/媒介] + [氛围/审美]
```

## 提示词实例

### 雨窗剪影（封面示例）

```
镜头捕捉到透过雨滴斑驳的窗户所呈现的画面，夜幕中模糊的城市灯光
作为背景，玻璃上映现出一个人的剪影，色调为忧郁的蓝色与琥珀色，
对比强烈，氛围阴郁而怀旧，采用 35 毫米胶片颗粒感。--宽高比 16:9
```

| 模块 | 拆解 |
|------|------|
| 主题 | 一个人的剪影 |
| 环境/动作 | 透过雨滴斑驳的窗户，夜幕中模糊的城市灯光 |
| 光影/色彩 | 忧郁的蓝色与琥珀色，对比强烈 |
| 镜头/媒介 | 35 毫米胶片颗粒感 |
| 氛围/审美 | 阴郁而怀旧 |
