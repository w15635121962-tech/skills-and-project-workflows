# Format C Vertical Short-Drama Prompt Group

```text
[固定画质词：按用户当前项目的原文保留，不擅自压缩]

GROUP｜[时间/场景]｜[关系或核心动作]｜[镜数]

开场状态：
[承接方式：A方案尾帧继承，或B方案独立开场。]
[角色逐一写：固定位置、朝向、姿态、已发生动作；只列当前组可见的角色/道具。]
空间关系：[屏幕左/右、前/中/后景、共同地面或床面、主轴、关键家具/门窗/道具锚点。]
环境：[时间、天气、前中后景、材质和生活痕迹。]
光影基调：[成熟影视参考的可执行翻译：主光来源/方向/质地/色温、反射面、暗部策略、全组连续规则。]
音频总则：[当前项目的现场声、台词、旁白、字幕、音乐、生理声限制。]
全组负面提示词：[仅放跨镜共有风险。]

【shot 1｜[谁的镜头，画内谁]｜[景别]｜[角度/相机位置]｜[运镜]｜[焦段]｜duration: [x.x]s】
镜头：[焦点、景深、镜头移动起止；过肩时写前景肩膀归属、左右侧、画面占比、轴线和焦点人物。]
画面：[主体在屏幕/深度层的固定位置、朝向、空间锚点、一个动作从起点到结果。]
微表演：[主动作 + 一个微泄露 + 一个克制/反动作；明确视线起点和落点。]
对白反应：[说话者和英文原句，或无对白时说明前文事件如何落在谁身上；明确禁止谁生成口型。]
人物背景融合：[同一地面/床面/座椅、接触阴影、压痕、遮挡、材质和环境色温。]
光影：[本镜如何承接全组主光；人物/道具材质反射，暗部细节，禁止项。]
音频：[只写允许的现场声与台词；台词必须与对白反应完全一致。]
运动强度：[1-3或用户指定。]
负面提示词：[本镜专属生成风险。]

[复制以上 shot 区块，按用户要求的镜数展开。]
```
