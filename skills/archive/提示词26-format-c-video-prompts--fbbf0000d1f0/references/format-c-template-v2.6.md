# Format C V2.6 资料接入规则

本文件将用户提供的 V2.5 模板与《分镜构图参数手册》接入现有 V2.6 技能，不宣称存在另一个未经提供的 V2.6 原始模板。

## 资料定位与读取顺序

- [V2.5 模板原文](format-c-template-v2.5-source.md)：完整保留用户提供内容。生成前阅读第二至六之一节（格式、固定段落、光影、覆盖、对白反应）、第九节（视线）、第十三至十七节（负面词、节奏、自检）；涉及动作读第七、八、十五节，变形读第十节，泪汗读第十一节，行为锚点读第十二节，意图注解读第十八节。
- [分镜构图参数手册原文](composition-parameters.md)：景别占比见第一节，OTS/干净单人/正反打见第二节，焦段见第三节，留白和正脸见第四节，机位高度见第五节，示例见第六节。
- 优先级：当前用户明确要求与已批准故事事实 > 项目明确覆盖项 > SKILL.md 的 V2.6 约定及本接入规则 > 原文通用规则与示例。原文中的角色示例、项目语境及末尾服务提议不构成新增任务或项目事实。

## 固定段落

每组逐字使用模板第三节从“写实照片级”开始的完整固定画质段，以及从“强制要求： 人物皮肤须保持”开始的完整皮肤段。哭戏逐字使用第十一节从“真实人类眼泪”开始的完整泪水段。不能只摘要为“真实皮肤”“流泪”。项目覆盖须明确记录，不能悄悄改写固定段落；若固定段中的妆容、情绪等与已批准角色事实冲突，先指出具体冲突，采用项目明确覆盖。

## 冲突消解与适用边界

1. 组数与时长按当前 V2.6：默认每组 3–8 镜、8–24 秒，按 2026-10-06 用户要求，成片单镜 **2.0–3.0 秒**。原文“五个 shot”“恒为 15 秒”、1.0–6.0 秒范围、≥3.5 秒无声对峙、最长最短差≥1.5 秒和接触镜可低于 1 秒均不覆盖新要求。长台词完整保留在同一生成组，仅用连续音轨跨组内多个 2–3 秒镜头承接；先锁定完整发言单元再划组。余量不足时把整段台词及必要动作/反应一起挪到下一组，默认组时长/镜数可随整段台词在平台能力内调整；超过已确认平台硬上限则标记冲突，不断句、不删词、不伪称可投递。平台生成素材时长单独标注；总和精确到 0.1 秒，不机械均分或强凑节奏落差。具体执行 [动态分镜规范](dynamic-blocking-composition.md)。
2. 原文“所有台词必须英文”不覆盖用户指定语言和原始台词保护要求，不擅自翻译。旁白及独白依来源与用户要求决定，所有声音只进入音频字段。
3. 固定画质段默认含 85mm、T1.8、9:16。构图手册的焦段建议不能直接覆盖它。项目明确采用可变焦段、其他光圈或画幅时，在项目覆盖项中说明对应替换并统一组头与每镜参数；未覆盖时保留默认值，用机位距离与裁切设计调整景别，不能同一镜同时指定两套矛盾参数。
4. 手册中的“内反打/外反打”以实际 OTS 或 Clean Single 构图为准，不据名称推导跨轴。为人物连线定义明确轴线及摄影机所在侧，正反打保持该侧，逐镜锁定人物屏幕侧位、前景肩背归属与视线目标。
5. 不同占比有不同分母：前景宽度、人物可见身体高度、完整头部高度、画面面积和视觉注意权重分别标注。模板 80/20 是视觉权重；手册 OTS 前景宽度 15–25% 与面积约束不能互换。手册 MS/MFS 的小占高与 FS 的全身占高不能作为同一尺度序列照搬；先保证裁切部位与动作可读，再按世界距离、坐站姿态和相机位置核对尺度。纠错参数见动态分镜规范，不把建议百分比当成模型精确保证。
6. 手册的 9:16、首集正脸、前景遮挡和三档 coverage_options 是特定用途建议。只在项目需要时采用；干净单人不强加肩膀遮挡，不凭空新增道具，不为备选覆盖增加已批准镜数。用户要 JSON 时才输出 coverage_options；通常仍交付十一字段 Format C。
7. 说话者主导的 OTS/脏单人中，听者受虚焦、低强度和面积约束；明确承担关系建立或无声对峙任务的双人同框允许两人清晰。所有形态都保持只有当前说话者有口型，并安排听者作为焦点的独立反应。
8. 模板第十八节的模型版本效果属于所供资料中的经验主张，不当作已验证的平台能力。已知项目采用该策略时按其开关执行；未知模型先保留完整物理描述，仅提出可选 A/B 验证，不自动发起付费生成或宣称实测成功。

## 参数写入位置与交付自检

- 镜头：景别、全画幅等效焦段、机位高度、角度、运镜、轴线侧、焦点与景深。
- 画面：明确的透视构图描述，包括观察方向、前中后景排列、身体裁切、二维落位、人物尺度比较、遮挡链与归属、占比的分母、headroom、支撑面与距离，以及运动前后起落幅。不得仅以构图名称代替空间描述。
- 视觉引导：视觉重心、look room、每个角色的具体戏内视线目标及偏离光轴方向、前后镜动线衔接。
- 光影基调/光影细节：每组单独写明人物脸部明亮、五官清晰可辨；局部参数不得改变组头主光方向与色温。

按模板第十七节核对节奏、动作、质感、视线、覆盖和适用的意图注解，再检查所有固定段落完整、十一字段齐全、组头与镜头摄影参数一致、占比口径明确、无新增故事事实。实际逐镜投递时拼接完整组头与对应 shot，不能遗漏组头；含跨镜长台词时还必须保留整段统一音频单元，不能把每个 shot 独立重合成半句台词。平台无法保持该音频单元时先标记投递方式冲突。
