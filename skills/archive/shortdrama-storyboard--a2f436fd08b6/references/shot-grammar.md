# Shot Grammar Reference (镜头语法)

Read this during scene segmentation and shot-sizing (workflow Steps 2–3).

## 1. Shot sizes (景别)

| 代号 | 景别 | 用途 |
|---|---|---|
| ELS | 大远景 | 建立场景、地理关系、气势 |
| LS | 远景/全身 | 人物与环境关系、造型展示 |
| MS | 中景(腰以上) | 对话、动作、信息量主力 |
| MCU | 中近景(胸以上) | 情绪、台词重点 |
| CU | 特写(头肩/面部) | 高光情绪、眼神、反应 |
| ECU | 大特写(眼/手/物) | 细节、道具、微表情、麦高芬 |
| INS | 插入镜 | 道具/符号/信息补充 |

Vertical 9:16 favors **CU/MCU/MS** (tall subjects fill the frame). Use ELS/LS
sparingly and with strong vertical elements (pillars, light beams, standing figures).

## 2. Pacing categories (节奏)

Match average shot length to the scene's dramatic type:

| 类型 | 平均镜长 | 特点 |
|---|---|---|
| 爽点/打脸/反转 | 1.5–3s | 短切、快节奏、卡点收尾 |
| 情感/催泪 | 4–8s | 长镜、慢推、留白 |
| 悬疑/威压 | 3–6s | 静滞、缓移、压迫构图 |
| 动作/战斗 | 1–3s | 快切、手持、冲击 |
| 唯美/魅惑 | 4–8s | 慢镜、环绕、柔光 |

End tension/reveal scenes on a **cliffhanger shot (卡点)** — a held beat or a hard
cut that hooks the next episode.

## 3. Coverage patterns per beat type

- **Entrance/reveal**: LS establish → push-in to MCU on the subject.
- **Dialogue turn**: MCU speaker → CU reaction of the other → back.
- **Emotional peak**: slow push-in to CU, hold, let a single detail (tear, hand,
  sigil glow) carry it in ECU.
- **Power/威压**: low-angle MS/LS, subject centered, environment reacting.
- **Seduction/魅惑**: orbiting MS + ECU of the carrier detail (tail, hair, hand),
  avoid dwelling on the face.
- **Action hit**: LS geometry (who is where) → CU impact → INS aftermath.

## 4. Vertical 9:16 composition

- Keep the key element in the **central vertical safe zone**; particles/light may
  overflow top.
- Prefer **low-angle + rising vertical elements** (light columns, standing stones,
  flared tails) to create depth in a tall frame.
- For two characters, stack **foreground/background** or upper/lower thirds rather
  than side-by-side.
- Faces are least stable in AI — for intimate/seductive beats, route the emotion to
  **body language, hair, hands, silhouette, and effects**, not micro-expression.
- Magic circles laid flat + low angle = natural 9:16 depth and a rising light column.

## 5. Transition types

- **Hard cut** — default for pace.
- **Match cut** — carry a shape/motion across a scene change.
- **Light-wipe / flash** — good to hide a transformation or time jump.
- **Whip pan** — action-to-action energy.
- **Slow dissolve** — memory, flashback (闪回), dream.
- **Cliffhanger freeze** — end-of-episode hook.

## 6. Axis / continuity (轴线)

- Keep the **180° line** consistent within a scene so spatial relations stay readable.
- Track **continuity state** shot to shot: costume damage, wetness, time of day,
  what a character is holding, whether an effect is active. Note it in every card's
  连续性 field.
- On multi-subject fights or casts, resolve **spatial geometry in the image layer**
  (a base keyframe) first, then let the video layer animate a single subject —
  this is the reliability trick for complex blocking.
