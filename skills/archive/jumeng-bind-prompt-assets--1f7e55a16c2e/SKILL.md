# 剧梦提示词素材绑定

## 目标与输入

将既有提示词中的目标引用绑定为剧梦可识别的素材卡，保留原有文字和生成设置。

从当前请求或明确的页面上下文取得：
- 目标项目/剧集/分镜链接或名称，以及处理范围。
- 人物或场景名称到素材库准确文件名的映射，含服装版本。
- 需要绑定的位置。默认沿用演示范围：组头“引用锁”的素材，以及每镜“画面”中各人物的第一次具名出现；不把所有重复名字、台词和其他字段全面替换。

明确映射可直接执行；遇到同名不同服装、缺失素材或分镜范围不明，只询问影响操作的缺项。项目 ID、角色、文件名和镜头数量都是输入，不固定为演示值。

## 操作方式

优先检查是否存在支持原生引用绑定的专用工具；普通文本写入不能替代素材绑定。无合适工具时使用 **Computer Use**，通过 `mcp__cua_repl` 的浏览器控制操作用户指定的浏览器。录制演示使用 Google Chrome 的剧梦页面（域名 `jzzm.duanju.com`）。遵循工具实时返回的文档，不使用猜测的接口。

1. 打开或选中目标剧梦标签，核对项目、剧集及当前分镜。定位主提示词编辑区，避免误操作历史结果的文本框。先读取完整提示词与已有引用状态；长文本只显示部分时滚动检查，不能从截断文本重建全文。
2. 记录待操作位置及当前素材映射、模型、分辨率和时长。通过上下文定位“引用锁”或具体 shot 的“画面”行，而不是只搜索一个可能重复的名字。
3. 检查已有素材卡是否正确。已正确绑定的位置跳过；需要修复时，只选中该位置的旧引用卡并删除，保留相邻的人名、动作、标点与空行。演示中的卡片位于人名之前，不要把人物文字连同卡片一起删掉。
4. 将插入点放在目标文字前，输入 `@`，在原生素材选择器中按准确文件名选择目标。必要时使用选择器提供的搜索功能。不能只输入 `@文件名` 后就认为绑定成功。
5. 每插入一个素材，立刻检查新卡片及其文件名、前后文本和位置。录制中可访问性树把卡片表现为带图片描述及文件名 Value 的容器，其后仍有独立文本。此结构是辅助证据；应同时利用当前页面可见卡片确认。动态元素 ID 每次重读，不保存录制时的 ID 或屏幕坐标。
6. 先处理引用锁，再逐镜处理画面字段。每次编辑后重新定位下一位置，避免富文本更新导致光标或元素引用失效。同一镜后面的重复人名保持原状，除非用户明确要求更多位置。
7. 完成后核对所有目标位置、素材文件名及正文连续性。检查模型、分辨率、时长未被意外修改。通过页面实际提供的保存状态确认持久化；若需要切换后返回验证，先确定不会丢失未保存编辑。无法确认时说明“已在编辑器绑定，持久保存未确认”。

## 验证与恢复

- 每处成功条件：目标素材卡存在、文件名正确、人物/场景归属正确、邻接正文未丢失且无重复卡。
- 人物仅出现在照片、画像或屏幕中时，引用仍绑定该人物素材，并保留“仅用于照片内人物、静止”等原有限定；不能把素材放到后面的“场景”标签下。只有手、袖口等局部出镜时，也按画面中的人物归属绑定，不能因为没有正脸而漏掉。
- 原文明确不引用场景图或道具图时，保留文字描述，不因素材挂载任务补加图片。
- 查看编辑器字数与错误提示。出现“提示词超过了5000字”时，引用绑定和生成可用性分别报告；绑定任务本身不授权压缩正文，不把生成按钮禁用当作绑定失败或继续点击生成。
- 选错素材、文本误删或光标位置不明时，停止下一项，检查当前状态并局部恢复；不能凭字符数变化判断成功，也不能整段覆盖富文本来修复局部引用。
- 素材不存在时报告缺项；不自行上传替代图或选取相似角色。登录失效时交由用户完成登录。
- 本技能的完成条件是引用绑定。生成按钮、消耗点数、批量生成与下载不属于此流程；如用户另行授权生成，按该授权处理，并区分提交、排队和生成完成。
- 交付简短报告：处理的分镜及位置、素材映射、未完成项、保存确认状态。没有运行真实回放时，不声称已验证回放成功。
