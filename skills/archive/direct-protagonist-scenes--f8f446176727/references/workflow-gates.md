# 叙事影视简化流程

当前用户要求优先于旧模板、附件建议和项目历史记录。只执行请求覆盖的阶段。

1. **读来源**：确认原剧情、原台词、人物、已有素材、批准版本和处理范围。关键事实不明时明确缺项，不虚构。
2. **直接写稿**：普通设计稿用 [分组镜头模板](../../short-drama-storyboarding/references/group-shot-template.md) 合并剧情作用、表演、位置、摄影、时间轴、台词和声音；最终视频提示词必须按 [Format C V2.6写作规范](../../write-format-c-video-prompts/SKILL.md) 输出完整组头和shot十一字段。按 [最新对白与表演方法](../../short-drama-storyboarding/references/dialogue-design.md) 区分短、长、混合对白和无台词段；[分镜经验](../../short-drama-storyboarding/references/storyboarding-experience.md)只作补充。不另输出独立导演表或分镜表。模板中的EP31示例只提供写法，不提供其他项目事实或生成授权。
3. **按授权制作**：需要剧梦操作时使用 [平台技能](../../jumeng-episode-producer/SKILL.md)，核对正文、原生资产卡、模型、分辨率、时长及保存，再执行已授权的生成。未要求平台制作的任务止于交付稿件。

交付前内部简查：剧情因果和人物状态正确；原台词逐字、说话者及口型归属正确；台词和动作有足够时间；人物位置、道具与前后组接续一致；无意外字幕、水印或重复人物。只报告会影响结果的未解决项，无需附检查表。

普通设计稿的组长、镜数、景别和切换按内容选择；最终提示词采用当前Format C模板的默认分组、节奏、覆盖与固定画质要求。用户明确的单镜补镜、长台词、时长或机位要求优先，不为模板增加原剧情没有的动作或高潮。无音频的台词时长注明估算；实际平台限制在提交前按当前可用设置核对。

此后新生成重新设计表演和摄影，不继承旧表演方案；原剧情、原台词、身份和必要真实状态仍核实接续。修订冻结未请求改变的事实；翻译或压缩不丢台词、人物、因果和衔接；仅绑定/填入/提交明确批准正文时复用该正文，不扩大修改。

平台正文保存、原生引用保存、生成受理及视频完成分别确认。主要人物缺少自己的指定原生资产卡时不生成；提交不明先查记录，避免重复扣费。未实际回放不宣称表演或口型通过。

默认结果留在平台；只提交的任务结束在确认受理，要求完成的任务确认实际返回状态。不自动下载、导出、转码或媒体打包。技能维护不触发旧视频重做或外部资料发送。
