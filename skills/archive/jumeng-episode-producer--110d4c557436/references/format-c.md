# 剧梦最终提示词格式

读取 [统一提示词写作规范](../../write-format-c-video-prompts/SKILL.md) 与 [强制模板](../../write-format-c-video-prompts/references/format-c-template-v2.6.md)。新写最终提示词必须包含完整组头、shot标题和按固定顺序排列的十一字段，不以普通分组动作时间轴代替。不额外制作独立分镜表；仅绑定/提交已有明确批准正文时保留其结构与内容。

准确角色、当场服装、场景、道具和音色素材列在组头引用锁，原生人物卡也放在对应shot“画面”首次具名处。卡片绑定只改对应引用位置，保留邻接文字。

所有原台词、VO/OS、环境和动作声只进入“音频（Audio）”；其余字段写画面与可见反应。无台词镜的“对白反应”仍写完整触发、承受者、沉默者、具体行为及终态。画内无台词字幕/翻译字幕/水印；剧本需要的屏幕或道具文字按真实承载面处理。

当前用户语言、原台词、声音要求及生成授权优先。维护规范不会自动改变或重生成已完成视频。
