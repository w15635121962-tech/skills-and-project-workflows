# Format C V2.6 强制输出模板

这是2026-10-13用户最新指定的最终视频提示词格式。组头与shot十一字段必须完整照此输出，取代此前将提示词路由到EP31动作时间轴的规则。普通分镜设计稿可以继续使用其设计模板；不得拿普通设计稿替代本格式的最终提示词。

来源：[粘贴全文](sources/用户粘贴_FormatC_V2.5_20261013.txt)（原题V2.5）、[技能包原始规范](sources/提示词26_技能包原始SKILL_20261013.md)（V2.6）。镜数/时长默认值按全文第2.0节及包内V2.6合同，“本组五个shot”等旧措辞不恢复固定五镜。当前用户具体镜数、完整台词时长和单镜补镜要求优先。单纯要求简洁不授权省略固定段和十一字段。

## 完整组稿格式

下方方括号说明在出稿时替换为本组事实，不原样输出。组号可写入组头；固定画质与皮肤两段逐字保留，每组只写一次，每镜不重复。组头之后按实际镜数重复shot块，组内编号从1开始。

```text
【组头｜EPXX-GXX｜固定画质词与光影基调】
固定画质词（Fixed Quality Descriptor）：写实照片级、超写实质感、真人实拍电影剧照，采用 ARRI Alexa 65 摄影机拍摄，85mm 定焦镜头（Prime Lens），光圈 T1.8，竖版 9:16 画幅（Aspect Ratio），180 度快门角（180-Degree Shutter Angle），浅景深（Shallow Depth of Field），柔和奶油般散景（Bokeh），细腻胶片颗粒质感（Film Grain）。真实皮肤纹理，哑光质感（Matte, Non-Glossy），清晰可见毛孔与细微皮肤纹理起伏，真实次表面散射（Subsurface Scattering / SSS）光影效果，肤色只呈现真实皮肤下轻微血色，不形成发光红脸；皮肤高光仅允许在鼻梁、颧骨等自然出油区域出现极细微、局部的自然反光，不得形成大面积油亮色块或蜡质反光层；皮肤色调在面部各区域必须均匀一致，不得因参考图融合产生局部色差、色块拼接感或纹理断层。真人质感眼眸只保留真实环境反射，禁止眼球自发光（No Self-Illuminating Eyes）。真实布料垂坠动态褶皱，真实接触投影（Contact Shadow），光束中漂浮细微尘埃丁达尔效果（Tyndall Effect）。

强制要求： 人物皮肤须保持细腻、紧致、哑光通透的真实质感，毛孔与皮肤纹理清晰可辨但不夸张、不放大为颗粒感；皮肤表面禁止出现以下任一状态——粗糙颗粒感、明显油光、不健康的浮油质感、过度磨皮导致的塑料感/蜡感、皮肤纹理消失导致的假面感、局部色调不均或色块拼接感、五官边缘与皮肤融合产生的模糊塌陷。若本组镜头基于多张参考图（垫图）生成，须额外保证：不同参考图来源的皮肤质感、色温、纹理清晰度在最终画面中完全统一，不得保留原图各自的皮肤处理痕迹或产生融合接缝。这一整段与固定画质词同等优先级，必须逐字出现在每一组的组头中，不允许省略、简写或用"皮肤真实"等笼统表述替代。

光影基调（Lighting Tone）：[具体主光源、方向和高度、软硬、色温、面部亮暗面、曝光、阴影落点、材质反射及连续性。]人物脸部明亮、五官清晰可辨。
节奏结构（Beat Structure）：组型：[组型]｜[镜数]镜｜共[x.x]s；[逐镜时长、铺垫/递进/最强拍/余韵和组尾落点；未实测时注明估算]
景别循环（Shot Size Cycle）：[按实际镜数写每镜景别及机位角度序列]
视觉动线（Visual Flow）：[整组阅读方向、重心迁移和主运动方向]

【shot n｜镜头主体｜景别（Shot Size）｜视角（Angle）｜运镜（Camera Movement）｜焦段（Focal Length）｜duration: x.xs】
叙事任务（Narrative Task）：[一句话写本镜唯一信息]
镜头：[机位、焦段、起幅、启动动机、运镜路线、落幅与停止点]
画面：[人物身份与服装、真实位置、前后层次、坐站支撑、动作阶段、接触、道具归属及稳定终态]
视觉引导（Visual Flow）：[视觉重心与迁移、画面减法、每人的戏内视线目标与方向，瞳孔不锁定镜头]
微表演（Micro-Performance）：[触发后的具体脸部/眼神/身体变化及表演分寸]
对白反应（Dialogue Reaction）：[触发、承受者、沉默者、具体可见反馈与终态；无台词也完整填写]
人物背景融合（Subject-Background Integration）：[比例透视、支撑面、接触阴影、衣料、遮挡与材质融合]
光影细节（Lighting Detail）：[仅写相对本组基础灯光新增或变化的阴影、反光、转身亮暗面等]
音频（Audio）：[所有原台词/VO/OS逐字文本、归属、入点与结束；所有环境/动作音效；无台词写明无台词无口型，是否配乐依当前要求]
运动强度（Motion Intensity）：[人物/道具与摄影机各自的速度、幅度、先后及收势]
负面提示词（Negative Prompt）：[本镜具体的身份、空间、皮肤、视线、口型、文字、水印、动作与材质失败态]
```

必要的素材原生卡、参考权限、模型版本与注解开关，可在组头五项之后写“引用锁/项目参数”；不能代替组头五项或另建声音字段。准确人物素材在对应shot“画面”首次具名处保留引用位置。投递单镜时带上完整组头。

## 固定段与专项规则

- 上方固定画质词及皮肤强制段来自用户全文第三节，字符不作压缩、同义替换或省略；项目有明确摄影/画幅覆盖时在项目参数单独写覆盖项，不暗改默认原文。
- 凡流泪，在对应shot的“画面”或“微表演”完整加入下段，不用“流泪”二字替代：

真实人类眼泪从内眼角缓慢溢出，半透明生理盐水质感，表面有细腻的环境光反射，顺着脸颊自然滑落，受重力影响形成不规则曲线，在颧骨处汇聚后滴落，打湿皮肤形成湿润反光，晕开少量睫毛膏，留下淡淡泪痕，睫毛上挂着细小泪珠。面部肌肉自然紧绷，嘴唇微微颤抖，整体情绪克制。

- 第2.0节：每组一个光影/空间连续单元，默认3–8镜、8–24秒、单镜1.0–6.0秒；时间加总精确至0.1秒。当前明确的单镜补镜和长台词覆盖采用真实所需时间，不为了数字拆断一句或补出动作。
- 第5–6节：覆盖受控，只有当前说话者动嘴。对白、VO/OS及任何声音仅写“音频”；“对白反应”写语义触发与可见结果，不重复原句。
- 对话覆盖的内部取舍：单主体说话镜中的听者遵守虚焦、低强度及面积受控规则；全文已定义的双人关系/无声对峙镜可按真实关系让两人清楚可见。此特例不放宽非说话者闭口、真实视线和180°轴线。
- 旧数字取舍：全文残留的固定五镜/恒为15秒由第2.0节的浮动分组覆盖；默认冲击镜最低采用V2.6的1.0秒，不把旧章节的低于1秒示例当新版默认。更具体的当前用户指示仍优先。
- 第6之一节：无台词反应也写实际触发、承受者、沉默者、脸部/眼神/身体或道具变化与稳定终态；不强迫每镜新增手势。
- 第9节：每人有真实戏内视线落点；正面机位仍看镜头旁的明确目标，不能盯镜头或凭两张单人图猜相邻座次。当前明确的POV/镜头直视例外逐镜标清归属。
- 第14–16节：默认执行非均匀节奏、景别/角度变化、有效动作拆解及组尾落点；用户当前机位、镜数和长短对白要求优先。变化不等于越轴、换座或重演已完成动作。
- 第18节：意图注解加在完整物理描述后，不替代动作；每字段≤1条，每shot≤3条，每条≤20字。音频、光影、固定段、负面词禁用；未知模型试验须另有授权。
