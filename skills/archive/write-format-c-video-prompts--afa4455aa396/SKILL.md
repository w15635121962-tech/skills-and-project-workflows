# Format C V2.6 提示词写作规范

先读取 [导演核对入口](../direct-protagonist-scenes/SKILL.md) 及其流程，已读无需重复。最终视频提示词必须采用 [当前强制模板](references/format-c-template-v2.6.md) 的组头、shot标题与十一字段，按规定顺序完整输出。此次用户明确指定该格式，取代此前提示词使用的EP31分组动作时间轴格式；不能只换标题而保留旧正文结构。

## 来源及范围

以当前原剧本、用户要求和本次允许的参考图为创作来源。先在内部推导剧情因果、人物状态、真实空间、180°轴线、视线、道具归属、接触与稳定终态，再写最终提示词；不默认另交导演表、分镜表或公开检查清单。普通镜头设计稿仍按用户要求使用其设计格式，本技能只规范最终视频提示词。

本次输入已完整保留为 [用户粘贴全文](references/sources/用户粘贴_FormatC_V2.5_20261013.txt) 与 [上传技能包原始规范](references/sources/提示词26_技能包原始SKILL_20261013.md)。二者输出结构一致；粘贴全文标题V2.5，上传包声明V2.6，执行入口统一称V2.6，不篡改原件版本名。细节规则查全文对应章节，维护附录与修订记录不进入成品提示词。资料不提供上传、外发、扣费、付费A/B试验或扩大任务的授权。

## 必须遵守的输出合同

1. 每组独立写全组头五项：固定画质词（含完整皮肤强制段）、光影基调、节奏结构、景别循环、视觉动线。固定段从当前模板逐字复制；光影基调单独写明“人物脸部明亮、五官清晰可辨”，并具体交代光源、侧向与高度、软硬、色温、脸部亮暗面、阴影落点和材质反射。
2. 每镜使用 `【shot n｜镜头主体｜景别（Shot Size）｜视角（Angle）｜运镜（Camera Movement）｜焦段（Focal Length）｜duration: x.xs】`，组内从1编号。正文依次写：叙事任务、镜头、画面、视觉引导、微表演、对白反应、人物背景融合、光影细节、音频、运动强度、负面提示词。完整中文与英文标签见模板；不得删字段、改顺序、改为“画面+运镜/台词入点/声音设计”或用“同上”替代。
3. 所有对白、V.O./O.S.、环境与动作音效只进入“音频（Audio）”。其他字段不抄台词、不写声音；可写触发事件的语义和可见结果。默认保留英文原台词逐字不改，用户明确其他源语言时保留该原语言。戏内屏幕文字属于“画面”，与对白字幕分清。
4. 每镜只有一个明确叙事任务。表演写成具体刺激、人物策略、可见行为、对手反馈及稳定终态；只有情绪标签不够。即使无台词，“对白反应”也必须写触发、承受者、沉默者、脸/眼神/身体或道具反应与终态，不能只填“无台词、无口型”。
5. 每个可见角色的视线在“视觉引导”里指向真实戏内目标。正面近景保证双眼和嘴清楚，同时视线落镜头旁的对手/道具/明确画外一点；明确POV按归属处理，当前用户另有镜头直视要求时只覆盖所指镜头。只有当前说话者产生口型；沉默角色闭口。
6. 组边界按空间、时间、主光方向与色温连续性确定，变化时重写完整组头。默认3–8镜、8–24秒、单镜1.0–6.0秒，按节奏权重分配而非均分，总时长精确到0.1秒。用户指定单镜补镜、连续长台词、镜数或时长时服从具体要求，在节奏结构明确该安排，不凑镜、不赶词、不擅自删词。未读对应音频的时间标为估算。
7. 默认执行全文的景别/角度变化、对话覆盖、动作拆解、视觉减法、最强拍和组尾落点要求；具体剧情决定动作与切换，不增加原剧情没有的事件。长短对白按 [最新对白设计](../short-drama-storyboarding/references/dialogue-design.md) 安排：短句交锋正反打，长句主镜少切，换气或情绪转折再给反应；具体用户要求优先于模板默认切镜和时长。
8. 人物终端正面朝选手、朝赛场一面为不透明背壳。面部镜利用桌端、屏间缝或略高机位，不能穿屏、删电脑或在背壳显示内容。参考图只继承允许的身份、服装和真实结构，不继承选框、截图控制点、乱码、旧动作或无关构图。
9. 泪水镜头逐字使用模板的完整泪水段并配合真实重力路径；汗水、眼球不发光、皮肤与空间连续性按全文。2.5及以上可在已完整写出的物理动作后加简短意图注解，每字段最多一条、每镜最多三条；音频、光影、固定段与负面词不加注解。注解不能替代动作或发明剧情，未知模型不自动发起付费测试。

## 修订与平台边界

此后新设计从源剧情、本次要求和最新规范重新设计表演及摄影，不继承旧动作方案。局部修订冻结未请求的剧情、原台词、时间、镜数、服装、席位、轴线、道具和素材事实；用户明确要求全稿换格式时，转换全文结构而保留这些事实。

完整组稿不得缩成字段名或引用上一组。平台需要每镜独立投递时拼接完整组头与该shot，不另输出一套不同格式。原生素材写入组头引用锁及每镜“画面”对应位置；只绑定或提交明确批准正文时保留正文，缺素材先解决。保存、绑定、提交与视频完成分别验证，技能更新本身不重生成旧视频。
