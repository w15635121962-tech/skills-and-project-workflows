# 叙事影视全流程必经关卡

## 范围与优先级

适用于短剧、电影和叙事 AI 视频的导演设计、分镜、视频提示词、修订续作，以及这些内容的平台填入、素材绑定和生成。与影视无关的代码、翻译、文档处理等任务不触发；纯文件转换也不借机重做导演设计。

用户当前明确要求优先；继承已批准的剧本、台词、人物、镜数、时长、画幅、轴线、走位、光影与格式。强制的是当前范围内的检查，不是擅自重写或追加外部操作。导演规则不能凌驾于原剧情事实，也不能把受限或受害主角改成主动反击者。

## 执行顺序

1. **源材料关卡**：识别当前阶段、场次/镜号与已批准版本；区分事实、推断、创作补充和未知。缺少会改变剧情或执行对象的关键资料时，停止受影响部分并明确缺项；其他独立工作继续。不得虚构缺失剧情。
2. **导演关卡**：新写或改动叙事/镜头时，按主技能建立主角目标与处境、冲突节拍、刺激—反应—行动、对手反馈、空间调度、视线/轴线、风格锚点、景别/焦段/运镜动机与稳定终态。读取类型风格执行指南及 [连续走位与构图核对](blocking-continuity.md)；先建立整场调度和逐镜接续记录，检查演员行动的剧情动机、上一镜切点到下一镜起态、前后景比例与透视；每镜能追溯到主角的处境、信息、选择或后果，非主角镜也需有作用。原作的被动、沉默或失败不因“主角驱动”被改写。
3. **分镜交接关卡**：使用 `short-drama-storyboarding` 的空间和逐镜契约补齐可执行信息。沿用镜号/组号，以其连接剧情节拍、表演、走位、声音、时长与下一镜；不要求另造重复文件。
4. **提示词交接关卡**：要求 Format C 时使用 `write-format-c-video-prompts` 的权威 V2.6 模板。把导演决定落实到已有字段；保留完整质量块、原台词、声音归属、眼神目标与连续性。不用本技能的输出模板替换 Format C，也不附加用户未要求的导演表或审计附录。
5. **平台关卡**：使用 `jumeng-episode-producer`。核对当前镜号、提示词版本、对应角色/场景/道具、时长和生成设置；原生素材引用与正文分别回读验证。生成前确认对应正文和引用已保存、当前授权覆盖生成；提交状态不明先查记录，不重复提交。完成保存不能冒充生成完成。

只执行请求所需阶段，但不能绕过该阶段所依赖的检查。后续技能无需再次反向加载本技能造成递归；本次请求已读且未变化的规则可复用。

## 修订、继承与恢复

- **完整新写**：完成源材料和导演关卡，再进入请求包含的下游阶段。
- **局部修改/续写**：锁住批准字段，只对受影响镜头及前后衔接重新检查；新续写部分完成导演关卡，已有部分继承。
- **压缩/翻译**：以原稿为契约，检查叙事作用、表演、空间、声音、台词和字段没有丢失；不另设风格，不重排剧情。
- **仅填入/绑定/生成**：必须读取主技能并做继承核对；可从完整批准稿恢复导演依据，无需重写。检查镜号、人物、动作、空间、台词和素材与批准稿一致。仅缺导演表但正文已明确所需信息时可继续；出现实质矛盾、错误素材或关键未知时，不提交受影响镜头，报告具体阻碍，不能暗改批准稿。
- **已有版本发生变化**：以镜号标识受影响范围，旧检查结果不能套到新版本；重新检查变化及交接处。

## 放行依据

在内部工作记录中为本次阶段记下：源版本或原文定位、镜号范围、已继承项、已检查项、未解决项、下一步。证据指向实际剧本、镜头正文或平台回读，不能只写“已通过”。无须新建文件，除非项目交接需要或用户要求。

剧情/人物矛盾、台词篡改、不可执行调度、轴线/道具断裂、错误资产和未确认提交结果，必须在受影响阶段解决或明确为阻碍。未知的低风险技术参数可以标为建议；不得伪装成实测。不能用质量检查授权上传、扣费或扩大修改范围。

## 强制机制边界

全局 AGENTS.md 和相关技能入口共同要求执行本关卡。这是代理的强制工作指令，不是操作系统、平台或工具的权限拦截器；不能声称能在程序层面阻止一切跳过行为。用户后续明确变更要求时服从新要求。
