# AIGC 画面描述五维统摄框架 · Visual Frame Protocol

> **Version 1.0.0** · 2026-06
> **一句话**：你给我场景/文本/情绪，我按五维标准输出可直接用于 AIGC 生成的画面描述。

---

## 定位 — 与其他技能的边界

| 技能 | 做什么 | 不做什么 | 引用本技能 |
|------|--------|---------|----------|
| `scene-asset` | 场景资产包（空间+灯光+调色卡+连续性） | 不做单镜画面描述 | 定场帧描述使用本五维框架 |
| `performance-description` | 角色表演+画面描述+主题总结 | 不做色彩锁定、不做灯光体系卡 | 画面描述部分遵循本五维框架 |
| `storyboard` / `storyboard-table` | 分镜表（镜头语法+运镜+时长） | 不做画面描述正文 | 画面描述列使用本五维框架 |
| `video-prompt` | AI 视频提示词生成 | 不做画面描述正文 | 提示词中的画面描述段使用本五维框架 |
| `movie-story` / `9-16-movie-story` | 全管线 | — | 所有画面描述模块遵循本五维框架 |
| **`visual-frame`** | **画面描述五维统摄框架：环境·光·色·人+质感** | **不做分镜、不做角色资产、不做场景卡、不做提示词** | **被以上所有技能引用** |

**一句话**：本技能是画面描述的「语法标准」，其他技能是「应用场景」。

---

## 五维框架总览

```
┌─────────────────────────────────────────────────────────────┐
│                    VISUAL FRAME PROTOCOL                     │
├──────────────┬──────────────────────────────────────────────┤
│  ① 环境 ENV  │ 真实地点 + 前/中/背景 + 关键物件 + 材质磨损    │
│  ② 光  LGT   │ 主光来源 + 辅光 + 反射/屏幕光 + 暗部细节 + 禁止项│
│  ③ 色  CLR   │ COLOR_LOCK + 主色 + 暗部策略 + 高光策略 + POP + 禁止色│
│  ④ 人  CHR   │ 角色身份 + 动作阶段 + 微表情 + 服装锚点 + 接触阴影 │
│  ⑤ 质  TEX   │ 照片级真实 + 非卡通/非动漫 + lived-in + 磨损包浆  │
└──────────────┴──────────────────────────────────────────────┘
```

**使用方式**：
- **直接模式**：用户给场景 → 按五维输出完整画面描述
- **引用模式**：其他技能在画面描述段落中引用本框架，确保一致
- **检查模式**：作为清单检查已有画面描述是否完整

## ① 环境 ENV · Environment

> **核心任务**：建立不可置疑的真实空间感。观众看到画面第一眼就知道「这是哪里」。

### 1.1 真实地点锚定

| 子项 | 书写规则 | 示例 |
|------|---------|------|
| **地点类型** | 精确到空间类型，禁止模糊 | ✅ "深夜便利店冷藏柜前" · ❌ "室内" |
| **时代感** | 标注年代/新旧程度 | ✅ "90年代港式茶餐厅，卡座皮面已开裂" |
| **规模感** | 用参照物建立空间尺度 | ✅ "天花板高3.5米，男主头顶距吊灯还有一臂" |
| **封闭度** | 开放/半开放/封闭/压迫 | ✅ "电梯轿厢，三面镜面，空间仅容两人并肩" |

### 1.2 前/中/背景分层（强制）

```markdown
【前景】___（距镜头最近的可辨识内容，占画面10-25%）
【中景】___（主体活动区域，占画面40-60%）
【背景】___（最远可辨识内容，占画面20-35%）
```

**规则**：
- 每个画面描述必须有此三层，不得省略任何一层
- 前景必须有具体物件（不只是模糊虚化）
- 背景必须有环境延伸（不只是色块）
- 9:16 竖屏：使用上/中/下纵向分层
- 16:9 横屏：使用左/中/右或前/中/后横向分层

**9:16 竖屏分层示例**：
```
上1/3：裸露的混凝土天花板，一根生锈的消防管道斜穿画面
中1/3：女主站在便利店冷白灯管下，手持半瓶矿泉水
下1/3：金属货架边缘入画，底层商品标签磨损模糊
```

### 1.3 关键物件（叙事锚点）

| 类型 | 功能 | 书写要求 |
|------|------|---------|
| **叙事物件** | 推动情节或承载情感 | 必须写出材质、状态、光线打在上面的效果 |
| **环境物件** | 建立空间真实感 | 写出使用痕迹、摆放自然度、灰尘状态 |
| **隐喻物件** | 潜台词视觉化 | 写出与人物的视线/动作关系 |

**关键物件清单格式**：
```markdown
关键物件:
- [物件名] | 位置: ___ | 材质: ___ | 状态: ___ | 光线交互: ___ | 叙事功能: ___
```

### 1.4 材质磨损（时间痕迹）

**必须检查项**：
- [ ] 风化/磨损表面（墙皮脱落、金属生锈、木材裂纹）
- [ ] 灰尘/污渍（均匀分布，非卡通式）
- [ ] 使用痕迹（把手包浆、按钮磨损、桌面划痕）
- [ ] 自然老化（非新造感，lived-in）
- [ ] 不完美/不对称（真实世界的混乱感）

**禁止项**：
- ❌ 全新感、完美对称、塑料质感（除非剧情需要）
- ❌ 干净得像样板间
- ❌ 所有材质均匀一致（真实世界有差异）

## ② 光 LGT · Lighting

> **核心任务**：定义光源逻辑，让每一束光都有来源、有方向、有温度、有质感。暗部必须有细节，不是死黑。

### 2.1 主光来源（Key Light）

| 子项 | 必填 | 示例 |
|------|------|------|
| **来源** | ✅ 必须 | "右上方45°窗口" · "头顶LED灯管" · "手机屏幕" |
| **方向** | ✅ 必须 | "侧逆光" · "顶光偏右" · "正面偏下15°" |
| **色温** | ✅ 必须 | "3200K钨丝暖光" · "6500K冷白月光" · "2700K烛光" |
| **光质** | ✅ 必须 | "硬光（清晰阴影边缘）" · "柔光（漫射，边缘模糊）" |
| **覆盖区域** | ✅ 必须 | "照亮中景女主上半身" · "仅覆盖桌面区域" |
| **强度** | ⚠️ 建议 | "主光占画面亮度60%" · "高光轻微过曝0.5档" |

### 2.2 辅助环境光（Fill + Ambient）

```markdown
补光 (Fill): 来源___ · 方向___ · 强度比___% of Key · 效果___
环境光 (Ambient): 场景内实用光源列表___ · 自然光残余___
```

**辅助光类型清单**：
- 反射光："冷白墙面反射漫射到女主左脸"
- 屏幕光："手机屏幕在男主下巴投出蓝色反光"
- 环境光："远处霓虹灯牌在玻璃上的微弱倒影"
- 天光："阴天散射光从左侧大窗均匀进入"

### 2.3 反射/屏幕光（Practical Light）

| 来源 | 色彩影响 | 动态特征 | 书写示例 |
|------|---------|---------|---------|
| 手机屏幕 | 冷蓝/白 | 随画面内容变化 | "手机屏在女主脸上投出冷蓝方框光，随滑动微闪" |
| 电视/显示器 | 环境色 | 画面内容色温 | "电视新闻画面在暗室墙上投出不稳定暖色光斑" |
| 霓虹灯牌 | 高饱和 | 闪烁/稳定 | "红色霓虹在雨夜玻璃上拉成横向光条" |
| 水面/镜面 | 反射主光 | 波纹动态 | "水面将顶光打碎成金色碎片，在女主侧脸跳动" |

### 2.4 暗部细节（强制）

> **禁止死黑。暗部必须有信息，哪怕只是层次。**

```markdown
暗部区域: ___
暗部信息: ___（可见内容，哪怕只是轮廓/材质/微弱反光）
暗部色温: ___（通常比亮部偏冷或偏暖，形成色温对比）
暗部到亮部的过渡: ___（硬切/渐变/柔和）
```

**暗部策略**：
- 保留轮廓："暗部中男主背影轮廓仍清晰，仅面部沉入阴影"
- 保留材质："暗部墙面粗糙质感可见，靠微弱环境反射辨识"
- 保留层次："暗部不是一潭死水，有浅暗→深暗的2-3个层次"
- 色温区分："亮部3200K暖，暗部偏5500K冷，形成冷暖角力"

### 2.5 禁止项（光）

- ❌ 无源之光（光没有明确来源）
- ❌ 均匀照明（像摄影棚平光，无阴影层次）
- ❌ 死黑暗部（暗部完全没有可见信息）
- ❌ 光色温混乱（同一画面色温漂移无逻辑）
- ❌ 过曝失控（高光全部死白，无纹理）
- ❌ 影子方向矛盾（多个光源产生的影子方向不一致）

## ③ 色 CLR · Color

> **核心任务**：COLOR_LOCK 保证项目级一致性，单画面内色彩有策略（主色定情绪、暗部/高光有方向、POP色抓眼球）。

### 3.1 COLOR_LOCK（项目级色彩锁定）

```markdown
COLOR_LOCK:
- 主色: ___（占画面60%+，决定情绪基调）
- 辅色: ___（占画面30%，丰富层次）
- 点缀色/POP: ___（占画面5-10%，视觉焦点）
- 暗部策略: ___（暗部偏向什么色温/色相）
- 高光策略: ___（高光偏向什么色温/色相）
- 饱和度: ___（高/中/低/去饱和）
- 对比度: ___（高/中/低）
- 参考影片/风格: ___（如：Kodak Vision3 / 银翼杀手 / 布达佩斯大饭店）
```

**色彩锁定后，所有单画面必须引用此锁定，不得漂移。**

### 3.2 主色（Dominant）

| 功能 | 选择依据 | 常见映射 |
|------|---------|---------|
| 情绪基调 | 剧情需要 | 暖色=亲密/怀旧/紧张 · 冷色=疏离/科幻/死亡 |
| 空间类型 | 场景设定 | 医院=青白 · 酒吧=琥珀/暗红 · 办公室=灰蓝 |
| 时代感 | 年代设定 | 80年代=高饱和 · 当代=低饱和 · 未来=冷白+霓虹 |

### 3.3 暗部策略（Shadow Strategy）

```markdown
暗部色相: ___（暗部不是纯黑，而是偏___色）
暗部饱和度: ___（暗部饱和度高 = 油画感/风格化；低 = 纪实/冷峻）
暗部与主色关系: ___（暗部是主色的加深变体，还是对比色？）
```

**策略选择**：
- **青蓝暗部**：好莱坞标准（Teal & Orange），暗部偏青，皮肤高光偏暖
- **暖褐暗部**：怀旧/胶片感，暗部偏暖褐，整体统一
- **冷灰暗部**：现代/冷峻，暗部偏冷灰，去饱和
- **高饱和暗部**：风格化/动漫感/超现实，暗部保留色相

### 3.4 高光策略（Highlight Strategy）

```markdown
高光色相: ___（高光偏向___色）
高光饱和度: ___（高光饱和度高 = 梦幻/温暖；低 = 冷峻/真实）
高光与主色关系: ___（高光是否跳出主色体系？）
过曝控制: ___（高光保留纹理/轻微过曝/完全过曝）
```

### 3.5 POP 色（视觉焦点色）

| POP 色类型 | 使用场景 | 面积占比 | 示例 |
|-----------|---------|---------|------|
| **红色** | 危险/爱情/重点 | 1-3% | "女主嘴唇上的暗红唇膏" |
| **黄色** | 警示/温暖/希望 | 2-5% | "远处一盏暖黄路灯" |
| **绿色** | 生命/异常/毒 | 1-3% | "桌上半杯青柠水" |
| **蓝色** | 科技/冷感/忧郁 | 2-5% | "男主手机屏幕的冷蓝反光" |
| **橙色** | 温暖/火焰/怀旧 | 2-5% | "壁炉火焰在暗部跳动的橙色" |

**规则**：POP 色必须小面积出现，面积超过10%就不再是POP色，而是辅色。

### 3.6 禁止色

- ❌ 色温不一致（同一画面不同区域色温漂移无逻辑）
- ❌ 饱和度爆炸（画面整体过饱和，像廉价广告）
- ❌ 荧光色滥用（除非剧情设定为霓虹/赛博朋克）
- ❌ 肤色偏移（肤色不得偏绿/偏紫/偏蓝，除非特定风格化）
- ❌ 色彩无层次（画面只有1-2个色块，无过渡）

## ④ 人 CHR · Character

> **核心任务**：角色在画面中必须是「活的」——有身份、有动作、有表情、有服装细节、有与环境的真实接触。

### 4.1 角色身份锚定

```markdown
角色身份:
- 姓名/称呼: ___
- 年龄/体型: ___
- 面部特征锚点: ___（眼睛___ · 下颌___ · 皮肤___ · 静态表情___）
- 发型/状态: ___
- 视觉辨识点: ___（观众一眼认出此角色的关键特征）
```

**规则**：
- 每次角色出现必须重新锚定身份，至少写出2个面部特征
- 9:16 竖屏特写：面部特征必须详细，这是竖屏主要内容
- 16:9 横屏中景：体态+服装优先，面部为辅

### 4.2 动作阶段（Motion Phase）

> 禁止「静止站立」。人物必须处于动作的中间阶段，哪怕只是「正在呼吸」。

```markdown
动作阶段:
- 整体动作: ___（角色正在做什么？）
- 动作阶段: ___（启动/进行/收尾/暂停？）
- 身体重心: ___（前倾/后仰/居中/下沉？）
- 接触点: ___（手触___ · 脚触___ · 背靠___ · 臀坐___）
- 与环境互动: ___（是否带起灰尘？是否压皱布料？是否留下痕迹？）
```

**动作阶段示例**：
- ✅ "女主正弯腰从地面拾起信件，身体前倾40°，重心在右脚，左手扶住桌沿"
- ❌ "女主站在房间里"（无动作阶段）

### 4.3 微表情（Micro-expression）

```markdown
微表情:
- 眼睛: ___（视向___ · 瞳孔___ · 眨眼___ · 眼睑___ · 泪膜___）
- 嘴唇: ___（嘴角___ · 开合度___ · 抿/咬/颤___）
- 下颌: ___（咬合___ · 紧绷/放松___）
- 呼吸: ___（节奏___ · 深浅___ · 胸腔起伏___）
- 面部整体: ___（肌肉收紧/放松 · 潮红/苍白 · 油光/干燥）
```

**规则**：
- 景别 CU/ECU/MCU 必须覆盖至少3项面部细节
- 禁止抽象情绪词（"悲伤""愤怒"），必须替换为具体肌肉动作
- 微表情与动作阶段融合：不能脱离动作写表情

### 4.4 服装锚点（Costume Anchor）

```markdown
服装锚点:
- 上衣: ___ · 材质___ · 颜色___ · 状态___（新/旧/磨损/污渍）
- 下装: ___ · 材质___ · 颜色___ · 状态___
- 关键配饰: ___（戒指/手表/项链/眼镜等，必须写出位置）
- 服装与环境接触: ___（衣角是否被风吹起？坐姿是否压皱？）
- 服装与光线交互: ___（半透明材质透光？粗糙材质吸光？）
```

### 4.5 与环境接触阴影（Contact Shadow）

> **强制项：人物必须与环境产生真实接触阴影。**

```markdown
接触阴影:
- 脚/底部: ___（地面阴影形状、虚实、方向）
- 手/接触物: ___（手触碰桌面时的压痕阴影）
- 身体/墙面: ___（身体靠墙时的轮廓阴影）
- 服装/自身: ___（衣领在颈部的阴影、袖口在手臂的阴影）
- 阴影与光源关系: ___（阴影方向是否与主光一致？）
```

**禁止项**：
- ❌ 人物像P上去的（无接触阴影、无环境交互）
- ❌ 阴影方向与光源矛盾
- ❌ 阴影过于锐利（柔光应有柔影）或过于模糊（硬光应有硬影）
- ❌ 人物悬空（没有脚踏实地的重量感）

## ⑤ 质 TEX · Texture & Realism

> **核心任务**：强制照片级真实感，排除一切卡通/动漫/插画风格。画面必须像「真实拍摄的」。

### 5.1 质感标准（强制）

```markdown
质感标准:
- 整体风格: 照片级真实 · 超写实 · 真人实拍质感
- 禁止风格: 非卡通 / 非动漫 / 非插画 / 非3D渲染感 / 非塑料感
- 生活痕迹: lived-in atmosphere · weathered surfaces · natural patina
- 光学真实: 景深自然 · 镜头畸变轻微 · 边缘色散合理 · 胶片颗粒可选
- 不完美: 不对称构图 · 轻微手抖痕迹 · 自然灰尘 · 意外反光
```

### 5.2 材质描写词典（快速参考）

| 材质 | 光线交互 | 磨损特征 | 书写示例 |
|------|---------|---------|---------|
| **金属** | 高反光，反射环境 | 氧化、锈迹、指纹 | "黄铜把手上有半圈氧化发黑，边缘磨出银白色" |
| **木材** | 吸收光，纹理显影 | 裂纹、包浆、划痕 | "老榆木桌面有环状杯痕，边缘漆皮翘起" |
| **布料** | 漫射，皱褶决定阴影 | 起球、褪色、污渍 | "棉麻衬衫后背有汗渍形成的深色地图" |
| **皮革** | 半反光，毛孔可见 | 裂纹、褶皱加深 | "皮沙发座面有同心裂纹，像干涸的河床" |
| **玻璃** | 透光+反射，双重特性 | 指纹、水渍、雾气 | "玻璃上有雨痕拖出的竖向水渍，反射室内灯光" |
| **混凝土** | 粗糙吸光，纹理明显 | 风化、剥落、污渍 | "混凝土墙面上有雨水冲刷的深色竖纹" |
| **皮肤** | 次表面散射，毛孔细节 | 毛孔、皱纹、油光、血丝 | "皮肤毛孔可见，鼻翼有轻微油光，左脸有淡红血丝" |
