# 把预设应用到原生字幕轨道

## 先识别预设所在位置

保留已有SRT字幕轨及其逐条字幕，按实际预设类型走对应入口。预设名称、文件名含“Preset”不能说明其类型。

### 特效库中的Fusion标题或动画字幕模板

1. 核对当前时间线、集号、字幕轨名称及现有字幕数量。
2. 在特效库定位用户指定的准确模板名称。名称和安装位置以当前列表为准。
3. 将该模板拖放到目标字幕轨的**轨道标题/轨头**。落点是显示S1、集号等轨道标识的轨头区域，不是单条字幕正文块、普通视频轨或空白区。
4. 此操作给原生字幕轨应用Fusion样式，保留SRT正文与时间码。官方21.1手册说明，该样式会覆盖检查器中的整轨及单条字幕外观；保留原有设置，核查覆盖后的显示。若用户同时要求保留某些既有单条外观且与该模板冲突，先处理该范围的冲突。
5. 核对全部cue的数量、文字及入出点没有变化；查看首、中、末、最长和双行字幕。动画模板还需播放确认进入、稳定段和退出，观察文字是否由每条cue正确驱动。

标题模板在此用于字幕轨道样式，字幕仍是原生SRT字幕。不要将其改做普通V轨文字片段或烘焙视频来替代用户要的字幕轨。

### 字幕检查器中的原生轨道样式预设

1. 选择目标字幕轨标题，核对活动时间线和轨名，确认检查器处于该字幕轨的**轨道（Track）**上下文。切换时间线后可能仍选着视频片段，须重新选中目标字幕轨。
2. 打开字幕检查器右上角三点选项菜单，选择精确预设名称，再选择其子菜单 **加载预设（Load Preset）**。弹出菜单后获取新的菜单窗口/AX状态，以“加载预设”文字定位，避免点中底层检查器的“音频/视频”页签。点击父预设项只展开子菜单，不足以证明载入；操作后核对轨道样式属性及字幕画面。中文名称以当前UI显示为准。
3. 若用户授权导入本地`.preset`文件，使用同一菜单的 **Import Preset**，随后再次选择已导入的预设并执行 **Load Preset**。导入文件只增加菜单项，载入才应用到当前轨道。
4. 该路径设置整轨默认样式。Caption面板中启用 **Customize Caption（自定义字幕）** 的cue/词可以具有独立外观；挂在轨道上的Fusion模板也可能覆盖检查器样式。按本次要求保留或处理这些覆盖，不能仅凭更改默认值宣称所有字幕外观已统一。

**Save Track as Preset** 用于新建预设，**Update Preset** 用于覆盖已有预设，均不是加载步骤。官方手册说明覆盖已有预设不可撤销；普通套用任务只加载用户选择的预设。

## 作用域和核验

- 学习、记录或维护技能时，只检查并更新方法，不把示例或录制扩大成批量套用授权。
- 当前集已有匹配字幕时直接复用；套预设不重新插入SRT，也不修改其正文、时间码或集号轨名。
- 区分“预设已安装/导入”“已载入目标字幕轨”“保存重开后仍存在”和“实际播放通过”。分别记录实际完成的阶段。
- `LoadRenderPreset`、`LoadLayoutPreset`、`LoadBurnInPreset`和自动识别参数`SUBTITLE_CAPTION_PRESET`不用于加载这里的指定字幕轨样式。

## 依据与已知范围

本机官方《DaVinci Resolve 21.1 Reference Manual》第1237–1240、1242页：轨道样式、单条自定义、保存/导入/载入`.preset`以及拖放Fusion模板到字幕轨头。

本机手册路径：`/Applications/DaVinci Resolve/DaVinci Resolve.app/Contents/Resources/DaVinci Resolve.pdf`。其他版本按其安装手册及实际UI核实入口，不据21.1手册推定所有版本行为。

此前学习通过官方文档确认上述两条路径，未由助手向示例各集实际套用新预设，也未验证特定安装模板的全轨播放效果。后续执行须读取当时工程状态并完成实际核验。
