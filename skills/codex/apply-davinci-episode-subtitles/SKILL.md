# 按集套用达芬奇字幕

按本次请求，为已有字幕轨应用指定样式，或把已有字幕素材按时间码放入对应集时间线并以集号命名轨道。两种任务均保留字幕正文和时间码。

## 先确定本次任务范围

- **已有字幕只套预设：** 核对目标时间线和字幕轨，记录现有字幕数量、正文、入出点与轨名，载入指定预设，再检查样式和保存回读。跳过素材导入、字幕插入及轨道重命名；现有轨名中的集号只作目标核对依据。目标轨不存在时报告该集缺少字幕，不自行扩大为导入、识别或插入字幕。
- **按集插入字幕并套预设：** 执行下方完整流程；已有一致字幕时复用，仅补本次请求的样式和命名。

项目、时间线完整名称/版本、集号、目标字幕轨和预设名称均为输入。批量套用时逐条确认实际活动时间线，不沿用上一集的检查器状态，也不把录制中点击过的所有标签当成已处理清单。

## 输入和默认值

- 项目、目标时间线和集号：从本次请求与当前项目核实。时间线和字幕来源必须属于同一集、同一版本；集号相同不代表男女版或不同剪辑版本可以混用。
- 字幕来源（涉及插入时）：媒体池中已有的字幕素材，或用户指定的本地字幕文件。常见媒体夹名为 `字幕_EP{集号}`、素材名为 `EP{集号}`，仅作查找线索，不硬编码完整项目路径。
- 字幕预设：默认使用录制中选择的 `九州海外短剧 Preset 字幕 Preset`；用户本次指定的预设优先。该预设需要已经安装，本技能不包含预设文件或其字体、尺寸等参数。先按实际所在位置判别它是特效库中的Fusion标题模板，还是字幕检查器中的轨道样式；名称含“Preset”不能用于判别类型。
- 字幕轨道名称（涉及命名时）：对应集号文本，例如第 21 集命名为 `21`，不是字号、字幕正文或时间线名称。前导零遵循用户本次要求或项目既有约定。仅套预设时沿用现有轨名。

已有上下文能唯一确定输入就直接执行；只在素材版本、时间码基准或目标仍有实质歧义时澄清受影响部分。批量请求逐集匹配与验证，不把示例第 21 集固化为目标。

## 工具选择

优先使用当前可用的 Resolve 专用工具或官方脚本 API 完成受支持的语义操作，例如读取项目、时间线、字幕轨道和片段，修改轨道名称以及保存项目。检查返回值并回读结果。

按时间码插入字幕和选择现有字幕样式预设，若当前工具没有对应能力，明确使用 **Computer Use** 操作 Resolve 原生界面。通过 `mcp__cua_repl` 获取 `com.blackmagic-design.DaVinciResolve` 的窗口和最新 AX 状态/截图；依据实际菜单名、轨道标题和检查器分区操作。每轮操作后刷新状态，AX 未命名的时间线区域用当前截图定位，不保存固定坐标、窗口编号或 AX 索引供下次复用。

使用 API 前检查本机 Resolve 随附的开发文档，不能用渲染预设、界面布局预设或自动语音识别代替字幕样式预设与已有字幕插入。没有支持的 API 时保持原生字幕轨道可编辑，不为绕过 UI 把字幕烘焙成视频。

## 操作

1. **核对目标和现有状态。** 读取当前项目与时间线名称；若当前不是用户指定目标，先切换到目标项目和目标时间线，切换后重新获取对象/界面并核对完整名称与版本，确认成功才开始修改。进入剪辑页并停止播放，记录目标字幕轨道与现有字幕片段。仅套预设时，以现有轨道为核对基线，无须重新查找SRT素材。涉及插入时，再核对本集字幕素材、时间线起始时间码及帧率，明确源字幕时间码是相对片头的经过时间还是绝对时间码；相对时间须与“时间线位置减时间线起点”比较，绝对时间码直接比较。无法判断会影响放置时先核实受影响部分，不能猜偏移量。保留当前视频、音频剪辑及其他字幕版本。
2. **避免重复插入。** 若本集字幕已经存在且正文、时间码与来源一致，复用该轨道，只补本次需要的预设或命名。若已有字幕内容冲突，先核实差异；不自动删除、覆盖或新叠一套字幕。录制开头的 Delete 已被用户明确排除，不属于工作流。
3. **按时间码插入对应字幕。** 仅在需要新增本集字幕时执行。在媒体池打开本集字幕媒体夹，选中已核实的字幕素材。需要从本地导入时仅导入用户指定文件。再次确认当前目标时间线后，打开素材上下文菜单，选择 **“将所选字幕插入到…” → “使用时间码的时间线”**。核对实际生效的目标仍是本集时间线，让 Resolve 按字幕时间码放置，不能改选“时间线”、按当前播放头拖放或擅自整体偏移。若出现目标选择弹窗，按当前名称选中本次目标。插入后按第 1 步确认的基准检查字幕轨道、片段数量和首尾时间码；不能仅凭菜单名称认定放置准确。操作结果不明时先回读，不能直接重复插入。
4. **按预设实际类型应用到字幕轨道。** 学习或执行此步时读取[字幕预设应用方法](references/subtitle-presets.md)。本次录制中的预设位于检查器的轨道预设菜单，执行时仍按当前安装状态核对。特效库中的Fusion标题/动画字幕模板，拖到已核实的原生字幕轨道标题（轨头）上；检查器内的原生轨道样式预设，进入该字幕轨的轨道上下文，在右上角三点菜单中选精确预设，再选其子菜单“加载预设”（Load Preset）。弹出菜单后重新读取菜单窗口，以子项名称定位；不能把父预设项点击或底层“音频/视频”控件误判为载入成功。`.preset`文件导入菜单后仍须载入。两条路径作用机制不同，按实际类型选择。确认应用对象是当前集的字幕轨道，保留正文、时间码、数量和集号轨名；预设缺失时报告精确名称，不用近似预设或猜测参数代替。载入后的状态不明时先检查属性与实际字幕画面，再决定是否需要重试，不能继续盲点或直接切到下一集。
5. **按本次范围命名轨道。** 仅套预设时保留现有轨名。完整插入并命名任务或用户另有明确命名要求时，把本次目标字幕轨道名称改为对应集号并提交，例如 `21`。API 可用时可对已经核实的字幕轨道调用 `SetTrackName("subtitle", trackIndex, episodeLabel)` 并用 `GetTrackName` 回读；轨道索引须来自当前状态。使用界面时编辑字幕轨道标题，回车后确认标题显示正确。不要把集号写入检查器数值字段、字幕正文或其他轨道。
6. **验证并保存。** 仅套预设时，对照操作前的轨道基线检查字幕数量、正文、入出点与轨名未变；涉及插入时，对照字幕来源检查数量及首尾、抽查中间字幕的正文和入出点。查看首、中、末及最长/双行字幕的换行、边缘裁切、位置和可读性，检查已有自定义字幕是否受预设覆盖。带动画的模板须播放检查进入、稳定段和退出，静帧不能证明动画正常。短段播放确认字幕与对应对白/独白的时序；有错位时先检查来源版本和时间码基准，不自行重写或重定时。保存当前项目后，在安全重新载入或重新打开后回读目标字幕轨道、轨名和样式，区分保存命令成功与持久化确认。

## 完成标准和交付

目标字幕轨保留正文、数量和时间码，并使用指定预设；只套预设时保留现有轨名及其他轨道。完整插入并命名任务应有且仅有本次需要的一套对应字幕，字幕轨道以对应集号命名。重复执行前重新识别已有状态。

简要报告处理的时间线/集号、字幕来源、轨道名称、预设，以及实际做过的时间码核对、播放和保存回读。未完成的验证明确标出；结构验证、预设点击和保存命令都不能单独证明播放质量或持久化。

本技能来源于 2026-10-20 的操作演示及用户澄清：不需要删除；插入选“使用时间码的时间线”；末尾输入为对应集号。随后只读界面核对确认该集号显示在字幕轨道标题处。原录制未覆盖项目重新载入或完整播放；这些是执行时的结果验证要求，不能描述成已录到或已完成的操作。

同日后续演示补充了“已有字幕只套预设”的入口及逐集切换方法；证据范围见[字幕预设应用方法](references/subtitle-presets.md)。该录制没有明确捕获子菜单载入成功、保存重开或播放结果，不能当作已重放验证。

用户仅要求学习、创建或修改技能时，只完成技能文件；录制不自动授权对其他集操作或导出成片。
