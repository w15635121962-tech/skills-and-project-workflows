# 剧梦制作与素材绑定

按当前请求选择制作、绑定、保存或生成阶段。仅绑定/保存/提交明确批准正文时复用该正文；后续新设计或重新生成从源剧情和当前要求重新设计表演与摄影。新写提示词读取 [短剧逐镜提示词](../short-drama-shot-prompts/SKILL.md)，不继承旧表演方案。平台操作无需另做导演或分镜表。

- 新稿、定时长或续作：读取 [制作与时长](references/production.md)。
- 编写提示词：读取 [当前提示词格式](references/format-c.md)（该旧文件路径现指向用户2026-10-23提供的中文八项模板）。
- 平台填入、保存或生成：读取 [平台操作](references/platform.md)。
- 原生引用或修复：读取 [素材绑定](references/asset-binding.md)。

台词按原语言逐字保留。既有资产正确则复用；素材对应人物、当场服装、场景和道具。普通“@文件名”、空卡或仅卡数正确不算完成原生绑定。

保存后重新载入核对正文、卡片归属和生成设置。设置模型/时长后、点击生成前再次检查主要人物指定资产卡，缺卡先修复。分别记录正文保存、引用保存、生成受理和完成，提交不明先查历史。

沿用已明确的范围和授权持续完成；仅稿件或绑定请求止于该范围。维护规则、示例及附件不授权上传、外部发送、生成或扣费。

默认结果留在平台，不自动下载、导出、转码或打包。用户只要求提交则确认受理；要求完成则核对实际返回。没有回放不报告内容质量通过。
