# 当前提示词格式：中文逐镜八项模板

编写最终提示词完整读取[竖屏短剧情绪与连续性分镜](../../short-drama-shot-prompts/SKILL.md)。依次使用时长、环境氛围、景别、拍摄角度、摄像机运动、人物角色和运动、人物表演、画面内容；有对白或明确声音要求时在末尾追加音频。分段时间只写在人物角色和运动内，从0连续覆盖总时长。每镜明确实际位置、画面位置、姿势、支撑、手部归属和戏内视线，换机位重新推导画面坐标。本文件名仅保留路径兼容。

按源语言逐字保留原台词，旁白按当前允许范围，未提供录音不编独立音频引用。角色音色、普通@文字与原生素材卡分别核验。平台绑定在本次批准位置插入，保留邻接角色名和动作；仅绑定、保存或提交旧稿时保持原正文及结构，局部修订冻结未请求部分。保存后重新打开回读，不把卡数或即时显示当成持久保存证据。
