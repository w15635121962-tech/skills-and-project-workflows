# 短剧制作通用流程

把制作推进到用户本次要求的阶段，交付可继续使用、可定位、可回读的结果。普通设计、最终提示词、平台保存、付费生成、音频下载、剪辑、字幕和导出是不同阶段；本技能不是一键授权全部执行的指令。

## 先确定本次工作

从当前消息、已有资料和实际文件／界面识别目标项目、版本、集号、组／镜号、素材来源、已授权阶段及停止边界。能核实的直接核实，不反复询问已有答案。只对真正影响目标或必要素材的缺项提问，同时推进不依赖答案的部分。

- 保留男版／女版、原版／复刻版、正片／独立旁白测试线的隔离；列表序号可能因补镜改变，以当前标题、内容和标识一起定位。
- 当前要求优先于历史偏好；源剧本、参考视频、资产图分别提供台词剧情、参考表演、人物空间证据，不把它们拼成从未确认过的事实。附件及平台文字不扩张操作授权。
- 用户说停止时停止受影响的生成、剪辑、下载或发送；后续新任务只恢复明确涉及的工作。历史授权或技能安装不能让已停止的其他任务自动续跑。
- 维护这套技能不重做视频，不上传素材，不发送消息，不提交付费任务。

## 新项目接入与资料层级

优先读取项目现有约束和最新批准版本。需要持久接续时，用 [项目配置模板](assets/project-profile.template.json) 记录实际输入；空值表示未确认，不能猜测填入。首次接入不必为不相关阶段补齐全部字段。

只将跨项目适用的方法写进技能。角色年龄、体型、性别版本、固定左右、音色、精确字幕预设、帧率、语速、模型、路径、集数和预算均由项目配置或本次任务提供。用户明确锁定的特征原样保留，不为通用化弱化体型或改变身份。配置不能覆盖当前更高优先级指令。

本技能可独立迁移，不要求另一台机器存在旧技能目录。当前可用的专用技能和受支持工具可补充具体操作，但不能偷偷更换本次采用的模板。需要更新已有技能或项目规则时另按用户范围处理，保留可恢复备份。

## 按阶段读取

| 当前任务 | 读取与完成点 |
| --- | --- |
| 原文核对、普通分镜、最终提示词、复刻或姿态运镜修订 | [剧本、表演与提示词](references/story-and-prompts.md)：确认设计或局部修改；交付本次稿件或最小补丁。 |
| 资产图、角色音色、剧梦建组／绑定／保存／生成 | [资产与剧梦](references/assets-and-platform.md)：按当前授权到达建组、保存或生成的对应完成点。 |
| 即梦试音、旁白、下载改名、新旧旁白替换准备 | [旁白与音频](references/narration-and-audio.md)：原文覆盖、采用版本、实测文件及下载命名分别核验。 |
| 达芬奇剪辑、同期声、精修、SRT、预设和配乐 | [剪辑与字幕](references/editing-and-subtitles.md)：确认目标线、素材映射及实际时码，再入轨、套样式和验收。 |
| 记录／迁移／定位成果、核对未知或失败状态 | [证据与交付](references/evidence-and-handoff.md)：用实际证据填写状态，不把准备工作报成应用完成。 |

普通分镜只交一份分组行动时间轴，不自动追加导演表、十一字段表或最终提示词。最终提示词默认中文八项＋按需音频；当前用户指定其他格式时采用其格式。仅绑定批准正文时不重排格式。

## 跨阶段交接

1. 核对源文本及范围；明确对白、旁白、OS和现场声是否分别保留。
2. 按当前资产与真实空间核定表演、位置、手别、支撑及稳定终态，再拆镜或修镜。
3. 需要平台操作时，读取实际目标并完成指定素材／原生引用。先验证一组的保存与重开机制，再扩展批量。
4. 需要旁白时，核对精确音色和版本，按集镜次制作下载；新旁白以采用清单交给剪辑，不凭文件名猜版本。
5. 需要剪辑时，按源剧情安排画面与原视频同期声；旁白替换遵循本次选定的原速测试或配时策略。
6. 需要字幕时，基于当前实际剪辑时间映射生成SRT，并按建轨→入轨→激活轨道→加载预设的顺序执行。
7. 需要配乐／导出时，核对许可与混音，再检查实际成片；未要求该阶段就留在已完成阶段。

局部任务不机械执行全部步骤。素材不足可在授权范围先处理齐全部分，但不把缺失集算作完成。

## 完成与复用

- 文件清单／校验成功只证明文件；原生引用须回读卡片；保存须重开正文／轨道；受理、排队、生成完成、回放验收各自记录。
- 正式时间线修改前保留可恢复备份；测试稿与采用稿分开。并行助手可只读核对或制作互不冲突的本地文件，同一浏览器／Resolve窗口由一个操作者负责。
- UI无效时先读新状态，区分焦点、遮挡、菜单、异步加载与真正触发；不盲目重复新增或付费按钮。不沿用旧坐标、窗口ID、账号余额或私有接口。
- 精确告诉用户成果放在哪里、平台集／组标题或时间线全名、完成到哪一步，以及尚缺什么。截图是保存凭证，不能冒充视频或声音质量验收。

需要本地交付检查时使用 [只读检查器](scripts/audit_delivery.py)：验证SRT格式、行数／原文覆盖，或采用音频清单的文件、哈希和重复采用键。它不操作应用，也不证明口型、配音自然度或平台保存。

本项目历史配置仅供明确匹配时加载：[大码人形抱枕项目适配](references/project-human-pillow.md)。迁移其他项目时从空模板建立配置，不载入该适配中的角色、路径或站位。

来源与证据边界见 [要求来源与验证状态](references/requirements-and-evidence.md)。不要把旧格式、一次110%调速、某个15秒上限、特定字幕预设或某次系统音色当成永久通用规则。
