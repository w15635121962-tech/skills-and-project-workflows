# 剪辑、同期声与原生 SRT 字幕

本参考用于叙事短剧的按集剪辑、旁白替换、字幕和音频整理。执行前读取主技能中的本次授权与项目档案；本文件不自动授权打开其他项目、生成旁白、下载音乐、重启软件或导出成片。

## 1. 本次输入与修改边界

- 确定项目名、男女版或其他改编版本、集号、源剧本版本、目标时间线完整名称和用户最后指定的交付范围。
- 确定任务是剪正片、整理原速旁白测试线、只替换旁白、只加 SRT，还是只给已有字幕轨套样式。
- 对照本地文件、媒体池及当前时间线核实素材；集号相同不能证明版本相同，不用相似文件或旧音色替代。
- 每集使用独立、可识别版本的时间线。结构性修改前保存可恢复的项目备份或复制时间线，记录原版本标识。
- 文件夹、轨道和时间线名称使用项目档案参数，不把本项目的盘符、角色名、时长或集数硬编码到其他项目。
- 读取活动项目、时间线、播放头、选择、轨道占用、片段及源区间；用户可能在上次操作后继续手工修改。
- 已有批准的画面、音频处理、字幕、镜头顺序及用户手改内容，只修改本次明确范围。
- 暂缺素材时继续素材齐全的集；把缺失集和缺失类型列清，不用旧旁白、静音或重复画面冒充完成。

## 2. 按剧本建立剪辑顺序

1. 先对应原剧本中的事件与原台词，再对应分镜、下载素材和实际可用版本。
2. 为每个片段记录集、镜、次、源文件、源入出点、目标位置和音频归属；实际内容优先于文件名中的序号。
3. 按剧情先后拼接可用片段，保留对白完整词尾、行动因果、人物终态与下一镜起始状态。
4. 不因自动文件排序把补镜放错位置；不因文件名相同忽略不同生成次数或不同男女版。
5. 正反打检查人物视线、180°轴线、动作方向、道具接点与表演接续，不仅检查时间线上没有空隙。
6. 重复素材只有在用户指定或叙事确实需要时使用，记录重复源区间，不用改名掩盖重复。
7. 先检查一小段实际导入和播放结果，再批量构建；发现时基或映射错误立即停止受影响批次。

## 3. 同期声必须随对应画面一起剪

- 有同期声的视频，画面与同期声按同一源区间导入并同步放置，核对实际音轨或声道，不只导入视频流。
- 同期声与画面在目标时间线上使用相同起止位置；源音频采样率或独立音频偏移另有依据时明确记录换算。
- 保留原始连接或等效的同步关系；切画面时同时切对应同期声，移动后检查两者是否仍对齐。
- 留意一个视频含多条音流、立体声双声道、独立录音或内嵌重复人声，避免漏声或把同一句叠加两遍。
- 对口型镜检查发声起点、口型、可听词与动作；源音频存在声画偏移时先确认真实偏移再修正。
- 一段有画面而没有声音时，先检查媒体音流、静音、轨道启用、声道映射、音量和源入点，不立即补配音。
- 跨镜保留环境连续性，必要时在本次音频授权内做短交叉淡化；不得削去辅音、词首、词尾以填平剪口。
- 同期对白、旁白、音效、音乐保持可辨的独立用途，轨道号是当前工程事实，不能假设 A1 永远是同期声。

## 4. 新旁白替换的两条分支

### 原速旁白独立测试线

- 用户要求“正常速度，只剪顺序、先放测试时间线”时，按剧本顺序排列新旁白，保持原速。
- 逐句核对内容、缺句、重复句、首尾静音与读音；可剪去无用空白，但保留语意停顿和完整发声。
- 测试线与正片分开命名。音频放在正片后面作测试时，明确记录正片结束与测试段开始位置。
- 不把测试线当成画面已精剪，不把旁白测试段字幕误加到前面正片，反之亦然。

### 在既有正片替换旁白

- 先记录旧旁白各片段的源文件、区间、时间线位置、轨道、音量、变速与用户手工处理。
- 只替换已经核实的旁白片段，保留画面、同期声和其他轨道；不因“一键替换”移除视频内的同期对白。
- 使用新旧原文逐句映射，检查新音频确属指定音色与版本；旧旁白的片段、嵌套或重复混音不能残留叠播。
- 默认不变速。若用户本次明确要求固定语速或同意微调，记录变速值、音高处理和受影响范围。
- 新旁白更长时依据用户选择处理：保留画面节奏微调旁白，或原速重排画面；不自行扩大到全片节奏修改。
- 用户后来改为原速时撤销受影响的新旁白变速，不沿用旧的“统一 110%”要求作为永久默认。
- 按句检查停顿与画面情节落点，播放接缝，确认没有截词、重复句、错句或旧新旁白同时发声。
- 缺少新旁白但用户允许先剪画面与同期声时，仅完成这两项；原文旁白字幕可预排，但标注尚待配音对齐。

## 5. 帧率、源入点与交换文件

- 分别读取源视频、音频、时间线与交换文件的时间基；23.976、24、25、29.97、30 不可凭显示四舍五入混用。
- 使用有理数或精确时间分数计算源区间与时间线位置，最后按目标帧边界量化；避免逐段浮点累积造成漂移。
- 声音按时间与采样数核对；不能把 48 kHz 的采样下标当作视频帧号，也不能把源帧号直接作目标帧号。
- 时间码表示法与播放速率分开核实；确认 drop-frame 与 non-drop-frame，不能只看冒号或分号猜测时基。
- 导入 XML、FCPXML、AAF 等前核实本机软件与文件格式文档，不凭旧版接口或字段名推定语义。
- 区分三件事：源媒体中的入点、父片段内的本地时间、片段在时间线中的偏移。三者不是同一坐标。
- 连接片段的 `start`、`offset` 或同类字段按所用格式定义换算；本地源 in 不可误加时间线起点或父片段偏移。
- 导入后尤其检查连接音频的源入点，避免画面正确但音频从文件开头、错句或后半段开始。
- 先选有非零源入点、连接音频、转场或变速的少量片段做试导入；回读源区间并实际播放，再批量执行。
- 修改源位置后同步重核字幕与音频；不要用整体拖移字幕掩盖源音频错误或时基换算错误。

## 6. SRT 内容与时间码准备

- 先取得源语言原剧本及最终采用的对白、旁白，区别已剪出的声音、预排原文和未制作内容。
- 正式对时优先实际采用的音轨、波形和逐句听检；识别结果只作定位线索，不能单独推翻原台词。
- ASR 的低置信名字、数字、零时长词、重复幻觉或漏词必须标记并核对，不把“识别完成”写成“听检完成”。
- 用户要求预排尚无配音的旁白字幕时可按原文制作，明确时码是预排，配音完成后须重新对齐。
- 保留源语言原台词和已批准修改，不擅自翻译、改词、补未读句或删实际出现的重复对白。
- 每条字幕不超过三行；优先按语意、短语及标点换行，不拆专名、固定搭配，不以删词满足行数。
- 字符宽度、字号、安全区和阅读速度由交付规格与实际画幅核定；其他项目不硬编码本项目的每行字符数。
- 验证 UTF-8 编码、连续编号、正时长、先后顺序、允许的重叠及全片范围，核对首、中、末和长句。
- 明确 SRT 是相对片头经过时间还是绝对时间码；绝对时码直接比较，相对时码与“时间线位置减起点”比较。
- 例如 24 fps、时间线起点 01:00:00:00 的素材，与相对 0 秒 SRT 可同时成立；不能据此擅自整体加一小时。
- 正片与片尾追加旁白测试段使用不同范围标识；用户后来要求“前面的正片上”时，以这次明确位置为准。
- 可先生成 SRT 文件再导入；文件校验、入轨校验、预设载入和实际播放分别记录。

## 7. 完整字幕流程：先入轨，再做预设

必须按本次指定集逐集执行，切换后重新确认完整时间线与版本，不复用上一集的检查器状态。

1. **核对与去重。** 记录当前字幕轨、正文、数量、首尾入出点；已有完全匹配的字幕直接复用。
2. **新增原生字幕轨道。** 目标无对应轨时先添加；原轨存在则不重复建轨，不先在空轨加载预设。
3. **导入对应 SRT。** 核实集号、版本、字幕文件与时间码基准，再导入媒体池。
4. **按时间码入轨。** 素材右键选择“将所选字幕插入到…”→“使用时间码的时间线”，核对目标仍是本集。
5. **确认已入轨。** 对照来源检查字幕条数、正文、首尾和中间入出点，避免当前播放头插入或叠加重复字幕。
6. **激活轨道检查器。** 点击目标字幕轨的空白处，确认进入轨道（Track）上下文，而非单条 Caption 或视频检查器。
7. **载入指定轨道预设。** 按下一节辨别类型，明确执行真正的“加载预设 / Load Preset”。
8. **命名与换行。** 完整添加任务把字幕轨命名为对应集数字，如 `25`；前导零按项目约定。每条仍须不超过三行。
9. **画面与时序核验。** 查看首、中、末、最长和多行字幕，播放对白、旁白接缝及动画进入退出。
10. **保存并重开回读。** 安全保存后重新载入项目或时间线，检查字幕数量、轨名、样式和位置仍然正确。

菜单执行结果不明时先回读，不能重复插入碰运气。普通“时间线”、当前播放头拖放或整体偏移不能代替已核实的按时间码插入。

### 已有字幕只套样式

- 记录并冻结当前正文、数量、入出点及轨名；跳过新增轨、素材导入、字幕插入及轨道重命名。
- 点击正确字幕轨空白处激活轨道上下文，只加载本次指定样式，再核对字幕画面并保存重开。
- 目标轨不存在时报告缺失，不自行扩大为识别、翻译或插入字幕；不同正文的已有轨先处理差异，不直接覆盖。

## 8. 预设类型与真正的加载动作

- 名称包含“Preset”不能判断类型。检查当前安装位置和本机版本文档，不猜测预设参数或找近似名代替。
- **字幕检查器原生轨道样式：** 在轨道上下文右上角三点菜单选择精确预设，再点子菜单“加载预设”。
- 父预设项只展开子菜单，按钮获得焦点不代表加载成功；读取新弹出的菜单，核对具体子项和样式属性。
- 仅导入 `.preset` 文件只增加可选项，导入之后还要执行 Load Preset；Save Track as Preset 和 Update Preset 均非加载。
- **特效库 Fusion 标题或动画模板：** 仅在当前软件支持该机制时，拖到已核实的原生字幕轨轨头，而非普通 V 轨。
- Fusion 轨道样式可能覆盖字幕检查器或单条自定义外观；检查已有 Customize Caption 与其他覆盖，再判断全轨效果。
- 渲染、界面布局、烧录、自动识别等预设不等于字幕轨样式，不能用它们的 API 替代正确操作。
- 字幕应保持原生、可逐条编辑和可导出 SRT；Text+、普通视频标题或烧录画面不能冒充完成 SRT 入轨。
- 项目曾使用的“九州海外短剧 Preset 字幕 Preset”仅是项目档案中的精确名称，不是本通用技能的全局默认。
- 预设没有安装时明确报告精确名称，保留现有字幕与已完成步骤，不自行替换为猜测的字体、字号或动画。

## 9. 音频精修、音乐与交付

- 原对白、同期声和旁白优先可懂；校准声道、相位、音量和峰值，处理过大的接缝与噪声时避免损伤语言。
- 音乐与音效独立可编辑，按剧情进入退出，不让音乐掩盖词句。固定 dB 值只是起点，必须结合实际混音听检。
- “没有版权”不是许可类型。取得适配用途的授权音乐，核实商业用途、分发平台、署名、剪改和内容识别条件。
- 保存来源、许可说明、下载日期、曲目版本和适用范围；名称写着免费或免版税不能证明所有用途都被许可。
- 下载、付费或向第三方发送须在本次授权范围内；音乐核验不意味着用户授权新增付费或对外发送。
- 修剪音乐前后空白并检查可听起点、淡入淡出和集尾衔接，不能仅以音频文件左边缘对齐情绪点。
- 完成后区分：源文件整理好、时间线已构建、原生字幕已入轨、样式已载入、保存回读通过、播放验收、导出验收。
- 截图、片段数量、波形、ASR、API 返回成功或保存菜单点击，都不能单独证明成片声音正确或口型同步。
- 输出时长、画幅、帧率、编码与音频规格按当前交付要求和源素材核定，不套其他技能的 4K 横屏默认。
- 导出后检查真实文件的时长、帧率、音流和可播放性，并实际审看关键剪口、字幕、音量及首尾；未完整听看就明确标注。

## 10. 界面故障与授权恢复

- 优先使用当前支持的 Resolve 语义工具或官方 API；不支持的步骤使用当前真实界面，不依赖过时坐标或窗口编号。
- 一次点击只改变焦点而未执行时，重新读取当前窗口、菜单和截图，确认一次正确入口；不要连续盲点父菜单或底层控件。
- 两次结果不一致或界面卡住时停止重复操作，检查播放状态、弹窗、活动项目、软件忙碌与单屏/多屏坐标。
- 用户在操作同一个窗口时先协调接管；不能把用户的手工修改当作自动任务失败后覆盖掉。
- Mac 锁屏时停止控制，请用户手动解锁；不得尝试绕过锁屏或把界面无响应误判为解锁授权。
- 强制退出可能丢失未保存修改；先保留可保存的恢复资料，只有用户本次已有明确授权时才执行恢复重启。
- AppleScript、JXA 或系统事件等替代点击方式须符合当前工具规则和本次授权，历史某项目许可不能扩展到其他项目。
- 重启、重绑或重开后重新核对项目、时间线、轨道、片段与保存状态，从实际进度续做，不重复导入或宣称故障前操作已成功。

## 11. 单集交付记录

记录集号、版本、时间线全名与标识、备份、素材源与范围、帧率、时间线起点、总时长、音轨用途和旁白速度。
字幕记录 SRT 路径与校验值、时间码基准、cue 数量、首尾时间码、轨名、行数上限、精确预设与加载类型。
验证记录源区间与同期声、实际听检和播放范围、保存重开回读、未完成验证及缺失素材；路径用稳定的项目目录。
交付说明只报告实际完成阶段。示例集号、既有导入清单和旧截图是方法证据，不是本次工程当前状态或完成证明。
