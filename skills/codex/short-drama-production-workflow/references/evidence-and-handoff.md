# 证据与交接

## 完成点分开记录

| 状态 | 必要证据 | 不代表 |
| --- | --- | --- |
| 稿件完成 | 当前稿及源台词、组镜映射 | 已写平台或生成 |
| 资产保存 | 准确条目、保存、重开对应图／音色 | 旧视频已更新 |
| 提示词保存 | 重开全文、原生卡名称归属一致 | 视频姿态／口型通过 |
| 任务受理 | 对应组／旁白条目的任务记录 | 扣分即受理、队列即完成 |
| 媒体返回 | 具体结果或非空可播放文件 | 内容和声音均通过 |
| 下载归档 | 正确文件、集镜次及采用记录 | 已剪辑或已发送 |
| 时间线导入 | 原生时间线、素材路径和源区间 | XML方案等于实际剪辑正确 |
| 字幕入轨 | 原生条目、正文、数量和时间码 | 媒体池素材等于入轨／预设加载 |
| 样式加载 | 真正Load、属性／画面、保存重开 | 父菜单获得焦点即加载 |
| 成片验收 | 对应版本实际画面、声音、字幕和接点播放 | 截图、ASR或文件哈希替代播放 |

## 记录只留恢复需要的内容

普通稿件不附公开检查表。持续或批量制作保存：项目／版本／组镜映射、源文及最新修订；精确资产与音色；改前／改后及回读；旁白源文、实测时长和采用路径；时间线全名、备份、源区间、帧率和起始时码；SRT来源、原生轨名、数量、首尾时码、预设；完成阶段、缺失项与具体原因。

不从截断工具输出重建全文。用 [交付记录模板](../assets/handoff.template.json) 时未知状态填unknown或pending。用户停止后记录范围，不因记录中仍有计划项就自动续做。

## 只读文件检查

```bash
python3 scripts/audit_delivery.py srt /absolute/path/EP01.srt --max-lines 3
python3 scripts/audit_delivery.py srt /absolute/path/EP01.srt --expected-text /absolute/path/narration.txt
python3 scripts/audit_delivery.py media-manifest /absolute/path/adopted-audio.json
```

SRT正文比对保留词、大小写及标点，仅忽略空白。时间重叠会报告，合法同时发言由项目接受，不擅自移动字幕。脚本不会识别声音、换行修稿或操作应用。

媒体清单格式：

```json
{
  "items": [
    {"episode": 1, "shot": 1, "take": 1, "selected": true,
     "path": "audio/EP01-01-01.wav", "sha256": null}
  ]
}
```

相对路径以清单目录为准；采用键为version、episode、shot。不同备选可以并存，一个采用键不能同时选两个候选。缺失哈希记录为未校验，不伪造结果。非空与哈希匹配不证明音色、自然度、同步或许可。

## 面向用户的交付

先说用户目标完成到哪一步，再给可打开的成果位置或平台／时间线全名，最后给实质性未完成点。问“放哪里”时核实实际文件／最新记录直接给位置；只有历史导入记录时注明依据记录，不冒充当前Resolve已现场检查。

截图展示实际保存界面，本地文件用绝对路径链接。内部临时脚本、成堆JSON及运行日志用于恢复，不是主要交付。

技能迁移只打包技能、空配置和可选项目适配，不带账号、密钥、浏览器状态或整库素材。技能静态验证、行为演练与真实平台回放验证分别报告。
