# 推文视觉转译对照表

> 推文分镜的核心难题：推文大量使用隐喻、感官描写和抽象情感词，
> 需要转译为具体的视觉画面。以下提供常见模式的转译参考。

---

## 一、情感隐喻 → 视觉

| 推文原文模式 | 直译陷阱 | 正确转译 | 景别 | 运镜 |
|------------|---------|---------|------|------|
| "胸口像灌了水泥" | ❌ 画水泥 | ✅ 手紧按胸口，指节发白，胸腔起伏沉重 | ECU→CU | 缓推 |
| "心碎了" | ❌ 画碎裂的心 | ✅ 角色僵立，手掌缓缓从桌面收回，指尖微颤 | MCU | 静态 |
| "天塌了" | ❌ 画天塌 | ✅ 空镜仰拍天花板/天空，缓慢下压，角色在画面底部变渺小 | ELS→WS | 缓拉 |
| "血都凉了" | ❌ 画蓝色血 | ✅ 角色手指触碰某物后猛然缩回，手悬在空中微颤 | ECU | 静态 |
| "像被抽走了灵魂" | ❌ 画灵魂出窍 | ✅ 角色瞳孔失焦，嘴唇微张，身体微微后仰靠在墙上 | CU | 静态 |
| "全身像被火烧" | ❌ 画火焰 | ✅ 额头细密汗珠，颈部血管跳动，手紧攥床单/衣物 | ECU | 缓推 |
| "脑子里嗡嗡响" | ❌ 画面震动 | ✅ 角色闭眼，周围虚焦，只有面部清晰，呼吸变浅 | CU | 静态+浅DoF |
| "脚下像踩空了" | ❌ 画踩空 | ✅ 角色踉跄一步，手扶住门框，画面微微倾斜 | MS→CU | 静态 |

## 二、感官描写 → 视觉

| 推文原文模式 | 转译策略 | 视觉画面 | 景别 |
|------------|---------|---------|------|
| "刺骨的冷" | 触觉→视觉 | 呼吸白雾清晰可见，手臂上汗毛竖起，裸露皮肤泛红 | CU |
| "空气都是甜的" | 味觉→视觉 | 阳光穿过树叶的光斑落在角色脸上，嘴角不自觉上扬 | MCU |
| "耳边全是尖叫声" | 听觉→视觉 | 角色双手捂耳，闭眼皱眉，周围人群模糊运动 | MCU |

| "眼前一黑" | 视觉→画面 | 画面从边缘渐暗至全黑，持续0.5-1.0s | 全黑 |

## 三、推文高频叙事动作 → 镜头设计

| 叙事动作 | 推文常见写法 | 推荐镜头序列 | 时长参考 |
|---------|------------|------------|---------|
| **背叛发现** | "我推开那扇门" | WS门框→MCU角色表情骤变→ECU眼睛 | 3+3+2=8s |
| **沉默崩溃** | "我什么都没说" | CU面部静止≥3s→ECU眼泪滑落→INSERT手攥紧 | 3+2+1.5=6.5s |
| **反转降临** | "他说，你不一样" | MCU对方说话→CU角色瞳孔微动→MCU双方构图→金句定格 | 3+2+3+3=11s |
| **压抑爆发** | "我忍了很久" | MS日常场景→CU面部变化→ECU拳头→WS爆发动作 | 3+3+1.5+3=10.5s |
| **告别离去** | "然后他关门走了" | MCU角色背影→WS空荡门口→CU留守角色表情→空镜门 | 3+2+3+2=10s |
| **等待绝望** | "我等了一整天" | MS角色等待→时间流逝蒙太奇(光线变化)→MCU最终表情 | 3+4+3=10s |
| **身份确认** | "我是___" | ECU关键物品/标记→CU角色表情→MCU角色宣告→金句定格 | 2+2+3+3=10s |

## 四、9:16竖屏构图规则

**单人构图：**
```
┌──────────┐
│  留白/环境  │ ← 上1/3：头顶空间
│          │
│   😊     │ ← 中1/3：面部（CU/MCU默认位置）
│          │
│  字幕区   │ ← 下1/3：字幕安全区，不放置关键元素
└──────────┘
```
- CU/MCU：面部居中偏上，下巴在画面中线附近
- MS：头部在上1/3，身体占据中2/3
- WS：人物在画面下部1/3，上方为环境

**双人构图（竖屏特有）：**
```
┌──────────┐          ┌──────────┐
│  😊 A    │          │  😊 A    │
│          │          │    │     │
│──────────│          │  😊 B   │
│  😊 B    │          │          │
│          │          │          │
└──────────┘          └──────────┘
  上下对峙构图            前后景构图
  （权力对峙）           （主次关系）
```

**金句定格构图：**
```
┌──────────┐

│          │
```

## 五、情感强度→视觉强度映射

| 情感强度 | 景别趋势 | 运镜 | 切镜频率 | 光线 |
|---------|---------|------|---------|------|
| 1-3（平静/日常） | WS→MS | 静态 | 慢（4-6s/镜） | 均匀，自然光感 |
| 4-5（积累/不安） | MS→MCU | 缓推 | 中（3-4s/镜） | 开始出现明暗对比 |
| 6-7（破防/崩溃） | MCU→CU→ECU | 急推 | 快（1.5-2.5s/镜） | 高对比，光源单一 |
| 8-9（至暗/绝望） | ECU/FRAGMENT | 急推 | 极快（0.5-1.5s/镜） | 极端对比，半面光 |
| 10（金句/反转） | CU→金句定格 | 纯静态 | 单镜≥3.0s | 戏剧光，光从画面外打入 |

## 六、VO与画面的三种关系

**同步型（最常用）：** 旁白说什么，画面就展示什么。
```
VO: "他站在雨中，没有伞"
画面: 男人站在暴雨中，雨水顺着头发流下，远处路灯模糊
```

**反差型（情感放大器）：** 旁白与画面形成反差，制造情感张力。
```
VO: "我很好。"
画面: 角色蹲在浴室角落，水龙头开着，眼睛通红
```

**留白型（意境营造）：** 旁白描述内心，画面展示环境/空镜。
```
VO: "那一刻，所有的声音都消失了。"
画面: 空镜——窗台上被风吹落的花瓶，水慢慢流向桌面边缘
```

选择规则：
- 推文原文有明确视觉 → 同步型
- 推文原文说"我没事""我很好""没关系" → 反差型
- 推文原文描述内心崩溃/巨大情感 → 留白型
- 一段内可以混合使用，但必须有意设计，不可无意混搭
