## 定位 — 与其他技能的边界

| 技能 | 输入 | 输出 | 画幅 | 特色 |
|------|------|------|------|------|
| `viral-thread-story` | 主题/需求 | 推文文字 | — | 文字创作引擎 |
| **`tweet-storyboard`** | **推文文字** | **分镜表** | **9:16** | **推文→画面转译，旁白驱动** |
| `storyboard` | 英文剧本 | 分镜表 | 9:16 | 剧本格式，纯分镜 |
| `9-16-movie-story` | 中文剧本 | 全管线 | 9:16 | 含AI提示词+空间坐标 |
| `movie-story` | 中文剧本 | 全管线 | 横屏 | 最深管线 |

- **用 `tweet-storyboard` 当：** 有一段推文故事文字，需要拆成画面分镜。
- **用 `storyboard` 当：** 有正式剧本格式，需要纯分镜。
- **用 `9-16-movie-story` 当：** 有正式剧本，需要完整AI生产管线。

## 上下游衔接

- **上游：`viral-thread-story`** → 推文分镜直接消费其产出的分段文本
- **下游：`9-16-movie-story` / `movie-story`** → 分镜表可作为视觉规划输入，进入全管线补充AI提示词和空间锁定
- **参考：`focal-grid`** → 对峙/凝视场景已有焦段网格时，直接引用其镜头弧线

## 核心挑战 — 推文 vs 剧本

| 维度 | 剧本 | 推文 |
|------|------|------|
| 格式 | slugline + 对话 + 舞台指示 | 散文叙述，无格式标记 |
| 视角 | 第三人称客观 | 多为第一人称主观 |
| 声音轨道 | 对话驱动 | **旁白驱动**（VO即推文原文） |
| 时间标记 | 有明确转场 | 隐含，需推断 |
| 情绪表达 | 通过对话+动作 | **大量隐喻/感官描写** |
| 视觉信息 | 舞台指示直接描述 | 需从叙述中提取+补全 |
| 节奏控制 | parenthetical + beat | 落点句 + 段尾钩子 |

核心工作是 **文字→画面的转译**，而非简单的格式映射。

---

## 工作流

按五步顺序执行，每步输出后再进入下一步。

```
STEP 1 → DISSECT   拆解推文，提取叙事节拍与情感曲线
STEP 2 → EXTRACT   从散文中提取角色/场景/物品视觉锚点
STEP 3 → TRANSLATE  文字→画面转译，每个节拍分配视觉策略
STEP 4 → BOARD     输出分镜表
STEP 5 → CHECK     自检，修复，通过声明
```

**硬规则：**
- 不跳过、不合并、不省略任何推文内容
- 每个镜头必须有对应的推文原文依据
- Step 5 未通过前不输出最终结果
- 每个镜头回答：**"这个画面比前一个多了什么新信息？"**

---

## 制作要求（v1.1 强制）

| 条目 | 要求 | 对应步骤 |
|------|------|---------|
| 固定镜头 | 占比 ≥80%，默认「静态」 | STEP 4 运镜列 |
| 画面密度 | 1句≥1镜，目标 1.5镜/句 | STEP 3 密度计算 |
| 旁白对齐 | VO起止时间与画面切换精确匹配 | STEP 4 时长 + STEP 5-E |
| 镜头组合 | 每段至少一种 A/B/C 模板 | STEP 3 策略 |
| 情绪高点 | 每篇至少2处（憋屈/反转/爽） | STEP 1 曲线 + STEP 4 |
| 人物统一 | 服装/发型/道具前后一致 | STEP 2 锚点 + STEP 5-F |
| 开头策略 | 第一段强制 MS→MCU→WS | STEP 4 段01 |

## STEP 1 — DISSECT（拆解推文）

### 1.1 段落标记

```
推文拆解
标题: ___  |  类型: ___  |  总段数: ___

 # | 段落首句摘要          | 情感   | 功能        | 落点句
---|----------------------|--------|------------|--------
 1 | ___                  | ___    | 钩子/铺垫/升级/破防/反转/收束 | ___
```

### 1.2 情感曲线标注

```
情感曲线
段01: 强度 ___ | 方向 ↑↓→ | 标签: ___
峰值段落: 段___ | 低谷段落: 段___
曲线形态: W形 / 单峰 / 阶梯 / ___

★ 制作要求：标记至少2处情绪高点（憋屈/反转/爽）
```

### 1.3 旁白节奏计算

**中文旁白语速：** 日常 3.5字/秒 · 情感 2.8字/秒 · 金句 2.0字/秒

```
段时长 = 段字数 ÷ 语速 + 情感停顿(0.5-2.0s) + 画面呼吸(0.3-1.0s)
全文预估时长: ___ 秒（目标 30-120s）
```

### 1.4 完整性合约

```
完整性合约
段落数: ___ | 金句数: ___ | 隐喻/感官描写: ___ | 角色名: ___ | 物品: ___ | 场景: ___
```

### 2.1 角色锚点

```
角色锚点: [名字] — [角色功能]
  原文线索: "___"
  外观推断: 年龄约___ · 体型___ · 发型___
  面部锚点: 眼睛___ · 嘴角___ · 默认表情___
  服装推断: ___
  情绪标记: 紧张时___ · 崩溃时___ · 反转时___
  屏幕默认位: [上/中/下三分之一] · [左/中/右]
  不可变更: 1.___ 2.___
  === 制作要求附加 ===
  服装基准: ___ | 发型基准: ___ | 配饰/道具: ___
  伤口/妆容变化: ___ | 穿帮风险点: ___
```

**推断规则：** 明确描述→直接使用 · 暗示→标注「推断」 · 未涉及→补全并标注「补全」

### 2.2 场景锚点

```
场景锚点: [场景名]
  原文线索: "___"
  类型: INT/EXT · 时间: 日/夜/黄昏/黎明
  规模: 密闭/中型/开阔/宏大

  隐藏(SPIELBERG): ___
  === 制作要求附加 ===
  固定道具列表: ___ | 光线一致性: ___ | 时间流逝标记: ___
```

### 2.3 关键物品锚点

```
物品锚点: [物品名]
  原文: "___" | 字面功能: ___ | 隐喻功能: ___
  视觉强调: 需要INSERT · 不需要 | 出现段落: 段___
```

## STEP 3 — TRANSLATE（文字→画面转译）

**"这段旁白配什么画面？"**

### 3.1 五种转译策略

| 策略 | 适用场景 | 示例旁白 | 对应画面 |
|------|---------|---------|---------|
| **直译** | 明确视觉描写 | "他站在雨中" | 男人站在雨中的画面 |
| **具象化** | 情感隐喻落地 | "胸口像灌了水泥" | ECU：手紧握胸口，指节发白 |
| **反差映衬** | 旁白与画面张力 | "我很好" | 角色蹲在角落，眼泪无声流下 |
| **留白代述** | 情感旁白+环境画面 | "那一刻天塌了" | 空镜：天空/天花板缓慢下压 |
| **金句定格** | 落点句/金句 | "我先遇到他的。" | CU/MCU静态定格≥3s，字幕叠加 |

### 3.2 每段转译

```
段[N] 转译
原文: "___"
旁白字数: ___ | 预估VO时长: ___s
策略: 直译/具象化/反差映衬/留白代述/金句定格
视觉核心: ___
镜头数: ___ | 节奏: 快/中/慢
★ 密度: ___句/___镜 = ___镜/句（目标≥1.0，争取≥1.5）
★ 镜头模板: A远+近+特 / B远+近 / C近+特
```

### 3.3 转译规则

1. **旁白不可删改** — VO即推文原文，逐字保留
2. **金句必须独占镜头** — 落点句不得与其他旁白共用镜头
3. **情感峰值=镜头密度峰值** — 高潮段镜头最密（2-3镜/句）
4. **隐喻必须视觉化** — 不写"表现悲伤"，写明怎么悲伤
5. **第一人称规则** — "我"出现时：显示主角或主角所见，段内一致
6. **禁止抽象画面** — 必须具体到人/动作/光线/构图

**禁止词汇：** 悲伤/愤怒/紧张/开心/恐惧 → 替换为身体动作/微表情/光线变化

### 3.4 画面密度

| 场景类型 | 密度要求 |
|---------|---------|
| 常规旁白段 | 1.5镜头/句 |
| 对话场景 | ≥1镜头/句 |
| 金句/落点句 | ≥1镜（金句定格） |
| 情绪高潮段 | 2-3镜头/句 |

**句子拆镜：** 「主语+动作+环境」→ WS+MS+CU · 「情感+回忆+现实」→ CU+INSERT+MS · 「对话+反应」→ 说话者+听者反应+继续

### 3.5 镜头组合模板

| 编号 | 组合 | 适用 |
|------|------|------|
| **A** | 远+近+特 | 低开高走、重要揭示、情感高潮 |
| **B** | 远+近 | 平稳叙述、快速进入主题 |
| **C** | 近+特 | 已建环境后的情绪聚焦、高潮段 |

### 3.6 VO与画面关系

- **同步型：** 旁白说什么，画面展示什么（有明确视觉时）
- **反差型：** "我没事/我很好" → 画面展示相反状态
- **留白型：** 内心崩溃 → 环境/空镜
- 一段内可混合，但必须有意设计

隐喻转译困难时，读取 [references/visual-translation.md](references/visual-translation.md)。

## STEP 4 — BOARD（分镜表输出）

**★ 第一段（钩子段）强制 MS→MCU→WS 三镜头序列**

### 场景头部

```
═══════════════════════════════════════════
段[N] — [段落功能] | 情感强度: ___ | 策略: ___
═══════════════════════════════════════════
VO原文: "___"
预估时长: ___s | 镜头数: ___
★ 画面密度: ___句/___镜 = ___镜/句（目标≥1.0，争取≥1.5）
═══════════════════════════════════════════
```

### 分镜主表

| 镜号 | 景别 | 运镜 | 画面描述 | 角色表演 | VO/音效 | 时长(s) | 备注 |
|------|------|------|---------|---------|--------|--------|------|

**景别：** ECU / CU / MCU / MS / WS / ELS / INSERT / FRAGMENT / LINGER / 金句定格

- **金句定格**：静态+字幕叠加 ≥3.0s，下方20%为字幕安全区
- **FRAGMENT**：观众脑补拼合的碎片（HITCHCOCK）
- **INSERT**：需阅读的信息物
- **LINGER**：凝视/驻留 ≥4.0s

**运镜约束（强制）：**
- **固定镜头占比 ≥80%**，默认填「静态」
- 优先级：静态 > 缓推/缓拉 > 急推（仅情绪爆发点）
- **禁止**：手持 · 微漂移 · 上摇下摇 · 横移（除非特殊场景）
- 金句定格 = 纯静态，运镜归零
- 每段运镜变化最多1-2次

**画面描述（SCOTT）：** 主体位置（上/中/下三分之一）、背景、前景、构图。9:16规则：
- 单人特写：面部居中偏上，留字幕空间
- 双人对峙：上下构图或前后景
- 环境交代：纵向延伸

**角色表演：** 下巴/眼睛/眉头/嘴唇/呼吸/姿势/手势。禁止抽象情绪词。

**VO/音效：** VO引用原文+语速模式（日常/情感/金句）。音效写具体声源。

**时长地板：** ECU≥1.0 · CU≥2.0 · MCU≥3.0 · MS≥3.5 · WS≥2.0 · INSERT≥1.5 · LINGER≥4.0 · 金句定格≥3.0

**备注格式：** `[光线] ___ [功能] ___ [连贯] ___`

### 段落闭合

```
── 段[N] 闭合 ──────────────────────────────
镜头数: ___ | 金句定格: ___处
VO时长: ___s | 总时长: ___s
合约: 段落[N/N]✓ · 金句[N/N]✓ · 隐喻[N/N]✓
───────────────────────────────────────────
```

### 开头三镜头模板（段01强制）

| 序 | 景别 | 功能 | 时长 |
|----|------|------|------|
| 镜01 | MS | 交代人物与环境关系 | 3.0-4.0s |
| 镜02 | MCU | 聚焦情绪或动作细节 | 2.5-3.5s |
| 镜03 | WS | 拉开展示整体局势/反差 | 3.0-4.0s |

## 四条导演法则

| # | 法则 | 一句话 |
|---|------|--------|
| 1 | **HITCHCOCK** | 峰值时刻：展示碎片，而非全貌 |
| 2 | **SCOTT** | 具体到演员、摄影师、特效各取所需 |
| 3 | **SPIELBERG** | 每个镜头说明它隐藏了什么 |
| 4 | **MILLER** | 声明空间位置，无字幕也能成立 |

**HITCHCOCK优先** — 破防/反转必须用碎片化视觉处理。

## STEP 5 — CHECK（自检）

修复每个失败项后再声明通过。

**A · 完整性**
- [ ] 每段有分镜表，无合并/跳过
- [ ] 每句旁白被引用在VO列
- [ ] 每个金句有独立「金句定格」镜头
- [ ] 每个隐喻/感官描写已视觉转译
- [ ] 关键物品有INSERT镜头

**B · 叙事**
- [ ] 每镜备注有明确功能（非"氛围"）
- [ ] 无重复功能镜头
- [ ] 峰值段镜头最密
- [ ] 金句定格≥3.0s
- [ ] 无意反差（弱旁白+强画面需有意设计）

**C · 运镜连贯**
- [ ] 运镜出点流入下一镜入点
- [ ] 无禁止组合：缓推→缓拉 / 急推→急推 / 手持→立刻静态
- [ ] 金句定格=纯静态

**D · 具象化**
- [ ] 无单独使用悲伤/愤怒/紧张/开心/恐惧
- [ ] CU/ECU含视向+呼吸+微表情
- [ ] CU/ECU备注含光线方向+光源
- [ ] 画面描述可画=合格

**E · 时长**
- [ ] 每时长格有计算数值，无低于地板
- [ ] 全片总时长 30-120s
- [ ] **旁白时间轴对齐：VO起止与画面切换精确匹配**

**F · 统一性**
- [ ] 同角色服装/发型一致
- [ ] 场景道具位置/状态合理
- [ ] 剧情变化（受伤/换装）在备注标注
- [ ] 穿帮风险点已标记
